Clase 11: Hola mundo en la Black Pill por USB

La Black Pill es más poderosa que la Blue Pill: Cortex-M4, versiones STM32F401CCU6 y STM32F411, más memoria (incluso acepta MicroPython). Se puede programar con ST-Link o por serial como vimos antes, pero su gran ventaja es que trae el bootloader USB (DFU) de fábrica en la ROM del sistema: no gasta memoria de programa y no hay que grabarle nada. En esta clase creamos el proyecto en STM32CubeMX importando la configuración (.ioc) del proyecto básico de la Blue Pill, ajustamos el reloj a 84 MHz, generamos el código para STM32CubeIDE y lo cargamos por USB con STM32CubeProgrammer.

  • Cable USB tipo C
  • STM32CubeMX, STM32CubeIDE y STM32CubeProgrammer

Fase 1

Conocer la Black Pill

1.1

Pinout y diferencias con la Blue Pill

▶ 0:40

Es un Cortex-M4 (la Blue Pill era Cortex-M3). El LED de usuario está en PC13 y la placa tiene botones BOOT0 y RST. Trabajaremos con la menos poderosa, la F401CCU6, que llega hasta 84 MHz.

1.2

Entrar en modo bootloader USB (DFU)

▶ 2:30
  • Desconecta el cable USB.
  • Mantén presionado BOOT0 y conecta el cable.
  • En STM32CubeProgrammer elige USB y pulsa el botón de refrescar: aparece USB1. Ya puedes soltar BOOT0.
  • Pulsa Connect.

Si no aparece el puerto USB, repite: desconecta, presiona BOOT0 y vuelve a conectar.

Fase 2

Crear el proyecto importando la configuración

En lugar de configurar todo de cero, pasamos la configuración de pines del proyecto de la Blue Pill al nuevo micro.

2.1

Nuevo proyecto en STM32CubeMX

▶ 3:20

En STM32CubeMX: ACCESS TO MCU SELECTOR y busca STM32F401CCUx (o el F411 si es tu placa).

2.2

File → Import Project

▶ 4:30
  • Elige el básico.ioc de la Blue Pill.
  • Marca Import Project Settings.
  • Try Import y luego OK. Ignora los avisos: solo importamos la configuración de pines, no el código.
2.3

Revisar pines y subir el reloj

▶ 4:45

Quedan configurados el LED (PC13 con etiqueta led), el puerto serial USART1, los pines de programación SWD y el cristal. En Clock Configuration el reloj queda en 72 MHz; como este micro llega a 84 MHz, escribe 84 en HCLK y Enter.

2.4

Generar el código

▶ 5:10
  • Project Manager: nombre del proyecto (ej. basico) y carpeta.
  • Toolchain / IDE: STM32CubeIDE.
  • GENERATE CODE y abre el proyecto en CubeIDE.
Fase 3

Código y carga por USB

3.1

El parpadeo

▶ 7:00

En main.c, dentro del while(1), el mismo código de la clase pasada. Compila (Build) y verifica 0 errores.

while (1)
{
  HAL_GPIO_TogglePin(led_GPIO_Port, led_Pin);
  HAL_Delay(200);
}
3.2

Cargar con STM32CubeProgrammer

▶ 7:55
  • Pon la placa en modo DFU (BOOT0 + conectar) y dale Connect por USB.
  • Open file: busca el basico.elf en la carpeta Debug del proyecto.
  • Download.
3.3

Ejecutar

▶ 8:15

Para que el programa arranque hay que sacar el micro del modo programación: desconecta y vuelve a conectar el USB (sin BOOT0). El LED parpadea. Sin programador, solo con un cable USB.
