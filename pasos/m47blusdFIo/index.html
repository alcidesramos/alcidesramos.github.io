Clase 119: Sensor barométrico MS5611

El MS5611 mide presión barométrica y temperatura, y con ellas se calcula la altura con mucha precisión. Se usa en drones, aviones no tripulados y cohetes. Tiene interfaz I2C y SPI; aquí se usa I2C porque el sensor necesita retardos de conversión y SPI no aporta velocidad real. En CubeIDE se habilita USART1 e I2C en modo fast (400 kHz), se agrega la librería MS5611 (adaptada de una librería de internet) y se ajusta la dirección y el tiempo de conversión según la resolución (OSR) elegida.

Fase 1

El sensor

1.1

Módulo GY-63

▶ 0:00

El MS5611 mide temperatura y presión barométrica; con una fórmula se obtiene la altura con precisión de centímetros.

El pin PS selecciona la interfaz: en 1 es I2C (viene así por defecto), en 0 es SPI.

El pin CSB define la dirección I2C: a tierra es 0x76 y a positivo 0x77.

El módulo tiene regulador, así que se puede alimentar con 5 V.

Fase 3

Ajustes de la librería

3.1

Dirección del sensor

▶ 3:59

En MS5611.h se pone la dirección: 0x76 si CSB está a tierra o 0x77 si está a positivo (en este montaje es 0x77).

MS5611_Init devuelve 1 si el sensor responde. Si no responde, prueba la otra dirección; si con ninguna responde, revisa conexiones, resistencias del I2C o el sensor.

3.2

Resolución y tiempo de conversión

▶ 5:06

La lectura se hace con una de cinco resoluciones (OSR). Más resolución da un dato más preciso pero tarda más: de 1 ms en ultra low a 10 ms en ultra high.

El retardo de la función de conversión debe cubrir el tiempo de la resolución elegida; para OSR_ULTRA_HIGH se pone 10 ms.

#define OSR_ULTRA_HIGH 12   // 10 ms
#define OSR_HIGH       11   //  5 ms
#define OSR_STANDARD   10   //  3 ms
#define OSR_LOW         9   //  2 ms
#define OSR_ULTRA_LOW   8   //  1 ms

// en MS5611_convert()
HAL_Delay(10);   // ajustar según el datasheet y el OSR

Si usas una resolución más baja, baja también el retardo de MS5611_convert para no perder tiempo.

4.1

Verificar el sensor

▶ 6:12

Se declara la cadena de texto y se habilita float con printf en las propiedades del proyecto.

char texto[100];

if (MS5611_Init()==1) uartx_write_text(&huart1, "SENSOR OK\r\n");
else uartx_write_text(&huart1, "SENSOR BAD\r\n");
4.2

Lectura en el while

▶ 8:20

Se lee con la resolución elegida y se obtienen temperatura, presión y altura.

while (1)
{
  MS5611_read(OSR_ULTRA_HIGH);
  float temp = MS5611_getTemperature();
  float pres = MS5611_getPressure();
  float altura = MS5611_getaltura(pres, temp);

  sprintf(texto,"Temp=%.2f, Pre=%.2fmbar  alt=%.1f\r\n",temp,pres,altura);
  uartx_write_text(&huart1, texto);
  HAL_Delay(800);
}
4.3

Resultado

▶ 9:32

Se leen unos 31.9 °C, cerca de 1009 mbar (nivel del mar) y unos 32 m de altura (un edificio).

Al subir el sensor medio metro la altura sube y al bajarlo vuelve; al tocarlo con el dedo la temperatura aumenta. Es más rápido y preciso para altura que un GPS.
