Librería para leer un GPS

La librería GPS.c/.h se apoya en las librerías de recepción serial por DMA con detección de línea inactiva (UARTRX y UART_INT_DMA_IDLE). El GPS llega por el USART2 a 9600 con un buffer de 600 bytes; GPS_RMC y GPS_GGA extraen los campos separados por comas y los dejan en variables globales. Se prueba con el simulador Virtual GPS conectado por un cable USB-serial y se monitorea por el USART1.

Fase 1

Las tramas NMEA

1.1

Simulador Virtual GPS

▶ 0:00

Virtual GPS permite fijar latitud, longitud, altitud, velocidad, rumbo, variación magnética y hora UTC, elegir el puerto COM y las tramas NMEA que envía. La librería decodifica por ahora GPRMC y GPGGA.

1.2

Qué trae cada trama

▶ 1:06

RMC trae la hora, si el dato es válido (A) o no (V), latitud, longitud, velocidad en nudos, rumbo, fecha y variación magnética. GGA aporta el modo de fijación, el número de satélites y la altitud.

Fase 2

Configurar el proyecto

2.1

Reloj

▶ 2:10

Crea el proyecto GPS_CANAL. Activa el cristal externo y un reloj moderado (80 MHz), suficiente para el GPS y compatible con F401 y F411.

2.2

USART1 para monitoreo

▶ 2:43

USART1 asíncrono a 9600 para enviar los datos al PC. Se le puede agregar DMA RX e interrupción para recibir otro dispositivo, aunque en este código no se usa.

2.3

USART2 para el GPS

▶ 3:16

El GPS va en el USART2 a 9600. Aquí sí es obligatorio agregar DMA RX y habilitar la interrupción global.

Fase 3

Integrar las librerías

3.1

Copiar e incluir

▶ 4:22

Crea la carpeta Librerias (en el include path) y copia GPS.c/.h, uart.c/.h, UARTRX.c/.h y UART_INT_DMA_IDLE.c. Incluye en main.c y activa Use float with printf.

#include "uart.h"
#include "UARTRX.h"
#include "GPS.h"

#include "stdio.h"
#include "stdlib.h"
#include "stdint.h"
#include "string.h"
3.2

Declarar el puerto del GPS

▶ 6:01

GPS.h trae la guía de uso. En UARTRX.c declara los UART y crea la estructura del GPS en el USART2 con un buffer de 600 (depende del largo de las tramas que envíe tu GPS). En UARTRX.h debe existir el extern.

// UARTRX.c
extern UART_HandleTypeDef huart1;
extern UART_HandleTypeDef huart2;

UARTRXS UARTRX1    = {&huart1, USART1, 100};
UARTRXS GPS_UARTRX = {&huart2, USART2, 600};

// UARTRX.h
extern UARTRXS GPS_UARTRX;
3.3

Buffer y zona horaria en GPS.c

▶ 7:42

En GPS.c pon el mismo tamaño de buffer y la diferencia horaria con UTC (Colombia es -5).

char GPS_buffer[600];  //tamaño buffer para captura de datos gps
#define hor_utc -5    //define la hora de colombia utc -5
3.4

Llamar a GPS_Interrupt

▶ 8:47

En UART_INT_DMA_IDLE.c incluye GPS.h y dentro de HAL_UARTEx_RxEventCallback llama a GPS_Interrupt. Si además quieres recibir otros datos por el USART1, deja también uartRX_INTERRUPT.

#include "GPS.h"

void HAL_UARTEx_RxEventCallback(UART_HandleTypeDef *huart, uint16_t Size)
{
    //llamar interrupciones de usart
    // uartRX_INTERRUPT(huart, Size);
    GPS_Interrupt(huart, Size);
}
Fase 4

Cómo decodifica

4.1

Validar y recorrer campos

▶ 9:56

GPS_RMC busca $GPRMC, copia hasta el fin de línea y avanza coma por coma con strtok. Primero revisa el campo de estado: si es A el dato es válido y continúa capturando hora, latitud, longitud y demás. En GGA el campo 6 indica el modo (0 sin fijar, 1 GPS, 2 diferencial).

Fase 5

Usar el GPS en main

5.1

Inicializar y leer

▶ 9:56

Antes del while arranca la recepción del GPS. En el while, cuando hay trama nueva, llama a GPS_RMC y GPS_GGA y usa las variables globales que llenan.

char texto[100];

uartx_write_text(&huart1, "INICIANDO\r\n");
uartRX_it_idle_dma_init(&GPS_UARTRX);

while (1)
{
    if (GPS_UARTRX.flag_rx == 1)
    {
        GPS_RMC();
        sprintf(texto, "LAT=%.5f   LON=%.5f\r\n", latitud, longitud);
        uartx_write_text(&huart1, texto);
        sprintf(texto, "A=%u  M=%u  D=%u\r\n", an_gps, mes_gps, dia_gps);
        uartx_write_text(&huart1, texto);

        GPS_GGA();
        sprintf(texto, "MOD=%u  SAT=%u\r\n", gps_modo, gps_satelites);
        uartx_write_text(&huart1, texto);
    }
    HAL_Delay(600);
}

Si no llega nada, revisa primero que el puerto de monitoreo funciona con un mensaje de inicio; en el video el problema era un cable suelto.

5.2

Variables disponibles

▶ 12:18

Además de latitud y longitud, la librería deja hor_gps, min_gps, seg_gps, dia_gps, mes_gps, an_gps, gps_vel_nudos, gps_vel_kph, gps_rumbo, gps_desv_mag, gps_modo, gps_satelites y gps_altura.

5.3

Prueba con Virtual GPS

▶ 17:23

Con el simulador en el COM del USART2 y Hercules en el del USART1 se ven hora, fecha, posición, velocidad (6 km/h = 3,24 nudos), modo 1 y 5 satélites. Al cambiar latitud, altitud (a 100 m) o agregar un satélite, los valores cambian en el monitor.
