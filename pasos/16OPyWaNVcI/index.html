Seguidor con velocidad base y giro

En lugar de girar con un motor adelante y otro atrás, los dos motores van siempre hacia adelante a una velocidad base. Según los sensores se calcula una velocidad de giro positiva o negativa que se suma a un motor y se resta al otro, limitando cada PWM entre 0 y 255. La velocidad de giro no debe superar la base. La función alante recibe ahora un valor con signo y analiza_sensores solo asigna esa velocidad. Al subir la base y el giro a 80, 90 o 110 se ve cómo mejora el seguimiento hasta que el robot se sale; los valores reales dependen de los motores.

Fase 2

El código

2.1

Nueva función adelante

▶ 2:52

La velocidad ahora tiene signo: se suma a un motor, se resta al otro y se limitan los valores.

// carro avanza adelante
void alante(signed int velo) {
  signed int veld, veli;
  veld = velo_BASE + velo;
  veli = velo_BASE - velo;

  if (veld >= 255) veld = 255;
  if (veld <= 0) veld = 0;
  if (veli >= 255) veli = 255;
  if (veli <= 0) veli = 0;

  PWM1_Set_Duty(veld);
  PWM2_Set_Duty(veli);
  md_alante();
  mi_alante();
}
2.2

Analizar los sensores

▶ 4:04

Ya no se manda derecha o izquierda, solo el valor de la velocidad de giro con su signo. El signo de cada caso se ajusta según la pista.

void analiza_sensores() {
  if      ((SI==negro)  && (SC==negro)  && (SD==negro))  velocidad = velo_giro;
  else if ((SI==negro)  && (SC==negro)  && (SD==blanco)) velocidad = -velo_giro;
  else if ((SI==negro)  && (SC==blanco) && (SD==negro))  velocidad = -velo_giro; // valor imposible
  else if ((SI==negro)  && (SC==blanco) && (SD==blanco)) velocidad = -velo_giro;
  else if ((SI==blanco) && (SC==negro)  && (SD==negro))  velocidad = velo_giro;
  else if ((SI==blanco) && (SC==negro)  && (SD==blanco)) velocidad = 0;
  else if ((SI==blanco) && (SC==blanco) && (SD==negro))  velocidad = velo_giro;
  else if ((SI==blanco) && (SC==blanco) && (SD==blanco)) velocidad = 0;
}
