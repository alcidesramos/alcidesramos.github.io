Datalogger con SD en XC8

El circuito tiene un PIC18F25K50 a 20 MHz, un sensor DS18B20, un reloj DS1307, una memoria SD por SPI, un pulsador en RB7 y la salida serial. En el MCC se configura el oscilador, el MSSP1 como SPI maestro (al inicio a baja velocidad), la EUSART y los pines. Para la SD se usa la librería FatFs (ff.c y diskio.c) adaptada a XC8; para el DS1307 una librería con I2C por software en RC0 y RC1, y para el DS18B20 una librería OneWire en RA0. El programa monta la memoria, crea el archivo con las cabeceras y, mientras el pulsador esté sin oprimir, escribe cada dos segundos una línea con temperatura, hora y fecha. Al oprimirlo se cierra el archivo.

2.2

Montar y crear el archivo

▶ 20:30

Se espera a que la memoria monte, se abre o crea el archivo y se escriben las cabeceras.

printf("INICIANDO\r\n");
//espera que este la memoria
while (f_mount(&sd_mem, "0", 1) != FR_OK);
printf("MEMORIA INICIADA\r\n");

// abre o crea el archivo
if (f_open(&fila, "0:datos4.txt", FA_OPEN_ALWAYS | FA_READ | FA_WRITE) == FR_OK)
{
  printf("ARCHIVO CREADO\r\n");
  f_write(&fila, "TEMPE\t", 6, &nada);     // Escribe Temperatura
  f_write(&fila, "HORA\t\t", 6, &nada);    // Escribe Hora
  f_write(&fila, "FECHA\r\n", 7, &nada);   // Escribe Fecha
  f_close(&fila);                           // cierra el archivo
}

3.2

Lectura del DS18B20

▶ 29:13

La función de lectura reinicia el bus, salta la dirección (0xCC) e inicia la conversión (0x44). Antes del ciclo se hacen lecturas iniciales para evitar el 85 del primer dato.

float ds18b20_read()
{
  unsigned int temp_;
  float tempo__;
  unsigned char t1_, t2_, td__;
  float signo = 1.0;
  float sensor_temp_;

  Ow_Reset();          // Onewire reset signal
  __delay_ms(18);
  Ow_Write(0xCC);      // direcciona todos sensores
  __delay_ms(1);
  Ow_Write(0x44);      // inicia conversion
  __delay_ms(150);
  // ... lectura del scratchpad (ver video)
}
Fase 4

Registro

4.1

Escribir hora y fecha

▶ 30:53

Con sprintf se arma la hora y la fecha. Si el pulsador no está oprimido se escriben en el archivo y también se envían por serial.

Al oprimir el pulsador se cierra el archivo.

//arma la trama de hora dando tab
memset(texto, 0, 50);   //limpia la trama
sprintf(texto, "%02u:%02u:%02u\t", (unsigned int)ds1307._hora, (unsigned int)ds1307._minuto, (unsigned int)ds1307._segundo);
printf(texto);
if (PORTBbits.RB7 == 1) f_write(&fila, &texto, strlen(texto), &nada);

//arma trama de mes año y dia poniendo enter
memset(texto, 0, 50);
sprintf(texto, "%02u/%02u/20%02u\r\n", (unsigned int)ds1307._fecha, (unsigned int)ds1307._mes, (unsigned int)ds1307._anho);
if (PORTBbits.RB7 == 1) f_write(&fila, &texto, strlen(texto), &nada);

//lo manda serial
printf(texto);

if (PORTBbits.RB7 == 0)
{
  f_close(&fila);   //cierra el archivo
  printf("CERRADA\r\n");
}
__delay_ms(2000);
