Sensores QTR: calibración y normalización

Segunda parte de la lectura de los sensores QTR. La lectura de tiempo que obtuvimos en el video anterior se convierte en unos y ceros: primero se calibra recorriendo la pista para guardar el máximo y el mínimo de cada sensor, y luego se normaliza comparando cada lectura con el punto medio. Un LED en PB13 indica cuándo el sistema está calibrando. Al final se agregan #define para elegir si el negro vale 1 o 0 (pista negra con línea blanca o al revés).

Fase 1

Calibración

1.1

Punto de partida

▶ 0:20

En la clase anterior se leía cuánto tarda en caer la señal de cada sensor. Ese tiempo depende del color, pero en robótica lo que se necesita es un 1 o un 0 para saber si el sensor está sobre la línea.

En la librería se corrigieron los nombres: ahora todas las funciones empiezan por QTR_ (QTR_lectura, QTR_calibra, QTR_Normaliza...).

1.2

Llamar a la calibración

▶ 1:10

Antes del while se llama a QTR_calibra con el número de muestras. Más muestras significa más tiempo para pasar el carrito por la pista. QTR_Manda_Limites envía por la UART los máximos y mínimos medidos, solo para revisar.

QTR_Init();
uartx_write_text(&huart1, "INICIANDO\r\n");
QTR_calibra(80);        // 80 muestras: ajústalo a la velocidad de tu micro
QTR_Manda_Limites();    // opcional: imprime maximos y minimos
1.3

Qué hace QTR_calibra

▶ 2:30

Enciende el LED de calibración, lee los sensores muchas veces y guarda para cada uno el valor más alto y el más bajo. Al terminar apaga el LED: desde ese momento ya no sirve seguir moviendo el carrito.

#ifdef LEDIR_Pin
HAL_GPIO_WritePin(LEDIR_GPIO_Port, LEDIR_Pin, 1);  // enciende LED de calibración
#endif

// toma N muestras del terreno para calibrar los sensores
for (cuenta2 = 0; cuenta2 < veces; cuenta2++)
{
  for (cont = 0; cont < 8; cont++)
  {
    QTR_lectura(lecturasir);
    if (lecturasir[cont] >= maximos[cont]) maximos[cont] = lecturasir[cont];
    if (lecturasir[cont] <= minimos[cont]) minimos[cont] = lecturasir[cont];
  }
}

#ifdef LEDIR_Pin
HAL_GPIO_WritePin(LEDIR_GPIO_Port, LEDIR_Pin, 0);  // apaga LED de calibración
#endif

El LED está dentro de #ifdef LEDIR_Pin: si no creas el pin, la librería funciona igual pero no tendrás aviso de cuándo termina la calibración.

1.4

Configurar el LED en CubeMX

▶ 3:30

En el .ioc se pone PB13 como GPIO_Output con la etiqueta LEDIR. Con ese nombre la librería lo detecta sola. Recuerda generar el código antes de compilar.

1.5

Revisar máximos y mínimos

▶ 4:25

Con el LED encendido se pasa el carrito por blanco y por negro. Cuando el LED se apaga, la terminal muestra los límites: mínimos cercanos a 0 a 16 y máximos cercanos a 1000. Los sensores 7 y 8 salen en 0 porque este carrito solo tiene 6.

Fase 2

Normalización

2.1

Llamar a QTR_Normaliza

▶ 5:38

Ya no hace falta enviar los límites. Después de cada lectura se llama a QTR_Normaliza sobre el mismo arreglo, y lo que se imprime ya son unos y ceros.

QTR_calibra(80);

while (1)
{
  HAL_GPIO_TogglePin(LED_GPIO_Port, LED_Pin);
  QTR_lectura(lecturas);
  QTR_Normaliza(lecturas);   // ahora lecturas[] vale 0 o 1
  sprintf(texto, "SEN1=%d\r\n", lecturas[0]);
  uartx_write_text(&huart1, texto);
  // ... igual para SEN2 a SEN6
}
2.2

Qué hace QTR_Normaliza

▶ 6:44

Para cada sensor calcula el punto medio entre su mínimo y su máximo. Si la lectura actual supera ese umbral, el sensor vale 1; si no, 0.

// normaliza el valor leído en un rango, en este caso de 0 a 1
void QTR_Normaliza(uint16_t *lectu_QTR)
{
  uint8_t cuenta;
  float min_temp, max_temp;
  float promedio;

  for (cuenta = 0; cuenta < 8; cuenta++)
  {
    min_temp = minimos[cuenta];
    max_temp = maximos[cuenta];
    promedio = (max_temp - min_temp) / 2;   // mitad del rango del sensor
    if (lectu_QTR[cuenta] >= (min_temp + promedio)) lectu_QTR[cuenta] = 1;
    else lectu_QTR[cuenta] = 0;
  }
}
2.3

Prueba

▶ 7:17

Se calibra pasando el carrito varias veces por la línea y luego se mueve: los sensores sobre la línea negra marcan 1 y los que están sobre blanco marcan 0.

Hay que calibrar cada vez que se enciende. Estos sensores son muy sensibles a la luz infrarroja del lugar, que cambia de un recinto a otro y con la hora del día.

Fase 3

Elegir qué color vale 1

3.1

Defines NEGRO y BLANCO

▶ 8:59

En QTR.h, después de los include, se definen dos constantes y en QTR_Normaliza se usan en lugar del 1 y el 0. Intercambiándolas se adapta el código a una pista negra con línea blanca.

// QTR.h
#define NEGRO  1
#define BLANCO 0

// QTR_Normaliza
if (lectu_QTR[cuenta] >= (min_temp + promedio)) lectu_QTR[cuenta] = NEGRO;
else lectu_QTR[cuenta] = BLANCO;

// línea blanca sobre pista negra: invierte el resultado
