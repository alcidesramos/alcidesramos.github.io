Hola mundo en un Cortex-M0

El hola mundo con la tarjeta STM32F030 Demo Board (Cortex-M0, 20 pines): configurar cristal, reloj y el LED en CubeMX, escribir el código en el lugar correcto para que CubeMX no lo borre, y programarla de tres formas: STM32CubeProgrammer con ST-Link, Keil µVision y por serial con el bootloader.

▶ Ver el video completo (18:21) Empezar el paso a paso
  • Tarjeta: STM32F030 Demo Board (STM32F030F4P6, cristal 8 MHz, LED en PA4)
  • Programador: ST-Link V2 o cable USB-serial
  • Software: STM32CubeMX, STM32CubeIDE, Keil µVision, STM32CubeProgrammer

Fase 1

La tarjeta

1.1

STM32F030 Demo Board

▶ 0:00

Micro STM32F030F4P6 de 20 pines. El USB es solo para alimentación (el micro no tiene USB). Se programa con ST-Link (pines GND, CLK, DIO, 3V3) o por serial (TXD/RXD). Tiene botón de reset, jumper de BOOT0 y un LED en PA4.

Fase 2

Configurar en CubeMX

2.1

Escoger el micro y el cristal

▶ 1:06

Nuevo proyecto con STM32F030F4. En System Core → RCC, High Speed Clock (HSE): Crystal/Ceramic Resonator, porque la tarjeta trae cristal de 8 MHz.

2.2

Reloj al máximo (48 MHz)

▶ 2:13

En Clock Configuration escribe 48 en HCLK y Enter: CubeMX calcula el PLL (multiplicadores y divisores) para llegar a esa frecuencia.

2.3

El LED como salida

▶ 2:49

Clic en PA4 → GPIO_Output y etiqueta led. En GPIO se puede escoger push-pull (0 o 3.3 V) u open drain (con resistencia a 5 V da 5 V, útil para interfaces).

2.4

Generar el proyecto

▶ 3:23

En Project Manager: nombre (holamundo_M0), carpeta y Toolchain/IDE: STM32CubeIDE (o MDK-ARM para Keil). Generate Code y abrir.

Fase 3

El código

3.1

Parpadeo en el while(1)

▶ 5:06

En Core/Src/main.c, dentro del while (1). Con Ctrl + espacio, el IDE completa los nombres.

/* USER CODE BEGIN WHILE */
while (1)
{
  HAL_GPIO_TogglePin(led_GPIO_Port, led_Pin);
  HAL_Delay(200);   // milisegundos
  /* USER CODE END WHILE */

  /* USER CODE BEGIN 3 */
}
/* USER CODE END 3 */
3.2

Escribe solo entre USER CODE BEGIN y END

▶ 6:46

Si vuelves a generar código desde CubeMX, todo lo que esté fuera de un bloque /* USER CODE BEGIN x */ … /* USER CODE END x */ se borra. Eso vale para includes, variables, defines y código.

Ojo: código fuera de los bloques USER CODE = código perdido al regenerar.

Fase 4

Programar la tarjeta

4.1

CubeIDE + ST-Link: error con un clon

▶ 8:29

Conecta GND, SWCLK, SWDIO y 3.3 V del ST-Link. Compila en Release. En Debug Configurations escoge ST-LINK (SWD). Como el micro no es original, CubeIDE da error y no programa.

4.2

Solución: STM32CubeProgrammer

▶ 10:00

Abre el programador, conéctate por ST-Link, abre el .elf (o el .hex, activándolo en MCU Post build outputs) y Download. El LED parpadea.

4.3

Con Keil µVision

▶ 11:32

En CubeMX cambia el Toolchain a MDK-ARM y genera. Keil avisa Not a genuine ST Device, pero al aceptar sí programa. Hay que desconectar y conectar la tarjeta para que arranque.

4.4

Por serial con el bootloader

▶ 14:22

Sin ST-Link: cable USB-serial a TXD/RXD (y GND). Pasa el jumper BOOT0 a 3.3 V, reinicia, y en CubeProgrammer escoge UART, el puerto COM, Connect y Download. Luego regresa BOOT0 a 0 y reinicia para que corra el programa.

Ojo: con algunos clones la programación por serial graba pero el programa no corre. En ese caso, mejor el ST-Link.
