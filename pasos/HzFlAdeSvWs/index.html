ST-Link como memoria USB para programar

Una función más del programador WeAct: al cambiar el tipo de firmware a STM32 Debug + Mass storage + VCP, al conectarlo aparece en Windows una unidad llamada STLINK, como una memoria USB. Basta arrastrar el archivo .hex a esa unidad para programar el micro, sin abrir STM32CubeProgrammer ni STM32CubeIDE.

Fase 1

Cambiar el tipo de firmware

1.1

Puerto serial ya disponible

▶ 0:00

Al conectarlo, en el Administrador de dispositivos ya aparece STMicroelectronics STLink Virtual COM Port: sirve como cable USB-serial.

1.2

Abrir Firmware upgrade

▶ 0:33

En STM32CubeProgrammer pulsa Firmware upgrade. Desconecta y vuelve a conectar el programador, pulsa Refresh y Open in update mode.

1.3

Change Type

▶ 1:07

Marca Change Type y elige STM32 Debug+Mass storage+VCP en vez de STM32 Debug+VCP. Pulsa Upgrade.

1.4

Listo

▶ 2:00

Al terminar dice Upgrade successful y el tipo queda como Debug+Mass storage+VCP. Windows muestra una unidad nueva llamada STLINK.

Si algo no te gusta, vuelve a Change Type y deja el firmware como estaba.

Fase 2

Programar arrastrando

2.1

Copiar el .hex a la unidad STLINK

▶ 2:40

Busca el programa en la carpeta Debug del proyecto y copia el archivo .hex a la unidad STLINK. El .elf no lo acepta (es más pesado); usa el .hex.

La copia programa el micro y el LED empieza a titilar.

2.2

Para qué sirve

▶ 4:01

Si alguien te pasa un .hex, puedes programar una tarjeta sin instalar CubeProgrammer ni CubeIDE. El mismo programador sigue dando 3.3 V y 5 V, puerto serial y debug con STM32CubeIDE.
