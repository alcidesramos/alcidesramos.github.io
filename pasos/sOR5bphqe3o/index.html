Texas Instruments: interrupción por timer

Se tienen dos procesos: uno lento en el ciclo principal (un LED cada 2 segundos) y uno rápido por interrupción. En HALCoGen se habilitan los drivers GIO y RTI, se habilita en el VIM la interrupción del comparador 0 del RTI y se ajusta su periodo a 150 ms. En Code Composer Studio se inicializa el RTI, se habilita su notificación y las interrupciones IRQ, se arranca el contador y se escribe rtiNotification.

2.2

Arrancar el RTI

▶ 4:52

Se inicializan GIO y RTI, se habilita la notificación del comparador 0, se habilitan las interrupciones IRQ y se arranca el bloque de contador 0. El ciclo principal cambia el LED del pin 6 cada 2 segundos.

int main(void)
{
  gioInit();
  rtiInit();
  rtiEnableNotification(rtiREG1, rtiNOTIFICATION_COMPARE0); // habilita la interrupción del compare 0
  _enable_IRQ_interrupt_();                                  // habilita IRQ
  rtiStartCounter(rtiREG1, rtiCOUNTER_BLOCK0);               // arranca el contador 0

  while (1)
  {
    gioToggleBit(gioPORTB, 6);
    delay_ms(2000);
  }
}
2.3

La notificación del timer

▶ 5:58

La función rtiNotification está declarada en HL_rti.h y la escribe el usuario. Ahí se cambia el otro LED, que queda titilando cada 150 ms.

void rtiNotification(rtiBASE_t *rtiREG, uint32 notification)
{
  gioToggleBit(gioPORTB, 7);
}
