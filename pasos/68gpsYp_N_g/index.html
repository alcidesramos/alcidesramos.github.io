Fase 1

Leer tramas

1.1

Nuevas funciones de la librería

▶ 0:00

uartx_read lee un solo carácter (lo de la clase 39). uartx_read_text lee hasta encontrar el carácter final o hasta llenar el tamaño indicado; antes limpia el buffer.

uint8_t uartx_read(UART_HandleTypeDef *huart)
{
    uint8_t dato_rx = 0;
    HAL_UART_Receive(huart, &dato_rx, 1, HAL_MAX_DELAY);
    return (dato_rx);
}
void uartx_read_text(UART_HandleTypeDef *huart, uint8_t *info, const uint8_t final, uint8_t cuanto)
{
    uint8_t dato_rx = 0;   // los datos leidos son de 8 bits
    char i = 0;
    memset(info, 0, cuanto);   // limpia el buffer
    while (dato_rx != final)   // lee hasta que llegue el final
    {
        dato_rx = uartx_read(huart);
        *info = dato_rx;   // va almacenando en el buffer
        info++;
        i++;
        if (i > cuanto - 1) break;   // si llegan n elementos sale
    }
}

Fase 2

Motor con L293D

2.1

El puente H

▶ 2:15

El L293D maneja dos motores de hasta 1 A por canal (el L298 hasta 2 A). A la izquierda las señales del micro, a la derecha el voltaje del motor (+12 V). Con EN1 en 1: IN1=1, IN2=0 gira a un lado, 0, 1 al otro, 0, 0 o 1, 1 frena. Con EN en 0 el motor queda libre.

2.2

Funciones del motor

▶ 3:56

Pines M11 (PB12) y M12 (PB13) como salidas:

void m1derecha()
{
    HAL_GPIO_WritePin(M11_GPIO_Port, M11_Pin, 0);
    HAL_GPIO_WritePin(M12_GPIO_Port, M12_Pin, 1);
}
void m1izquierda()
{
    HAL_GPIO_WritePin(M11_GPIO_Port, M11_Pin, 1);
    HAL_GPIO_WritePin(M12_GPIO_Port, M12_Pin, 0);
}
void m1stop()
{
    HAL_GPIO_WritePin(M11_GPIO_Port, M11_Pin, 0);
    HAL_GPIO_WritePin(M12_GPIO_Port, M12_Pin, 0);
}
Fase 3

Procesar órdenes

3.1

Órdenes directas con strstr

▶ 7:48

strstr dice si la trama contiene un texto. Crea una función que procese lo recibido y llámala después de leer:

void procesarx()
{
    if (strstr(trama_rx, "M1DER")) m1derecha();
    else if (strstr(trama_rx, "M1IZQ")) m1izquierda();
    else if (strstr(trama_rx, "M1STOP")) m1stop();
}
while (1)
{
    uartx_read_text(&huart1, trama_rx, '*', 50);
    procesarx();
    HAL_GPIO_TogglePin(led1_GPIO_Port, led1_Pin);
    HAL_Delay(200);
}

Las órdenes se envían terminadas en *: M1DER*, M1IZQ*, M1STOP*. Deben coincidir exactamente, mayúsculas incluidas. Los warnings de tipo (uint8_t vs char) no son críticos.

Fase 4

Extraer números

4.1

strtok y atoi

▶ 15:17

Para LEDON=2/*: strtok corta en el = y luego hasta el /, y atoi convierte el texto a entero (atof para flotantes). Así más adelante se podrá mandar, por ejemplo, la velocidad de un motor.

char texto[50];
uint8_t valor;
else if (strstr(trama_rx, "LEDON="))
{
    strcpy(texto, strtok(trama_rx, "="));   // inicia captura de tokens
    strcpy(texto, strtok(0, "/"));          // captura primer dato
    valor = atoi(texto);
    switch (valor)
    {
        case 2: HAL_GPIO_WritePin(led2_GPIO_Port, led2_Pin, 1); break;
        case 3: HAL_GPIO_WritePin(led3_GPIO_Port, led3_Pin, 1); break;
    }
}
