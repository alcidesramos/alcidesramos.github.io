Puerto COM por USB (CDC)

Con la clase CDC el micro aparece en Windows como un puerto COM y sirve para LabVIEW, Hercules o cualquier programa serial. Se instala el paquete USB Device de Libstock, se agrega el descriptor VCP al proyecto y se incluye la librería. En el main se inicia el USB y en el ciclo se revisa el buffer; lo recibido se procesa y aquí se devuelve como eco.

▶ Ver el video completo (19:10) Empezar el paso a paso
  • MikroC PRO for PIC con el paquete USB Device (Libstock)
  • PIC18F2550 con cristal de 8 MHz
  • Conector USB y capacitor de más de 10 µF en VUSB
  • Driver VCP para Windows
  • Hercules

Proyecto

▶ 2:10

PIC18F2550 con cristal de 8 MHz. En la vida real se configura el PLL para que el USB tenga sus 48 MHz; también se habilita el regulador de USB.

1.3

Descriptor y librería

▶ 3:54

Se agrega al proyecto el archivo VCP_Descriptor.c (ahí va el nombre del dispositivo) y se incluye la librería usb_cdc_lib.h. Si da error, se instala el paquete USB Device desde Libstock y se activa en el Library Manager.

Fase 2

Programa

2.1

Buffers y funciones

▶ 9:39

Buffers de 64 bytes, la bandera de dato recibido y las funciones que pide la librería. cdc_analiza prepara el buffer de recepción cuando el dispositivo se configura.

char buffer[64] absolute 0x500;
char trama[64] absolute 0x555;   // transmision
void USBDev_CDCParamsChanged() { }
extern const uint8_t _USB_CDC_BULK_EP_IN;
extern const uint8_t _USB_CDC_BULK_EP_OUT;
uint8_t datoRecibido = 0;
uint16_t dataReceivedSize;

void USBDev_CDCDataReceived(uint16_t size) {
  datoRecibido = 1;
  dataReceivedSize = size;
}
void cdc_analiza() {
  if (USB_CDC_DeviceConfigured) {
    USBDev_CDCSetReceiveBuffer(buffer);
    USB_CDC_DeviceConfigured = 0;
  }
}
2.2

Interrupción y proceso

▶ 10:14

La interrupción llama al manejador del USB; si se usan otras interrupciones van ahí también. procesa_recibido es donde se decodifica la trama; en el ejemplo solo devuelve lo que llegó.

void interrupt() {
  USBDev_IntHandler();
  // aqui otras interrupciones
}
void procesa_recibido() {
  datoRecibido = 0;
  manda_cdc_text(buffer);           // eco
  USBDev_CDCSetReceiveBuffer(buffer);
  memset(buffer, 0, 64);
}
2.3

Main

▶ 11:37

Todo digital, un retardo para que Windows cree el puerto, se inicia el USB y en el ciclo siempre se llama cdc_analiza.

ADCON1 = 0b1111;
Delay_ms(1000);
usb_cdc_init();
Delay_ms(1000);
while (1) {
  cdc_analiza();
  if (datoRecibido == 1) procesa_recibido();
}
