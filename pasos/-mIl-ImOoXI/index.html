Velocista: leer sensores digitales

El robot Zumo de Proteus tiene seis sensores tipo QTR-RC: en lugar de una resistencia tienen un capacitor y se mide cuánto tarda en descargarse; sobre negro tarda más. El procedimiento es encender los LEDs, poner el pin como salida en 1, esperar 10 µs, pasarlo a entrada y medir el tiempo hasta que cae. Con un PIC18F25K50 a 4 MHz, el Timer1 se configura para unos 5 ms (TMR1H 236, TMR1L 120) y durante ese tiempo se guarda el valor del timer cuando cae cada sensor. Los valores se envían por serial. Luego se calibra moviendo el robot sobre la línea para hallar el máximo y el mínimo de cada sensor, y se normaliza: si la lectura supera el mínimo más la mitad del rango es 1, si no 0.

Pines

2.2

Configurar el Timer1

▶ 9:21

El timer queda apagado hasta que se necesita.

void config_timer1() {
  T1CON = 0;
  // 5 milisegundos
  TMR1H = 236;
  TMR1L = 120;
  // prescalador uno
  T1CKPS1_bit = 0;
  T1CKPS0_bit = 0;
  TMR1IF_bit = 0;
  TMR1ON_bit = 0;
}
2.3

Analizar los sensores

▶ 10:29

Se encienden los LEDs, se sacan unos, se espera 10 µs, se pasan a entrada y se arranca el timer. Mientras no se desborda, cuando cae un sensor se guarda el valor del timer y se activa su bandera.

void analizasensoresir() {
  char cuenta1;
  config_timer1();
  leds = 1;          // enciende la regleta de los leds
  config_salidas();
  saca_uno();
  Delay_us(10);
  config_entradas();
  TMR1ON_bit = 1;    // prende el timer
  // limpia la lectura de los sensores
  for (cuenta1 = 0; cuenta1 <= 8; cuenta1++) lecturas[cuenta1] = 0;
  banderas = 0;      // limpia las banderas de los sensores
  while (TMR1IF_bit == 0) {
    // ... igual para cada sensor
    // detecta si ya cayó la señal del sensor6
    if ((s6_in == 0) && (flag_s6 == 0)) {
      lecturas[5] = (unsigned int)TMR1H << 8 | TMR1L;
      flag_s6 = 1;
    }
  }  // fin del tiempo para leer los sensores
  leds = 0;  // apaga la regleta para ahorrar batería
}

3.1

3.2

Calibrar

▶ 21:24

Durante 200 muestras se mueve el robot sobre la línea y se actualizan el máximo y el mínimo de cada sensor. El LED indica que terminó y se mandan los límites.

for (cont = 0; cont < 6; cont++) {
  analizasensoresir();
  if (lecturas[cont] >= maximos[cont]) maximos[cont] = lecturas[cont];
  if (lecturas[cont] <= minimos[cont]) minimos[cont] = lecturas[cont];
}
// dentro de un ciclo de 200 muestras (ver video)
led = 1;
Delay_ms(500);
led = 0;

Al arrancar

▶ 23:01

3.4

Normalizar

▶ 24:39

Para cada sensor se calcula la mitad del rango; si la lectura supera el mínimo más esa mitad es 1, si no 0. Con línea blanca se invierten.

void normaliza() {
  unsigned char cuenta;
  float min_temp, max_temp;
  float promedio;
  for (cuenta = 0; cuenta < 6; cuenta++) {
    min_temp = minimos[cuenta];
    max_temp = maximos[cuenta];
    promedio = (max_temp - min_temp) / 2;
    if (lecturas[cuenta] >= (min_temp + promedio)) normalizados[cuenta] = 1;
    else normalizados[cuenta] = 0;
  }
}
