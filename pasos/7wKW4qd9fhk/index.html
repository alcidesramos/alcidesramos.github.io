Del joystick a una trama serial

La trama tiene inicio (INI=), datos separados por / y final (*), para que el receptor no la confunda. Se configura VISA con el puerto y el carácter de terminación desactivado. Un Wait Until Next ms Multiple mantiene un periodo de envío constante (50 a 100 ms según el micro). Los números se pasan a texto con Number To Fractional String (sin usar el punto decimal del sistema) y los botones con un Select que da 1 o 0. Todo se une con Concatenate Strings y se envía con VISA Write. Con un puerto virtual y Hercules se ve la trama cambiar al mover el control.

Fase 1

La trama

1.1

Formato

▶ 0:00

INI=/ al inicio, cada dato terminado en / y un * al final. Ejemplo: INI=/-90/50/1/0/*. El micro debe separar cada valor.

1.2

Puerto serial

▶ 1:05

Se crea un puerto virtual con VSPE. En LabVIEW, VISA Configure Serial Port con el puerto, 9600 baudios y el carácter de terminación en falso.

1.3

Periodo constante

▶ 2:46

Wait Until Next ms Multiple espera hasta el siguiente múltiplo del tiempo, así el envío es regular aunque el ciclo tarde distinto. Con un PIC16 o PIC18, 50 a 100 ms; con un dsPIC o un ARM puede ser más rápido.

Fase 2

Armar la cadena

2.1

VISA Write

▶ 4:28

VISA Write va dentro del ciclo y VISA Close afuera. Lo que se escribe tiene que ser texto.

2.2

Números a texto

▶ 5:07

Number To Fractional String con un decimal y use system decimal point en falso, para que siempre salga con punto.

2.3

Botones a texto

▶ 6:47

Un Select da "1" si el botón está presionado y "0" si no.

2.4

Concatenar

▶ 8:02

Concatenate Strings une INI=/, dirección, /, velocidad, /, led1, /, led2, / y *.

Fase 3

Probar

3.1

Ver la trama

▶ 10:55

Con un indicador se ve la trama cambiar al mover el control y presionar los botones.

3.2

En la terminal

▶ 12:38

Hercules en el otro puerto virtual recibe la trama continuamente. Esto es lo que le llegará al microcontrolador, que es la parte 3.
