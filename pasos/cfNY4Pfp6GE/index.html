Recibir datos de Ubidots con SIM800

En el tablero de Ubidots se agregan un switch y un slider (PWM). Para leerlos se hace una petición GET por cada variable, pidiendo solo el último valor (page_size=1). Ubidots responde con un texto largo; para no llenar la RAM, una máquina de estados en la interrupción serial guarda solo la parte que trae el valor. Luego strtok toma lo que hay entre los dos puntos y la coma y atof lo convierte. El ciclo completo envía datos y GPS y luego lee las variables.

Variables nuevas

Fase 2

En el PIC

2.1

Variables

▶ 4:56

Se agregan variables para lo capturado y para los valores de suiche y pwm, y un nuevo estado inicial para la recepción de Ubidots.

2.2

Máquina de estados

▶ 6:33

La interrupción busca el texto del campo value; desde ahí guarda en trama_rx hasta el final del dato. Si un carácter no coincide vuelve al estado inicial.

2.3

Esperar la respuesta

▶ 11:28

Antes de pedir, el estado pasa a capturar, se limpia el buffer, se limpian errores de recepción y se habilita la interrupción. Una función espera hasta 6 segundos o hasta que llegue una respuesta válida.

2.4

Pedir y convertir

▶ 13:16

Se abre el envío con AT+CIPSEND, se manda el GET, se cierra con Ctrl+Z (0x1A) y se espera la respuesta. Entre los dos puntos y la coma está el valor.

// para recibir de ubidots
tempo = manda_AT_COMANDO("AT+CIPSEND", ">", "OK", 6000);
Delay_ms(500);
// pregunta por la variable deseada
Uart1_write_text_const("GET /api/v1.6/devices/pruebas/suiche/values?page_size=1&token=TU_TOKEN HTTP/1.1\r\nHost: things.ubidots.com\r\n\r\n");
Delay_ms(4000);
tempo = manda_AT_COMANDO("\x1A", "SEND OK", "ERROR", 6000);  // fin de envio
// lee la respuesta
tempo = tiempo_rec(6000);   // espera una respuesta valida
// captura el valor de la variable   "value": 0.0,
strcpy(captu, strtok(trama_rx, ":"));   // inicia captura desde el :
strcpy(captu, strtok(0, ","));          // captura hasta la ,
suiche_ubi = atof(captu);               // pasa la cadena a numero
