Clase 126: acelerómetro ADXL345

Video corto con la librería del ADXL345, un acelerómetro de 3 ejes por I2C. Solo mide aceleraciones, pero como la gravedad siempre está presente se pueden calcular dos ángulos de inclinación: pitch y roll. El giro sobre el eje Z (yaw o rumbo) no se puede medir con este sensor; para eso hace falta un giroscopio o una brújula (por eso, si puedes elegir, un MPU6050 trae acelerómetro y giroscopio). Se configura I2C1 y USART1 en una Blackpill STM32F401, se agregan las librerías ADXL345 y uart, y se envían aceleraciones y ángulos al computador.

Proyecto y periféricos

1.1

El sensor

▶ 0:20

El ADXL345 es un acelerómetro digital de 3 ejes con resolución de hasta 13 bits y comunicación I2C o SPI. Aquí se usa por I2C.

1.2

Crear el proyecto y configurar

▶ 1:55

Nuevo proyecto STM32 para la STM32F401CCU, llamado ADXL345_CANAL.

En el .ioc solo se activan dos cosas: I2C1 (donde está conectado el sensor) y USART1 a 115200 baudios para mandar los datos al computador. Se genera el código.

1.3

Carpeta de librerías e includes

▶ 3:20

Se crea la carpeta Librerias dentro de Core, se pegan ADXL345.c/.h y uart.c/.h, y se agrega la carpeta al include path (clic derecho > Add/Remove include path).

En el main se incluyen las dos librerías más stdio.h y string.h para usar sprintf. Se declara un buffer de texto de 50 caracteres.

Fase 2

La librería ADXL345

2.1

Configuración en ADXL345.h

▶ 3:50

La dirección del sensor (0xA6) no se cambia. Lo que sí hay que ajustar es el I2C que usa tu micro: hi2c1, hi2c2, etc.

#define ADXL_I2CAddress 0xA6     // direccion del sensor (no se cambia)
#define ADXL345I2C hi2c1          // i2c a usar (cambiar si usas otro)

extern float ADXL345_ACELX, ADXL345_ACELY, ADXL345_ACELZ;
extern float acel_pitch, acel_roll;
extern I2C_HandleTypeDef ADXL345I2C;

void ADXL345_Init(void);
void ADXL345_READ_ACEL();
void ADXL345_Angulos();
2.2

Funciones de la librería

▶ 4:20

ADXL345_Init verifica el ID del chip (0xE5) y pone el sensor en modo medición.

ADXL345_READ_ACEL lee los 6 bytes de datos desde el registro 0x32, arma los valores de 16 bits y los pasa a gravedades (g).

ADXL345_Angulos calcula pitch y roll con atan2f a partir de las aceleraciones. EPSILON evita dividir por cero.

void ADXL345_Init(void)
{
  uint8_t chipID;
  ADXL345_Read(0x00, &chipID, 1);   // registro DEVID
  if (chipID == 0xE5)
  {
    ADXL345_Write_Reg(0x2D, 0x00);  // POWER_CTL: reset
    ADXL345_Write_Reg(0x2D, 0x08);  // POWER_CTL: modo medicion
  }
}

void ADXL345_READ_ACEL()
{
  ADXL345_Read(0x32, ADXL345_BUF, 6);   // DATAX0 ... DATAZ1
  int16_t RAWX = ((ADXL345_BUF[1] << 8) | ADXL345_BUF[0]);
  int16_t RAWY = ((ADXL345_BUF[3] << 8) | ADXL345_BUF[2]);
  int16_t RAWZ = ((ADXL345_BUF[5] << 8) | ADXL345_BUF[4]);
  // paso a gravedades
  ADXL345_ACELX = RAWX * .0078;
  ADXL345_ACELY = RAWY * .0078;
  ADXL345_ACELZ = RAWZ * .0078;
}

void ADXL345_Angulos()
{
  float denom = sqrtf(ADXL345_ACELY * ADXL345_ACELY + ADXL345_ACELZ * ADXL345_ACELZ);
  if (denom < EPSILON) denom = EPSILON;
  acel_pitch = atan2f(ADXL345_ACELX, denom) * RAD_TO_DEG;

  denom = sqrtf(ADXL345_ACELX * ADXL345_ACELX + ADXL345_ACELZ * ADXL345_ACELZ);
  if (denom < EPSILON) denom = EPSILON;
  acel_roll = atan2f(ADXL345_ACELY, denom) * RAD_TO_DEG;
}

El factor .0078 g por cuenta depende del rango configurado en el sensor. Si cambias el rango en el registro DATA_FORMAT (0x31), ajusta también ese factor.

Fase 3

Programa principal

3.1

Código del main

▶ 6:10

Se inicializa el sensor antes del while. En el while se leen las aceleraciones, se calculan los ángulos y se envían por USART1 cada 500 ms.

/* USER CODE BEGIN Includes */
#include "ADXL345.h"
#include "uart.h"
#include "stdio.h"
#include "string.h"
/* USER CODE END Includes */

/* USER CODE BEGIN PV */
char texto[50];
/* USER CODE END PV */

/* USER CODE BEGIN 2 */
ADXL345_Init();
/* USER CODE END 2 */

while (1)
{
  ADXL345_READ_ACEL();   // lee aceleraciones en g
  ADXL345_Angulos();     // calcula pitch y roll

  sprintf(texto, "AX=%.2f  AY=%.2f  AZ=%.2f\r\n", ADXL345_ACELX, ADXL345_ACELY, ADXL345_ACELZ);
  uartx_write_text(&huart1, texto);

  sprintf(texto, "pitch=%.2f  roll=%.2f\r\n\r\n", acel_pitch, acel_roll);
  uartx_write_text(&huart1, texto);

  HAL_Delay(500);
}
3.2

Habilitar float en sprintf

▶ 6:20

Para que %.2f funcione: clic derecho al proyecto > Properties > C/C++ Build > Settings > MCU Settings y marcar "Use float with printf from newlib-nano (-u _printf_float)". Apply.

3.3

Resultado

▶ 8:20

En la terminal serial (115200) aparecen AX, AY, AZ en g y pitch y roll en grados.

Al inclinar la tarjeta hacia un lado el pitch se vuelve negativo y hacia el otro positivo; lo mismo con el roll en el otro eje.

En Z solo se ve el cambio de aceleración al moverlo; no hay ángulo de giro porque no hay inclinación respecto a la gravedad.
