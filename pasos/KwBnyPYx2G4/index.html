De Arduino a STM32: pluviómetro SEN0575

El SEN0575 es un pluviómetro de balancín (tipping bucket) con un reed switch y un micro propio que se lee por I2C o UART. DFRobot solo da la librería para Arduino y ChatGPT inventa datos (direcciones I2C falsas). La solución es leer el código de Arduino y traducirlo: copiar los #define, sacar la dirección I2C del código, reemplazar readRegister/writeRegister de Wire por funciones HAL con dos #define, y pasar cada método de la clase a una función en C. Al final se lee la lluvia acumulada en mm y el número de basculaciones.

Fase 1

El sensor y el problema

1.1

Cómo mide

▶ 0:00

La lluvia cae en un balancín con dos recipientes. Cuando uno se llena, el balancín bascula y un imán activa un reed switch. Un micro dentro del sensor cuenta las basculaciones y calcula la lluvia acumulada.

2.3

Copiar los defines y las variables

▶ 9:21

Los #define de registros del .h de Arduino se copian tal cual. Las variables privadas de la clase (pid, vid) pasan al .c, inicializadas en cero como hace begin().

2.4

Puerto y dirección I2C

▶ 10:33

En el .h se define qué I2C usar y la dirección del sensor. La dirección no está en internet: se saca del código de Arduino. El constructor UART usa 0xC0 (dirección Modbus), pero el de I2C usa 0x1D.

extern I2C_HandleTypeDef hi2c1;
#define RainfallSensor_I2C   hi2c1          // para I2C2: hi2c2
#define RainfallSensor_ADDR  (0x1D << 1)    // la HAL usa la dirección de 7 bits corrida

La HAL espera la dirección de 7 bits corrida un bit a la izquierda. Si tu librería I2C ya hace el corrimiento, deja 0x1D.

Fase 3

Traducir las funciones

3.1

readRegister y writeRegister con HAL

▶ 14:24

En Arduino, readRegister hace beginTransmission, write, endTransmission, requestFrom y un ciclo de read. Con la HAL todo eso es una sola llamada a HAL_I2C_Mem_Read. Con dos #define, el código copiado de Arduino llama a las funciones nuevas sin cambiar nombres.

// SN0575.c
#define readRegister  I2C_Readm_n
#define writeRegister I2C_Writem_n

uint8_t I2C_Writem_n(uint8_t dir, uint8_t *buff, uint8_t n)
{
  HAL_I2C_Mem_Write(&RainfallSensor_I2C, RainfallSensor_ADDR, dir,
                    I2C_MEMADD_SIZE_8BIT, buff, n, 100);
  return n;
}

uint8_t I2C_Readm_n(uint8_t dir, uint8_t *buff, uint8_t n)
{
  HAL_I2C_Mem_Read(&RainfallSensor_I2C, RainfallSensor_ADDR, dir,
                   I2C_MEMADD_SIZE_8BIT, buff, n, 100);
  return n;
}
3.2

De método de clase a función

▶ 13:19

Se copia cada método y se ajusta: DFRobot_RainfallSensor:: pasa a RainfallSensor_, se quitan (void) y los if de modo I2C/UART (se deja solo la parte I2C), y (void*)buff pasa a un puntero normal. Con Buscar y reemplazar (Ctrl+F) se hace en todo el archivo a la vez.

bool RainfallSensor_getPidVid()
{
  bool ret = false;
  uint8_t buff[4] = {0};
  readRegister(I2C_REG_PID, buff, 4);
  pid = buff[0] | ((uint16_t)buff[1] << 8) | ((uint32_t)(buff[3] & 0xC0) << 10);
  vid = buff[2] | (uint16_t)((buff[3] & 0x3F) << 8);
  if ((vid == 0x3343) && (pid == 0x100C0))
  {
    ret = true;   // el sensor está conectado y responde
  }
  return ret;
}

3.4

Lluvia acumulada

▶ 20:09

getRainfall lee 4 bytes del registro de lluvia acumulada y los convierte a mm. En las propiedades del proyecto hay que habilitar float en printf.

float RainfallSensor_getRainfall()
{
  uint32_t rainfall = 0;
  uint8_t buff[4] = {0};
  readRegister(I2C_REG_CUMULATIVE_RAINFALL, buff, 4);
  rainfall = buff[0] | ((uint32_t)buff[1] << 8)
           | ((uint32_t)buff[2] << 16) | ((uint32_t)buff[3] << 24);
  return rainfall / 10000.0;
}

Fase 4

Programa final

4.1

main.c

▶ 30:26

Al inicio se carga el valor por basculación con setRainAccumulatedValue(0.2794): es el valor de fábrica que usa el sensor para calcular los mm, no un reinicio a cero. En el while se lee la lluvia y el dato crudo (número de basculaciones).

/* USER CODE BEGIN 2 */
RainfallSensor_setRainAccumulatedValue(0.2794);   // mm por basculación (de fábrica)

while (1)
{
  if (RainfallSensor_getPidVid() == 1) uartx_write_text(&huart1, "SENSOR OK\r\n");
  float lluvia = RainfallSensor_getRainfall();
  sprintf(texto, "Lluvia=%.1f\r\n", lluvia);
  uartx_write_text(&huart1, texto);

  uint16_t llu = RainfallSensor_getRawData();       // número de basculaciones
  sprintf(texto, "veces=%u\r\n", llu);
  uartx_write_text(&huart1, texto);
  HAL_Delay(1000);
}

El sensor guarda la lluvia acumulada aunque reinicies el STM32. Si quieres empezar de cero, quítale la alimentación al sensor.
