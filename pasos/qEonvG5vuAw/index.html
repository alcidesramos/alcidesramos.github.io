Velocista: PID y turbo en rectas

La mejora consiste en detectar las rectas. Cada vez que la posición de la línea queda entre -1 y 1 se incrementa un contador, y si sale de ese rango el contador vuelve a cero. Cuando el contador llega a un valor (se prueban 30, 8 y 10) el robot está en una recta y se llama a velo_linea(255), que pone ambos motores al máximo hacia adelante y borra la integral y el error anterior del PID para que no arrastre valores viejos. Un LED extra en RB6 cambia de estado en ese modo. Fuera de la recta se usa el PID de la parte anterior, con velocidad base 150. En la carrera el robot es más rápido que la versión anterior.

Código del ciclo

▶ 9:57

Así queda el ciclo principal con el umbral en 10.

linea_actual = calcula_pesos();
// si los pesos están entre un rango
if ((linea_actual >= -1) && (linea_actual <= 1))
{
  cont_linea++;          // incrementa variable de línea
}
else cont_linea = 0;

if (cont_linea >= 10)    // valor para detectar que la línea es recta
{
  velo_linea(255);       // velocidad de la línea recta
  ledl = !ledl;
}
else PID(linea_actual);
