Leer voltaje AC con PIC

Hay varias formas de medir voltaje AC con un micro: un amplificador de aislamiento como el ISO124, un transformador o, la que se usa aquí, un puente rectificador con un divisor resistivo de 330k y 6,8k, un zener de 5,1 V (o 3,3 V según el micro) como protección, y un fusible con un varistor del 150% del voltaje RMS. Un capacitor de filtro no se recomienda porque no sigue cambios rápidos. La señal rectificada tiene 120 Hz, o sea 8,33 ms por semiciclo, y basta leer unos 4 ms para encontrar el pico: se hacen 200 pares de lecturas con 10 µs de pausa guardando el mayor. Con el pico se calcula el voltaje, se deshace el divisor, se suman 1,4 V de los diodos y se divide entre 1,4142 para obtener el RMS, que se muestra en el LCD cada 100 ms. Con 155 V de pico se leen unos 109,6 V RMS.

Fase 1

Opciones de hardware

1.1

Divisor directo

▶ 0:20

La entrada de 110 V con un divisor y un varistor de protección. El micro no acepta voltajes negativos, así que hay que adaptar la señal.

1.2

Aislamiento o transformador

▶ 1:42

Se puede usar un amplificador de aislamiento como el ISO124, que separa físicamente las dos partes, o un transformador reductor.

1.3

Rectificar

▶ 3:24

La opción elegida: puente rectificador para que la señal sea siempre positiva y divisor de 330k con 6,8k.

1.4

Protecciones

▶ 5:04

Un zener de 5,1 V (o 3,3 V si el micro trabaja a 3,3 V) limita la entrada. Antes del circuito van un fusible y un varistor del 150% del voltaje RMS para los picos.

1.5

Sin capacitor

▶ 6:49

Con un capacitor la señal queda continua, pero por su tiempo de carga y descarga no sigue cambios rápidos. Sirve solo para sistemas lentos.

Fase 2

Programa

2.1

Circuito con el PIC

▶ 8:29

La señal va a AN0 del PIC16F1824 y el LCD al puerto C.

2.2

Variables

▶ 9:31

Conexiones del LCD, lecturas, el mayor, las dos resistencias del divisor, el voltaje y el texto.

unsigned int lectura_1, lectura_2;
unsigned int mayor, mayor1;
const float res1 = 330000;
const float res2 = 6800;
float voltaje;
char texto[30];
2.3

Inicio

▶ 10:32

Se inicia el LCD con el texto Voltaje=, se inicia el ADC y se configura todo digital menos AN0.

2.4

Buscar el pico

▶ 11:48

El semiciclo rectificado dura 8,33 ms y con la mitad basta. 200 pares de lecturas con 10 µs de pausa recorren esa ventana guardando el valor mayor.

while (1)
{
  mayor = 0;
  mayor1 = 0;
  for (cont = 0; cont < 200; cont++)
  {
    lectura_1 = ADC_Get_Sample(0);  // realiza primera lectura
    Delay_us(10);
    lectura_2 = ADC_Get_Sample(0);  // realiza segunda lectura
    Delay_us(10);
    if (lectura_2 > lectura_1) mayor = lectura_1;
    else mayor = lectura_2;
    if (mayor > mayor1) mayor1 = mayor;
  }
2.5

Calcular el RMS

▶ 15:37

Del valor del ADC al voltaje, se deshace el divisor, se suman 1,4 V de los diodos y se divide entre raíz de 2.

  voltaje = mayor1 * 5.0 / 1023.0;           // calcula el voltaje
  voltaje = voltaje * (res1 + res2) / res2;  // aplica el divisor resistivo
  voltaje = voltaje + 1.4;                   // suma caída en el puente rectificador
  voltaje = voltaje / 1.4142;                // saca RMS
  FloatToStr_FixLen(voltaje, texto, 6);      // toma 6 dígitos
  Lcd_Out(1, 9, texto);
  Delay_ms(100);                             // retardo de refresco
}
