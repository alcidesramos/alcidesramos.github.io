Interrupciones por flanco (EXTI) en STM32

Continuando la clase de interrupciones por timer, se añade un pulsador en PB3 configurado como GPIO_EXTI3 con flanco de bajada y pull-up interno. En el NVIC se habilita la línea EXTI3 con prioridad 3 (menos prioritaria que el timer). En stm32f4xx_it.c, dentro de EXTI3_IRQHandler, se conmuta LED4. Luego se agrega un segundo pulsador en PA10 (EXTI10); como las líneas 10 a 15 comparten un solo vector (EXTI15_10_IRQHandler), se usa __HAL_GPIO_EXTI_GET_IT para saber qué pin generó la interrupción. Al final un botón enciende LED4 y el otro lo apaga, mientras el main y el timer siguen con sus LEDs: varias tareas en paralelo gracias a las interrupciones.

Fase 1

Primer pulsador en EXTI3

1.1

Pulsador en el circuito

▶ 0:20

Se parte del montaje de la clase anterior (LED1 en el main, LED2 y LED3 por timer) y se agrega un pulsador entre PB3 y GND. La resistencia pull-up se activa por software, así que al presionar el micro lee un 0.

1.2

PB3 como GPIO_EXTI3

▶ 0:45

En el pinout, PB3 se configura como GPIO_EXTI3 (no como entrada normal) y se etiqueta SW1. En GPIO se elige External Interrupt Mode with Falling edge trigger detection y Pull-up.

1.3

Habilitar EXTI line3 en el NVIC

▶ 1:41

En NVIC se marca EXTI line3 interrupt. Se le da prioridad 3 para que sea menos prioritaria que la del timer (prioridad 1): entre mayor el número, menor la prioridad.

1.4

Código en EXTI3_IRQHandler

▶ 2:13

El include de pinout.h se mueve a la sección de includes de stm32f4xx_it.c. En el manejador generado se conmuta LED4:

void EXTI3_IRQHandler(void)
{
  /* USER CODE BEGIN EXTI3_IRQn 0 */
  PIN_BLINK(LED4);
  /* USER CODE END EXTI3_IRQn 0 */
  HAL_GPIO_EXTI_IRQHandler(SW1_Pin);
}

Fase 2

Segundo pulsador en línea compartida

2.1

PA10 como GPIO_EXTI10

▶ 3:18

Se añade otro pulsador en PA10 (SW2), también con flanco de bajada y pull-up. En el NVIC las líneas 10 a 15 aparecen unidas en EXTI line[15:10] interrupts, a diferencia de EXTI3 que tiene vector propio.

2.2

Manejador compartido EXTI15_10

▶ 4:27

Como el vector lo comparten los pines 10 a 15, dentro del manejador se pregunta cuál pin generó la interrupción. SW2 apaga LED4 y SW1 lo enciende:

void EXTI15_10_IRQHandler(void)
{
  /* USER CODE BEGIN EXTI15_10_IRQn 0 */
  if (__HAL_GPIO_EXTI_GET_IT(SW2_Pin) != RESET)
  {
    PIN_OFF(LED4);
  }
  /* USER CODE END EXTI15_10_IRQn 0 */
  HAL_GPIO_EXTI_IRQHandler(SW2_Pin);
}
2.3

Verificar también en la dedicada

▶ 5:35

Aunque EXTI3 es dedicada, por seguridad se puede hacer la misma verificación:

void EXTI3_IRQHandler(void)
{
  /* USER CODE BEGIN EXTI3_IRQn 0 */
  if (__HAL_GPIO_EXTI_GET_IT(SW1_Pin) != RESET)
  {
    PIN_ON(LED4);
  }
  /* USER CODE END EXTI3_IRQn 0 */
  HAL_GPIO_EXTI_IRQHandler(SW1_Pin);
}

En las interrupciones por flanco compartidas (normalmente las líneas 10 a 15) siempre hay que comprobar con __HAL_GPIO_EXTI_GET_IT cuál pin la disparó.
