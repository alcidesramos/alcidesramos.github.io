ESP32 en Proteus con MicroPython

Se crea un proyecto nuevo en Proteus 8.17 SP4 (también funciona en la 9). En el asistente se elige firmware con MicroPython y una ESP32; solo acepta el compilador propio de Proteus. Se conecta un LED con su resistencia a GP2, se pega un programa sencillo de MicroPython que prende y apaga el LED cada 0.5 s y se corre la simulación. El WiFi todavía no está implementado, pero sí SPI, I2C, UART y otros periféricos.

2.1

Código en MicroPython

▶ 1:49

Se borra lo que Proteus pone por defecto y se pega el programa: importa Pin y sleep, define el pin 2 como salida y prende y apaga el LED cada medio segundo.

from machine import Pin
from time import sleep

# Configura el pin GPIO 2 como salida (puedes cambiarlo según tu conexión)
led = Pin(2, Pin.OUT)

# Bucle infinito para parpadear el LED
while True:
    led.on()        # Enciende el LED
    sleep(0.5)      # Espera 0.5 segundos
    led.off()       # Apaga el LED
    sleep(0.5)      # Espera 0.5 segundos
