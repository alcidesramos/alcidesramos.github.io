Recibir órdenes seriales en PIC y Arduino

En vez de mandar una sola letra, se mandan órdenes legibles que terminan en '*'. El micro lee la trama hasta el asterisco y con funciones estándar de C (strstr para buscar, strtok para separar y atoi para convertir) decide qué hacer: encender leds, girar un motor y cambiar su velocidad con PWM. Se hace el mismo programa en Arduino y en un PIC16F876A con MikroC para mostrar que el código casi no cambia.

▶ Ver el video completo (26:27) Empezar el paso a paso
  • MikroC PRO for PIC y PIC16F876A a 4 MHz
  • Arduino Uno e IDE de Arduino
  • L293D con motor DC, dos leds
  • Proteus con Virtual Terminal

Fase 1

Las órdenes

1.1

Trama con final

▶ 0:00

Lo más básico es una trama con un carácter de final. Aquí todas las órdenes terminan en '*', que le dice al micro que la orden llegó completa.

1.2

El circuito

▶ 1:38

Un motor con L293D (dos pines de sentido y uno de PWM), dos leds y el puerto serial conectado a una terminal.

1.3

Lista de órdenes

▶ 2:44

led1=on* y led1=off* manejan un led; led2 igual. mder* gira a la derecha, mizq* a la izquierda y mstop* detiene. mpwm=valor* cambia la velocidad.

Fase 2

Proyecto

2.1

Pines y variables

▶ 5:30

Se definen los pines del motor y de los leds, y dos cadenas: trama para lo que llega y procesa para lo que se separa. En Arduino se usan números de pin; en MikroC, bits de puerto.

char trama[30];
char procesa[30];
char dato;
2.2

Funciones del motor

▶ 7:50

mderecha(), mizquierda() y mquieto() ponen los dos pines del puente H en 1-0, 0-1 o 0-0.

void mderecha()  { m11 = 1; m12 = 0; }
void mizquierda(){ m11 = 0; m12 = 1; }
void mquieto()   { m11 = 0; m12 = 0; }
2.3

Configuración

▶ 9:43

Serial a 9600, pines de motor y leds como salida, PWM iniciado con una velocidad básica y el motor quieto.

UART1_Init(9600);
PWM1_Init(1000);
PWM1_Set_Duty(100);
PWM1_Start();
mquieto();
Fase 3

Interpretar

3.1

Leer hasta el asterisco

▶ 13:46

En MikroC UART1_Read_Text guarda en trama todo hasta el '*' (máximo 30). En Arduino se usa Serial.readBytesUntil('*', trama, 30). Esta forma deja al micro esperando; con interrupciones se mejora en el siguiente video.

3.2

Buscar con strstr

▶ 15:33

strstr dice si una cadena contiene otra. Si llega led1= y además on, se enciende; si no, se apaga. Lo mismo para el resto de órdenes.

UART1_Read_Text(trama, "*", 30);
if (strstr(trama, "led1=")) {
  if (strstr(trama, "on")) led1 = 1;
  else led1 = 0;
}
else if (strstr(trama, "led2=")) { ... }
else if (strstr(trama, "mder"))  mderecha();
else if (strstr(trama, "mizq"))  mizquierda();
else if (strstr(trama, "mstop")) mquieto();
3.3

Mismo código

▶ 20:10

El bloque de órdenes se copia del Arduino a MikroC casi igual, porque strstr es de C estándar.

3.4

Valor numérico

▶ 23:04

Para mpwm=valor* se separa lo que hay entre el '=' y el '*' con strtok, se convierte con atoi y se aplica al PWM (analogWrite en Arduino).

else if (strstr(trama, "mpwm=")) {
  strcpy(procesa, strtok(trama, "="));
  strcpy(procesa, strtok(0, "*"));
  dato = atoi(procesa);
  PWM1_Set_Duty(dato);
}

Prueba

▶ 25:16
