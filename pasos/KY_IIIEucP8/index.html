La ESP32 de mentira en Proteus

Se copian los archivos de la librería en la carpeta de librerías de Proteus (la que dice System Settings, para no equivocarse de carpeta) y se reinicia Proteus. Al buscar ESP32 aparece el módulo; si se descompone se ve que es un Arduino Uno disfrazado. Por eso sirve para lo básico, pero no para funciones propias de la ESP32 como el PWM avanzado. Se escribe un programa de LED en la IDE de Arduino, se compila eligiendo la placa Arduino Uno, se exporta el binario compilado y se carga el .hex en el módulo de Proteus.

Fase 1

El módulo

1.1

Instalar la librería

▶ 0:32

Los dos archivos de la librería se copian donde Proteus tiene sus librerías. Para no equivocarse de carpeta, se abre Proteus, se mira la ruta de librerías en System Settings y se pegan ahí. Luego se cierra y se vuelve a abrir Proteus.

1.2

Buscar la ESP32

▶ 1:06

Al buscar ESP32 en los componentes aparece el módulo ESP32-WROOM hecho por otra persona.

1.3

Por dentro es un Arduino

▶ 1:39

Si se descompone el módulo se ve que es un ATmega328P a 16 MHz, es decir, un Arduino Uno con carcasa de ESP32. Sirve para cosas normales porque la ESP32 acepta las librerías de Arduino, pero no para las funciones avanzadas de la ESP32.

Fase 2

Programa en Arduino

2.1

Sketch del LED

▶ 3:24

En la IDE de Arduino se hace un sketch nuevo: el pin 2 como salida y en el loop se prende y apaga cada 500 ms.

void setup() {
  // put your setup code here, to run once:
  pinMode(2, OUTPUT);
}

void loop() {
  // put your main code here, to run repeatedly:
  digitalWrite(2, 1);
  delay(500);
  digitalWrite(2, 0);
  delay(500);
}
2.2

Placa Arduino Uno

▶ 5:20

Como placa se elige Arduino Uno, no la ESP32, porque se va a simular en este módulo. Con una ESP32 física sí se elegiría la ESP32, ya que el código es compatible.

2.3

Exportar el .hex

▶ 5:30

Se compila y en Sketch se usa exportar binarios compilados para que la IDE cree el .hex junto al sketch.

Fase 3

Simulación

3.1

Cargar el programa

▶ 5:54

Doble clic al módulo en Proteus y en el archivo de programa se elige el .hex más corto (el que no trae el bootloader).

3.2

LED y prueba

▶ 6:27

Se conecta un LED con resistencia de 220 Ω al pin 2 y a tierra, y con play el LED titila. Ojo: es un Arduino Uno disfrazado; para simular es igual poner un Arduino normal.
