Clase 127: TFT ILI9341 / ST7789V

Video corto para alumnos que compraron la pantalla WeAct de 2.8 pulgadas (240x320) y no lograban hacer funcionar las librerías de internet. Se parte del ejemplo oficial de WeAct para el STM32F411 y se adapta: se renombra LCD a TFT, los pines se llaman como los definimos en CubeMX, se puede elegir el puerto SPI y la orientación de la pantalla. La misma librería detecta si la pantalla trae ILI9341 o ST7789. Se configura el proyecto en una Blackpill F411, se agregan las librerías y se escribe texto, números, un círculo y un rectángulo.

Fase 1

Librería original

1.1

Descargar el ejemplo

▶ 1:00

En el GitHub de WeActStudio (TFT-LCD-Module), en Examples > LCD_Test_STM32F411 > Display, están los archivos lcd.c, lcd.h y lcdfont.h.

Solo se usan lcd (renombrada TFT_) y la de fuentes (renombrada font). El logo, las imágenes y el touch xpt2046 se dejan para otro video.

Fase 2

Proyecto en CubeMX

2.1

Conexiones

▶ 2:55

SCK a PA5, SDO (MISO) a PA6, SDA (MOSI) a PA7. Pines de salida: TFT_CS en PB0, TFT_RST en PB1, TFT_DC (dato/comando) en PB2 y TFT_LED en PB10 para la luz de fondo.

El pin BL (LED) es opcional: si lo conectas a 3.3 V la pantalla queda siempre encendida. Con un PWM podrías controlar el brillo. El pin IM de modo paralelo no se usa, viene en SPI por defecto.

2.2

Configurar SPI y reloj

▶ 3:35

Connectivity > SPI1 en Full-Duplex Master, datos de 8 bits.

RCC con cristal externo (HSE) y en Clock Configuration el micro a su máxima velocidad (100 MHz en el F411).

2.3

Pines de salida

▶ 5:00

PB0, PB1, PB2 y PB10 como GPIO_Output, con las etiquetas TFT_CS, TFT_RST, TFT_DC y TFT_LED. Los nombres deben ser exactamente esos porque la librería los usa así.

En el video la compilación dio error porque una etiqueta quedó como RTS en lugar de RST. Revisa bien los nombres.

Fase 3

Agregar la librería

3.1

Carpeta de librerías

▶ 7:20

Se crea Core/Librerias, se agrega al include path y se pegan TFT_.c, TFT_.h, font.h y pinout.c/.h (librería propia para manejar pines).

En el main solo se incluyen pinout.h y TFT_.h. font.h ya va incluido dentro de la librería; si lo incluyes también en el main aparece el error multiple definition.

3.2

Cambios hechos a la librería

▶ 7:50

En TFT_.h se elige el puerto SPI (1, 2, 3...) y las orientaciones: vertical, horizontal y sus versiones invertidas.

En TFT_.c las macros de los pines usan los nombres de CubeMX (TFT_CS, TFT_DC, TFT_RST) y todas las funciones LCD_ pasaron a llamarse TFT_.

Fase 4

Usar la pantalla

4.1

Iniciar y poner fondo

▶ 9:20

TFT_Init() inicia la pantalla, TFT_direction() fija la orientación y TFT_Clear() pinta el fondo.

Si no se enciende el pin TFT_LED no se ve nada aunque la pantalla esté funcionando.

4.2

Texto, números y figuras

▶ 12:40

TFTdev.id indica qué controlador detectó la librería, así se escribe en pantalla si es ILI9341 o ST7789.

TFT_ShowString recibe posición, texto, color, fondo, tamaño de letra (16) y un último parámetro de modo: con 0 pinta el fondo del texto y con 1 escribe encima de lo que ya hay, sin fondo.

TFT_ShowIntNum muestra un número con la cantidad de dígitos indicada; TFT_DrawCircle y TFT_Fill dibujan un círculo y un rectángulo relleno.

/* USER CODE BEGIN Includes */
#include "pinout.h"
#include "TFT_.h"      // font.h ya lo incluye la libreria, no lo incluyas aqui
/* USER CODE END Includes */

/* USER CODE BEGIN 2 */
PIN_ON(TFT_LED);                 // enciende la luz de fondo (o BL a 3.3 V)

TFT_Init();                      // inicia el TFT
TFT_direction(Horizontal);       // direccion de escritura
HAL_Delay(100);
TFT_Clear(YELLOW);               // color de fondo

if (TFTdev.id == 0)              // la libreria detecta el controlador
    TFT_ShowString(10, 40, (uint8_t *)"2.8 Inch ILI9341 TFT", RED, BLACK, 16, 0);
else
    TFT_ShowString(10, 40, (uint8_t *)"2.8 Inch ST7789 TFT", RED, BLACK, 16, 0);

TFT_ShowString(10, 56, (uint8_t *)"TFT_W:", GREEN, BLACK, 16, 0);
TFT_ShowIntNum(58, 56, TFT_W, 3, WHITE, BLACK, 16);

TFT_ShowString(90, 56, (uint8_t *)"TFT_H:", BLUE, BLACK, 16, 0);
TFT_ShowIntNum(138, 56, TFT_H, 3, WHITE, BLACK, 16);

TFT_DrawCircle(200, 50, 30, BLUE);
TFT_Fill(0, 120, 50, 170, WHITE);
/* USER CODE END 2 */
4.3

Resultado

▶ 14:00

En la pantalla aparece "2.8 Inch ILI9341 TFT", el ancho 240 y alto 320, el círculo azul y el rectángulo blanco sobre fondo amarillo.

Cambiando el último parámetro de TFT_ShowString a 1, el texto rojo queda sin el fondo negro.
