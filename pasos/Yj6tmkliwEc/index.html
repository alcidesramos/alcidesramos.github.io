Display de 7 segmentos con PIC

Lección corta para mostrar algo en un display. Se arma el circuito en Proteus con el display conectado al puerto B (RB0 a RB6 para los segmentos a a g) usando un bus con etiquetas, y en MikroC se usa el editor de 7 segmentos para obtener el valor de cada número en cátodo común. Con esos valores, uno por uno y con un retardo, queda un contador de 0 a 9.

Fase 1

Circuito en Proteus

1.1

Display y resistencia

▶ 0:00

Se coloca un display de 7 segmentos de cátodo común. Lo normal es una resistencia de 220 Ω por segmento; un truco es poner una sola resistencia del común a tierra (en la vida real de 100 a 220 Ω). Con una sola resistencia el display se ve un poco más opaco cuando se encienden muchos segmentos.

En Proteus la resistencia común debe ser muy baja (unos 30 Ω) o el display no enciende.

1.2

Bus y etiquetas

▶ 1:06

Cada pin del display se etiqueta con A a G y lo mismo en RB0 a RB6, empezando en el bit 0. Con un bus azul y etiquetas, Proteus une los pines con el mismo nombre sin tirar cables uno por uno.

Fase 2

Programa

2.1

Seven Segment Editor

▶ 2:52

En Tools → Seven Segment Editor de MikroC se dibuja el número encendiendo segmentos y el editor da el valor en decimal o hexadecimal para cátodo o ánodo común. Para el 0 en cátodo común es 63.

2.2

Contador de 0 a 9

▶ 4:01

Se escribe cada valor en el puerto B con un retardo. Los valores en cátodo común son:

TRISB = 0b00000000;   // puerto B salida
while (1)
{
  PORTB = 63;  Delay_ms(200);   // 0
  PORTB = 6;   Delay_ms(200);   // 1
  PORTB = 91;  Delay_ms(200);   // 2
  PORTB = 79;  Delay_ms(200);   // 3
  PORTB = 102; Delay_ms(200);   // 4
  PORTB = 109; Delay_ms(200);   // 5
  PORTB = 125; Delay_ms(200);   // 6
  PORTB = 7;   Delay_ms(200);   // 7
  PORTB = 127; Delay_ms(200);   // 8
  PORTB = 111; Delay_ms(200);   // 9
}

Más adelante, con el ciclo for y los vectores, este código se hará mucho más corto.

2.3

Comentarios y prueba

▶ 5:48

Se puede comentar una línea con // o seleccionando el texto y usando clic derecho → comentar. Al compilar y cargar el .hex en Proteus, el display cuenta de 0 a 9.
