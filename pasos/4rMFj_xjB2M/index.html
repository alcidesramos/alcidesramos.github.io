Librería para teclado matricial

Un teclado matricial une las teclas por filas y columnas. Se activa una fila a la vez y se leen las cuatro columnas: si una columna cambia, se sabe qué tecla se presionó (número del 1 al 16). La librería tiene t_tecla1 a t_tecla4 (una por fila), tecla_presionada (escanea todo con antirrebote) y tecla_deco (convierte el número en el carácter de tu teclado). Con un #define se elige si las resistencias de las columnas van a VDD o a tierra, y si no hay resistencias se usan las internas del micro.

Fase 1

Cómo funciona

1.1

Escaneo por filas

▶ 0:32

Las columnas son entradas con resistencia (a tierra o a VDD) y las filas son salidas. Se pone un nivel activo en la fila 1 y se leen las columnas 1 a 4: la que cambió indica la tecla 1, 2, 3 o 4. Luego la fila 2 (teclas 5 a 8), y así hasta la 16.

Ese número del 1 al 16 luego se traduce al carácter que tenga tu teclado.

Fase 3

La librería

3.1

Tipo de resistencia (Teclado.h)

▶ 10:00

res indica a dónde van las resistencias de las columnas: 1 si van a VDD (pull-up), 0 si van a tierra (pull-down). Las columnas se leen con macros.

// define si las resistencias de las columnas son pull-up o pull-down
#define res 1      // 0 = TIERRA   1 = VDD

// lectura de las columnas
#define te_c1 HAL_GPIO_ReadPin(TC1_GPIO_Port, TC1_Pin)
#define te_c2 HAL_GPIO_ReadPin(TC2_GPIO_Port, TC2_Pin)
#define te_c3 HAL_GPIO_ReadPin(TC3_GPIO_Port, TC3_Pin)
#define te_c4 HAL_GPIO_ReadPin(TC4_GPIO_Port, TC4_Pin)

uint8_t tecla_presionada(void);   // retorna el número de la tecla (1 a 16)
uint8_t tecla_deco(void);         // decodifica la tecla leída
3.2

Escanear una fila

▶ 11:31

Se activa solo la fila con el nivel contrario a la resistencia (!res_) y se revisan las cuatro columnas. Las otras tres funciones son iguales, con las teclas 5-8, 9-12 y 13-16.

#include "Teclado.h"
#include "stdbool.h"

bool res_ = res;

uint8_t t_tecla1(void)
{
    HAL_GPIO_WritePin(TF1_GPIO_Port, TF1_Pin, !res_);   // activa solo la fila 1
    HAL_GPIO_WritePin(TF2_GPIO_Port, TF2_Pin, res_);
    HAL_GPIO_WritePin(TF3_GPIO_Port, TF3_Pin, res_);
    HAL_GPIO_WritePin(TF4_GPIO_Port, TF4_Pin, res_);

    if      (te_c1 == !res_) return (1);
    else if (te_c2 == !res_) return (2);
    else if (te_c3 == !res_) return (3);
    else if (te_c4 == !res_) return (4);   // comentar si es 3x4
    else return (0);
}

Si tu teclado es de 3x4, comenta la línea de la columna 4 en cada función.

3.3

Escanear todo el teclado

▶ 13:09

tecla_presionada llama a las cuatro filas con 5 ms entre ellas (antirrebote). Devuelve en cuanto encuentra una tecla, o 0 si no hay ninguna.

uint8_t tecla_presionada(void)
{
    uint8_t te;
    HAL_Delay(5);
    te = t_tecla1();  if (te != 0) return (te);
    HAL_Delay(5);
    te = t_tecla2();  if (te != 0) return (te);
    HAL_Delay(5);
    te = t_tecla3();  if (te != 0) return (te);
    HAL_Delay(5);
    te = t_tecla4();
    return (te);
}
3.4

Decodificar al carácter

▶ 18:47

Cada teclado numera distinto. Con un switch se asigna a cada número el carácter impreso en tu teclado (este es el KEYPAD de Proteus).

uint8_t tecla_deco(void)
{
    switch (tecla_presionada())
    {
        case 1:  return '7';  case 2:  return '8';  case 3:  return '9';  case 4:  return '/';
        case 5:  return '4';  case 6:  return '5';  case 7:  return '6';  case 8:  return '*';
        case 9:  return '1';  case 10: return '2';  case 11: return '3';  case 12: return '-';
        case 13: return 'C';  case 14: return '0';  case 15: return '=';  case 16: return '+';
        default: return 0;
    }
}
Fase 4

Programa principal

4.1

Probar el número de tecla

▶ 14:19

Primero muestra el número crudo para comprobar el escaneo: aparece del 1 al 16 según la posición.

Lcd_Init();
Lcd_Cmd(_LCD_CLEAR);
Lcd_Cmd(_LCD_CURSOR_OFF);
Lcd_Text(1, 1, "     TECLADO");

while (1)
{
    tecla = tecla_presionada();
    sprintf(texto, "Tecla=%02u", tecla);
    Lcd_Text(2, 1, texto);
}
4.2

Mostrar el carácter y avisar con el LED

▶ 19:20

Con tecla_deco ya tienes el carácter. Escribe 'Tecla=' una sola vez fuera del bucle y solo actualiza cuando la tecla no es 0; así el último carácter queda en pantalla. El LED parpadea 100 ms en cada pulsación (podría ser un buzzer).

Lcd_Text(2, 1, "Tecla=");

while (1)
{
    tecla = tecla_deco();
    if (tecla != 0)
    {
        Lcd_Chr(2, 7, tecla);
        HAL_GPIO_WritePin(LED_GPIO_Port, LED_Pin, 1);
        HAL_Delay(100);
        HAL_GPIO_WritePin(LED_GPIO_Port, LED_Pin, 0);
    }
}

El 0 no es el carácter '0' (que vale 48): es el fin de cadena. Por eso, si no hay tecla, no se escribe nada.

Fase 5

Resistencias

5.1

Cambiar el tipo de resistencia

▶ 24:27

Si tu módulo trae las resistencias a tierra, cambia en Teclado.h #define res 0 y vuelve a compilar. La librería funciona igual.

5.2

Sin resistencias externas

▶ 25:36

Sin resistencias las entradas quedan flotando y el teclado se vuelve loco. En System Core → GPIO pon las columnas TC1 a TC4 con Pull-down (si res es 0) o Pull-up (si res es 1): el micro pone la resistencia interna.
