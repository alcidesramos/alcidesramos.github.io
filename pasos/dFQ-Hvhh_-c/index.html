Sensores reflectivos sin ADC

Es el método de los sensores tipo QTR-RC. El pin se pone como salida en 1 para cargar el condensador, luego como entrada; el fototransistor lo descarga más rápido cuanto más luz refleja la superficie. El Timer1 se configura para una ventana de unos 13 ms y, mientras corre, se guarda el valor del timer en el instante en que cada pin cae a 0. Así se leen ocho sensores sin usar el ADC. Las lecturas se envían por serial.

Fase 1

Cómo funciona

1.1

El sensor

▶ 0:00

El CNY70 tiene un LED infrarrojo y un fototransistor. Según la distancia y el color de la superficie conduce más o menos.

1.2

Medir tiempo

▶ 3:00

Con un condensador en el colector, el pin lo carga y luego se mide cuánto tarda en descargarse. En Proteus se usa una gráfica transitoria para ver la curva de descarga.

1.3

Timer1

▶ 5:00

La carga del Timer1 sale de 65536 − tiempo deseado / (Tciclo × preescalador). Se elige el preescalador que cumple para unos 13 ms de ventana.

Pines

▶ 7:08

Cada sensor usa el mismo pin como salida (LATB) y como entrada (RB).

sbit led at LATC0_bit;
unsigned int timer = 0;   // acumula contador del sensor
// pines sensores
sbit s1_out at LATB0_bit;
sbit s1_in  at RB0_bit;
sbit s2_out at LATB1_bit;
sbit s2_in  at RB1_bit;
// ... igual hasta s8 en RB7
2.2

Entradas y salidas

▶ 8:48

config_entradas pone el puerto B como entrada, config_salidas como salida y saca_uno pone todos en 1 para cargar los condensadores.

2.3

Medir

▶ 10:27

Se cargan los condensadores unos microsegundos, los pines pasan a entrada y arranca el timer. Mientras no se desborde, el primer momento en que cada pin lee 0 se guarda el valor del Timer1 y se marca su bandera.

void analizasensoresir() {
  config_timer1();       // TIMER 13MS
  config_salidas();
  saca_uno();
  Delay_us(10);
  config_entradas();
  TMR1ON_bit = 1;        // prende el timer
  // limpia lecturas y banderas
  while (TMR1IF_bit == 0) {
    if ((s1_in == 0) && (flag_s1 == 0)) {
      lectura1 = ((unsigned int)TMR1H << 8) | TMR1L;
      flag_s1 = 1;
    }
    // igual para los demas sensores
  }
}
2.4

Enviar

▶ 12:07

En el ciclo principal se mide y se envían las lecturas por el UART a 9600.

UART1_Init(9600);
UART1_Write_Text("iniciando");
while (1) {
  analizasensoresir();
  sprintf(texto, "lecturas=%d %d %d\r\n", lectura1, lectura2, lectura3);
  UART1_Write_Text(texto);
  Delay_ms(200);
}
