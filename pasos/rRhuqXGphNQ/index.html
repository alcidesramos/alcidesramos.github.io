Librería para servomotores

Un servo usa PWM de 50 Hz (20 ms). El ángulo depende del ancho del pulso: en la teoría clásica 0.5 ms es -90°, 1.5 ms es 0° y 2.5 ms es +90°, pero muchos servos (y los de Proteus) van de 1 a 2 ms. Como 50 Hz también sirve para la mayoría de motores DC, se usa un solo timer: canales 1 y 2 para motores DC, canales 3 y 4 para servos. La librería tiene SERVO_init y SERVO_ANG, y los límites en ms y en grados son configurables.

Fase 1

Teoría

1.1

Señal de un servo

▶ 0:33

Periodo fijo de 20 ms (50 Hz). Solo importa el ancho del pulso positivo:

  • 0.5 ms → -90° (o 0° si cuentas de 0 a 180)
  • 1.5 ms → 0° (centro)
  • 2.5 ms → +90° (o 180°)

Hoy muchos servos se mueven entre 1 y 2 ms, y los de Proteus también. Por eso la librería deja calibrar los límites.

Fase 2

Configuración

2.1

Circuito

▶ 2:13

Se agregan dos servos (SER1 y SER2) y se llevan al osciloscopio junto a EN1 y EN2 de los motores DC.

2.2

Canales 3 y 4 y periodo de 20 ms

▶ 2:45

En TIM1 activa también Channel3 y Channel4 como PWM Generation. Deja el prescaler en 16-1 (1 µs por cuenta a 16 MHz) y cambia el Counter Period de 10000 a 20000: 20 ms, es decir 50 Hz.

Al crear los canales CubeMX puede remapear la USART a otros pines; revisa el circuito.

2.3

Constantes de usuario

▶ 4:23

Igual que en la clase 45, agrega en User Constants los nombres de los servos (CubeMX los escribe en main.h). O descomenta el bloque de definiciones en servos.h.

#define PWMTIM1    TIM1
#define PWMT1      htim1
#define SERVO1_CH  TIM_CHANNEL_3
#define SERVO2_CH  TIM_CHANNEL_4
#define SERVO1     TIM1->CCR3
#define SERVO2     TIM1->CCR4

Servo 1 no es el canal 1: SERVO1 usa el canal 3 y SERVO2 el canal 4. Los canales 1 y 2 siguen siendo PWM1 y PWM2 de los motores DC.

Fase 3

Librería de servos

3.1

Límites configurables (servos.h)

▶ 6:03

Pon el ancho de pulso mínimo y máximo de tu servo en ms y el rango de ángulos que quieres usar. Escribe siempre los valores con decimal (1.0, no 1).

// límites en ms de los servos
#define ser_lim_inf_ms  1.0     // 0.5 si tu servo llega a 0.5 ms
#define ser_lim_sup_ms  2.0     // 2.5 si llega a 2.5 ms

// movimiento deseado del servo
#define ser_inf  -90.0           // o 0.0
#define ser_sup   90.0           // o 180.0

void SERVO_init(TIM_HandleTypeDef *servo, uint16_t canal);
void SERVO_ANG(uint32_t *canal, float posi);
3.2

Ecuación de la recta (servos.c)

▶ 6:37

SERVO_ANG calcula el ancho de pulso para el ángulo pedido con la recta que pasa por (ser_inf, lim_inf) y (ser_sup, lim_sup), y lo pasa a microsegundos (cuentas del timer).

#include "servos.h"

void SERVO_init(TIM_HandleTypeDef *servo, uint16_t canal)
{
    HAL_TIM_PWM_Start(servo, canal);
}

void SERVO_ANG(uint32_t *canal, float posi)
{
    float calcu;
    calcu = (ser_lim_sup_ms - ser_lim_inf_ms) / (ser_sup - ser_inf);
    calcu = calcu * (posi - ser_inf);
    calcu = (calcu + ser_lim_inf_ms) * 1000.0;   // ms a µs
    *canal = calcu;
}

El ×1000 supone que el timer cuenta 1 µs por tick (prescaler = MHz del reloj - 1). Si cambias el prescaler, ajusta ese factor.

3.3

Usarla en main

▶ 7:43
PWM_init(&PWMT1, PWM1_CH);      // motores DC
PWM_init(&PWMT1, PWM2_CH);

SERVO_init(&PWMT1, SERVO1_CH);  // servos
SERVO_init(&PWMT1, SERVO2_CH);

SERVO_ANG(&SERVO1, 30);         // 30 grados
SERVO_ANG(&SERVO2, -60);        // -60 grados
