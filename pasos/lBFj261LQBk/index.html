Pantalla OLED SSD1306 con PIC

La OLED SSD1306 es pequeña y económica. Se usa una librería de terceros modificada que trabaja por I2C (por hardware o por software) y trae funciones para texto, números, líneas, rectángulos, círculos e imágenes. Se revisa en la hoja de datos cómo se elige la dirección con el pin SA0 (D/C), se arma el circuito en Proteus, se escribe texto y se convierten imágenes con el GLCD Bitmap Editor. Al final se quita el pin de reset y se mueve el I2C a otros pines.

▶ Ver el video completo (31:09) Empezar el paso a paso
  • MikroC PRO for PIC (librería I2C o Soft_I2C)
  • PIC18F2550
  • Pantalla OLED 128x64 SSD1306 (UG-2864HSWEG01 en Proteus)
  • Resistencias de 4.7 kΩ para SDA y SCL
  • Librería SSD1306 (fonts.c, SSD1306.c y SSD1306.h)
  • GLCD Bitmap Editor de MikroC

Fase 1

La pantalla

1.1

OLED SSD1306

▶ 0:02

Es una pantalla gráfica monocromática de 128x64 puntos. La librería que se usa sirve también para otros micros; se modificó para dibujar y para trabajar el I2C por software.

1.2

Pines y dirección

▶ 2:19

En modo I2C, CS va a tierra. El pin D/C hace de SA0: con 0 la dirección es 0b0111100 (0x78 al escribir) y con 1 es 0b0111101 (0x7A). El pin RES reinicia la pantalla; si el módulo no lo trae no se usa.

1.3

Circuito

▶ 5:46

En Proteus el modelo de la OLED trae el bus de datos de 8 bits; para I2C se dejan solo SDA (D1 y D2 unidos), SCL (D0), RES y D/C. SDA y SCL llevan resistencias de 4.7 kΩ a VDD.

Fase 2

Programa

2.1

Librería

▶ 10:19

Se copian fonts.c, SSD1306.c y SSD1306.h al proyecto. Con #define reset se indica que se usa el pin de reset y en qué pin está.

2.2

Activar I2C

▶ 12:53

Al compilar sale error en I2C1_Init si no se activa la librería I2C. Se habilitan I2C y conversiones en el Library Manager.

2.3

Texto

▶ 13:59

Todo digital, se inicia la pantalla y se escribe. Primero va la columna (0 a 127) y luego la fila (0 a 7).

void main() {
  adcon1 = 0b1111;   // todo digital
  OLED_init();
  OLED_print_string(0, 0, "HOLA");
  OLED_print_string(0, 7, "esto es una prueba");
  Delay_ms(3000);
  while (1) {
  }
}
Fase 3

Imágenes

3.1

Crear la imagen

▶ 17:30

En el GLCD Bitmap Editor (pestaña de 128x64) se carga una imagen o se dibuja, y con Copy to Clipboard se copia el arreglo para mikroC. Se pega en un archivo imagenes.h y se incluye en el programa; el arreglo va en memoria de programa (const).

3.2

Dibujar

▶ 21:54

OLED_print_Image muestra una imagen de pantalla completa; con ON u OFF se invierten los colores. OLED_draw_bitmap pone una imagen más pequeña en una posición y tamaño dados.

OLED_clear_screen();
OLED_print_Image(&truck, OFF);
// OLED_draw_bitmap(0, 0, 50, 50, &media);
Delay_ms(3000);
OLED_clear_screen();
OLED_print_Image(&carsun, ON);
Fase 4

Menos pines

4.1

Sin reset

▶ 27:54

Si el módulo no tiene pin de reset, se conecta RES a VDD y se borra el #define reset. La pantalla sigue funcionando.

4.2

I2C en otros pines

▶ 29:08

Con el I2C por software, SDA y SCL pueden ir en cualquier pin del micro; solo se cambian las definiciones de pines y su dirección (TRIS).
