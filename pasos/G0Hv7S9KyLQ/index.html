Control de posición con PID y encoder

Con la lectura del encoder del video anterior se cierra el lazo: un potenciómetro fija el setpoint en pulsos (de -50 a 50 en el ejemplo), la interrupción por flanco cuenta los pulsos y una función PID calcula la salida entre -255 y 255. La magnitud va al PWM y el signo decide el sentido de giro.

Fase 1

La idea

1.1

Posición con un PID

▶ 0:00

La idea es decirle al motor cuántos pasos dar, como para abrir una puerta: va rápido y frena suave al llegar. El encoder cuenta los pasos y el PID decide la velocidad y el sentido.

1.2

Pulsos por vuelta

▶ 1:07

En la simulación una vuelta son unos 50 pulsos. En un motor real hay que medir cuántos pulsos da y usar ese número.

1.3

Setpoint con el potenciómetro

▶ 2:10

El ADC de 10 bits da 0 a 1023. En Excel se ponen dos puntos (0 → -50, 1023 → 50), se hace la gráfica de dispersión y la línea de tendencia da la ecuación: setpoint = 0.0978 · código - 50.

2.2

Función PID

▶ 7:29

kp, ti y td se ajustan para cada sistema. La salida se limita a ±255 porque el PWM llega a 255 y el signo da el sentido. Con tiempo de muestreo 1 no hay que tenerlo en cuenta.

float kp = 1.0, ti = 100.0, td = 0.0;   // ajustar al sistema
float error, up, ui = 0.0, ui_ = 0.0, error_ = 0.0, ud, ut = 0.0, d_error = 0;
float ki, kd;
float setpoint = 0;

void pid(float pid_in) {
  const float max_s = 255.0;
  const float min_s = -255.0;
  const float t_muestreo = 1.0;

  error = setpoint - pid_in;
  up = kp * error;                          // proporcional
  if (ti != 0) ki = (kp / ti); else ki = 0;
  ui = ui_ + (ki * t_muestreo * error);     // integral
  kd = kp * td;
  d_error = error - error_;
  ud = kd * (d_error) / t_muestreo;         // derivativa
  ut = up + ui + ud;
  if (ut > max_s) ut = max_s;
  if (ut < min_s) ut = min_s;
  ui_ = ui;
  error_ = error;
}
2.3

Interrupción del encoder

▶ 11:29

Es la misma del video del encoder: compara A con B en cada flanco y cambia el flanco. Además limita los pulsos a ±50.

void interrupt() iv 0x0004 ics ICS_AUTO {
  if (INTF_bit == 1) {
    if (PORTB.RB1 == PORTB.RB0) pulsos++;
    else pulsos--;
    if (pulsos > 50) pulsos = 50;
    if (pulsos < -50) pulsos = -50;
    INTEDG_bit = ~INTEDG_bit;
    INTF_bit = 0;
  }
}

2.5

Lazo principal

▶ 13:43

Se lee el ADC con ADC_Get_Sample (más rápido que ADC_Read, porque el ADC ya se inició), se calcula el setpoint y se llama al PID con los pulsos. Si la salida es negativa se cambia de signo y se invierte el giro; la magnitud va al PWM.

codigo = ADC_Get_Sample(0);
setpoint = 0.0978 * codigo - 50.0;
pid(pulsos);
if (ut < 0) {
  ut = -ut;
  m11 = 0; m12 = 1;   // un sentido
} else {
  m11 = 1; m12 = 0;   // el otro
}
PWM1_Set_Duty(ut);

Prueba

3.1

Llega al setpoint

▶ 17:04

Con setpoint 43 el motor se mueve hasta que los pulsos llegan cerca de 43. En simulación la sintonía no es perfecta; en un motor real se ajustan las constantes.

3.2

Setpoint negativo

▶ 18:11

Con setpoint negativo el motor gira al otro lado. Esto sirve para puertas o para orientar un panel solar, convirtiendo pulsos en ángulo o desplazamiento.
