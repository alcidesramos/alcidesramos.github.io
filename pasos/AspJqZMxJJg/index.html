ESP32 en Wokwi: IA y depuración en VS Code

Se crea un proyecto de PlatformIO para la ESP32 DevKit V1 con el framework de Arduino. Wokwi necesita un archivo wokwi.toml y un diagram.json; en vez de copiarlos a mano, se le pide a la IA del editor que arme la placa con el LED interno y el TX0/RX0 conectados al terminal. Se escribe el programa con ayuda del autocompletado, revisando lo que propone (a veces se equivoca en mayúsculas o en lo que agrega). Luego se agrega un segundo LED en el pin 4, se pasa el circuito del editor web de Wokwi al de VS Code y se le pide a la IA ordenar los cables. Para depurar se agrega gdbServerPort al wokwi.toml, se arranca Wokwi con debugger y se corre paso a paso con breakpoints y una variable en Watch.

Fase 1

Proyecto y archivos de Wokwi

1.1

Proyecto en PlatformIO

▶ 0:00

En PlatformIO se crea un proyecto nuevo con la placa ESP32 DevKit V1 y el framework Arduino. Se limpia la función de ejemplo que trae main.cpp para dejar setup y loop vacíos.

1.2

Falta el wokwi.toml

▶ 1:09

Si se le da play a la simulación sale un error: falta el archivo wokwi.toml. Ese archivo dice dónde está el firmware compilado; también tiene opciones para depurar y para conectarse por fuera.

1.3

La IA crea la placa

▶ 2:50

Se le pide a la IA: simular la ESP32 DevKit en Wokwi, solo la placa, con el LED interno de la placa y con TX0 y RX0 conectados al terminal.

La IA crea el wokwi.toml, el diagram.json con una placa que ya trae el LED y hasta un programa de ejemplo.

1.4

Editar el circuito

▶ 5:38

El diagram.json se puede abrir con el editor de texto o con el editor visual de Wokwi. También se puede copiar el JSON al editor web de Wokwi, agregar piezas allá y traerlo de vuelta.

Fase 2

Programa con ayuda de la IA

2.1

Código del LED y serial

▶ 6:43

Se deja el serial a 9600 y se quita lo que la IA inventó de más. Mientras se escribe, el autocompletado propone el resto (se acepta con Tab), pero hay que leerlo: a veces copia cosas que no son.

2.2

Simular

▶ 8:22

Se compila y se inicia la simulación. El LED de la placa parpadea y el terminal muestra «LED encendido» y «LED apagado».

2.3

Segundo LED

▶ 9:03

En el editor web se agregan un LED, una resistencia y tierra en el pin 4, y se pega el JSON de vuelta en VS Code. En el código se define LED2 en el pin 4 y se alterna con el de la placa.

Ojo: el autocompletado escribió DIGITAL_WRITE en mayúsculas y faltó el pinMode del LED2; hay que revisar lo que se acepta.

uint8_t BUILTIN_LED_PIN = 2;
#define LED2 4

void setup() {
  pinMode(BUILTIN_LED_PIN, OUTPUT);
  pinMode(LED2, OUTPUT);
  Serial.begin(9600);
  Serial.println("ESP32 DevKit V1 listo");
}

void loop() {
  digitalWrite(BUILTIN_LED_PIN, HIGH);
  digitalWrite(LED2, LOW);
  Serial.println("LED encendido");
  delay(1000);
  digitalWrite(BUILTIN_LED_PIN, LOW);
  digitalWrite(LED2, HIGH);
  Serial.println("LED apagado");
  delay(1000);
}
2.4

Circuito con IA

▶ 11:54

También se le puede pedir a la IA que agregue un LED azul en D13 con su resistencia, y luego, con una captura, que lo pase al lado izquierdo sin cruces de cables.

Fase 3

Depuración

3.1

Habilitar el debugger

▶ 14:08

En wokwi.toml se agrega el puerto del servidor GDB. Para que aparezca la opción de depurar con Wokwi, se le pide a la IA que configure el launch del proyecto y se le permiten los cambios.

[wokwi]
version = 1
firmware = '.pio/build/esp32doit-devkit-v1/firmware.bin'
elf = '.pio/build/esp32doit-devkit-v1/firmware.elf'
gdbServerPort = 3333
3.2

Correr paso a paso

▶ 19:40

El orden es: compilar, abrir Wokwi y darle «Start simulation with debugger» para que quede esperando; luego en Run and Debug elegir la opción de Wokwi y darle play.

Con breakpoints se avanza línea a línea. El LED de la placa prende con cero, por eso arranca apagado. En la última línea del loop conviene darle play y no step, porque entra al código interno y se traba.

3.3

Reparar el serial

▶ 21:20

Al copiar el JSON se perdieron las conexiones de TX0 y RX0 al terminal. Se le pide a la IA que las vuelva a colocar.

3.4

Ver variables

▶ 23:35

Se crea una variable cont que aumenta en cada vuelta y se agrega en Watch. Al correr paso a paso se ve cómo cambia su valor, sin tener la placa ni un depurador JTAG.

uint8_t cont = 0;
// ...
void loop() {
  cont++;
  Serial.print("Contador: ");
  digitalWrite(BUILTIN_LED_PIN, HIGH);
  digitalWrite(LED2, LOW);
  Serial.println("LED encendido");
  delay(1000);
  digitalWrite(BUILTIN_LED_PIN, LOW);
  digitalWrite(LED2, HIGH);
  Serial.println("LED apagado");
  delay(1000);
}
