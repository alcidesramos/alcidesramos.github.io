DFPlayer Mini con PIC

El DFPlayer Mini se alimenta con 5 V; un parlante de 1 W va a SPK1 y SPK2, o DAC_R y DAC_L a un amplificador. Solo se usa el TX del PIC al RX del módulo, sin eco, a 9600 baudios. BUSY baja mientras suena. Cada comando es una trama 7E FF 06 comando 00 dato_alto dato_bajo checksum EF. La librería mp3_chino (.c y .h) define los comandos y tiene funciones para siguiente, previo, pista, volumen (0 a 30) y ecualizador. Los archivos de la SD empiezan por cuatro dígitos. El ejemplo, en un PIC16F877A a 4 MHz, da la bienvenida (pista 5), avisa temperatura alta o baja leyendo un LM35, y con dos pulsadores reproduce un mensaje o música.

▶ 1:00

Solo se conecta el TX del micro al RX del módulo; el módulo puede contestar, pero se trabaja sin eco. Los archivos de la SD deben empezar por un número de cuatro dígitos, de 0001 a 9999.

Fase 2

La librería

2.1

Trama y comandos

▶ 3:40

La trama empieza en 0x7E, sigue la versión 0xFF, el largo 0x06, el comando, el eco, el parámetro de 16 bits, el checksum y termina en 0xEF.

#include "built_in.h"
const char inicio = 0x7E;
const char fin = 0xEF;
const char version = 0xFF;
const char eco = 0;     // si se coloca 1 responde con eco
const char largo = 0x06;
unsigned int checksum;
unsigned char comando;
unsigned int parametro = 0;

// comando
#define next        0x01
#define previus     0x02
#define archivo     0x03  // de 0 a 2999
#define volumen_sub 0x04
#define volumen_baj 0x05
#define volumen     0x06  // de 0 a 30
#define equaliza    0x07

Funciones

▶ 6:00

Cada función pone el comando y el parámetro, calcula el checksum y manda la trama.

void mp3_previo() {
  comando = previus;
  calula_checksum();
  manda_mp3();
}

void mp3_play_x(unsigned int cancion) {
  comando = archivo;
  parametro = cancion;
  calula_checksum();
  manda_mp3();
}

3.2

Inicio

▶ 8:30

Se configuran entradas y salidas, pull-up del puerto B, se inicializa el módulo y suena la bienvenida.

void main() {
  ADCON1 = 0;          // todo análogo
  TRISA0_bit = 1;      // entrada análoga
  TRISB0_bit = 1;      // entrada pulsador1
  TRISB1_bit = 1;      // entrada pulsador2
  TRISC0_bit = 0;      // salida led
  TRISC6_bit = 0;      // salida tx
  TRISC7_bit = 1;      // entrada rx
  NOT_RBPU_bit = 0;    // habilita pull up en portb
  Delay_ms(500);
  mp3_inicializa();    // manda comando de inicialización
  Delay_ms(200);
  mp3_play_x(bienvenida);
  Delay_ms(1000);
  while (1) {
    // lectura del LM35: sobre 60 suena temp_alta, bajo 20 temp_baja (ver video)
    // pulsador sw: mensaje suiche_pres a volumen 20
    if (sw1 == 0) {
      mp3_play_x(musica);   // en el video, a volumen 30
      Delay_ms(2000);
    }
    led = !led;
    Delay_ms(500);
  }
}
