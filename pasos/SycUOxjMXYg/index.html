Macros con #define para manejar pines IN/OUT

En esta clase simplificamos el manejo de GPIO en STM32. En lugar de escribir HAL_GPIO_WritePin(LED1_GPIO_Port, LED1_Pin, 1) cada vez, creamos macros con #define que usan el operador ## para pegar la etiqueta del pin con _GPIO_Port y _Pin. Así basta escribir PIN_ON(LED1). Probamos todo en Proteus con una BlackPill STM32F401, tres LEDs y un pulsador, y al final movemos las macros a una librería propia (pinout.h) para reutilizarlas en cualquier proyecto.

2.2

Configurar y etiquetar los pines

▶ 7:50

PA0, PA1 y PA2 como GPIO_Output; PA3 como GPIO_Input con pull-up interno.

Con clic derecho > Enter User Label les ponemos nombre: LED1, LED2, LED3 y SW1. Estas etiquetas son la clave de las macros, porque CubeMX genera LED1_Pin y LED1_GPIO_Port en main.h.

El pulsador va a tierra, por eso se activa el pull-up: suelto lee 1 y presionado lee 0.

Fase 3

Macros con ##

3.1

Primera macro

▶ 19:00

El operador ## concatena el parámetro con el resto del texto. Si escribimos PIN_ON(LED2), el preprocesador lo reemplaza por HAL_GPIO_WritePin(LED2_GPIO_Port, LED2_Pin, 1).

#define PIN_ON(pin) HAL_GPIO_WritePin(pin##_GPIO_Port, pin##_Pin, 1)
3.2

Crear la librería pinout.h

▶ 23:00

Creamos una carpeta Librerias dentro de Core y en ella un Header File llamado pinout.h. Como solo tiene macros, no necesita archivo .c.

Recordar agregar la carpeta a los Include paths del proyecto.

3.3

Contenido de pinout.h

▶ 29:20

Estas son todas las macros de la librería:

#include "main.h"
#ifndef LIBRERIAS_PINOUT_H_
#define LIBRERIAS_PINOUT_H_

#define PIN_ON(pin)          HAL_GPIO_WritePin(pin##_GPIO_Port, pin##_Pin, 1)
#define PIN_OFF(pin)         HAL_GPIO_WritePin(pin##_GPIO_Port, pin##_Pin, 0)
#define PIN_PUT(pin, value)  ((value) ? PIN_ON(pin) : PIN_OFF(pin))
#define PIN_BLINK(pin)       HAL_GPIO_TogglePin(pin##_GPIO_Port, pin##_Pin)
#define PIN_READ(pin)        HAL_GPIO_ReadPin(pin##_GPIO_Port, pin##_Pin)

#endif /* LIBRERIAS_PINOUT_H_ */
Fase 4

Uso en main.c

4.1

Programa de prueba

▶ 32:00

Incluimos la librería y usamos las macros: LED2 queda encendido, LED1 parpadea y LED3 copia el estado del pulsador.

/* USER CODE BEGIN Includes */
#include "pinout.h"
/* USER CODE END Includes */

/* USER CODE BEGIN 2 */
PIN_ON(LED2);
/* USER CODE END 2 */

while (1)
{
  PIN_BLINK(LED1);
  HAL_Delay(200);
  PIN_PUT(LED3, PIN_READ(SW1));
}

Las macros solo funcionan si el pin tiene etiqueta (User Label) en CubeMX; si no, no existen LEDx_Pin ni LEDx_GPIO_Port y da error de compilación.
