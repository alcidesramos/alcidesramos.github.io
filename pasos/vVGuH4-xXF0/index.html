Más PIC con el PICkit 2 y 3

Los programas del PICkit 2 y del PICkit 3 leen la lista de micros de un archivo PK2DeviceFile.dat. Si se reemplaza por uno actualizado (hay un editor y un foro donde descargarlo), aparecen micros como el PIC16F1824. Para micros más modernos, como el dsPIC33EP512MU810, el programa del PICkit 3 no sirve: en Tools se pasa a modo MPLAB y se programa desde MPLAB X (con XC8, XC16) o, si el código se hizo en MikroC o CCS, con MPLAB IPE cargando el .hex. Ambos actualizan el firmware solos. Se puede volver al modo anterior cargando el sistema operativo del PICkit 3 sin interrumpir el proceso.

Fase 1

Archivo de dispositivos

1.1

El problema

▶ 0:00

El programa del PICkit tiene una lista de micros en el archivo PK2DeviceFile.dat. Si el micro no está, no lo reconoce, como pasa con un PIC16F1824 de montaje superficial.

1.2

Actualizarlo

▶ 2:12

Se descarga el archivo actualizado del foro de Microchip y se pega en la carpeta de instalación del PICkit 2 o del PICkit 3, reemplazando el viejo. El editor del archivo es opcional, solo sirve para ver la lista.

1.3

Prueba

▶ 3:18

Con el archivo nuevo el PICkit 3 reconoce el PIC16F1824 y lo puede leer y programar.

Fase 2

Micros más modernos

2.1

Modo MPLAB

▶ 4:28

Un dsPIC33EP512MU810 no se programa con el programa básico. En Tools se elige pasar a modo MPLAB; desde ahí el PICkit 3 se usa con MPLAB X o MPLAB IPE.

2.2

Desde MPLAB X

▶ 5:36

Se crea el proyecto para el micro, se elige el PICkit 3 y se compila con XC16. Al programar, MPLAB descarga el firmware nuevo y luego graba. Debe detectar el ID del micro; si no, hay una mala conexión o el micro está dañado.

2.3

Desde MPLAB IPE

▶ 8:22

Si el programa se hizo en MikroC o CCS, se usa MPLAB IPE, que se instala con MPLAB X: se escribe el micro, se elige el PICkit 3, se conecta, se carga el .hex y se programa.

2.4

Volver al modo anterior

▶ 10:02

En el programa del PICkit 3, Tools, se carga el sistema operativo desde su carpeta. No se debe interrumpir porque se puede dañar el programador. En modo MPLAB, el IPE puede no conectar hasta que actualiza el firmware.
