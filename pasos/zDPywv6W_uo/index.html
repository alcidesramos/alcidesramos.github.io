Módulo MP3 YX5300 con PIC

El YX5300 (Serial MP3 Player) recibe comandos por la UART y lee archivos de una tarjeta SD, numerados 001 a 255 dentro de carpetas 01 a 99. A diferencia del DFPlayer no puede mover un parlante directo: necesita audífonos o un amplificador, y se alimenta de 3,3 a 5 V. Con un PIC16F876A a 4 MHz y una librería propia se inicializa el módulo, se fija el volumen y se reproduce la pista 5 o 6 al arrancar; los demás comandos (repetir, carpeta, aleatorio, dormir) quedan como comentarios. En el ciclo se lee un LM35: por encima de 60 °C suena el mensaje de temperatura alta y por debajo de 20 °C el de temperatura baja, y un pulsador sube el volumen. En Proteus se ven los comandos en un terminal virtual.

2.2

Configuración

▶ 4:00

Se configuran el ADC, los pulsadores con pull-up, el LED y los pines de la UART, y se inicializa el módulo.

unsigned int codigo;
float temperatuta;

void main()
{
  ADCON1 = 0;          // todo análogo
  TRISA0_bit = 1;      // entrada análoga
  TRISB0_bit = 1;      // entrada pulsador1
  TRISB1_bit = 1;      // entrada pulsador2
  TRISC0_bit = 0;      // salida led
  TRISC6_bit = 0;      // salida tx
  TRISC7_bit = 1;      // entrada rx
  NOT_RBPU_bit = 0;    // habilita pull up en portb
  Delay_ms(100);
  mp3_init();          // manda comando de inicialización

2.7

Temperatura y pulsador

▶ 9:30

El LM35 da 10 mV por grado: con referencia de 5 V la temperatura es codigo * 500 / 1023. Según el valor suena un aviso, y el pulsador sube el volumen.

temperatuta = codigo * 500.0 / 1023.0;

if (temperatuta > 60)
{
  mp3_play_song(temp_alta);
  Delay_ms(5000);
}
else if (temperatuta < 20)
{
  mp3_play_song(temp_baja);
  Delay_ms(4000);
}

if (sw == 0)          // sube volumen
{
  mp3_vol_up();
  Delay_ms(200);
}
