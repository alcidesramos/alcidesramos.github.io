Termocupla tipo K con MAX6675

El MAX6675 entrega la temperatura de una termocupla K por una interfaz serie simple: el micro baja CS, genera el reloj SCK y lee el bit en SO en cada pulso. De los 16 bits, los 3 menos significativos no son temperatura, así que se desplaza a la derecha 3 veces y cada cuenta vale 0.25 °C. La librería se hace por software con HAL_GPIO y Delay_us (DWT), sin usar el periférico SPI.

Fase 1

Circuito

1.1

MAX6675 y termocupla

▶ 0:00

Coloca el MAX6675 y una termocupla tipo K (busca TCK). Para que la simulación se parezca a una termocupla real, conecta en la unión fría (CJ) un generador DC de 1 mV.

SO es entrada del micro (dato), SCK lo genera el micro (reloj) y CS habilita el módulo.

1.2

Pines en CubeMX

▶ 1:47

Además de la USART, configura tres pines con estas etiquetas exactas (la librería las usa):

  • DAT_MAX (PA0): GPIO_Input, a SO
  • CK_MAX (PA1): GPIO_Output, a SCK
  • CS_MAX (PA2): GPIO_Output, a CS
Fase 2

Librería

2.1

Trama del MAX6675

▶ 2:19

Según la hoja de datos se leen 16 bits. D15 es un bit de relleno, D14 a D3 son los 12 bits de temperatura, D2 indica termocupla abierta y D1-D0 son ID y estado. Por eso se desplaza el dato 3 veces a la derecha y se multiplica por 0.25 °C.

2.2

Inicializar y dar un pulso

▶ 2:19

El reloj arranca en 0 y CS en 1 (módulo apagado), con 100 ms de espera. Cada pulso sube el reloj, lee SO y vuelve a bajar el reloj.

#include "max6675.h"

void MAX6675_init(void)
{
    HAL_GPIO_WritePin(CK_MAX_GPIO_Port, CK_MAX_Pin, 0);  // reloj en 0
    HAL_GPIO_WritePin(CS_MAX_GPIO_Port, CS_MAX_Pin, 1);  // apaga el módulo
    HAL_Delay(100);
}

uint8_t MAX6675_pulso(void)
{
    uint8_t lei;
    HAL_GPIO_WritePin(CK_MAX_GPIO_Port, CK_MAX_Pin, 1);  // sube el reloj
    Delay_us(10);
    lei = HAL_GPIO_ReadPin(DAT_MAX_GPIO_Port, DAT_MAX_Pin);
    HAL_GPIO_WritePin(CK_MAX_GPIO_Port, CK_MAX_Pin, 0);  // baja el reloj
    Delay_us(10);
    return lei;
}
2.3

Leer la temperatura

▶ 3:25

Con CS en 0 se dan los pulsos del bit 15 al 0. El dato arranca en cero y solo se ponen los unos en su posición con una OR.

float MAX6675_lee(void)
{
    uint16_t sensor_dato;
    uint16_t max6675_dato = 0;   // importante: arranca en 0
    int8_t cont;

    HAL_GPIO_WritePin(CS_MAX_GPIO_Port, CS_MAX_Pin, 0);   // habilita
    for (cont = 15; cont >= 0; cont--)
    {
        if (MAX6675_pulso() == 1)
            max6675_dato = max6675_dato | 1 << cont;
    }
    HAL_GPIO_WritePin(CS_MAX_GPIO_Port, CS_MAX_Pin, 1);   // apaga

    sensor_dato = (max6675_dato >> 3);   // quita los 3 bits bajos
    return ((float)sensor_dato * 0.25);
}

Si quieres detectar la termocupla desconectada, revisa el bit 2 antes de desplazar: (max6675_dato & 0x04) distinto de 0 indica sensor abierto.

Fase 3

Programa principal

3.1

Includes y bucle

▶ 4:33

Incluye las librerías, stdio.h y string.h para sprintf. Inicializa el contador DWT de Delay_us y el MAX6675, y envía la temperatura por la UART cada segundo.

#include "uart.h"
#include "delays.h"
#include "max6675.h"
#include "stdio.h"
#include "string.h"

float temperatura;
char texto[30];

/* USER CODE BEGIN 2 */
uartx_write_text(&huart1, "INICIANDO\r\n");
delay_us_dwt_init();
MAX6675_init();

while (1)
{
    temperatura = MAX6675_lee();
    sprintf(texto, "temperatura=%.1f\r\n", temperatura);
    uartx_write_text(&huart1, texto);
    HAL_Delay(1000);
}

Para imprimir float con sprintf activa -u _printf_float (clase de sprintf).

Resultado
