Capturar varias teclas del teclado matricial

Partimos del proyecto del teclado matricial de la clase anterior y le agregamos una máquina de estados (n1, n2, n3, n4, en) que guarda cuatro dígitos en una cadena, los muestra en la LCD y, al presionar '=', los convierte con atoi() en el retardo de parpadeo de un LED. Al final se reemplaza HAL_Delay por una función de retardo que sigue escaneando el teclado mientras espera, para no perder teclas.

▶ Ver el video completo (18:19) Empezar el paso a paso
  • STM32F401 (Black Pill) o simulación en Proteus
  • Teclado matricial 4x4
  • LCD 16x2
  • LED con resistencia de 220 Ω (LED1 indica que se están ingresando dígitos)
  • Proyecto de la clase del teclado matricial (Teclado.c / Teclado.h)

Fase 1

Hardware y objetivo

1.1

El circuito

▶ 0:40

Es el mismo montaje del teclado matricial: filas TF1 a TF4 como salidas y columnas TC1 a TC4 como entradas, más la LCD. Se agrega un LED (en la simulación, LED-YELLOW con R5 de 220 Ω).

La idea: escribir un número de 4 dígitos (por ejemplo 1000), presionar '=' y que el LED parpadee con ese retardo en milisegundos.

Fase 2

Máquina de estados en Teclado.c

2.1

Variables y estados

▶ 3:30

En Teclado.c se declara la cadena donde se guardan los dígitos y un enum con un estado por dígito más el estado final. Hay que incluir ctype.h para usar isdigit().

#include "ctype.h"
#include "stdlib.h"   // atoi

int  retardo = 100;          // retardo inicial en ms
char retardo_cad[5];         // 4 dígitos + fin de cadena
enum teclado_estado {n1, n2, n3, n4, en};
char estado_teclado = n1;
2.2

Estados n1 a n4: guardar cada dígito

▶ 5:00

teclado_estado() lee la tecla con tecla_deco() y, según el estado, acepta solo dígitos. Cada dígito se guarda en su posición, se muestra en la LCD y se pasa al siguiente estado. El Delay_ms(400) funciona como antirrebote.

void teclado_estado(void)
{
  uint8_t tecla = tecla_deco();

  switch (estado_teclado)
  {
    case n1:
      if ((tecla != 0) && (isdigit(tecla)))
      {
        HAL_GPIO_WritePin(LED1_GPIO_Port, LED1_Pin, 1); // ingresando dígitos
        retardo_cad[0] = tecla;
        estado_teclado = n2;
        Lcd_Chr(2, 8, tecla);
        Delay_ms(400);            // antirrebote
      }
      break;

    case n2:
      if ((tecla != 0) && (isdigit(tecla)))
      {
        retardo_cad[1] = tecla;
        estado_teclado = n3;
        Lcd_Chr(2, 9, tecla);
        Delay_ms(400);
      }
      break;

    case n3:
      if ((tecla != 0) && (isdigit(tecla)))
      {
        retardo_cad[2] = tecla;
        estado_teclado = n4;
        Lcd_Chr(2, 10, tecla);
        Delay_ms(400);
      }
      break;

    case n4:
      if ((tecla != 0) && (isdigit(tecla)))
      {
        retardo_cad[3] = tecla;
        estado_teclado = en;
        Lcd_Chr(2, 11, tecla);
        Delay_ms(400);
      }
      break;
2.3

Estado en: confirmar con '='

▶ 7:30

En el estado final se espera el '='. Se cierra la cadena con 0, atoi() la convierte en número y ese valor pasa a ser el retardo. Si se presiona cualquier otra tecla se cancela y se vuelve a empezar.

    case en:
      if ((tecla != 0) && (tecla != '='))   // otra tecla: cancelar
      {
        HAL_GPIO_WritePin(LED1_GPIO_Port, LED1_Pin, 0);
        estado_teclado = n1;
        Lcd_Text(2, 8, "    ");           // borra la pantalla
        Delay_ms(600);
      }
      else if ((tecla != 0) && (tecla == '='))  // se presionó el igual
      {
        HAL_GPIO_WritePin(LED1_GPIO_Port, LED1_Pin, 0);
        retardo_cad[4] = 0;                 // fin de cadena
        retardo = atoi(retardo_cad);        // texto a número
        estado_teclado = n1;                // vuelve a capturar el primer número
        Lcd_Text(2, 8, "    ");
        Delay_ms(600);
      }
      break;
  }
}

Sin retardo_cad[4] = 0 la cadena no termina y atoi() puede leer basura después del cuarto dígito.

Fase 3

Usarlo en main.c

3.1

Primera versión con HAL_Delay

▶ 12:20

En main.c se declara la variable externa y en el while se llama a teclado_estado(), se conmuta el LED y se espera el retardo.

/* USER CODE BEGIN PV */
extern int retardo;

/* USER CODE BEGIN WHILE */
while (1)
{
  teclado_estado();
  HAL_GPIO_TogglePin(LED_GPIO_Port, LED_Pin);
  HAL_Delay(retardo);
}

Con retardos largos (por ejemplo 5000 ms) el teclado solo se lee una vez cada 5 s, así que se pierden teclas.

3.2

Retardo que sigue leyendo el teclado

▶ 15:30

La solución es un retardo propio que, mientras espera, llama a teclado_estado() todo el tiempo. Así el LED parpadea con el retardo elegido y el teclado responde de inmediato.

void teclado_init(void)
{
  delay_Init();
}

void teclado_retardo(int16_t valor)
{
  uint32_t tiem1;
  tiem1 = HAL_GetTick();
  while (HAL_GetTick() - tiem1 < valor) teclado_estado();
}

/* en main.c, antes del while */
teclado_init();

while (1)
{
  HAL_GPIO_TogglePin(LED_GPIO_Port, LED_Pin);
  teclado_retardo(retardo);
}

valor es int16_t, así que el máximo es 32767 ms. Con 4 dígitos (9999) alcanza; si quieres más, cámbialo a uint32_t.

Fase 4

Prueba en simulación

4.1

Cambiar el parpadeo desde el teclado

▶ 13:50

Se escribe 1000 y '=': el LED parpadea cada segundo. Con 5000 y '=' parpadea cada 5 s y el teclado sigue respondiendo. Con 0200 y '=' vuelve a ser rápido.

  • Mientras se escriben dígitos, LED1 se enciende.
  • Los dígitos aparecen en la LCD en las columnas 8 a 11.
  • Cualquier tecla que no sea '=' en el último paso cancela la captura.
