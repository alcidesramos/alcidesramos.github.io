Monitoreo WiFi con DT-06 y LabVIEW por TCP

Se usa el mismo programa del STM32 de la clase anterior (DS18B20 y pulsador enviando el protocolo de Virtuino), pero enviando más rápido (200 ms). El PC se conecta a la red WiFi del DT-06 y en LabVIEW se arma un ciclo while con TCP Open Connection (IP del módulo y puerto 200), TCP Read en modo Buffered y TCP Close Connection. De la cadena recibida se extrae el valor entre !A00= y $ con Match Pattern, se convierte con Fract/Exp String To Number y se muestra en un termómetro. El pulsador (!A01=) se compara con 1 para encender un LED. Es mucho más rápido que Virtuino.

Fase 1

Conexión TCP en LabVIEW

1.1

Abrir la conexión

▶ 0:33

En el diagrama de bloques se crea un ciclo while con botón Stop. Desde Data Communication → Protocols → TCP se pone TCP Open Connection con controles para la dirección y el puerto, y timeout −1 (espera indefinida). El PC debe estar conectado a la red WiFi del DT-06; la IP del módulo es 192.168.4.1 y el puerto el que se configuró en el servidor (200).

1.2

Leer y cerrar

▶ 2:18

Dentro del ciclo va TCP Read con timeout −1, modo Buffered y un número de bytes mayor que una trama (para que siempre haya dos o tres tramas completas en el buffer). Al salir del ciclo se cierra con TCP Close Connection. Un retardo de unos 300 ms basta, porque el PC es mucho más rápido que Virtuino.

1.3

Ver los datos crudos

▶ 4:00

En el STM32 se baja el retardo de envío a 200 ms. Al correr el VI, el indicador data out muestra las tramas que llegan, por ejemplo !A01=1$!A00=28.0$.

Fase 2

Extraer y mostrar los valores

2.1

Termómetro con la temperatura

▶ 5:15

Se agrega un termómetro (0 a 100) con display digital y un LED en el panel frontal. Con un Match Pattern se busca !A00= y con un segundo Match Pattern sobre el after string se busca el fin de la trama; lo que queda en before substring es el valor.

Match Pattern 1:  regular expression = !A00=
Match Pattern 2:  regular expression = \$     (el $ escapado con \)

El $ es un carácter especial en las expresiones de Match Pattern; hay que escribirlo como \$. También verifique que el identificador sea A00 (analógico) y no V00.

2.2

Convertir a número

▶ 7:20

La cadena se convierte con String/Number Conversion → Fract/Exp String To Number y se cablea al termómetro. Con clic derecho se pone use system decimal point en False para que tome el punto como separador decimal sin importar la configuración regional.

2.3

Pulsador al LED

▶ 8:35

Se repite el mismo bloque buscando !A01=. El resultado es 1 o 0, así que se compara con 1 y el booleano enciende o apaga el LED.

2.4

Resultado

▶ 9:26

Al cambiar la temperatura del DS18B20 en Proteus el termómetro se actualiza casi de inmediato, y el LED sigue al pulsador. El retardo que se nota es de la simulación de Proteus, no de la comunicación.
