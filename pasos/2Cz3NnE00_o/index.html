Dimmer AC con cruce por cero

Para regular la energía de una carga AC (bombillo, motor universal) se dispara un triac un tiempo después de cada cruce por cero: mientras más tarde, menos energía. La red se rectifica y un optoacoplador entrega un pulso en cada cruce. El micro lee un potenciómetro, convierte ese valor en un retardo con el Timer0 (o Timer1 en Arduino) y luego da un pulso corto al triac. Se agregan límites para no disparar dos veces cerca de los extremos.

Fase 1

La idea

1.1

Control de fase

▶ 0:00

La red es de 120 V y 60 Hz. Si el triac se dispara al inicio de cada semiciclo la carga recibe casi toda la energía; si se dispara más tarde, recibe menos. Así funcionan muchos dimmers y controles de velocidad.

1.2

Detector de cruce por cero

▶ 1:43

La señal AC pasa por un puente rectificador y un optoacoplador. Su salida da un pulso cada vez que la onda pasa por cero, es decir, cada 8.33 ms, porque la señal rectificada tiene dos semiciclos por periodo.

1.3

Circuito de control

▶ 3:23

El PIC12F1822 lee un potenciómetro, recibe el pulso de cruce por cero y maneja la salida de disparo. El osciloscopio muestra la red y la salida.

1.4

Calcular el timer

▶ 4:01

En Excel se calcula con qué prescaler el Timer0 de 8 bits alcanza unos 8 ms con el micro a 32 MHz.

Fase 2

Programa en el PIC

2.1

Retardo con el timer

▶ 6:56

La función espera carga un valor en el Timer0 y espera a que se desborde. Mientras más alto el valor, menos espera y más energía.

#define opto  RA2_bit
#define triac LATA1_bit

void espera(char t) {
  TMR0 = t;
  TMR0IF_bit = 0;
  while (TMR0IF_bit == 0);
}
2.2

Configuración

▶ 7:29

Oscilador interno a 8 MHz con PLL para llegar a 32 MHz, RA0 analógico para el potenciómetro, RA2 entrada del cruce por cero, RA1 salida al triac, ADC iniciado y Timer0 con su prescaler.

2.3

Disparo

▶ 9:23

Se lee el potenciómetro, se divide entre 4 para pasar de 0-1023 a 0-255, se espera el cruce por cero, se espera el retardo y se da un pulso de 100 µs al triac.

codigo = ADC_Get_Sample(0);
while (opto == 1);          // espera cruce por cero
velocidad = codigo >> 2;    // 0-1023 a 0-255
espera(velocidad);
triac = 1;
Delay_us(100);
triac = 0;
2.4

Límites

▶ 12:19

Cerca de los extremos el retardo es casi un semiciclo y el triac se puede disparar dos veces. Por eso, por debajo de 200 se deja apagado y por encima de 900 se deja encendido todo el tiempo.

if (codigo < 200) triac = 0;
else if (codigo > 900) triac = 1;
else {
  while (opto == 1);
  velocidad = codigo >> 2;
  espera(velocidad);
  triac = 1;
  Delay_us(100);
  triac = 0;
}
Fase 3

En Arduino

3.1

Por qué Timer1

▶ 16:22

En Arduino el Timer0 lo usa millis, así que se trabaja con el Timer1 de 16 bits. El circuito es el mismo con un Arduino Uno.

3.2

Funciones del timer

▶ 18:20

Se reutilizan las funciones de escritura del Timer1 de otros videos y una función espera que carga el valor y espera la bandera de desborde (TOV1).

3.3

Prescaler y escala

▶ 20:46

Con prescaler 8 el Timer1 se desborda en 32 ms. Para 8 ms hay que cargar desde 49536, así que el potenciómetro se escala con map entre 49536 y 65535.

codigo = analogRead(0);
if (codigo < 200) digitalWrite(triac, LOW);
else if (codigo > 900) digitalWrite(triac, HIGH);
else {
  velocidad = map(codigo, 0, 1023, 49536, 65535);
  while (digitalRead(opto) == 1);
  espera(velocidad);
  digitalWrite(triac, HIGH);
  delayMicroseconds(100);
  digitalWrite(triac, LOW);
}
