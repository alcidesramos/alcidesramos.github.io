PIC y LabVIEW full duplex en XC8

Se pasa a MPLAB XC8 la comunicación full duplex con LabVIEW hecha en MikroC. Con el MCC se configura un PIC18F25K20: reloj, ECCP1 en PWM con el Timer2, la EUSART a 9600 con printf redirigido y el ADC para el LM35. La recepción va por interrupción: cada dato se guarda en la trama y, al llegar el carácter de fin, se desactiva la interrupción y se activa una bandera. En el ciclo principal se procesa la trama con strstr para encender LEDs, girar el motor a la derecha, a la izquierda o detenerlo, y con strtok y atoi se toma el valor del PWM. Luego se limpia la trama, se reactiva la interrupción, se envía la temperatura con sprintf y el estado del pulsador. En Proteus el panel de LabVIEW muestra la temperatura, el pulsador y controla LEDs y motor.

2.2

Procesar la trama

▶ 21:02

strstr busca cada comando. Para el PWM, strtok toma el número entre = y /, atoi lo convierte y se escala de 0 a 100%.

else if (strstr(trama, "m1der"))  m1derecha();
else if (strstr(trama, "m1izq"))  m1izquierda();
else if (strstr(trama, "m1stop")) m1quieto();
else if (strstr(trama, "m1pwm="))
{
  strcpy(procesa, strtok(trama, "="));  // inicia captura de tokens desde el =
  strcpy(procesa, strtok(0, "/"));      // captura hasta el /
  dato = atoi(procesa);                 // pasa la cadena a número
  dato = dato * 623 / 100;              // escala la salida de 0 a 100% de PWM
  EPWM1_LoadDutyValue(dato);            // aplica la velocidad al PWM
}
2.3

Interrupción serial

▶ 23:48

Cada dato se guarda en la trama. Si se pasa de 30 se reinicia; al llegar el fin de trama se desactiva la interrupción y se activa la bandera.

void interrupt INTERRUPT_InterruptManager(void)
{
  if (RCIF == 1)
  {
    datorx = UART1_Read();      // lee el dato
    trama[puntero] = datorx;    // lo almacena en la trama
    puntero++;                  // incrementa el contador de trama
    if (puntero >= 30) puntero = 0;
    if (datorx == '*')          // si llega el fin de la trama
    {
      RCIE = 0;                 // deshabilita la interrupción
      flag_rx = 1;              // activa la bandera de trama válida
    }
    RCIF = 0;
  }
}
