Manejar un solo bit del puerto

Hasta aquí se manejaba el puerto completo. En esta lección se repasa el parpadeo del puerto B con el PIC16F84A y luego se hacen titilar solo RA0 y RB7. Se ven las dos formas de MikroC para acceder a un bit (registro.Bx o NOMBRE_bit) y se recomienda la segunda porque se parece más a otros compiladores. Al final se usan #define y sbit para llamar a los pines led1 y led2.

Fase 1

Repaso: el puerto completo

1.1

Parpadeo del puerto B

▶ 0:35

Proyecto nuevo con el PIC16F84A a 4 MHz y power-up timer activado. Se configura todo el puerto como salida y se prende y apaga completo.

TRISB = 0b00000000;   // todo salida
while (1)
{
  PORTB = 0b11111111;
  Delay_ms(300);
  PORTB = 0b00000000;
  Delay_ms(300);
}
Fase 2

Un solo pin

2.1

Registro punto bit

▶ 3:01

Para configurar solo RA0 como salida se escribe el registro, un punto y el bit. Lo mismo para encender o apagar solo RA0 y RB7 sin tocar los demás pines.

TRISB = 0b00000000;
TRISA.B0 = 0;      // solo RA0 es salida
PORTA = 0;
PORTB = 0;

while (1)
{
  PORTA.B0 = 1;    // enciende solo RA0
  PORTB.B7 = 1;
  Delay_ms(300);
  PORTA.B0 = 0;    // apaga solo RA0
  PORTB.B7 = 0;
  Delay_ms(300);
}
2.2

La forma _bit

▶ 6:20

MikroC también permite escribir el nombre del pin con _bit. Es equivalente y es la forma recomendada, porque se parece más a otros compiladores. Con Ctrl + espacio aparece la ayuda con los nombres.

TRISA0_bit = 0;   // RA0 salida
RA0_bit = 1;
RB7_bit = 1;
Fase 3

Nombres para los pines

3.1

#define

▶ 9:03

Si el LED cambia de pin habría que buscar y cambiar cada línea. Con #define se le da un nombre al pin al principio y el compilador lo reemplaza en todo el programa. Así el código se entiende mejor y basta con cambiar una línea.

#define led1 RA3_bit
#define led2 RB7_bit

led1 = 1;
led2 = 0;
3.2

sbit de MikroC

▶ 11:13

MikroC también tiene sbit, que hace lo mismo. #define es estándar de C y sirve en otros compiladores; sbit se usará más adelante con las librerías de MikroC.

sbit led2 at RB7_bit;
