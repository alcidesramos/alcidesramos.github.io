Clase 125: TFT ILI9488 dashboard animado

Sobre el mismo proyecto de la pantalla TFT ILI9488 (texto, figuras e imágenes) agregamos interactividad visual con una librería propia llamada DASHBOARD, hecha a puro código. Así se gasta mucha menos memoria que con TouchGFX u otros editores gráficos y sirve en micros pequeños. La librería trae dos tipos de LED, barra horizontal, dos variantes de barra vertical (tipo termómetro) y un gauge en arco con degradado verde, amarillo y rojo. Cada elemento se define como una estructura en DASHBOARD.c, se declara extern en DASHBOARD.h y en el while se actualiza su campo value y se redibuja.

Fase 1

Agregar la librería DASHBOARD

1.1

Incluir DASHBOARD.h

▶ 1:15

Se copian DASHBOARD.c y DASHBOARD.h a la carpeta de librerías y se incluye junto a las demás en el main.

Las pruebas de figuras e imágenes de las clases anteriores se dejan comentadas.

/* USER CODE BEGIN Includes */
#include "ili9488.h"
#include "fonts.h"
#include "imagenes.h"
#include "DASHBOARD.h"
/* USER CODE END Includes */
1.2

Qué trae la librería

▶ 1:50

En DASHBOARD.h están las estructuras de cada instrumento: Gauge_ARZ (centro, radio, grosor, ángulo inicial y final, valor, colores), Led y Barra.

Por cada elemento que se cree en DASHBOARD.c hay que poner su extern en DASHBOARD.h para poder usarlo desde el main.

// DASHBOARD.h : un extern por cada elemento que se crea en DASHBOARD.c
extern Led led1;
extern Led led2;
extern Barra barrah1;     // barra horizontal
extern Barra barrav1;     // barra vertical
extern Gauge_ARZ gauge1;  // gauge en arco
Fase 2

LEDs

2.1

Definir los LEDs

▶ 2:30

Cada LED tiene posición x, y, color apagado, color encendido y radio. Para un segundo LED se copia la estructura, se cambia el nombre y los valores.

Cuidado con las coordenadas: en el video el LED2 no aparecía porque se escribió y = 1000, fuera de la pantalla.

// DASHBOARD.c : define los led a usar
Led led1 =
{
  .x = 50,
  .y = 250,
  .color_off = COLOR_GREY,
  .color_on  = COLOR_RED,
  .r = 20,
};

Led led2 =
{
  .x = 50,
  .y = 100,
  .color_off = COLOR_WHITE,
  .color_on  = COLOR_GREEN,
  .r = 30,
};
2.2

Encender y apagar en el while

▶ 5:00

Se pone un color de fondo una sola vez antes del while. Dentro se cambia el campo estado (1 encendido, 0 apagado) y se dibuja.

led_draw dibuja el LED plano y led_draw1 lo dibuja con un punto de brillo. Dentro de esa función se puede cambiar la división del radio para hacer el brillo más grande o más pequeño.

fillScreen(COLOR_BEIGE);

while (1)
{
  led1.estado = 1;
  led2.estado = 0;
  led_draw(&led1);    // LED tipo 1
  led_draw1(&led2);   // LED tipo 2 (con brillo)
  HAL_Delay(200);

  led1.estado = 0;
  led2.estado = 1;
  led_draw(&led1);
  led_draw1(&led2);
  HAL_Delay(200);
}
Fase 3

Barras de progreso

3.1

Variable a mostrar

▶ 7:30

Se crea una variable flotante temp que simula una temperatura: arranca en 10.5, sube 2.2 en cada vuelta y vuelve a 0 al pasar de 50. En un proyecto real aquí iría la lectura de un sensor.

3.2

Configurar las barras

▶ 9:20

Barra vertical: posición, ancho 30, alto 120, rango 0 a 50, colores de fondo, relleno y marco, si muestra o no el valor (showValue), color del texto, fuente y número de rayitas.

La barra horizontal usa la misma estructura: aquí empieza en la esquina (0,0), mide 200 de ancho y va de 0 a 100 con relleno azul.

// barras de progreso verticales
Barra barrav1 =
{
  .x = 150,
  .y = 150,
  .w = 30,
  .h = 120,
  .vmin = 0,
  .vmax = 50,
  .value = 0,
  .colorFondo = COLOR_LIGHTGRAY,
  .colorFill  = COLOR_RED,
  .colorMarco = COLOR_BLACK,
  .showValue  = 1,              // 1 = escribe el valor, 0 = solo la barra
  .textColor  = COLOR_BLACK,
  .text_fondo = COLOR_WHITE,
  .font = font1,
  .numTicks = 5,                // # de rayitas
};

// barras de progreso horizontales
Barra barrah1 =
{
  .x = 0,
  .y = 0,
  .w = 200,
  .h = 20,
  .vmin = 0,
  .vmax = 100,
  .value = 0,
  .colorFondo = COLOR_LIGHTGRAY,
  .colorFill  = COLOR_BLUE,
  .colorMarco = COLOR_BLACK,
  .showValue  = 1,
  .textColor  = COLOR_BLACK,
  .text_fondo = COLOR_WHITE,
  .font = font1,
  .numTicks = 5,
};
3.3

Dibujar las barras

▶ 13:10

En el while se copia la variable al campo value de cada barra y se llama la función de dibujo.

Hay dos funciones para la vertical: barrav_draw escribe el valor debajo de la barra y barrav_draw1 lo escribe a la derecha.

3.4

Ancho del texto del valor

▶ 13:50

Dentro de la función de dibujo de la barra, el valor se escribe con un formato tipo "%5.1f". El 5 es el número de caracteres que ocupa el texto (por ejemplo 100.1).

Si vas a mostrar valores negativos o de miles, aumenta ese número para que el texto anterior se borre bien. Aplica a la barra horizontal y a la vertical.

Fase 4

Gauge en arco

4.1

Configurar el gauge

▶ 15:00

Se define centro, radio 80, ancho del arco 12, rango 0 a 100, ángulo inicial -225 y final 45, y resolución angular de 5.

El arco cambia de color en degradado: verde al inicio, amarillo en el centro y rojo al final.

Cambiando el ángulo inicial (por ejemplo a -270) el arco se abre más o se cierra completamente.

// gauge a usar
Gauge_ARZ gauge1 = {
  .x = 300,          // centro
  .y = 120,
  .r = 80,           // radio
  .w = 12,           // ancho del arco
  .vmin = 0,         // valor minimo
  .vmax = 100,       // valor maximo
  .value = 0,        // valor inicial variable
  .Ang_ini = -225,   // angulo inicial
  .Ang_fin = 45,     // angulo final
  .Res_ang = 5,      // pasos
  .fondo = COLOR_WHITE,      // fondo del arco
  // degradado
  .colorIni = COLOR_GREEN,   // color inicio
  .colorMed = COLOR_YELLOW,  // color centro
  .colorFin = COLOR_RED,     // color final
  // del texto
  .showValue = 1,            // muestra el valor
  .textColor = COLOR_WHITE,  // color del texto
  .font = font2,             // font a usar
};

El gauge trabaja solo con enteros: el valor se escribe con %d. Si quieres decimales, cambia el formato dentro de la función a algo como %.3f.

4.2

Animar todo en el while

▶ 16:40

Se crea otra variable velo que sube de 8 en 8 y vuelve a 0 al pasar de 100. Se asigna a gauge1.value y se dibuja con gauge_draw_arc.

Así quedan funcionando al mismo tiempo los LEDs, las dos barras y el gauge.

/* USER CODE BEGIN PV */
float temp = 10.5;
float velo = 0;
/* USER CODE END PV */

/* ... dentro del main ... */
fillScreen(COLOR_BEIGE);

while (1)
{
  barrav1.value = temp;
  barrah1.value = temp;
  barrav_draw(&barrav1);      // valor abajo (barrav_draw1: valor a la derecha)
  barrah_draw(&barrah1);

  gauge1.value = velo;        // el gauge trabaja con enteros
  gauge_draw_arc(&gauge1);

  temp += 2.2;
  if (temp > 50) temp = 0;

  velo += 8;
  if (velo > 100) velo = 0;

  led1.estado = 1; led2.estado = 0;
  led_draw(&led1); led_draw1(&led2);
  HAL_Delay(200);
  led1.estado = 0; led2.estado = 1;
  led_draw(&led1); led_draw1(&led2);
  HAL_Delay(200);
}
4.3

Resultado

▶ 18:20

En la pantalla el gauge avanza en verde, pasa por naranja y llega a rojo antes de reiniciarse, mientras la barra vertical simula el termómetro.

Si un elemento sale encima de otro, ajusta sus coordenadas x, y en DASHBOARD.c.
