Evasor mejorado con máquina de estados

Con Timer Calculator se genera el Timer0 a 10 ms. En la interrupción, si el carro gira, una variable rumbo sube o baja como un encoder; al llegar a 105 o −105 (cerca de 90 grados) se detiene el timer y se activa la bandera de giro. Si avanza, cuenta el tiempo hasta un límite (200 equivale a 2 s) y activa la bandera de tiempo. Así el programa no se bloquea. La máquina de estados tiene avante, babor, estribor, avante después de girar a la derecha y avante después de girar a la izquierda: si hay un obstáculo gira a la derecha; si al girar encuentra otro a 5 cm o menos, invierte el giro; después avanza un tiempo y se endereza. El robot llega al otro lado desde distintas posiciones; los valores se ajustan según los objetos y la pista.

1.4

Estados y banderas

▶ 4:02

La máquina de estados tiene avante, avance después de girar a la derecha o a la izquierda, babor y estribor. Rumbo es el encoder; hay banderas de giro, de tiempo, de dirección y de giro correcto.

enum estado_dir {avante, avante_time_d, avante_time_i, babor, estribor};
char dir_estado = avante;  // variable estado actual

signed long rumbo = 0, limite_giro = car_A;
unsigned int limite_tiempo = 0;

char flag_tiempo = 0;   // detecta si avanzó el tiempo requerido

Fase 2

La interrupción

2.1

Encoder y tiempo

▶ 6:47

Cada 10 ms: si el carro gira, rumbo sube o baja; al llegar al límite se apaga el timer y se activa flag_giro. Si avanza, cuenta el tiempo y al llegar al límite activa flag_tiempo.

void Interrupt() {
  if (TMR0IF_bit) {
    TMR0IF_bit = 0;
    TMR0H = 0xD8;
    TMR0L = 0xF0;
    if (flag_dir != car_A) {  // si no está moviendo adelante
      if (flag_dir == car_D) rumbo++;
      else rumbo--;
      if (rumbo == limite_giro) {
        TMR0IE_bit = 0;  // deshabilita timer
        flag_giro = 1;   // activa bandera que ya llegó al límite
      }
    }
    else {  // si es movimiento adelante
      tiempo++;
      if (tiempo >= limite_tiempo) {
        TMR0IE_bit = 0;  // deshabilita timer
        tiempo = 0;
        flag_tiempo = 1;
      }
    }
  }
}

3.2

Giro correcto

▶ 17:30

Mientras gira, si la distancia es de 30 cm o más el giro es correcto. Al terminar, si fue correcto, pasa a avanzar un tiempo para pasar el obstáculo.

case babor:
  if (distancia >= 30) flag_giro_ok = 1;  // detecta si es correcto girar en ese sentido

Enderezar

▶ 18:39

Cumplido el tiempo después de girar a la derecha, gira a la izquierda hasta rumbo 0 para quedar recto y vuelve a avante.
