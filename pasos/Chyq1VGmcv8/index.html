Clase 115: Tiempo de muestreo del control

Segundo capítulo de la serie del motor DC. Para un control en lazo cerrado el tiempo de muestreo debe ser constante y mayor que lo que tarda el proceso (leer frecuencia, leer set point, calcular el PID y aplicar el PWM). Con el TIM9 contando microsegundos se mide que todo tarda unos 40 µs. Luego se configura el TIM3 con preescalador 840-1 y periodo 2000 para obtener una interrupción cada 20 ms, y el proceso se mueve a la librería timer.c, declarando como extern las variables compartidas con el main.

Fase 1

Medir el tiempo del proceso

1.1

Incluir la librería PID

▶ 1:06

Se agrega la librería PID solo para medir el tiempo total: leer frecuencia, leer el set point, calcular el PID y sacar el PWM. El PID se explica en un próximo capítulo.

Para motores DC se usan tiempos de muestreo de 10 a 80 ms; el proceso debe tardar mucho menos que eso.

1.2

TIM9 a 1 µs

▶ 2:46

Se activa un timer libre, el TIM9, con reloj interno y prescaler 84-1 para que cuente microsegundos.

1.3

Medir con el contador

▶ 3:20

Se arranca el timer, se pone el contador en cero, se ejecuta el proceso y se lee el valor del contador.

HAL_TIM_Base_Start(&htim9);
TIM9->CNT=0;

// proceso a medir: leer, calcular PID y aplicar PWM

uint32_t tiempo=TIM9->CNT;
sprintf(texto,"TIM=%lu\r\n",tiempo);
uartx_write_text(&huart1, texto);
1.4

Resultado: 40 µs

▶ 5:03

El proceso tarda unos 40 µs. Se podría muestrear desde 2-3 ms, pero muestrear muy rápido carga el micro con interrupciones.

Se recomienda 10 ms o más, salvo procesos muy críticos. Aquí se usan 20 ms. El código de medición se deja comentado.

Fase 2

Timer de muestreo

2.1

Calcular el TIM3

▶ 5:37

Con preescalador 84-1 cada cuenta es 1 µs y el contador de 16 bits solo llega a 65 ms.

Si el preescalador es 840-1 (cristal x10) cada cuenta vale 10 µs: periodo 2000 = 20 ms, 5000 = 50 ms, 10000 = 100 ms. Así hay un rango más amplio sin pasar de 65535.

2.2

Configurar TIM3 con interrupción

▶ 6:54

TIM3 con reloj interno, Prescaler 840-1 y Counter Period 2000.

En NVIC Settings se habilita TIM3 global interrupt.

Fase 3

El proceso en la interrupción

3.1

Código del callback

▶ 8:33

timer.c no tiene .h: el callback se llama solo. Se indica el timer (TIM3) y se pega el proceso que estaba en el while.

Se calcula la frecuencia, se lee el potenciómetro, se mapea al rango del motor y se aplica al PWM (por ahora sin PID). El LED de la tarjeta se conmuta en cada interrupción para poder medir el muestreo con un osciloscopio.

#define TIM_INT TIM3

#include "main.h"
#include "Frecuencia.h"
#include "PWMB.h"
#include "adc_x.h"
#include "MAP.h"

extern uint16_t codigo;
extern ADC_HandleTypeDef hadc1;
extern float frecuencia1;

void HAL_TIM_PeriodElapsedCallback(TIM_HandleTypeDef *htim)
{
  if (htim->Instance == TIM_INT)
  {
    HAL_GPIO_TogglePin(Led_GPIO_Port, Led_Pin);
    if (FREC1.frec_leida==0) frecuencia1=0;
    else
      frecuencia1=FREC1.frec_muestreo/FREC1.frec_leida;
    FREC1.frec_leida=0;   // en cero para otra lectura
    codigo=ADC_Read(&hadc1);
    codigo=map(codigo,0,4095,1300,4200);
    PWM_valor(&PWM1, codigo);
  }
}
3.2

Variables externas

▶ 11:57

Todo lo que el callback usa del main se declara extern en timer.c (codigo, frecuencia1, hadc1) y se incluyen las librerías que usa (Frecuencia, PWMB, adc_x, MAP).

Si no, aparecen errores de variables no declaradas.

Fase 4

Arrancar y probar

4.1

Iniciar el TIM3

▶ 14:40

Hay que arrancar el timer en el main, después de iniciar el PWM y la frecuencia. Sin esto la interrupción no se ejecuta y el motor no responde.

PWM_init(&PWM1);
Frec_init(&FREC1);
HAL_TIM_Base_Start_IT(&htim3);
4.2

Resultado

▶ 15:31

El motor responde igual que en lazo abierto, pero ahora la lectura y la salida se hacen cada 20 ms exactos. En el while solo queda imprimir los datos, aunque tenga retardos grandes.

El siguiente paso es graficar la curva del motor para identificarlo y sintonizar el PID.

while (1)
{
  sprintf(texto,"DN=%u   Frec=%.1f\r\n\r\n",codigo,frecuencia1);
  uartx_write_text(&huart1, texto);
  HAL_Delay(300);
}
