Control y monitoreo WiFi con DT-06 y Virtuino

El montaje pasa a físico con una BlackPill STM32F411 a 100 MHz, el DT-06, el DS18B20 y el pulsador; el monitoreo sigue igual (cada 4 s). Para el control se agregan en Virtuino un switch y un slider en memorias virtuales V00 y V01, configurados para enviar el valor solo cuando cambian. El STM32 recibe las tramas con la librería uart_int_idle_dma (clase 87) y en procesa_rx busca V00=1 / V00=0 para el LED y V01= para capturar el valor con strtok y aplicarlo a un PWM en TIM2 CH1 (50 Hz) con la librería PWMB. Un analizador lógico muestra el cambio de ancho de pulso.

Fase 2

Recepción en el STM32

2.1

Inicializar la recepción

▶ 5:01

Se agregan uart_int_idle_dma.c/.h (clase 87). Antes del while se inicia la recepción y en el while se procesa cuando llega una trama:

uartdat_it_idle_dma_init();

while (1)
{
    if (flag_rx == 1)
    {
        procesa_rx();
        flag_rx = 0;
        uartdat_it_idle_dma_init();
    }
    /* ...monitoreo de temperatura y pulsador */
}
2.2

Procesar el switch

▶ 6:09

Basta con buscar V00=1 o V00=0. El LED de la BlackPill es de lógica invertida, por eso con 1 se apaga el pin:

Al tocar el switch en el celular, después de unos segundos el LED azul de la tarjeta cambia, mientras la app sigue mostrando la temperatura y el estado del pulsador.

void procesa_rx()
{
    if (strstr(trama_rx, "V00=1"))      PIN_OFF(LED);   // LED invertido: enciende
    else if (strstr(trama_rx, "V00=0")) PIN_ON(LED);    // apaga
}
Fase 3

Control analógico con PWM

3.1

Slider en Virtuino

▶ 9:08

Se agrega un slider en memoria virtual V01, de 0 a 100 %, que envíe solo cuando se mueve. En Hercules se ve llegar !V01=50$, !V01=80$…

3.2

PWM en TIM2 canal 1

▶ 11:23

TIM2 con reloj interno y PWM Generation CH1. Con el micro a 100 MHz: Prescaler 100-1 y Counter Period 20000 para 50 Hz, auto-reload habilitado.

Prescaler (PSC)      = 100-1
Counter Period (ARR) = 20000      // 50 Hz
auto-reload preload  = Enable
3.3

Librería PWMB

▶ 12:38

En PWMB.c la escala se deja de 0 a 100 y se declara la salida; en el main se inicializa:

float escala = 100;
extern TIM_HandleTypeDef htim2;
PWMS PWM1 = {&htim2, &(TIM2->CCR1), TIM_CHANNEL_1};

/* en main() */
PWM_init(&PWM1);
PWM_valor(&PWM1, 50);   // prueba al 50 %
3.4

Capturar el valor del slider

▶ 14:51

En procesa_rx se agrega la orden V01: se captura lo que hay entre = y $, se convierte y se aplica al PWM:

else if (strstr(trama_rx, "V01="))
{
    strcpy(procesa, strtok(trama_rx, "="));  // inicia captura
    strcpy(procesa, strtok(0, "$"));          // captura hasta el $
    ancho = atoi(procesa);                     // cadena a numero
    PWM_valor(&PWM1, ancho);
}
3.5

Resultado

▶ 16:46

Al mover el slider, en 4 o 5 segundos el analizador lógico muestra el nuevo ancho de pulso; el switch sigue controlando el LED y el monitoreo continúa. La lentitud es propia de Virtuino; con una app propia o una plataforma IoT es más rápido.
