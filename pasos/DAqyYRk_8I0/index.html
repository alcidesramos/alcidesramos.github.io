Clase en vivo: recepción serial por interrupción

La función uartx_read_text deja el micro esperando hasta que llega el '*'. En esta clase la reemplazamos por recepción por interrupción: habilitamos la interrupción de la USART1 en el NVIC, escribimos nuestra propia HAL_UART_RxCpltCallback (la de la HAL es __weak), guardamos cada byte en trama_rx con un contador y, al llegar el '*', levantamos una bandera. El while revisa la bandera y procesa la orden, así el carrito sigue funcionando mientras el micro hace otras tareas.

Fase 1

Habilitar la interrupción serial

1.1

El problema: lectura bloqueante

▶ 2:30

uartx_read_text se queda esperando el final de trama. Mientras tanto el micro no hace nada más. La comentamos para reemplazarla.

1.2

Activar USART1 global interrupt

▶ 5:30

En el .ioc entra a Connectivity → USART1 → NVIC Settings y marca USART1 global interrupt.

En System Core → NVIC puedes darle prioridad: número más bajo, más prioridad.

Fase 2

Callback propio

2.1

Dónde llega la interrupción

▶ 7:40

En stm32f4xx_it.c aparece USART1_IRQHandler, que llama a HAL_UART_IRQHandler. Esta termina llamando a HAL_UART_RxCpltCallback cuando se completa la recepción.

2.2

La palabra __weak

▶ 12:20

En stm32f4xx_hal_uart.c, HAL_UART_RxCpltCallback está declarada como __weak (débil).

Si escribes una función con el mismo nombre en otro archivo, el compilador usa la tuya. Así tienes tu propio código en tu librería y no en el archivo generado.

No borres la versión __weak del archivo de la HAL. Basta con definir la tuya sin la palabra __weak.

2.3

Arrancar la recepción

▶ 17:10

Como el timer, la recepción por interrupción necesita un arranque. Antes del while pide un byte con HAL_UART_Receive_IT.

/* USER CODE BEGIN 2 */
HAL_UART_Receive_IT(&huart1, dato_rx, 1);
/* USER CODE END 2 */
2.4

Buffer de un byte

▶ 19:30

Declara el buffer de un dato en main.c.

char dato_rx[1];
2.5

Primera prueba: un LED por byte

▶ 21:10

En uart.c escribe tu callback: cambia un LED y vuelve a pedir el siguiente byte.

void HAL_UART_RxCpltCallback(UART_HandleTypeDef *huart)
{
  HAL_GPIO_TogglePin(led3_GPIO_Port, led3_Pin);
  HAL_UART_Receive_IT(&huart1, dato_rx, 1);
}

Si no vuelves a llamar a HAL_UART_Receive_IT, solo se recibe el primer byte.

2.6

Compartir variables con extern

▶ 25:20

uart.c necesita dato_rx, trama_rx y huart1, que están en main.c. Decláralas con extern y el mismo tipo, sin tamaño ni valor inicial.

Recomendación del profe: deja la variable real en tu librería y el extern en main.c.

// en uart.c
extern UART_HandleTypeDef huart1;
extern char dato_rx[];
extern uint8_t trama_rx[];

Probar

▶ 26:40

Corre Proteus y LabVIEW: el LED cambia con cada byte que llega.

Fase 3

Armar la trama

3.1

Contador de bytes

▶ 29:00

Crea un contador de 16 bits en uart.c. uint8_t solo cuenta hasta 255; uint16_t llega a 65 535.

uint16_t contador_rx = 0;
3.2

Guardar cada byte

▶ 32:40

Copia el byte a una variable local y guárdalo en la posición del contador.

3.3

Límite del buffer y final de trama

▶ 36:00

Si el contador llega al tamaño del buffer (100), vuelve a 0 para no desbordar.

Si llega el '*', la trama está completa.

3.4

Probar con Hercules

▶ 38:50

Envía texto sin '*' y no pasa nada; cuando envías una trama terminada en '*' el LED cambia. Para devolver la trama, une también PA9 (TX) con el TX del COMPIM.

3.5

No olvidar incrementar

▶ 42:40

En la clase al principio no funcionaba porque faltaba contador_rx++ después de guardar el byte.

Fase 4

Bandera y procesamiento en el while

4.1

Levantar una bandera

▶ 47:20

Procesar dentro de la interrupción la hace lenta. En su lugar, cuando llega el '*', pon una bandera en 1.

char flag_rx = 0;

void HAL_UART_RxCpltCallback(UART_HandleTypeDef *huart)
{
  char dato_leido;
  dato_leido = dato_rx[0];
  trama_rx[contador_rx] = dato_leido;
  contador_rx++;
  if (contador_rx >= 100)
  {
    contador_rx = 0;
  }
  if (dato_leido == '*')
  {
    contador_rx = 0;
    flag_rx = 1;
  }
  HAL_UART_Receive_IT(&huart1, dato_rx, 1);
}
4.2

Procesar en el while

▶ 49:10

En main.c declara extern char flag_rx y extern uint16_t contador_rx.

En el while, si la bandera está en 1, procesa la trama y baja la bandera.

while (1)
{
  if (flag_rx == 1)
  {
    procesarx();
    flag_rx = 0;
    contador_rx = 0;
  }
  uartx_write_text(&huart1, "mas puntos");
  HAL_GPIO_TogglePin(led1_GPIO_Port, led1_Pin);
  HAL_Delay(200);
}

Una mejora es desactivar la recepción mientras se procesa y reactivarla al terminar, para tramas largas.

4.3

Prueba final

▶ 53:40

El micro transmite y hace titilar el LED mientras recibe órdenes por interrupción: el carrito se mueve desde LabVIEW sin bloquear nada.

Si el carrito no responde, revisa que Hercules no tenga abierto el mismo puerto que LabVIEW.
