True RMS con XC8

Es la traducción a XC8 del medidor de voltaje RMS real hecho en MikroC. En el MCC se pone el oscilador HS de 10 MHz, los pines del LCD en RC0 a RC5 y el ADC en AN0 justificado a la derecha. El código se copia casi igual: se lee el ADC, se suma el cuadrado del voltaje y, al llegar a 1500 muestras (más de tres ciclos de 60 Hz), se saca la raíz del promedio, se aplica el divisor resistivo y la caída del puente rectificador. El problema es la memoria: sprintf con flotantes no cabe, así que primero se muestra el valor entero con una función propia y luego, subiendo la optimización de XC8 a nivel 3, ya se puede mostrar con decimales: 127,55 V.

Fase 2

Pasar el código

2.1

El programa de MikroC

▶ 3:57

Se incluyen el LCD, string, stdio y math, y se copian las variables. La inicialización del LCD cambia un poco en XC8.

2.2

Muestrear

▶ 6:08

Cada muestra se convierte a voltaje y se suma su cuadrado. Las muestras deben cubrir varios ciclos de la señal.

lectura = ADC_GetConversion(0);   // realiza primera lectura
__delay_us(10);
voltaje = lectura * 5.0 / 1023.0;  // calcula el voltaje
suma += voltaje * voltaje;
muestras++;
2.3

Calcular el RMS

▶ 7:19

A las 1500 muestras se saca la raíz del promedio, se aplica el divisor resistivo y se suma la caída del puente rectificador.

if (muestras == 1500)
{
  voltaje = sqrt(suma / (float)muestras);
  voltaje = voltaje * (res1 + res2) / res2;   //aplica el divisor resistivo
  voltaje = voltaje + 1.4;                    //suma caida en el puente rectificador
  muestras = 0;
  suma = 0;
  floattostr(voltaje, texto, 2);
  Lcd_Set_Cursor(2, 9);
  Lcd_Write_String(texto);
  __delay_ms(100);   ///retardo de refresco
}
Fase 3

Memoria

3.1

No cabe

▶ 8:24

Con sprintf la memoria del micro queda al 85 % y luego no compila. Se prueba una función propia para pasar el número a texto.

3.2

Valor entero

▶ 10:07

numbertostr, más pequeña, muestra el valor sin decimales: 127 V.

3.3

Optimización

▶ 13:30

Para usar los decimales se sube la optimización de XC8 a nivel 3. Ya compila y el LCD muestra 127,55 V estable.

3.4

Comparación

▶ 14:04

En MikroC el mismo programa ocupaba el 65 % de la ROM; en XC8 con el MCC, el 95 %. El MCC agrega código que no siempre se necesita.
