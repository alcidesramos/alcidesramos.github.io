Módulo de inicio y parada con IR

En las competencias de seguidores de línea y sumo el robot debe arrancar y detenerse con un módulo de inicio comercial. La idea es hacerlo con un receptor IR común conectado a un Arduino Nano. En lugar de IRremote se usa una librería propia (irarz) que decodifica el control por interrupciones con un algoritmo de hash y usa solo el Timer2. Se explica qué timer usa cada función de Arduino para evitar conflictos, se arma el circuito en Proteus, se imprime el código de cada tecla por el puerto serial y con dos de esos códigos se arma el arranque y la parada, mientras el programa principal sigue trabajando.

  • Arduino Nano (o Uno)
  • Receptor infrarrojo de tres pines y un control remoto
  • Resistencia de 100 Ω y condensador de 0,1 µF para el receptor (montaje real)
  • Dos LEDs con sus resistencias
  • Proteus para la simulación y la librería del receptor en .zip

Fase 1

El circuito

1.1

Arduino Nano y receptor IR

▶ 2:12

Se usa un Arduino Nano por el poco espacio que hay en estos robots. El receptor IR va al pin 2 o 3 (pines de interrupción externa).

En el montaje real el receptor se alimenta de 5 V a través de una resistencia de 100 Ω y lleva un condensador de 0,1 µF, como indica su hoja de datos; con un micro de 3,3 V puede ir directo.

1.2

LEDs y terminal virtual

▶ 4:28

Se agregan dos LEDs en los pines 11 y 12: uno parpadea para mostrar que el programa principal sigue corriendo y el otro muestra el estado de arranque o parada.

Un Virtual Terminal en TX permite ver los códigos que llegan del control.

Fase 2

Por qué el Timer2

2.1

Qué timer usa cada función

▶ 6:02

En el Arduino Uno/Nano el Timer0 (8 bits) lo usan delay(), millis() y micros(); el Timer1 (16 bits) lo usa la librería Servo, y el Timer2 (8 bits) lo usa tone().

2.2

Los pines PWM también dependen de los timers

▶ 6:37

analogWrite usa el Timer0 en los pines 5 y 6, el Timer1 en los pines 9 y 10 y el Timer2 en los pines 11 y 3.

Como la librería usa solo el Timer2, con ella no se puede usar tone() ni analogWrite en los pines 3 y 11. Si hace falta, la librería se puede pasar al Timer1 cambiando los registros que dicen 2 por 1.

Por esto IRremote suele dar problemas con Servo y tone: usa más de un timer.

Fase 3

El programa

3.1

Incluir la librería y declarar variables

▶ 9:20

Se instala la librería desde el .zip (Sketch, Incluir librería, Añadir biblioteca .ZIP) y se incluye. Se declara el pin del receptor y una variable unsigned long donde la librería deja el código de la tecla.

#include "irarz.h"

#define led 11
#define led1 12

int irpin=2;             // pin usado para el sensor IR
unsigned long codigo_ir; // código único de la tecla

void setup() {
  pinMode(led, OUTPUT);
  pinMode(led1, OUTPUT);
  Serial.begin(9600);  // inicia comunicación a 9600
  ir_init();           // inicializa el receptor IR
}
3.2

Capturar los códigos del control

▶ 10:29

En el loop se llama analiza_ir() y se imprime codigo_ir en hexadecimal. Si no hay tecla presionada llega 0. Con un delay largo se alcanza a leer el código de cada botón en el terminal.

void loop() {
  analiza_ir();
  Serial.println(codigo_ir, HEX); // deshabilitar si se desea
  delay(5000);  // solo mientras se capturan los códigos
}
3.3

Arranque y parada

▶ 12:23

Los códigos de las dos teclas elegidas se guardan como constantes y se comparan. En el ejemplo de abajo van valores de ejemplo: cada control tiene los suyos.

El LED del pin 11 sigue parpadeando, lo que muestra que el programa principal no se detiene mientras la interrupción analiza el código.

#define IRSTART 0x00000000  // código de tu tecla de arranque
#define IRSTOP  0x00000000  // código de tu tecla de parada

void loop() {
  analiza_ir();
  if (codigo_ir == IRSTART)      digitalWrite(led1, HIGH);
  else if (codigo_ir == IRSTOP)  digitalWrite(led1, LOW);

  digitalWrite(led, HIGH);
  delay(50);
  digitalWrite(led, LOW);
  delay(50);
}
3.4

Exportar y probar en Proteus

▶ 14:25

Con Sketch, Exportar binarios compilados se genera el .hex, se carga en el Arduino de Proteus y se prueba con el control: una tecla prende la salida y la otra la apaga.
