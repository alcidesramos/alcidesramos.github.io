Módulo MP3 DFPlayer Mini con STM32

Se pasa a STM32 la librería del DFPlayer Mini que antes estaba hecha para PIC. El módulo se controla por la UART (solo hace falta TX del micro) y reproduce archivos MP3 de una memoria SD. El ejemplo lee un LM35 por el ADC y dice en voz alta si la temperatura está alta o baja; un pulsador baja el volumen y otro pone música al máximo. Se simula en Proteus con un COMPIM conectado al módulo real por un cable USB serial.

▶ Ver el video completo (13:33) Empezar el paso a paso
  • Black Pill STM32F401 (o simulación en Proteus con COMPIM)
  • Módulo DFPlayer Mini con memoria SD (FAT16 o FAT32, hasta 32 GB)
  • Parlante de máximo 3 W (más potencia necesita amplificador)
  • Sensor LM35 en ADC1_IN0
  • Dos pulsadores (sw1, sw2) y un LED
  • Librerías dfplayer, built_in, uart y adc

Fase 1

El módulo

1.1

Conexión

▶ 0:00

El módulo trabaja por puerto serial. Con el micro real se conectan tierra, positivo (de 3.6 a 5 V) y el TX del micro al RX del módulo. En el video se usa un cable USB serial y Proteus con un COMPIM en el puerto COM donde quedó el cable (se ve en el Administrador de dispositivos).

El parlante no puede pasar de 3 W. Para más potencia hay que poner un amplificador.

1.2

Características y archivos

▶ 1:05

Soporta hasta 100 carpetas o archivos en la raíz numerados de 0001 a 2999, memorias de hasta 32 GB en FAT16 o FAT32, 30 niveles de volumen y 10 de ecualización. Sirve para que un proyecto hable: avisar que la temperatura está alta, dar la bienvenida, poner una canción.

Con este módulo los archivos deben llevar solo el número (0001.mp3, 0002.mp3...). Con nombres después del número tomaba archivos equivocados.

Fase 2

Proyecto

2.1

Periféricos

▶ 3:22

USART1 asíncrono a 9600 baudios (la velocidad del módulo). ADC1 con IN0 para el LM35 y la constante adc1 en User Constants para que la librería lo reconozca. Dos entradas con etiquetas sw1 y sw2 y una salida led que parpadea para ver que el programa corre.

2.2

Librerías

▶ 4:34

En la carpeta Librerias se copian dfplayer, built_in (la necesita dfplayer para calcular byte alto y bajo), uart y adc. built_in no se incluye en main: la llama dfplayer.

/* USER CODE BEGIN Includes */
#include "uart.h"
#include "adc.h"
#include "dfplayer.h"
2.3

Defines y variables

▶ 6:14

Cada define dice en qué número de archivo está guardado cada audio en la SD. Los switches se definen como lecturas directas del pin.

/* USER CODE BEGIN PD */
#define musica      1
#define temp_alta   2
#define temp_baja   3
#define suiche_pres 4
#define bienvenida  5

#define sw1 HAL_GPIO_ReadPin(sw1_GPIO_Port, sw1_Pin)
#define sw2 HAL_GPIO_ReadPin(sw2_GPIO_Port, sw2_Pin)

/* USER CODE BEGIN PV */
uint16_t codigo;
float temperatura;
Fase 3

Programa

3.1

Inicializar el módulo

▶ 7:20

El módulo es más lento que el micro para arrancar, así que conviene esperar antes de inicializarlo y un poco después.

/* USER CODE BEGIN 2 */
HAL_Delay(500);
mp3_inicializa();
HAL_Delay(200);
mp3_play_x(bienvenida);
3.2

El while

▶ 9:38

Se lee el LM35 (10 mV/°C). Si pasa de 60 °C dice que la temperatura está alta y si baja de 20 °C que está baja; la espera de 5 s es lo que dura el audio. sw1 baja el volumen y dice que se presionó el switch; sw2 sube el volumen y pone música.

while (1)
{
  codigo = ADC_Read();
  temperatura = codigo * 3.3 * 100.0 / 4095.0;   // LM35: 10 mV/°C

  if (temperatura > 60)
  {
    mp3_play_x(temp_alta);
    HAL_Delay(5000);       // lo que dura el audio
  }
  else if (temperatura < 20)
  {
    mp3_play_x(temp_baja);
    HAL_Delay(5000);
  }

  if (sw1 == 0)
  {
    mp3_volumen_x(20);
    mp3_play_x(suiche_pres);
    HAL_Delay(2000);
  }
  if (sw2 == 0)
  {
    mp3_volumen_x(30);     // volumen máximo
    mp3_play_x(musica);
  }

  HAL_GPIO_TogglePin(led_GPIO_Port, led_Pin);
  HAL_Delay(500);
}
Fase 4

Prueba y funciones

4.1

Simulación con el módulo real

▶ 9:01

Se habilita la generación del .hex (Properties, Post-build) y se carga en Proteus. Al arrancar suena la bienvenida. Bajando el LM35 de 20 °C dice que la temperatura está baja, subiéndolo de 60 °C que está elevada, y los pulsadores cambian volumen y ponen la canción. En la terminal virtual se ven las tramas que se envían (7E FF 06 ... EF).
