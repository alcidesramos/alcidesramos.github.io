Lectura de ancho de pulso PWM con Input Capture

Muy útil para sensores que entregan PWM (como el HC-SR04 o algunas brújulas) y para leer receptores de radiocontrol. Se usan los mismos canales Input Capture de la clase anterior (TIM1 CH1, TIM1 CH4 y TIM2 CH1) con el timer en pasos de 1 µs. La librería PWM_IN captura el contador en el flanco de subida, cambia la polaridad a bajada, captura de nuevo y la resta da el ancho de pulso en microsegundos (corrigiendo el desborde con el ARR). En el main solo se inicializan los canales y se leen las variables.

1.2

Timers en microsegundos

▶ 1:38

En el .ioc se usa TIM1 con Input Capture en los canales 1 y 4, y TIM2 en el canal 1. Prescaler = MHz del timer − 1 (16-1 aquí; 100-1 si el timer va a 100 MHz), Counter Period al máximo y auto-reload preload habilitado. La captura debe iniciar en flanco de subida (Polarity Selection: Rising Edge). Se habilitan las interrupciones de captura igual que en la clase 88.

2.2

Cómo mide el ancho de pulso

▶ 3:14

En el flanco de subida guarda el contador y cambia la polaridad a bajada; en el flanco de bajada guarda de nuevo, vuelve a subida y resta. Si el timer se desbordó suma el ARR:

void PWM_IN_INT_Analiza(PWM_INS *PWM_IN)
{
    // si la bandera del canal x del timer seleccionado esta activa
    if (__HAL_TIM_GET_FLAG(PWM_IN->htim, PWM_IN->PWM_flag) == 1)
    {
        if (PWM_IN->caida == 1)   // flanco de subida
        {
            __HAL_TIM_SET_CAPTUREPOLARITY(PWM_IN->htim, PWM_IN->channel,
                                          TIM_INPUTCHANNELPOLARITY_FALLING);
            PWM_IN->caida = 0;
            PWM_IN->pulso_s = *PWM_IN->ccr;   // lee el contador
        }
        else                      // flanco de bajada
        {
            __HAL_TIM_SET_CAPTUREPOLARITY(PWM_IN->htim, PWM_IN->channel,
                                          TIM_INPUTCHANNELPOLARITY_RISING);
            PWM_IN->caida = 1;
            PWM_IN->pulso_b = *PWM_IN->ccr;
            if (PWM_IN->pulso_b > PWM_IN->pulso_s)
                PWM_IN->pulso = PWM_IN->pulso_b - PWM_IN->pulso_s;
            else
                PWM_IN->pulso = PWM_IN->htim->Instance->ARR - PWM_IN->pulso_s + PWM_IN->pulso_b;
        }
        __HAL_TIM_CLEAR_FLAG(PWM_IN->htim, PWM_IN->PWM_flag); // limpia la bandera
    }
}
Fase 3

Uso en el proyecto

3.1

Main

▶ 4:53

Se incluye PWM_IN.h, se crean las variables, se inicializan los canales y en el while se leen. Después de leer se ponen en cero para que, si dejan de llegar pulsos, no quede el valor anterior:

char texto[100];
uint32_t pulso1, pulso2, pulso3;

PWM_IN_init(&PWM_IN1);
PWM_IN_init(&PWM_IN2);
PWM_IN_init(&PWM_IN3);

while (1)
{
    pulso1 = PWM_IN1.pulso;
    pulso2 = PWM_IN2.pulso;
    pulso3 = PWM_IN3.pulso;

    // limpia los pulsos por si no se dan interrupciones
    PWM_IN1.pulso = 0;
    PWM_IN2.pulso = 0;
    PWM_IN3.pulso = 0;

    sprintf(texto, "pulso1=%lu\r\n", pulso1);
    uartx_write_text(&huart1, texto);
    /* ...igual para pulso2 y pulso3 */
    HAL_Delay(100);
}
3.2

Interrupciones

▶ 5:58

En stm32f4xx_it.c se incluye PWM_IN.h y en la interrupción de cada timer se analizan sus canales:

#include "PWM_IN.h"

void TIM1_CC_IRQHandler(void)
{
  PWM_IN_INT_Analiza(&PWM_IN1);
  PWM_IN_INT_Analiza(&PWM_IN2);
  HAL_TIM_IRQHandler(&htim1);
}

void TIM2_IRQHandler(void)
{
  PWM_IN_INT_Analiza(&PWM_IN3);
  HAL_TIM_IRQHandler(&htim2);
}
