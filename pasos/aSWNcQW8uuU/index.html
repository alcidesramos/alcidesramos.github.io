Medir frecuencia con interrupciones

Entre dos flancos de subida pasa un periodo. Si el Timer1 cuenta ese tiempo, la frecuencia es Fosc / (4 × conteo × preescalador). En la primera versión cada flanco en RB0 dispara la interrupción INT, que lee y reinicia el Timer1. En la segunda, el módulo CCP en modo captura guarda solo el valor del timer al llegar el flanco. Una bandera indica si hubo flanco para mostrar 0 Hz cuando la señal desaparece. Sirve para encoders, tacómetros o un frecuencímetro.

Fase 1

La idea

1.1

Circuito

▶ 0:00

Un selector rotatorio elige entre cuatro señales de distinta frecuencia (hasta 60 Hz) que entran por RB0. El resultado se muestra en un LCD.

1.2

Medir el periodo

▶ 1:40

El Timer1 (16 bits) cuenta el tiempo entre un flanco de subida y el siguiente. Con ese valor se calcula el periodo y de ahí la frecuencia.

Fase 2

Con la interrupción INT

2.1

Variables e interrupción

▶ 4:16

contador guarda el valor del timer. En cada flanco se para el timer, se arma el valor de 16 bits, se reinicia y se vuelve a prender.

unsigned int contador = 0;
float frecuencia;
char texto[15];

void Interrupcion() iv 0x0004 ics ICS_AUTO {
  if (INTF_bit == 1) {
    TMR1ON_bit = 0;                    // para el conteo del timer
    contador = (TMR1H << 8) | TMR1L;
    TMR1H = 0;
    TMR1L = 0;
    TMR1ON_bit = 1;                    // arranca el conteo del timer
  }
  INTF_bit = 0;
}
2.2

Timer1 e INT

▶ 6:31

Timer1 con preescalador 1, registros en cero y apagado. INT por flanco de subida, bandera limpia, interrupción habilitada y al final GIE.

T1CON = 0;
T1CKPS1_bit = 0;   // preescalador 1
T1CKPS0_bit = 0;
TMR1L = 0;
TMR1H = 0;
TMR1ON_bit = 0;    // timer quieto

INTEDG_bit = 1;    // flanco de subida
INTF_bit = 0;      // limpia la bandera
INTE_bit = 1;      // habilita la interrupcion
GIE_bit = 1;       // habilita interrupciones
2.3

Calcular

▶ 11:05

Clock_kHz() da el cristal en kHz; por 1000 queda en Hz. Se divide entre el conteo por 4 (ciclo de instrucción) y por el preescalador. El micro queda libre para otras tareas.

while (1) {
  frecuencia = (Clock_kHz()*1e3)/(contador*4.0);
  FloatToStr(frecuencia, texto);
  Lcd_Out(2, 5, texto);
  Lcd_Out_CP(" HZ");
  Delay_ms(100);
}
2.4

Cuando no hay señal

▶ 14:28

Sin flancos no hay interrupción y se queda el último valor. Con una bandera flag_cero, que la interrupción pone en 1, se calcula solo si hubo flanco; si no, la frecuencia es 0. También se usa una función propia para mostrar solo dos decimales.

Fase 3

Con el módulo CCP

3.1

Captura

▶ 19:17

En modo captura, al llegar el flanco el CCP copia el Timer1 en CCPR2H y CCPR2L. Se puede capturar en cada flanco o cada 4 o 16 para señales rápidas. La señal entra por RC1 (CCP2).

3.2

Configurar

▶ 22:36

RC1 como entrada, el Timer1 igual que antes y el CCP2 en captura por flanco de subida; se limpia su bandera y se habilitan su interrupción, la de periféricos y la global.

3.3

Interrupción del CCP

▶ 27:06

Se lee el valor capturado, se avisa con flag_frec y se reinicia el timer.

void interrupcion() iv 0x0004 ics ICS_AUTO {
  if (CCP2IF_bit == 1) {
    TMR1ON_bit = 0;                    // para el timer
    frecu = (CCPR2H << 8) | CCPR2L;
    flag_frec = 1;                     // hay dato
    TMR1L = 0;
    TMR1H = 0;
    TMR1ON_bit = 1;                    // timer para el proximo dato
    CCP2IF_bit = 0;
  }
}
3.4

Mostrar

▶ 29:24

Si la bandera está activa se calcula; si no, la frecuencia vale 0. Luego se baja la bandera.

if (flag_frec == 1) {
  if (frecu != 0) {
    frecuencia = Clock_kHz()*1e3/(frecu*4.0);  // convierte a hercios
    frecu = 0;
  }
}
else frecuencia = 0;
flag_frec = 0;
