Lector RFID RC522 en XC8

Es una traducción del proyecto de MikroC, sin MCC. Se usan dos librerías: la del RC522, igual a la de MikroC, y una de SPI por software, porque XC8 no la trae. Antes de incluirlas se definen los pines del módulo en el puerto A. Las funciones seriales se hacen con los mismos nombres de MikroC para que el código quede compatible. El programa revisa si hay tarjeta, lee su número de serie y con el algoritmo hash FNV lo convierte en un unsigned long; luego lo compara con los códigos guardados y cambia el LED de cada tarjeta. Se prueba en la tarjeta entrenadora a 48 MHz con un terminal serial.

1.4

Algoritmo hash

▶ 4:11

El hash FNV recorre los bytes del UID y da un número único por tarjeta.

unsigned long Hash_algoritmo()
{
  unsigned long hash_acum = FNV_BASIS;

  for (cont = 0; cont < 4; cont++)
  {
    // Add value into the hash
    hash_acum = (hash_acum * FNV_PRIME) ^ UID[cont];
  }
  return (hash_acum);
}

Comparar códigos

▶ 9:21

Cada código conocido cambia el estado de un LED. Como el número está en decimal, se escribe sin 0x.

Aquí van los códigos de tus propias tarjetas; los de abajo son de ejemplo.

if (codigo_rfid == 1111111111)        // código de tu tarjeta 1
{
  led1 = ~led1;
  Uart1_write_text("TAG1\r\n");
}
else if (codigo_rfid == 2222222222)   // código de tu tarjeta 2
{
  led2 = ~led2;
