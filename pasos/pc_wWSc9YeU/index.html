Motores paso a paso con LabVIEW

Cada motor tiene su secuencia (paso simple de 4 códigos o medio paso de 8) y funciones para avanzar a la derecha o a la izquierda. El Timer0 interrumpe cada 8 ms y unos contadores deciden cuándo dar el siguiente paso según la velocidad (0 a 255). Cada motor puede estar quieto, girar continuo o dar un número de pasos. Las órdenes llegan por serial terminadas en asterisco y se procesan con strstr y strtok.

1.4

Funciones de giro

▶ 10:16

Cada función mueve la secuencia una posición y saca el código por los pines. n_pasos es 3 en paso simple y 7 en medio paso.

void saca_secuencia1() {
  pasos1++;
  m11 = codigo1[secuencia1].b0;
  m12 = codigo1[secuencia1].b1;
  m13 = codigo1[secuencia1].b2;
  m14 = codigo1[secuencia1].b3;
}
void izquierda1() {
  secuencia1++;
  if (secuencia1 > n_pasos) secuencia1 = 0;
  saca_secuencia1();
}
void derecha1() {
  secuencia1--;
  if (secuencia1 < 0) secuencia1 = n_pasos;
  saca_secuencia1();
}

2.4

Estados del motor

▶ 21:45

Cada motor puede estar a la derecha, a la izquierda o quieto, y en modo continuo o por pasos.

#define derecha 1
#define izquierda 2
#define quieto 3
#define continuo 1
#define pasos 2
char estado_giro1 = quieto, estado_giro2 = quieto;
char estado_modo1 = continuo, estado_modo2 = continuo;
2.5

Dentro de la interrupción

▶ 22:56

En cada interrupción suben los contadores. Cuando el de un motor llega a 256 menos su velocidad, se da un paso. En modo pasos, al completar los pedidos el motor queda quieto. Luego se recarga el timer y se limpia la bandera.

velo1++;
if (velo1 >= 256 - velo_m1) {
  velo1 = 0;
  if (estado_modo1 == pasos) {
    if (pasos1 >= n_pasos1) {
      estado_giro1 = quieto;   // llego a los pasos pedidos
      pasos1 = 0;
    }
  }
  switch (estado_giro1) {
    case derecha: derecha1(); break;
    case izquierda: izquierda1(); break;
  }
}

3.3

Procesar la orden

▶ 33:11

procesarx busca cada orden en la trama: m1der*, m1izq*, m1stop*, lo mismo para m2, la velocidad y los pasos. El valor numérico se saca con strtok y atoi.

void procesarx() {
  if (strstr(trama_rx, "m1der*")) estado_giro1 = derecha;
  else if (strstr(trama_rx, "m1izq*")) estado_giro1 = izquierda;
  else if (strstr(trama_rx, "m1stop*")) estado_giro1 = quieto;
  else if (strstr(trama_rx, "m2der*")) estado_giro2 = derecha;
  else if (strstr(trama_rx, "m2izq*")) estado_giro2 = izquierda;
  else if (strstr(trama_rx, "m2stop*")) estado_giro2 = quieto;
  else if (strstr(trama_rx, "vel1")) {
    strcpy(procesa, strtok(trama_rx, "="));
    strcpy(procesa, strtok(0, "*"));
    dato = atoi(procesa);
    estado_modo1 = continuo;
    velo_m1 = dato;
  }
  // ... vel2 y los pasos de cada motor igual
}
3.4

Interrupción serial

▶ 34:22

La interrupción guarda los datos y, al llegar el asterisco, desactiva la recepción y activa la bandera. Si hay error de desbordamiento (OERR) se reinicia CREN.

3.5

▶ 35:25

Si la bandera está activa se procesa la orden, se limpian la trama y el puntero y se habilita otra vez la interrupción serial.
