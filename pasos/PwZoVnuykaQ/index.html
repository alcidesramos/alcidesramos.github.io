Leer un control USB en LabVIEW

Query Input Devices dice cuántos controles hay; se inicializa el joystick con su índice (0), se lee dentro de un while con Acquire Input Data y al salir se cierra y se limpian los errores. Los ejes van de -32768 a 32767 y los botones son booleanos. Se usan el eje X de rotación para la dirección, el eje Z para la velocidad y los botones 1 y 3 para dos luces. Con una gráfica de dispersión en Excel se saca la ecuación lineal de cada eje: la dirección queda de -90 a 90 grados y la velocidad de 0 a 100 %. Las ecuaciones se ponen en nodos de fórmula. En la parte 2 esto se convierte en una trama serial.

Fase 1

Leer el control

1.1

La idea

▶ 0:00

Con un control USB en el computador se manejará un buque: velocidad, timón y luces. Primero se lee el control en LabVIEW.

1.2

Buscar el control

▶ 0:33

En Connectivity, Input Device Control, Query Input Devices muestra los controles conectados, sus botones y ejes. Si hay varios, cada uno tiene un índice.

1.3

Inicializar y leer

▶ 1:39

Initialize Joystick con el índice (0) va antes del while. Dentro, Acquire Input Data lee los datos. Al salir se cierra el dispositivo y se limpian los errores.

1.4

Ver los datos

▶ 3:59

Con indicadores se ve que los ejes van de -32768 a 32767, los botones son verdadero o falso y la cruceta da 0, 90, 180 o 270.

Fase 2

Elegir los mandos

2.1

Desempacar por nombre

▶ 5:39

Con Unbundle By Name se sacan solo los datos que interesan: el eje X de rotación (dirección), el eje Z (velocidad) y los botones 1 y 3.

2.2

Luces

▶ 8:26

Dos LEDs, ROJO y VERDE, con el color de apagado oscuro, se conectan a los botones.

2.3

Indicadores

▶ 10:18

Un medidor de 0 a 100 % para la velocidad y una perilla de -90 a 90 para la dirección del timón.

Fase 3

Escalar los ejes

3.1

Ecuación de la dirección

▶ 12:03

En Excel se ponen los extremos (-32768 → -90 y 32767 → 90), se hace una gráfica de dispersión y se agrega la línea de tendencia con su ecuación.

3.2

Nodo de fórmula

▶ 13:11

La ecuación se pone en un Formula Node con la entrada x y la salida a la perilla. Según el sistema, el decimal es punto o coma, y la multiplicación lleva *.

3.3

Velocidad

▶ 14:55

El eje Z va de 0 a 32640; se escala a 0 a 100 % con otra ecuación igual.

3.4

Prueba

▶ 16:41

Al mover el control cambian la velocidad, el timón y las luces. En la práctica conviene una zona muerta en el centro.
