STM32 desde MATLAB: instalación

Primera parte de la serie para programar los STM32 desde MATLAB y Simulink, desde prender un LED hasta algoritmos de lógica difusa. Aquí solo se deja todo instalado: el paquete de soporte de hardware, las versiones antiguas de STM32CubeMX (6.4.0) y STM32CubeProgrammer (2.6.0) que exige el paquete, la validación de ambas rutas y el firmware STM32Cube. En la parte 2 se hace el primer programa.

▶ Ver el video completo (6:10) Empezar el paso a paso

  • STM32CubeMX 6.4.0
  • STM32CubeProgrammer 2.6.0
  • Archivo STM32F4-Discovery_FW_V1.1.0 (lo pide el instalador al final)

Fase 1

Instalar el paquete

1.1

Buscar el soporte STM32

▶ 0:32

En MATLAB: Home, Add-Ons, Get Hardware Support Packages. Se escribe STM32 y aparecen dos paquetes:

  • Embedded Coder Support Package for STMicroelectronics STM32 Processors: para los micros (Black Pill, Blue Pill...). Es el que se usa en esta serie.
  • Simulink Coder Support Package for STMicroelectronics Nucleo Boards: solo para tarjetas Nucleo.
1.2

Elegir la familia de micros

▶ 1:05

Después de instalarlo aparece la opción de configurarlo (Hardware Setup). En Select STM32 MCUs Family se puede marcar todo o solo la familia F4 si solo se va a trabajar con F401 o F411.

1.3

Versiones que pide

▶ 1:38

La ventana STM32 Tools Information indica las versiones exactas: STM32CubeMX 6.4.0 y STM32CubeProgrammer 2.6.0. Aunque tengas versiones más nuevas instaladas, el paquete trabaja con estas.

Fase 2

Versiones antiguas aparte

2.1

Crear las carpetas

▶ 2:10

Para no tocar tus versiones nuevas, en C:\Program Files\STMicroelectronics crea una carpeta STM32CubeOLD y dentro STM32CubeMX y STM32CubeProgrammer. Al instalar cada programa antiguo, elige su carpeta como destino.

  • Crea un icono en el escritorio para CubeMX 6.4.0, así sabes cuál es la versión vieja.
  • El CubeProgrammer viejo no hace falta abrirlo: MATLAB lo usa solo al programar.
Fase 3

Validar y terminar

3.1

Validar STM32CubeMX

▶ 3:15

En Validate STM32CubeMX se busca la carpeta donde quedó instalado y se presiona Validate. Si eliges una versión más nueva, avisa que puede haber incompatibilidades y que es bajo tu propio riesgo. Con la carpeta de la versión 6.4.0 aparece: The STM32CubeMX folder provided is valid.

Si te sale el aviso de versión más avanzada, es que apuntaste a la carpeta de tu CubeMX nuevo. Regresa y elige la de STM32CubeOLD.

3.2

Validar STM32CubeProgrammer

▶ 4:23

Igual con el programador: se selecciona la carpeta STM32CubeProgrammer dentro de STM32CubeOLD (la que contiene bin con STM32_Programmer_CLI) y se valida.

3.3

Firmware STM32Cube

▶ 4:57

Luego pide instalar el firmware de las familias (STM32F4xx, F7xx, G4xx...). Se deja el repositorio que propone y se presiona Install; tarda bastante si se marcan todas.

Al final pide el archivo STM32F4-Discovery_FW_V1.1.0: se copia en la carpeta STM32CubeOLD y se continúa con Next.
