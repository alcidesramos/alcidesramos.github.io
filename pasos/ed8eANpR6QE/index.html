PWM y PWM complementario con librerías por estructuras, parte 2

Rehacemos el proyecto con un STM32F401 a 84 MHz y librerías más ordenadas. Primero vemos que el TIM1 cuelga del bus APB2 y que la frecuencia de ese bus es la que cuenta para los cálculos. Con la hoja de Excel actualizada configuramos el TIM2 a 25 kHz y el TIM1 complementario a 100 kHz y 45 %. Cada PWM se declara con una estructura (timer, registro CCR y canal), y las funciones init, stop, valor y valor con escala reciben solo esa variable. Al final calculamos el tiempo muerto según los rangos del registro DTG del manual de referencia y lo medimos con el analizador lógico.

Fase 1

Reloj y bus del timer

1.1

Cristal y 84 MHz

▶ 1:05

Proyecto nuevo PWMFINAL para el STM32F401. Activamos el HSE y llevamos el sistema a 84 MHz.

1.2

¿En qué bus está el timer?

▶ 1:37

En el manual de referencia se ve que el TIM1 está en APB2 y los TIM2 a TIM5 en APB1.

La frecuencia que se usa en los cálculos es la de APB timer clocks del bus del timer, no la del cristal. Aquí coincide en 84 MHz, pero en otros micros los timers pueden ir divididos.

Fase 2

PWM básico con estructuras

2.1

TIM2 a 25 kHz

▶ 2:42

TIM2 Channel1: PWM Generation CH1 (PA0). Con la hoja de Excel a 84 MHz: Prescaler 1-1, Counter Period 3360, auto-reload preload habilitado y Pulse 1680 (50 %, 20 µs).

Pulsa el engranaje (Device Configuration Tool) después de cada cambio en el .ioc y luego compila.

2.2

Agregar PWMB

▶ 4:23

Copiamos PWMB.c/.h (PWM básico) en la carpeta Librerias, la añadimos a las rutas de include y en el main ponemos #include "PWMB.h". En el .h ya no hay que configurar nada.

2.3

Declarar cada PWM en una línea

▶ 5:29

En PWMB.c se define la escala (1000 para tener décimas de porcentaje), se declaran los timers usados y cada PWM con la estructura PWMS: timer, registro CCR y canal.

float escala = 1000;   // define la escala a trabajar el pwm

//incluir los timer usados
extern TIM_HandleTypeDef htim2;

//configurar cada salida pwm usada
PWMS PWM1 = {&htim2, &(TIM2->CCR1), TIM_CHANNEL_1};
//PWMS PWM2 = {&htim2, &(TIM2->CCR3), TIM_CHANNEL_3};

El registro CCR y el canal deben corresponder: canal 1 con CCR1, canal 3 con CCR3.

2.4

Inicializar y cambiar el valor

▶ 7:41

Con PWM_init(&PWM1) arranca a 25 kHz y 50 %. PWM_valor cambia el ciclo útil en la escala de 0 a 1000: el 10 % es 100 y el 90 % es 900.

PWM_init(&PWM1);

while (1)
{
  PWM_valor(&PWM1, 100);   // 10 %
  HAL_Delay(100);
  PWM_valor(&PWM1, 900);   // 90 %
  HAL_Delay(100);
}
2.5

Macros, stop y valor con escala

▶ 9:54

Se pueden crear macros para encender y apagar. PWM_stop existe, pero es mejor apagar con valor 0, sobre todo en el complementario.

PWM_valor_escala recibe además la escala en la llamada; no puede superar el periodo (3360).

#define pwmledon()  PWM_valor(&PWM1, 800)
#define pwmledoff() PWM_valor(&PWM1, 0)

PWM_valor_escala(&PWM1, 1500, 3000);   // 1500 de 3000 = 50 %

PWM_init y PWM_stop recargan mucha configuración de la HAL y son más lentos que escribir el valor.

Fase 3

PWM complementario

3.1

TIM1 CH1 y CH1N

▶ 13:38

TIM1 con Internal Clock y Channel1: PWM Generation CH1 CH1N. Para 100 kHz y 45 %: Prescaler 1-1, Counter Period 840 y Pulse 378 (4.5 µs).

En el video al principio quedó 368 y el ciclo útil daba 43 %; con 378 da el 45 % exacto.

3.2

Librería PWMC

▶ 14:53

En PWMC.c se pone su escala (por ejemplo 800, el 50 % es 400), el timer y cada PWM complementario con la estructura PWMSC. La init arranca el canal y el negado juntos.

#include "PWMC.h"

// PWMC.c
extern TIM_HandleTypeDef htim1;
PWMSC PWMC1 = {&htim1, &(TIM1->CCR1), TIM_CHANNEL_1};

void PWMC_init(PWMSC *pwm)
{
  // inicia el timer y el canal en modo complementario
  HAL_TIM_PWM_Start(pwm->htim, pwm->channel);
  HAL_TIMEx_PWMN_Start(pwm->htim, pwm->channel);
}

// main
PWM_init(&PWM1);
PWMC_init(&PWMC1);

PWM1 (normal) y PWMC1 (complementario) son variables distintas, de librerías independientes.

Fase 4

Tiempo muerto

4.1

Rangos del registro DTG

▶ 17:41

El registro de tiempo muerto es de 8 bits y tiene cuatro rangos según sus bits altos (manual RM0368):

DTG[7:5]=0xx: DT = DTG[7:0] × tdtg (valores 0 a 127)

10x: DT = (64 + DTG[5:0]) × 2 tdtg

110: DT = (32 + DTG[4:0]) × 8 tdtg

111: DT = (32 + DTG[4:0]) × 16 tdtg

A 84 MHz el primer rango cubre de 0 a 1.5 µs, suficiente aquí. Para 0.5 µs (5 %) el valor es 42.

Con frecuencias más lentas o tiempos muertos grandes hay que usar los otros rangos; la hoja de Excel los calcula.

4.2

Medir y cambiar el ciclo útil

▶ 19:55

Con Dead Time 42 el analizador mide 0.5 µs de tiempo muerto.

PWMC_valor cambia el ciclo útil en la escala del complementario: con 200 de 800 una salida queda cerca del 20 % y la otra cerca del 70 %, separadas por el tiempo muerto.

PWMC_valor(&PWMC1, 200);

Para apagar el complementario usa valor 0 o el máximo, no Stop. Si una medida no cuadra, revisa que los canales del analizador no estén cruzados (pasó en el video).
