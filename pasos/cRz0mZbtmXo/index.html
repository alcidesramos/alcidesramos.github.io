Multiplexar displays de 7 segmentos con interrupciones

Video a pedido de un seguidor, pensado para mostrar números como en un turnero. Con un PIC18F2550, cuatro displays de cátodo común en el puerto B y transistores 2N3904 como habilitadores, el Timer1 genera una interrupción cada 5 ms. En cada interrupción se apaga todo, se saca el código del dígito que toca y se prende su display. Para separar el número en dígitos se usa un truco: sprintf con %04d y restar 48 a cada carácter. Como la multiplexación va en la interrupción, el while puede tener retardos o leer sensores sin que el display parpadee.

Fase 1

Circuito y datos

1.1

El circuito

▶ 0:00

Los segmentos van al puerto B con resistencias. Cada display se habilita con un transistor 2N3904: tres en RC0, RC1 y RC2 y el cuarto en el puerto A, porque RC3 en este micro no sirve como salida. Hay un LED en RA1.

1.2

Variables y códigos

▶ 2:08

Se nombran el puerto del display y los habilitadores, y se guardan en un vector los códigos de 7 segmentos del 0 al 9 para cátodo común. MikroC los da en Tools > Seven Segment Editor.

unsigned int conteo = 0;
#define display LATB   // puerto del display

// pines de habilitador
sbit EN1 at LATC0_bit;
sbit EN2 at LATC1_bit;
sbit EN3 at LATC2_bit;
sbit EN4 at LATA2_bit;
sbit LED at LATA1_bit;

// códigos de los números, cátodo común
char codigo_siete[] = {63, 6, 91, 79, 102, 109, 125, 7, 127, 111};
char multiplexa = 1;
char digito1, digito2, digito3, digito4;
char texto[20];

void apaga_siete() {
  EN1 = 0;  EN2 = 0;  EN3 = 0;  EN4 = 0;
}
Fase 2

Timer1 cada 5 ms

2.1

Calcular el timer

▶ 4:40

Con un cristal de 10 MHz cada ciclo de instrucción dura 0.4 µs. Con preescalador de 2, para 5 ms hacen falta 6250 pasos, así que el Timer1 se carga con 65536 - 6250 = 59286: TMR1H = 231 y TMR1L = 150.

2.2

Configurar la interrupción

▶ 5:24

Se habilitan las interrupciones de periféricos, se configura el Timer1 y se activa su interrupción. Al final, GIE autoriza que las interrupciones ocurran.

ADCON1 = 0b1111;        // todo digital
TRISA = 0;  TRISB = 0;  TRISC = 0;
INTCON = 0b01000000;    // habilita interrupción de periféricos
UART1_Init(9600);
// configuración timer 1 a 5 ms
T1CON = 0;
T1CKPS1_bit = 0;        // preescalador de 2
T1CKPS0_bit = 1;
TMR1H = 231;
TMR1L = 150;
TMR1IF_bit = 0;
TMR1IE_bit = 1;         // habilita la interrupción del timer1
TMR1ON_bit = 1;         // prende el timer
GIE_bit = 1;            // autoriza las interrupciones
Fase 3

La multiplexación

3.1

La rutina de interrupción

▶ 7:35

Si la interrupción es del Timer1, se recarga el timer, se apagan los displays y, según la variable multiplexa, se saca el código de un dígito y se prende su display. Luego multiplexa se desplaza para que la próxima vez toque el siguiente y vuelve a 1 después del último.

void Interrupcion() iv 0x0008 ics ICS_AUTO
{
  if (TMR1IF_bit == 1) {
    TMR1H = 231;   // recarga para mantener los 5 ms
    TMR1L = 150;
    apaga_siete();
    switch (multiplexa) {
      case 0b0001: display = codigo_siete[digito1]; EN1 = 1; break;
      case 0b0010: display = codigo_siete[digito2]; EN2 = 1; break;
      case 0b0100: display = codigo_siete[digito3]; EN3 = 1; break;
      case 0b1000: display = codigo_siete[digito4]; EN4 = 1; break;
    }
    multiplexa = multiplexa << 1;
    if (multiplexa == 0b10000) multiplexa = 1;   // vuelve al primero
    TMR1IF_bit = 0;
  }
}

Si tiene menos displays, quite los case que sobran y cambie el valor con el que multiplexa vuelve a 1.

3.2

Separar los dígitos

▶ 10:52

El truco: sprintf con %04d rellena con ceros a la izquierda (125 queda "0125"). Cada carácter menos 48 (el código ASCII del '0') da el número. El dígito de las unidades está en la posición 3 del texto.

void mostrar() {
  sprintf(texto, "%04d\r\n", conteo);
  digito1 = texto[3] - 48;   // pasa a número
  digito2 = texto[2] - 48;
  digito3 = texto[1] - 48;
  digito4 = texto[0] - 48;
}
3.3

El programa principal

▶ 15:15

En el while basta llamar a mostrar() cuando cambia el valor. Aquí un contador sube cada 150 ms hasta 9999. El retardo no afecta la multiplexación, que corre sola en la interrupción, así que el programa puede leer sensores o enviar por serial.

while (1) {
  if (conteo > 9999) conteo = 0;
  mostrar();
  conteo++;
  Delay_ms(150);
}
