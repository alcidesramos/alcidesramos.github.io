Dimmer AC: control de energía con cruce por cero

Se explican dos tarjetas de potencia (con 4N25 más puente rectificador o con H11AA1) que se conectan a cualquier micro por 4 pines: VCC, GND, CRUCE y DISPARO. A 60 Hz cada semiciclo dura 8.33 ms; al detectar el cruce por cero se espera un tiempo y se dispara el TRIAC con un MOC3021: cuanto antes se dispara, más energía recibe la carga. En el STM32 el pin de cruce genera una interrupción EXTI; ahí se carga el tiempo en el ARR de un timer en microsegundos y, cuando el timer desborda, se da un pulso de 10 µs al TRIAC. Un potenciómetro (ADC) se mapea entre los límites LIM_SUP y LIM_INF. Luego se lleva el código a una F411 con HSE y PLL a 100 MHz y finalmente a un STM32G031 de bajo costo, resolviendo la falta de la librería de retardos interna y de printf con float.

Fase 1

Teoría y hardware

1.1

La idea del control

▶ 2:11

La tarjeta entrega un pulso cada vez que la señal AC pasa por cero. A 60 Hz el período es 16.66 ms y, rectificado, cada semiciclo dura 8.33 ms. Tras el pulso se espera un tiempo y se dispara el TRIAC: disparar a 1 ms entrega casi toda la energía, a 7 ms muy poca. La energía es inversamente proporcional al tiempo de espera.

1.2

Detector de cruce con 4N25

▶ 3:50

La red se rectifica para encender el LED del optoacoplador; mientras hay tensión el transistor conduce y el pin de CRUCE está en 0; cerca del cero el LED se apaga y una pull-up de 10k pone el pin en 1. El LED se apaga por debajo de ~1 V, así que el pulso dura unos cientos de microsegundos. Sirven 4N25, 4N26, 4N35 o similares; la versión con H11AA1 no necesita puente rectificador.

1.3

Resistencia de entrada

▶ 5:31

Para unos 11 mA con 110 V se necesita ≈10k, pero disiparía P = V²/R = 110²/10k ≈ 1.2 W. Por eso se usan tres resistencias de 33k (o 39k) de 1/2 W en serie: ≈11k (o 13k) y 1.5 W repartidos. En 220 V se recalcula.

R = V / I = 110 V / 11 mA ≈ 10 kΩ
P = V² / R = 110² / 10k ≈ 1.2 W
3 × 33k (1/2 W) en serie = 11 kΩ, 1.5 W
1.4

Etapa de disparo

▶ 7:44

El micro enciende el LED de un MOC3020/3021/3030 con 220 Ω; el MOC dispara el TRIAC a través de su resistencia de gate. No use un MOC3041 porque tiene detector de cruce interno. Para cargas inductivas (ventiladores, motores universales) es obligatoria la red snubber de 390 Ω 1 W con 10 nF de poliéster; con cargas resistivas puede omitirse junto con la red RC que recomienda el fabricante. El TRIAC se elige según la corriente de la carga.

Fase 2

Proyecto simulado (F401)

2.1

Pines y periféricos

▶ 13:05

En Proteus el micro va a 16 MHz. Se configura USART1 para monitorear, PB12 como salida DISP, PB13 como GPIO_EXTI13 con etiqueta C_CERO (flanco de subida, sin pull) y un canal ADC para el potenciómetro. En NVIC se habilita la EXTI de PB13.

2.2

Timer en microsegundos

▶ 16:00

TIM5 con reloj interno, Prescaler 16-1 (1 µs por cuenta) y Counter Period 10000 (el semiciclo no pasa de 8.33 ms; el ARR se cambia en cada disparo). Se habilita su interrupción. En el proyecto se activa float por software (por Proteus) y la salida .hex.

Prescaler (PSC)      = 16-1     // MHz del reloj - 1
Counter Period (ARR) = 10000
2.3

Librerías

▶ 17:56

En Core/Librerias se copian adc, CRUCE_CERO, delays, MAP, pinout y uart. En CRUCE_CERO.h se indica el timer y los límites de disparo:

#define TIM_CERO   htim5   // timer usado
#define TIM_CERO_V TIM5

// limites en microsegundos minimo y maximo para disparo
#define LIM_INF  300    // resistiva (inductiva: 1500)
#define LIM_SUP  8000
#define LIM_BASE 100    // offset de encendido y apagado
2.4

Interrupción de cruce

▶ 19:43

Si el valor está cerca del mínimo se deja el TRIAC encendido (máxima energía), si está cerca del máximo se apaga; en otro caso se carga el tiempo en el ARR y se arranca el timer:

uint16_t cero_valor = LIM_SUP;

void flanco_cero_int()
{
    if (__HAL_GPIO_EXTI_GET_IT(C_CERO_Pin) != RESET)
    {
        // si es menor que el limite inferior enciende
        if (cero_valor <= LIM_INF + LIM_BASE) PIN_ON(DISP);
        // si es superior al superior apaga
        else if (cero_valor >= LIM_SUP - LIM_BASE) PIN_OFF(DISP);
        // sino activa el timer
        else
        {
            TIM_CERO_V->ARR = cero_valor;                    // carga valor de disparo
            __HAL_TIM_CLEAR_FLAG(&TIM_CERO, TIM_FLAG_UPDATE);  // limpia bandera
            HAL_TIM_Base_Start_IT(&TIM_CERO);                 // empieza el timer
        }
    }
}
2.5

Interrupción del timer: disparo

▶ 21:56

Al desbordar, se detiene el timer y se da un pulso de 10 µs al TRIAC (basta para que quede conduciendo hasta el siguiente cruce):

void timer_cero_int()
{
    HAL_TIM_Base_Stop_IT(&TIM_CERO);  // para el timer
    PIN_ON(DISP);                     // enciende el triac
    delay_us(10);                     // retardo de disparo
    PIN_OFF(DISP);                    // apaga el triac
}
2.6

Main con potenciómetro

▶ 23:03

Se lee el ADC (0–4095), se mapea entre LIM_SUP y LIM_INF y se entrega al cruce por cero. En stm32f4xx_it.c se incluye CRUCE_CERO.h, se llama flanco_cero_int() en la EXTI y timer_cero_int() en la interrupción de TIM5:

cruce_init();

while (1)
{
    codigo = ADC_Read();
    tiempo = map(codigo, 0, 4095, LIM_SUP, LIM_INF);
    sprintf(texto, "VALOR=%u\r\n", codigo);
    uartx_write_text(&huart1, texto);
    sprintf(texto, "float=%.1f\r\n\r\n", tiempo);
    uartx_write_text(&huart1, texto);
    Cruce_set(&tiempo);
    HAL_Delay(500);
}

/* stm32f4xx_it.c */
void EXTI15_10_IRQHandler(void) { flanco_cero_int(); HAL_GPIO_EXTI_IRQHandler(C_CERO_Pin); }
void TIM5_IRQHandler(void)      { timer_cero_int();  HAL_TIM_IRQHandler(&htim5); }
Fase 3

Tarjeta física F411

3.1

Cambios para la F411

▶ 30:02

Se activa el HSE y se lleva el PLL a 100 MHz (84 MHz en una F401). El único cambio en el timer es el prescaler: 100-1.

3.2

Ver el cruce con el analizador

▶ 32:17

El pulso de cruce dura unos 229 µs, por eso el límite inferior no puede ser 200 µs: se usa 250–300 µs para cargas resistivas, o ~1.5 ms para inductivas (la corriente se desfasa y el bombillo o motor oscilaría). Al mover el potenciómetro el pulso de disparo se desplaza dentro de los 8.33 ms.

Fase 4

Tarjeta económica STM32G031

4.1

Proyecto para el G031

▶ 34:29

Micro STM32G031F6P6. USART1 a 9600, PA3 como DISP, PA2 como C_CERO (EXTI), un canal ADC y TIM1 con Prescaler 64-1 y su interrupción de update. Reloj HSI a 64 MHz (la tarjeta no tiene cristal, así se aprovechan más pines).

4.2

Librerías y ajustes

▶ 38:54

Se copian las mismas librerías más floattostr, porque en este micro con poca memoria no conviene printf con float. La librería de retardos interna (DWT) no existe para la serie G0, así que se configura TIM3 (Prescaler 64-1, auto-reload) como base de microsegundos en delays.h. El tiempo se imprime con floattostr:

floattostr(texto, tiempo, 2);   // 2 decimales
uartx_write_text(&huart1, "TIEMPO=");
uartx_write_text(&huart1, texto);
uartx_write_text(&huart1, "\r\n\r\n");

Si el TRIAC parpadea en vez de apagarse a mínima energía, revise que en cada cruce el pin de disparo se apague antes de decidir si se vuelve a disparar.

4.3

Resultado

▶ 55:05

La tarjeta de bajo costo controla la intensidad del bombillo igual que la BlackPill: el pulso de disparo se mueve en el tiempo según el potenciómetro, ocupando alrededor del 76 % de la memoria del G031.
