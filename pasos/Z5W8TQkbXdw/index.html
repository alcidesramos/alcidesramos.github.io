Imágenes y figuras en OLED

Se actualiza la librería OLED SSD1306: ahora el texto se puede imprimir normal o invertido y hay funciones para dibujar mapas de bits, rectángulos y círculos. Se convierte una imagen a 128x64 con un conversor web, se ajusta una imagen pequeña de 64x64 con IrfanView, se pega el arreglo en imagenes.h y se dibuja con OLED_DrawBitmap, controlando si se borra o no el buffer para combinar varios dibujos.

▶ Ver el video completo (12:32) Empezar el paso a paso
  • STM32F103C8T6 (Blue Pill) o simulación en Proteus
  • Pantalla OLED SSD1306 128x64 I2C
  • STM32CubeIDE con la librería SSD1306 actualizada (imagenes.h, fonts.h)
  • Conversor de imágenes a mapa de bits 128x64 (web) y editor OLED Bitmap de ArduinoBlocks
  • IrfanView (gratuito) para reducir y pasar a blanco y negro

Fase 1

Librería actualizada

1.1

Texto normal o invertido

▶ 0:04

La librería de la clase anterior sigue funcionando; ahora existe OLED_print_text_inv para que el texto salga invertido (fondo blanco, letras negras) y OLED_print_text para el texto normal.

OLED_print_text_inv(0,0,"SUSCRIBETE",&font1);
OLED_print_text(0,2,"    AL",&font1);
OLED_print_text(0,4,"CANAL",&font4);
1.2

Parámetros de OLED_DrawBitmap

▶ 0:36

La función recibe la posición inicial, el tamaño del dibujo, el nombre del arreglo, si va normal (NOR) o invertido (INV) y si borra el buffer (SI) o no (NO) antes de dibujar. Borrar el buffer limpia toda la pantalla; no borrarlo permite poner varios dibujos a la vez.

// x, y, ancho, alto, imagen, NOR/INV, borrar buffer SI/NO
OLED_DrawBitmap(0, 0, 128, 64, DOBBY, INV, SI);
Fase 2

Imagen de pantalla completa

2.1

Convertir la imagen a 128x64

▶ 1:10

En la carpeta resource del proyecto están el enlace del conversor y el editor de mapas de bits. En el conversor web carga la imagen (no tiene que ser blanco y negro, pero si lo es pierde menos píxeles), ajústala a toda la pantalla y descarga la imagen final.

2.2

Generar los datos

▶ 1:50

En el editor OLED - Bitmap Data de ArduinoBlocks deja el tamaño en 128x64, carga la imagen descargada y pulsa Copy data. No hace falta invertirla aquí: la librería lo hace.

2.3

Crear el arreglo en imagenes.h

▶ 2:15

En Core/Librerias/imagenes.h declara un arreglo constante, abre llaves y pega los datos. Si el editor no cierra la llave, ciérrala y pon punto y coma. Borra los dos primeros valores (el tamaño 128,64) porque el tamaño se pasa en la función.

const unsigned char miperro[]=
{
    0x0,0x0,0x0,0x0, /* ...datos copiados... */
};
2.4

Dibujar la imagen

▶ 2:48

En main.c llama a la función con el nombre del arreglo. Con NOR sale fondo negro y puntos blancos; NOR o nor funcionan igual, mayúsculas o minúsculas.

OLED_DrawBitmap(0, 0, 128, 64, miperro, NOR, SI);
Fase 3

Imagen pequeña de 64x64

3.1

Reducir con IrfanView

▶ 3:53

Para una imagen que ocupe solo una parte de la pantalla, el conversor web no sirve (pierde mucha resolución). En IrfanView abre la imagen, usa Decrease Color Depth a 2 colores (blanco y negro) y luego Resize con el tamaño deseado, por ejemplo 64 x 64. Guárdala como JPG.

Desactiva Preserve aspect ratio: si queda activo, al poner el ancho se calcula el alto solo y puede salirse de las dimensiones de la pantalla.

3.2

Generar datos de 64x64

▶ 5:20

Recarga el editor de ArduinoBlocks (a veces no carga sin recargar), ajusta el tamaño a 64x64 con las flechas del teclado, carga la imagen y copia los datos.

3.3

Crear el arreglo y dibujarlo

▶ 6:00

Crea el nuevo arreglo en imagenes.h igual que antes (borra los valores 64,64 del inicio) y dibújalo con tamaño 64 x 64. Revisa que el nombre en main.c sea exactamente el del arreglo: en el video el error era escribir perillo en vez de perrillo.

const unsigned char perrillo[]=
{
    0x0,0x0,0x0, /* ...datos... */
};

OLED_DrawBitmap(0, 0, 64, 64, perrillo, NOR, SI);
Fase 4

Varios dibujos y figuras

4.1

Dos imágenes a la vez

▶ 7:51

Para poner otra imagen en la mitad derecha (x = 64), solo la primera llamada borra el buffer; las siguientes deben llevar NO, o cada dibujo borrará el anterior.

OLED_DrawBitmap(0, 0, 64, 64, perrillo, NOR, SI);
OLED_DrawBitmap(64, 0, 64, 64, perrillo, NOR, NO);
4.2

Rectángulos y círculos

▶ 8:24

La librería trae funciones para rectángulos (esquinas SQUARE o ROUND), círculos y triángulos, rellenos (FILL) o sin rellenar (NOFILL), normales o invertidos. Los dibujos se hacen sobre lo que ya hay, así que limpia la pantalla antes si quieres empezar en blanco.

Si ya tienes imágenes en pantalla, no la limpies: dibuja las figuras encima. En el video quedan los dos perritos con un rectángulo redondeado relleno sobre ellos. Esta librería reemplaza la del video 99; la del video 100 (fuentes) sigue igual pero ahora admite texto invertido.

OLED_clear_screen();
OLED_Draw_Rectangle(50, 40, 60, 60, NOFILL, NOR, ROUND);
OLED_Draw_Circle(64, 20, 5, NOFILL, NOR);

Si la pantalla va invertida, en lugar de limpiarla hay que ponerla toda encendida primero y luego dibujar en modo invertido.
