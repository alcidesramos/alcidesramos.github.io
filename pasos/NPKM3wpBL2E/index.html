Varios SRF04 con XC8

El programa que se hizo en MikroC para leer varios sensores ultrasónicos se pasa a MPLAB XC8 con un PIC12F1822. Con el MCC se configuran el oscilador interno a 32 MHz con PLL, la EUSART a 9600 y los pines: uno de disparo común (RA5) y cuatro de eco. La función lee_distancia recibe el puerto y el pin: envía un pulso de 10 µs, limpia y arranca el Timer1 con prescalador 4, espera el flanco del eco con una función LEEBIT y devuelve -1 si el timer se desborda porque no hay sensor; si no, calcula la distancia con la frecuencia real. Como el micro solo tiene 2K de programa, printf y sprintf llenan la memoria, así que se usa una función propia para pasar de flotante a cadena y otra para enviar por serial, y el programa cabe.

2.3

Medir la distancia

▶ 18:43

Pulso de disparo de 10 µs, se limpia y arranca el Timer1 y se espera el eco. Si el timer se desborda, no hay sensor y devuelve -1.

float lee_distancia(char puerto, char pin)   // lee en el pin especificado
{
  float calculo;

  // pulso de disparo de 10us
  disparo1 = 1;
  __delay_us(10);
  disparo_SetLow();

  // limpia el contador
  TMR1ON = 0;   // timer quieto
  TMR1L = 0;    // limpia parte baja
  TMR1H = 0;    // limpia parte alta
  TMR1IF = 0;   // limpia la bandera de desbordamiento
  TMR1ON = 1;   // arranca el timer

  while (LEEBIT(puerto, pin) == 0)
  {
    if (TMR1IF == 1)    // si no hay objeto se va a desbordar el timer
    {
      return (-1);      // si no hay sensor conectado retorna -1
    }
  }
  // ... luego se mide el tiempo del eco y se calcula la distancia
}
2.4

Timer1 y ciclo

▶ 21:47

Timer1 con prescalador 4. En el ciclo se lee cada sensor, se pasa a texto con 2 decimales y se envía.

disparo1 = 0;   // inicia en cero el pin de disparo
T1CON = 0;      // limpia registro del timer 1
// prescalador en 4
T1CKPS1 = 1;
T1CKPS0 = 0;

while (1)
{
  distancia = lee_distancia(&PORTA, eco1);
  floattostr_(distancia, texto, 2);   // 2 decimales
  UART1_Write_Text("Dis1=");
  UART1_Write_Text(texto);
  UART1_Write('\r');                  // enter y final de línea
  __delay_ms(50);
  // ... igual para eco2, eco3 y eco4
}
