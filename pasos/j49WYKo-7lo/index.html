ESP32 en Proteus con MicroPython e IA

Se crea el proyecto en Proteus con firmware MicroPython y la ESP32-S3. Se pone un LED con resistencia de 220 Ω en GP2. En vez de escribir el código, se le pide a la IA un programa en MicroPython para titilar un LED cada 500 ms en el pin 2, y se pega desde la línea 17 del archivo que genera Proteus. Después se agrega un servo en GP4 y se le pide a la IA que lo mueva de −90 a 90 grados cada vez que el LED cambia. La idea es ver cómo se simula en Proteus y cómo la IA ayuda a quien todavía no sabe programar.

Fase 2

LED con código de la IA

2.1

Pedir el código

▶ 3:02

Se le pide a la IA: «dame un código en MicroPython para titilar un LED cada 500 milisegundos en un ESP32. El LED está en el pin 2».

from machine import Pin
import time

# Configura el pin 2 como salida (este es el LED integrado en la mayoría de ESP32)
led = Pin(2, Pin.OUT)

# Bucle infinito para hacer parpadear el LED
while True:
    led.value(not led.value())  # Invierte el estado actual del LED (1 a 0, o 0 a 1)
    time.sleep_ms(500)          # Pausa la ejecución por 500 milisegundos
