Arduino en VS Code

Visual Studio Code es gratuito y, con la extensión Arduino de Microsoft, da autocompletado y ayudas que el IDE de Arduino no tiene. Se abre una carpeta para el proyecto, con F1 se ejecuta Arduino: Initialize para crear el sketch, y se escogen la tarjeta y el puerto. Se escribe el clásico parpadeo del LED 13 viendo cómo el editor sugiere funciones y variables, se verifica y se carga a la tarjeta física. Para Proteus se agrega en arduino.json una carpeta de salida, así al verificar queda el .hex que se carga al Arduino Uno simulado.

Fase 1

Preparar VS Code

1.1

Instalar la extensión

▶ 0:34

Se descarga Visual Studio Code, se va a Extensiones, se busca «arduino» y se instala la primera, la de Microsoft. No hace falta tener la tarjeta conectada para empezar.

1.2

Carpeta y sketch

▶ 1:09

Se crea una carpeta para el proyecto y se abre con File > Open Folder. Luego, con F1 se escribe «arduino» y se escoge Arduino: Initialize; pide el nombre del sketch (led.ino) y crea el archivo con setup y loop.

1.3

Tarjeta y puerto

▶ 2:53

En la barra de abajo se escoge la tarjeta (Arduino Uno) y el puerto donde está conectada. Esa configuración queda guardada en la carpeta .vscode.

Fase 2

Programar y cargar

2.1

Autocompletado

▶ 3:30

Al escribir, el editor muestra los parámetros de cada función (por ejemplo pinMode(pin, mode)) y sugiere funciones como digitalWrite o delay. También reconoce las variables que uno declara.

2.2

El programa

▶ 5:00

Se escribe el parpadeo del LED 13 cada segundo. La variable yuca está solo para ver que el autocompletado la reconoce.

char yuca;
void setup() {
  pinMode(13,OUTPUT);
}
void loop()
{
  digitalWrite(13,HIGH);
  delay(1000);
  digitalWrite(13,LOW);
  delay(1000);
  yuca=34;
}
2.3

Verificar y cargar

▶ 6:00

Con los botones de arriba a la derecha se verifica y se carga el programa. El LED de la tarjeta física empieza a parpadear.

Fase 3

Simular en Proteus

3.1

Circuito en Proteus

▶ 6:50

En Proteus se busca el Arduino Uno en la librería y se le pone un LED con su resistencia en el pin 13.

3.2

Sacar el .hex

▶ 7:40

En arduino.json, que tiene el sketch, la tarjeta y el puerto, se agrega una línea de salida para que el compilado quede en una carpeta del proyecto (por ejemplo bin). Al verificar de nuevo aparece esa carpeta con el .hex.

{
  "sketch": "led.ino",
  "board": "arduino:avr:uno",
  "port": "COM5"
  // ... + la carpeta de salida para el .hex
}
3.3

Cargar y simular

▶ 8:40

En las propiedades del Arduino de Proteus se escoge el .hex de esa carpeta y se simula: el LED parpadea igual que en la tarjeta física.
