Tarjetas clon y firmware del ST-Link

Se prueban tres Blue Pill (original, semi-clon y clon sin el nombre STM32) con STM32CubeIDE y Keil µVision usando un ST-Link V2 clon. Cuando el IDE no deja programar o depurar un clon, se usa STM32CubeProgrammer por ST-Link o por serial. También se muestra cómo actualizar el firmware del ST-Link.

Fase 1

Probar con una tarjeta original

1.1

Parpadeo de prueba

▶ 0:34

El programa de prueba solo hace parpadear el LED. Cambiando el retardo se nota si de verdad se grabó el programa nuevo.

while (1)
{
  HAL_GPIO_TogglePin(LED_GPIO_Port, LED_Pin);
  HAL_Delay(100);   // cambia el tiempo para comprobar que se programó
}
1.2

CubeIDE y Keil programan sin problema

▶ 1:07

Con una tarjeta original, los dos IDE graban y el LED cambia de velocidad. En Keil a veces hay que resetear la tarjeta después de bajar el programa.

Fase 3

Solución: STM32CubeProgrammer

3.1

Grabar el .hex o .bin con el programador

▶ 5:03

Abre STM32CubeProgrammer, conéctate por ST-Link, carga el archivo con Open file (el .hex o .bin que genera el compilador) y pulsa Download. El LED empieza a parpadear: el programa quedó grabado aunque el IDE no lo dejara.

3.2

Si ni el ST-Link lo reconoce: por serial

▶ 6:09

Algunos clones no se dejan conectar por ST-Link. Entonces se programa por UART con un cable USB-serial: TX/RX a PA10/PA9, BOOT0 en 1, y en CubeProgrammer se escoge UART. Con un clon se pierde la opción de depurar.

Fase 4

Actualizar el firmware del ST-Link

4.1

Desde STM32CubeProgrammer

▶ 7:54

Si la tarjeta es original y aun así hay errores, actualiza el programador: en CubeProgrammer, botón Firmware upgrade. Desconecta y vuelve a conectar el ST-Link, pulsa Open in update mode y luego Upgrade.

4.2

Con el programa ST-LinkUpgrade

▶ 8:27

ST también tiene un programa solo para eso, ST-LinkUpgrade, que se usa igual. Los enlaces a todos los programas están en la descripción del video.
