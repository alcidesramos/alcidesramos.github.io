USB HID con LabVIEW

HID es la clase de los teclados y ratones: no necesita driver. Con el HID Terminal de MikroC se generan los descriptores con el VID y PID. El micro lee dos canales análogos y dos pulsadores, arma una trama separada por barras y la envía con HID_Write. En LabVIEW una librería HID se conecta al dispositivo, lee la trama y Scan From String la convierte en números para indicadores.

  • MikroC PRO for PIC (librería USB y HID Terminal)
  • PIC18F2550 a 48 MHz con cristal de 8 MHz
  • Sensor LM35, potenciómetro y dos pulsadores

Fase 1

Preparar

1.1

Circuito y proyecto

▶ 0:00

PIC18F2550 con oscilador HS y PLL a 48 MHz, regulador de USB habilitado. RA0 lee el LM35 y RA1 un potenciómetro; dos pulsadores en el puerto B con pull-up.

1.2

Entradas

▶ 2:17

Dos canales análogos, puertos A y B como entradas y pull-up del puerto B habilitadas.

ADCON1 = 0b1101;   // dos canales analogos
TRISA = 255;
TRISB = 255;
RBPU_bit = 0;      // habilita pull up
1.3

Descriptor

▶ 3:27

Con Tools > HID Terminal se genera el archivo descriptor: VID y PID (cuatro dígitos hexadecimales), nombre del fabricante y del producto. Se agrega al proyecto.

Fase 2

Enviar por HID

2.1

Buffers y HID_Enable

▶ 4:32

Del ejemplo de la ayuda se copian los buffers de lectura y escritura y la interrupción. HID_Enable inicia el USB. En Proteus el USB Analyzer muestra la enumeración.

char readbuff[64] absolute 0x500;
char writebuff[64] absolute 0x540;

void interrupt() {
  USB_Interrupt_Proc();
}

HID_Enable(&readbuff, &writebuff);
2.2

Leer los sensores

▶ 17:02

Se usa ADC_Get_Sample, más rápido que ADC_Read, después de iniciar el ADC. Se calcula la temperatura y el voltaje.

2.3

Armar la trama

▶ 19:16

Se limpia el buffer, sprintf pone la temperatura con tres decimales y el voltaje con dos, y strcat agrega el estado de cada pulsador. Todo separado por barras: T/V/SW/SW1. Luego se envía.

codigo = ADC_Get_Sample(0);
temperatura = codigo * 500.0 / 1023.0;
Delay_us(10);
codigo = ADC_Get_Sample(1);
voltaje = codigo * 5.0 / 1023.0;
memset(&writebuff, 0, 64);
// T/V/SW/SW1
sprintf(&writebuff, "%.3f/%.2f/", temperatura, voltaje);
if (sw == 0) strcat(&writebuff, "1/"); else strcat(&writebuff, "0/");
if (sw1 == 0) strcat(&writebuff, "1/"); else strcat(&writebuff, "0/");
while (!HID_Write(&writebuff, 64));
Fase 3

LabVIEW

3.1

Librería HID

▶ 9:01

Se usa una librería HID para LabVIEW que se copia en user.lib (con LabVIEW como administrador). En la paleta aparecen Connect, Read, Write, Disconnect y otras.

3.2

Conectar

▶ 11:19

Se pone el VID y el PID en Connect; si el handle es distinto de cero el dispositivo está conectado y se prende un LED.

3.3

Leer y separar

▶ 13:33

Read trae el arreglo de bytes, Byte Array To String lo pasa a texto y Scan From String con el formato %f/%f/%u/%u/%s separa los valores. Ojo con el primer carácter en blanco y con el separador decimal: MikroC envía punto.

Adquisición
