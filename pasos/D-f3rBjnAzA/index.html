Velocidad de un balín en un acelerador magnético con STM32

Apoyo a un proyecto de física: un acelerador de balín con bobinas que se activan cuando unos sensores infrarrojos detectan el balín. Del circuito de cada sensor sale un pulso de unos 10 V que enciende un LED; tomado en el LED da unos 2,6 V que se pueden llevar directo al micro. El STM32F401 mide con un timer cuánto tarda el pulso y con eso calcula la velocidad. Se usan librerías solo para el serial y para leer el pin; el timer se maneja directo con sus registros.

Configurar el proyecto

2.1

Proyecto y reloj

▶ 1:06

Crea el proyecto con el STM32F401 (balin). En RCC activa el cristal externo y lleva el PLL a 84 MHz para procesar más rápido.

2.3

USART1

▶ 3:21

Activa USART1 en modo asíncrono a 115200 baudios para enviar los datos.

2.4

TIM2 contando microsegundos

▶ 3:35

Usa un timer de 32 bits (TIM2 o TIM5) con reloj interno: cuenta hasta 4 294 967 295. Con Prescaler 84-1 cada cuenta es 1 µs (8400-1 daría décimas de milisegundo).

2.5

El pin de entrada

▶ 4:10

Configura el pin del pulso (en el video PB7) como GPIO_Input con la etiqueta VELOCIDAD. Genera el código, compila y prueba que llegue un mensaje de inicio a Hércules.

Fase 3

Medir y calcular

3.1

Medir el pulso

▶ 6:20

Se esperan los cambios del pulso con ciclos while, se pone el contador en cero, se arranca el timer y al siguiente cambio se captura la cuenta, que queda en microsegundos.

while (1)
{
  uartx_write_text(&huart1, "ESPERANDO\r\n");
  while (PIN_READ(VELOCIDAD) == 1);
  while (PIN_READ(VELOCIDAD) == 0);
  TIM2->CNT = 0;
  HAL_TIM_Base_Start(&htim2);
  while (PIN_READ(VELOCIDAD) == 1);
  tiempo = TIM2->CNT;            // microsegundos
  ...
}
3.2

Calcular la velocidad

▶ 8:07

Se usa la circunferencia del recorrido, 2πr con r = 19 cm. El tiempo está en microsegundos (× 1 000 000) y el radio en centímetros (÷ 100), por eso se multiplica por 10 000. Para imprimir flotantes activa printf con float en las propiedades del proyecto (MCU Settings).

VELOCIDAD = (6.28 * 19 * 10000) / tiempo;
sprintf(TEXTO, "%1.f \r\n", VELOCIDAD);
uartx_write_text(&huart1, TEXTO);

Si al principio no aparece el valor, revisa que esté activado el uso de float en printf.

Probar

▶ 8:39

Con el acelerador funcionando, Hércules muestra ESPERANDO y la velocidad en cada pasada: el valor sube a medida que el balín se acelera.
