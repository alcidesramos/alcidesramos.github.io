El pin RA4 y la pull-up en PIC antiguos

Lección corta del curso. Se hace un juego de luces en todo el puerto A de un PIC16F877A y se ve que el LED de RA4 (que también es la entrada T0CKI del timer 0) no enciende: en este micro ese pin es de drenador abierto y necesita una pull-up externa. Luego se cambia al PIC16F887, un micro más moderno donde RA4 funciona normal, y se muestra que allí los pines se ponen digitales con ANSEL y ANSELH en vez de ADCON1.

Fase 1

PIC16F877A

1.1

Proyecto nuevo

▶ 0:34

Se crea el proyecto salidas_especial (sin espacios en el nombre) en la carpeta clase 9, con el PIC16F877A a 4 MHz. En Edit Project se escoge el oscilador XT, se apaga el watchdog y se habilita el power-up timer.

1.2

Poner el puerto A como digital

▶ 2:20

El puerto A de este micro es analógico al arrancar. Mientras se llega al tema del conversor, basta con saber que esta línea deja todos los pines como digitales:

void main() {
  ADCON1 = 0b0111;       // todo digital
  TRISA = 0b00000000;    // puerto A salida
  while (1) {
    PORTA = ~PORTA;
    Delay_ms(200);
  }
}
1.3

RA4 no enciende

▶ 3:37

Al simular, todos los LEDs titilan menos el de RA4. En este micro ese pin (también entrada T0CKI del timer 0) es de drenador abierto: solo puede llevar a 0 y para sacar un 1 necesita una resistencia pull-up al positivo.

En Proteus se agrega la resistencia y en sus propiedades se pone como digital; con eso el LED funciona.

Si un circuito con PIC16F877A funciona en todos los pines menos RA4, revise que tenga la pull-up externa de unos 10 kΩ.

Fase 2

PIC16F887

2.1

Cambiar a un micro más moderno

▶ 5:17

Se reemplaza el micro por un PIC16F887, que es compatible en pines y ya no tiene este problema. Además, con el oscilador interno, deja RA6 y RA7 libres como entradas y salidas.

2.2

Configurar el proyecto

▶ 7:05

En el proyecto se cambia el micro a mano. El 16F887 tiene más opciones de oscilador, incluido el interno de 8 MHz, y el Fail-Safe Clock Monitor, que pasa al oscilador interno si el externo falla. Aquí se sigue usando un cristal XT.

2.3

ANSEL y ANSELH

▶ 8:16

En este micro ya no se usa ADCON1 para lo digital: se ponen en 0 los registros ANSEL y ANSELH. También conviene arrancar el puerto en 0 para que todos los LEDs empiecen igual. Al simular, RA4 titila sin resistencia externa.

ANSEL = 0;        // todo digital
ANSELH = 0;
TRISA = 0b00000000;
PORTA = 0;        // arrancar en cero
while (1) {
  PORTA = ~PORTA;
  Delay_ms(200);
}
