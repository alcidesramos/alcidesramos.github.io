Solución al error Ninja exited with code: 1

Video corto para un error muy común: al copiar la carpeta de un proyecto y meterla dentro de otra, el proyecto deja de compilar. No aparecen errores en el código, pero la salida termina en -G Ninja exited with code: 1. La causa es la caché de CMake, que guarda la ruta vieja. Se soluciona borrando la caché y reconfigurando.

Fase 1

El error

1.1

Mover el proyecto de carpeta

▶ 0:20

El problema aparece cuando la carpeta del proyecto se copia o se mueve dentro de otras carpetas y luego se abre con VS Code.

1.2

Compila sin errores pero falla

▶ 0:40

Al compilar no hay errores en el código, pero la salida termina con -G Ninja exited with code: 1 y no se genera el .elf. La caché de CMake quedó con la ruta anterior.

Fase 2

La solución

2.1

Borrar la caché de CMake

▶ 0:55

Con el proyecto abierto presione F1 o Ctrl+Shift+P, escriba CMake: delete y elija CMake: Delete Cache and Reconfigure. Espere a que termine de configurar.

CMake: Delete Cache and Reconfigure
2.2

Compilar de nuevo

▶ 1:20

Al compilar otra vez desaparece el error de Ninja y se genera el .elf del proyecto.

Después de usarla una vez, la opción aparece de primera en la paleta de comandos.
