Datos en la memoria flash

Muchos PIC16F nuevos tienen 4K o más de flash y muy poca o ninguna EEPROM. La flash se borra y escribe por filas de 32 palabras de 14 bits, con una secuencia de desbloqueo en NVMCON2 (55h y luego AAh). Sin MCC, con un PIC16F15324, se agregan funciones propias: FLASH_WriteBlock solo acepta direcciones múltiplo de 32; las funciones de alto nivel calculan la fila y la posición dentro de ella, leen toda la fila a un buffer, cambian el dato y la vuelven a escribir. Para int, long y float el dato se parte en bytes con un puntero. Todo se comprueba en el simulador mirando la memoria de programa y las variables. Hay que escribir lejos del código, porque si se pisa el programa el micro se bloquea.

Fase 1

La memoria flash

1.1

Secuencia de desbloqueo

▶ 0:00

Para borrar o escribir la flash se cargan 55h y AAh en NVMCON2 y luego se pone WR, con interrupciones deshabilitadas.

1.2

Filas de 32 palabras

▶ 3:14

El PIC16F15324 tiene 4096 palabras de flash. Se borra y escribe por filas de 32 palabras, y cada palabra guarda 14 bits, así que se usa un byte por posición.

2.2

FLASH_WriteBlock

▶ 12:10

Con una AND contra el tamaño del bloque se ve si la dirección es múltiplo de 32. Si no lo es, la función no escribe.

signed char FLASH_WriteBlock(unsigned int FLASH_DIR, unsigned int *flashWordArray)
{
  unsigned int dir_aux = (unsigned int)(FLASH_DIR & ((END_FLASH - 1) ^ (FLASH_BLOCKSIZE - 1)));
  unsigned char GIE_Value = GIE;   // captura el valor de gie
  unsigned char i;

  // analiza si es multiplo de 32
  if (FLASH_DIR != dir_aux)
  {
    return -1;
  }
  GIE = 0;   // deshabilita interrupcion
  // ... borra la fila y escribe las 32 palabras (ver video)
}

Probar en el simulador

▶ 16:44

Con 0x22 no escribe; con 0x20, que es múltiplo de 32, el bloque aparece en la memoria de programa.

Fase 3

Cualquier dirección

3.1

Escribir un char

▶ 21:17

Para escribir en cualquier posición se calcula el inicio de la fila y el desplazamiento, se lee la fila al buffer, se cambia el dato y se escribe la fila completa.

3.2

Escribir un entero

▶ 28:08

Un int ocupa dos posiciones. Con un puntero tipo char se toma cada byte y se guarda en dos casillas seguidas.

char *punte;   // puntero tipo char
punte = &data_flash;

// captura la direccion inicial multiplo de 32 donde se encuentra la direccion dada
unsigned int dir_ini = (unsigned int)(flash_dir & ((END_FLASH - 1) ^ (FLASH_BLOCKSIZE - 1)));
// captura la posicion del dato a guardar dentro de la fila
unsigned char offset = (unsigned char)(flash_dir & (FLASH_BLOCKSIZE - 1));
unsigned char i;

//Lee la flash toda la fila y lo guarda en el buffer
for (i = 0; i < FLASH_BLOCKSIZE; i++)
{
  Buf[i] = FLASH_Read((dir_ini + i));
}

// escribe en el buffer el nuevo dato
Buf[offset] = *punte;
punte++;
offset++;
Buf[offset] = *punte;

//Guarda la info
FLASH_WriteBlock(dir_ini, Buf);
3.3

Leer

▶ 34:08

Las funciones de lectura recorren las mismas posiciones y arman el dato. En la ventana Variables se comprueba cada valor.

3.4

long y float

▶ 36:29

Long y float ocupan cuatro posiciones: la función es la misma, solo cambia el tipo y se repite el paso del puntero cuatro veces.

3.5

Texto

▶ 40:57

El texto se escribe carácter por carácter hasta el cero final, máximo 31 caracteres por fila. Se recomienda ponerlo en direcciones altas, lejos del programa.

3.6

Programa final

▶ 43:11

Se guardan y leen los cinco tipos de dato. En Variables aparecen 0x17, 1578, 102365, 19.473 y el texto.

FLASH_Write(0x27, buffer, 0x17);
FLASH_Write_Int(0x30, buffer, 1578);
FLASH_Write_Long(0x34, buffer, 102365);
FLASH_Write_Float(0x61, buffer, 19.473);
FLASH_Write_Texto(0x900, buffer, "Esto SE ACABO");

while (1)
{
  dato = FLASH_Read(0x27);
  dato = FLASH_Read_Int(0x30);
  dato_l = FLASH_Read_Long(0x34);
  decimal = FLASH_Read_Float(0x61);
  FLASH_Read_Texto(0x900, &texto);

}

Cuidado

▶ 45:30

Si se escribe en una dirección donde hay código, el programa se daña y el micro se bloquea. Hay que saber qué zona de la flash está libre.
