PWM y set point para un motor DC

Continuación de la clase de Input Capture, ahora con el motor real. Se pasa el micro a 84 MHz con cristal, se configura TIM2 canal 1 como PWM en PA15 y dos pines para el sentido de giro del puente H. Una librería PWM con escala de 0 a 10000 (en lugar de 0 a 255) da más resolución para control. Al final, una librería de UART con DMA y evento IDLE recibe el set point desde Hercules, lo convierte con atoi y mueve el motor mientras se envía la frecuencia del encoder: un sistema de lazo cerrado listo para identificar el motor.

Fase 1

Montaje

1.1

Motor con encoder y puente H

▶ 1:05

El motor va a OUT1/OUT2 del puente H (cables rojo y negro). El encoder se alimenta con 5 V y GND, y su salida A (o B) va a la entrada de captura del micro.

El L298 se alimenta con 12 V y entrega 5 V, que pueden alimentar el micro. Recibe la señal PWM (ENA) y dos señales de sentido de giro (IN1, IN2). En la simulación, las entradas de sensado de corriente del modelo de Proteus se ponen a tierra.

1.2

Repaso: lectura de frecuencia en físico

▶ 3:17

Ahora es montaje real: HSE con cristal y PLL a 84 MHz. Por eso el prescaler del TIM1 (Input Capture) pasa de 16-1 a 84-1 para seguir muestreando a 1 MHz. Al girar el motor con la mano, la frecuencia cambia en la terminal.

Fase 2

PWM en TIM2

2.1

Configuración

▶ 4:52

El PWM necesita otro timer porque TIM1 muestrea muy rápido. TIM2: Clock Source = Internal Clock, Channel1 = PWM Generation CH1. El pin se remapea a PA15 con Ctrl + clic sobre el pin, y se le pone la etiqueta pwm.

Conviene usar más de 50 Hz para que el motor responda bien; el valor ideal depende de la inductancia y la resistencia del motor.

2.2

Prescaler y periodo

▶ 7:00

Con la hoja de Excel: reloj de 84 MHz, Prescaler = 84-1 (un paso por microsegundo) y para 100 Hz el Counter Period es 10000 (10 ms). Para 200 Hz sería 5000.

2.3

Pines de sentido de giro

▶ 12:13

PA11 y PA12 como GPIO_Output con etiquetas M11 y M12 (motor 1, terminales 1 y 2). 1-0 gira hacia un lado y 0-1 hacia el otro.

Fase 3

Librería PWM

3.1

PWM.h: timer y canales

▶ 9:29

Solo hay que indicar el timer y el registro de cada canal. Si usas otro timer o canal, cambia estos defines.

// info relacionada a los servos
#define PWMT    htim2      // timer usado
#define PWMTIM  TIM2       // registro timer usado

// canales pwm a usar
// pwm1
#define PWM1_CH TIM_CHANNEL_1   // canal de pwm
#define PWM1    TIM2->CCR1      // registro del ciclo útil, canal 1
// pwm2
#define PWM2_CH TIM_CHANNEL_2
#define PWM2    TIM2->CCR2

void PWM_init(TIM_HandleTypeDef *serv, uint16_t canal);
void pwm_valor(uint32_t *canal, float valor);
3.2

Escala: más resolución

▶ 11:08

En PWM.c la variable escala define el rango de valores. En Arduino va de 0 a 255; aquí se usa de 0 a 10000 para aprovechar los 16 bits del timer, que es mejor para control. Si solo quieres porcentaje, pon 100.

//float escala = 100;    // escala de 0 a 100 %
float escala = 10000;    // define la escala a trabajar el pwm

Si cambias la frecuencia (por ejemplo a 200 Hz con periodo 5000), cambia también la escala a 5000. Así 2500 vuelve a ser el 50 %.

3.3

Inicializar y dar un valor

▶ 13:28

Antes del while se inicializa el PWM con el timer y el canal, se fija el sentido de giro y se da el valor. Con 200 el motor no arranca por la inercia; con 2000 sí.

PWM_init(&PWMT, PWM1_CH);   // inicia el TIMER2 canal PWM1

HAL_GPIO_WritePin(M11_GPIO_Port, M11_Pin, 1);
HAL_GPIO_WritePin(M12_GPIO_Port, M12_Pin, 0);
pwm_valor(&PWM1, 2000);     // de 0 a escala (5000 = 50 %)

Si el PWM sale (se ve en el analizador) pero el motor no gira, revisa el sentido de giro: sin M11/M12 el puente H no mueve el motor.

3.4

Funciones para el motor

▶ 21:49

Dos funciones facilitan las pruebas de identificación: arrancar con una velocidad y parar.

/* USER CODE BEGIN 0 */
void motorstop()
{
  HAL_GPIO_WritePin(M11_GPIO_Port, M11_Pin, 0);
  HAL_GPIO_WritePin(M12_GPIO_Port, M12_Pin, 0);
  pwm_valor(&PWM1, 0);
}

void motorset(float velo)
{
  HAL_GPIO_WritePin(M11_GPIO_Port, M11_Pin, 1);
  HAL_GPIO_WritePin(M12_GPIO_Port, M12_Pin, 0);
  pwm_valor(&PWM1, velo);
}

/* prueba: gira 4 s y para */
motorset(2500);
HAL_Delay(4000);
motorstop();
Fase 4

Set point por la UART

4.1

Librería UART con DMA e IDLE

▶ 23:24

La librería uart_int_idle_dma detecta cuándo dejan de llegar datos (línea inactiva) y avisa con una bandera. En el .h se define el puerto y el tamaño de la trama (aquí 50).

// uart_int_idle_dma.h
#define uartdatosreg USART1   // puerto serial a analizar
#define uartdatos    huart1
#define trama_size   50       // tamaño del buffer

// main.c
#include "uart_int_idle_dma.h"
/* USER CODE BEGIN PV */
uint8_t  trama_rx[trama_size];
char     flag_rx = 0;
uint16_t num_datos;
uint16_t salida_pwm;
4.2

Activar DMA en USART1

▶ 26:43

En USART1: NVIC con la interrupción global habilitada y en DMA Settings agregar USART1_RX.

4.3

Cómo funciona

▶ 27:18

La inicialización limpia el buffer y arranca la recepción por DMA hasta línea inactiva. Cuando llega una trama, el callback guarda cuántos datos llegaron y levanta la bandera.

void uartdat_it_idle_dma_init()
{
  memset(trama_rx, 0, trama_size);   // limpia el buffer
  HAL_UARTEx_ReceiveToIdle_DMA(&uartdatos, (uint8_t*)trama_rx, trama_size);
}

// procedimiento de idle para recepción serial
void HAL_UARTEx_RxEventCallback(UART_HandleTypeDef *huart, uint16_t Size)
{
  if (huart->Instance == uartdatosreg)
  {
    num_datos = Size;
    flag_rx = 1;
  }
}
4.4

El while completo

▶ 29:39

Si llegó una trama, atoi la convierte a número y ese valor va al motor. Luego se limpia la bandera y se vuelve a armar la recepción. Además se envía la frecuencia del encoder.

/* USER CODE BEGIN 2 */
Frec1_Init();
PWM_init(&PWMT, PWM1_CH);
uartdat_it_idle_dma_init();
motorstop();

while (1)
{
  if (flag_rx == 1)
  {
    salida_pwm = atoi((char*)trama_rx);  // pasa a número el pwm recibido
    motorset(salida_pwm);                // coloca la señal al motor
    flag_rx = 0;
    uartdat_it_idle_dma_init();
  }
  HAL_GPIO_TogglePin(led_GPIO_Port, led_Pin);
  if (frec1 != 0) frecuencia1 = frecmuestreo / frec1;
  else frecuencia1 = 0;
  frec1 = 0;    // limpia las frecuencias usadas
  sprintf(texto, "RPM=%.1f\r\n", frecuencia1);
  uartx_write_text(&huart1, texto);
  HAL_Delay(500);
}

Lo que se imprime como RPM es la frecuencia de pulsos del encoder. Para pasarla a RPM hay que dividir entre los pulsos por vuelta y multiplicar por 60.
