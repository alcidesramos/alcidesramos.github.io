Termocupla K con MAX6675

El MAX6675 entrega 16 bits por SPI. En vez de usar el SPI del micro (8 bits) se hace una función que da un pulso de reloj y lee un bit. Con CS en 0 se leen 16 bits del más significativo al menos significativo, poniendo un 1 en la posición que corresponde con desplazamiento y OR. Luego se desplaza 3 veces a la derecha (los primeros bits no son temperatura) y se multiplica por 0.25. En Proteus la termocupla se simula con una fuente en milivoltios. El paso a XC8 solo cambia los nombres de los pines, los bits de configuración y las funciones del LCD.

UART1_Init(9600);
max6675_init();   //inicializa el sensor
Uart1_write_text_const("INICIANDO\r\n");
while (1)
{
  temperatura = max6675_lee();   //lee el sensor
  FloatToStr_(temperatura, texto, 2);
  Uart1_write_text_const("TEMPERATURA=");
  UART1_Write_Text(texto);
  Uart1_write_text_const("\r\n");
  Lcd_Out(2, 7, texto);
  delay_ms(500);
}
Fase 2

La librería

2.1

Inicializar

▶ 5:36

Reloj y CS como salidas, dato como entrada. CS en 1 deshabilita el sensor; se habilita con 0.

#include "max6675.h"
// procedimientos del max6675
void max6675_init()
{
  max6675_ck_dir = 0;    //salida reloj
  max6675_cs_dir = 0;    //salida cs
  max6675_dat_dir = 1;   //entrada dato
  max6675_cs = 1;        //salida 1
  max6675_ck = 0;        //saca cero por el reloj
  Delay_ms(100);
}
2.2

Un pulso, un bit

▶ 7:14

max6675_pulso pone el reloj en 1, espera 10 µs, lee el dato, pone el reloj en 0 y retorna lo leído.

char max6675_pulso()
{
  char lei;
  max6675_ck = 1;     //saca uno por el reloj
  Delay_us(10);
  lei = max6675_dat;
  max6675_ck = 0;     //saca cero por el reloj
  Delay_us(10);
  return lei;
}
2.3

Leer 16 bits

▶ 7:52

Con CS en 0 se hace un for de 15 a 0: si el pulso devuelve 1, se pone un 1 en esa posición con (1 << i) y OR. Al final CS vuelve a 1. Según la hoja de datos el dato empieza en el tercer bit, así que se desplaza 3 veces y se multiplica por 0.25.
