Los ciclos while y do-while

Lección 12 del curso. Se explica que while revisa la condición antes de entrar (puede no ejecutarse nunca) y do-while la revisa después (se ejecuta al menos una vez). Luego, con un PIC16F877A, un display en el puerto D y un pulsador con pull-up en RC0, se arma un contador de 0 a 9: primero se ve el problema del rebote, se agrega un antirrebote y al final un while que espera a que se suelte el pulsador.

Fase 1

while y do-while

1.1

El ciclo while

▶ 0:00

while (condición) { ... } revisa la condición y, mientras se cumpla, repite lo que está entre llaves. Si no se cumple desde el principio, no lo hace ni una vez.

1.2

El ciclo do-while

▶ 0:33

do { ... } while (condición); primero hace la acción y después revisa la condición. Se usa cuando la acción debe hacerse al menos una vez.

Fase 2

Contador con pulsador

2.1

Proyecto y códigos del display

▶ 1:39

Se crea el proyecto ciclowhile en la carpeta Clase 12 (PIC16F877A a 4 MHz) y se copian los códigos de 7 segmentos de la clase anterior. Si al compilar no reconoce TRISD, hay que revisar que el micro escogido en el proyecto sea el correcto.

#define display PORTD
const char codigos[] = {63, 6, 91, 79, 102, 109, 125, 7, 127, 111};
char cuenta = 0;
2.2

Nombrar el pulsador con sbit

▶ 4:30

El pulsador está en RC0. Se puede nombrar con #define o con una variable sbit, que asocia el nombre al pin; esta segunda forma es la que usan muchas librerías de MikroC (LCD, motores). No se pueden usar las dos a la vez con el mismo nombre. RC0 se configura como entrada.

sbit sw at RC0_bit;

TRISD = 0;        // salida display
TRISC0_bit = 1;   // entrada pulsador
2.3

El problema del rebote

▶ 6:13

Si al leer el pulsador en 0 se incrementa la cuenta, cada pulsación avanza varios números: las láminas del pulsador rebotan y el micro alcanza a leer esos pulsos. Se agrega un retardo antirrebote de 200 a 300 ms.

while (1) {
  display = codigos[cuenta];
  if (sw == 0) {
    cuenta++;
    if (cuenta > 9) cuenta = 0;
    Delay_ms(300);   // antirrebote
  }
}
2.4

Esperar a que se suelte con while

▶ 8:33

Con el antirrebote, si se deja presionado el pulsador sigue contando cada 300 ms. Para que cuente solo una vez por pulsación se agrega un while vacío que deja al programa esperando mientras el pulsador siga en 0. Así el retardo puede bajar a 100 ms.

if (sw == 0) {
  cuenta++;
  if (cuenta > 9) cuenta = 0;
  Delay_ms(100);
  while (sw == 0);   // espera a que se suelte
}
