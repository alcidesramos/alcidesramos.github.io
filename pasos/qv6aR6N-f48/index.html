Configurar el reloj de los PIC con USB

Lección 26 del curso, a pedido de un suscriptor. Con un programa sencillo que manda "hola mundo" por el puerto serial cada segundo, se recorre el diagrama de reloj del PIC18F2550 en la hoja de datos y las opciones de Edit Project en MikroC: oscilador HS, divisor del cristal, PLL de 96 MHz, postscaler del CPU y reloj del USB. Si la frecuencia del proyecto no coincide con la real, el serial muestra caracteres raros. Luego se compara con el PIC18F25K50, que puede trabajar a 48 MHz con el oscilador interno y alimentar el USB sin cristal.

Fase 1

PIC18F2550 sin PLL

1.1

El programa de prueba

▶ 0:33

Un PIC18F2550 manda "hola mundo" por el UART cada segundo a un Virtual Terminal de Proteus. Lo que interesa es la configuración del reloj: si no está bien sincronizada, en el terminal salen caracteres raros.

void main() {
  UART1_Init(9600);
  while (1) {
    UART1_Write_Text("hola mundo\r\n");
    Delay_ms(1000);
  }
}
1.2

Oscilador HS y el postscaler

▶ 1:08

En Project > Edit Project se escoge HS oscillator para el cristal de 8 MHz. En el diagrama de reloj, sin PLL el cristal pasa por un divisor de 1, 2, 3 o 4 antes de llegar al CPU (System Clock Postscaler).

1.3

Si se divide, cambia la frecuencia

▶ 3:55

Si el postscaler divide entre 2, el micro trabaja realmente a 4 MHz aunque el cristal sea de 8, y así hay que indicarlo en la frecuencia del proyecto. Lo recomendable es dejarlo en 1 para tener la máxima velocidad.

1.4

Oscilador interno

▶ 5:37

El micro también puede trabajar con su oscilador interno, sin cristal, y esa frecuencia se puede usar para el CPU. No sirve para el USB.

Fase 2

PIC18F2550 a 48 MHz

2.1

El PLL de 96 MHz

▶ 6:13

El USB 2.0 de este micro necesita 48 MHz. El PLL solo acepta 4 MHz de entrada y entrega 96 MHz, por eso el cristal se divide primero con el PLL Prescaler: con un cristal de 8 MHz se divide entre 2. Luego los 96 MHz se dividen entre 2 para el USB y para el CPU.

2.2

La configuración en MikroC

▶ 8:29

Con un cristal de 8 MHz:

  • PLL Prescaler Selection: Divide by 2 (8 MHz oscillator input).
  • System Clock Postscaler: 96 MHz PLL Src /2.
  • USB Clock Selection: from the 96 MHz PLL divided by 2.
  • Oscillator Selection: HS oscillator, PLL enabled (HSPLL).
  • MCU Clock Frequency: 48 MHz.
2.3

Cuidado con Proteus

▶ 10:12

Proteus no simula bien el PLL a 48 MHz para los periféricos en estos micros, así que en la simulación el serial sale con caracteres raros. En el micro físico sí funciona. Si se deja el CPU en HS sin PLL, el USB puede seguir a 48 MHz desde el PLL.

Una configuración con PLL que falla en Proteus no significa que esté mal: pruébela en el micro físico.

Fase 3

PIC18F25K50 sin cristal

3.1

Diagrama de reloj

▶ 11:56

El 18F25K50 tiene un oscilador interno de 16 MHz con buena precisión y un PLL de 3x o 4x. Su desventaja es que el PLL tiene menos opciones de división, así que con algunos cristales hay que hacer más cálculos. Su gran ventaja es que el CPU y el USB pueden trabajar a 48 MHz sin cristal.

3.2

Configurarlo a 48 MHz

▶ 13:41

En Edit Project se habilita el PLL, se deja el CPU sin división, se escoge el oscilador interno y la frecuencia de 48 MHz. Basta alimentar el micro y conectar el cable USB.

  • PLL Enable: Enabled.
  • CPU System Clock Postscaler: no divide.
  • Oscillator Selection: Internal oscillator.
  • MCU Clock Frequency: 48 MHz.
