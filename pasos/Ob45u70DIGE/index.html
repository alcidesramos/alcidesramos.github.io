Teclado 4x4 en XC8

Se crea el proyecto en MPLAB X con un PIC18F45K50 y el MCC solo para el oscilador. El teclado va en el puerto D: la parte alta saca las filas y la parte baja lee las columnas. La función Keypad_Key_Press recorre las cuatro filas con un desplazamiento, cuenta en qué posición se detecta la tecla y devuelve el carácter desde una tabla. Con eso el LCD muestra la tecla pulsada. Después se pasa la versión que lee varias teclas: una máquina de estados guarda hasta cuatro dígitos y una pausa propia, miretardo, revisa el teclado cada milisegundo para no perder pulsaciones. Al final, con atoi, el texto se convierte en número.

Fase 2

Leer una tecla

2.1

Función del teclado

▶ 5:31

Se copia la función de MikroC y se adapta a XC8. La parte alta del puerto D son salidas (filas) y la parte baja entradas (columnas).

Por cada fila se pone un 1 y se revisan las cuatro columnas; tec cuenta la posición y al final se busca el carácter en la tabla.

void Keypad_Init()
{
  TRISD = 0b00001111;   // inicia el puerto del teclado
}

unsigned char Keypad_Key_Press(void)
{
  const unsigned char keypad_deco[17] = { /* caracteres del teclado */ };
  unsigned int tec = 0, fila;

  for (fila = 0b00000001; fila < 0b00010000; fila <<= 1)
  {
    LATD = fila << 4;
    if (PORTDbits.RD0 == 1) break; tec++;
    if (PORTDbits.RD1 == 1) break; tec++;
    if (PORTDbits.RD2 == 1) break; tec++;
    if (PORTDbits.RD3 == 1) break; tec++;
  }
  PORTD = 0x00;
  return keypad_deco[tec];
}

Mostrar la tecla

▶ 8:58

En el ciclo principal, si hay tecla se escribe en la segunda línea del LCD.

tecla = Keypad_Key_Press();
if (tecla != 0)
{
  Lcd_Set_Cursor(2, 8);
  Lcd_Write_Char(tecla);
  __delay_ms(400);
}
