Full duplex por USB CDC

En la clase 34 el micro solo transmitía por USB CDC. Ahora también recibe: la función CDC_Receive_FS de usbd_cdc_if.c se llama sola cada vez que llegan datos (es una interrupción), así que el micro puede transmitir y recibir al mismo tiempo. Se copia lo recibido en trama_rx, se procesan las órdenes (M1DER*, M1IZQ*, M1STOP*) y se borra la trama para no repetir. Proteus no simula el USB, así que se prueba con la placa real (Black Pill F401) y un terminal como Hercules.

Fase 1

CubeMX

1.1

Activar USB OTG FS y la clase CDC

▶ 1:37

En Connectivity → USB_OTG_FS elige Mode Device_Only. En Middleware → USB_DEVICE elige Class Communication Device Class (Virtual Port Com).

1.2

Reloj para el USB

▶ 2:10

El reloj queda en rojo: el USB necesita exactamente 48 MHz. Usa el cristal externo (HSE) y deja que CubeMX resuelva los divisores (Resolve Clock Issues). Puede tardar. El sistema queda en 84 MHz y la salida USB en 48 MHz.

2.2

Probar la transmisión

▶ 4:53

Programa la placa con el ST-LINK. Windows crea un puerto COM nuevo (aquí COM16). Envía algo en el bucle para comprobar que llega.

usb_uart_write("HOLA\r\n");

Sin el driver Virtual COM Port de ST, Windows no reconoce el puerto. En Proteus no se puede simular el USB.

Fase 3

Recibir

3.1

Buffer externo

▶ 6:09

En main.c crea uint8_t trama_rx[64]; (64 es el tamaño de paquete del USB FS). En USB_DEVICE/App/usbd_cdc_if.c declárala como externa en USER CODE PV.

/* USER CODE BEGIN PV */
extern uint8_t trama_rx[64];
/* USER CODE END PV */
3.2

Copiar lo recibido

▶ 6:46

CDC_Receive_FS se llama automáticamente cada vez que llega un paquete. Antes del return, borra trama_rx, copia lo que trae Buf (con su largo) y limpia Buf.

static int8_t CDC_Receive_FS(uint8_t* Buf, uint32_t *Len)
{
    /* USER CODE BEGIN 6 */
    USBD_CDC_SetRxBuffer(&hUsbDeviceFS, &Buf[0]);
    USBD_CDC_ReceivePacket(&hUsbDeviceFS);
    memset(trama_rx, 0, 64);           // limpia el buffer final
    memcpy(trama_rx, Buf, *Len);       // pasa la info al buffer
    memset(Buf, 0, *Len);
    return (USBD_OK);
    /* USER CODE END 6 */
}

Agrega #include "string.h" en usbd_cdc_if.c para memset y memcpy. A diferencia de la UART, no hace falta esperar un '*': llega el paquete completo.

3.3

Eco de prueba

▶ 9:03

En el bucle envía de vuelta lo que hay en trama_rx. Funciona, pero se repite sin parar porque la trama conserva el último valor.

usb_uart_write(trama_rx);
Fase 4

Procesar órdenes

4.1

Responder a cada orden

▶ 10:57

Vuelve a llamar a procesarx() de la clase 40. Como aquí no hay motor conectado, cada función responde por el USB lo que haría.

void m1derecha(void)
{
    HAL_GPIO_WritePin(M11_GPIO_Port, M11_Pin, 0);
    HAL_GPIO_WritePin(M12_GPIO_Port, M12_Pin, 1);
    usb_uart_write("GIRANDO A LA DERECHA\r\n");
}
4.2

Borrar la trama al final

▶ 13:13

El micro envía HOLA continuamente y además responde cuando llega una orden. Para que la respuesta salga una sola vez, al final de procesarx() borra trama_rx.

    }   // fin del procesamiento
    memset(trama_rx, 0, 64);   // borra la trama para no repetir
}

En el video el primer intento (memset(trama_rx,0,)) no compiló por falta del tamaño. Debe ser memset(trama_rx, 0, 64).
