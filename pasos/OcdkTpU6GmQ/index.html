Detección de color con el TCS3200

El TCS3200 entrega una señal cuadrada cuya frecuencia depende de la luz que recibe en el filtro elegido. Con una BlackPill STM32F411 montada en protoboard (Proteus no simula este sensor) medimos esa frecuencia con el modo Input Capture del TIM1 por interrupción, usando una librería que se configura con una estructura y funciona en cualquier timer y canal. Calibramos cada color mirando las frecuencias por el puerto serial y al final un LED RGB se enciende del color de la tarjeta que ponemos frente al sensor.

Fase 1

El sensor

1.1

Pines S0–S3

▶ 1:15

S0 y S1 eligen la escala de la frecuencia de salida; S2 y S3 eligen el filtro de color. Dejamos S0 y S1 en alto (100 %) directamente, sin usar pines del micro. S2 y S3 sí van al micro.

  • Rojo: S2 = L, S3 = L.
  • Azul: S2 = L, S3 = H.
  • Sin filtro: S2 = H, S3 = L.
  • Verde: S2 = H, S3 = H.
1.2

Rango de frecuencias

▶ 1:50

Con escala al 100 % la salida llega a unos 500–600 kHz; al 20 %, 100–120 kHz; al 2 %, 10–12 kHz. El color se debe leer siempre a la misma distancia, porque la distancia cambia la reflexión.

Fase 2

CubeMX

2.1

Reloj, UART y pines

▶ 5:10

Activamos el cristal externo (HSE con PLL) a 100 MHz; la librería se adapta a cualquier velocidad.

USART1 asíncrono a 115200 baudios para ver las frecuencias.

Salidas con etiqueta S2 y S3 para el filtro, y ROJO, VERDE y AZUL para el LED RGB.

2.2

Calcular el prescaler

▶ 8:40

Con la hoja de Excel elegimos el prescaler. Con 100 MHz y prescaler 100 el contador de 16 bits (hasta 65.535) permite medir desde unos 15 Hz hasta 1 MHz, suficiente para los 600 kHz del sensor.

2.3

TIM1 en Input Capture

▶ 10:40

TIM1 con Internal Clock y Channel1 en Input Capture direct mode (PA8). Prescaler 100-1, periodo 65535 y polaridad Rising Edge.

En NVIC Settings activamos TIM1 capture compare interrupt.

El contador da la vuelta en 65.535. Si la segunda captura es menor que la primera, hay que sumarle el máximo antes de restar; la librería ya lo hace.

Fase 3

Librería TCS3200

3.1

Agregar las librerías

▶ 14:10

En Core/Librerias copiamos TCS3200_COLOR.c/.h, uart y pinout.h, agregamos la carpeta a los Include paths e incluimos todo en main.c.

#include "uart.h"
#include "TCS3200_COLOR.h"
#include "pinout.h"

#include "stdint.h"
#include "stdio.h"
#include "stdlib.h"
#include "string.h"
3.2

Configurar timer y canal

▶ 15:00

En TCS3200_COLOR.c se indica el timer usado y se llena la estructura con el timer, el registro CCR, el canal y la bandera. Para otro canal, cambia los tres números (CCR2, CHANNEL_2, FLAG_CC2…).

// timer a usar
extern TIM_HandleTypeDef htim1;

// configurar timer input capture
COLORS TCS3200_SEN = {&htim1, &(TIM1->CCR1),
                      TIM_CHANNEL_1, TIM_FLAG_CC1};
3.3

Cómo mide la frecuencia

▶ 17:30

En cada flanco de subida la interrupción guarda el valor del contador. Con dos capturas calcula la diferencia y con el reloj y el prescaler obtiene la frecuencia, que queda en la variable global frecuencia.

3.4

Llamar la interrupción

▶ 19:30

En stm32f4xx_it.c incluimos la librería y llamamos TCS3200_Interrupt() dentro de TIM1_CC_IRQHandler.

/* USER CODE BEGIN TIM1_CC_IRQn 0 */
#include "TCS3200_COLOR.h"
TCS3200_Interrupt();
/* USER CODE END TIM1_CC_IRQn 0 */
HAL_TIM_IRQHandler(&htim1);
Fase 4

Leer y calibrar

4.1

Programa principal

▶ 26:40

Declaramos float frecuencia y char texto[50]. Iniciamos el sensor y le damos 200 ms para arrancar. En el while se elige el filtro, se espera 1 ms para que se mida la frecuencia, se envía por serial y se vuelve a cero (si no llegan más interrupciones no debe quedar el valor viejo).

float frecuencia;
char texto[50];

/* USER CODE BEGIN 2 */
TCS3200_Init();
HAL_Delay(200);

while (1)
{
  PIN_OFF(S2);      // filtro rojo
  PIN_OFF(S3);
  HAL_Delay(1);     // tiempo para capturar la frecuencia
  sprintf(texto, "FrecRojo=%.1f\r\n", frecuencia);
  uartx_write_text(&huart1, texto);
  frecuencia = 0;
  HAL_Delay(500);
}

Para que sprintf imprima flotantes hay que activar «Use float with printf» en Properties > C/C++ Build > Settings > MCU Settings.

4.2

Ver la frecuencia

▶ 31:40

En el monitor serial vemos la frecuencia del rojo (unos 5 kHz sin tarjeta). Con la tarjeta roja sube a unos 34 kHz; el analizador lógico confirma la medida.

4.3

Umbrales de cada color

▶ 39:20

Con las medidas en nuestras condiciones de luz y distancia fijamos el mínimo de cada color en TCS3200_COLOR.h.

#define rojo_min   30000
#define verde_min  12800
#define azul_min   30000

Estos valores dependen de la luz, la distancia y el sensor. Mide los tuyos antes de usarlos.

Fase 5

LED RGB por color

5.1

Función RGB

▶ 33:30

El LED RGB enciende con 0, por eso se niega cada valor.

void RGB(uint8_t rojo, uint8_t verde, uint8_t azul)
{
  PIN_PUT(ROJO, !rojo);
  PIN_PUT(VERDE, !verde);
  PIN_PUT(AZUL, !azul);
}
5.2

Los tres filtros

▶ 36:10

Se apaga el LED y se prueba cada filtro. El que supere su umbral enciende su color.

RGB(0, 0, 0);

// filtra rojo
PIN_OFF(S2); PIN_OFF(S3);
HAL_Delay(1);
if (frecuencia > rojo_min) RGB(1, 0, 0);
frecuencia = 0;

// filtra verde
PIN_ON(S2); PIN_ON(S3);
HAL_Delay(1);
if (frecuencia > verde_min) RGB(0, 1, 0);
frecuencia = 0;

// filtra azul
PIN_OFF(S2); PIN_ON(S3);
HAL_Delay(1);
if (frecuencia > azul_min) RGB(0, 0, 1);
frecuencia = 0;
