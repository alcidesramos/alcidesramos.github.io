ADC_Read o ADC_Get_Sample

Complemento de la lección 19. Con el PIC18F45K22 se cambia el estado de un pin en cada lectura del ADC y se mide la frecuencia en Proteus con un contador. Con ADC_Read se obtienen unos 1690 Hz y con ADC_Get_Sample unos 1780 Hz, porque esta no inicializa el módulo en cada lectura. A cambio, ADC_Get_Sample necesita ADC_Init antes del while y un pequeño retardo entre lecturas.

Fase 1

Medir la velocidad

1.1

Un pin que cambia en cada lectura

▶ 0:00

Se pone RD0 como salida y se invierte en cada vuelta del while, junto a las lecturas del ADC. En Proteus se conecta un contador de frecuencia (Counter Timer) a ese pin.

TRISD0_bit = 0;

while (1) {
  codigo = ADC_Read(0);
  codigo = ADC_Read(10);
  LATD0_bit = ~LATD0_bit;
}
1.2

Resultado con ADC_Read

▶ 1:30

Con ADC_Read el pin cambia a unos 1690 Hz. ADC_Read inicializa el módulo en cada llamada, y eso toma tiempo.

Fase 2

ADC_Get_Sample

2.1

Qué necesita

▶ 1:50

ADC_Get_Sample solo lee, así que el módulo se inicializa una vez con ADC_Init() antes del while. Además hay que dar un pequeño retardo entre lectura y lectura, de unos 10 µs.

ADC_Init();

while (1) {
  codigo = ADC_Get_Sample(0);
  Delay_us(10);
  codigo = ADC_Get_Sample(10);
  Delay_us(10);
  LATD0_bit = ~LATD0_bit;
}
2.2

Resultado

▶ 2:40

Ahora el pin cambia a unos 1780 Hz: es un poco más rápido. Use ADC_Get_Sample cuando necesite leer más rápido, y ADC_Read cuando prefiera la sencillez.
