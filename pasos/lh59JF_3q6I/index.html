Evasor de obstáculos básico

Se usa el sonar del robot tortuga con el servo fijo al centro (50 Hz, 1,5 ms). Un PIC18F25K50 a 4 MHz maneja los motores con PWM y mide el eco con el Timer1: se da un pulso de 10 µs al disparo, se mide el tiempo del eco y se divide entre 58 para tener centímetros. La distancia se muestra en una terminal virtual. El evasor básico retrocede, espera y gira a la derecha si hay algo a 10 cm o menos, y si no, avanza. No choca, pero no sabe a dónde va; en la parte 2 se le da más inteligencia.

Fase 2

Medir la distancia

2.1

Leer el ultrasónico

▶ 7:01

Se da un pulso de 10 µs al disparo, se arranca el Timer1 y se mide el tiempo del eco. El tiempo en microsegundos dividido entre 58 da centímetros.

float lee_distancia(char *puerto, char pin) {  // lee en el pin especificado
  float calculo;
  // pulso de disparo de 10 us
  disparo = 1;
  Delay_us(10);
  disparo = 0;
  // limpia el contador
  TMR1ON_bit = 0;  // timer quieto
  TMR1L = 0;       // limpia parte baja
  TMR1H = 0;       // limpia parte alta
  TMR1IF_bit = 0;  // limpia la bandera de desbordamiento
  TMR1ON_bit = 1;  // arranca el timer
  // ... espera el eco en el pin indicado (ver video)
  contador = (TMR1H << 8) | TMR1L;  // arma el valor del timer
  calculo = (float)contador * 1.0 / (Frec_real);  // 1.0 prescalador de 1
  calculo = calculo / 58.0;
  return (calculo);
}

▶ 9:19

La función sonar lee la distancia y la manda por serial cada medio segundo. Al acercar el robot a un obstáculo se ven valores como 4,2, 62 o 97 cm.

Fase 3

Evasor

3.1

Algoritmo básico

▶ 10:25

Si la distancia es de 10 cm o menos, retrocede un poco y gira despacio a la derecha; si no, avanza. Los retardos se ajustan.

void basico() {
  sonar();
  if (distancia <= 10) {
    atras(100);
    Delay_ms(50);
    derecha(50);
    Delay_ms(200);
  }
  else {
    adelante(100);
    Delay_ms(200);
  }
}

Prueba
