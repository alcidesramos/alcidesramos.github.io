Transmitir por UART con paridad

Lección 28 del curso, complemento de la 27 a partir de una pregunta en un grupo. Si la terminal espera paridad y el micro no la manda, los datos llegan mal. Los PIC no calculan la paridad solos: se activa la transmisión de 9 bits con TX9 y el noveno bit (TX9D) se calcula contando los unos del dato. Se hacen tres funciones, para un carácter, un texto en variable y un texto constante, y basta cambiar un valor para pasar de paridad par a impar.

Fase 1

Nueve bits

1.1

El problema

▶ 0:00

Se parte del programa de la lección 27, que manda voltaje y temperatura. Si en el Virtual Terminal se pone paridad par o impar, los datos salen con errores porque el micro no está mandando ese bit.

1.2

Activar TX9

▶ 1:09

La paridad indica si el número de unos transmitidos es par o impar. En la hoja de datos, en la parte del UART, el bit TX9 habilita la transmisión de 9 bits: el noveno será la paridad, y se carga en TX9D antes de mandar cada dato.

UART1_Init(9600);
TX9_bit = 1;   // habilita transmitir 9 bits
Fase 2

Funciones con paridad

2.1

Enviar un carácter

▶ 2:13

La función cuenta los unos del dato con un for de 0 a 7 y una máscara. Con el residuo de dividir entre 2 sabe si la cuenta es par o impar, ajusta el bit de paridad, lo pone en TX9D y manda el dato. La variable pari arranca en 1 para paridad par o en 0 para impar.

// para paridad par (even)
void UART1_Write_pa(char dat_)
{
  char cont_, pari, p_cont = 0;
  pari = 1;   // 1 paridad par (even), 0 impar (odd)
  for (cont_ = 0; cont_ <= 7; cont_++)
  {
    if ((dat_ & 1 << cont_) != 0) p_cont++;
  }
  if (p_cont % 2 != 0) pari = ~pari;   // división por residuo
  TX9D_bit = pari;
  UART1_Write(dat_);
}
2.2

Textos y constantes

▶ 4:21

Con la misma idea de la lección 27, una función manda textos en variable y otra textos constantes, letra por letra, usando la función con paridad.

void UART1_Write_Text_pa(char *info)
{
  while (*info) UART1_Write_pa(*info++);
}

void UART1_Write_Text_pa_const(const char *info)
{
  while (*info) UART1_Write_pa(*info++);
}
2.3

Usarlas en el programa

▶ 5:27

Se cambian las llamadas del programa por las nuevas: constante con paridad para textos fijos y texto con paridad para lo que arma sprintf. Con el terminal en la misma paridad los datos llegan bien.

Uart1_write_text_pa_const("INICIANDO\r\n");

sprintf(texto, "Voltaje=%4.2f V\r\n", voltaje);
UART1_Write_Text_pa(texto);
2.4

Cambiar a impar

▶ 5:59

Para pasar de paridad par a impar solo se cambia el valor inicial de pari en la función y se configura el terminal igual. Si no coinciden, vuelven los errores.
