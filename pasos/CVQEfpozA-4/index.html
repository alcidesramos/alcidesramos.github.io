Barco por XBee: receptor con PIC18F2550

Video extra (3.1) de la serie del barco controlado con un joystick USB, LabVIEW y módulos XBee. Se pasa el receptor a un PIC18F2550 en MikroC: se agregan la librería de servos (hasta ocho servos con un solo timer) y la librería serial, se arma una interrupción global que atiende ambas, y la trama que llega se recibe con una máquina de estados. En el programa principal se procesa la trama y se mueven los servos de dirección y velocidad.

Fase 1

Proyecto y librerías

1.1

Por qué un 3.1

▶ 0:01

Varios pidieron el receptor con un PIC18F, así que se hace la versión en MikroC con el PIC18F2550. Las librerías de servos y serial ya se vieron en otros videos; aquí se juntan.

1.2

Reloj

▶ 1:38

Se trabaja con el cristal de 20 MHz. Con PLL podría ir a 48 MHz, pero Proteus a veces falla con simulaciones muy rápidas.

1.3

Agregar las librerías

▶ 2:12

Se agregan al proyecto la librería de servos y la serial, y sus cabeceras se pegan al inicio del programa. También se incluye la de conversiones porque se necesita para pasar texto a número.

1.4

Pines de los servos

▶ 3:20

La librería maneja hasta ocho servos. El truco para no gastar pines es dejar los servos que no se usan todos en un mismo pin libre. Aquí el servo 0 es la dirección y el 1 la velocidad.

Fase 2

Interrupciones

2.1

Una interrupción global

▶ 4:24

El PIC18 tiene un vector de interrupción de alta prioridad. Dentro se llama primero la rutina de los servos y luego la serial.

void interrupciones() iv 0x0008 ics ICS_AUTO {
  servos_interrupcion();
  interrupcion_serial();
}
2.2

Configurar el serial

▶ 4:59

config_serial() inicia el UART a la velocidad deseada y habilita la interrupción de recepción. Si se quiere más velocidad solo se cambian los baudios.

2.3

Máquina de estados

▶ 6:37

interrupcion_serial() espera la 'I', luego la 'N', luego el '='; después guarda cada byte en Trama_rx1 hasta que llega el '*'. Ahí apaga la recepción y levanta flag_rx1. Si un carácter no corresponde, vuelve al estado inicial.

Fase 3

Programa principal

3.1

Configuración

▶ 7:11

Todo digital, puertos B y C como salida excepto RC7 (RX), interrupciones de periféricos, serial, servos con pulso de 1 a 2 ms, ambos servos en cero y por último GIE.

ADCON1 = 0b1111;
TRISC = 0; TRISB = 0;
TRISC7_bit = 1;
INTCON = 0b01000000;
config_serial();
init_servos(1.0, 2.0);
servo_valor(dir, 0);
servo_valor(vel, 0);
GIE_bit = 1;
3.2

Procesar la trama

▶ 7:43

Cuando flag_rx1 vale 1 se procesa la trama y se mueven los servos. Luego se baja la bandera, se limpia el vector y se reinicia la recepción con CREN.

if (flag_rx1 == 1) {
  procesa_rx1();
  flag_rx1 = 0;
  memset(Trama_rx1, 0, 50);
  CREN_bit = 0; CREN_bit = 1;
}
3.3

Traducción del programa

▶ 8:17

El análisis de la trama es el mismo de la versión anterior; solo cambian los nombres de registros. Se agregan dos leds, rojo y verde, para mostrar el sentido de la marcha.

3.4

Prueba con el joystick

▶ 9:23

Desde LabVIEW se mueve el joystick: el servo de dirección y el de velocidad responden y se encienden los leds según el sentido.
