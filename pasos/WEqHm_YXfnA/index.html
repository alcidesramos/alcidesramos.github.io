Diseñar la interfaz Nextion

Las pantallas Nextion son pantallas táctiles HMI: la interfaz se diseña en el PC con Nextion Editor y el microcontrolador solo envía y recibe órdenes por el puerto serial. Además, el editor permite simular la pantalla sin tenerla. En esta primera parte se crea el proyecto, se genera una fuente, se cargan las imágenes y se arman dos páginas con los objetos que después controlará un PIC o un Arduino.

▶ Ver el video completo (18:04) Empezar el paso a paso
  • Nextion Editor
  • Pantalla Nextion NX3224T024 de 2,4 pulgadas (opcional: se puede simular)
  • Imágenes de 320 × 240 píxeles para fondos, aguja, LED, interruptor y termómetro

Fase 1

El proyecto

1.1

Modelo de pantalla

▶ 0:32

File, New y se elige el modelo: hay pantallas Basic, Enhanced e Intelligent, de 2,4 a 9 pulgadas. En el video se usa la NX3224T024 (320 × 240) y se escoge la orientación.

1.2

Generar una fuente

▶ 2:18

Para mostrar texto hay que crear al menos una fuente con el generador de fuentes (Tools, Font Generator): se elige el tamaño (16) y el tipo de letra y se agrega al proyecto.

1.3

Cargar las imágenes

▶ 2:54

Se agregan las imágenes en la pestaña Picture. La pantalla es de 320 × 240 píxeles, así que los fondos deben tener ese tamaño. Cada imagen queda con un número que luego se usa en los objetos.

Fase 2

Página 0: velocímetro

2.1

Fondo y botón para cambiar de página

▶ 5:51

Cada pantalla es una página (aquí pa0 y pa1). A la página 0 se le pone una imagen de fondo y un botón «SIGUIENTE» que llevará a la página 1; se le cambian los colores normal y presionado.

2.2

Pulsador de dos estados

▶ 7:31

Con un Dual-state button se pone un interruptor que en lugar de color sólido usa dos imágenes: una para encendido y otra para apagado. Al tocarlo en la pantalla se le enviará una orden al micro.

2.3

Aguja del velocímetro

▶ 8:08

Un objeto Gauge hace de aguja encima del dibujo del velocímetro, con fondo de imagen recortada (crop image) para que no tape el dibujo. Su valor es un ángulo de 0 a 360, así que no coincide con la escala del dibujo y hay que linealizar el valor que envía el micro. Se le da un nombre fácil (z0).

2.4

Valor digital

▶ 10:23

Debajo se pone un objeto de número o texto para mostrar la velocidad en digital, también sobre la imagen de fondo.

Fase 3

Página 1: termómetro

3.1

Termómetro con barra de progreso

▶ 12:45

En la página 1 se pone otro fondo, un botón para volver a la página anterior y una Progress bar vertical que usa dos imágenes: el termómetro vacío y el termómetro lleno. Al cambiar su valor se ve subir el mercurio. También se agrega un valor digital de temperatura.

3.2

LED que controla el micro

▶ 15:05

Un objeto Picture hace de LED: el micro cambia su imagen entre la del LED encendido y la del LED apagado para dar una alerta.

3.3

Slider

▶ 15:41

Un Slider horizontal con imágenes permite manejar algo deslizando el dedo, por ejemplo la velocidad de un motor, y un número muestra el valor que se está enviando.

3.4

Interfaz completa

▶ 17:28

Con esto queda la interfaz completa. En la siguiente parte se programa el microcontrolador para enviar datos a la pantalla y recibir sus órdenes.
