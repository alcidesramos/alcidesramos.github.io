Leer un encoder de cuadratura

Un encoder de cuadratura da dos señales desfasadas, A y B. Comparando la lectura actual con la anterior se sabe el sentido de giro y se cuentan los pasos. Primero se hace en el while (sirve, pero se pierden pasos si hay retardos), luego con una interrupción de timer cada 5 ms y por último con la interrupción por flanco en RB0, alternando subida y bajada: la forma más precisa.

Fase 1

Cómo funciona

1.1

Señales A y B

▶ 0:34

El encoder entrega dos señales cuadradas. Según cuál va adelante se sabe si gira a la derecha o a la izquierda, y cada cambio es un paso. Se usan en motores, robots y perillas digitales.

1.2

Actual y anterior

▶ 1:41

Se toma la lectura anterior (2 bits), se corre dos posiciones a la izquierda y se le agrega la actual. El número de 4 bits que resulta dice el sentido: hay cuatro combinaciones para cada lado.

Fase 2

Método 1: en el while

2.1

Circuito

▶ 3:57

El encoder va a RB0 y RB1, el LCD al puerto C y el motor se mueve solo con el L293D para probar.

2.2

Variables

▶ 6:29

pulsos es signed int porque cuenta hacia arriba y hacia abajo. Se guardan los bits actuales, los anteriores y el armado. Se activa la librería del LCD y las conversiones.

2.3

Lectura

▶ 9:27

Se leen A y B, se arma el número con la lectura anterior y se compara con las combinaciones de cada sentido. El sentido real depende de cómo esté conectado el encoder.

sbit encoder_A at portb.b0;
sbit encoder_B at portb.b1;
signed int pulsos = 0;
char bits_actual = 0, bits_anterior = 0, bits_armado = 0;

while (1) {
  bits_actual = (encoder_A << 1) | encoder_B;
  bits_armado = (bits_anterior << 2) | bits_actual;
  if ((bits_armado == 13) || (bits_armado == 4) || (bits_armado == 2) || (bits_armado == 11)) pulsos++;
  if ((bits_armado == 14) || (bits_armado == 7) || (bits_armado == 1) || (bits_armado == 8)) pulsos--;
  inttostr(pulsos, texto);
  Lcd_Out(2, 1, texto);
  bits_anterior = bits_actual;
}
2.4

Prueba y problema

▶ 12:22

El LCD cuenta hacia arriba en un sentido y hacia abajo en el otro. Pero si el main tiene retardos o el motor va rápido, se pierden pasos.

Fase 3

Método 2: timer

3.1

Leer cada 5 ms

▶ 13:27

Con Timer Calculator se genera una interrupción de Timer1 cada 5 ms y la lectura se pasa dentro de ella. En el main solo queda mostrar el valor. Hay que llamar la función que configura el timer antes del while.

Ahora se puede poner un retardo de 500 ms en el main y la cuenta sigue bien.

Fase 4

Método 3: flancos

4.1

Mirar el flanco

▶ 17:31

Cuando A tiene un flanco, si A y B son iguales el motor va hacia un lado y si son distintos hacia el otro. Si se detectan tanto los flancos de subida como los de bajada se aprovecha toda la señal.

4.2

Interrupción por RB0

▶ 20:19

Se configura la interrupción externa empezando por flanco de bajada y se habilitan las interrupciones. En cada interrupción se compara A con B y luego se invierte el flanco a detectar.

void interrupt() iv 0x0004 ics ICS_AUTO {
  if (INTF_bit == 1) {
    if (PORTB.RB1 == PORTB.RB0) pulsos++;
    else pulsos--;
    INTEDG_bit = ~INTEDG_bit;   // cambia el flanco a detectar
    INTF_bit = 0;
  }
}
4.3

Resultado

▶ 22:05

Cuenta igual, pero en el mismo instante en que ocurre cada flanco. Es la forma más precisa y la base para el control de posición con PID.
