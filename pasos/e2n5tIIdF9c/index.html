Tarjeta entrenadora con PIC18F2550

El esquema en Proteus muestra el PIC18F2550 con su conector USB, el cristal, el reset, LEDs en el puerto B y conectores para serial, PWM, entradas análogas y digitales. Un jumper elige si la tarjeta trabaja a 5 V o a 3.3 V. El micro tiene un bootloader USB, así que se programa sin programador: se crea el proyecto en MikroC, se carga el esquema de configuración y se graba un parpadeo de todo el puerto B.

  • PIC18F2550 con bootloader USB
  • Cristal de 20 MHz
  • Conector USB, diodos 1N4001, regulación a 3.3 V y jumper de selección
  • LEDs, pulsador de reset y conectores
  • MikroC PRO for PIC
  • Proteus para el esquema

Fase 1

El diseño

1.1

Micro y USB

▶ 0:00

El PIC18F2550 va directo al conector USB (D+ y D-), con su condensador en VUSB, el cristal en OSC1 y OSC2 y un pulsador de reset en MCLR. Los LEDs van en el puerto B con sus resistencias.

1.2

Alimentación

▶ 1:00

La tarjeta se alimenta del USB. Con diodos y un jumper se elige si VDD es 5 V o 3.3 V, para poder conectar módulos de 3.3 V.

1.3

Conectores

▶ 2:00

Hay conectores para el serial (TX y RX), las salidas PWM, las entradas análogas (AN0 a AN4) y los pines digitales del puerto B, cada uno con VDD y GND al lado.

1.4

Tarjeta armada

▶ 3:50

Así queda la tarjeta: el micro en el centro, el USB abajo y los conectores marcados alrededor.

Fase 2

Programarla

2.1

Proyecto

▶ 5:00

Proyecto nuevo con el PIC18F2550. Como el bootloader trabaja con el PLL, el reloj del proyecto es 48 MHz aunque el cristal sea de 20 MHz.

2.2

Configuración

▶ 7:50

En Edit Project se carga el esquema de configuración para cristal de 20 MHz, el mismo que usa el bootloader, para no tener que ajustar bit por bit.

2.3

Parpadeo

▶ 8:51

Todo digital, el puerto B como salida y en el ciclo se invierte LATB cada medio segundo.

void main() {
  ADCON1 = 0b1111;
  TRISB = 0;
  LATB = 0;
  while (1) {
    LATB = ~LATB;
    Delay_ms(500);
  }
}
2.4

Grabar y probar

▶ 10:20

Se compila, se conecta la tarjeta en modo bootloader y se graba el .hex por USB. Los LEDs empiezan a parpadear.
