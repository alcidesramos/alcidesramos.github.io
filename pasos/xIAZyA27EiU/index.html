Primeras interrupciones con Timer Calculator

Lección 31 del curso. Una interrupción es algo que el micro atiende tan rápido que parece que hiciera varias cosas a la vez. Para empezar sin registros se usa Timer Calculator de MikroElektronika, que genera la configuración del Timer1 y la función de interrupción. Con una variable se alarga el tiempo a un segundo, se revisa un pulsador y se arma un juego de luces con un arreglo, todo sin bloquear la recepción serial de la lección 30.

Fase 1

Qué es una interrupción

1.1

El problema

▶ 0:00

En la lección anterior la recepción se quedaba esperando la trama. Si además se quiere que un led parpadee solo o atender otras cosas, se necesitan interrupciones: el micro deja un momento lo que hace, atiende el evento y vuelve.

1.2

Timer Calculator

▶ 1:43

Es un programa gratuito de MikroElektronika que calcula y genera el código de los timers. Se elige el micro, el cristal de 4 MHz, el timer y el tiempo. El Timer0 de 8 bits no alcanza 200 ms a 4 MHz, así que se usa el Timer1 de 16 bits.

Fase 2

Timer1 cada 200 ms

2.1

Código generado

▶ 5:19

Timer Calculator crea dos funciones: InitTimer1, que configura el timer y se llama antes del while, y la función de interrupción, que el micro llama solo. Ahí se recarga el timer y se pone lo que se quiere hacer, por ejemplo cambiar el led.

void InitTimer1(){
  T1CON = 0x21;
  TMR1IF_bit = 0;
  TMR1H = 0x3C;
  TMR1L = 0xB0;
  TMR1IE_bit = 1;
  INTCON = 0xC0;
}

void Interrupt(){
  if (TMR1IF_bit){
    TMR1IF_bit = 0;
    TMR1H = 0x3C;
    TMR1L = 0xB0;
    //Enter your code here
    led = ~led;
  }
}
2.2

Probar

▶ 6:31

El led parpadea solo mientras desde la terminal se siguen mandando tramas como led1=on*. La recepción sigue esperando la trama, pero el parpadeo ya no depende de ella.

2.3

Alargar el tiempo

▶ 7:39

Para un segundo no se cambia el timer: se cuenta cuántas veces entra la interrupción. Cinco veces 200 ms es un segundo.

cuenta++;
if (cuenta >= 5)   /// si va 1 segundo
{
  led = ~led;
  cuenta = 0;
}
Fase 3

Más tareas en la interrupción

3.1

Pulsador

▶ 9:37

Se agrega un pulsador en RA1 y un led en RA0. El puerto A se pone todo digital con ADCON1 y el pin del pulsador como entrada. En cada interrupción se revisa el pulsador, fuera del bloque del segundo para que responda rápido.

sbit led3 at RA0_bit;
sbit sw at RA1_bit;

// dentro de la interrupcion
if (sw == 0) led3 = 1;
else led3 = 0;
3.2

Sin retardos

▶ 15:24

Dentro de una interrupción no se ponen retardos: la idea es hacer lo necesario rápido y volver al programa principal.

3.3

Juego de luces

▶ 16:29

Se crea un arreglo con los patrones del juego de luces y una variable que recorre las posiciones. En cada interrupción se saca un patrón por el puerto B y se pasa al siguiente; al llegar al último se vuelve a cero.

char luces[] = {0b00000001, 0b00000010, 0b00000100, 0b00001000,
                0b00010000, 0b00100000, 0b01000000, 0b10000000};
char cuenta1 = 0;

// dentro de la interrupcion
PORTB = luces[cuenta1];
cuenta1++;
if (cuenta1 > 7) cuenta1 = 0;   // 7 es el numero de efectos empezando en cero
3.4

Cambiar la base de tiempo

▶ 22:26

Para que las luces vayan más rápido se baja el timer a 100 ms y, para que el led siga en un segundo, la cuenta pasa de 5 a 10. Así varios procesos con tiempos distintos salen de un solo timer.
