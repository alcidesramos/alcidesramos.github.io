Detecta colores con el TCS34725

Se conecta el sensor de color TCS34725 al STM32F411 por I2C (solo VIN, GND, SDA y SCL), se configura el I2C en Fast Mode a 400 kHz y el USART1 a 9600, y se usa una librería de terceros adaptada para elegir el I2C. Con getRGB se obtienen rojo, verde y azul y se envían por serial cada 600 ms. Se prueba acercando objetos verdes, rojos, azules y amarillos.

  • STM32F411 (Black Pill)
  • Módulo sensor de color TCS34725

Fase 1

Conexión del sensor

1.1

Pines del TCS34725

▶ 0:00

Conecta Vin a 5 V, GND a tierra, SDA y SCL al I2C del micro. El pin LED no se conecta: así el LED del módulo queda siempre encendido. Si trabajas con batería puedes llevarlo a un pin del micro y apagarlo con un 0 cuando no estés leyendo. El pin INT es para interrupciones y tampoco se usa.

Fase 2

Configurar el proyecto

2.1

USART1 a 9600

▶ 1:45

Crea el proyecto (COLOR_CANAL) y activa USART1 en modo Asynchronous a 9600 baudios para enviar los datos del color.

2.2

I2C1 en modo rápido

▶ 2:05

Activa I2C1 y en Parameter Settings cambia I2C Speed Mode a Fast Mode (400 kHz); este sensor lo necesita así. Guarda para generar el código.

2.3

Librerías e includes

▶ 2:23

Crea la carpeta Librerias, agrégala al include path y copia TCS34725.c/.h y uart.c/.h. En main.c inclúyelas junto con las librerías estándar.

/* USER CODE BEGIN Includes */
#include "uart.h"
#include "TCS34725.h"

#include "stdio.h"
#include "stdint.h"
#include "stdlib.h"
#include "string.h"
/* USER CODE END Includes */
2.4

Elegir el I2C en la librería

▶ 3:35

La librería original escribía siempre por el I2C2. Se adaptó para que en TCS34725.h indiques el handle que uses (hi2c1, hi2c2 o hi2c3); el .c usa ese define en HAL_I2C_Master_Transmit y en las lecturas.

Fase 3

Leer los colores

3.1

Variables

▶ 4:08

Crea un buffer de texto para el serial y las tres variables de color.

/* USER CODE BEGIN PV */
char texto[100];
int rojo, verde, azul;
/* USER CODE END PV */
3.2

Probar el serial

▶ 5:00

Antes de usar el sensor comprueba la comunicación enviando un mensaje al iniciar.

/* USER CODE BEGIN 2 */
uartx_write_text(&huart1, "INICIANDO\r\n");
/* USER CODE END 2 */
3.3

Leer y enviar cada 600 ms

▶ 6:02

getRGB guarda en ese orden rojo, verde y azul. Luego se formatean y se envían por el serial.

while (1)
{
    getRGB(&rojo, &verde, &azul);
    sprintf(texto, "R=%d   V=%d    A=%d\r\n\r\n", rojo, verde, azul);
    uartx_write_text(&huart1, texto);
    HAL_Delay(600);
}
Fase 4

Prueba

4.1

Valores en reposo

▶ 8:20

Sin objeto delante el sensor da valores parecidos en los tres canales (en el video unos 76, 95 y 84).

4.2

Verde, rojo, azul y amarillo

▶ 8:30

Con un objeto verde sube el canal verde (a 116), con uno rojo el rojo sube a 213 y con uno azul el azul sube a 105 según la tonalidad. El amarillo sube rojo y verde mientras el azul queda bajo. Con esos valores se puede hacer un algoritmo que compare los canales para identificar el color.
