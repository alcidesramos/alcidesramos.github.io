Códigos de 7 segmentos sin el editor de MikroC

Video corto para quienes no les abre el editor de 7 segmentos de MikroC. Se usa un programa externo pequeño (7-Segment, de Hannes) que permite marcar los segmentos y copiar el código en decimal o hexadecimal para la tabla del display.
