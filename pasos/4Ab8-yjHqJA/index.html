Programador de PIC con Arduino

Para programar un PIC por ICSP se necesitan VPP entre 12,5 y 14 V, 5 V, tierra, un pin de datos y uno de reloj. Con solo 5 V del Arduino se hace una fuente elevadora (boost) con una bobina, un transistor y dos zener de 6,8 V para fijar unos 13 V. La señal debe ser de más de 50 kHz, así que se sube la frecuencia del PWM del Timer0 a 62,5 kHz. Pero el Timer0 lo usa delay(): al cambiarlo los retardos se vuelven 64 veces más rápidos, y se corrige con una función propia. VPP se activa con un par de transistores (2N3904 y 2N3906). Después se arman las funciones para mandar comandos de 6 bits y datos de 14 bits según la hoja de programación del PIC16F84A y se hace una primera prueba.

Fase 1

El hardware

1.1

Qué necesita un PIC para programarse

▶ 1:07

Todos los PIC se programan con cinco pines: VPP (entre 12,5 y 14 V), 5 V, tierra, datos y reloj. Algunos tienen programación en bajo voltaje, pero viene desactivada y para activarla hay que programarlos primero con alto voltaje.

1.2

Activar VPP

▶ 2:15

Los 13 V no se pueden manejar directo con un pin del Arduino: se usa un arreglo de un 2N3904 y un 2N3906, de modo que con 5 V o 0 V en el pin se pone VPP en unos 13 V o en 0.

1.3

Fuente elevadora

▶ 3:21

Para sacar 13 V desde 5 V se usa una fuente conmutada tipo boost: una bobina, un transistor que conmuta con una señal pulsante de más de 50 kHz, un diodo y un condensador.

Si no se regula, el voltaje sigue subiendo (14, 15, 16 V…). Por eso se ponen dos zener de 6,8 V en serie, que son fáciles de conseguir, para fijar unos 13 V.

1.4

La tarjeta

▶ 8:23

La bobina debe ser de 330 µH o más (aquí una de 680 µH, de las mismas que usa el PICkit 2). Este es el montaje real de la fuente.

Fase 2

La frecuencia del PWM

2.1

Subir la frecuencia a 62,5 kHz

▶ 9:29

Con analogWrite el pin 5 da unos 976 Hz, muy poco para la fuente. Cambiando el preescalador del Timer0 sube a 62,5 kHz.

2.2

El problema con delay()

▶ 14:48

El Timer0 también lo usan delay y millis. Con el cambio, el LED que debía titilar cada segundo se queda prendido: los retardos ahora van 64 veces más rápido. La solución es una función propia que multiplica el tiempo por 64.

void setup() {
  pinMode(5,OUTPUT);
  TCCR0B = TCCR0B & B11111000 | B00000001;
  analogWrite(5,127);
  pinMode(13,OUTPUT);
}

void loop() {
  digitalWrite(13,1);
  delay_ms(1000);
  digitalWrite(13,0);
  delay_ms(1000);
}

3.2

Mandar comandos y datos

▶ 20:54

Un comando son 6 bits. Un dato se manda con un bit de inicio en 0, los 14 bits del dato y un bit de parada. Cada bit se escribe con el reloj.

char lee_un_bit (unsigned int variable, char bit1)
{
  if ((variable & (1 << bit1))>0) return (1);
  else return (0);
}

void manda_comando(char coma)
{
  char cont;
  for (cont=0;cont<=5;cont++)
  {
    if (lee_un_bit(coma,cont)==0) write_bit(0);
    else write_bit(1);
  }
}

void manda_dato(unsigned int dat)
{
  signed char cont;
  write_bit(0); //necesario
  for (cont=0;cont<=13;cont++)
  {
    if (lee_un_bit(dat,cont)==0) write_bit(0);
    else write_bit(1);
  }
  // ... bit de parada
}
3.3

Programar una palabra

▶ 22:32

Para programar: se carga el dato con el comando de carga, se manda el comando de borrar y programar, se espera el tiempo de programación y se incrementa la dirección.

void programa_dato(unsigned int dato)
{
  inicio();
  manda_comando(load_prog);
  manda_dato(dato);
  manda_comando(begin_ere_prog);
  delay_ms(20);
  manda_comando(inc_dir);
}
3.4

Primera prueba

▶ 24:10

En el setup se configuran los pines, la frecuencia de 62,5 kHz, VPP en cero y el serial (que luego se comunicará con una aplicación en Delphi), y se programan dos palabras de prueba.

Al leer el PIC con otro programador aparecen 2815 y 2830 en las dos primeras posiciones: la escritura funciona. En la siguiente entrega se arma el programador completo.

void setup()
{
  // pin PWM1
  pinMode(5,OUTPUT);
  pinMode(vpp_,OUTPUT);
  pinMode(reloj_,OUTPUT);
  pinMode(dato_,OUTPUT);
  pinMode(led,OUTPUT);
  pinMode(8,OUTPUT);

  TCCR0B = TCCR0B & B11111000 | B00000001; // coloca la frecuencia del pwm en 62500

  vpp(0);// quita los 12 voltios de vpp poniendolo en cero
  analogWrite(5,127); //crea una onda con ciclo util de 50%
  digitalWrite(led,LOW);

  Serial.begin(9600);
  inicio();
  programa_dato(0x2815);
  programa_dato(0x2830);

  resetpic();
}
