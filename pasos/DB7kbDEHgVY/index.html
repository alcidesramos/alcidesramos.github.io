Hola mundo en la Blue Pill · parte 1

Hola mundo con la Blue Pill, esta vez todo desde STM32CubeIDE sin abrir CubeMX aparte. Se configura el cristal, el reloj a 72 MHz y el LED de PC13, y se programa de dos formas: con un cable USB-serial usando el bootloader de fábrica, y con el ST-Link desde el IDE.

▶ Ver el video completo (13:13) Empezar el paso a paso
  • Tarjeta: Blue Pill (STM32F103C8T6, cristal 8 MHz, LED en PC13)
  • Para programar: cable USB-serial (CH340, PL2303, FT232, CP2102…) o ST-Link V2
  • Software: STM32CubeIDE, STM32CubeProgrammer

Fase 1

Proyecto en STM32CubeIDE

1.1

Nuevo proyecto STM32

▶ 1:24

File → New → STM32 Project, busca STM32F103C8T6, dale nombre (basico1) y desmarca la ubicación por defecto para guardarlo en tu carpeta.

1.2

LED en PC13 y cristal

▶ 3:41

Según el pinout de la Blue Pill, el LED está en PC13: GPIO_Output con etiqueta led. En RCC → HSE: Crystal/Ceramic Resonator (cristal de 8 MHz).

1.3

Reloj a 72 MHz

▶ 4:15

En Clock Configuration, HCLK a 72 MHz, el máximo del F103. Al guardar el .ioc se genera el código.

Fase 2

El código

2.1

Parpadeo

▶ 5:18

En Core/Src/main.c, dentro del while. Si el IDE no reconoce led_Pin, compila una vez primero.

/* USER CODE BEGIN WHILE */
while (1)
{
  HAL_GPIO_TogglePin(led_GPIO_Port, led_Pin);
  HAL_Delay(200);
  /* USER CODE END WHILE */
Fase 3

Programar por serial

3.1

Conectar el cable USB-serial

▶ 2:31

Solo hacen falta TX y RX del cable a PA10 (RX1) y PA9 (TX1). Si la tarjeta se alimenta por su USB del mismo PC, no hace falta unir GND ni positivo. Instala el driver del cable que tengas.

3.2

BOOT0 en 1 y cargar con CubeProgrammer

▶ 7:42

Pasa el jumper de BOOT0 (el de afuera) a 1 y reinicia: el micro entra en modo bootloader. En CubeProgrammer escoge UART, el puerto COM (míralo en el Administrador de dispositivos), Connect, abre el .elf de la carpeta Debug y Download. Luego regresa BOOT0 a 0 y reinicia.

Fase 4

Programar con ST-Link

4.1

Desde el IDE con Run

▶ 9:55

Conecta el ST-Link y pulsa Run. La primera vez pregunta el depurador: escoge ST-LINK. Si el micro es original, programa directo sin desconectar nada. Cambia el retardo a 1200 para ver que sí cambió.

HAL_Delay(1200);
4.2

Si el micro no es original

▶ 12:08

El IDE no deja depurar ni programar un clon. Usa CubeProgrammer con ST-Link → Connect, abre el archivo y Download.
