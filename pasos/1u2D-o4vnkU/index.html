Sensor de temperatura interno del STM32

El STM32 tiene un sensor de temperatura conectado a un canal interno del ADC. Proteus no lo simula (siempre marca 25 °C), así que la práctica se hace en una Black Pill real. Se configura el ADC1 con dos conversiones regulares: el canal 0 (un potenciómetro) y el canal del sensor de temperatura. Con las constantes V25 y Avg_Slope del datasheet y la fórmula del manual de referencia se calcula la temperatura en °C y se envía por la UART cada segundo.

Fase 1

La fórmula

1.1

Manual de referencia y datasheet

▶ 0:33

La fórmula está en el manual de referencia (RM0368, sección del ADC, Reading the temperature). Las constantes de cada micro están en su datasheet: buscando Avg_Slope aparecen los valores.

  • Avg_Slope = 2.5 mV/°C (0.0025 V/°C)
  • V25 = 0.76 V (voltaje del sensor a 25 °C)
  • Temperatura (°C) = ((Vsense − V25) / Avg_Slope) + 25
Fase 2

Configuración en CubeMX

2.1

Reloj y UART

▶ 2:15

Proyecto nuevo con el STM32F401CCUx. En RCC se activa el cristal (HSE) y en Clock Configuration se lleva el PLL a 84 MHz. USART1 en modo asíncrono; como es un montaje físico se puede usar 115200 baudios. El LED de la tarjeta (PC13) queda como salida con la etiqueta LED.

2.2

ADC1 con dos canales

▶ 3:25

En Analog, ADC1 se marca IN0 y Temperature Sensor Channel. En User Constants se agrega ADC1 para que la librería lo reconozca.

En Parameter Settings: Number Of Conversion = 2, Scan Conversion habilitado y Discontinuous Conversion con 1 conversión. Rank 1 = Channel 0 y Rank 2 = canal del sensor de temperatura.

El manual pide un tiempo de muestreo mayor que el mínimo del datasheet para el sensor de temperatura (unos 10 µs). Si la lectura sale inestable, sube el Sampling Time del Rank 2 a 480 ciclos.

3.2

Variables

▶ 7:54

Una cadena para el texto, el voltaje del pin A0, el voltaje del sensor y la temperatura calculada. Faltaba declarar codigo, que guarda el valor del ADC.

/* USER CODE BEGIN PV */
float voltaje, temp_voltios, temp_interna;

uint16_t codigo;
3.3

Lectura y cálculo en el while

▶ 9:36

La primera lectura del ADC es el canal 0 y la segunda es el sensor de temperatura. Ambas se pasan a voltaje con 3.3/4095 y la segunda se convierte a grados con la fórmula del manual.

uartx_write_text(&huart1, "Iniciando\r\n");

while (1)
{
  // leer el voltaje de AN0
  codigo = ADC_Read();
  voltaje = codigo * 3.3 / 4095.0;

  // leer la temperatura interna del micro
  codigo = ADC_Read();
  temp_voltios = codigo * 3.3 / 4095.0;   // voltaje del sensor interno

  // datos sacados del datasheet
  float const V25 = 0.76;          // V (voltaje típico a 25 °C)
  float const Avg_Slope = 0.0025;  // V/°C
  // fórmula sacada del manual de referencia
  temp_interna = ((temp_voltios - V25) / Avg_Slope) + 25;

  sprintf(texto, "Volt=%.2f\r\nTEMP=%.2f\r\n\r\n", voltaje, temp_interna);
  uartx_write_text(&huart1, texto);
  HAL_Delay(1000);
}

El orden importa: con Discontinuous Conversion cada ADC_Read() convierte el siguiente Rank, así que la primera lectura es AN0 y la segunda es la temperatura.

Fase 4

Prueba en la tarjeta

4.1

Grabar y ver los datos

▶ 11:19

Se graba con STM32CubeProgrammer y se abre el puerto serial con Hercules. Al resetear aparece Iniciando y luego el voltaje de AN0 (de 0 a 3.3 V moviendo el potenciómetro) y la temperatura del micro, que arranca en unos 35 °C y baja mientras se estabiliza.

Al tocar el microcontrolador con el dedo la temperatura sube a unos 38 °C.

4.2

¿Para qué sirve?

▶ 11:56

Para vigilar si el micro se está calentando demasiado en un proyecto y decidir si hace falta un disipador o ventilador. Si se calienta mucho puede resetearse o dañarse.
