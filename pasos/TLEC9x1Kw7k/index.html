Librería para pantallas HMI Nextion

Se muestra la librería Nextion.c/.h para STM32, que se apoya en la recepción serial por DMA con detección de línea inactiva (UARTRX). El micro lee un potenciómetro y la temperatura interna con ADC por DMA y los envía a la pantalla, cambia la imagen de un LED según un pulsador, grafica en una waveform, y recibe órdenes de la Nextion: encender un LED, activar la gráfica, fijar el PWM y recibir números de 2 o 4 bytes y textos. Se prueba con el simulador del Nextion Editor.

Fase 1

El proyecto

1.1

Periféricos usados

▶ 0:35

El ADC1 lee por DMA dos canales: el potenciómetro y el sensor de temperatura interno. Un timer genera el PWM, el LED y el pulsador de la tarjeta son E/S digitales, el USART1 va a la Nextion y el USART2 es solo de monitoreo.

1.2

USART de la Nextion con DMA

▶ 1:39

El USART1 va a 9600 baudios con DMA RX e interrupción global habilitados, igual que en la librería de recepción de varios UART (clase 103) y en la del GPS.

Fase 2

Configurar la librería

2.1

Puerto y buffer

▶ 2:45

En Nextion.c indica el UART de la pantalla y crea la estructura UARTNEXTION con el handle, la instancia y el tamaño del buffer (100 caracteres; amplíalo si tus tramas son más largas). nextion_text guarda los textos leídos.

//COLOCAR UART A USAR
extern UART_HandleTypeDef huart1;
//defina uart y tamaño para la nextion
UARTRXS UARTNEXTION = {&huart1, USART1, 100};

//si se quieren leer mas o menos texto poner tamaño
char nextion_text[50];
2.2

Funciones disponibles

▶ 3:19

La librería trae funciones para inicializar y reinicializar la recepción, enviar un valor o un texto a un objeto, enviar un punto a una gráfica, leer una orden de texto, leer 1, 2 o 4 bytes y leer una variable de texto. Nextion_interrup es la interrupción de llegada de datos.

En UART_INT_DMA_IDLE.c incluye Nextion.h y llama a Nextion_interrup dentro de HAL_UARTEx_RxEventCallback. Si la Nextion ya está en ese UART, no hace falta la interrupción genérica para el mismo puerto.

void nextion_Send_Graf(uint8_t id, uint8_t canal, uint16_t valor)
{
    char nexti[100];
    sprintf(nexti, "add %u,%u,%u\xFF\xFF\xFF", id, canal, valor);
    uartx_write_text(UARTNEXTION.huart, nexti);
}

// UART_INT_DMA_IDLE.c
#include "Nextion.h"

void HAL_UARTEx_RxEventCallback(UART_HandleTypeDef *huart, uint16_t sizex)
{
    Nextion_interrup(huart, sizex);
}
Fase 3

La interfaz en Nextion Editor

3.1

Objetos de la página

▶ 4:24

La página pa0 tiene un termómetro (barra te), un número con decimales tef, un gauge para el voltaje (vol y vf), la imagen led1, una waveform, interruptores, el PWM y una página de mantenimiento. Los gráficos se recortan de LabVIEW o de cualquier editor.

Los números con decimales no son flotantes: con ws1 = 1 decimal se envía el valor × 10.

3.2

Calibrar los indicadores

▶ 7:06

El termómetro y el gauge no coinciden exactamente con el valor que se les manda. Se toman varios puntos (valor deseado vs valor que hay que enviar), se grafica en Excel y se saca la recta. El gauge es circular, así que necesita dos rectas: una para menos de 1 V y otra para 1 V o más.

Fase 4

Enviar datos a la pantalla

4.1

Voltaje y temperatura

▶ 10:00

Se calcula la temperatura interna con los datos del datasheet (V25 = 0,76 V, pendiente 2,5 mV/°C), se corrigen los valores con las rectas de calibración y se envían a cada objeto como pagina.objeto.propiedad=.

voltaje1 = adc_codigo[0]*3.3/4095.0;
voltaje2 = adc_codigo[1]*3.3/4095.0;
float voltajex;
if (voltaje1 >= 1) voltajex = 80.429*voltaje1 - 71.357;
else voltajex = 80*voltaje1 + 290;

//datos sacados del datasheet
float const V25 = 0.76;          // V (Typical voltage at 25°C)
float const Avg_Slope = 0.0025;  // V/°C
temperatura = ((voltaje2 - V25) / Avg_Slope) + 25;
float temperatura1 = 0.845*temperatura + 11.836;

//envia voltaje
Nextion_Send_Valor("pa0.vol.val=", voltajex);
Nextion_Send_Valor("pa0.vf.val=", voltaje1*10);
//envia la temperatura
Nextion_Send_Valor("pa0.te.val=", temperatura1);
Nextion_Send_Valor("pa0.tef.val=", temperatura*10);

4.3

Gráfica

▶ 12:41

Si la gráfica está activa se envía un punto a la waveform: id del objeto (2), canal (el primero es 0) y el voltaje mapeado de 0–3,3 V a 0–200, la altura de la gráfica.

if (graf == 1)
{
    nextion_Send_Graf(2, 0, map(voltaje1, 0, 3.3, 0, 200));
}
Fase 5

Recibir órdenes de la pantalla

5.1

Procesar los textos

▶ 14:05

Cuando llega una trama de la Nextion se llama a procesa_nextion. Los botones envían textos como sw1=on, sw1=off, graon o graoff desde su evento (print "sw1=on"), y el micro hace lo que corresponda.

void procesa_nextion()
{
    if (Nextion_Read_Text("sw1=on") == 1) PIN_OFF(led);
    else if (Nextion_Read_Text("sw1=off") == 1) PIN_ON(led);

    else if (Nextion_Read_Text("graon") == 1) graf = 1;
    else if (Nextion_Read_Text("graoff") == 1) graf = 2;

    //calcula una variable
    else if (Nextion_Read_Text("pwm1=") == 1)
    {
        uint8_t ancho = Nextion_Read_1Byte();
        PWM_valor(&PWM1, ancho);
    }
    else if (Nextion_Read_Text("setint=") == 1)
    {
        uint16_t numero = Nextion_Read_2Byte();
        sprintf(texto, "\r\nnum1=%d\r\n", numero);
        uartx_write_text(&huart2, texto);
    }
}
5.2

Probar LED, gráfica y PWM

▶ 15:58

En el simulador, el botón enciende y apaga el LED de la tarjeta y el deslizador cambia el ancho de pulso, que se ve en el analizador lógico. El PWM se envía con print pwm1.val de 1 byte porque va de 0 a 100.

5.3

Números de 2 y 4 bytes y textos

▶ 17:07

En la página de valores se envían números de 2 bytes (hasta 65535) o de 4 bytes, o un texto con formato setext=valor/ que se lee con Nextion_Read_TextVar y se convierte con atoi o atof. Así se pueden mandar decimales (PWM de 15,8 %), nombres, la red Wi-Fi o su contraseña.

//lee una variable en forma cadena, debe ir entre = y /
void Nextion_Read_TextVar()
{
    strcpy(nextion_text, strtok(UARTNEXTION.trama_rx, "="));
    strcpy(nextion_text, strtok(0, "/"));
}
