Librerías dinámicas con #ifdef: LiDAR TF-mini

Lección 42 del curso. El sensor LiDAR TF-mini puede entregar la distancia en tramas hexadecimales o como texto. En vez de dos programas, se hace una librería con las dos versiones y el compilador incluye solo la que se elige con un #define. Se explica la trama de cada modo, la interrupción con máquina de estados y el procesamiento de la distancia, y se prueba en un PIC18F2550 con LCD.

Fase 1

La librería del sensor

1.1

Librerías dinámicas

▶ 0:33

Con directivas del preprocesador se decide qué código se compila antes de quemar el micro. Así una sola librería sirve para los dos modos del sensor.

1.2

Variables

▶ 1:38

Una trama de 20 bytes (suficiente para este sensor), contador, bandera y un enum para los estados de la recepción.

unsigned char trama_rx_lidar[20];
unsigned char trama_rx_lidar_cont;
char flag_rx_lidar;
enum tf_estado_ {tf_cabe, tf_cabe1, tf_datos, tf_fin};
unsigned int distancia, fuerza;
float distancia_float;
1.3

Configurar el modo

▶ 2:43

tf_mini_config() inicia el UART a 115200 y limpia la trama. tf_mini_out_hex() y tf_mini_out_str() mandan al sensor el comando de 8 bytes (0x42 0x57 0x02 0x00 0x00 0x00 0x01 ...) que cambia el formato de salida.

Fase 2

Recepción

2.1

Modo hexadecimal

▶ 3:53

La trama empieza con 0x59 0x59. La interrupción espera las dos cabeceras, guarda los siete bytes siguientes y al terminar apaga RCIE y levanta la bandera.

2.2

Modo texto

▶ 5:02

En texto, se espera un fin de línea, se guarda hasta el siguiente '\n' y se agrega el 0 final. Si llegan más de 20 bytes se reinicia para no salirse del vector.

2.3

Procesar

▶ 6:40

En hexadecimal la distancia es la parte alta por 256 más la baja, y la fuerza indica la calidad de la señal. En texto basta con atof.

distancia = ((unsigned int)trama_rx_lidar[1] << 8) + (unsigned int)trama_rx_lidar[0];
fuerza = ((unsigned int)trama_rx_lidar[3] << 8) + (unsigned int)trama_rx_lidar[2];

// modo texto
distancia_float = atof(trama_rx_lidar);
Fase 3

Programa principal

3.1

Incluir la librería

▶ 10:28

Se agrega el archivo tf_mini.c al proyecto (clic derecho, añadir) junto con las librerías de UART y LCD.

3.2

Elegir el modo

▶ 13:15

Arriba se escribe #define tf_hex. Si está, se compila el modo hexadecimal; si se comenta, el modo texto.

#define tf_hex
...
#ifdef tf_hex
  tf_mini_out_hex();
#else
  tf_mini_out_str();
#endif
3.3

Interrupción

▶ 14:19

La interrupción llama a una u otra rutina según el mismo #ifdef, para no quedar esperando al sensor.

void INTERRUPCION() iv 0x0008 ics ICS_AUTO {
#ifdef tf_hex
  tf_mini_interrupcion_hex();
#else
  tf_mini_interrupcion_str();
#endif
}
3.4

Mostrar la distancia

▶ 17:50

Cuando la bandera está activa se procesa la trama, se muestra la distancia en el LCD (entero en hexadecimal, con decimal en texto) y se reactiva la recepción.

if (flag_rx_lidar == 1) {
#ifdef tf_hex
  procesa_lidar_hex();
  sprintf(texto, "DIST=%u", distancia);
#else
  procesa_lidar_str();
  sprintf(texto, "DIST=%4.1f", distancia_float);
#endif
  Lcd_Out(1, 1, texto);
  CREN_bit = 0; CREN_bit = 1;
  RCIF_bit = 0; RCIE_bit = 1;
}
3.5

Prueba

▶ 20:40
