Configurar el DAC con MCC de MPLAB X

Lección 25 del curso, complemento de la 24. MikroC no trae librería para el DAC, pero el MPLAB Code Configurator (MCC) de MPLAB X sí genera su código. Con el mismo circuito del PIC16F1705 (potenciómetro en RA1, DAC en RA0) se crea un proyecto en MPLAB X, se configura en MCC el reloj, el DAC de 8 bits y el ADC, se generan los archivos y se escribe el programa con ADC_GetConversion y DAC_SetOutput. Como los compiladores son muy compatibles, ese código sirve de base para llevar las funciones a MikroC.

Fase 1

Configurar con MCC

1.1

El mismo circuito

▶ 0:00

El potenciómetro en RA1 cambia el voltaje del DAC en RA0, como en la lección 24. El ADC es de 10 bits y el DAC de 8, así que se divide entre 4. Se crea un proyecto estándar en MPLAB X para el PIC16F1705 y se abre el MCC.

1.2

Reloj del sistema

▶ 1:43

En System Module se escoge el oscilador interno a 8 MHz, como en el proyecto de MikroC.

1.3

DAC y ADC

▶ 2:18

Se agregan los módulos DAC (8 bits) y ADC desde Device Resources. En el DAC se marca Enable DAC, referencia positiva VDD y negativa VSS, y se habilita la salida DACOUT1. En el ADC se escoge el reloj (FOSC/4) y la justificación a la derecha.

1.4

Pines

▶ 3:26

En Pin Module se revisa que RA0 quede como salida del DAC (DACOUT1) y RA1 como entrada análoga del ADC. Luego se pulsa Generate y MCC crea main.c y los archivos de cada módulo.

Fase 2

El programa

2.1

Leer y escribir

▶ 4:35

En el while del main.c generado se lee el canal con ADC_GetConversion y se escribe el DAC con DAC_SetOutput. Las funciones salen de los archivos que generó MCC.

while (1)
{
    codigo = ADC_GetConversion(channel_AN1);
    DAC_SetOutput(codigo / 4);
    __delay_ms(200);
}
2.2

Llevarlo a MikroC

▶ 6:14

El código generado muestra qué registros hay que configurar. Como XC8 y MikroC son muy compatibles, esa configuración se puede copiar al proyecto de MikroC cuando este no trae librería para el periférico.

En Proteus el DAC funcionó configurando el pin como salida en MCC, aunque MCC advierte que debe ser entrada. Conviene probarlo con el micro físico.
