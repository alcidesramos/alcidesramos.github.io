LabVIEW envía al PIC por USB HID

Es el camino contrario del video anterior. En LabVIEW dos indicadores de aguja dan la velocidad de dos motores (0 a 100) y dos botones prenden LEDs. Todo se une en una trama dat=v1/v2/l1/l2/ que se envía por HID. En MikroC se espera el dato con HID_Read, se busca dat= con strstr y strtok va sacando cada valor separado por /. Las velocidades se escalan a 0-255 para el PWM y los valores 1 o 0 prenden o apagan los LEDs.

  • MikroC PRO for PIC (librerías USB HID, PWM, C_String, C_Stdlib)
  • PIC18F2550
  • LabVIEW con las funciones de HID del video anterior

Fase 2

Programa en MikroC

2.1

Circuito

▶ 8:16

El PIC18F2550 va al conector USB. LED1 está en RB0 y LED2 en RB1; las salidas PWM (RC1 y RC2) van al osciloscopio para ver el cambio de velocidad.

2.2

Configuración

▶ 9:49

Todo digital, RB0 y RB1 como salida para los LEDs, RC1 y RC2 como salida para los PWM, que se inician y arrancan.

ADCON1 = 0b1111;     // todo digital
// salida de los leds
TRISB0_bit = 0;
TRISB1_bit = 0;
// salidas pwm
TRISC1_bit = 0;
TRISC2_bit = 0;
// pwm
PWM1_Init(500);
PWM2_Init(500);
PWM1_Start();
PWM2_Start();
2.3

Descriptor e interrupción

▶ 12:56

Con el HID Terminal (menú Tools) se genera el archivo USBdsc.c y se agrega al proyecto. En la interrupción se llama USB_Interrupt_Proc y se declaran los buffers readbuff y writebuff de 64 bytes.

2.4

Esperar la trama

▶ 17:36

Se habilita el HID y en el ciclo se espera hasta que llegue un dato. Con strstr se revisa que traiga dat=; el primer strtok con = arranca la separación.

2.5

Separar los datos

▶ 20:42

Cada strtok(0, "/") entrega el siguiente valor. Las velocidades se pasan a número y se escalan de 0-100 a 0-255 para el ciclo útil. El tercer y cuarto dato deciden si cada LED se prende.

HID_Enable(&readbuff, &writebuff);
while (1) {
  while (!HID_Read());
  if (strstr(readbuff, "dat=")) {
    strcpy(tramita, strtok(readbuff, "="));  // inicia captura de tokens
    strcpy(tramita, strtok(0, "/"));          // primer dato
    pwm1 = atoi(tramita);
    PWM1_Set_Duty(pwm1*255/100);
    strcpy(tramita, strtok(0, "/"));          // 2 dato
    pwm2 = atoi(tramita);
    PWM2_Set_Duty(pwm2*255/100);
    strcpy(tramita, strtok(0, "/"));          // 3 dato
    pwm1 = atoi(tramita);
    if (pwm1 == 1) led1 = 1; else led1 = 0;
    // el 4 dato igual para led2
  }
}
