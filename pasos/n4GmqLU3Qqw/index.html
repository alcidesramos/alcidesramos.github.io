Timers de 16 y 32 bits con XC16

Se crea el proyecto en MPLAB X para el dsPIC33FJ32MC202 con cristal de 4 MHz y PLL a 80 MHz, y se generan los bits de configuración. El serial se abre con OpenUART1; como putsUART1 a veces falla según la versión, se hace una función propia que escribe byte a byte y espera a que el buffer quede libre. El Timer1 se configura con OpenTimer1 (prescaler 64, PR de 62500) para 100 ms, y la interrupción se habilita a mano con banderas y prioridad. Para 2 segundos se unen Timer2 y Timer3 en 32 bits; como la librería de XC16 no deja hacerlo bien, se configura por registros.

Remapeo y UART

▶ 5:22

Se remapea solo el TX a RP0 y se configura el UART con config1 y config2. El último valor de OpenUART1, 259, sale de la hoja de Excel para 9600 baudios a 80 MHz.

//puertos como salida
TRISB=0x0;

PPSLock;// bloquea configuracion periferico

Función propia para textos

▶ 8:07

putsUART1 a veces no manda bien la cadena. Se hace Uart1_write_text_const, que escribe byte a byte y espera a que el buffer de transmisión quede libre.

void Uart1_write_text_const(const char *info)
{
 while(*info)
 {
    WriteUART1(*info++);
    while (_UTXBF==1);//espera que se envie el dato
 }
}

2.2

Habilitar interrupciones

▶ 14:22

Se da prioridad 3, se limpia la bandera y se habilita la interrupción del Timer1. La función habilita baja la prioridad de la CPU a 0 para que entren todas las de prioridad mayor.

void habilita()
{
 //nivel de prioridad interrupcion CPU //0 habilita interrupciones
 _IPL3=0;
 INTCON1bits.NSTDIS=0; //PARA PODER HACER EL CAMBIO DEBE STAR EN CERO HABILITADO EL ANIDAMIENTO
 _IPL2=0;
 _IPL1=0;
 _IPL0=0;
 _NSTDIS=0; //HABILITA ANINAMIENTO INTERRUPCIONES
}
2.3

Rutina del Timer1

▶ 16:07

La interrupción se declara con __attribute__ y auto_psv. Cambia led1 y limpia la bandera: el LED parpadea cada 100 ms mientras el principal lo hace cada segundo.

void __attribute__((__interrupt__,__auto_psv__)) _T1Interrupt(void)
{
    TMR1=0;
    led1=!led1;
    _T1IF=0;
}

▶ 17:10

Habilitar la interrupción desde OpenTimer1 no funcionó; sí funciona darle la prioridad ahí con T1_INT_PRIOR_3 y habilitar la interrupción a mano.

Fase 3

Timer de 32 bits

3.1

Librería limitada

▶ 18:53

Para 2 segundos ningún prescaler de 16 bits sirve. Se unen Timer2 y Timer3, pero la función de XC16 para eso es muy pobre, así que se configura por registros, como en MikroC.

3.2

Configuración por registros

▶ 20:34

Con prescaler 1, la hoja da PR3 = 1220 (parte alta) y PR2 = 46080 (parte baja). El prescaler y el encendido van en el Timer2 con el bit T32; la interrupción la da el Timer3.

//configuracion timer 32
TMR3=0;
TMR2=0;
PR3=1220;
PR2=46080;
T2CON=0;
//preescalador 1
T2CONbits.TCKPS1=0;
T2CONbits.TCKPS0=0;
//INTERRUPCION CON TIMER 3
//prioridad timer3
_T3IP2=0;
_T3IP1=1;
_T3IP0=0;
//INICIO CON TIMER 2
T2CONbits.T32= 1; //trabaja a 32 bits
T2CONbits.TON=1;//prende el Timer

SetPriorityIntT1(3);
SetPriorityIntT3(3);
_T1IF=0;
_T1IE=1;
_T3IF=0;
_T3IE=1;
habilita();//hABULITA INTERPCIONES
3.3

Prueba final

▶ 22:51

La rutina _T3Interrupt limpia los dos timers y cambia led2. En Proteus un LED va cada 100 ms, otro cada 2 segundos y el principal cada segundo.
