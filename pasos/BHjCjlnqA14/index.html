RFID RC522 con STM32

El RC522 es un lector RFID de 13.56 MHz que se comunica por SPI, I2C o UART; aquí se usa SPI, cuidando no pasar de 10 MHz. Con una librería adaptada de PIC se detecta la tarjeta, se lee su UID y se envía por la UART. Se muestran dos formas de reconocer tags: comparando el UID con vectores guardados (función verifica) y con un algoritmo hash que convierte el UID en un solo número de 32 bits, más fácil de comparar y que ahorra memoria.

Fase 1

Configuración

1.1

El módulo

▶ 0:00

Pines del RC522: VCC (3.3 V), RST, GND, IRQ (no se usa), MISO, MOSI, SCK y SS (SDA). Se usa SPI porque es el más rápido, pero el módulo admite como máximo 10 Mbit/s.

1.2

Reloj, LED y UART

▶ 2:20

HSE con cristal y PLL a 84 MHz. PC13 como salida con etiqueta led. USART1 asíncrono a 9600 hacia un cable USB serial.

1.3

SPI1 por debajo de 10 MHz

▶ 3:25

SPI1 en Full-Duplex Master, Hardware NSS Signal deshabilitado. El Baud Rate Prescaler se elige para no pasar de 10 MHz: con este reloj, prescaler 16 da 5.25 MHz (con 8 se pasa a 10.5 MHz).

Dos pines más como GPIO_Output con etiquetas RC522_CS (habilitador) y RC522_RST.

El prescaler correcto depende del reloj que le pongas al micro. Revisa en CubeMX el valor de Baud Rate que calcula.

Fase 3

Detectar y leer

3.1

Inicializar y detectar tarjeta

▶ 8:43

MFRC522_isCard indica que hay una tarjeta en el lector. Útil para probar, pero no dice cuál es.

/* USER CODE BEGIN 2 */
MFRC522_Init();
uartx_write_text(&huart1, "INICIANDO\r\n");

while (1)
{
  if (MFRC522_isCard(&TagType))
  {
    HAL_GPIO_TogglePin(led_GPIO_Port, led_Pin);
    uartx_write_text(&huart1, "TARJETA DETECTADA\r\n");
    HAL_Delay(200);
  }
}
3.2

Leer el UID

▶ 12:47

Con MFRC522_ReadCardSerial se leen los 5 bytes del código único y se envían en hexadecimal. Cada tarjeta da un código distinto, por ejemplo 0x73 0x78 0xE7 0xA6 0x4A.

// lee UID
if (MFRC522_ReadCardSerial(UID))
{
  uartx_write_text(&huart1, "cod=");
  // escribe el código
  for (uint8_t cont = 0; cont < 5; cont++)
  {
    sprintf(texto, "0x%0X ", UID[cont]);
    uartx_write_text(&huart1, texto);
  }
  uartx_write_text(&huart1, "\r\n");
}
Fase 4

Reconocer tags

4.1

Forma 1: comparar vectores

▶ 15:08

Se guarda el UID de cada tarjeta conocida en un vector constante y se compara con verifica. Funciona, pero cada tarjeta ocupa 5 bytes y la comparación recorre el vector.

const uint8_t codigo1[] = {0x73, 0x78, 0xE7, 0xA6, 0x4A};
const uint8_t codigo2[] = {0x.., 0x.., 0x.., 0x.., 0x..};   // código de tu segunda tarjeta

// dentro de if (MFRC522_ReadCardSerial(UID))
if (verifica(codigo1, UID, 5) == 1)
{
  HAL_GPIO_TogglePin(led_GPIO_Port, led_Pin);
  uartx_write_text(&huart1, "TAG1 DETECTADO\r\n");
}
else if (verifica(codigo2, UID, 5) == 1)
{
  uartx_write_text(&huart1, "TAG2 DETECTADO\r\n");
}
HAL_Delay(300);
4.2

Forma 2: algoritmo hash

▶ 21:37

Hash_algoritmo convierte el UID leído en un número único de 32 bits. Se imprime una vez para conocer el número de cada tarjeta y luego se guarda con un #define: comparar es una sola operación y se ahorra memoria.

/* USER CODE BEGIN PD */
#define tag1 2903407447   // código del tag 1
#define tag2 1044690731   // código del tag 2

// METODO HASH (dentro del while, con tarjeta presente)
codigo_rfid = Hash_algoritmo();     // lee código único
sprintf(texto, "tag#=%lu\r\n", codigo_rfid);
uartx_write_text(&huart1, texto);

// ANALISIS
if (codigo_rfid == tag1)
{
  HAL_GPIO_TogglePin(led_GPIO_Port, led_Pin);
  uartx_write_text(&huart1, "TAG1 DETECTADO\r\n");
}
else if (codigo_rfid == tag2)
{
  uartx_write_text(&huart1, "TAG2 DETECTADO\r\n");
}
HAL_Delay(500);

Los números tag1 y tag2 son los de las tarjetas del video. Pon los que te imprima tu lector.

4.3

Prueba

▶ 28:06

Con el tag 2 aparece TAG2 DETECTADO y su número; con el tag 1, TAG1 DETECTADO y el LED cambia. Una tarjeta desconocida solo muestra TARJETA DETECTADA y su número.

Las tarjetas también tienen memoria (8 kB) para guardar datos, descontar saldo, etc. Eso queda para otra clase.
