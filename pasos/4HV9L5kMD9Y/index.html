Texas Instruments: primer LED

Los TMS570 son microcontroladores ARM Cortex-R5 de Texas Instruments pensados para aplicaciones críticas y de seguridad: frenos ABS, dirección eléctrica, aviónica o vehículos eléctricos. Se trabaja con dos programas gratuitos de Texas: HALCoGen, que configura el micro y genera los drivers, y Code Composer Studio, donde se escribe y se programa el código. Se arma el primer proyecto completo y se hace titilar el LED del pin 6 del puerto B.

Fase 1

El micro y las herramientas

1.1

La tarjeta

▶ 0:00

La LaunchPad trae el TMS570LC4357, dos pulsadores y dos LEDs de usuario, además de CAN, Ethernet y varios puertos seriales. El programador XDS110 viene en la misma tarjeta.

1.2

Aplicaciones

▶ 0:36

Según la hoja de datos, la familia se usa en frenos y control de estabilidad, dirección eléctrica, vehículos híbridos y eléctricos, aeroespacial y ferrocarriles. Es un micro de 32 bits con dos núcleos Cortex-R5 en paralelo.

Fase 2

HALCoGen

2.1

Proyecto nuevo

▶ 2:16

Conviene crear primero una carpeta para el proyecto. En HALCoGen: File, New Project, se elige el TMS570LC4357, se le da nombre (en el video «titila») y se desmarca la opción de crear directorio para usar la carpeta propia.

2.2

Drivers y pines

▶ 3:20

En Driver Enable se deja solo el driver GIO. En el puerto B, los pines 4 y 5 quedan como entradas (los pulsadores) y los pines 6 y 7 como salidas (los LEDs). No se activa pull-up ni pull-down porque la tarjeta ya tiene las resistencias. Luego File, Generate Code.

Fase 3

Code Composer Studio

3.1

Proyecto en CCS

▶ 6:37

En Code Composer Studio se crea un proyecto CCS con el mismo nombre y en la misma carpeta, con el XDS110 como programador. Se borra el main.c que crea por defecto, porque el código viene de HALCoGen.

3.2

Agregar el include

▶ 7:45

En las propiedades del proyecto (Build, ARM Compiler, Include Options) se agrega la carpeta include que generó HALCoGen.

3.3

Escribir dentro de USER CODE

▶ 9:24

Todo lo propio va entre los comentarios USER CODE BEGIN y USER CODE END de HL_sys_main.c. Si se escribe por fuera, al volver a generar código con HALCoGen se borra.

Ahí se incluye HL_gio.h y se pegan las funciones de retardo, que este compilador no trae; la constante está calibrada para la frecuencia del micro.

/* USER CODE BEGIN (1) */
#include "HL_gio.h"
/* USER CODE END */

/* USER CODE BEGIN (2) */
void delay_ms(uint32 reta)
{
  uint32 cont_, cont1_;
  for (cont_=0; cont_<reta; cont_++)
  {
    for (cont1_=0; cont1_<27258; cont1_++); // 1 ms
  }
}

void delay_us(uint32 reta)
{
  uint32 cont_, cal_;
  cal_ = 27*reta - 9;
  for (cont_=0; cont_<cal_; cont_++);
}
/* USER CODE END */
3.4

Titilar el LED

▶ 11:07

En el main se inicializa el GIO y en el ciclo infinito se cambia el estado del pin 6 del puerto B cada 200 ms con gioToggleBit, una de las funciones que ya trae el driver (se pueden ver en HL_gio.c).

Se compila, se programa la tarjeta (primero borra la flash y luego carga) y el LED empieza a titilar.

int main(void)
{
/* USER CODE BEGIN (3) */
  gioInit();
  while (1)
  {
    gioToggleBit(gioPORTB, 6);
    delay_ms(200);
  }
/* USER CODE END */
}
