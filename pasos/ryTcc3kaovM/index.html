Timers de 16 y 32 bits en dsPIC

Se arma un programa con tres LEDs: uno lo maneja el while y los otros dos los timers. Primero se configura el PLL para pasar de un cristal de 4 MHz a 80 MHz y se remapea el TX del UART. Luego se repasa en el manual de referencia cómo funcionan las interrupciones del dsPIC: tabla de vectores, una dirección por interrupción, trampas del núcleo, prioridades de 0 a 7 y anidamiento. Con dos librerías se dejan listas las funciones para habilitar y deshabilitar interrupciones y para configurar los timers. Con una hoja de Excel se calculan el PR y el prescaler: 200 ms en el Timer1 de 16 bits y 4 segundos uniendo Timer2 y Timer3 en uno de 32 bits.

Fase 1

Proyecto base

1.1

Circuito y proyecto

▶ 0:00

El circuito tiene el dsPIC33FJ32MC202, tres LEDs y un terminal serial. En MikroC se crea el proyecto con ese micro a 80 MHz, aunque el cristal es de 4 MHz: el PLL hace la diferencia.

1.2

PLL a 80 MHz y serial

▶ 2:18

Se configura el PLL como en la clase 1, todo el puerto B como digital y salida, y se remapea el TX del UART al pin RP0. El remapeo se hace entre el desbloqueo y el bloqueo de los pines.

//VELOCIDAD= 4M*M/(N1*N2)= 4M*80/4=80M
CLKDIVbits.PLLPRE = 0;   // N1 = 2
CLKDIVbits.PLLPOST = 0;  // N2 = 2
PLLFBD=78; // selecciona M=80; siempre lo deseado menos 2;

AD1PCFGL=0xffff; // todo digital
TRISB=0x0;
LATB=0;
Unlock_IOLOCK();
PPS_Mapping(0,_OUTPUT,_U1TX);
UART1_Init(9600);
Lock_IOLOCK();
1.3

LED del programa principal

▶ 4:31

El while cambia el LED de RB13 cada 200 ms y manda Procesando por el serial.

UART1_Write_Text("INCICIANDO\r\n");
while(1){
  LATB13_bit=!LATB13_bit;
  Delay_ms(200);
  UART1_Write_Text("Procesando\r\n");
}
Fase 2

Interrupciones del dsPIC

2.1

Tabla de vectores

▶ 6:13

A diferencia de los PIC, cada interrupción tiene su propia dirección en la tabla de vectores. Además están las trampas del núcleo: error matemático, falla del oscilador, error de pila o de dirección.

2.2

Prioridades y anidamiento

▶ 7:50

Las interrupciones de periféricos tienen prioridad de 0 a 7. Con el anidamiento, una interrupción más importante puede cortar a otra que se está atendiendo; eso se activa o no con un bit de INTCON1.

2.3

Librería de interrupciones

▶ 10:06

La librería Config_Interrupcion.h limpia las trampas del núcleo para que el micro no se bloquee. deshabilita pone la CPU en prioridad 7, más alta que cualquier periférico; habilita la baja a 0 para que pasen todas las que tengan prioridad de 1 en adelante.

void deshabilita(){
  intcon1.b15=0;
  IPL3_bit=1;
  IPL_2_bit=1;
  IPL_1_bit=1;
  IPL_0_bit=1;
  intcon1.b15=1;
}

void habilita(){

  // ... pone en cero los bits IPL
}
Fase 3

Timer1 de 16 bits

3.1

Tipos de timer

▶ 12:53

El Timer1 es tipo A y admite un cristal de 32 kHz para reloj de tiempo real. Los tipo B y C se pueden unir de a dos (2 con 3, 4 con 5...) para tener timers de 32 bits.

3.2

Cálculo con Excel

▶ 16:48

En la hoja se pone la frecuencia de 80 MHz y el tiempo deseado, 200 ms. Solo el prescaler de 256 cumple, con PR1 = 31250.

3.3

Configurar el Timer1

▶ 17:22

En Config_timers.h se cargan PR1 y el prescaler, se da prioridad 1, se limpia la bandera, se habilita la interrupción y se prende el timer.

void confi_timer_1(){ //30ms
  tmr1=0;
  pr1=31250;
  t1con=0;
  //preescalador 256
  T1CONbits.TCKPS1=1;
  T1CONbits.TCKPS0=1;
  //prioridad timer1
  T1IP_2_bit=0;
  T1IP_1_bit=0;
  T1IP_0_bit=1;
  T1IF_bit=0;
  T1IE_bit=1;
  T1CONbits.TON=1;
}
3.4

Rutina de interrupción

▶ 18:59

Con el asistente de interrupciones de MikroC se crea la rutina del Timer1. Dentro se cambia el LED y se limpia la bandera. Ojo: hay que guardar el .h antes de compilar o MikroC no toma los cambios.

void timer1() iv IVT_ADDR_T1INTERRUPT ics ICS_AUTO {
  tmr1=0;
  led1=!led1;
  T1IF_bit=0; // limpia bandera inetrrupcion
}
Fase 4

Timer de 32 bits

4.1

4 segundos con 32 bits

▶ 23:23

Con 16 bits a 80 MHz el máximo ronda los 400 ms. Uniendo Timer2 y Timer3 cualquier prescaler sirve para 4 segundos, y se puede llegar a varios minutos sin variables de conteo.

4.2

Configurar Timer2 + Timer3

▶ 24:29

El PR de 32 bits se reparte: la parte alta va al timer impar (PR3) y la baja al par (PR2). El prescaler y el encendido van en el timer par, con el bit de 32 bits activo, pero la interrupción la da el Timer3.

4.3

Interrupción del Timer3

▶ 27:22

La rutina se asocia al Timer3: limpia los dos timers, cambia el segundo LED y limpia la bandera.

void timer32_int() iv IVT_ADDR_T3INTERRUPT ics ICS_AUTO {
  tmr2=0;
  tmr3=0;
  led2=!led2;
  // ... limpia la bandera del Timer3
}
4.4

Programa final

▶ 28:27

El main deshabilita las interrupciones al arrancar, configura los dos timers y las habilita justo antes del while. En la simulación un LED cambia cada 200 ms y el otro cada 4 segundos, sin cargar el programa principal.

#include "Config_timers.h"
#include "Config_Interrupcion.h"
// ... configuración de reloj y pines
confi_timer_1();
confi_timer_32();
habilita();
while(1){
  LATB13_bit=~LATB13_bit;
  Delay_ms(200);
  UART1_Write_Text("HOLA MUNDO\r\n");
}
