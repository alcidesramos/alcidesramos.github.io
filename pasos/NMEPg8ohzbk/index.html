PID discreto con MATLAB y MikroC

La planta es el modelo OVEN de Proteus con un calentador movido por un transistor. El PIC lee la temperatura y el set point por el ADC y los muestra en un LCD. Para conocer la planta se le aplica el máximo PWM y se envía la temperatura cada 100 ms por USB HID a LabVIEW, que la guarda en un archivo. En MATLAB, PID Tuner identifica un modelo de un polo y sintoniza un PI. Las constantes se usan en una función pid discreta que se llama en cada muestreo.

Fase 1

La planta

1.1

Horno en Proteus

▶ 0:00

El modelo OVEN tiene un calentador y una salida de temperatura en voltaje. Un transistor lo prende y apaga con el PWM. En sus propiedades se ajustan la temperatura ambiente, la resistencia térmica, la constante de tiempo y la potencia.

1.2

Escalar la temperatura

▶ 6:20

La salida del horno pasa por un divisor de 27 k y 10 k para no superar 5 V en el PIC. Despejando, la temperatura queda en función del código del ADC.

Vpic = Vfuen*10k/(27k+10k) = Vfuen/3.7
Vpic = codigo*5/1023
Temperatura = 100*Vfuen = 100*3.7*codigo*5/1023 = 1850*codigo/1023

Configuración

▶ 8:46

▶ 12:53

▶ 31:29

Los datos se cargan en MATLAB y en PID Tuner se usa Plant Identification con Step Response: amplitud 255 y tiempo de muestreo 0.1 s. Un modelo de un polo, K/(T1·s+1), se ajusta bien a la curva.

3.4

Sintonizar

▶ 35:37

Con un controlador PI, PID Tuner da Kp ≈ 0.235 y Ki ≈ 0.047, con un sobrepico de 2 % y un tiempo de establecimiento de unos 19 s. Se puede mover la respuesta más rápida o más robusta.

Fase 4

PID en el PIC

4.1

Función pid

▶ 37:40

La parte integral acumula ki·T·error y la derivativa usa el error anterior. La salida se limita entre 0 y 255, que es el rango del PWM.

float kp = 0.2346, ki = 0.0469, kd = 0;
float error, up, ui = 0.0, ui_ = 0.0, error_ = 0.0, ud, ut;
float set_point = 0;

void pid(float pid_in) {
  const float max_x = 255;
  const float min_x = 0;
  const float t_muestreo = 0.1;
  // calculando el error
  error = set_point - pid_in;
  up = kp*error;
  ui = ui_ + (ki*t_muestreo*error);
  ud = kd*(error - error_)/t_muestreo;
  ut = up + ui + ud;
  if (ut > max_x) ut = max_x;
  if (ut < min_x) ut = min_x;
  ui_ = ui;
  error_ = error;
}
