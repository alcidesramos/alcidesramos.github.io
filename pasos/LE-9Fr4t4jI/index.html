Clase 137: varios lidar con la misma dirección usando el TCA9548A

Cuando varios sensores I2C tienen la misma dirección (o la pierden al resetear, como el VL53L0X), el TCA9548A permite conectarlos en 8 canales separados. Conectamos el módulo al I2C1 del STM32F411, configuramos su dirección (0x70 con A0 a A2 a tierra) y usamos una librería que selecciona cada canal escribiendo una máscara de 1 bit. Recorremos los 8 canales para inicializar y leer cada lidar, guardamos las lecturas en distancia[0..7] y las mostramos por serial y en Teleplot.

Fase 1

El multiplexor TCA9548A

1.1

Para qué sirve y cómo se conecta

▶ 0:00

Se alimenta a 3.3 V y GND, y sus pines SDA/SCL van al I2C del micro con pull-up de 4.7 k (aunque el módulo ya las traiga, se recomiendan).

El pin RESET va con una resistencia de 10 k a positivo.

Sus 8 canales (SD0/SC0 a SD7/SC7) se conectan directamente a cada sensor, sin resistencias.

El VL53L0X permite cambiar la dirección pero no la guarda: al resetear la pierde. Por eso conviene el multiplexor.

1.2

Dirección con A0, A1 y A2

▶ 0:36

Con A0, A1 y A2 a tierra la dirección es 0x70; con todos a positivo, 0x77. Se pueden poner hasta 8 multiplexores en el mismo bus.

Como la dirección I2C es de 7 bits, en el código se desplaza una posición a la izquierda (0x70 << 1), como se explicó en la clase 136.

Fase 3

Cómo funciona la librería

3.1

Configurar puertos y dirección

▶ 5:46

En I2C_LIDAR_MUX_TCA9548.h se define el I2C, el UART y la dirección del multiplexor (desplazada).

#include "main.h"
#include "uart.h"
#include "lidarvl53.h"

// puerto I2C a usar
#define I2C_PORT   hi2c1
// puerto UART a usar
#define UART_PORT  huart1
// direccion del Tca9548
#define LIDAR_ADDR 0x70<<1

extern float distancia[];
3.2

Seleccionar un canal

▶ 6:54

Para activar un canal se le envía al TCA9548A un byte con un solo bit en 1: el bit del canal (0 a 7).

float distancia[8];
char textomux[30];

void I2C_MUX(uint8_t channel)
{
    uint8_t mask = (1 << channel);
    HAL_I2C_Master_Transmit(&I2C_PORT, LIDAR_ADDR, &mask, 1, 100);
}

El último parámetro (timeout) no se ve completo en el video; 100 ms funciona bien.

3.3

Leer los 8 canales

▶ 7:26

Para leer se hace un for de 0 a 7: se selecciona el canal, se pregunta si el lidar responde y se guarda la lectura en distancia[canal].

La versión FAST usa la lectura rápida del lidar. Si usas otro sensor, cambia aquí la función de lectura.

void LEE_LIDARS_FAST()
{
    for (uint8_t canal = 0; canal < 8; canal++)
    {
        I2C_MUX(canal);  // activa el canal correspondiente (0-7)
        if (HAL_I2C_IsDeviceReady(&I2C_PORT, dir_s1, 1, 100) == HAL_OK)
        {distancia[canal] = lidar_lee_cm_fast(dir_s1);}
    }
}

La función INIT_LIDARS_FAST hace el mismo recorrido, pero inicializando cada lidar y avisando por serial cuáles detectó.

3.4

Enviar las distancias por serial

▶ 7:26

Manda_Lidars envía Dis1 a Dis8 con un decimal. Para que sprintf acepte float hay que activar en Properties, C/C++ Build, Settings, la opción de printf con float.

void Manda_Lidars()
{
    sprintf(textomux, "Dis1=%.1f\r\n", distancia[0]);
    uartx_write_text(&UART_PORT, textomux);
    sprintf(textomux, "Dis2=%.1f\r\n", distancia[1]);
    uartx_write_text(&UART_PORT, textomux);
    // ... igual hasta Dis8 con distancia[7]
}
Fase 4

Programa principal y pruebas

4.1

main.c

▶ 6:18

Incluimos la librería del multiplexor (ya incluye la del lidar), inicializamos los lidar una vez y en el while leemos y enviamos cada 500 ms.

/* USER CODE BEGIN Includes */
#include "I2C_LIDAR_MUX_TCA9548.h"

/* USER CODE BEGIN 2 */
INIT_LIDARS_FAST();

/* USER CODE BEGIN WHILE */
while (1)
{
    LEE_LIDARS_FAST();
    Manda_Lidars();
    HAL_Delay(500);
}

Graficar con Teleplot

▶ 13:08

4.4

Usar las distancias en tu código

▶ 16:01

El arreglo distancia[8] es externo, así que desde el main puedes usar distancia[0] a distancia[7] (canal 0 a 7) en cualquier cálculo.

Si tienes menos sensores, puedes reducir el for dentro de la librería.

float valor = distancia[0];   // lectura del sensor del canal 0
