Recepción serial con interrupción

Continuación del video de órdenes seriales. Ahora cada byte que llega se recibe en la interrupción (serialEvent en Arduino, vector de interrupción en el PIC), se guarda en la trama y, al llegar el '*', se levanta una bandera. El programa principal procesa la orden solo cuando la bandera está activa y mientras tanto hace otras cosas. Se controla desde LabVIEW por un puerto virtual.

  • Arduino Uno
  • LabVIEW (panel de control de la serie)

2.2

serialEvent

▶ 7:45

serialEvent se ejecuta cuando hay datos. Cada byte se guarda en la trama; si se pasa de 30 se limpia y si llega el '*' se levanta flag_rx.

void serialEvent() {
  while (Serial.available()) {
    datorx = (char)Serial.read();
    trama[puntero] = datorx;
    puntero++;
    if (puntero >= 30) { memset(trama, 0, 30); puntero = 0; }
    if (datorx == '*') flag_rx = 1;
  }
}

3.2

Habilitar la interrupción

▶ 15:00

Toda interrupción tiene bandera y habilitador. Se habilitan las de periféricos en INTCON, se limpia RCIF, se activa RCIE y al final GIE.

INTCON = 0b01000000; // interrupciones de periféricos
RCIF_bit = 0;        // limpia bandera serial
RCIE_bit = 1;        // habilita interrupción serial
GIE_bit = 1;         // autoriza todas
3.3

Rutina de interrupción

▶ 17:42

Se revisa que la bandera sea la del serial, se guarda el dato y, al llegar el '*', se apaga la interrupción y se levanta flag_rx.

void interrupcion() iv 0x0004 ics ICS_AUTO {
  if (RCIF_bit == 1) {
    datorx = UART1_Read();
    trama[puntero] = datorx;
    puntero++;
    if (puntero >= 30) puntero = 0;
    if (datorx == '*') {
      RCIE_bit = 0;
      flag_rx = 1;
    }
    RCIF_bit = 0;
  }
}
3.4

Programa principal

▶ 19:18

Se procesa la orden, se limpian puntero y trama y se vuelve a habilitar la interrupción. Deshabilitarla mientras se procesa evita recibir basura.

while (1) {
  if (flag_rx == 1) {
    procesarx();
    puntero = 0;
    memset(trama, 0, 30);
    flag_rx = 0;
    RCIF_bit = 0;
    RCIE_bit = 1;
  }
  led3 = ~led3;
  Delay_ms(200);
}
