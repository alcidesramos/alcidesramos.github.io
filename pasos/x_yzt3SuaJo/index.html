Procedimientos para mover un carrito

Con un Arduino Uno y el carrito simulado de Proteus (con sensores de línea) se repasa qué es un procedimiento: un bloque de código con nombre que se llama desde el loop. Primero cada movimiento pone los pines de dirección y de habilitación con digitalWrite. Después los procedimientos reciben un entero velo y usan analogWrite en los pines de habilitación para controlar la velocidad de 0 a 255. Se ven errores típicos de compilación y se termina con una tarea: una secuencia de movimientos y un procedimiento que toca música.

Fase 1

El carrito en Proteus

1.1

El montaje

▶ 0:10

El carrito de Proteus tiene dos motores y sensores de línea. Cada motor tiene un pin de dirección (MDG y MIG) y un pin de habilitación (MDH y MIH) que va a un pin PWM del Arduino.

Fase 2

Procedimientos sin velocidad

2.1

adelante, atrás y stop

▶ 1:50

Cada movimiento se escribe una vez como procedimiento void y luego basta llamarlo por su nombre.

// procedimiento de avance
void adelante()
{
  digitalWrite(MDG,0);
  digitalWrite(MIG,0);
  digitalWrite(MDH,1);
  digitalWrite(MIH,1);
}

// procedimiento de reversa
void atras()
{
  digitalWrite(MDG,1);
  digitalWrite(MIG,1);
  digitalWrite(MDH,1);
  digitalWrite(MIH,1);
}
2.2

Llamarlos desde el loop

▶ 4:20

En setup se configuran los cuatro pines como salida y en el loop se encadenan los movimientos con retardos.

void setup() {
  pinMode(MDG, OUTPUT);
  pinMode(MDH, OUTPUT);
  pinMode(MIG, OUTPUT);
  pinMode(MIH, OUTPUT);
}

void loop() {
  adelante();
  delay(1000);
  derecha();
  delay(1000);
}

Si un procedimiento se declara dos veces con el mismo nombre aparece el error «redefinition of void ...».

Fase 3

Procedimientos con velocidad

3.1

Un parámetro velo

▶ 7:45

Cada procedimiento recibe un int velo. La dirección se sigue poniendo con digitalWrite y en los pines de habilitación se usa analogWrite(pin, velo), de 0 a 255. Para parar basta poner 0 en las habilitaciones.

void stop()
{
  analogWrite(MDH,0);
  analogWrite(MIH,0);
}

// procedimiento derecha
void derecha(int velo)
{
  digitalWrite(MDG,1);
  digitalWrite(MIG,0);
  analogWrite(MDH,velo);
  analogWrite(MIH,velo);
}

// procedimiento izquierda
void izquierda(int velo)
{
  digitalWrite(MDG,0);
  digitalWrite(MIG,1);
  analogWrite(MDH,velo);
  analogWrite(MIH,velo);
}

Errores vistos en clase: escribir danalogWrite (no está declarada) o 1=velo en lugar de velo (lvalue required as left operand of assignment). Además, el nombre del parámetro debe escribirse igual dentro del procedimiento: velo y VELO son distintos.

3.2

Rápido y lento

▶ 13:04

En el loop se llama cada movimiento con la velocidad deseada: 255 es la máxima y valores como 50 hacen que el carrito avance más despacio en la simulación.

void loop() {
  adelante(255);
  delay(1000);
  derecha(255);
  delay(1000);
  izquierda(255);
  delay(500);
  // más lento
  adelante(50);
  delay(1000);
  derecha(50);
  delay(1000);
}
