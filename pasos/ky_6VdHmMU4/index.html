Clase 145: DAC simple y con DMA para generar una senoidal

Usamos la tarjeta WeAct con STM32H523CET6 (250 MHz) para estudiar el DAC de 12 bits. Primero en modo simple: escribimos un valor fijo, calculamos el código a partir de un voltaje y hacemos una rampa de 0 a 3.3 V. Luego generamos una senoidal: una función llena un buffer con las muestras, el TIM6 marca el ritmo (frecuencia de la señal por número de muestras) y el DMA en modo circular las envía al DAC sin ocupar la CPU. Vemos el resultado en el osciloscopio a 60 Hz y 1 kHz, y qué pasa si usamos muy pocas muestras.

Fase 1

Configuración del DAC en CubeMX

1.1

Reloj a 250 MHz

▶ 1:40

Creamos el proyecto para el STM32H523CETx. En RCC activamos el HSE como Crystal/Ceramic Resonator (cristal de 8 MHz) y en Clock Configuration llevamos el sistema a 250 MHz.

1.2

DAC1 con OUT1 y OUT2

▶ 2:55

En Analog > DAC1 conectamos OUT1 (PA4) y OUT2 (PA5) a only external pin.

Dejamos Output Buffer: Enable para que la salida pueda entregar corriente. DAC High Frequency Mode se puede dejar en Disable o en automático.

Fase 2

DAC en modo simple

2.1

Escribir un valor fijo

▶ 6:50

Se arranca el canal y se escribe un código de 0 a 4095 alineado a 12 bits a la derecha. Con 2000 la salida da unos 1.61 V.

La fórmula es Vout = Dato / 4095 × Vref, con Vref = 3.3 V.

HAL_DAC_Start(&hdac1, DAC_CHANNEL_1);
HAL_DAC_SetValue(&hdac1, DAC_CHANNEL_1, DAC_ALIGN_12B_R, 2000);
2.2

Pasar de voltaje a código

▶ 10:00

En el canal 2 pedimos directamente un voltaje: codigo = 4095 × voltaje / 3.3. Con 3.0 V el código es 3723.

uint16_t codigo;
float voltaje;

HAL_DAC_Start(&hdac1, DAC_CHANNEL_2);
voltaje = 3.0;
codigo = 4095*voltaje/3.3;
HAL_DAC_SetValue(&hdac1, DAC_CHANNEL_2, DAC_ALIGN_12B_R, codigo);
2.3

Rampa de 0 a 3.3 V

▶ 11:40

En el while un for sube el voltaje de 0 a 3.3 V en pasos de 0.2 V cada 200 ms; en el osciloscopio se ve la escalera.

while (1)
{
  for (voltaje = 0; voltaje <= 3.3; voltaje += 0.2)
  {
    codigo = 4095*voltaje/3.3;
    HAL_DAC_SetValue(&hdac1, DAC_CHANNEL_2, DAC_ALIGN_12B_R, codigo);
    HAL_Delay(200);
  }
}
Fase 3

Senoidal con DMA

3.1

Función que llena el buffer

▶ 13:10

Definimos Vref, resolución y número de muestras, y la función SENO calcula cada muestra con amplitud y offset, limitando el código entre 0 y 4095.

#define DAC_VREF        3.3f
#define DAC_RESOLUCION  4096.0f   // 12 bits
#define muestras        100

uint32_t senobuff[muestras];

void SENO(float frecuencia, float amplitud, float offset)
{
  if (amplitud > DAC_VREF) amplitud = DAC_VREF;
  if (offset < 0.0f) offset = 0.0f;
  if (offset > amplitud) offset = amplitud;

  float scale = (DAC_RESOLUCION - 1.0f) / DAC_VREF;

  for (uint32_t i = 0; i < muestras; i++)
  {
    float angulo = (2.0f * M_PI * i) / muestras;
    float voltaje_dac = offset + (amplitud - offset) *
                        ((sinf(angulo) + 1.0f) * 0.5f);
    int32_t code = (int32_t)(voltaje_dac * scale);
    if (code < 0) code = 0;
    if (code > (int32_t)(DAC_RESOLUCION - 1)) code = (int32_t)(DAC_RESOLUCION - 1);
    senobuff[i] = (uint32_t)code;
  }
}

Incluye math.h para sinf y M_PI. El parámetro frecuencia no se usa dentro: la frecuencia real la fija el TIM6.

3.2

Calcular el TIM6

▶ 16:40

El timer debe dispararse a frecuencia de la señal × muestras. Para 60 Hz y 100 muestras son 6000 Hz.

Con 250 MHz: Prescaler 10-1 y Counter Period 4166 (250 MHz / 10 / 4167 ≈ 6000 Hz).

En Trigger Event Selection elegimos Update Event.

Para 1 kHz con 100 muestras (100 kHz): Prescaler 0 (1-1) y Counter Period 2499.

3.3

Canal GPDMA y disparo del DAC

▶ 20:00

En GPDMA1 habilitamos un canal en Standard Request Mode y modo circular. Request: DAC1_CH1, dirección memoria a periférico, con incremento en la fuente y ancho Word en origen y destino.

En el DAC, el Trigger del canal 1 pasa a Timer 6 Trigger Out event.

3.4

Arrancar DAC con DMA y el timer

▶ 23:20

Llenamos el buffer, arrancamos el DAC con DMA y luego el TIM6. Si olvidas arrancar el timer no sale nada.

SENO(60, 3.0, 0.0);
HAL_DAC_Start_DMA(&hdac1, DAC_CHANNEL_1, (uint32_t*)senobuff, muestras, DAC_ALIGN_12B_R);
HAL_TIM_Base_Start(&htim6);

Los valores de SENO(...) son de ejemplo; ajusta amplitud y offset a lo que necesites.

3.5

1 kHz y efecto del número de muestras

▶ 27:30

Cambiando el TIM6 a Prescaler 0 y Period 2499 obtenemos la senoidal de 1 kHz.

Con solo 4 muestras la señal se reconstruye mal (criterio de Nyquist): más muestras dan una senoidal más limpia.
