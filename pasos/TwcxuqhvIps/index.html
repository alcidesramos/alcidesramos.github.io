Varios canales del ADC con DMA en un solo paquete

En un proyecto real hay varios sensores análogos (potenciómetros, humedad, voltaje de batería). En vez de leerlos uno por uno, el ADC en modo scan convierte todos los canales y el DMA los deja en un arreglo de una sola vez. En esta clase se configura en CubeMX un STM32F411 con cuatro canales (IN0, IN1, IN3, IN4), se activa el DMA en modo normal, se abre el proyecto en VS Code y se usa la librería del ADC. También se ve cómo usar el autocompletado de la IA con criterio: ayuda mucho, pero a veces inventa funciones o elige tipos poco eficientes. Esto no lo simula Proteus: se prueba con la tarjeta física.

Fase 1

Configurar en CubeMX

1.1

Reloj y puerto serial

▶ 3:07

Elige el micro que tienes físicamente (F401 o F411). En RCC activa el cristal, y en Clock Configuration lleva el PLL a la máxima velocidad (100 MHz en el F411, 84 MHz en el F401). Activa USART1 asíncrono a 115200.

1.2

Elegir los canales

▶ 5:00

En Analog → ADC1 marca los canales que vas a usar. En el video IN0, IN1, IN3 e IN4: se saltó el IN2 a propósito para mostrar que no tienen que ser seguidos.

1.3

Scan, fin de conversión y número de conversiones

▶ 6:03

En los parámetros del ADC:

  • Scan Conversion Mode: Enabled, para convertir todos los canales en una sola orden.
  • End Of Conversion Selection: al final de todas las conversiones.
  • Number Of Conversion: 4.
1.4

Los Rank

▶ 7:45

Cada Rank es una conversión del paquete y tú decides qué canal va en cada uno: Rank 1 canal 0, Rank 2 canal 1, Rank 3 canal 3, Rank 4 canal 4. Así puedes conectar por comodidad de hardware y aun así tener el orden que quieras.

Sube el Sampling Time de 3 ciclos a unos 84 ciclos. Con señales lentas como potenciómetros, un tiempo muy corto hace que los canales se "peguen".

1.5

Agregar el DMA

▶ 11:15

En DMA Settings pulsa Add y elige ADC1. Deja el modo Normal (tú pides cada lectura) y la dirección Peripheral To Memory. El modo circular lee solo y sin parar, útil para un osciloscopio.

1.6

Generar el proyecto

▶ 12:55

Ponle nombre (por ejemplo ADC_PROYECTO2026), genera el código con toolchain CMake y ábrelo en VS Code. Deja que la extensión de STM32 configure el proyecto (Setup STM32Cube project).

Fase 2

La librería del ADC

2.1

Copiar las librerías

▶ 17:53

Crea la carpeta LIBRERIAS y pega adc.c/adc.h y uart.c/uart.h. Inclúyelas en main.c y agrégalas al proyecto para que compile.

2.2

Número de canales y el buffer

▶ 21:19

En adc.h solo se configura cuántos canales tiene el paquete. Los datos quedan en el arreglo adc1_codigo, uno tras otro (0, 1, 2, 3) en el orden de los Rank, sin importar el número del canal. La bandera adc1_flag avisa que hay datos nuevos.

#define adc1_canales 4   // número de canales del ADC1

extern uint16_t adc1_codigo[];
extern uint8_t  adc1_flag;   // fin de conversión

void ADC_Read_DMA(ADC_HandleTypeDef *adc_n, uint8_t adc_num, uint16_t *adc_codigo);
2.3

El callback de fin de conversión

▶ 46:03

En adc.c, cuando el DMA termina el paquete, HAL llama al callback y la librería pone adc1_flag = 1. El main solo procesa cuando la bandera está en 1, la pone en 0 y pide otra lectura. Esa sincronización evita bloqueos del micro.

Fase 3

El programa

3.1

Iniciar la primera lectura

▶ 29:56

Antes del while manda un mensaje, espera un poco y lanza la primera conversión por DMA. Para no pelear con el autocompletado, copia el nombre exacto de la función desde adc.h.

char buffer[100];   // global

uartx_write_text(&huart1, "Iniciando\r\n");
HAL_Delay(1000);
ADC_Read_DMA(&hadc1, adc1_canales, adc1_codigo);

La IA a veces cambia mayúsculas o inventa funciones que no existen. Revisa siempre lo que sugiere.

3.2

Procesar cuando hay datos

▶ 39:44

En el while revisa la bandera, envía los cuatro códigos y vuelve a pedir otra lectura. Usa %u (sin signo) porque los códigos van de 0 a 4095; es un poco más eficiente que %d.

while (1)
{
  if (adc1_flag == 1)
  {
    adc1_flag = 0;
    sprintf(buffer, "ADC Values: %u, %u, %u, %u\r\n",
            adc1_codigo[0], adc1_codigo[1], adc1_codigo[2], adc1_codigo[3]);
    uartx_write_text(&huart1, buffer);
    ADC_Read_DMA(&hadc1, adc1_canales, adc1_codigo);
  }
}
3.3

Programar y probar

▶ 48:51

Si el debug no arranca, programa con STM32CubeProgrammer: Connect, Open file (el .elf o .hex de build/Debug) y Download. En Hércules a 115200, al mover cada potenciómetro cambia su valor.

3.4

Pasar a voltios

▶ 54:01

Declara cuatro variables float y calcula el voltaje con la referencia de 3.3 V. Envía un solo decimal y agrega un retardo para no saturar el terminal.

float vol1, vol2, vol3, vol4;   // globales

vol1 = (adc1_codigo[0] * 3.3) / 4095.0;
vol2 = (adc1_codigo[1] * 3.3) / 4095.0;
vol3 = (adc1_codigo[2] * 3.3) / 4095.0;
vol4 = (adc1_codigo[3] * 3.3) / 4095.0;
sprintf(buffer, "Voltaje: %.1f V, %.1f V, %.1f V, %.1f V\r\n", vol1, vol2, vol3, vol4);
uartx_write_text(&huart1, buffer);
HAL_Delay(600);

Escribir las constantes como 3.3f y 4095.0f hace que el cálculo se haga en float y no en double, que es más lento.

3.5

Tarea

▶ 62:33
