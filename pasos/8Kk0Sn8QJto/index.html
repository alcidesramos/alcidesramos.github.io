Clase en vivo 1 (2023): la Black Pill y el primer programa

Primera clase en vivo del curso 2023. Antes de programar entendemos la tarjeta STM32F401 Black Pill leyendo su esquemático y su pinout: pulsador KEY en PA0, LED de usuario en PC13 con lógica inversa, circuito de reset y BOOT0, diodos Schottky para la batería del RTC, bobina y capacitores de filtro, regulador de 5 V a 3.3 V, conector SWD, USB tipo C, memoria flash opcional y cristales de 25 MHz y 32.768 kHz. Después creamos el primer proyecto en STM32CubeIDE, configuramos un pin como salida, generamos el .hex y lo simulamos en Proteus: primero encender un LED y luego hacerlo titilar.

Fase 1

Conocer la tarjeta

1.1

Esquemático y pinout

▶ 2:30

Busca el esquemático de la Black Pill (archivo 4877_sc_ill_V2.0) y su pinout. Como ingenieros, primero entendemos qué tiene la tarjeta antes de programarla.

1.2

LEDs de la tarjeta

▶ 5:00

El LED rojo (PWR) va de 3.3 V a tierra con 5.1 kΩ: se enciende apenas conectas la tarjeta.

El LED azul va de 3.3 V a PC13 con 1 kΩ: es el LED de usuario y funciona con lógica inversa, enciende con un 0.

1.3

Reset, BOOT0 y pulsador de usuario

▶ 10:00

NRST tiene una resistencia a positivo, el pulsador a tierra y un capacitor de 100 nF contra el ruido: el circuito de reset que debe tener todo micro.

BOOT0 con su pulsador permite entrar al bootloader de fábrica para programar por USB.

El pulsador KEY está en PA0 y manda un 0 al presionarlo.

1.4

Batería del RTC

▶ 13:50

Dos diodos Schottky (BAT54C) eligen entre los 3.3 V de la tarjeta y una batería de respaldo en VBAT, para que el reloj de tiempo real siga contando sin alimentación.

Se usan Schottky por su conmutación rápida y su baja caída de voltaje.

1.5

Filtros de alimentación

▶ 18:20

VREF+ (referencia del conversor A/D) se alimenta a través de una bobina con núcleo, que elimina ruido.

Cada pin VDD lleva un capacitor de 100 nF a tierra, lo más cerca posible del chip: en alta frecuencia el capacitor es casi un corto y manda el ruido a tierra.

1.6

Regulador de 5 V a 3.3 V

▶ 22:40

La tarjeta recibe 5 V por USB y un regulador pequeño (unos 300 mA) entrega 3.3 V al micro. No conectes motores ni cargas grandes a la tarjeta.

1.7

SWD y USB tipo C

▶ 24:50

El conector SWD (3.3 V, SWDIO en PA13, SWCLK en PA14, GND) sirve para programar y depurar con un ST-Link.

El USB tipo C alimenta la tarjeta y permite programarla por el bootloader.

1.8

Memoria flash opcional

▶ 27:40

Hay espacio para una memoria W25Q32 por SPI, que viene sin soldar. Sirve si necesitas más memoria para datos.

1.9

Cristales

▶ 30:30

Cristal principal de 25 MHz con dos capacitores de 12 pF. Con el PLL el F401 llega a 84 MHz (el F411 a 100 MHz).

Cristal de 32.768 kHz para el RTC, que permite medir segundos exactos.

Fase 2

Primer proyecto en STM32CubeIDE

2.1

Nuevo proyecto

▶ 43:10

File → New → STM32 Project. Cierra los proyectos viejos para trabajar solo con el actual.

2.2

Elegir el micro

▶ 44:20

En MCU/MPU Selector busca STM32F401CCUx (el de la Black Pill y el que simula Proteus). Márcalo con la estrella de favoritos.

2.3

Nombre y carpeta

▶ 46:50

Escribe el nombre del proyecto y quita Use default location para guardarlo en una carpeta propia: un proyecto genera muchos archivos.

Para descargar los paquetes del micro, CubeIDE pide iniciar sesión con tu propia cuenta de ST.

2.4

Configurar un pin como salida

▶ 49:20

En el dibujo del micro haz clic en un pin (en la clase PA12) y elige GPIO_Output.

Clic derecho → Enter User Label y ponle un nombre, por ejemplo LED.

2.5

Compilar

▶ 61:50

Compila con el martillo para generar el código de la configuración. Abre Core/Src/main.c.

Escribe solo entre USER CODE BEGIN y USER CODE END. Lo que pongas fuera se borra al regenerar el código.

Fase 3

Encender y hacer titilar el LED

3.1

Encender el LED

▶ 64:50

Encender es una orden que se da una vez, así que va antes del while, en USER CODE BEGIN 2.

Las funciones HAL empiezan por HAL_. Usa Ctrl+Espacio para autocompletar.

/* USER CODE BEGIN 2 */
HAL_GPIO_WritePin(LED_GPIO_Port, LED_Pin, 1);
/* USER CODE END 2 */
3.2

Generar el .hex

▶ 66:50

Clic derecho en el proyecto → Properties → C/C++ Build → Settings → MCU Post build outputs → Convert to Intel Hex file. Se hace una vez por proyecto.

3.3

Circuito en Proteus

▶ 74:00

Agrega el STM32F401CC, una resistencia de 330 Ω y un LED. Une el LED al pin configurado y a tierra.

Conecta NRST a POWER para que el micro no quede en reset.

3.4

Cargar y simular

▶ 75:10

Doble clic en el micro → Program File → el .hex de la carpeta Debug. Dale Play y el LED enciende.

3.5

Hacer titilar el LED

▶ 77:30

Titilar es repetitivo, así que va dentro del while con un retardo.

while (1)
{
  HAL_GPIO_TogglePin(LED_GPIO_Port, LED_Pin);
  HAL_Delay(500);
}
3.6

Mover el LED a PC13

▶ 79:50

Con Ctrl presionado arrastra la etiqueta LED a PC13, el LED de la tarjeta. Compila, cambia la conexión en Proteus y el mismo programa sirve para la tarjeta física.
