Balanza con HX711 en MikroC

El HX711 es un ADC de 24 bits para celdas de carga. Se leen 24 bits por DOUT dando pulsos por PD_SCK; los pulsos extra eligen el canal y la ganancia siguiente: uno para el canal A con 128, dos para el B con 32 y tres para el A con 64. La librería hx711 (.c y .h) tiene funciones para iniciar, dar un pulso, leer con signo, promediar n lecturas y tarar. En el PIC16F877A a 4 MHz el programa resta el offset, multiplica por un factor (peso de prueba de 1000 g sobre la lectura de calibración) y muestra el peso en la LCD. Un botón tara y otro calibra; los valores quedan en RAM y se sugiere guardarlos en EEPROM.

Fase 1

El HX711

1.1

El montaje

▶ 0:00

El PIC16F877A lee el HX711, que va a la celda de carga; tiene una LCD, un LED y los pulsadores TARAR y CALIBRAR.

1.2

Cómo se lee

▶ 1:00

Cuando DOUT baja hay dato listo. Con 24 pulsos de reloj salen los 24 bits; con 1, 2 o 3 pulsos más se elige la siguiente lectura: canal A ganancia 128, canal B ganancia 32 o canal A ganancia 64.

1.3

Variables del programa

▶ 2:30

El programa principal define los pines de la LCD, los pulsadores, el LED, el offset, el factor y el texto para mostrar.

1.4

Pines y constantes

▶ 4:00

DT y CLK en RB6 y RB7. offset_manual es lo que se lee sin peso, calibra es la lectura con el peso de prueba menos el offset, y el factor es prueba / calibra. En un PIC18 el reloj se maneja con LAT.

#include "hx711.h"

sbit hx711_dat at portB.b6;   // pin de datos del micro
sbit hx711_ck  at portB.b7;   // pin de reloj
sbit hx711_dat_dir at trisB.b6;
sbit hx711_ck_dir  at trisB.b7;

const float offset_manual = 293;   // offset, valor leído a 0
const float calibra = 416.9 - offset_manual; // valor a la calibración menos el offset
const float prueba = 1000.0;       // peso de prueba para calibración, gramos

float factor = prueba / calibra;   // factor multiplicativo a lectura base
signed long offset = offset_manual; // carga el offset manual al offset a usar
Fase 2

La librería

2.1

Iniciar y dar un pulso

▶ 5:20

hx711_init pone el reloj como salida en 0 y el dato como entrada. hx711_pulso sube el reloj, espera, lee el dato, baja el reloj y devuelve el bit.

extern signed long offset;  // guarda el offset

void hx711_init() {
  hx711_ck_dir = 0;
  hx711_dat_dir = 1;
  hx711_ck = 0;     // saca cero por el reloj
  Delay_ms(500);
}

char hx711_pulso() {
  char lei;
  hx711_ck = 1;     // saca uno por el reloj
  Delay_us(1);
  lei = hx711_dat;
  hx711_ck = 0;     // saca cero por el reloj
  Delay_us(1);
  return lei;
}
2.2

Leer 24 bits

▶ 7:00

Se espera a que DT baje (esta espera bloquea), se dan 24 pulsos armando el dato del bit 23 al 0 y luego los pulsos de la ganancia.

signed long hx711_lectura(unsigned char ganancia) {
  signed int hx711_cont;
  signed long hx711_dato = 0;
  while (hx711_dat == 1);   // que no esté ocupado el módulo
  // da los primeros 24 pulsos
  for (hx711_cont = 23; hx711_cont >= 0; hx711_cont--) {
    if (hx711_pulso() == 1)
      hx711_dato = hx711_dato + (1L << hx711_cont);
  }
  Delay_us(100);
  if (ganancia == 128) hx711_pulso();
  else if (ganancia == 32) {
    hx711_pulso(); Delay_us(100); hx711_pulso();
  }
  else if (ganancia == 64) {
    hx711_pulso(); Delay_us(100); hx711_pulso(); Delay_us(100); hx711_pulso();
  }
  // verifica si es negativo
  if ((hx711_dato & 0x800000) != 0) {
    hx711_dato = hx711_dato | 0xff000000;  // lo convierte a 32 bits con signo
    return (-hx711_dato);  // se coloca - si no se quiere regresar valor negado
  }
  else return (hx711_dato);
}
2.3

Signo

▶ 9:40

El dato viene en complemento a dos de 24 bits: si el bit 23 está en 1 se completa con 0xFF000000 para tener un long con signo. En el video se devuelve negado; se quita el signo menos si no se quiere así.

2.4

Promedio y tara

▶ 11:00

hx711_promedio suma n lecturas con un retardo y divide. tarar guarda ese promedio como offset.

signed long hx711_promedio(unsigned char veces, unsigned char ganancia) {
  signed long prom = 0;
  unsigned char cont;
  for (cont = 0; cont < veces; cont++) {
    prom = prom + hx711_lectura(ganancia);
    Delay_ms(100);
  }
  return (prom / cont);
}

void tarar(unsigned char veces, unsigned char ganancia) {
  offset = hx711_promedio(veces, ganancia);
}

3.4

Calcular el peso

▶ 18:10

Peso = (lectura − offset)·factor; si sale negativo se muestra 0. Se borra el valor anterior y se escribe el nuevo.

while (1) {
  if (sw_tarar == 0) {
    led = 0;
    tarar(10, 128);   // número de datos, a qué ganancia
    floattostr_(offset, texto, 1);
    Lcd_Out(1, 8, texto);  // muestra el offset
  }
  peso = hx711_lectura(128) - (float)offset;
  peso = peso * factor;
  if (peso <= 0) peso = 0;
  floattostr_(peso, texto, 1);
  Lcd_Out(2, 10, "      ");  // borra
  Lcd_Out(2, 10, texto);     // muestra el peso
  led = !led;
  Delay_ms(100);
  // botón de calibrar: ver video
}
3.5

Prueba de peso

▶ 19:40

3.6

Calibrar

▶ 21:10

Con el peso de prueba se toman 50 muestras y se calcula el factor automáticamente. Los valores quedan en RAM; para no perderlos se pueden guardar en la EEPROM, que se explica en otro video del canal.
