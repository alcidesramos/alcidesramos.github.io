Puerto COM virtual por USB CDC con STM32

Para mandar datos al computador desde un micro real normalmente se usa una tarjeta o cable USB-UART. El STM32F401 de la Black Pill puede hacerlo solo: se configura como dispositivo USB de clase CDC (Virtual COM Port) y Windows le asigna un puerto COM. Se habilita el cristal externo, se ajusta el reloj para que el USB quede en 48 MHz, se activa USB_OTG_FS y el middleware USB_DEVICE, se agrega la librería de USB serial y se cambia la función de escritura. Esto no lo simula Proteus: se hace con la tarjeta física.

Fase 1

Configurar el reloj y el USB

1.1

Habilitar el cristal externo

▶ 1:06

En el .ioc, System Core → RCC → High Speed Clock (HSE): Crystal/Ceramic Resonator. El USB necesita el cristal externo y el PLL a máxima velocidad.

1.2

Activar USB_OTG_FS como dispositivo

▶ 1:39

En Connectivity → USB_OTG_FS selecciona Mode: Device_Only.

1.3

Middleware USB_DEVICE

▶ 1:50

En Middleware and Software Packs → USB_DEVICE elige Class For FS IP: Communication Device Class (Virtual Port Com).

1.4

Arreglar el reloj en rojo

▶ 2:11

El reloj del USB debe quedar exactamente en 48 MHz. Si Clock Configuration sale en rojo y no encuentra solución, escribe 84 en HCLK para forzarlo: él mismo pasa a PLL y al cristal y el USB queda en 48 MHz.

Si configuras primero el USB y después el cristal, el asistente puede no encontrar la solución. Configura el cristal primero.

Fase 2

Programa y prueba

2.1

Agregar la librería de USB serial

▶ 2:50

Pega los archivos de la librería en la carpeta Librerias e inclúyela en la sección de includes de main.c. Compila para comprobar que todo está bien.

2.2

Escribir por USB

▶ 3:23

En el while, donde antes se escribía al UART físico (que necesita la tarjeta USB-UART), usa la función de escritura de la librería USB con el mismo texto. Así los datos salen por el cable USB directo al computador.

2.3

Cargar el programa

▶ 4:05

Carga el .hex con STM32CubeProgrammer (Open file → Download). Por USB a veces da problemas; es mejor un programador ST-Link, aunque sea uno económico.

2.4

Ver el nuevo puerto COM

▶ 4:50

Desconecta y vuelve a conectar la tarjeta. En el Administrador de dispositivos → Puertos (COM y LPT) aparece un STMicroelectronics Virtual COM Port (en el video COM3; a ti puede salirte otro número).

2.5

Abrir Hércules

▶ 5:05

En Hércules, pestaña Serial, abre ese COM. La velocidad no importa porque va por USB: puedes cambiar los baudios y sigue funcionando.
