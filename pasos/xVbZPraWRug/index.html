Alarma con GPS en XC8

Se pasa a MPLAB XC8 la alarma de posición hecha en MikroC. Con el MCC se configura el PIC16F1619 con oscilador interno y la EUSART a 9600. Como XC8 no trae librería de LCD, se usa una externa (lcd.h): primero se definen los pines y luego se incluye. La captura de la trama del GPS se copia casi igual, cambiando la lectura del dato recibido: una máquina de estados espera la P, la G y el resto de la cabecera, y guarda la trama. Luego strtok separa los campos por comas; de la latitud se toman 2 dígitos de grados y el resto son minutos que se dividen entre 60, y si el hemisferio es S queda negativa; la longitud usa 3 dígitos y W la vuelve negativa. Con sprintf se arma el texto para el LCD y un LED indica la alarma. En XC8 la conversión a decimales resulta más exacta que en MikroC.

Capturar la trama

▶ 8:20

Se copia la máquina de estados de MikroC. La lectura del dato cambia a la función de la EUSART o al registro RCREG.

while (demora <= 96667)
{
  demora++;
  switch (estado_rec)
  {
    case cap_P:
      if (RCIF == 1)             // si hay un dato recibido
      {
        dato_rx = UART_Read();   // lee el dato
        trama_rx[contador_trama] = dato_rx;
        if (dato_rx != 'P') contador_trama = 0;  // no fue el dato que interesa
        else
        {
          contador_trama++;      // incrementa contador para próximo dato
          estado_rec = cap_G;    // pasa al estado de capturar la G
        }
        RCIF = 0;
      }
      break;
    case cap_G:
      // ... igual para los demás caracteres de la cabecera
  }
}
2.4

Latitud y longitud

▶ 10:43

Con strtok se toma cada campo. Los grados se separan de los minutos, que se pasan a grados dividiendo entre 60. S y W vuelven negativo el valor.

strncpy(c_grados, captura_rx, 2);          // captura los grados
grados = atof(c_grados);                   // de cadena a flotante
minutos = atof(&captura_rx[2]) / 60.0;     // lo pasa a grados
latitud = grados + minutos;

strcpy(captura_rx, strtok(0, ","));        // orientación o signo de la latitud
if (captura_rx[0] == 'S') latitud = -latitud;

// captura la longitud
strcpy(captura_rx, strtok(0, ","));
memset(c_grados, 0, 10);                   // limpia los grados
strncpy(c_grados, captura_rx, 3);          // 3 posiciones
grados = atof(c_grados);
minutos = atof(&captura_rx[3]) / 60.0;
longitud = grados + minutos;
strcpy(captura_rx, strtok(0, ","));
if (captura_rx[0] == 'W') longitud = -longitud;
