Clase 130: TFT ILI9341 dashboard y gráficas

Última parte de la serie de la TFT ILI9341: después de texto e imágenes, se agrega la librería DASHBOARD para mostrar variables de forma visual (todavía sin touch). Trae gauge en arco, dos tipos de LED, barras horizontal y vertical, y algo nuevo: gráficas que se desplazan en tiempo real. Se prueba primero con una onda seno guardada en un arreglo y luego con un canal ADC leyendo un potenciómetro de 0 a 3.3 V. Hacerlo a código ahorra mucha memoria frente a TouchGFX o SquareLine/LVGL.

  • Blackpill STM32F411CEU
  • Pantalla TFT ILI9341 2.8" SPI
  • Potenciómetro de 10 kΩ en PA0
  • Proyecto de las clases 128 y 129

Fase 1

Agregar DASHBOARD

1.1

Incluir la librería

▶ 0:40

Se copia DASHBOARD.c/.h a Librerias y se incluye en el main. Dentro de DASHBOARD.c se incluye el driver de la pantalla que tengas (aquí ili9341.h); hay versiones para las otras TFT del canal.

Como la librería usa sprintf con decimales, se habilita en Properties > C/C++ Build > Settings > MCU Settings la opción de float en printf.

1.2

Declarar los objetos

▶ 1:50

En DASHBOARD.h se pone un extern por cada objeto que se use. Los nombres los eliges tú; si necesitas más LEDs, barras o gauges, copias y agregas otro (led3, gauge2...).

data_seno es solo una onda de prueba para la gráfica; se puede borrar.

// DASHBOARD.h : si se quieren usar en el main, declare los objetos
extern Gauge_ARZ gauge1;
extern Led led1;
extern Led led2;
extern Barra barrah1;
extern Barra barrav1;
extern Grafica grafica1;
extern Grafica grafica2;

extern float data_seno[];   // onda seno de prueba (se puede borrar)
1.3

Configurar cada objeto

▶ 3:50

En DASHBOARD.c se define cada objeto con su estructura: el gauge (centro, radio, ancho, rango, ángulos de -225 a 45, degradado verde, amarillo y rojo, fondo y texto), los LEDs (posición, colores y radio), las barras (posición, tamaño, rango, colores, marco y número de rayitas) y las gráficas.

Fase 2

Dashboard animado

2.1

Actualizar y dibujar

▶ 6:50

Se crean variables que simulan datos: temp sube de 2.2 en 2.2 y velo de 8 en 8. En el while se copia cada variable al campo value del objeto y se llama su función de dibujo. Los LEDs cambian de estado y se redibujan.

/* USER CODE BEGIN PV */
float temp = 10.5;
float velo = 0;
float voltaje = 0;
/* USER CODE END PV */

while (1)
{
  barrav1.value = temp;
  barrah1.value = temp;
  barrav_draw(&barrav1);
  barrah_draw(&barrah1);

  gauge1.value = velo;
  gauge_draw_arc(&gauge1);

  temp += 2.2;
  if (temp > 50) temp = 0;
  velo += 8;
  if (velo > 100) velo = 0;

  led1.estado = 1; led2.estado = 0;
  led_draw(&led1); led_draw1(&led2);
  HAL_Delay(200);
  led1.estado = 0; led2.estado = 1;
  led_draw(&led1); led_draw1(&led2);
  HAL_Delay(200);
}
2.2

Mejorar el contraste

▶ 8:20

Si un texto no se ve, revisa en DASHBOARD.c los colores de texto y de fondo de ese objeto. En el video el valor del gauge salía blanco sobre blanco y se cambió el color del texto.

Fase 3

Gráficas en tiempo real

3.1

Estructura de la gráfica

▶ 11:20

Cada gráfica tiene posición, ancho (número de datos que muestra), alto, rango de valores, colores de fondo, marco, cuadrícula y línea, y número de divisiones en Y.

Se crean dos: grafica1 de 0 a 100 para la onda seno y grafica2 de 0 a 3.3 para el voltaje.

Grafica grafica1 =
{
  .x = 0,  .y = 20,
  .w = 200, .h = 150,      // w es numero de datos a graficar
  .vmin = 0, .vmax = 100,
  .colorFondo = COLOR_BLACK,
  .colorMarco = COLOR_WHITE,
  .colorGrid  = COLOR_DARKGRAY,   // lineas divisorias
  .colorLinea = COLOR_GREEN,      // linea de la grafica
  .numTicksY  = 4                 // divisiones en el eje Y
};

Grafica grafica2 =
{
  .x = 0,  .y = 20,
  .w = 200, .h = 150,
  .vmin = 0, .vmax = 3.3,         // voltios
  .colorFondo = COLOR_BLACK,
  .colorMarco = COLOR_WHITE,
  .colorGrid  = COLOR_DARKGRAY,
  .colorLinea = COLOR_GREEN,
  .numTicksY  = 2
};
3.2

Graficar una onda seno

▶ 12:40

Antes del while se inicializa la gráfica, se dibuja el rango (los valores del eje a la derecha) y el título, que puede ir arriba o abajo y a la izquierda, centro o derecha.

En el while, grafica_add_point agrega un punto y la gráfica se desplaza. Para probar se deja un segundo while(1) antes del dashboard: el micro se queda en el primero que encuentre.

/* USER CODE BEGIN 2 */
grafica_init(&grafica1);
grafica_draw_rango(&grafica1);   // valores a la derecha (comentar para quitarlos)
grafica_draw_titulo(&grafica1, "ONDA SENO", COLOR_YELLOW, font1, titulo_arriba, titulo_centro);
uint16_t i = 0;
/* USER CODE END 2 */

while (1)
{
  grafica_add_point(&grafica1, data_seno[i]);   // agrega un punto
  i++;
  if (i >= 200) i = 0;
  HAL_Delay(100);   // velocidad de muestreo
}
3.3

Canal ADC para el potenciómetro

▶ 15:10

En CubeMX se activa ADC1 canal 0 (PA0): modo independiente, 12 bits, un canal y un sampling time más largo que 3 ciclos para tener menos ruido. Se genera el código y, con CubeIDE ya abierto, el proyecto se actualiza.

3.4

Graficar el voltaje

▶ 16:30

Se inicializa grafica2 en lugar de grafica1 y en el while se convierte la lectura del ADC a voltios y se agrega a la gráfica.

Al mover el potenciómetro la línea sube hasta 3.3 V y baja. Con numTicksY = 2 solo aparece la división del medio (1.6 V).

grafica_init(&grafica2);
grafica_draw_rango(&grafica2);
grafica_draw_titulo(&grafica2, "VOLTAJE", COLOR_YELLOW, font1, titulo_arriba, titulo_centro);

while (1)
{
  voltaje = ADC_Read(&hadc1) * 3.3 / 4095.0;   // 12 bits -> voltios
  grafica_add_point(&grafica2, voltaje);
  HAL_Delay(100);
}
