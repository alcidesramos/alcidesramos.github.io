Medición de frecuencia con Input Capture y estructuras

Se retoma la medición de frecuencia por Input Capture (clase 67) pero con una librería reescrita usando estructuras, al estilo de la librería PWM. Cada canal se describe con una variable FRECS {htim, &CCR, canal, bandera}. Los timers se llevan a pasos de 1 µs (PSC = MHz del reloj − 1) y se habilita la interrupción de captura/comparación. En cada interrupción la función Frec_Analiza guarda el contador en dos flancos de subida consecutivos y calcula la diferencia (teniendo en cuenta el desborde). En el main se divide la frecuencia de muestreo entre esa diferencia para obtener Hz y se envía por el puerto serial. Se termina midiendo tres señales a la vez, cada una llamada desde la interrupción de su propio timer.

Fase 1

Configuración en CubeMX

1.1

Elegir canales de captura

▶ 1:37

Se crea el proyecto Frecuencia_canal. En TIM1 se activa Input Capture direct mode en el canal 1 (PA8) y en el canal 4 (PA11); en TIM2 el canal 1 (PA0). Puede ser cualquier timer y cualquier canal; aquí se eligen según el circuito de Proteus.

1.2

Puerto serial para monitorear

▶ 2:46

USART1 en modo Asynchronous (TX en PA9, RX en PA10). Solo se usa TX para enviar las lecturas.

1.3

Llevar los timers a microsegundos

▶ 5:37

Con reloj de 16 MHz: Prescaler = 16-1 para que cada cuenta sea 1 µs, y Counter Period al máximo (65535 en TIM1). Así se mide desde unos 15 Hz hasta cientos de kHz. TIM2 es de 32 bits (ARR hasta 4 294 967 295), por lo que mide frecuencias mucho más bajas.

Prescaler (PSC)      = 16-1      // MHz del reloj - 1 -> paso de 1 us
Counter Period (ARR) = 65535     // TIM1 (16 bits)
Counter Period (ARR) = 4294967295 // TIM2 (32 bits)
1.4

Librerías y opciones del proyecto

▶ 7:50

Se crea Core/Librerias con Frecuencia.c/.h y uart.c/.h, se agrega la carpeta a los include paths y en el main se incluyen junto con stdio.h, stdlib.h, stdint.h y string.h. En las propiedades se habilita la salida .hex y printf con float.

En NVIC Settings de TIM1 se marca TIM1 capture compare interrupt. Desde System Core → NVIC se puede ajustar su prioridad frente a otras interrupciones.

Fase 2

La librería Frecuencia

2.1

Estructura FRECS

▶ 10:14

Cada entrada de frecuencia guarda su timer, el registro de captura, el canal, la bandera, la frecuencia de muestreo, el valor leído y variables auxiliares:

typedef struct {
    TIM_HandleTypeDef *htim;
    volatile uint32_t *ccr;
    uint32_t channel;
    uint32_t frec_flag;
    uint32_t frec_muestreo;
    float    frec_leida;
    uint32_t frec1_1, frec1_2;
    uint8_t  cap_f1, cap_f2;
} FRECS;
2.2

Declarar los canales en Frecuencia.c

▶ 11:19

Solo hay que incluir los timers y declarar cada canal (FREC1, FREC2… hasta 20) con su timer, CCR, canal y bandera:

extern TIM_HandleTypeDef htim1;
extern TIM_HandleTypeDef htim2;

FRECS FREC1 = {&htim1, &(TIM1->CCR1), TIM_CHANNEL_1, TIM_FLAG_CC1};
FRECS FREC2 = {&htim1, &(TIM1->CCR4), TIM_CHANNEL_4, TIM_FLAG_CC4};
FRECS FREC3 = {&htim2, &(TIM2->CCR1), TIM_CHANNEL_1, TIM_FLAG_CC1};
2.3

Init y análisis en la interrupción

▶ 11:53

Frec_init calcula la frecuencia de muestreo (reloj / (PSC+1)) y arranca la captura con interrupción. Frec_Analiza revisa la bandera del canal: en el primer flanco guarda el contador y en el segundo calcula la diferencia; si el timer se desbordó, corrige con el ARR.

void Frec_init(FRECS *frec)
{
    frec->frec_leida = 0;
    frec->frec_muestreo = SystemCoreClock / ((frec->htim->Instance->PSC) + 1);
    HAL_TIM_IC_Start_IT(frec->htim, frec->channel);
}

void Frec_Analiza(FRECS *frec)
{
    if (__HAL_TIM_GET_FLAG(frec->htim, frec->frec_flag) == 1)
    {
        if (frec->cap_f1 == 0) {
            frec->cap_f1 = 1;
            frec->frec1_1 = *frec->ccr;      // primer flanco
        }
        else if (frec->cap_f1 == 1) {
            frec->cap_f1 = 0;
            frec->frec1_2 = *frec->ccr;      // segundo flanco
            if (frec->frec1_2 > frec->frec1_1)
                frec->frec_leida = frec->frec1_2 - frec->frec1_1;
            else
                frec->frec_leida = (frec->htim->Instance->ARR - frec->frec1_1) + frec->frec1_2;
        }
    }
}

A diferencia de la recepción serial, aquí no se usa una bandera para procesar en el main: la captura se hace siempre en tiempo real dentro de la interrupción.

Fase 3

Leer una frecuencia

3.1

Inicializar y calcular en el main

▶ 15:42

Se inicializa el canal y en el while se calcula la frecuencia; si no hubo capturas se reporta 0, y frec_leida se limpia para refrescar:

float frecuencia1;
char texto[100];

Frec_init(&FREC1);

while (1)
{
    if (FREC1.frec_leida == 0) frecuencia1 = 0;
    else frecuencia1 = FREC1.frec_muestreo / FREC1.frec_leida;
    FREC1.frec_leida = 0;   // en cero para otra lectura

    sprintf(texto, "FREC1=%.1f\r\n", frecuencia1);
    uartx_write_text(&huart1, texto);
    HAL_Delay(100);
}
3.2

Llamar desde TIM1_CC_IRQHandler

▶ 18:39

En stm32f4xx_it.c se incluye Frecuencia.h y en la interrupción de captura de TIM1 se analiza el canal:

#include "Frecuencia.h"

void TIM1_CC_IRQHandler(void)
{
  /* USER CODE BEGIN TIM1_CC_IRQn 0 */
  Frec_Analiza(&FREC1);
  /* USER CODE END TIM1_CC_IRQn 0 */
  HAL_TIM_IRQHandler(&htim1);
}
3.3

Prueba en Proteus

▶ 23:13

Al mover el selector la terminal muestra 2 kHz, 1 kHz, 700 Hz, 300 Hz, 60 Hz y 0 en DC.

Si la simulación se queda en cero o se bloquea, baje el retardo del main (aquí a 100 ms) porque Proteus se carga mucho con señales de kHz, y refresque el componente con el engranaje.

Fase 4

Varias frecuencias

4.1

Segundo canal en TIM1

▶ 24:22

Se declara FREC2 (TIM1 canal 4), se inicializa con Frec_init(&FREC2), se copia el bloque de cálculo cambiando 1 por 2 y en TIM1_CC_IRQHandler se agrega Frec_Analiza(&FREC2).

4.2

Tercer canal en TIM2

▶ 26:58

TIM2 no tiene una interrupción dedicada a captura: solo TIM2 global interrupt, que se dispara por desborde o por captura, así que la librería comprueba la bandera del canal. Se habilita, se declara FREC3 y se repite el proceso en el main.

4.3

Cada timer llama a sus canales

▶ 29:47

Es más eficiente llamar en la interrupción de cada timer solo a los canales de ese timer, en lugar de una función que revise todos:

void TIM1_CC_IRQHandler(void)
{
  Frec_Analiza(&FREC1);
  Frec_Analiza(&FREC2);
  HAL_TIM_IRQHandler(&htim1);
}

void TIM2_IRQHandler(void)
{
  Frec_Analiza(&FREC3);
  HAL_TIM_IRQHandler(&htim2);
}
