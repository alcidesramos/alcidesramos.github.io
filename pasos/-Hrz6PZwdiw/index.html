Introducción a los dsPIC con XC16

Primera clase del curso de dsPIC con MPLAB X y el compilador XC16. Se instalan las librerías de periféricos (se descargan aparte) y se arma el mismo programa en tres micros: un LED que titila y un mensaje por el puerto serial. En el 30F4013 se usa un cristal de 8 MHz con PLL por 8; en el 33FJ128MC802 se calcula el PLL con N1, M y N2 y se remapea el pin TX con PPS; en el 33EP512MU810 se sube a 140 MHz. En cada caso se calcula el valor del registro de baudios con una hoja de Excel.

Fase 1

Preparar el entorno

1.1

Instalar las librerías de periféricos

▶ 3:20

Las funciones como OpenUART1 no vienen con XC16: hay que descargar las PIC24/dsPIC Peripheral Libraries desde la página de compiladores de Microchip e instalarlas en la carpeta del compilador.

Estas librerías ya no se actualizan, así que no traen soporte para los micros más nuevos; para esos toca manejar los registros directamente.

1.2

Crear el proyecto y generar los bits de configuración

▶ 7:50

Se crea un proyecto para el 30F4013 con un archivo main.c que incluye xc.h. En Window > Target Memory Views > Configuration Bits se escoge el oscilador (cristal con PLL), se apaga el watchdog y se pulsa Generate Source Code to Output para pegar los #pragma config en el programa.

Si el watchdog queda encendido el micro se reinicia solo y parece que el programa no funciona.

Fase 2

dsPIC30F4013

2.1

Velocidad del micro y Fcy

▶ 15:00

Con un cristal de 8 MHz y PLL por 8 el oscilador queda en 64 MHz. En los 30F cada instrucción toma 4 ciclos, así que la velocidad efectiva es 16 MHz. Ese valor se define como FCY antes de incluir libpic30.h para que funcionen los retardos.

Se agregan también stdio.h, stdlib.h, string.h y uart.h, y se configuran los pines del puerto serial (TX salida, RX entrada) y los pines como digitales con ADPCFG = 0xFFFF.

#define FCY 16000000UL
#include <xc.h>
#include <libpic30.h>
#include <stdio.h>
#include <uart.h>

unsigned int config1, config2;
2.2

Configurar la UART con OpenUART1

▶ 22:10

OpenUART1(config1, config2, ubrg) recibe dos palabras de configuración armadas con las constantes de la librería unidas con &, y el valor del registro de baudios. La ayuda de cada función está en la documentación que se instala con las librerías.

El valor de baudios sale de BRG = Fcy / (16 × baudios) − 1: a 16 MHz y 9600 baudios da 103.

config1 = UART_EN & UART_IDLE_CON & UART_DIS_WAKE & UART_DIS_LOOPBACK &
          UART_EN_ABAUD & UART_NO_PAR_8BIT & UART_1STOPBIT;
config2 = UART_INT_TX & UART_TX_PIN_NORMAL & UART_TX_ENABLE &
          UART_INT_RX_CHAR & UART_ADR_DETECT_DIS & UART_RX_OVERRUN_CLEAR;
OpenUART1(config1, config2, 103);   // 9600 baudios a 16 MHz
2.3

Programar y probar

▶ 28:00

En el ciclo infinito se invierte un LED, se envía el texto con putsUART1 y se espera con __delay_ms. El programador ICD3 falló en la clase, así que se cargó el .hex con el programador de MikroElektronika, y el mensaje se vio en Hércules.

Fase 3

dsPIC33FJ128MC802

3.1

Bits de configuración y PLL

▶ 32:10

Se arranca con el oscilador interno FRC y se pide que cambie solo al oscilador escogido con PLL. Luego, en el programa, se fija el PLL con la fórmula Fosc = Fin × M / (N1 × N2): con PLLPRE = 0 (N1 = 2), PLLPOST = 0 (N2 = 2) y PLLFBD = 38 (M = 40) se llega a 80 MHz, o sea 40 MHz efectivos.

CLKDIVbits.PLLPRE = 0;   // N1 = 2
CLKDIVbits.PLLPOST = 0;  // N2 = 2
PLLFBD = 38;             // M = 40 (siempre el deseado menos 2)
AD1PCFGL = 0xFFFF;       // pines digitales

En los 33F el valor que se escribe en PLLFBD es M menos 2.

3.2

Remapear el pin TX con PPS

▶ 43:10

Este micro tiene pines remapeables: hay que desbloquear el PPS, asignar la salida U1TX al pin RP14 y volver a bloquear. Se usan las macros de la librería pps.h.

PPSUnLock;
PPSOutput(OUT_FN_PPS_U1TX, OUT_PIN_PPS_RP14);
PPSLock;
3.3

Calcular los baudios con Excel

▶ 46:00

La documentación de la librería muestra un ejemplo de configuración de la UART que se puede copiar. Para el valor de baudios se usa una hoja de Excel: con 40 MHz efectivos y 9600 baudios, dividiendo entre 16 da 259; con la opción de alta velocidad (división entre 4) da unos 1040.

3.4

Programar el 33FJ

▶ 54:41

Se carga el .hex con el programador y se verifica el mensaje en la terminal.

Fase 4

dsPIC33EP512MU810

4.1

PLL a 140 MHz

▶ 59:50

Se repite el proyecto para el 33EP. Con N1 = 2, N2 = 2 y PLLFBD = 68 el oscilador llega a 140 MHz y la velocidad efectiva es 70 MHz. Todos los puertos se ponen digitales con los registros ANSELx = 0.

CLKDIVbits.PLLPRE = 0;
CLKDIVbits.PLLPOST = 0;
PLLFBD = 68;   // 140 MHz, 70 MHz efectivos
ANSELA = 0x00; ANSELB = 0x00; ANSELC = 0x00;
4.2

UART y prueba final

▶ 62:10

Se remapea el TX igual que en el 33F, se arma la configuración de la UART y se calcula el valor de baudios: a 70 MHz y 9600 baudios, dividiendo entre 16, da 455. El mensaje llega a Hércules desde la tarjeta.
