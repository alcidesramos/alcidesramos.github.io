Git en VS Code: configurar y subir a GitHub

Video corto para dejar listo Git en Visual Studio Code. Primero se instala Git para Windows, luego en Git Bash se registran el usuario y el correo de la cuenta de GitHub con git config. Con eso, desde la pestaña de control de código fuente (las ramitas) se hace el commit y se publica el repositorio, privado o público, en GitHub.

Fase 1

Instalar y configurar Git

1.1

Por qué hace falta Git

▶ 0:15

Aunque ya estemos registrados en GitHub en el chat de VS Code, para hacer commits y subir código hay que instalar Git en Windows y registrar nuestros datos.

1.2

Instalar Git para Windows

▶ 0:45

Se descarga Git para Windows y se instala con las opciones por defecto (Next hasta terminar). Se puede agregar el ícono al escritorio.

1.3

Registrar usuario y correo

▶ 2:00

Abrimos Git Bash y pegamos (clic derecho → Paste) los dos comandos con el usuario y el correo de la cuenta de GitHub. Con el tercero verificamos que quedaron bien.

git config --global user.name "SU_USUARIO_GITHUB"
git config --global user.email "su_correo@ejemplo.com"
git config --list

Ponga su usuario y su correo de GitHub entre comillas. Después cierre y vuelva a abrir VS Code.

Fase 2

Primer commit y publicar

2.1

Hacer el commit

▶ 2:40

En la pestaña de control de código fuente (las ramitas) ya no pide descargar Git. Escribimos el mensaje, por ejemplo mi primer código, y pulsamos Commit.

Si al hacer commit le pide el usuario, es porque faltó el paso de git config en Git Bash.

2.2

Publicar en GitHub

▶ 3:15

Después del commit aparece Publish Branch. Se inicia sesión con GitHub en el navegador, se elige repositorio privado o público y se sube. En la página de GitHub ya aparece el repositorio.
