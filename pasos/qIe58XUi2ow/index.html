Recibir tramas por el UART

Lección 30 del curso, continuación de la 29. Cada orden es una trama que termina en *, por ejemplo led1=on*. El micro la lee con UART1_Read_Text, revisa con strstr qué palabras trae y, para la velocidad del motor, separa el número entre el igual y el asterisco y lo convierte con atoi. Las tramas se mandan desde un programa en LabVIEW por puertos virtuales y COMPIM.

Fase 1

Leer la trama

1.1

Por qué tramas

▶ 0:00

Un solo carácter se puede confundir con ruido. Con una trama la orden es una palabra completa que termina en un carácter fijo, y además puede llevar valores.

1.2

Variables

▶ 1:04

Se crean dos arreglos: uno para guardar la trama que llega y otro para procesar partes de ella.

char trama_rx[30];
char procesa[30];
char dato_rx;
1.3

UART1_Read_Text

▶ 1:36

La función guarda lo que llegue hasta encontrar el *, o hasta 30 caracteres. Es una lectura que espera, así que el programa se queda ahí hasta que llegue la trama.

// lee la trama hasta que llegue el * o 30 datos
UART1_Read_Text(trama_rx, "*", 30);   // semibloqueante
Fase 2

Interpretar órdenes

2.1

Buscar palabras con strstr

▶ 3:19

Se agrega la librería C_String. strstr dice si una palabra está dentro de la trama: si trae led1 y además on, se prende el led; si no, se apaga. Lo mismo para el led 2.

if (strstr(trama_rx, "led1"))     // led1=on*
{
  if (strstr(trama_rx, "on")) led1 = 1;
  else led1 = 0;
}
2.2

Probar con LabVIEW

▶ 5:01

Un programa en LabVIEW manda las tramas al presionar botones. En Proteus el COMPIM se conecta a un puerto virtual a 9600. El Virtual Terminal se desconecta de TX porque solo puede transmitir uno.

2.3

Órdenes del motor

▶ 8:59

Con la misma idea, otras palabras mandan el motor a la derecha, a la izquierda o lo paran.

else if (strstr(trama_rx, "m1der")) m1derecha();
else if (strstr(trama_rx, "m1izq")) m1izquierda();
else if (strstr(trama_rx, "m1stop")) m1quieto();
Fase 3

Mandar valores

3.1

Separar el número

▶ 10:04

Para la velocidad llega una trama como m1pwm=90*. LabVIEW ya convierte el 0 a 100 de la perilla a 0 a 255. Con strtok se corta la trama: primero hasta el igual y luego, desde donde quedó (con 0 como primer argumento), hasta el asterisco. Lo que queda es el número en texto.

else if (strstr(trama_rx, "m1pwm="))   // m1pwm=90*
{
  strcpy(procesa, strtok(trama_rx, "="));   // inicia captura de tokens desde el =
  strcpy(procesa, strtok(0, "*"));          // captura hasta el *
  dato_rx = atoi(procesa);                  // pasa la cadena a numero
  PWM1_Set_Duty(dato_rx);                   // aplica la velocidad al pwm
}
3.2

atoi y atof

▶ 12:22

El número llega como caracteres. atoi, de la librería Conversions, lo pasa a entero. Si se necesitaran decimales existe atof.

3.3

Resultado

▶ 14:01

Desde LabVIEW se cambia la velocidad y el sentido del motor y se prenden los leds. Sigue siendo una recepción que espera la trama; con interrupciones el micro podrá hacer otras cosas mientras tanto.
