PWM normal y PWM complementario con tiempo muerto, parte 1

Con un STM32F401 (Black Pill) generamos un PWM de 25 kHz en el TIM2, primero simulado en Proteus con el reloj interno de 16 MHz y luego en la tarjeta real, donde el oscilador interno da 24.6 kHz y 44 % de ciclo útil. Con el cristal externo de 25 MHz y el sistema a 84 MHz la señal queda exacta. Una hoja de Excel calcula prescaler, periodo, ciclo útil y tiempo muerto. Usamos una librería PWM para inicializar y cambiar el ciclo útil en una escala de 0 a 128, y otra para el PWM complementario del TIM1 (canal y canal negado) a 100 kHz con tiempo muerto, medido con un analizador lógico.

Fase 1

PWM simulado en Proteus

1.1

Circuito en Proteus

▶ 0:33

Ponemos la Black Pill (librería propia de Proteus), el reset a power y en Power Rail Configuration 3.3 V para el micro y la referencia VDDA.

Conectamos un osciloscopio a las etiquetas PWM1 y PWMC1. El proyecto de CubeIDE se llama PWMPRUEBA.

Guarda el proyecto de Proteus en la misma carpeta del proyecto de CubeIDE.

1.2

TIM2 canal 1 en PWM

▶ 1:41

El TIM1 lo reservamos para el complementario. En el TIM2 (32 bits) elegimos Internal Clock y Channel1: PWM Generation CH1, que sale por PA0.

1.3

Calcular prescaler, periodo y pulso

▶ 2:14

Con la hoja de Excel: a 16 MHz y prescaler 1 el contador para 25 kHz es 640. Debe ser mayor que la resolución que usaremos (0 a 128) y, en timers de 16 bits, menor que 65535.

En CubeMX: Prescaler 1-1, Counter Period 640, auto-reload preload Enable y Pulse 320 para arrancar al 50 %.

Después de cada cambio en el .ioc pulsa el engranaje (Device Configuration Tool) y luego compila; solo compilar a veces no aplica los cambios.

Fase 2

Librería PWM

2.1

Agregar la librería

▶ 4:56

Creamos la carpeta Librerias en Core, la añadimos a las rutas de include y pegamos PWM.c/.h. En el main: #include "PWM.h".

2.2

Timer y canales en PWM.h

▶ 5:30

En PWM.c se fija la escala (128). En PWM.h se indica el timer y, por cada PWM, su canal y el registro CCR del mismo canal y timer.

// PWM.c
float escala = 128;   // define la escala a trabajar el pwm

// PWM.h
#define PWMT     htim2   // timer usado
#define PWMTIM   TIM2    // registro timer usado

//pwm1
#define PWM1_CH  TIM_CHANNEL_1   // canal de pwm1
#define PWM1     TIM2->CCR1      // registro del timer usado y canal

El registro debe coincidir con el canal: canal 1 va con CCR1, canal 2 con CCR2, y del mismo timer.

2.3

Inicializar y probar en Proteus

▶ 7:09

Antes del while se inicializa el timer y el canal; arranca con el 50 % configurado en el .ioc.

Para Proteus se genera el .hex: Properties > C/C++ Build > Settings > MCU Post build outputs. En la simulación el contador marca unos 24 995 Hz.

PWM_init(&htim2, PWM1_CH);   // timer y canal a configurar
Fase 3

En la tarjeta real

3.1

Reloj interno contra cristal

▶ 8:44

En la tarjeta real, con el oscilador interno, el analizador mide 24.6 kHz y unos 44.5 %: depende de la temperatura y del oscilador.

Activamos HSE: Crystal/Ceramic Resonator (25 MHz) y con el PLL subimos a 84 MHz.

3.2

Nuevos valores del TIM2

▶ 9:51

A 84 MHz, con divisor 10: Prescaler 10-1, Counter Period 336 y Pulse 168. Seguimos en 25 kHz y ahora el analizador marca 24.9 kHz y 49.9 %.

En CubeMX, después de escribir un valor haz clic en otra celda para que se guarde antes de generar.

3.3

Cambiar el ciclo útil

▶ 12:01

PWM_valor recibe el registro del canal y un valor en la escala de 0 a 128 (64 es el 50 %). Para encender y apagar, mejor cambiar el valor que parar el timer con Stop, que obliga a reinicializar.

while (1)
{
  PWM_valor(&PWM1, 64);
  HAL_Delay(200);
  PWM_valor(&PWM1, 0);
  HAL_Delay(200);
}
3.4

Macros para un canal

▶ 13:38

Se pueden crear definiciones para un PWM concreto, por ejemplo un LED.

#define PWMLEDON()  PWM_valor(&PWM1, 64)
#define PWMLEDOFF() PWM_valor(&PWM1, 0)

while (1)
{
  PWMLEDON();
  HAL_Delay(200);
  PWMLEDOFF();
  HAL_Delay(200);
}

El contenido exacto de las macros no se ve completo en pantalla; esta es la forma que explica el video.

Fase 4

PWM complementario con tiempo muerto

4.1

Configurar el TIM1

▶ 15:46

En este micro solo el TIM1 tiene salidas complementarias. Elegimos Internal Clock y Channel1: PWM Generation CH1 CH1N (PA8 y PA7).

Para 100 kHz a 84 MHz: Prescaler 2-1, Counter Period 420, Pulse 189 (45 %) y Dead Time 42 (10 %).

4.2

Librería PWMC

▶ 17:27

Pegamos PWMC.c/.h en Librerias. La escala se llama escala1 para no chocar con la otra librería. En PWMC.h se define el timer complementario.

#include "PWMC.h"

// PWMC.h
#define PWMCPT    htim1   // timer usado
#define PWMCPTIM  TIM1    // registro timer usado

// main, antes del while
PWMCP_init(&htim1, PWM1CP_CH);   // inicia CH1 y CH1N a la vez

En el video la llamada PWMCP_init_CP daba 'undefined reference': el nombre correcto de la función es el que esté en tu PWMC.h. La init arranca el canal positivo y el negado juntos.

4.3

Medir frecuencia y tiempo muerto

▶ 20:10

En el analizador lógico se ven las dos salidas complementarias a unos 99.6 kHz.

Con Dead Time 42 el tiempo muerto medido fue de 500 ns, la mitad de lo esperado; con 84 se obtiene 1 µs. La fórmula del Excel se corrigió multiplicando por 2.

Verifica el tiempo muerto con tu propio osciloscopio o analizador; en Proteus no se nota este detalle.
