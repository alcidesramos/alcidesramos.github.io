Input capture con XC16

Es la versión XC16 de la clase 5 de MikroC. Se crea un proyecto nuevo y se agrega una librería propia (config_Input_capture_33f_util), porque las funciones de input capture de XC16 a veces no funcionan bien. El Timer2 se abre con prescaler 64 y periodo máximo, los cuatro módulos se asocian a él y capturan en cada flanco. En cada interrupción se resta la captura anterior, con corrección si el timer desbordó. Los pines de captura se remapean a RP2 a RP5 y se declaran como entrada.

2.2

Cómo se calcula el ancho

▶ 5:03

El timer cuenta de 0 a 65535. Si la segunda captura es mayor que la primera, el ancho es la resta. Si el timer desbordó entre las dos, hay que restar la primera del máximo y sumarle la segunda.

Configurar timer y módulos

▶ 6:11

Timer2 con prescaler 64 y periodo 65535. Los cuatro módulos se limpian, se asocian al Timer2, capturan cada flanco, se limpian sus banderas, se habilitan y se les da prioridad 3.

// las variables de pulso y los pines los declaro en otro archivp
extern unsigned int pulso_1,pulso_2,pulso_3,pulso_4;

//variables usadas para calculo
unsigned int pul1_1=0,pul1_2=0;
unsigned int pul2_1=0,pul2_2=0;
unsigned int pul3_1=0,pul3_2=0;
unsigned int pul4_1=0,pul4_2=0;

void config_inputcapure()
{
 OpenTimer2(T2_ON & T2_GATE_OFF &T2_PS_1_64 & T2_SOURCE_INT , 65535);
 IC1CON=0;
 IC2CON=0;
 IC7CON=0;
 IC8CON=0; //limpia registo
 IC1CONbits.ICTMR=IC2CONbits.ICTMR=IC7CONbits.ICTMR=IC8CONbits.ICTMR=1; //1=timer 2 es la fuente de reloj
 //  Captura cada flanco de subida o bajada
 IC1CONbits.ICM=IC2CONbits.ICM=IC7CONbits.ICM=IC8CONbits.ICM=0b001;
 //habilita la interrupcion
 _IC1IF=_IC2IF=_IC7IF=_IC8IF=0;  // limnpia la bandera
 _IC1IE=_IC2IE=_IC7IE=_IC8IE=1;  //habilita las interrpcion
 //Priorad d ela interrupcion
 SetPriorityIntIC1(3);
 SetPriorityIntIC2(3);
 SetPriorityIntIC7(3);
 SetPriorityIntIC8(3);
}
2.4

Interrupciones de captura

▶ 7:19

En cada interrupción se lee ICxBUF. Cuando el pin ya está en cero se calcula el ancho, con la corrección de desborde usando PR2.

void __attribute__((__interrupt__,__auto_psv__)) _IC1Interrupt(void)
{
 pul1_2=IC1BUF;
 if (in_pulso_1==0)
 {
 //Para medir ancho de pulso
 if (pul1_2>pul1_1) pulso_1=(pul1_2-pul1_1);
 else pulso_1=(PR2 - pul1_1) + pul1_2;  //desborde del timer
 }
 pul1_1=pul1_2;
 _IC1IF=0; // limpia la bandera
}
// ... igual para _IC2Interrupt, _IC7Interrupt e _IC8Interrupt
