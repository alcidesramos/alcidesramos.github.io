Pasar un código a otro STM32: parte 1

Un proyecto que funciona en la Black Pill F401 (envía "probando" por serial y titila un LED) se pasa a la Blue Pill F103. Entre micros de la misma familia basta copiar el main, pero entre núcleos distintos conviene hacerlo con orden: en STM32CubeMX se busca el micro nuevo, se importa el .ioc viejo, se genera el proyecto para STM32CubeIDE y solo se copia la parte del main que no depende de la configuración de relojes.

Fase 1

El proyecto original

1.1

Qué hace

▶ 1:05

El proyecto del F401 crea un puerto serial, envía "probando" y alterna un LED. La meta es que el F103 haga exactamente lo mismo.

while (1)
{
  uartx_write_text(&huart1, "probando\r\n");
  HAL_GPIO_TogglePin(led_GPIO_Port, led_Pin);
  HAL_Delay(500);
}
Fase 2

En STM32CubeMX

2.1

Elegir el micro nuevo e importar

▶ 1:39

Abre STM32CubeMX y crea un proyecto con el micro destino (STM32F103C8T6). Luego File → Import Project y elige el .ioc del proyecto del F401.

Saldrán advertencias por ser micros distintos; continúa con OK.

2.2

Revisar la configuración

▶ 2:12

Se cargan los pines, el puerto serial y el LED. Revisa el reloj: en Proteus el F103 se simula a 8 MHz.

2.3

Project Manager y Generate

▶ 2:44

Dale nombre y carpeta al proyecto. Con esta forma la herramienta ya queda en STM32CubeIDE. Pulsa GENERATE CODE y abre el proyecto en la IDE.

Fase 3

En STM32CubeIDE

3.1

Librerías y .hex

▶ 4:21

Copia la carpeta Librerias al Core del proyecto nuevo y agrégala al path. Activa el .hex en Properties → C/C++ Build → Settings → MCU Post build outputs.

3.2

Copiar solo una parte del main

▶ 4:56

No copies todo el main. Copia desde el principio del archivo hasta el while (1) sin las funciones de configuración del reloj (SystemClock_Config) y pégalo sobre la misma zona del main nuevo. Así no se mezclan configuraciones de micros distintos.

Entre micros de la misma familia (F401 → F411) sí se puede copiar el main completo.

3.3

Compilar y probar

▶ 6:07

Corrige los errores de copiado (por ejemplo un comentario cortado), compila y carga el .hex en la Blue Pill de Proteus: la terminal muestra "probando" y el LED titila.
