Billetero NV10 con PIC

En modo pulsos el NV10 entrega un pulso por cada 1000: un billete de 2000 da dos pulsos. Cada flanco de bajada genera una interrupción que suma un pulso y reinicia el Timer0 (16 bits, preescalador 256, TMR0H = 146 y TMR0L = 35, unos 600 ms). Si el timer se desborda es porque ya no llegan más pulsos y el billete es válido. El pin RB1 (inhibir) habilita el billetero con 0. El procedimiento billetero multiplica los pulsos por 1000, los suma al saldo y lo envía por serial. Se usó en un proyecto de lavadero con pantalla HMI.

Preparar

1.1

El billetero

▶ 0:00

El NV10 valida el billete y, en modo pulsos, entrega un pulso por cada 1000. Tiene un pin de inhibir para habilitarlo o no desde el micro.

1.2

Variables

▶ 2:50

pulsos_var cuenta los pulsos, flag_bill indica que llegó un billete completo y dinero acumula el saldo.

1.3

Configuración

▶ 4:10

RB1 en 0 habilita el billetero. Se inicia el UART y la interrupción externa por flanco de bajada.

Fase 2

Contar pulsos

2.1

Timer0

▶ 5:40

El Timer0 en 16 bits con preescalador 256 y TMR0H = 146, TMR0L = 35 tarda unos 600 ms, más que el espacio entre pulsos. Queda apagado hasta el primer pulso.

2.2

Interrupciones

▶ 9:50

Cada pulso recarga y enciende el timer y suma uno. Si el timer se desborda, ya no llegaron más pulsos: se apaga y se activa flag_bill.

// en la interrupcion externa (cada pulso)
TMR0H = 146;
TMR0L = 35;
TMR0ON_bit = 1;  // enciende el timer para medir desborde y saber si ya termino los pulsos
pulsos_var++;
INT0IF_bit = 0;

if (TMR0IF_bit == 1) {
  TMR0H = 146;
  TMR0L = 35;
  TMR0ON_bit = 0;  // apaga el timer
  flag_bill = 1;
  TMR0IF_bit = 0;
}
2.3

Ciclo principal

▶ 12:30

billetero revisa flag_bill: multiplica los pulsos por 1000, los suma a dinero, envía el saldo por serial y limpia las variables. El LED de RB7 indica que el programa corre.

while (1)
{
  billetero();
  UART1_Write_Text("FUNCIONANDO\r\n");
  LATB7_bit = ~LATB7_bit;
  Delay_ms(1000);
}
2.4

Prueba

▶ 13:50

Al meter billetes en la terminal aparece el saldo acumulado, por ejemplo SALDO=7000 después de un billete de 5000 y uno de 2000.
