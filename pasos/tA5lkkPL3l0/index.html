Clase 134: TouchGFX slider de control

Continuación del proyecto TouchGFX con la ILI9341 táctil. En la pantalla 2 se agrega un Slider de 0 a 100. Una interacción "slider value changed" llama una función virtual que recibe el valor. Se muestran dos formas de usarlo: procesarlo directamente en el archivo de la pantalla (lo que obliga a llamar funciones de C desde C++ con extern "C") o, la forma recomendada, activar una bandera y procesarlo en el main. Al final se muestra el valor en un Text Area con wildcard.

Fase 1

Slider en TouchGFX

1.1

Agregar el slider

▶ 1:00

En Screen2 se agrega un Slider (Miscellaneous > Slider) y se elige un estilo pequeño en Preset. Se le pone nombre: SLIDER_VELO. Por defecto va de 0 a 100; se puede cambiar el rango en sus propiedades.

1.2

Interacción al cambiar de valor

▶ 1:50

Interactions > nueva: Trigger "Slider value changed", Choose slider SLIDER_VELO, Action "Call new virtual function" con el nombre CAMBIA_VELOCIDAD. Generate Code.

1.3

Declarar la función

▶ 3:00

En gui_generated/include/gui_generated/screen2_screen/Screen2ViewBase.hpp aparece la función virtual, que ahora recibe el valor del slider (int value). Se copia a gui/include/gui/screen2_screen/Screen2View.hpp.

// gui/include/gui/screen2_screen/Screen2View.hpp
virtual void CAMBIAPANTALLA();
virtual void CAMBIA_VELOCIDAD(int value);   // recibe el valor del slider
Fase 2

Primera forma: todo en la pantalla

2.1

USART1 y librería uart

▶ 5:30

En CubeMX se activa USART1 a 115200 baudios y se conecta su TX a un convertidor USB-serial. Se pega la librería uart en LIBRERIAS.

2.2

Enviar el valor por serial

▶ 7:00

En Screen2View.cpp se escribe la función: arma el texto con sprintf y lo envía por USART1 cada vez que el slider cambia.

// gui/src/screen2_screen/Screen2View.cpp  -- primera forma (todo aqui)
#include "main.h"
#include "uart.h"
#include <stdio.h>
extern UART_HandleTypeDef huart1;
char texto_tft[50];

void Screen2View::CAMBIA_VELOCIDAD(int value)
{
    sprintf(texto_tft, "VELOCIDAD=%d\r\n", value);
    uartx_write_text(&huart1, texto_tft);
}
2.3

Llamar funciones de C desde C++

▶ 7:50

Al compilar aparece undefined reference to uartx_write_text: los archivos de TouchGFX son C++ y la librería está en C.

La solución es envolver los prototipos del .h de la librería con extern "C". Sirve para cualquier librería en C que quieras usar desde C++.

// uart.h : permitir que C++ llame funciones escritas en C
#ifdef __cplusplus
extern "C" {
#endif

void uartx_write(UART_HandleTypeDef *huart, char ch);
void uartx_write_text(UART_HandleTypeDef *huart, char *info);
/* ... resto de prototipos ... */

#ifdef __cplusplus
}
#endif
2.4

Probar

▶ 9:00

En la terminal serial aparece VELOCIDAD=0 ... VELOCIDAD=100 al mover el slider. Este touch resistivo necesita bastante presión.

Fase 3

Segunda forma: bandera al main

3.1

Procesar en el main

▶ 10:00

En el main se crean velocidad, una bandera flag_velo y un texto. En el while, si la bandera está en 1 se envía el valor y la bandera vuelve a 0.

Así la pantalla solo avisa y el main decide qué hacer (PWM, motor, etc.).

// main.c -- segunda forma (bandera y se procesa en el main)
/* USER CODE BEGIN PV */
uint16_t velocidad;
uint8_t  flag_velo = 0;
char texto[50];
/* USER CODE END PV */

while (1)
{
    voltaje = ADC_Read(&hadc1) * 100.0 / 4095.0;

    if (flag_velo == 1)
    {
        sprintf(texto, "VELOCIDAD=%d\r\n", velocidad);
        uartx_write_text(&huart1, texto);
        flag_velo = 0;
    }
    MX_TouchGFX_Process();
}
3.2

Activar la bandera desde la pantalla

▶ 10:50

En Screen2View.cpp las variables se declaran extern y la función solo activa la bandera y copia el valor. En el video falló hasta declarar también flag_velo como extern.

Fase 4

Mostrar el valor en pantalla

4.1

Text Area y tipografía

▶ 13:10

Se agrega un Text Area llamado SLIDER_TEXT, sin Auto-size, con texto y Wildcard 1 (valor inicial 0 y buffer).

En Typographies se agregan a la tipografía los Wildcard Characters 0123456789.,%

4.2

Escribir el valor

▶ 15:20

En CAMBIA_VELOCIDAD se escribe el valor en SLIDER_TEXTBuffer y se llama SLIDER_TEXT.invalidate().

Los nombres del buffer y del tamaño salen en mayúsculas; si el widget se llama en minúsculas, te dará error. Acostúmbrate a nombrar todo en mayúsculas.

// Screen2View.cpp -- segunda forma + texto en pantalla
extern uint16_t velocidad;
extern uint8_t  flag_velo;

void Screen2View::CAMBIA_VELOCIDAD(int value)
{
    flag_velo = 1;          // aviso al main
    velocidad = value;

    Unicode::snprintf(SLIDER_TEXTBuffer, SLIDER_TEXT_SIZE, "%d", value);
    // Unicode::snprintfFloat(SLIDER_TEXTBuffer, SLIDER_TEXT_SIZE, "%.1f", valor);  // si es flotante
    SLIDER_TEXT.invalidate();
}
