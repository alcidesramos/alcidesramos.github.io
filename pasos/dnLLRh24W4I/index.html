Librerías de MikroC a XC8

El MCC puede generar el I2C, pero su código usa más memoria y no le gusta al autor, así que se usa su librería de MikroC. En el MCC se configuran solo el reloj, los pines, la EUSART a 9600 con printf y un LED; el MSSP se agrega para comparar y luego se quita. Se copian I2C_ARZ.c y I2C_ARZ.h al proyecto. Los dos cambios son: reemplazar en todo el .c el sufijo _bit, porque en XC8 los bits se llaman sin él, y cambiar Clock_MHz() de MikroC por _XTAL_FREQ. También se definen Hi y Lo, que XC8 no trae. Con eso se escriben cinco datos en la memoria 24LC512 y se leen por serial.

2.2

Dos cambios

▶ 6:55

Con buscar y reemplazar se quita _bit de todo el archivo, porque en XC8 el bit se nombra directo. Y el reloj se toma de _XTAL_FREQ en lugar de la función de MikroC.

#include "I2C_ARZ.h"
#include "mcc_generated_files/mcc.h"

const unsigned long cristal = _XTAL_FREQ * 1e6 / 4;   //obtiene el reloj en mega

void I2C_CONFIG_master(unsigned long i2c_velo)
{
  SSP1STAT = 0;           // limpia registro de estado
  SSP1CON1 = 0b1000;      // i2c en modo master
  SSP1CON2 = 0;
  SSP1ADD = (cristal / i2c_velo) - 1;   // carga valor del registro de velocidad
  SSPEN = 1;              // habilita el i2c
}

void I2C_WAIT()
{
  while (SSP1IF == 0);
  SSP1IF = 0;
}

Escribir y leer la memoria

▶ 8:36

Las funciones de la memoria se copian de MikroC. Hi y Lo, que separan la dirección en dos bytes, se definen porque XC8 no las tiene.

void memoria_i2c_write(unsigned int dir_mem, unsigned char dato_mem)
{
  I2C_STARTBIT();
  I2C_WRITE_BYTE(dir_esclavo & 0b11111110);   //para escribir
  //Direccion
  I2C_WRITE_BYTE(Hi(dir_mem));
  I2C_WRITE_BYTE(Lo(dir_mem));
  //dato
  I2C_WRITE_BYTE(dato_mem);
  I2C_STOPBIT();
  //retardo de escritura
  __delay_ms(5);
}

unsigned char memoria_i2c_read(unsigned int dir_mem)
{
  unsigned char i2c_dato_read;

  I2C_STARTBIT();
  I2C_WRITE_BYTE(dir_esclavo & 0b11111110);   //para escribir
  //Direccion
  I2C_WRITE_BYTE(Hi(dir_mem));
  I2C_WRITE_BYTE(Lo(dir_mem));
  //inicia proceso de leer
  I2C_REPEATSTARTBIT();
  // ... se envía la dirección para leer y se lee el dato (ver video)
}
