Texas Instruments: puerto serial

La tarjeta crea un puerto COM virtual por USB. En HALCoGen se habilitan los drivers GIO y SCI, se configura el SCI a 9600 baudios, 8 bits y un bit de parada. En Code Composer Studio se incluyen HL_gio.h y HL_sci.h, se inicializa con sciInit() y se envía un byte con sciSendByte. Como el driver solo trae funciones para bytes o bloques con largo, se hacen dos funciones propias que recorren la cadena con un puntero hasta el carácter nulo: una para constantes y otra para variables.

2.2

Enviar un byte

▶ 6:31

Después de gioInit() se llama sciInit(). El driver trae sciSendByte(sciREG1, dato) para enviar un byte y otra función para enviar un bloque indicando el largo. Con sciSendByte(sciREG1, 'Q') se ve llegar la letra en el terminal.

2.3

Funciones para textos

▶ 9:01

Para no tener que contar caracteres se hacen dos funciones: mientras el puntero no apunte al carácter nulo, envía el carácter y avanza. Una recibe constantes (const char *) y la otra variables (char *).

// transmisión serial de constantes
void sci_send_text_const(const char *info)
{
  while (*info) sciSendByte(sciREG1, *info++);
}

// transmisión serial de variables
void sci_send_text(char *info)
{
  while (*info) sciSendByte(sciREG1, *info++);
}
2.4

Hola mundo

▶ 10:39

Antes del ciclo se envía «INICIANDO» y dentro del ciclo «HOLA MUNDO» con su retorno de carro y salto de línea, junto con el código de las clases anteriores.

Luego se mejoran las funciones para recibir también el puerto SCI por el que se envía, y así usarlas con cualquiera de los SCI del micro.

// versión con el puerto como parámetro
void sci_send_text_const(sciBASE_t *sci, const char *info)
{
  while (*info) sciSendByte(sci, *info++);
}

int main(void)
{
  gioInit();
  sciInit();
  bool sw;

  sci_send_text_const(sciREG1, "INICIANDO\r\n");

  while (1)
  {
    sci_send_text_const(sciREG1, "HOLA MUNDO\r\n");
    sw = gioGetBit(gioPORTB, 4);
    if (sw == 1) gioSetBit(gioPORTB, 6, 1);
    else         gioSetBit(gioPORTB, 6, 0);

    gioToggleBit(gioPORTB, 7);
    delay_ms(200);
  }
}

En el video el parámetro del puerto se declara uint32 y el compilador avisa que sciREG1 es de tipo sciBASE_t *. Por eso aquí se declara como sciBASE_t *sci, que evita la advertencia.
