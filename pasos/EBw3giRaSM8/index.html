PID de velocidad con XC8

En el MCC se configuran el oscilador HS de 10 MHz, el ADC en AN0, la interrupción externa por flanco de subida, el Timer1, la EUSART a 19200 baudios y el PWM3 con el Timer2 en RC0. Primero se prueba lazo abierto: el valor del potenciómetro pasa directo al PWM. Luego se copia el medidor de frecuencia de MikroC: la interrupción externa usa el conteo del Timer1 y, como está en otro archivo, sus variables se declaran extern. El set point se escala de 0-1023 a 5-70 Hz con una recta calculada en Excel. El PID se ajusta en Proteus mirando la respuesta en LabVIEW: con solo proporcional no llega, y un poco de integral lo lleva al set point.

Medir la frecuencia

▶ 14:19

Se copian las variables del medidor de frecuencia. El 10000000 es el cristal de 10 MHz y el 8 el preescalador del Timer1. Las variables que usa la interrupción externa se declaran extern en su archivo.

// medidor de frecuencia
unsigned int contador = 0;
float frecuencia;
char texto[40];
char flag_cero = 0;

// se lee la frecuencia
if (flag_cero != 0) frecuencia = (10000000) / (8.0 * contador * 4.0);

flag_cero = 0;

sprintf(texto, "frec=%.2f\r\n", frecuencia);
printf(texto);
__delay_ms(500);

3.3

Lazo cerrado

▶ 23:57

Se calcula la frecuencia, se llama al PID y su salida va al PWM. Se envían set point, RPM y salida a LabVIEW cada 60 ms.

while (1)
{
  codigo = ADC_GetConversion(0);
  set_point = 0.0635 * codigo + 5.0;   // set point en rango de la frecuencia min y max 5 - 70

  // se lee la frecuencia
  if (flag_cero != 0) frecuencia = (10000000) / (8.0 * contador * 4.0);   // 8.0 ES EL PREESCALADOR

  flag_cero = 0;
  pid(frecuencia);
  salida = ut;

  PWM3_LoadDutyValue(salida);
  sprintf(texto, "SP=%.2f/RPM=%.2F/\r\n", set_point, frecuencia, salida);
  printf(texto);

  __delay_ms(60);
}
