Control por Bluetooth desde el celular

En vez de LabVIEW se usa una app de panel para Bluetooth (Bluetooth Electronics) donde se arrastran botones, un slider, un termómetro y un led. Cada control se configura para mandar exactamente las órdenes que el micro ya conoce (led1=on*, mder*, mpwm=valor*). Para mostrar datos, el micro manda la temperatura y el estado del switch con el formato de la app. Se hace en PIC18F25K20 con MikroC y en Arduino.

  • Módulo Bluetooth serial (HC-05 o similar)

Fase 1

La app

1.1

Mismo circuito

▶ 0:00

Se usa el circuito de la serie full duplex: LM35, motor con L293D, dos leds y un switch. Ahora el puerto serial va a un módulo Bluetooth.

1.2

Armar el panel

▶ 1:40

En la app se arrastran un termómetro, un led indicador, botones de izquierda, derecha y stop, un slider de velocidad y dos switches para los leds.

Fase 2

Órdenes

2.1

No se cambia el micro

▶ 5:40

El micro ya entiende led1=on*, mder*, mizq*, mstop* y mpwm=valor*. Solo hay que configurar la app para que mande esas mismas tramas.

2.2

Botones y switches

▶ 7:22

El switch amarillo manda led1=on* al presionar y led1=off* al soltar; el rojo, led2. Los botones del motor mandan mizq*, mder* y mstop*.

2.3

Slider

▶ 9:36

El slider se configura de 0 a 255 y para que empiece con mpwm= y termine con '*'. Así manda mpwm=valor* cada vez que cambia.

2.4

Prueba

▶ 11:17

Se conecta el celular al módulo y desde el panel se encienden leds, se gira el motor y se cambia su velocidad.

Fase 3

Datos hacia el celular

3.1

Temperatura

▶ 12:58

La app espera un carácter de inicio y uno de fin según el indicador. Para el termómetro se manda *T, el valor y *.

sprintf(texto, "*T%.2f*", temperatura);
UART1_Write_Text(texto);
3.2

Led indicador

▶ 14:07

Para el led se manda el color: *LR255G0B0* lo pone rojo y con todo en 0 queda apagado. Conviene un retardo entre envíos para que los comandos no se peguen.

Fase 4

Arduino

4.1

Mismo programa

▶ 18:02

El programa full duplex de Arduino funciona igual con la app.

4.2

Tramas de la app

▶ 21:08

Se cambia el envío: la temperatura con *T y dtostrf, y el switch con el color del led.

Serial.print("*T");
dtostrf(temperatura, 5, 3, texto);
Serial.print(texto);
Serial.print("*");
if (digitalRead(suiche) == 1) Serial.print("*LR255G0B0*");
else Serial.print("*LR0G0B0*");
4.3

Prueba

▶ 22:50

La temperatura y el led cambian en el celular mientras se manejan motor y leds.
