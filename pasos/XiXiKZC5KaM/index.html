De Simulink a C para el PIC

Se hace un modelo de Simulink con dos entradas (uno y dos), un bloque suma y una salida. En la configuración se pone paso fijo, tipo de dato single (float), el vendedor Microchip y el dispositivo PIC18, y se desactiva la generación de main. El código generado (suma.c, suma.h y otros) se copia a la carpeta del proyecto de MikroC, se incluye suma.h y se agrega suma.c. En el programa se cargan las entradas en suma_U, se llama suma_step y el resultado queda en suma_Y. Se prueba con el depurador de MikroC.

Fase 1

El modelo en Simulink

1.1

Opciones

▶ 0:00

MATLAB también tiene un paquete para programar dsPIC y PIC32 por bloques, pero aquí se usa solo la generación de código C, que sirve para cualquier compilador.

1.2

Bloques

▶ 2:15

Se crea un modelo con dos entradas (uno y dos), un bloque Add y una salida (salida). Puede ser cualquier cosa: un controlador PID, un filtro, etc.

1.3

Paso fijo y float

▶ 4:24

En Model configuration parameters el solver es de paso fijo y el tipo de dato por defecto se cambia de double a single, que es el float de los compiladores de 8 bits.

1.4

Hardware

▶ 4:59

En Hardware Implementation se elige Microchip y PIC18. Muestra cuántos bits tiene cada tipo; si el compilador es diferente se puede personalizar.

En Code Generation, Templates, se quita la opción de generar un main de ejemplo; el main lo hace uno. Se pide empaquetar el código en un .zip.

Generar

En la pestaña C CODE se da Generate Code y se obtienen suma.c, suma.h y las demás cabeceras.

Fase 3

Usarlo en MikroC

3.1

Agregar archivos

▶ 10:00

Se crea el proyecto (aunque se configuró para PIC18, funciona en un PIC16F877A), se copian los .h y .c a la carpeta, se incluye suma.h y se agrega suma.c en Sources.

3.2

La función generada

▶ 12:49

suma.c tiene suma_step, que calcula la salida con las entradas guardadas en las estructuras suma_U y suma_Y.

/* Model step function */
void suma_step(void)
{
  /* Outport: '<Root>/salida' incorporates:
   *  Inport: '<Root>/dos'
   *  Inport: '<Root>/uno'
   *  Sum: '<Root>/Add'
   */
  suma_Y.salida = suma_U.uno + suma_U.dos;
}
3.3

Probar

▶ 14:29

Se cargan las entradas, se llama suma_step y se lee la salida. En el depurador, con Watch Values, la salida vale 6.

#include "suma.h"
float salida_suma;

void main()
{
  suma_U.uno = 2;
  suma_U.dos = 4;
  suma_step();
  salida_suma = suma_Y.salida;
}
