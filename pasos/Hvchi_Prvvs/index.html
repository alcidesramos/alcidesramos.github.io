Fase 1

El problema de HAL_Delay

1.1

HAL_Delay(1) dura casi 2 ms

▶ 0:00

Un pulso con HAL_Delay(1) mide 1.99 ms en el analizador. Si necesitas precisión, HAL_Delay no sirve para tiempos cortos.

Fase 2

Delay_ms propio

2.1

La función

▶ 1:04

Recibe milisegundos, multiplica por 1000 y llama al retardo en microsegundos que prefieras:

void Delay_ms(uint32_t ms)
{
    delay_us_dwt(ms * 1000);     // o delay_us_ASM, delay_us_C, delay_us_tim
}
2.2

Inicializar si hace falta

▶ 1:36

El de DWT y el de timer necesitan su init antes del while. El de C y el de ensamblador no.

delay_us_dwt_init();   // si usas DWT
delayus_tim_init();    // si usas timer
while (1)
{
    salida_GPIO_Port->BSRR = salida_Pin;
    Delay_ms(1);
    salida_GPIO_Port->BSRR = salida_Pin << 16;
    Delay_ms(1);
}

Si olvidas el init del DWT o del timer, el retardo no funciona y no sale señal.
