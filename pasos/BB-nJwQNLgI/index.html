Tonos y melodías con el PIC

Quinta lección del curso. Se repasa el rango de frecuencias que escucha el ser humano y se usa por primera vez una librería de MikroC: Sound. Con Sound_Init se indica el pin del parlante y con Sound_Play se toca cada nota con su frecuencia y duración, hasta armar una melodía simulada en Proteus. Luego se explica por qué el parlante no va directo al pin y cómo armar la etapa de potencia con un transistor, un diodo para la carga inductiva y un Darlington.

Fase 1

Sonido con la librería Sound

1.1

Frecuencias que escuchamos

▶ 0:00

El oído humano escucha más o menos entre 20 Hz y 20 kHz. Lo que está por fuera de ese rango (ultrasonido, radiofrecuencia) también se aprovecha en electrónica: ecografías, radares, medición de distancia, celulares. La voz está más o menos entre 300 Hz y 3,3 kHz.

1.2

Crear el proyecto

▶ 1:38

Se crea el proyecto parlante en una carpeta nueva clase5, con el PIC16F877A a 10 MHz. Como el cristal pasa de 8 MHz se usa el oscilador HS; se habilita el power-up timer y se compila una vez para guardar.

1.3

Activar la librería en el Library Manager

▶ 2:44

Hasta ahora se trabajó con registros; aquí se empieza a usar librerías. En el Library Manager se busca Sound y se marca su casilla. Las demás librerías se pueden desmarcar.

1.4

Leer la ayuda (F1)

▶ 3:18

Con F1 se abre la ayuda, que funciona sin internet. Buscando sound en el índice aparecen las dos funciones: Sound_Init, que dice en qué puerto y pin está el parlante, y Sound_Play, que toca una frecuencia en Hz durante cierto tiempo en milisegundos.

La librería configura el pin como salida sola, pero hay que saber manejar TRIS porque a veces toca hacerlo a mano.

Fase 2

La melodía

2.1

Programa de prueba

▶ 4:22

Con Ctrl + espacio se ven las funciones disponibles. Se indica que el parlante está en RD0 y dentro del while(1) se tocan varios tonos seguidos. Para un silencio basta un Delay_ms.

void main() {
  Sound_Init(&PORTD, 0);      // parlante en RD0
  while (1) {
    Sound_Play(1000, 200);    // 1 kHz durante 200 ms
    Sound_Play(2000, 200);
    Sound_Play(3000, 200);
    Delay_ms(500);            // silencio
    Sound_Play(5000, 400);
  }
}
2.2

Simular en Proteus

▶ 6:02

En Proteus se pone el parlante (SPEAKER) en RD0, se carga el .hex y se pone la misma frecuencia del cristal que en MikroC; si no coinciden, la melodía no suena como debe. Para una melodía de verdad hay que saber la frecuencia de cada nota, su duración y las pausas; en el video se toca la introducción de un juego clásico.

Fase 3

Etapa de potencia

3.1

No conectar el parlante directo

▶ 7:12

Cada pin del micro da como mucho 20 a 25 mA y un parlante tiene 4 u 8 Ω, así que se puede dañar el pin. Se pone un transistor como el TIP41: la base con una resistencia al pin, el emisor a tierra y el parlante entre el colector y una fuente aparte, que puede ser de 10 V o más.

3.2

Diodo para la carga inductiva

▶ 8:18

El parlante, un relé o una bobina son cargas inductivas: no aceptan cambios bruscos de corriente y al conmutar invierten el voltaje, lo que puede dañar el transistor. Por eso se pone un diodo 1N4001 en paralelo con la carga, con el cátodo hacia el positivo de la fuente.

Siempre que haya una bobina (parlante, relé, motor) se pone el diodo de protección.

3.3

Darlington para saturar

▶ 9:23

Si el transistor no se satura bien con una carga de baja impedancia, se usa un Darlington: el emisor del primero va a la base del segundo y los colectores se unen. La ganancia total es el producto de las dos (100 × 100 = 10.000). También se puede usar uno que ya venga armado, como el TIP122 o el TIP127.
