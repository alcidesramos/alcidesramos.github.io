Monitoreo y control con Ubidots

Continuación del monitoreo con Ubidots. Primero se cambia al PIC18F25K50, que usa registros ANSEL. En Ubidots se agregan las variables luces y nivel con un switch y un slider. El PIC pide el último valor de cada una con un GET, y una máquina de estados busca en la respuesta el campo value; si no llega nada en unos 2 segundos se sale. El valor de luces prende un LED y el de nivel se lleva al DAC de 5 bits con funciones generadas en MPLAB X. Al final se crea un evento que manda un correo si la temperatura pasa de 30.

▶ 0:34

1.2

Registros ANSEL

▶ 2:46

En este micro la parte análoga se configura por puerto con ANSELA, ANSELB y ANSELC. Se ponen en 0 (todo digital) y solo AN0 en 1.

ANSELA = 0;
ANSELB = 0;
ANSELC = 0;
ANSELA.b0 = 1;   // AN0 analogo

Fase 3

Máquina de estados

3.1

Variables

▶ 10:06

El LED de salida, los estados (capturar l, u, e, comillas y esperar el final), el valor recibido, la trama de 50 caracteres, el contador y la variable demora para salir si no hay respuesta.

enum estados_ {cap_l, cap_u, cap_e, cap_co, esp_final};
char estado_rec = cap_l;
float valor_rx;
char trama_rx[50];
char contador_trama = 0;
unsigned long demora = 0;   // para salir de la lectura
3.2

Primer estado

▶ 12:57

Se limpia todo, incluso los errores de recepción. En el primer estado se guarda el dato solo si es la l; si no, se vuelve a empezar. No se usan interrupciones: se espera la respuesta un tiempo máximo.

memset(trama_rx, 0, 50);
demora = 0;
contador_trama = 0;
estado_rec = cap_l;
RCIF_bit = 0;
CREN_bit = 0;   // borra errores de recepcion
CREN_bit = 1;
while (demora < 66667) {
  demora++;
  switch (estado_rec) {
    case cap_l:
      if (RCIF_bit == 1) {
        dato_rx = UART1_Read();
        trama_rx[contador_trama] = dato_rx;
        if (dato_rx != 'l') contador_trama = 0;
        else {
          contador_trama++;
          estado_rec = cap_u;
        }
        RCIF_bit = 0;
      }
      break;
    // ... cap_u, cap_e, cap_co y esp_final
  }
}
return 0;
3.3

Medir el tiempo con el debugger

▶ 15:44

Con el debugger de MikroC y el Watch Clock se mide cuánto tarda el ciclo: con 10000 vueltas son unos 300 ms. Con una regla de tres, para 2 segundos hacen falta unas 66667 vueltas.

3.4

Resto de estados

▶ 20:10

Si llega la u pasa a esperar la e, luego las comillas, y después guarda todo hasta la llave de cierre. Si un dato no es el esperado vuelve al principio. Al llegar la llave retorna 1 sin esperar más; si se acaba el tiempo retorna 0, que sirve para saber que no hay conexión.

Control

4.1

Prender el LED

▶ 23:34

Se pide la variable luces, se lee la respuesta y con strtok se toma lo que está entre los dos puntos y la llave. Si vale 1.0 se prende el LED.

lee_trama();
strcpy(captu, strtok(trama_rx, ":"));
strcpy(captu, strtok(0, "}"));
valor_rx = atof(captu);
if (valor_rx == 1.0) led_out = 1; else led_out = 0;
Delay_ms(200);

4.3

Pedir el nivel

▶ 28:19

4.4

DAC con MPLAB X

▶ 28:53

MikroC no trae librería del DAC para este micro. Se crea un proyecto en MPLAB X, se configura el DAC de 5 bits con MCC y se generan las funciones. Se copian a MikroC cambiando el tipo uint8_t por char.

Se inicializa el DAC antes del while. Como es de 5 bits (0 a 31), la salida es valor × 31 / 5.

4.5

▶ 32:21

4.6

▶ 32:55
