Dado electrónico con PIC

Se usan 14 LEDs (7 por dado) y el oscilador interno a 4 MHz, así quedan libres casi todos los pines; RA4 es de drenador abierto y necesita resistencia de pull-up. Un arreglo constante decodifica cada número en los LEDs que se prenden. Como los LEDs no están en un solo puerto, se escriben funciones para poner, borrar y leer un bit por medio de un puntero. borrar_dado apaga los 7 LEDs y mostrar_dado recorre los bits del número. El valor aleatorio usa el Timer0 y el Timer2 corriendo libres (0 a 255) como semilla de srand; rand se escala de 1 a 7 con una función como map de Arduino.

Mostrar el número

2.1

Decodificador

▶ 5:50

Cada número es un patrón de 7 bits. Las funciones setbit, clearbit y readbit trabajan sobre cualquier variable o puerto por medio de un puntero.

// decodificador de dados
const char numeros[] = {0b0000000, 0b1000000, 0b0001001, 0b1001001, 0b0101101, 0b1101101, 0b0111111};

void setbit(unsigned int *port, char bit)
{
  *port |= (1 << bit);
}

void clearbit(unsigned int *port, char bit)
{
  *port &= ~(1 << bit);
}

3.2

srand, rand y map

▶ 15:20

Se siembra srand con el timer y el número anterior, rand da un valor de 0 a 32767 y map lo lleva al rango del dado. Se repite si queda fuera de 1 a 6.

unsigned char random1()
{
  float temp;
  do {
    srand(tmr0 * random_num * random_num);
    temp = rand();
    valor = map(temp, 0, 32767, 1, 7);
    random_num = valor;
  } while ((random_num < 1) || (random_num > 6));
  return random_num;
}
