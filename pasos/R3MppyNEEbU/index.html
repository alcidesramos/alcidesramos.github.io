Clase 117: Identificar la planta y sintonizar el PID

Cuarto capítulo de la serie del motor DC. Se le da al motor un escalón de 0 a 4200 durante 10 segundos y se graban las RPM con Teleplot, exportando a CSV. Un script de MATLAB carga la columna de datos y la grafica. Con la app PID Tuner se identifica la planta a partir de la respuesta al escalón (modelo de un polo, ajuste de 83%) y se obtienen las constantes del PID. Esos valores se cargan en PID.h, el control se ejecuta en la interrupción del timer y se verifica en Teleplot que la velocidad sigue al set point y se recupera cuando se frena el motor.

Fase 1

Respuesta al escalón

1.1

Aplicar el escalón

▶ 1:08

En el main, antes del while, se lleva el PWM al máximo durante 10 segundos y luego se apaga. Hay que dejar de tomar datos antes de que se apague.

En el callback del timer se comenta el mapeo y el PWM: el motor recibe el escalón directo y solo se envían las RPM.

// main.c
PWM_valor(&PWM1, 4200);
HAL_Delay(10000);
PWM_valor(&PWM1, 0);

// timer.c (en el callback)
sprintf(texto,">IN:%.1f\n",RPM);
uartx_write_text(&huart1, texto);
1.2

Capturar con Teleplot y exportar

▶ 2:44

Para un solo dato Teleplot funciona muy bien. Se resetea la tarjeta y se abre el puerto al mismo tiempo para capturar desde el arranque.

Se exporta con Export to CSV, con separador punto y coma, y se guarda como teleplot.csv en la carpeta del script de MATLAB.

Fase 2

MATLAB

2.1

Script para cargar los datos

▶ 4:55

El CSV tiene el tiempo en la primera columna y los datos en la segunda. El script toma la segunda columna y la grafica.

Con esa gráfica impresa también se puede identificar la planta a mano (por ejemplo con el 63% para la constante de tiempo), pero aquí se deja que MATLAB lo haga.

clc, clear all, close all

data = readmatrix('teleplot.csv');

% Extraer columna 2
data_out_tele = data(:, 2);

figure(1);
plot(data_out_tele, 'r');
title('SALIDA');
xlabel('Tiempo');
ylabel('PWM');
grid on;
Fase 3

PID Tuner

3.1

Abrir PID Tuner

▶ 6:01

En APPS se abre PID Tuner. Se elige un PID estándar y en Plant se selecciona identificar una nueva planta, lo que abre la herramienta de identificación.

3.2

Importar la respuesta al escalón

▶ 6:32

En Get I/O Data se elige Step Response. La salida es la variable data_out_tele, la amplitud del escalón es 4200 (lo que se aplicó al PWM) y el tiempo de muestreo es el del sistema: 20 ms.

3.3

Estimar la planta

▶ 7:55

Con Auto Estimate MATLAB ajusta un modelo de un polo con aproximadamente 83% de ajuste. Se aplica y aparece la planta con su ganancia Kp y constante Tp1.

3.4

Sintonizar y ver parámetros

▶ 8:47

De vuelta en PID Tuner se mueven los controles de tiempo de respuesta y robustez, y con Show Parameters se leen las constantes.

En este caso: Kp = 348.8513, Ti = 44.648 y Td = 0.52006.

PID Tuner entrega Ti y Td en forma estándar. Si tu librería usa la forma paralela (kp, ki, kd), la equivalencia es ki = Kp/Ti y kd = Kp·Td; también puedes pedir el formato paralelo en PID Tuner.

Fase 4

PID en el STM32

4.1

Constantes en PID.h

▶ 9:51

Se ajusta el rango de salida a 0-4200 (el máximo del PWM) y se cargan las constantes obtenidas. El tiempo de muestreo debe ser el mismo del timer (20 ms).

#define PID_muestreo 20e-3
#define PID_kp 348.8513
#define PID_ki 44.648
#define PID_kd 0
#define PID_SET 0

#define PID_MAX 4200
#define PID_MIN 0
4.2

Control en la interrupción

▶ 9:18

Al PID le entran las RPM leídas y su salida ut va al PWM. Se envían set point y RPM a Teleplot para ver la respuesta.

El escalón del main se deja comentado: el main queda libre.

setpoint=ADC_Read(&hadc1)*222.0/4095.0;
PID_Control(RPM);
PWM_valor(&PWM1, ut);

sprintf(texto,">SP:%.1f\n",setpoint);
uartx_write_text(&huart1, texto);
sprintf(texto,">OUT:%.1f\n",RPM);
uartx_write_text(&huart1, texto);
4.3

Resultado

▶ 13:46

En Teleplot se arrastran SP y OUT a la misma gráfica: la velocidad sigue al set point con rapidez. El ruido del set point viene del potenciómetro.

Si se intenta frenar el motor con la mano, el PID aumenta la salida y mantiene la velocidad, algo imposible en lazo abierto.
