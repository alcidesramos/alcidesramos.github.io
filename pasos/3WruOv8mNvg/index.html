Clase 121: TFT ILI9225: figuras y fonts

Primera parte del trabajo con la pantalla TFT ILI9225 (176x220, no táctil). La librería original se tomó de internet y se mejoró: elige el puerto SPI, detecta la orientación vertical u horizontal, usa las librerías de retardo del canal, agrega figuras (rectángulos, triángulos y círculos rellenos o con borde) y permite escribir con cualquier tipo de letra. Se configura el reloj a 100 MHz, SPI1 en modo solo transmisión y los pines CS, RST, CMD (RS) y LED como salidas. Luego se dibuja el fondo, un círculo y textos, y se crea un font nuevo con GLCD Font Creator.

Fase 1

La pantalla

1.1

Pines de la ILI9225

▶ 0:31

Además de la alimentación (puede ser 5 V) se usan seis pines: CS, CLK y SDI del SPI; LED para encender o apagar la luz de fondo; RST para el reset; y RS, que es el pin de comando (CMD).

Solo se envían datos a la pantalla, así que no se necesita MISO.

Fase 2

Configuración

2.1

Reloj a 100 MHz

▶ 2:08

Se crea el proyecto TFT_canal con la Blackpill. En RCC se pone cristal externo y con el PLL se lleva a 100 MHz.

2.2

SPI1 y pines de control

▶ 2:43

SPI1 en modo Transmit Only Master: solo se usan el reloj y MOSI.

PB2 como salida con el nombre TFT_CS, PB1 como TFT_RST, PB0 como TFT_CMD y otro pin libre como TFT_LED. Estos cuatro pueden ir en cualquier pin.

Si no quieres nombrar los pines en CubeMX, decláralos solo como salida y define puerto y pin en ILI9225.h.

Fase 3

Librerías

3.1

Incluir las librerías

▶ 5:56

Se crea la carpeta Librerias con ILI9225, fonts, imagenes y delays, y se agrega al include path.

fonts.h e imagenes.h contienen variables, así que se incluyen en main.c y no dentro de la librería; si no, salen errores de definición múltiple.

#include "ILI9225.h"
#include "fonts.h"
#include "imagenes.h"
3.2

Configurar ILI9225.h

▶ 10:05

Se pone el tamaño en posición vertical (176 x 220). Para usarla horizontal se activa LANDSCAPE y la librería intercambia ancho y alto.

tft_spi_port indica el SPI usado. Si los pines no se definieron en CubeMX, se descomentan las definiciones manuales.

#define WIDTH   176
#define HEIGHT  220
//#define LANDSCAPE      // descomentar para horizontal

#define tft_spi_port hspi1

// solo si no se definen de forma gráfica
#define TFT_CMD_Pin        GPIO_PIN_0
#define TFT_CMD_GPIO_Port  GPIOB
#define TFT_RST_Pin        GPIO_PIN_1
#define TFT_RST_GPIO_Port  GPIOB
#define TFT_CS_Pin         GPIO_PIN_2
#define TFT_CS_GPIO_Port   GPIOB
Fase 4

Dibujar

4.1

Iniciar y pintar el fondo

▶ 11:42

Primero se inicia la pantalla y se enciende el LED; si no, la pantalla queda apagada.

Luego se pinta un rectángulo de toda la pantalla como fondo; sin esto la pantalla muestra ruido.

lcd_init();
HAL_GPIO_WritePin(TFT_LED_GPIO_Port, TFT_LED_Pin, 1);  // enciende
draw_fill_rectangle(0, 0, WIDTH, HEIGHT, COLOR_NAVY);
4.2

Figuras

▶ 14:27

Sobre el fondo se dibuja lo que se quiera: líneas, rectángulos, triángulos y círculos, rellenos o con borde de un grosor dado.

draw_circle_borde(100, 100, 30, COLOR_CYAN, 4);
4.3

Texto con y sin fondo

▶ 15:01

draw_string_fondo escribe con color de letra y color de fondo; draw_string escribe sobre lo que ya hay en la pantalla.

El último parámetro es el font: la librería trae varios y se pueden agregar más.

draw_string_fondo(0, 0, "Hola", COLOR_RED, COLOR_BLACK, font1);
draw_string(100, 100, "ARZ", COLOR_RED, font4);
Fase 5

Crear un font propio

5.1

Generar el font

▶ 17:53

En GLCD Font Creator: File > New Font > Import an existing system font, se escoge la letra, el estilo y el tamaño (por ejemplo 20) y se acepta sin cambiar más.

Se pueden ajustar los caracteres uno por uno. El proceso tarda un poco; al terminar se exporta para mikroC.

5.2

Adaptarlo a STM32

▶ 19:39

Se pega el arreglo al final de fonts.h con un nombre nuevo (por ejemplo font5).

En la cabecera del arreglo el primer número (31 en el ejemplo) se deja; el segundo (41) se divide entre 8 y se redondea hacia arriba: 41/8 = 5.1, se pone 6.

El tipo short que genera el programa se cambia a char: en mikroC short era de 8 bits, en STM32 no.

5.3

Resultado

▶ 22:51

Con font5 el texto aparece con el nuevo tipo de letra. Así se puede usar cualquier font en la pantalla.
