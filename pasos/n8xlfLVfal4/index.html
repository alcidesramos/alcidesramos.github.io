Presión con el sensor HX710

El HX710 es un ADC de 24 bits que acompaña al sensor de presión MPS20N0040D (hasta 40 kPa). Se lee con dos pines cualquiera: reloj (salida) y datos (entrada). La librería HX710.c/.h, adaptada de la del HX711, promedia lecturas a 10 o 40 Hz, convierte a presión con un offset y un factor de calibración, y permite tarar y calibrar con dos pulsadores. Se prueba aplicando presión con una jeringa.

Fase 1

El sensor

1.1

Qué es el HX710

▶ 0:00

El HX710 no es el sensor: es un amplificador con ADC de 24 bits para señales de pocos milivoltios, como una celda de carga. En este módulo viene con el MPS20N0040D, que mide hasta unos 40 kPa (5,8 psi). Sirve para presión de agua o aire, nivel de agua o presión sanguínea.

Fase 2

Configurar el micro

2.1

Reloj

▶ 1:49

Crea el proyecto hx710_canal (STM32F401) y activa el cristal externo con el PLL a máxima velocidad.

2.2

Pines

▶ 2:24

PA0 entrada SW1_TARAR (botón de la tarjeta), PA3 entrada SW1_CAL, PA1 salida HX710_CK (reloj), PA2 entrada HX710_DAT (datos) y PC13 salida led. Puedes usar cualquier pin, pero respeta los nombres que usa la librería. Activa USART1 asíncrono a 9600.

2.3

Pull-up en las entradas

▶ 17:38

En System Core > GPIO configura con Pull-up todas las entradas: SW1_TARAR, SW1_CAL y HX710_DAT. Solo la salida de reloj queda sin tocar.

En el video los botones no respondían hasta que se activaron las resistencias pull-up.

3.2

Valores de calibración en HX710.c

▶ 6:29

Las variables ya están declaradas como externas en el .h; sus valores se dan en el .c. offset_manualhx es la lectura sin presión y calibrahx la lectura con la presión de prueba menos el offset. prueba_hx es la presión conocida que aplicas (en el video se supone 30 kPa).

const float offset_manualhx = 6941123;               //offset, valor leido a 0
const float calibrahx = 8388607 - offset_manualhx;  //valor a la calibracion menos el offset

//IMPORTANTE ESTE VALOR presion conocida
const float prueba_hx = 30.0;  //presion de prueba para calibracion

float factor_hx = prueba_hx / calibrahx;  //factor de multiplicativo a lectura

int32_t offset_hx = offset_manualhx;  //carga el offset manual al offset
int32_t celda_hx = 0;
float presion_hx, cal_hx;
3.3

Retardos

▶ 13:38

En HX710.h delay_promedio fija cada cuánto se toma una muestra al promediar: 150 ms sirve para 10 Hz; para 40 Hz se puede bajar. Más muestras dan más precisión pero una lectura más lenta.

#define delay_promedio 150  //retardo en ms para promedio
#define delay_pulso 1       //retardo pulsos, en microsegundos
Fase 4

Calibración manual

4.1

Inicializar y tarar

▶ 8:13

Antes del while inicializa el sensor y tara con 50 lecturas a 10 Hz. Imprimir el offset sirve para copiarlo en offset_manualhx.

uartx_write_text(&huart1, "Iniciando\r\n");
HX710_init();          //inicia LA CELDA
HX710_tarar(50, 10);   //Tara el sistema: numero de datos, frecuencia

//si desea manda el offset inicial
sprintf(texto, "Tarado offset=%.1lu\r\n", offset_hx);
uartx_write_text(&huart1, texto);
4.2

Tomar los dos valores

▶ 10:50

Corre el programa sin presión y copia el offset en offset_manualhx. Luego aplica la presión conocida, resetea el micro manteniéndola y copia el valor que salga para calcular calibrahx. Después puedes comentar el envío del offset.

Fase 5

Leer la presión

5.1

Promediar y convertir

▶ 13:04

HX710_promedio(muestras, frecuencia) admite 10 o 40 Hz. Se resta el offset, se multiplica por el factor y se recortan los negativos.

while (1)
{
    presion_hx = HX710_promedio(10, 10) - offset_hx;  //10 muestras a 10Hz
    presion_hx = presion_hx * factor_hx;
    if (presion_hx <= 0) presion_hx = 0;
    sprintf(texto, "Pres=%.1f\r\n", presion_hx);
    uartx_write_text(&huart1, texto);
}

Si solo sale Pres= sin número, falta activar Use float with printf en Properties > C/C++ Build > Settings > MCU Settings.

5.2

Probar con la jeringa

▶ 15:53

Sin presión marca 0 y al empujar la jeringa sube a 15, 20 o 30 según la presión. No hace falta un retardo: el promedio de 10 muestras ya lo implica.

Fase 6

Tara y calibración con botones

6.1

Código de los botones

▶ 16:31

Con SW1_TARAR presionado el sistema busca su cero. Con SW1_CAL presionado, mientras se aplica la presión conocida, toma 50 muestras y recalcula el factor para que esa lectura valga prueba_hx.

if (PIN_READ(SW1_TARAR) == 0)
{
    HAL_GPIO_WritePin(led_GPIO_Port, led_Pin, 0);
    uartx_write_text(&huart1, "TARANDO\r\n");
    HAL_Delay(300);
    HX710_tarar(50, 10);
    //OPCIONAL PARA SABER EL DATO DEL TARADO
    sprintf(texto, "Tarado offset=%.1lu\r\n", offset_hx);
    uartx_write_text(&huart1, texto);
}

if (PIN_READ(SW1_CAL) == 0)
{
    HAL_GPIO_WritePin(led_GPIO_Port, led_Pin, 0);
    uartx_write_text(&huart1, "CALIBRANDO\r\n");
    HAL_Delay(2000);
    cal_hx = HX710_promedio(50, 10) - offset_hx;  //promedia 50 datos a 10Hz
    factor_hx = prueba_hx / cal_hx;
}
6.2

Tarar

▶ 18:50

Mantén presionado el botón de la tarjeta hasta que aparezca TARANDO: el sistema vuelve a cero. El offset que imprime también sirve para la calibración manual.

6.3

Calibrar

▶ 19:24

Aplica la presión conocida, mantén el botón de calibrar hasta que salga CALIBRANDO y espera a que vuelvan los datos: esa presión queda en 30. Al soltar la jeringa vuelve a 0.
