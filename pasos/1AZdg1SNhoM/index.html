Crea tus propias fuentes para OLED

Partiendo de la librería OLED SSD1306 de una clase anterior, se usa el programa gratuito GLCD Font Creator de MikroElektronika para importar cualquier fuente instalada en el PC, exportarla como arreglo en C (formato mikroC) y adaptarla a la librería: cambiar el tipo, añadir el ancho y el número de bytes por columna al inicio del arreglo. Se prueban fuentes de 10x11 y 25x22 en Proteus y se corrigen letras editándolas en el propio programa.

Fase 1

Crear la fuente en GLCD Font Creator

1.1

Abrir GLCD Font Creator

▶ 1:10

El programa es gratuito y fue hecho por MikroElektronika para sus compiladores; aquí se adapta su salida para usarla con cualquier compilador, en este caso STM32CubeIDE.

1.2

Importar una fuente existente

▶ 1:25

Ve a File > New Font > Import An Existing System Font. Elige la fuente, el estilo (normal, negrita, cursiva…) y el tamaño. Con 8 puntos sale el tamaño más pequeño que cabe bien en la pantalla.

1.3

Esperar a que genere los caracteres

▶ 2:00

El programa procesa un rato y genera los caracteres del 32 al 127. Si la fuente se ve fea en ese tamaño, crea otra (en el video se cambia a una fuente más negrita de 10x11).

1.4

Exportar a código C

▶ 2:45

Pulsa Export for GLCD y elige la pestaña mikroC (no mikroBasic). Fíjate en el tamaño que aparece en el comentario, por ejemplo FontSize : 10 x 11: el primer número es el ancho en columnas y el segundo la altura en píxeles. Copia el código con Copy Code To Clipboard.

Asegúrate de estar en la pestaña mikroC; si copias la de mikroBasic el formato no sirve.

Fase 2

Adaptar la fuente a la librería

2.1

Pegar en fonts.h

▶ 3:26

En el proyecto, abre Core/Librerias/fonts.h y pega el arreglo al final. Borra los comentarios del encabezado que no necesitas.

2.2

Cambiar el tipo y añadir ancho y bytes

▶ 3:45

Cambia unsigned short por unsigned char, ponle un nombre (font3, font4…) y al inicio del arreglo agrega dos valores: el ancho y el número de bytes por columna, que es la altura dividida entre 8 y redondeada hacia arriba.

Para 10x11: ancho 10 y 11/8 = 1,4 → 2 bytes.

const unsigned char font3[] = {10,2,
    0x06, 0x00, 0x00, 0x00, 0x00, /* ...datos exportados... */
};

No olvides la coma después del 2; sin ella el compilador da el error "expected '}' before...".

2.3

Usar la nueva fuente

▶ 5:30

Pasa la dirección de la fuente como último parámetro de OLED_print_text. Cada texto puede usar una fuente distinta.

OLED_print_text(0,0,"SUSCRIBETE",&font3);
OLED_print_text(0,2,"    AL",&font1);
OLED_print_text(0,4,"CANAL",&font2);
Fase 3

Fuente grande de 25x22

3.1

Crear una fuente más grande

▶ 6:00

Repite el proceso con una fuente más grande, por ejemplo Cooper Black de 18 puntos. Puedes elegir cursiva, negrita, subrayado o tachado. Las fuentes nuevas lucen mejor en tamaños grandes.

3.2

Ajustar el arreglo

▶ 7:32

Exporta a mikroC, pega en fonts.h como font4 y calcula la cabecera: el tamaño es 25 x 22, así que el ancho es 25 y 22/8 = 2,75 → 3 bytes.

//GLCD FontName : Cooper_Black25x22
const unsigned char font4[] = {25,3,
    0x0D, 0x00, 0x00, /* ...datos exportados... */
};

El segundo valor es la altura entre 8 (redondeado hacia arriba), no el ancho. Si pones un valor incorrecto el texto sale desordenado en la pantalla.

Fase 4

Corregir letras y probar

4.1

Probar en Proteus

▶ 9:10

Compila y corre la simulación. Al escribir DIOS con font4 se nota que la I queda muy separada de la O porque la letra está pegada a la izquierda de su celda.

4.2

Mover la letra dentro de su celda

▶ 7:00

En GLCD Font Creator selecciona la letra y usa Shift/Move para moverla a la derecha o al centro. Guarda el proyecto (si no lo guardas no se aplica), vuelve a exportar a mikroC y reemplaza el arreglo en fonts.h aplicando de nuevo el cambio de tipo y la cabecera {25,3,.

4.3

Resultado

▶ 13:07

Ahora la palabra DIOS queda con la I centrada. Con este método puedes crear y ajustar cualquier tipo de letra para tus proyectos con OLED.
