Conociendo STM32CubeMonitor, parte 1

STM32CubeMonitor lee las variables del micro mientras el programa corre, usando el mismo programador (ST-Link original o el clon WeAct que permite debug). Es muy útil para identificar una planta, ver un tiempo de muestreo o preparar un PID. Se monitorea la lectura de un potenciómetro en el ADC: se configura el probe y el archivo .elf, se grafica la variable, se cambia a barras, se agrega un gauge y luego una segunda variable con el voltaje.

Fase 1

El programa del micro

1.1

Variables globales

▶ 0:32

El programa lee el canal análogo cada milisegundo y guarda el valor (0 a 4095) en una variable global: CubeMonitor solo ve variables globales.

uint16_t codigo;
float voltaje;

while (1)
{
  codigo = ADC_Read();
  voltaje = 3.3 * codigo / 4095.0;
  HAL_Delay(1);
}
1.2

Habilitar el debug

▶ 1:04

En el .ioc, System Core → SYS → Debug: Serial Wire (y Timebase en SysTick). Compila y programa el micro; compilar no basta.

Fase 2

Configurar CubeMonitor

2.1

Flujo básico

▶ 2:19

Al abrir aparece un ejemplo (Basic_Flow). Si lo dañas, recupéralo con Import → Local → STM32CubeMonitor_BasicFlow.json.

2.2

Elegir el ST-Link

▶ 2:53

Doble clic en el nodo de salida (myProbe_Out), en Probe pulsa el lápiz, elige tu ST-Link, ponle un nombre y la frecuencia máxima. Haz lo mismo en el nodo de entrada (myProbe_In). Se hace una sola vez.

2.3

Archivo .elf y variables

▶ 3:26

Doble clic en myVariables, en Executable pulsa el lápiz y pega la ruta de la carpeta Debug del proyecto; elige el .elf. En la lista marca la variable codigo.

Si una variable declarada no aparece, puede ser que el compilador la eliminó por no usarse.

Fase 3

Ver los datos

3.1

Deploy y Start Acquisition

▶ 5:09

Pulsa DEPLOY, luego DASHBOARD y START ACQUISITION. Al mover el potenciómetro la gráfica sube y baja en tiempo real.

3.2

Gráfica de barras

▶ 6:18

En el nodo myChart puedes cambiar el tipo a barras. Después de cambiar algo, si DEPLOY no se activa, mueve cualquier nodo para que lo detecte.

3.3

Agregar un gauge

▶ 7:23

Arrastra un subflow Single value, elige la variable codigo y conéctale un nodo gauge con rango de 0 a 5000. Ajusta el tamaño de cada elemento para armar tu dashboard.

3.4

Una segunda variable

▶ 9:37

Agrega el cálculo del voltaje en el programa, vuelve a programar el micro, recarga la lista en myVariables y marca voltaje. En la gráfica puedes ocultar una de las dos variables haciendo clic en su nombre, mostrar los puntos y hacer zoom.
