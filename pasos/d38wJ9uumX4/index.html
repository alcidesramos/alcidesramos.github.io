Clase 36: printf por USB CDC

Repasamos cómo activar USB Device CDC (USB_OTG_FS en Device_Only, middleware USB_DEVICE con Virtual Port Com y reloj con cristal externo a 84 MHz) y modificamos printf_out.h con #ifdef para que printf salga por la UART o por USB según una sola línea.

Activar USB CDC

USB Device CDC

Fase 2

printf_out.h universal

2.1

UART o USB con #ifdef

▶ 3:25

Si está definido uartx, printf va a la UART con __io_putchar. Si comentas el #define, se compila la versión USB, que redefine _write y manda el bloque completo con CDC_Transmit_FS, esperando mientras el USB está ocupado:

#include "string.h"
#include "stdio.h"
#include "main.h"
#include "usbd_cdc_if.h"
//#define uartx huart1   // descomenta para usar el puerto serial
#ifdef uartx
extern UART_HandleTypeDef uartx;
int __io_putchar(int ch)
{
    HAL_UART_Transmit(&uartx, (uint8_t *)&ch, 1, 0xFFFF);
    return ch;
}
#else   // si no se define uartx, printf se asocia al USB CDC
int _write(int file, char *ptr, int len)
{
    while (CDC_Transmit_FS((uint8_t *)ptr, len) == USBD_BUSY);   // espera que el dato sea enviado
    return len;
}
#endif

Si el compilador avisa "implicit declaration of function CDC_Transmit_FS", falta #include "usbd_cdc_if.h", como está arriba.
