Un DAC hecho con PWM y un filtro

Lección 23 del curso. Muchos micros antiguos no tienen conversor digital a análogo. Se puede hacer uno generando un PWM de alta frecuencia y filtrándolo con un RC pasa bajos de primer orden, que deja pasar solo el valor medio. Se compara el efecto de distintos condensadores (más capacidad, menos rizado pero respuesta más lenta). Luego, con un PIC18F2550, un potenciómetro controla el voltaje de salida. Para conectarlo a otro circuito se agrega un seguidor de voltaje, un transistor TIP41 para manejar un motor y un amplificador no inversor para llevar la salida de 0 a 5 V hasta casi 10 V.

Fase 1

Filtro pasa bajos

1.1

Idea: PWM filtrado

▶ 0:00

El objetivo es que el micro saque por un pin un voltaje análogo que siga a un potenciómetro, para controlar un motor, un PLC o un variador. Se genera un PWM de frecuencia alta y se filtra; el analogWrite de Arduino también es un PWM, no una salida análoga real.

1.2

Filtro RC de primer orden

▶ 1:38

Una resistencia en serie y un condensador a tierra forman un filtro pasa bajos de primer orden (un solo condensador). La reactancia del condensador es Xc = 1/(2πfC): a frecuencias altas es casi un corto y la señal se va a tierra; a frecuencias bajas es un circuito abierto y la señal pasa.

1.3

Escoger el condensador

▶ 3:17

Con la misma señal se prueban condensadores de 10 nF, 100 nF, 220 nF y 470 nF. Más capacidad baja la frecuencia de corte y quita más rizado, pero el circuito tarda más en responder. Es un compromiso que escoge el ingeniero; aquí se usan 220 nF con 1 kΩ, que dan una frecuencia de corte de unos 723 Hz.

Fase 2

El programa

2.1

PWM a 100 kHz

▶ 7:08

Proyecto con un PIC18F2550 a 8 MHz. El potenciómetro entra por AN0 y el PWM sale por CCP1 (RC2). Se inicia el PWM a 100 kHz para que el filtro lo deje bien liso.

unsigned int codigo;
float DAC;

ADCON1 = 0;            // todo análogo
TRISA = 0b11111111;    // todo entrada
TRISC = 0;             // salida
PWM1_Init(100000);
PWM1_Start();
2.2

De 10 bits a 8 bits

▶ 9:59

El ADC va de 0 a 1023 y el ciclo útil de 0 a 255: hay 4 veces de diferencia, así que basta dividir entre 4.

while (1) {
  codigo = ADC_Read(0);
  DAC = codigo / 4.0;
  PWM1_Set_Duty(DAC);
}
2.3

Resultado

▶ 11:42

Al mover el potenciómetro, el voltímetro después del filtro va de 0 a casi 5 V. Es un DAC de unos 8 bits de resolución.

Fase 3

Etapa de salida

3.1

Seguidor de voltaje

▶ 12:16

Si se conecta otro circuito directo al filtro, su impedancia cambia el voltaje. Lo mínimo es un seguidor de voltaje con un operacional de una sola fuente, como el LM358.

3.2

Transistor para dar corriente

▶ 15:09

El operacional no da corriente para un motor y se puede dañar. Se agrega un transistor TIP41 como seguidor de emisor, alimentado con una fuente mayor (12 V). Para no perder la caída del transistor, la realimentación del operacional se toma del emisor.

3.3

Operacional rail to rail

▶ 18:34

El LM358 alimentado a 5 V no llega a 5 V en la salida. Un operacional rail to rail, como el AD8031, sí llega a todo el rango de su alimentación.

3.4

Subir el rango

▶ 19:45

Si el sistema necesita 0 a 10 V, se usa un amplificador no inversor. Su ganancia es 1 + R1/R3: con dos resistencias iguales la ganancia es 2 y la salida va de 0 a casi 10 V. Con un potenciómetro en R1 la ganancia es ajustable; hay que alimentar el operacional con más voltaje, por ejemplo 15 V.
