El DAC interno de los PIC modernos

Lección 24 del curso. Los micros más nuevos, y a menudo más económicos, ya traen DAC. Primero se usa el PIC12F1822, de 8 pines, cuyo DAC es de 5 bits (32 niveles): un potenciómetro en RA1 controla el voltaje en RA0. Después el mismo programa pasa casi sin cambios al PIC16F1705, que tiene un DAC de 8 bits con dos salidas, gracias a la compatibilidad entre micros de Microchip. Por último se usa el operacional interno del 16F1705 como seguidor, así que ya no hace falta un operacional externo; solo queda el transistor para dar corriente.

Fase 1

DAC de 5 bits en el 12F1822

1.1

El circuito

▶ 0:00

Es el circuito de la lección 23 sin el PWM ni el filtro: la salida del DAC va al operacional con ganancia, al transistor TIP41 y al motor. El 12F1822 tiene un DAC de 5 bits, es decir, 32 niveles. Para controlar un motor alcanza; si se necesita más precisión, hay que usar otro micro o un DAC externo.

1.2

Configurar el micro

▶ 1:48

Proyecto a 8 MHz con oscilador interno. El potenciómetro va en RA1, que se pone análogo y como entrada. La salida del DAC sale por RA0, y según la hoja de datos ese pin se pone como entrada para que el DAC lo maneje.

unsigned int codigo;
float dac;

// oscilador interno a 8 MHz
SCS1_bit = 1;  SCS0_bit = 0;
IRCF3_bit = 1; IRCF2_bit = 1;
IRCF1_bit = 1; IRCF0_bit = 0;

ANSELA = 0;
ANSELA.B1 = 1;   // entrada análoga
TRISA.B1 = 1;
TRISA.B0 = 1;    // salida del DAC
1.3

Registros del DAC

▶ 4:38

DACCON0 configura el DAC: DACEN lo habilita y DACOE conecta el voltaje al pin DACOUT (RA0). En DACCON1 se escribe el valor de salida, de 0 a 31.

DACCON0 = 0;      // limpia los registros
DACCON1 = 0;
DACEN_bit = 1;    // habilita el DAC
DACOE_bit = 1;    // conecta el DAC a RA0
1.4

De 10 bits a 5 bits

▶ 6:19

El ADC da 1024 códigos y el DAC tiene 32, así que se divide entre 32.

while (1) {
  codigo = ADC_Read(1);
  dac = codigo / 32.0;
  DACCON1 = dac;
}
1.5

Resultado

▶ 7:58

Al mover el potenciómetro, el motor recibe casi 10 V con la ganancia del operacional. Se ahorra el PWM y el filtro de la lección 23.

Fase 2

DAC de 8 bits en el 16F1705

2.1

Dos salidas de DAC

▶ 9:04

El PIC16F1705 tiene un DAC de 8 bits con dos salidas: DAC1OUT1 en RA0 y DAC1OUT2 en RA2. Sus registros son DAC1CON0 y DAC1CON1; el potenciómetro puede seguir en RA1.

2.2

Pasar el programa

▶ 12:22

Los micros de Microchip son muy compatibles: se copia el programa del 12F1822 y solo se agregan los registros del puerto C y se cambian los nombres del DAC. Como el DAC es de 8 bits, se divide entre 4.0 y hay más resolución: 256 niveles.

ANSELA = 0;
ANSELC = 0;
ANSELA.B1 = 1;   // entrada análoga
TRISA.B1 = 1;
TRISA.B0 = 1;    // salida DAC
TRISC = 0;

DAC1CON0 = 0;
DAC1CON1 = 0;
DAC1EN_bit = 1;   // habilita el DAC
DAC1OE1_bit = 1;  // conecta el DAC a RA0

while (1) {
  codigo = ADC_Read(1);
  dac = codigo / 4.0;
  DAC1CON1 = dac;
}
Fase 3

Operacional interno

3.1

OPA1 del 16F1705

▶ 16:16

El 16F1705 también trae operacionales. El OPA1 tiene la entrada positiva en RC0, la negativa en RC1 y la salida en RC2. Se configura con el registro OPA1CON: primero se limpia y luego se habilita.

// configurar operacional
TRISC0_bit = 1;   // entrada +
TRISC1_bit = 1;   // entrada -
TRISC2_bit = 0;   // salida
OPA1CON = 0;
OPA1EN_bit = 1;
3.2

Sin operacional externo

▶ 19:41

Se quita el LM358: la salida del DAC se cablea a la entrada positiva del operacional interno y su salida va al transistor. El operacional del micro es rail to rail, así que llega casi a 5 V. Solo queda el transistor para dar corriente al motor.
