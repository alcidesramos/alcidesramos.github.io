IoT con ESP8266 y XC8

Se toma el programa de MikroC que envía la temperatura de un LM35 y el estado de un pulsador a Ubidots por medio de un ESP8266 con comandos AT, y se pasa a MPLAB XC8. Con el MCC se configura el PIC16F1619 a 4 MHz con oscilador interno, el ADC y la EUSART a 115200 con los pines TX y RX. Las variables y funciones se copian casi iguales; lo que cambia es la parte serial: se crean funciones propias para enviar cadenas constantes y variables con EUSART_Write, se usa string.h, el ADC se lee con ADC_GetConversion y los retardos pasan de Delay_ms a __delay_ms. En Proteus, al cambiar la temperatura del LM35, el valor llega a la plataforma.

2.3

Funciones seriales

▶ 8:00

En XC8 se escriben con EUSART_Write: una para cadenas variables, otra para constantes y una para un carácter.

void UART1_Write_Text(char *trama)
{
  while (*trama) EUSART_Write(*trama++);
}

void manda_serial_const(const char *trama)
{
  while (*trama) EUSART_Write(*trama++);
}

void UART1_Write(char txData)
{
  EUSART_Write(txData);
}
