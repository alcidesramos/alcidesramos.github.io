El ciclo for

Lección 11 del curso. Se explica la estructura del for (valor inicial, condición de permanencia e incremento) y se aplica en un PIC16F877A con LEDs en el puerto B y un display en el puerto D: repetir un procedimiento un número de veces, invertir los LEDs varias veces para un juego de luces, recorrer un vector constante subiendo y bajando, y mostrar los números del 0 al 9 en el display con un vector de códigos.

Fase 1

Cómo funciona el for

1.1

Proyecto nuevo

▶ 0:34

Se crea el proyecto ciclofor en la carpeta Clase 11 con el PIC16F877A a 4 MHz (XT). Conviene no ponerle a los proyectos nombres de palabras de C, como for, para evitar problemas. Los puertos B y D se ponen como salida.

1.2

Estructura del for

▶ 1:43

Entre paréntesis van tres partes separadas por punto y coma: el valor inicial de una variable, la condición para seguir en el ciclo y la operación que cambia la variable. Mientras la condición se cumpla, se repite lo que está entre llaves.

cuenta++ es lo mismo que cuenta = cuenta + 1.

for (cuenta = 0; cuenta < 10; cuenta++) {
  // se repite 10 veces
}
Fase 2

Ejemplos

2.1

Repetir un procedimiento

▶ 3:24

Se definen nombres para los puertos y se copia el procedimiento hola() de las clases anteriores, encima del main. Con una variable char cuenta (no necesita valor inicial porque el for se lo da) se enciende los LEDs, se dice HOLA tres veces y se apagan.

Contar de 0 mientras sea menor que 3, o de 1 mientras sea menor o igual a 3, da las mismas tres vueltas.

#define leds PORTB
#define display PORTD
char cuenta;

leds = 0b11111111;
for (cuenta = 0; cuenta < 3; cuenta++) {
  hola();
}
leds = 0;
Delay_ms(1000);

Si dentro del for hay una sola orden, las llaves se pueden omitir. Con dos o más son obligatorias.

2.2

Juego de luces invirtiendo

▶ 7:19

Se carga un patrón en los LEDs y se invierte varias veces con un for. Cambiando el patrón y el número de vueltas se arman distintos efectos.

leds = 0;
for (cuenta = 0; cuenta < 4; cuenta++) {
  leds = ~leds;
  Delay_ms(100);
}
leds = 0b00110011;
for (cuenta = 0; cuenta < 4; cuenta++) {
  leds = ~leds;
  Delay_ms(100);
}
2.3

Recorrer un vector de ida y vuelta

▶ 11:13

Con el vector constante de luces de la clase anterior, un for creciente recorre las posiciones de 0 a 8 y otro decreciente las recorre de 8 a 0. La misma variable cuenta se reutiliza en todos los for.

Como el for de bajada compara con mayor o igual a 0, se recomienda que la variable tenga signo (signed char) para que pueda pasar a negativo y el ciclo termine bien.

const char luces[] = {0, 0b00000001, 0b00000010, 0b00000100,
                      0b00001000, 16, 32, 64, 128};
signed char cuenta;

for (cuenta = 0; cuenta <= 8; cuenta++) {
  leds = luces[cuenta];
  Delay_ms(100);
}
for (cuenta = 8; cuenta >= 0; cuenta--) {
  leds = luces[cuenta];
  Delay_ms(100);
}
2.4

Contar de 0 a 9 en el display

▶ 14:37

Los códigos de 7 segmentos de 0 a 9 (sacados con el Seven Segment Editor) se guardan en otro vector constante y se recorren igual, hacia arriba y hacia abajo. Un vector puede tener efectos de luces y otro números o letras.

const char codigos[] = {63, 6, 91, 79, 102, 109, 125, 7, 127, 111};

for (cuenta = 0; cuenta <= 9; cuenta++) {
  display = codigos[cuenta];
  Delay_ms(500);
}
for (cuenta = 9; cuenta >= 0; cuenta--) {
  display = codigos[cuenta];
  Delay_ms(500);
}
