Imágenes en la pantalla TFT ILI9225 con STM32

Segunda parte de la pantalla TFT ILI9225 por SPI. Para mostrar una imagen hay que convertirla a un arreglo de colores de 16 bits con el programa LCD Image Converter, configurado en el formato de la pantalla (R5G6B5). El arreglo se pega en imagenes.h con el ancho y alto al inicio y se dibuja con draw_bitmap. También se muestra cómo pasar la pantalla a vertical comentando una sola definición.

Fase 1

Convertir la imagen

1.1

Abrir la imagen

▶ 0:34

Abre lcd-image-converter.exe y en File → Open carga la imagen. En el video, un zorro de 150 x 150 píxeles (pasa el mouse sobre el archivo en Windows para ver el tamaño).

1.2

Opciones de conversión

▶ 1:08

En Options → Conversion deja esta configuración, que es crucial:

  • Preset: Color R5G6B5 (el formato de esta pantalla).
  • Pestaña Image: Split to rows, Block size 16 bit, Little-Endian.
  • Prefix 0x y Delimiter coma.
1.3

Copiar el arreglo

▶ 2:00

Pulsa Show Preview y copia todos los valores que muestra. Ahí también puedes escalar la imagen.

Fase 2

Pegarla en el programa

2.1

Crear la variable

▶ 2:16

Lo copiado no trae el tipo de variable. En imagenes.h crea un arreglo constante, pon primero el ancho y el alto, pega los valores y cierra con llave y punto y coma.

const unsigned int zorro[] = {
  150, 150,
  0xb77b, 0xb77b, 0xb77b, /* ... lo que dio el programa ... */
};
2.2

Dibujarla

▶ 3:27

En el main dibuja la imagen en la posición (0, 0) con escala 1 (puedes escalar 2 o 3 veces). Si quieres texto encima, escríbelo después de la imagen.

lcd_init();
HAL_GPIO_WritePin(TFT_LED_GPIO_Port, TFT_LED_Pin, 1); // enciende la luz
draw_fill_rectangle(0, 0, WIDTH, HEIGHT, COLOR_NAVY);

draw_bitmap(0, 0, 1, zorro);
draw_string(100, 100, "ARZ", COLOR_RED, font5);
Fase 3

Horizontal o vertical

3.1

Pasar a vertical

▶ 4:50

En la configuración de la librería (ILI9225.h) comenta la definición LANDSCAPE: el ancho y el alto se intercambian y la pantalla, textos incluidos, queda vertical. Para volver a horizontal, quita el comentario.

//#define LANDSCAPE   // comentada = vertical

#ifdef LANDSCAPE
uint16_t WIDTH = HEIGHT_;
uint16_t HEIGHT = WIDTH_;
#else
uint16_t WIDTH = WIDTH_;
uint16_t HEIGHT = HEIGHT_;
#endif
3.2

Una foto vertical

▶ 5:46

Repite la conversión con una foto vertical del tamaño de la pantalla (176 x 220) y pégala en imagenes.h como otro arreglo (en el video, yo). Luego dibújala y escribe el nombre debajo.

draw_bitmap(0, 0, 1, yo);
draw_string(0, 100, "ARZ", COLOR_RED, font5);
3.3

Resultado

▶ 7:24

La foto ocupa toda la pantalla en vertical. Más adelante se verá cómo leer las imágenes desde una memoria SD.
