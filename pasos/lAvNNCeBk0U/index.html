GLCD 128x64 con Visual GLCD

Una GLCD de 128x64 se maneja por puntos y permite imágenes y textos. Visual GLCD, de Mikroelektronika, genera el código para MikroC: se configura el micro, el controlador KS0108 y los pines, se dibuja la interfaz y se exporta. Luego en MikroC se lee el sensor, se pasa la temperatura a texto y se redibuja el botón que la muestra.

Código

3.1

Variables

▶ 19:23

En el main generado se agregan el código del ADC, la temperatura y un texto de 20 posiciones. Se activan las librerías ADC, C_String y conversiones.

3.2

Leer el LM35

▶ 20:00

Se pone RA0 como entrada análoga, se lee el canal y se convierte a grados.

3.3

A texto

▶ 21:10

Con sprintf se pasa la temperatura a texto con dos decimales. Ese texto se copia en el Caption del botón y se vuelve a dibujar el botón redondeado cada 2 segundos.

unsigned int codigo;
float temperatura;
char texto[20];

while (1) {
  codigo = ADC_Read(0);
  temperatura = codigo * 500.0 / 1023.0;
  sprintf(texto, "%.2f", temperatura);
  // copiar texto al Caption del boton y redibujarlo
  Delay_ms(2000);
}
