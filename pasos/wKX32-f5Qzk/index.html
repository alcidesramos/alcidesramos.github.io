Encoder de cuadratura con Arduino

El canal A del encoder entra al pin 2 (interrupción) y el canal B al pin 3. En cada interrupción se comparan los dos canales: si son iguales se suma un pulso y si no se resta. Luego se invierte la variable del flanco y se vuelve a configurar la interrupción, así se detectan tanto los flancos de subida como los de bajada. Es el mismo método que se usó con PIC, traducido a Arduino. En el loop se muestra el conteo en un LCD de 20x4.

LCD y variables

▶ 0:34

Se incluye LiquidCrystal con los pines del LCD, una variable flanco que arranca en cero y la variable pulsos con signo, para contar hacia los dos lados.

#include <LiquidCrystal.h>
LiquidCrystal lcd(13,12, 11, 10, 9, 8);// pines de conexion del lcd
bool flanco=0;  //variable para determinar flanco de la interrupcion
signed int  pulsos=0;  //variable del encoder
1.2

Habilitar la interrupción

▶ 1:05

En el setup se inicia el LCD, se escribe el título y se habilita la interrupción del pin 2. En el lugar del flanco se usa la variable flanco: como vale cero arranca por flanco de bajada.

void setup()
{
  lcd.begin(20, 4);
  lcd.setCursor(0, 0);
  lcd.print("    ENCODER ARZ");
  attachInterrupt(digitalPinToInterrupt(2), interrupcion,flanco ); // interrupcion por flanco de bajada
}
1.3

La rutina de interrupción

▶ 2:00

Si el pin 2 y el pin 3 están iguales el encoder va en un sentido y se suma; si no, se resta. Después se invierte flanco y se vuelve a configurar la interrupción, para que la siguiente sea por el flanco contrario.

void interrupcion()
{
  if (digitalRead(2)==digitalRead(3)) pulsos++; else pulsos--;
  flanco=!flanco;// niega la variable flanco
  attachInterrupt(digitalPinToInterrupt(2), interrupcion,flanco );//invierte el flanco en la interrupcion
}
