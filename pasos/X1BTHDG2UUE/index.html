Virtuino con PIC (parte 2)

El ESP8266 se baja a 9600 baudios para la simulación con AT+UART_DEF. El PIC lo pone en modo punto de acceso con su propia red, una sola conexión y servidor en el puerto 100. La trama de Virtuino tiene inicio (!) pero no un final fijo ni un tamaño fijo, así que al detectar !V se arranca el Timer1 (50 ms por 4, unos 200 ms) y se guarda todo lo que llegue. Al cumplirse el tiempo se marca la trama como válida. procesarx recorre las variables con strtok: lo que hay entre V y = es el número de pin y lo que hay entre = y $ es el valor (si no es ?). V0 y V1 prenden LEDs y V2 cambia el PWM. Luego se arma con sprintf la respuesta con V3, V4 (pulsadores) y V5 (temperatura de un DS18B20) y se envía con AT+CIPSEND.

Velocidad del ESP8266

▶ 0:00

El módulo viene a 115200. Para simular en Proteus conviene 9600. AT+RESTORE lo devuelve a fábrica y AT+UART_DEF=9600,8,1,0,0 cambia la velocidad. Con un módulo real se puede dejar en 115200.

Fase 3

Capturar la trama

3.1

La estrategia

▶ 22:02

La trama tiene inicio pero no un final fijo y su tamaño cambia. Al recibir el inicio se arranca un timer y durante unos 200 ms se guarda todo lo que llegue.

3.2

Variables

▶ 25:50

trama_rx guarda lo recibido, procesa sirve para extraer valores, puntero apunta a la siguiente posición, flag_rx avisa que hay una trama lista y flag_timer que se cumplió el tiempo. total_variables es el número de pines virtuales usados (6).

3.3

Interrupción serial

▶ 32:46

Una máquina de estados espera el !, luego la V. Si llega la V arranca el Timer1 y pasa al estado fin, donde guarda todo hasta que se cumpla el tiempo. Entonces cierra la cadena, desactiva la recepción y activa flag_rx.

if (RCIF_bit == 1)          // si es serial
{
  datorx = UART1_Read();    //lee el dato
  switch (estado)           // analiza maquina de estado
  {
    case Adm:               // espera signo de admiracion
      trama_rx[puntero] = datorx;
      if (datorx != '!') puntero = 0;   //no fue el dato que me interesa
      else {
        puntero++;          //incrementa contador para proximo dato
        estado = V_;        //pasa al estado de capturar la v
      }
      break;
    // case V_: si llega la V arranca el timer y pasa a fin
    case fin:
      trama_rx[puntero] = datorx;
      puntero++;
      if (puntero > 100) {
        puntero = 0;
        estado = Adm;
      }
      if (flag_timer == 1) {
        trama_rx[puntero] = 0;   // agrega final de linea
        RCIE_bit = 0;            //deshabilita la interrupcion
        flag_rx = 1;             //activa la bandera de que hay una trama valida
        estado = Adm;            // RESETEA EL ESTADO
        flag_timer = 0;          //limpia la bandera timer
      }
      break;
  }
}
3.4

Timer de 200 ms

▶ 35:34

El Timer1 interrumpe cada 50 ms. Un contador llega a 4 (200 ms) y activa flag_timer. Si el tiempo es muy largo se pierde tiempo real; si es corto no llega la trama completa. La interrupción debe ir en el vector de alta prioridad.

Fase 4

Procesar y responder

4.1

Sacar los valores

▶ 41:54

procesarx recorre las variables: con strtok toma lo que hay entre V y = (número de pin) y entre = y $ (valor). Si el valor no es ?, V0 y V1 cambian los LEDs y V2 el ciclo útil del PWM.

strcpy(procesa, strtok(trama_rx, "V"));   //inicia captura de tokens desde el V
for (son = 0; son < total_variables - 1; son++)
{
  strcpy(procesa, strtok(0, "="));   //captura hasta el =
  variable = atoi(procesa);
  strcpy(procesa, strtok(0, "$"));   //captura hasta el $
  //procesa lo que lelga
  if (procesa[0] != '?')
  {
    if (variable == 0) led1 = atoi(procesa);
    else if (variable == 1) led2 = atoi(procesa);
    else if (variable == 2)
    {
      pwm = atof(procesa);
      PWM1_Set_Duty(pwm);
    }
  }
  strcpy(procesa, strtok(0, "V"));   //apunta a la otra variable
}

Armar la respuesta

▶ 49:40

Con sprintf se arma !V03=..$!V04=..$!V05=..$ con los suiches (negados, porque presionados dan 0) y la temperatura con un decimal. Las variables enteras se pasan con (unsigned int).

while (1)
{
  if (flag_rx == 1)
  {
    soft_Uart_write_text_const("\r\n ME LLEGO=");
    soft_Uart_write_text(trama_rx);
    procesarx();
    Delay_ms(100);
    sprintf(trama_tx, "!V03=%d$!V04=%d$!V05=%4.1f$", (unsigned int)!suiche1, (unsigned int)!suiche2, temperatura);

    // limpia variables y habilita otra vez la recepcion
  }
}
4.4

Enviar con CIPSEND

▶ 51:53

manda_esp8266 envía AT+CIPSEND con el número de conexión (0) y el largo de la trama, y luego la trama.

void manda_esp8266(char *info)
{
  unsigned int largo;
  Uart1_write_text_const("AT+CIPSEND=");   //manda envia solo constantes
  UART1_Write('0');                        //manda el socket el cual se conecta
  UART1_Write(',');
  largo = strlen(info);                     //calcula el largo de la cadena a enviar
  sprinti(captu, "%u", largo);              //es el largo de la trama
  UART1_Write_Text(captu);                  //envia el largo de la trama
  Uart1_write_text_const("\r\n");
  // ... espera y envia la trama
}
