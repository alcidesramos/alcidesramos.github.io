Virtuino con PIC (parte 1)

Virtuino está pensada para Arduino, pero se puede usar con un PIC si se entiende la trama. Se crea un servidor de tipo propósito general con la IP y el puerto (100), primero apuntando al computador para probar con Hercules como servidor TCP. Todos los elementos usan pines virtuales: V0 y V1 son interruptores, V2 un regulador para el PWM, V3 y V4 LEDs y V5 la temperatura. La aplicación envía tramas como !V00=1$!V01=?$ ... cuyo orden cambia y que traen ? cuando no hay cambio. Para mostrar datos se le envía !V05=32.5$ y así. La actualización es lenta (mínimo 1 s). En la parte 2 se hace el programa del PIC.

Fase 1

El proyecto

1.1

Qué se va a hacer

▶ 0:00

Desde el celular se prenden LEDs y se cambia la velocidad de un motor, y en el celular se ve la temperatura y el estado de dos pulsadores. Todo por WiFi con un ESP8266 y un PIC.

1.2

Servidor

▶ 2:15

En Server settings se agrega un servidor nuevo de tipo propósito general, con nombre, IP y puerto 100. Para probar se usa la IP del computador. El refresco mínimo es 1 segundo.

1.3

Probar la conexión

▶ 4:50

Hercules en modo TCP Server, puerto 100. Al conectar, en Client connection status aparece el celular.

Fase 2

Elementos de control

2.1

Interruptores

▶ 6:41

Se agrega un panel y un switch asociado al servidor, en el pin virtual V0 y otro en V1. Se ponen textos LED1 y LED2.

2.2

La trama que llega

▶ 10:37

Al correr, la aplicación envía !V00=1$!V01=?$ ... El orden de las variables cambia y si no hay cambio manda ?. El programa del PIC debe entender eso.

2.3

Regulador

▶ 11:41

En vez de slider se usa un regulador en V2 con rango de 0 a 255 para el PWM del motor.

Fase 3

Indicadores

3.1

LEDs

▶ 14:27

Se agregan dos LEDs en los pines virtuales V3 y V4, que mostrarán el estado de los pulsadores del circuito.

3.2

Temperatura

▶ 16:12

Un instrumento análogo en V5, de 0 a 100 grados, con un decimal y líneas de escala de 10, 50 y 100.

3.3

Enviar datos

▶ 20:23

Desde Hercules se escribe la trama !V03=1$!V04=1$!V05=32.5$ y en el celular cambian los LEDs y la temperatura. En Hercules el signo $ se escribe doble.
