Pasar las interrupciones a un PIC18F

Lección 34 del curso. Se toma el programa de las lecciones 31 a 33 y se lleva a un PIC18F4550. Hay que mover los leds porque RC4 y RC5 son del USB, cambiar el vector de interrupción a 0x0008 (alta prioridad), renombrar los bits de la interrupción por flanco y del Timer0, poner el puerto digital y prender el Timer0. Al final se aprovecha que el Timer0 del PIC18 puede ser de 16 bits para sacar un segundo directo.

Fase 2

Corregir el código

2.1

Vector 0x0008

▶ 5:56

Al compilar sale error en el vector 0x0004. Los PIC18 tienen dos vectores: alta prioridad en 0x0008 y baja en 0x0018. Para trabajar como en un PIC16 todo va a la alta.

void INTERRPCION() iv 0x0008 ics ICS_AUTO
2.2

INT0 y Timer0

▶ 7:39

El PIC18 tiene INT0, INT1 e INT2, así que INTF e INTE pasan a INT0IF e INT0IE (se pueden reemplazar con Ctrl+R). El Timer0 puede ser de 16 bits: TMR0 pasa a TMR0L, OPTION_REG a T0CON y los bits del prescalador a T0PS2 a T0PS0. Además el Timer0 se debe prender con TMR0ON.

// timer cero
T0CON = 0;
// cargar timer
TMR0L = 100;
// prescalador 64, 10 ms
T0PS2_bit = 1;
T0PS1_bit = 0;
T0PS0_bit = 1;
// INTERRUPCION
TMR0IF_bit = 0;
TMR0IE_bit = 1;
T08BIT_bit = 1;   // trabaja 8 bit
TMR0ON_bit = 1;   // prende timer 0
2.3

Puertos

▶ 13:25

El puerto D debe quedar como salida para los leds y ADCON1 se ajusta para que los pines sean digitales. El Timer1 y la interrupción por flanco se configuran igual que antes.

2.4

Timer0 a 8 bits

▶ 14:33

El bit T08BIT en 1 hace que el Timer0 trabaje a 8 bits como en el PIC16. Con eso el programa funciona igual que en el PIC16F876A.

Fase 3

Timer0 a 16 bits

3.1

Un segundo directo

▶ 16:19

A 16 bits y con prescalador de hasta 256, el Timer0 llega a un segundo sin variable auxiliar. La hoja de cálculo da prescalador de 16 y valores 11 en TMR0H y 220 en TMR0L. Se carga primero la parte alta.

TMR0H = 11;
TMR0L = 220;
// prescalador 16, 1 s
T0PS2_bit = 0;
T0PS1_bit = 1;
T0PS0_bit = 1;
T08BIT_bit = 0;   // trabaja 16 bit
3.2

En la interrupción

▶ 18:04

En la interrupción se recargan los mismos valores y ya no hace falta contar con una variable. El Timer0 da hasta unos 16 segundos y el Timer1 solo medio segundo, así que se elige el timer según el tiempo que se necesite.

if (TMR0IF_bit == 1)
{
  TMR0H = 11;
  TMR0L = 220;
  led2 = ~led2;
  TMR0IF_bit = 0;
}
