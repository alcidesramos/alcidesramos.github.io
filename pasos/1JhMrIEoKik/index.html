Teclado 4x4 con máquina de estados

Con la librería Keypad4x4 de MikroC se lee la tecla y una función la traduce al carácter real. Una máquina de estados guarda cuatro dígitos y espera el igual; con atoi el texto pasa a número y se usa como retardo del LED con Vdelay_ms. Como un retardo largo bloquea el teclado, se crea miretardo, que espera de a 1 ms y en cada vuelta revisa el teclado.

2.1

Keypad_Key_Click

▶ 8:18

Keypad_Key_Click devuelve 0 si no hay tecla, o un número de 1 a 16. Para mostrarlo se convierte a texto con ByteToStr (librería de conversiones).

2.2

Traducir la tecla

▶ 11:23

La función teclado_deco usa Keypad_Key_Press y un switch para convertir el número en el carácter impreso en la tecla. Así se puede escribir con Lcd_Chr.

char teclado_deco() {
  char tec = 0;
  tec = Keypad_Key_Press();
  if (tec != 0) {
    switch (tec) {
      case 1: tec = '7'; break;
      case 2: tec = '8'; break;
      case 3: tec = '9'; break;
      // ... una linea por tecla, segun el teclado
      case 15: tec = '='; break;
      case 16: tec = '+'; break;
    }
  }
  return tec;
}

3.1

Estados

Los estados son n1 a n4 (cada dígito) y en (esperar el igual). Se guarda en retardo_cad y se usa isdigit de la librería C_Type para aceptar solo números.

unsigned int retardo = 100;

char estado_teclado = n1;
3.2

Cada dígito

▶ 18:15

En cada estado, si llegó un número se prende un LED indicador, se guarda, se muestra y se pasa al siguiente. Un retardo de 400 ms sirve de antirrebote.

void teclado_estado() {
  tecla = teclado_deco();
  switch (estado_teclado) {
    case n1:
      if ((tecla != 0) && (isdigit(tecla))) {
        led1 = 1;
        retardo_cad[0] = tecla;
        estado_teclado = n2;
        Lcd_Chr(2, 8, tecla);
        Delay_ms(400);   // antirrebote
      }
      break;
    // n2, n3 y n4 igual con las posiciones 1, 2 y 3

El igual

▶ 20:37

En el último estado, si la tecla no es igual se descarta todo. Si es igual se cierra la cadena, atoi la convierte en número y se vuelve al primer estado.

Fase 4

Retardo sin bloquear

4.1

Vdelay_ms

▶ 22:22

En el while se llama la máquina de estados y se invierte el LED. Delay_ms solo acepta constantes, así que para una variable se usa Vdelay_ms. El problema: con 5 segundos el teclado no responde durante la espera.

4.2

miretardo

▶ 26:06

La solución es una función que espera de a 1 ms y en cada milisegundo revisa el teclado. Ahora el LED parpadea con el tiempo pedido y el teclado responde siempre.

void miretardo(signed int valor) {
  while (valor > 0) {
    Delay_ms(1);
    teclado_estado();
    valor--;
  }
}

while (1) {
  teclado_estado();
  led = ~led;
  miretardo(retardo);
}

Prueba

▶ 28:02
