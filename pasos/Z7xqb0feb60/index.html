Clase 17: Display 7 segmentos en Keil y números binarios

Quienes usan un ST-Link clon programan con Keil µVision (MDK-ARM), como vimos en la clase 13. Al llevar a Keil el proyecto del display de 7 segmentos, el compilador ARM no acepta los literales binarios con prefijo 0b y da dos errores. Basta activar las extensiones GNU con la opción --gnu.

▶ Ver el video completo (2:59) Empezar el paso a paso
  • Proyecto del display 7 segmentos (STM32F401 en el video)
  • STM32CubeMX
  • Keil µVision MDK-ARM
  • ST-Link (original o clon)
1 · Keil2 · --gnu
Fase 1

Pasar el proyecto a Keil

1.1

Regenerar para MDK-ARM

▶ 1:05

Abre el .ioc del proyecto en STM32CubeMX, en Project Manager → Toolchain / IDE elige MDK-ARM y GENERATE CODE. Se abre el proyecto en µVision.

Si lo generas en la misma carpeta, el proyecto queda para el último IDE que generaste.

1.2

El código del display

▶ 1:40

Los segmentos están en un mismo puerto y se escriben de una vez en el registro ODR, en hexadecimal, decimal o binario:

ADP_GPIO_Port->ODR = 0x39;        // hexadecimal
HAL_Delay(600);
ADP_GPIO_Port->ODR = 118;         // decimal
HAL_Delay(600);
ADP_GPIO_Port->ODR = 0b01101101;  // binario
HAL_Delay(600);
ADP_GPIO_Port->ODR = 0b01111111;
HAL_Delay(600);
Fase 2

El error con 0b y su solución

2.1

Activar --gnu

▶ 2:00
  • Al compilar salen 2 errores en las líneas con 0b….
  • Clic derecho en el proyecto → Options for Target → pestaña C/C++.
  • En Misc Controls escribe --gnu y OK.
--gnu
2.2

Compilar y cargar

▶ 2:30

Vuelve a compilar (Rebuild): 0 errores. Ya puedes descargar el programa al micro con Download.
