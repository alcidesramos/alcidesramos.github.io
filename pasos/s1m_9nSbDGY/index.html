Proteus · parte 2: el .hex desde CubeIDE

Complemento corto de la clase 5: qué archivo cargar en Proteus cuando el programa se hace con STM32CubeIDE, y cómo hacer que el IDE genere también el .hex.

▶ Ver el video completo (1:53) Empezar el paso a paso
1 · Compilar
Fase 1

Compilar y cargar en Proteus

1.1

Compilar en Release y cargar el .elf

▶ 0:34

En STM32CubeIDE, cambia la configuración de Debug a Release y compila. En la carpeta Release aparece el .elf: ese archivo se puede cargar en el micro de Proteus.

1.2

Generar también el .hex

▶ 1:07

A veces el .elf da errores en Proteus. Para tener el .hex: Project → Properties → C/C++ Build → Settings → MCU Post build outputs y marca Convert to Intel Hex file (-O ihex). Aplica y compila.

1.3

Cargar el .hex en el micro

▶ 1:32

Doble clic sobre el micro en Proteus, y en Program File escoge el .hex de la carpeta Release.
