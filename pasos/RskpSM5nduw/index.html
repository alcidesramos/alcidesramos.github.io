8 LEDs con 5 pines de un PIC

Un PIC12F629 tiene cinco pines de entrada y salida y el de reset. Los 8 LEDs van en parejas entre el común (GP0) y cada fila (GP1, GP2, GP4, GP5): común en 1 y fila en 0 prende uno, y al revés prende el otro. Para apagar todo, los pines se ponen como entrada. Se escriben funciones para cada LED, para prender 4 bajos o 4 altos (con cuidado de la corriente del común) y para apagar. Los efectos se eligen con un switch. El pulsador está en GP3 (MCLR deshabilitado), que no tiene interrupción, así que se revisa cada 200 ms con la interrupción del Timer1 configurada con Timer Calculator.

Prender un LED

▶ 4:51

Primero todo como entrada (apaga lo anterior), luego el común y la fila como salida con la polaridad del LED. Para prender 4 a la vez, toda la corriente pasa por el común: mejor subir las resistencias o prenderlos uno por uno rápido.

//prende 4 led parte baja
void prende_4_bajo(unsigned int tiempo)
{
  in_todo();
  out_todo();
  comun = 1;
  f1 = 0;
  f2 = 0;
  f3 = 0;
  f4 = 0;
  VDelay_ms(tiempo);
}

3.2

Leer el pulsador

▶ 8:07

GP3 no tiene interrupción, así que se usa el Timer1 cada 200 ms (configuración de Timer Calculator). Si el pulsador está presionado se detiene el timer, se pasa al siguiente efecto con un antirrebote y se vuelve a arrancar.

void InitTimer1(){
  T1CON      = 0x11;
  TMR1IF_bit = 0;
  TMR1H      = 0x3C;
  TMR1L      = 0xB0;
  TMR1IE_bit = 1;
  INTCON     = 0xC0;
}

void Interrupt(){
  if (TMR1IF_bit){
    TMR1H = 0x3C;
    TMR1L = 0xB0;
    if (sw == 0)
    {
      TMR1ON_bit = 0;   //para el timer, para evitar mas interrupciones
      efecto++;
      // retardo antirebote con Delay_ms
      TMR1ON_bit = 1;
    }
    if (efecto >= n_efectos) efecto = 0;   //limite de numero de efectos
    TMR1IF_bit = 0;
  }
}
