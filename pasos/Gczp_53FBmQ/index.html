Control de motores con PWM

Lección 21 del curso. La señal PWM tiene frecuencia fija y cambia el ancho del pulso positivo (ciclo útil), lo que cambia la energía que llega a la carga. Primero se ve en Proteus con un puente H L298 y dos generadores de pulso, y se explica cómo escoger la frecuencia según el motor. Luego, con un PIC16F877A a 4 MHz, se usan PWM1 y PWM2 (pines CCP1 en RC2 y CCP2 en RC1), con su frecuencia mínima según el cristal. Al final se arma un control de dos motores: el motor 1 sigue a un potenciómetro, el motor 2 sube y baja con botones, dos interruptores cambian el sentido de giro y la LCD muestra la velocidad en porcentaje y el giro.

Fase 1

La señal PWM

1.1

Ancho de pulso

▶ 0:00

Una señal PWM mantiene la frecuencia (por ejemplo 1 kHz, periodo de 1 ms) y cambia cuánto tiempo está en alto. Ese tiempo es el ciclo útil o ciclo de trabajo: con 0.5 ms en alto es el 50 %, con 0.9 ms el 90 %. Más ciclo útil es más energía para la carga.

  • Control de velocidad de motores DC.
  • Control de luminosidad de LED y selección de color en LED RGB.
  • Inversores DC-AC y fuentes conmutadas.
  • Servomotores, comunicaciones y conversión digital a análogo.
1.2

Puente H L298

▶ 2:09

El L298 maneja dos motores. IN1 e IN2 dan el sentido del motor 1, IN3 e IN4 el del motor 2, y la señal PWM entra por ENA y ENB. Si un enable está en 0 el motor queda deshabilitado. Para un solo motor más grande se pueden poner las salidas en paralelo.

1.3

Probar con generadores de pulso

▶ 4:10

En Proteus se pone un generador de pulsos en cada enable, de 0 a 5 V y a la misma frecuencia, uno con ancho de pulso de 10 % y otro mayor. El motor con más ancho de pulso gira más rápido.

Fase 2

Escoger la frecuencia

2.1

Ni muy lenta ni audible

▶ 5:30

Con un periodo muy lento el motor se prende y se apaga a saltos. Algunas frecuencias hacen que el motor suene o chille, y otras pueden entrar en resonancia con él. Lo ideal es estar por encima de unos 20 kHz, que el oído ya no escucha.

2.2

Frecuencia mínima por la bobina

▶ 7:43

La bobina del motor tiene resistencia R e inductancia L, con constante de tiempo L/R. Para controlar en 255 pasos, el periodo máximo sale de T = 5 · PWM_step · L/R. Con R = 5 Ω y L = 10 µH, T = 2.55 ms, o sea unos 392 Hz como mínimo.

2.3

Los pines y el cristal

▶ 9:55

En el 16F877A, PWM1 sale por CCP1 (RC2) y PWM2 por CCP2 (RC1). Los dos usan el Timer2, así que trabajan a la misma frecuencia. La frecuencia mínima depende del cristal: con 4 MHz son 245 Hz y con 20 MHz son 1222 Hz. Si se pide menos, MikroC da error al compilar.

Fase 3

PWM en MikroC

3.1

Configurar puertos

▶ 11:00

Proyecto con PIC16F877A a 4 MHz (frecuencia baja para que Proteus no se ponga lento). AN0 queda análogo para el potenciómetro, el puerto B maneja el puente H y RC1 y RC2 son las salidas PWM.

ADCON1 = 0b1110;     // solo AN0 análogo
TRISA = 0b11111111;  // entrada
TRISB = 0;           // salida
TRISB4_bit = 1;      // entradas
TRISB5_bit = 1;
// salidas PWM
RC1_bit = 0;
RC2_bit = 0;
3.2

Init, Set_Duty y Start

▶ 14:34

PWMx_Init(frecuencia) fija la frecuencia, PWMx_Set_Duty(valor) el ciclo útil de 0 a 255 (255 es el 100 % y 127 cerca del 50 %), y PWMx_Start() arranca la señal. También existe PWMx_Stop().

PWM1_Init(245);      // frecuencia
PWM2_Init(245);
PWM1_Set_Duty(20);
PWM2_Set_Duty(200);
PWM1_Start();        // arranca PWM
PWM2_Start();

while (1) {
}
3.3

Sentido de giro

▶ 21:22

Se nombran los pines del puente H y se hace un procedimiento por cada sentido. Para cambiar el giro se invierten los dos pines del motor.

sbit m11 at RB0_bit;
sbit m12 at RB1_bit;
sbit m21 at RB2_bit;
sbit m22 at RB3_bit;

void derecha1()   { m11 = 1; m12 = 0; }
void izquierda1() { m11 = 0; m12 = 1; }

while (1) {
  derecha1();  izquierda2();
  Delay_ms(5000);
  derecha2();  izquierda1();
  Delay_ms(5000);
}
Fase 4

Control de dos motores

4.1

LCD y potenciómetro

▶ 23:45

Se agregan la LCD en el puerto D, ADC_Init y los textos fijos: Ve1 y Ve2 para las velocidades y G1 y G2 para el giro.

Lcd_Out(1, 1, "Ve1=");
Lcd_Out(2, 1, "Ve2=");
Lcd_Out(1, 10, "G1=");
Lcd_Out(2, 10, "G2=");
4.2

Motor 1 con el potenciómetro

▶ 29:30

El código del ADC (0 a 1023) se lleva a 0 a 255 con una regla de tres y se manda al PWM1.

codigo = ADC_Read(0);
velo1 = codigo * 255.0 / 1023.0;
PWM1_Set_Duty(velo1);

Escriba 255.0 y 1023.0. Con 255 y 1023 la operación se hace con enteros y el resultado da 0.

4.3

Motor 2 con botones

▶ 33:05

Un botón sube y otro baja la velocidad en pasos de 10, limitada entre 0 y 255. La variable se declara con signo para que no se dé la vuelta al bajar de 0.

signed int velo2 = 100;

if (sube2 == 0) {
  velo2 = velo2 + 10;
  if (velo2 >= 255) velo2 = 255;
  PWM2_Set_Duty(velo2);
  Delay_ms(250);
}
if (baja2 == 0) {
  velo2 = velo2 - 10;
  if (velo2 <= 0) velo2 = 0;
  PWM2_Set_Duty(velo2);
  Delay_ms(250);
}
4.4

Botones en el puerto B

▶ 38:02

En el puerto A los botones respondían mal, así que se pasan a RB6 y RB7 y se activan las resistencias pull-up del puerto B. El bit que las habilita es negado, así que se activan con 0.

sbit sube2 at RB6_bit;
sbit baja2 at RB7_bit;

OPTION_REG = 0;   // pull-ups del puerto B
TRISB6_bit = 1;
TRISB7_bit = 1;
4.5

Giro con interruptores

▶ 42:37

Dos interruptores (giro1 y giro2) escogen el sentido de cada motor, y la LCD muestra D o I según el giro.

if (giro1 == 0) {
  derecha1();
  Lcd_Chr(1, 13, 'D');
}
else {
  izquierda1();
  Lcd_Chr(1, 13, 'I');
}
4.6

Velocidad en porcentaje

▶ 47:10

La velocidad se pasa a porcentaje (velo × 100 / 255.0) y se convierte a texto con la función float_to_str_ de la lección 18, con un decimal.

char texto[20];

floattostr_(velo1 * 100 / 255.0, texto, 1);
Lcd_Out(1, 5, texto);
floattostr_(velo2 * 100 / 255.0, texto, 1);
Lcd_Out(2, 5, texto);
