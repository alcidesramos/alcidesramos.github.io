Recibir tramas con interrupción serial

Lección 36 del curso. El programa de las lecciones anteriores leía la trama con UART1_Read_Text y se quedaba esperando. Ahora la interrupción de recepción, en alta prioridad, guarda los bytes en un arreglo con un puntero, detecta el * final, desactiva la interrupción y levanta una bandera. El procesamiento se hace en el programa principal, que luego limpia errores y vuelve a habilitar la recepción.

Fase 1

Habilitar la interrupción

1.1

El problema

▶ 0:00

Se agregan tres leds: dos se controlan por serial y otro parpadea en el programa principal. Mientras UART1_Read_Text espera la trama, ese led se queda quieto.

1.2

Configurar RC

▶ 2:45

Primero la prioridad, luego se limpia la bandera RCIF y se habilita RCIE. Se recomienda activar también la recepción continua con CREN.

// configuracion int serial
RCIP_bit = 1;   // alta prioridad
RCIF_bit = 0;   // limpia la bandera
RCIE_bit = 1;   // habilita la interrupcion
CREN_bit = 1;   // habilita la recepcion continua
1.3

Primera prueba

▶ 3:58

En la función de alta prioridad se pregunta por RCIF, se lee el dato con UART1_Read y se cambia un led. Cada carácter que llega cambia el led.

Fase 2

Guardar la trama

2.1

Búfer y puntero

▶ 8:14

Los datos llegan uno a uno, así que se guardan en un arreglo. Una variable puntero_rx indica en qué posición va.

char trama_rx[100];
char procesa[100];
char dato_rx;
char puntero_rx = 0;   // recorre el vector trama_rx
2.2

Guardar y detectar el final

▶ 9:20

Cada dato se guarda y el puntero avanza. Si llega al tamaño del arreglo vuelve a cero para no desbordar la RAM. Cuando llega el *, la trama está completa y se desactiva la interrupción serial mientras se procesa.

void INTERRPCION_altas() iv 0x0008 ics ICS_AUTO
{
  if (RCIF_bit == 1)
  {
    dato_rx = UART1_Read();
    trama_rx[puntero_rx] = dato_rx;   // lo almacena en la trama
    puntero_rx++;
    if (puntero_rx >= 100) puntero_rx = 0;
    if (dato_rx == '*')   // si dato es igual final trama
    {
      RCIE_bit = 0;   // deshabilito la int serial
      flag_rx = 1;
    }
  }
}
2.3

Volver a habilitar

▶ 12:45

Después de procesar se limpia la bandera, el puntero vuelve a cero y se habilita otra vez la interrupción. Antes se apaga y prende CREN para borrar errores de recepción y datos que llegaron mientras se procesaba.

RCIF_bit = 0;
puntero_rx = 0;
CREN_bit = 0;   // limpia buffer
CREN_bit = 1;   // habilitar la recepcion
RCIE_bit = 1;   // habilita la interrupcion
Fase 3

Procesar fuera de la interrupción

3.1

Reentrada

▶ 14:31

Si se procesa dentro de la interrupción y la misma función (aquí PWM1_Set_Duty) también se llama desde el main, MikroC avisa que no permite reentrada. Además una interrupción larga no es recomendable.

3.2

Probar

▶ 15:03

El led del main parpadea solo y desde la terminal se prenden y apagan los leds con led1=on* o se cambia el PWM con m1pwm=127*, sin bloquear el programa.

3.3

Bandera propia

▶ 16:45

La forma correcta es que la interrupción solo levante una bandera flag_rx y el programa principal la revise, procese la trama, vuelva a habilitar la recepción y baje la bandera.

while (1)
{
  ledmain = ~ledmain;
  Delay_ms(500);
  if (flag_rx == 1)
  {
    procesa_rx();
    RCIF_bit = 0;
    puntero_rx = 0;
    CREN_bit = 0;
    CREN_bit = 1;
    RCIE_bit = 1;
    flag_rx = 0;
  }
}
