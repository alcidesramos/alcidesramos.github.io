Tiempos largos con timer de 32 bits

El proyecto consistía en medir el tiempo entre dos pulsos, de 2 a 120 segundos. Con un timer de 16 bits a la resolución necesaria solo se llega a unos 60 segundos, y en muchos micros de 32 bits, como los STM32F1, los timers siguen siendo de 16 bits. El dsPIC33FJ32MC202, aunque es de 16 bits, puede unir Timer2 y Timer3 en un timer de 32 bits: con la configuración usada llega a unos 27.487 segundos, casi 7 horas. La entrada de los pulsos se asigna con PPS a INT1; en la interrupción, el primer flanco borra y arranca el timer, el segundo lo detiene y arma el valor de 32 bits con TMR2 y TMR3. Luego se calcula el tiempo y se envía por la UART. La lección: elegir el micro según lo que pide el proyecto.

Con PPS se asignan la UART y la entrada INT1 al pin que se quiera, y se configura la interrupción por flanco positivo.

// asignación de pines remapeables
PPS_Mapping(14, _OUTPUT, _U1TX);  // TX del micro
PPS_Mapping(15, _INPUT, _U1RX);   // RX del micro
PPS_Mapping(7, _INPUT, _INT1);    // RB7 entrada de velocidad

UART1_Init(9600);

// configura interrupción por flanco
INT1EP_bit = 0;    // flanco positivo
INT1IP_2_bit = 1;  // prioridad
INT1IP_1_bit = 1;
INT1IP_0_bit = 0;
INT1IF_bit = 0;    // limpia bandera
INT1IE_bit = 1;    // habilita interrupción

2.4

Capturar en la interrupción

▶ 7:48

El primer flanco borra y arranca el timer; el segundo lo detiene y arma el valor de 32 bits con TMR2 y TMR3 corrido 16 bits. Al capturar por hardware no hay errores por software.

void INT1_int() iv IVT_ADDR_INT1INTERRUPT ics ICS_AUTO
{
  switch (esta)
  {
    case 0:
      tmr2 = 0;
      tmr3 = 0;
      T2CONbits.TON = 1;   // prende el timer
      esta = 1;
      break;
    case 1:
      T2CONbits.TON = 0;
      tiem1 = TMR2;
      tiem2 = (unsigned long)TMR3 << (unsigned long)16;
      tiem = tiem1 + tiem2;
      esta = 2;
      break;
    case 2:
      tmr2 = 0;
      tmr3 = 0;
      T2CONbits.TON = 0;   // apaga el timer
      break;
  }
}
