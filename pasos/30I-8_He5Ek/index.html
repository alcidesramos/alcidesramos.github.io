Clase 14: Tarjetas Nucleo originales de ST

Las tarjetas Nucleo son las placas originales de STMicroelectronics. Sus ventajas: traen el ST-Link integrado (en la parte que se puede separar), y ese ST-Link también sirve para programar otras placas; al conectarlas aparecen en el PC como una memoria USB; y en STM32CubeMX se eligen por placa, de modo que los LED, el botón, el puerto serial y el reloj quedan configurados solos. Trabajamos con la NUCLEO-L476RG (Cortex-M4 de bajo consumo, 80 MHz con HSI + PLL) y la programamos de dos formas: desde CubeIDE con Run, y arrastrando el .bin o .hex a la unidad NOD_L476RG.

Fase 1

Conocer las Nucleo

1.1

ST-Link integrado

▶ 0:45

La parte superior de la placa es un ST-Link: se puede separar y tiene pines para programar otros micros. Comprar una Nucleo es comprar también un ST-Link. La "L" de L476 indica bajo consumo; estas placas suelen venir sin el cristal HSE soldado (queda el espacio para ponerlo).

1.2

Conectarla

▶ 1:40

Con el cable USB la placa se energiza y en el PC aparece una unidad como si fuera una memoria USB (NOD_L476RG). Más abajo la usamos para programar.

Fase 2

Proyecto con el Board Selector

2.1

Elegir la placa, no el micro

▶ 2:00
  • En STM32CubeMX entra por ACCESS TO BOARD SELECTOR y busca NUCLEO-L476RG.
  • Cuando pregunte si inicializa los periféricos por defecto, di Yes.
  • Queda todo listo: botón azul B1 en PC13, LED verde LD2 en PA5, USART2 y el reloj a 80 MHz con HSI + PLL.
2.2

Generar el proyecto

▶ 2:45

Project Manager: nombre nucleo, Toolchain / IDE STM32CubeIDE y GENERATE CODE.

Fase 3

Programar

3.1

El hola mundo con LD2

▶ 3:35
while (1)
{
  HAL_GPIO_TogglePin(LD2_GPIO_Port, LD2_Pin);
  HAL_Delay(200);
}
3.2

Forma 1: Run desde CubeIDE

▶ 4:15

Compila y pulsa Run. En la ventana de configuración de depuración deja el ST-LINK (ST-LINK GDB server) y OK. Como todo es original, lo reconoce sin problema y el LED empieza a parpadear.

3.3

Forma 2: arrastrar el archivo

▶ 5:45
  • En Properties → C/C++ Build → Settings → MCU Post build outputs activa el .hex y el .bin.
  • Cambia el retardo (ej. 1000) y solo compila.
  • Abre la carpeta Debug del proyecto y arrastra nucleo.bin (o .hex) a la unidad NOD_L476RG.
  • La placa se programa sola y el LED parpadea más lento.

Esta forma sirve para pasar un programa a la placa sin abrir ningún IDE: basta tener el .hex o el .bin.
