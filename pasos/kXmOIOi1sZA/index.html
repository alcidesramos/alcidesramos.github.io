Recibir órdenes de Nextion por interrupción

Lección 39 del curso. La librería de Nextion que antes era para dsPIC se pasa a PIC18F4550. La recepción usa una máquina de estados en la interrupción serial con protección contra desbordes por ruido. En la Nextion cada botón manda IN=, la información y FF FF FF. En el PIC se decodifican órdenes como onle1, un byte para el PWM, números de hasta 4 bytes armados según su largo, textos y órdenes con elemento y estado para controlar varios leds.

Fase 2

La librería

2.1

Máquina de estados

▶ 5:14

La trama empieza con IN= y termina con tres FF, como las tramas propias de la Nextion. Los tres caracteres de inicio se pueden cambiar.

char flag_rx1 = 0;
2.2

nextion_init

▶ 6:20

Inicia el UART a 9600 (en la pantalla real suele usarse 115200), limpia la bandera, habilita la interrupción serial y reinicia la recepción continua.

void nextion_init()
{
  UART1_Init(9600);   // inicia la nextion a 9600
  RCIF_bit = 0;       // limpia bandera recepcion serial
  RCIE_bit = 1;       // activa la interrupcion de recepcion serial
  // borra errores de recepcion e inicia recepcion continua
  CREN_bit = 0;
  CREN_bit = 1;
}
2.3

Recepción robusta

▶ 7:29

Si llegan las letras de inicio en orden se avanza; si no, se vuelve al inicio. Entre el = y los FF se guarda todo, y si el contador llega al tamaño del arreglo se vuelve a empezar para que el ruido no desborde la memoria. Al final se agrega un cero para cerrar la cadena, se desactiva la interrupción y se levanta la bandera.

2.4

Interrupción y main

▶ 10:17

La función de interrupción solo llama a nextion_interrupcion. En el main, si la bandera está activa se procesa la trama, se limpian errores, se vuelve a habilitar la interrupción y se baja la bandera.

void interrupciones() iv 0x0008 ics ICS_AUTO
{
  nextion_interrupcion();
}
Fase 3

Órdenes desde la Nextion

3.1

Orden puntual

▶ 16:35

En la Nextion un botón de dos estados manda una orden al soltarlo. En el PIC se busca con strstr y se actúa.

// en la Nextion
print "IN=onle1"
printh ff ff ff

// en el PIC
if (strstr(trama_rx_nextion, "onle1")) led1 = 1;
else if (strstr(trama_rx_nextion, "offle1")) led1 = 0;
3.2

Un byte

▶ 19:57

Para valores de 0 a 255 se manda el número como un byte con prints, encerrado entre /. En el PIC se captura con strtok y se saca por el PWM. Se puede usar un número con teclado o un slider.

// en la Nextion
print "IN=pwm1/"
prints pwm.val,1   // imprime un solo byte de la variable
print "/"          // imprime token para encerrar el valor
printh ff ff ff

// en el PIC
if (strstr(trama_rx_nextion, "pwm1"))   // analiza la orden
{
  strcpy(captura_nextion, strtok(trama_rx_nextion, "/"));
  strcpy(captura_nextion, strtok(0, "/"));   // captura hasta el 1 dato
  nextion_var_corta = captura_nextion[0];
  PWM1_Set_Duty(nextion_var_corta);   // saca el valor capturado
}
3.3

Números largos

▶ 28:22

Con prints var1.val,4 la Nextion manda los 4 bytes. Como un byte cero corta la cadena, el largo dice cuántos bytes llegaron y se arma el número multiplicando cada uno por 256, 65536 o 16777216. Luego se muestra en el LCD.

largo_cap = strlen(captura_nextion);
switch (largo_cap)
{
  case 1:
    nextion_var_larga = (unsigned long)captura_nextion[0];
    break;
  case 2:
    nextion_var_larga = (unsigned long)captura_nextion[0]
                      + (unsigned long)captura_nextion[1] * 256;
    break;
  case 3:
    nextion_var_larga = (unsigned long)captura_nextion[0]
                      + (unsigned long)captura_nextion[1] * 256
                      + (unsigned long)captura_nextion[2] * 65536;
    break;
  // case 4 suma el cuarto byte por 16777216
}
3.4

Decimales

▶ 35:05

Texto

Fase 4

Arreglos de elementos

4.1

Orden, elemento y estado

▶ 42:29

Para controlar muchos leds o válvulas se manda la orden, el número del elemento y el estado, por ejemplo IN=led/2/1.

if (led1.val == 1)
{
  print "IN=led/1/1"
  printh ff ff ff
}else
{
  print "IN=led/1/0"
  printh ff ff ff
}
4.2

Decodificar

▶ 46:06

En el PIC se captura la posición y el estado con strtok y atoi, y un switch decide qué elemento cambiar.

else if (strstr(trama_rx_nextion, "led"))
{
  strcpy(captura_nextion, strtok(trama_rx_nextion, "/"));
  strcpy(captura_nextion, strtok(0, "/"));
  nextion_var = atoi(captura_nextion);         // captura la posicion
  strcpy(captura_nextion, strtok(0, "/"));
  nextion_var_corta = atoi(captura_nextion);   // captura el estado
  switch (nextion_var)
  {
    case 1: led1 = nextion_var_corta; break;
    case 2: led2 = nextion_var_corta; break;
  }
}
