Full duplex más timer

Sobre el proyecto de transmisión y recepción serial se agrega una tarea más: un juego de luces que se abre desde el centro. En Arduino se usa la librería TimerOne con una interrupción cada 100 ms; en el PIC se configura Timer1 con los valores de Timer Calculator. Un contador dentro de la interrupción permite hacer tareas más lentas con el mismo timer.

  • Arduino Uno y librería TimerOne
  • MikroC PRO for PIC y PIC18F25K20
  • Timer Calculator
  • Cinco leds más el montaje de la serie (LM35, motor, leds)
  • Proteus y LabVIEW

Arduino con TimerOne

Cinco leds más

1.2

Instalar TimerOne

▶ 1:16

Se descarga la librería TimerOne y se agrega desde Programa, Incluir librería, o copiando la carpeta en libraries (sin guiones en el nombre).

1.3

Configurar la interrupción

▶ 3:04

En el setup se inicia el timer en microsegundos y se le asocia la función que se ejecutará en cada desborde.

#include <TimerOne.h>
...
Timer1.initialize(100000); // cada 100 ms
Timer1.attachInterrupt(timerInterpcion);
1.4

Patrón de luces

▶ 10:10

Los patrones se guardan en un vector y la interrupción saca uno por vez al puerto: primero el centro y luego se va abriendo. Cuando el índice llega a 4 vuelve a cero.

void timerInterpcion() {
  veces++;
  if (veces >= 10) {        // tarea más lenta
    sacar = luces[recorre];
    sacar = sacar << 1;     // los leds empiezan en PC1
    PORTC = sacar;
    recorre++;
    if (recorre >= 4) recorre = 0;
    veces = 0;
  }
}
1.5

Más lento

▶ 15:16

Con un contador (veces) dentro de la interrupción se ejecuta el patrón cada 10 desbordes, es decir, cada segundo, sin cambiar el timer.

En el PIC18 se usan los registros LAT para las salidas. Los leds van en el puerto A.

Timer Calculator

▶ 17:56

Con el programa gratuito Timer Calculator se elige el micro, la frecuencia y el tiempo, y se copia la función InitTimer1 que genera. En la interrupción se revisa también TMR1IF y se recargan TMR1H y TMR1L.

▶ 21:24
