Fin de trama serial con timer

Lección 41 del curso. Algunos dispositivos mandan datos sin inicio ni final. La técnica de línea en reposo (idle line) usa un timer: cada byte recibido lo reinicia y, si se desborda sin que llegue otro, se da la trama por terminada. Se calcula el tiempo según los baudios, se configura Timer0 en un PIC18F2550 a 4 MHz y se procesa la trama en el programa principal.

Fase 1

La idea

1.1

Tramas sin inicio ni fin

▶ 0:00

Se pueden recibir tramas de una letra, medianas o largas sin saber dónde terminan. Es lo que en los STM32 se conoce como detección de línea en reposo; aquí se hace con un timer.

1.2

Tiempo por byte

▶ 1:42

El tiempo de un bit es 1/baudios. Un byte con inicio y parada son unos 10 bits; con margen se multiplica por unos 12. A 2400 baudios son unos 5 ms y a 9600 unos 1.25 ms.

1.3

Elegir el timer

▶ 2:49

Un timer de 5 a 10 ms sirve para velocidades comunes. Aquí se calcula para unos 8 ms con Timer0 en 8 bits y su prescaler.

1.4

Cómo funciona

▶ 3:21

Cada byte que llega reinicia el timer. Si el timer termina su cuenta y no llegaron datos, la trama acabó y se levanta una bandera.

Fase 2

Configuración

2.1

Pines, UART y Timer0

▶ 5:01

RC6 salida (TX), RC7 entrada (RX), dos leds en RC0 y RC1. Timer0 en 8 bits con reloj interno y prescaler, apagado y sin interrupción hasta que llegue el primer byte.

INTCON = 0b01000000;
TRISC6_bit = 0; TRISC7_bit = 1;
TRISC0_bit = 0; TRISC1_bit = 0;
UART1_Init(9600);
T0CON = 0; T08BIT_bit = 1;
TMR0ON_bit = 0; T0CS_bit = 0; PSA_bit = 0;
TMR0IF_bit = 0; TMR0IE_bit = 0;
2.2

Habilitar recepción

▶ 6:42

Se limpia RCIF, se reinicia la recepción con CREN, se habilita la interrupción de recepción y por último GIE.

RCIF_bit = 0;
CREN_bit = 0; CREN_bit = 1;
RCIE_bit = 1;
GIE_bit = 1;
Fase 3

Interrupción

3.1

Llega un byte

▶ 8:19

Se guarda en la trama, se avanza el contador (con tope de 50) y se reinicia y enciende el Timer0 con su interrupción.

3.2

Se desborda el timer

▶ 9:57

Si el Timer0 llega a desbordarse, la trama terminó: se levanta flag_rx, se pone el contador en cero, se apaga la recepción y el timer.

void uartrx() iv 0x0008 ics ICS_AUTO {
  if (RCIF_bit == 1) {
    dato_rx = RCREG;
    trama_rx[cont_trama] = dato_rx;
    cont_trama++;
    if (cont_trama >= 50) cont_trama = 0;
    TMR0L = 0; TMR0ON_bit = 1; TMR0IE_bit = 1;
    RCIF_bit = 0;
  }
  if (TMR0IF_bit == 1) {
    flag_rx = 1; cont_trama = 0; RCIE_bit = 0;
    TMR0IF_bit = 0; TMR0IE_bit = 0; TMR0ON_bit = 0;
  }
}
Fase 4

Procesar y probar

4.1

En el programa principal

▶ 10:31

Con flag_rx en 1 se devuelve la trama por el serial, se busca "led=" y "on" para manejar el led, se limpia la trama y se vuelve a habilitar la recepción.

UART1_Write_Text(trama_rx);
if (strstr(trama_rx, "led=")) {
  if (strstr(trama_rx, "on")) led2 = 1;
  else led2 = 0;
}
memset(trama_rx, 0, 50);
CREN_bit = 0; CREN_bit = 1;
RCIF_bit = 0; RCIE_bit = 1;
flag_rx = 0;
4.2

Prueba

▶ 12:47

Con Hercules y un puerto virtual se manda una letra o una frase larga y el micro la repite completa, sin importar el tamaño. Sirve para dispositivos que mandan datos sin inicio ni final.
