Temas oscuros con DevStyle en CubeIDE

Además del tema oscuro que trae STM32CubeIDE, se puede instalar DevStyle, un complemento de Eclipse con varios temas (Dark Gray, Dark Green, Light…) y opciones de color. Se muestra cómo queda, dónde se cambia y cómo se instala desde Eclipse Marketplace.

▶ Ver el video completo (3:46) Empezar el paso a paso
  • STM32CubeIDE con conexión a Internet
1 · Eclipse Marketplace2 · Color Themes
Fase 1

Instalar DevStyle

1.1

Abrir Eclipse Marketplace

▶ 1:13

En el menú Help → Eclipse Marketplace…. La primera vez tarda en cargar la lista.

1.2

Buscar e instalar

▶ 1:20

En Find escribe dark y pulsa Go. Aparece Darkest Dark Theme with DevStyle. Pulsa Install, acepta la licencia y confirma.

1.3

Esperar y reiniciar

▶ 1:46

Abajo a la derecha se ve el progreso; la instalación tarda bastante. Al terminar pide reiniciar STM32CubeIDE: di que sí.

Si Windows Defender avisa que puede afectar el rendimiento, puedes elegir Fix Automatically o Skip.

Fase 2

Elegir y personalizar el tema

2.1

Asistente de inicio

▶ 0:01

Al arrancar de nuevo aparece un asistente para escoger el tema (claro u oscuro). La pantalla de carga también cambia.

2.2

Cambiar el tema cuando quieras

▶ 0:38

En Window → Preferences → DevStyle → Color Themes eliges el Workbench theme (Dark Gray, Dark Green…) y el Editor theme. Pulsa Apply para verlo.

2.3

Dónde se nota

▶ 2:52

El tema oscuro aplica sobre todo al editor de código en C. La vista de configuración de pines (el .ioc) sigue con sus colores claros.

Si prefieres no instalar nada, el tema oscuro básico está en Window → Preferences → Appearance.
