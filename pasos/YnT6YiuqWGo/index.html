ST-Link V2 clon con STM32CubeProgrammer

Con algunos ST-Link V2 clon, STM32CubeProgrammer muestra un número de serie de una sola cifra o letra y no deja conectar, por eso antes se usaba el viejo ST-Link Utility. En este tip corto se muestra cómo programar directamente desde CubeProgrammer: se habilita la opción Shared, se refresca el serial y ya conecta. Al final se carga un programa que hace titilar un LED.

Fase 1

El problema

1.1

El serial del clon sale incompleto

▶ 0:35

Al conectar algunos clones, en ST-LINK configuration el campo Serial number muestra solo un carácter (un 7, una A, una B…). Así CubeProgrammer no deja conectarse al micro.

Antes la salida era usar el programa antiguo STM32 ST-LINK Utility, que sí reconoce el clon.

Fase 2

La solución en CubeProgrammer

2.1

Habilitar Shared y refrescar

▶ 1:06

En la configuración del ST-Link cambia Shared de Disabled a Enabled.

Pulsa el botón de refrescar junto a Serial number: el programa le asigna un serial provisional al clon.

2.2

Connect

▶ 1:15

Pulsa Connect. El indicador pasa a Connected y en Target information aparece el micro (por ejemplo STM32F401 de la Black Pill).

Fase 3

Cargar un programa

3.1

Abrir el archivo y descargar

▶ 1:25

Con Open file elige el .hex del proyecto (está en la carpeta Debug) y pulsa Download. El log termina con File download complete.

3.2

Resetear el micro

▶ 1:37

Después de programar pulsa el botón de reset de la tarjeta para que arranque el programa. El LED empieza a titilar.

Si después de cargar no pasa nada, casi siempre falta el reset.
