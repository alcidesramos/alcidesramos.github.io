Recepción serial DMA en varios UART

Actualización de la librería de la clase 87 (recepción serial por DMA con detección de línea inactiva). Ahora cada puerto se describe con una estructura UARTRXS que guarda el handle, la instancia, el buffer, la bandera y el número de datos, así que agregar un UART más es declarar una variable y un if. Se prueba físicamente en un STM32F411 con USART1 y USART2 conectados a dos conversores USB-serial (Proteus solo simula IDLE en un puerto).

▶ Ver el video completo (16:38) Empezar el paso a paso
  • STM32F411 (Black Pill) u otro STM32F4
  • Dos conversores USB-serial (USART1 en PA9/PA10 y USART2)
  • Librerías uart.c/.h, UARTRX.c/.h y UART_INT_DMA_IDLE.c
  • Hercules u otra terminal serial

Fase 1

Configurar el primer UART

1.1

USART1 asíncrono con DMA RX

▶ 1:43

Crea el proyecto y en USART1 elige modo Asynchronous a 9600 baudios (en físico se puede usar 115200). En DMA Settings agrega USART1_RX y en NVIC habilita la interrupción global. Guarda para generar el código.

Fase 2

Agregar la librería

2.1

Copiar los archivos

▶ 3:14

Crea la carpeta Librerias dentro de Core y agrégala al include path. Copia uart.c/uart.h (escritura por el puerto), UART_INT_DMA_IDLE.c (el callback del evento de línea inactiva) y la nueva UARTRX.c/UARTRX.h.

2.2

Incluir en main.c

▶ 4:21

Incluye uart.h y UARTRX.h. UART_INT_DMA_IDLE.c no se incluye: solo contiene el evento de interrupción del micro, que llama al procedimiento uartRX_INTERRUPT de la librería.

/* USER CODE BEGIN Includes */
#include "uart.h"
#include "UARTRX.h"
/* USER CODE END Includes */
2.3

Declarar el puerto en UARTRX.c

▶ 4:53

Declara el handle del UART como externo y crea una variable de tipo UARTRXS con el handle, la instancia del USART y el tamaño del buffer (100 datos). El nombre de la variable es libre (UARTRX1, GPS, NEXTION…).

//DEFINE LOS USART A USAR
extern UART_HandleTypeDef huart1;

//iniciar uart de recepcion por interrupcion y tamaño del buffer
UARTRXS UARTRX1 = {&huart1, USART1, 100};
2.4

Variables externas en UARTRX.h

▶ 5:24

En el .h ya hay variables externas predefinidas (UARTRX1 a UARTRX8 y UARTNEXTION). Si usas otro nombre, agrégalo aquí como extern. El .h también trae una ayuda con los pasos de uso.

extern UARTRXS UARTRX1;
extern UARTRXS UARTRX2;
/* ... */
extern UARTRXS UARTRX8;
extern UARTRXS UARTNEXTION;
Fase 3

Usar la librería en main

3.1

Inicializar

▶ 6:34

Después de inicializar los periféricos escribe un mensaje de prueba y arranca la recepción DMA para la variable creada.

uartx_write_text(&huart1, "INICIANDO1\r\n");
uartRX_it_idle_dma_init(&UARTRX1);
3.2

Revisar la bandera en el while

▶ 7:45

Cuando llega una trama, flag_rx de la estructura vale 1. Aquí se devuelve lo recibido (eco) y se reactiva el DMA. En un proyecto real se llamaría a procesa_rx() para decodificar la trama, como en videos anteriores.

while (1)
{
    if (UARTRX1.flag_rx == 1)
    {
        uartx_write_text(&huart1, UARTRX1.trama_rx);
        // procesa_rx();  // procedimiento donde se procesan los datos
        uartRX_DMA_Re_init(&UARTRX1);
    }
}
3.3

Número de datos recibidos

▶ 9:24

La estructura también guarda cuántos datos llegaron en num_datos. Crea un buffer texto de 50 posiciones e imprímelo antes de reactivar el DMA. "SUSCRIBANSE" devuelve 11 y "AL CANAL" 8.

char texto[50];

sprintf(texto, "\r\nson=%u\r\n", UARTRX1.num_datos);
uartx_write_text(&huart1, texto);
uartRX_DMA_Re_init(&UARTRX1);
Fase 4

Agregar un segundo UART

4.1

Configurar USART2

▶ 11:52

En el .ioc activa USART2 asíncrono (los baudios pueden ser distintos), agrega su DMA RX y habilita su interrupción. Guarda para regenerar el código.

4.2

Declarar la segunda variable

▶ 12:24

En UARTRX.c agrega el extern de huart2 y una nueva variable UARTRXS. El nombre de la variable no tiene que coincidir con el número del puerto: UARTRX2 podría asociarse a USART1 si quieres.

extern UART_HandleTypeDef huart1;
extern UART_HandleTypeDef huart2;

UARTRXS UARTRX1 = {&huart1, USART1, 100};
UARTRXS UARTRX2 = {&huart2, USART2, 100};
4.3

Inicializar y atender ambos

▶ 13:31

En main inicializa las dos recepciones y crea un if igual para el segundo puerto. Las respuestas se pueden enviar por el puerto que quieras; aquí todo se monitorea por el USART1.

uartx_write_text(&huart1, "INICIANDO1\r\n");
uartx_write_text(&huart2, "INICIANDO2\r\n");
uartRX_it_idle_dma_init(&UARTRX1);
uartRX_it_idle_dma_init(&UARTRX2);

while (1)
{
    if (UARTRX1.flag_rx == 1)
    {
        uartx_write_text(&huart1, UARTRX1.trama_rx);
        sprintf(texto, "\r\nson=%u\r\n", UARTRX1.num_datos);
        uartx_write_text(&huart1, texto);
        uartRX_DMA_Re_init(&UARTRX1);
    }
    if (UARTRX2.flag_rx == 1)
    {
        uartx_write_text(&huart1, UARTRX2.trama_rx);
        sprintf(texto, "\r\nson=%u\r\n", UARTRX2.num_datos);
        uartx_write_text(&huart1, texto);
        uartRX_DMA_Re_init(&UARTRX2);
    }
}
4.4

Un if por puerto en uartRX_INTERRUPT

▶ 14:20

En UARTRX.c, dentro de uartRX_INTERRUPT, debe haber un bloque por cada variable: comprueba que su bandera esté en 0 y que la interrupción venga de su instancia, detiene el DMA, guarda el tamaño y levanta la bandera.

Con dos terminales abiertas (COM5 y COM4) llegan INICIANDO1 e INICIANDO2, y lo que se envía por cualquiera de los dos puertos se recibe por interrupción y se informa con su número de caracteres. Así se pueden seguir agregando USART3 y los que tenga el micro.

void uartRX_INTERRUPT(UART_HandleTypeDef *huart, uint16_t sizex)
{
    //colocar una por cada usart usado
    if ((UARTRX1.flag_rx == 0) && (huart->Instance == UARTRX1.usart_instance))
    {
        HAL_UART_DMAStop(UARTRX1.huart);
        UARTRX1.num_datos = sizex;
        UARTRX1.flag_rx = 1;
    }
    if ((UARTRX2.flag_rx == 0) && (huart->Instance == UARTRX2.usart_instance))
    {
        HAL_UART_DMAStop(UARTRX2.huart);
        UARTRX2.num_datos = sizex;
        UARTRX2.flag_rx = 1;
    }
}

Al copiar el bloque para el segundo puerto, cambia todos los UARTRX1 por UARTRX2 (bandera, instancia, huart y num_datos).
