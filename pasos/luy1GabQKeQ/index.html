Modbus TCP con PIC y ESP8266

Factory IO se configura como servidor Modbus TCP en el puerto 502. El PIC18F2550 maneja el ESP8266 a 9600 baudios con una librería propia y se conecta a la IP del PC. Una trama Modbus TCP lleva la cabecera MBAP (identificador de transacción, protocolo 0 y largo) y luego el esclavo, la función y los datos. La función 0x06 escribe un registro holding; con la escritura de varios registros se mandan los dos potenciómetros en una sola trama, más rápido. digital_out es un entero de 16 bits con nombres para cada bit, que se manda como coils para mover las bandas con cuatro pulsadores. Una UART por software sirve para depurar.

2.2

Escribir un registro

▶ 11:40

modbus_write_holding arma la cabecera MBAP (transacción 0, protocolo 0, largo 6), el esclavo, la función 6 y la dirección y el dato en dos bytes cada uno.

void modbus_write_holding(unsigned int dir_mod, unsigned int dat_mod) {
  RCIE_bit = 0;     // deshabilita interrupciones
  modbus_tx[0] = 0;
  modbus_tx[1] = 0;
  modbus_tx[2] = 0;
  modbus_tx[3] = 0; // identifica protocolo modbus
  modbus_tx[4] = 0; // identifica protocolo modbus
  modbus_tx[5] = 6; // largo trama
  modbus_tx[6] = dir_esclavo; // identificación del esclavo
  modbus_tx[7] = 6; // comando de escribir 1 registro holding
  // guarda la dirección
  modbus_tx[8] = Hi(dir_mod);
  modbus_tx[9] = Lo(dir_mod);
  // ... el dato y el envío (ver video)
}

▶ 13:00

3.1

Varios registros

▶ 16:30

En lugar de dos tramas se carga el buffer con los dos valores y se mandan juntos desde la dirección 0; así el sistema responde más en tiempo real.

val2 = codigo * 100.0 / 1023.0;  // lo escala de 0 a 100
Delay_us(2);

// manda varias variables análogas
// carga el buffer con los datos a enviar
buff_tx[0] = val1;
buff_tx[1] = val2;
modbus_write_holding_varios(0, buff_tx, 2); // manda desde la dirección cero dos datos
