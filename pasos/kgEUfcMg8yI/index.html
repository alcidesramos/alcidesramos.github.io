Clase 35: printf por el puerto serial

Antes armábamos el texto con sprintf y luego lo mandábamos con uartx_write_text. printf de C llama internamente a __io_putchar por cada carácter; si esa función transmite por la UART, printf imprime por el puerto serie con todo su formato.

Fase 1

Crear printf_out.h

1.1

Nueva cabecera

▶ 0:36

En la carpeta Librerias crea printf_out.h (New → Header File). Basta con el .h porque solo redefine una función que la librería de C ya declara.

1.2

El código

▶ 2:20

Cambia huart1 por el puerto que uses (huart2, huart6…):

#include "string.h"
#include "stdio.h"
#include "main.h"
#define uartx huart1   // colocar el puerto serial a usar
extern UART_HandleTypeDef uartx;
int __io_putchar(int ch)
{
    //ITM_SendChar(ch);   // si se quiere usar por debugger
    HAL_UART_Transmit(&uartx, (uint8_t *)&ch, 1, 0xFFFF);   // printf al puerto
    return ch;
}
1.3

Incluirlo en main.c

▶ 1:45
#include "printf_out.h"
Fase 2

Usar printf

2.1

Imprimir directo

▶ 3:28

Ya no hace falta indicar el puerto ni pasar por un arreglo:

printf("HOLA\r\n");
printf("CNT1=%-u  CNT1=%3d  CNTf=%4.2f\r\n", cont8, cont8s, contf);

Para el LCD sigues usando sprintf + Lcd_Text. Para flotantes recuerda habilitar -u _printf_float (clase 32).
