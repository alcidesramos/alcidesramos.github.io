Hasta 8 servos con un timer

Un servo necesita un pulso cada 20 ms cuyo ancho (entre 0.5 y 2.5 ms según el modelo) fija el ángulo. Como 20 ms divididos entre 2.5 ms dan 8, un solo timer puede atender ocho servos por turnos. La librería (publicada en Libstock) calcula los valores del Timer1, recorre los estados alto y bajo de cada servo en la interrupción y ofrece servo_valor para dar el ángulo. Los servos que no se usan se ponen en un mismo pin libre.

Fase 2

Cómo funciona

2.1

Cálculos del timer

▶ 8:16

Con la frecuencia del cristal se calcula cuánto cargar en el Timer1 para 2.5 ms y para 1.5 ms. Los estados alto y bajo de cada servo se definen con un enum.

const unsigned long cristal = Clock_kHz();
const float tmr1_reg = 65536.0 - ((cristal*2.5)/(4.0));
const float tmr1_reg_ini = 65536.0 - ((cristal*1.5)/(4.0));
enum servo_estado {hi_1, lo_1, hi_2, lo_2, ..., hi_8, lo_8};
2.2

init_servos

▶ 11:05

Recibe el pulso mínimo y máximo, calcula la pendiente para pasar de ángulo a tiempo y deja todos los servos en el centro.

2.3

Configurar el Timer1

▶ 11:41

Timer1 con prescaler 1, se carga casi lleno para forzar la primera interrupción y se habilita su interrupción.

T1CON = 0;
T1CKPS1_bit = 0; T1CKPS0_bit = 0;
TMR1IF_bit = 0;
TMR1L = 254;   // fuerza la primera interrupción
TMR1H = 255;
TMR1IE_bit = 1;
TMR1ON_bit = 1;
2.4

Máquina de estados

▶ 12:46

En cada interrupción se ve en qué estado va: en el alto se pone el pin en 1 y se carga el tiempo de ese servo; en el bajo se pone en 0 y se carga lo que falta para completar 2.5 ms. Luego pasa al siguiente servo.

case hi_2:
  servo2 = 1;
  int_tempo = servos[1];
  tmr1h = hi(int_tempo);
  tmr1l = lo(int_tempo);
  estado_servos = lo_2;
  break;
Fase 3

Usarla

3.1

Pines

▶ 15:34

En el programa se declaran los ocho pines y sus direcciones. Pueden ir en cualquier pin; los servos que no se usan se ponen todos en un mismo pin libre.

#include "servos_T1.h"
sbit servo1 at portb.b0;
sbit servo2 at portb.b1;
sbit servo3 at portb.b2;
sbit servo4 at portb.b3;
...
sbit servo1_direction at trisb.b0;
...
3.2

Main

▶ 17:49

Se inicia con el rango de pulso, se habilita la interrupción global y con servo_valor(número, ángulo) se mueve cada servo.

init_servos(0.5, 2.5);
GIE_bit = 1;
while (1) {
  servo_valor(1, 0);
  servo_valor(2, 90);
}
