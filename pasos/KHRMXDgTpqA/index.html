Texas Instruments: leer un pulsador

No hay que tocar HALCoGen: en la clase 1 los pines 4 y 5 del puerto B ya quedaron como entradas. Solo se agrega código en Code Composer Studio: una variable bool, la lectura con gioGetBit y un if que decide el estado del LED. Como el pulsador tiene resistencia de pull-up, al presionarlo se lee 0.

Leer el pin y decidir

▶ 0:00

Se crea una variable bool sw y en cada vuelta se lee el bit 4 del puerto B. Si vale 0 (pulsador presionado) se prende el LED del pin 7; si no, se apaga.

int main(void)
{
  gioInit();
  bool sw;

  while (1)
  {
    sw = gioGetBit(gioPORTB, 4);

    if (sw == 0) gioSetBit(gioPORTB, 7, 1);
    else         gioSetBit(gioPORTB, 7, 0);

    gioToggleBit(gioPORTB, 6);
    delay_ms(200);
  }
}
