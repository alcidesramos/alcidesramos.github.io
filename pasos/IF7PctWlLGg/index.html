La función millis en un PIC

En Arduino millis devuelve los milisegundos desde que arrancó el micro y permite hacer tareas a distintos tiempos sin bloquear. Aquí se hace lo mismo en un PIC16F876A a 20 MHz: Timer Calculator genera la configuración del Timer0 para una interrupción de casi 1 ms, en la interrupción se incrementa un contador y la función millis lo retorna. En el ciclo principal se compara el tiempo actual con el guardado.

1.3

Contador unsigned long

▶ 2:14

Igual que en Arduino se usa un unsigned long, que llega hasta 4294967295. En milisegundos eso son unos 49.7 días antes de volver a cero.

sbit led1 at RB0_bit;
sbit led2 at RB1_bit;
unsigned long millis_count = 0;
unsigned long time1, time2;
Fase 2

Crear millis

2.1

Timer Calculator

▶ 5:40

Timer Calculator (gratis, en los programas de soporte de MikroElektronika) se elige la familia del PIC, la frecuencia y 1 ms. Da el código del Timer0: prescaler 1:32 y precarga 100, para una interrupción de 998.4 µs.

2.2

Interrupción

▶ 6:44

Se pega el código generado y dentro de la interrupción se incrementa el contador.

void InitTimer0() {
  OPTION_REG = 0x84;
  TMR0 = 100;
  INTCON = 0xA0;
}

void Interrupt() {
  if (TMR0IF_bit) {
    TMR0IF_bit = 0;
    TMR0 = 100;
    millis_count++;
  }
}
2.3

La función

▶ 7:16

millis solo retorna el valor del contador.

unsigned long millis() {
  return (millis_count);
}

3.2

Comparar tiempos

▶ 10:31

Si pasó un segundo desde time1 se invierte el led 1 y se actualiza time1. Lo mismo con time2 y 3 segundos. Nada bloquea el programa.

while (1) {
  if (millis() - time1 >= 1000) {
    led1 = ~led1;
    time1 = millis();
  }
  if (millis() - time2 >= 3000) {
    led2 = ~led2;
    time2 = millis();
  }
}
