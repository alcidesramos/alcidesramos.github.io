Usar el modo sleep en MikroC

Versión en MikroC de un video hecho antes con MPLAB XC8. En MikroC no hay un configurador gráfico, así que hay que conocer los registros. Un PIC16F1824 con cristal hace una secuencia de LED, avisa por el serial que se va a dormir y ejecuta sleep. Se despierta con la interrupción externa en RA2 (con pull-up interna) o al recibir un carácter por el UART, remapeado a RA0 y RA1. Unos LED indican si despertó por flanco o por serial.

Fase 1

Configuración

1.1

Proyecto

▶ 0:00

Proyecto con un PIC16F1824 y cristal externo (oscilador XT). Se habilita el Power-up Timer y se deja deshabilitado lo demás, incluido el watchdog.

1.2

LED y pines del UART

▶ 2:14

Los LED se manejan con LAT, como en los 16F nuevos. El UART se remapea con los bits RXDTSEL y TXCKSEL: en 1, TX queda en RA0 y RX en RA1.

sbit led1 at LATC4_bit;
sbit led2 at LATC5_bit;
sbit led_f at LATC2_bit;   // despertó por flanco
sbit led_s at LATC3_bit;   // despertó por serial

ANSELA = 0;  ANSELC = 0;   // todo digital
UART1_Init(9600);
TRISC = 0;  TRISA = 0;
TRISA1_bit = 1;   // entrada serial
TRISA2_bit = 1;   // entrada por flanco
RXDTSEL_bit = 1;  // RX en RA1, si no RC5
TXCKSEL_bit = 1;  // TX en RA0, si no RC4
1.3

Pull-up interna

▶ 4:37

Para ahorrar energía no se pone resistencia externa en el pulsador: se usa la pull-up interna de RA2. NOT_WPUEN en 0 autoriza las pull-up individuales y WPUA2 activa la de ese pin.

INTCON = 0b01000000;   // habilita interrupciones de periféricos
NOT_WPUEN_bit = 0;     // autoriza las pull-up individuales
WPUA2_bit = 1;         // pull-up en RA2
UART1_Write_Text("Iniciando\r\n");
Fase 2

Dormir y despertar

2.1

La instrucción sleep

▶ 5:44

El programa hace una secuencia con el LED 1, avisa por el serial y se duerme. En MikroC la instrucción va dentro de un bloque asm.

asm sleep;
2.2

Despertar por flanco

▶ 7:25

Antes del while se configura la interrupción externa por flanco de bajada y se habilita GIE. La rutina de interrupción se crea con el Interrupt Assistant: si fue por flanco, prende el LED de flanco y limpia la bandera. Al despertar, el programa prende un LED un rato y vuelve a dormir.

INTF_bit = 0;
INTEDG_bit = 0;   // flanco de bajada
INTE_bit = 1;     // habilita la interrupción por flanco
GIE_bit = 1;
2.3

Despertar por serial

▶ 9:04

Se limpia RCIF y se habilita RCIE. En la interrupción se lee RCREG (obligatorio para limpiar la recepción), se prende el LED de serial y se limpia la bandera. Así el micro despierta al recibir un carácter.

char dato;

void interrupcion() iv 0x0004 ics ICS_AUTO
{
  if (INTF_bit == 1) {
    led_f = 1;
    INTF_bit = 0;
  }
  if (RCIF_bit == 1) {
    dato = RCREG;
    led_s = 1;
    RCIF_bit = 0;
  }
}

Esta rutina maneja un solo carácter. Para recibir cadenas hace falta otra lógica.
