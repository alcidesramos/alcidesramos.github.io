Seno de 60 Hz con PWM

Si el ancho de cada pulso sigue la forma del seno, al filtrar queda el seno. Con 120 muestras por periodo de 60 Hz el PWM debe ser de 7200 Hz. En MATLAB se calcula el seno entre 0 y 5 V y cada valor se convierte al registro de ciclo útil de 10 bits. En el PIC, cada interrupción del Timer2 carga el siguiente valor en CCPR1L y en los dos bits bajos. Un filtro RC de dos etapas deja el seno y una etapa con amplificador y transistores lo lleva a mayor voltaje.

Fase 1

La idea

1.1

Seno con PWM

▶ 0:00

El periodo del seno se divide en partes iguales y en cada una el ancho del pulso es proporcional al valor del seno. Al filtrar, el promedio sigue la forma de la onda.

1.2

Frecuencia del PWM

▶ 2:03

Con 120 muestras por periodo de 60 Hz, el PWM es de 60 × 120 = 7200 Hz. El ancho de cada pulso se pasa al registro del PWM con la ecuación de la hoja de datos.

Fase 2

Tabla en MATLAB

2.1

El seno

▶ 3:36

Se generan 120 puntos de un periodo de 60 Hz, con un seno que va de 0 a 5 V.

clc, close all, clear
frecuencia = 60;
muestras = 120;
x = linspace(0, 1/frecuencia, muestras);
y = 2.5 + 2.5*sin(2*pi*frecuencia*x);
2.2

Pasar a registro

▶ 8:15

Cada voltaje se convierte en tiempo en alto y ese tiempo en el valor del registro: Ton / (Tosc × preescalador). Con 20 MHz y preescalador 4 los valores quedan entre 0 y unos 696.

frec = frecuencia*muestras;
vmax = 5;
vmin = 0;
t = 1/frec;
xtal = 20e6;
tosc = 1/xtal;
pres = 4;
% calcula el Ton del pwm
for i = 1:muestras
  pwm(i) = y(i)*t/vmax;
  reg(i) = pwm(i)/(tosc*pres);
end
Fase 3

Programa en MikroC

3.1

La tabla

▶ 11:21

Los 120 valores redondeados se copian a un arreglo constante. LEEBIT devuelve un bit de un número, para cargar los dos bits bajos del ciclo útil.

3.2

PWM a mano

▶ 14:26

CCP1 en modo PWM, Timer2 con preescalador 4 y PR2 = 173, que a 20 MHz da unos 7200 Hz.

INTCON = 0b01000000;
TRISA = 0;
TRISC = 0;              // salida pwm
CCP1CON = 0b00001100;   // configura como pwm
T2CON = 0;
// preescalador a 4
T2CKPS1_bit = 0;
T2CKPS0_bit = 1;
PR2 = 173;              // registro pr2
3.3

Arrancar

▶ 15:59

Se carga el primer valor, se limpia la bandera, se habilitan la interrupción del Timer2 y la global, y se prende el timer.

3.4

Interrupción

▶ 18:20

En cada periodo del PWM se toma el siguiente valor de la tabla. Los 8 bits altos van a CCPR1L y los 2 bajos a DC1B1 y DC1B0.

unsigned int es, toca;

char LEEBIT(unsigned int port, char bit1) {
  if ((port & (1 << bit1)) > 0) return (1);
  else return (0);
}

void interrupcion() iv 0x0008 ics ICS_AUTO {
  if (TMR2IF_bit == 1) {
    toca++;
    if (toca >= muestras-1) toca = 0;
    es = onda[toca];
    CCPR1L = es >> 2;            // carga los 8 bits altos
    DC1B1_bit = LEEBIT(es, 1);   // carga bit 1
    DC1B0_bit = LEEBIT(es, 0);   // carga bit 0
    TMR2IF_bit = 0;
  }
}
