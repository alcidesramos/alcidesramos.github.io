Clase 120: Librerías C++ en STM32CubeIDE

Muchos tutoriales renombran main.c a main.cpp, pero cada vez que se regenera el código desde CubeMX vuelve a aparecer main.c y se pierde el trabajo. La propuesta es dejar main.c casi intacto y crear un main.cpp en la carpeta de librerías, con dos funciones: cpp_main(), que reemplaza lo que va antes del while, y cpp_while(), que se ejecuta dentro del while. Se declaran con extern "C" para que main.c pueda llamarlas. Desde main.cpp se pueden usar librerías en C (como uart) y clases de C++ (una calculadora de ejemplo). También se muestra cómo convertir a C++ un proyecto que se creó en C.

Fase 1

El problema

1.1

Renombrar main.c no es buena idea

▶ 1:22

Se crea el proyecto con Targeted Language C++. Aun así el main sigue siendo main.c.

Si se renombra a main.cpp funciona, pero al cambiar algo en CubeMX y regenerar el código se crea otro main.c y el trabajo queda en el archivo viejo.

La solución: dejar main.c y que este llame a un main.cpp donde va todo el código.

Fase 2

main.cpp

2.1

Librerías e includes

▶ 2:32

Se crea la carpeta Librerias, se agrega al include path y se copian uart.c/uart.h. En USART1 se activa el modo asíncrono a 115200.

Se pega la plantilla main.cpp, que ya incluye main.h y las librerías estándar de C. Debajo van las librerías de terceros.

2.2

Periféricos como extern

▶ 4:50

Los handles que CubeMX crea en main.c (en Private variables: timers, UART, I2C, etc.) se copian a main.cpp como extern para poder usarlos allí.

// periféricos usados, sacados del main.c
extern UART_HandleTypeDef huart1;
Fase 3

Enlazar main.c con main.cpp

3.1

Declarar las funciones en main.c

▶ 5:54

En main.c, en una sección USER CODE (por ejemplo Private define), se declaran las dos funciones externas dentro de un bloque extern "C".

/* USER CODE BEGIN PD */
#ifdef __cplusplus
extern "C" {
#endif

void cpp_main(void);
void cpp_while(void);

#ifdef __cplusplus
}
#endif
/* USER CODE END PD */
3.2

Llamarlas en main.c

▶ 8:07

cpp_main() va en USER CODE BEGIN 2 (antes del while) y cpp_while() dentro del while. Después de esto main.c no se vuelve a tocar.

/* USER CODE BEGIN 2 */
cpp_main();
/* USER CODE END 2 */

while (1)
{
  cpp_while();
  /* USER CODE END WHILE */
}
3.3

Escribir en main.cpp

▶ 6:57

En main.cpp se definen las dos funciones con extern "C". Lo que antes iba arriba del while va en cpp_main y lo del while en cpp_while.

extern "C" void cpp_main(void)
{
  uartx_write_text(&huart1, "Iniciando\r\n");
}

extern "C" void cpp_while(void)
{
  uartx_write_text(&huart1, "suscribete al canal\r\n");
  HAL_Delay(600);
}
Fase 4

Usar una clase C++

4.1

Incluir la librería C++

▶ 9:11

Se copian operaciones.cpp y operaciones.h a Librerias. Definen una clase calculadora con suma, resta y multiplicación.

Esta librería no se puede incluir en main.c porque tiene clases; se incluye en main.cpp junto a la de C.

#include "uart.h"         // librería en C
#include "operaciones.h"  // librería en C++

// ejemplo de clase en operaciones.h
class Calculadora {
public:
  int suma(int a, int b);
  int resta(int a, int b);
  int multiplica(int a, int b);
};

La definición de la clase es un ejemplo de cómo luce operaciones.h; el archivo del video puede tener otros nombres.

4.2

Usar el objeto

▶ 10:18

Se declaran las variables y un objeto de la clase, y en cpp_while se usan sus métodos.

int resultado;
char texto[50];
Calculadora calc;

extern "C" void cpp_while(void)
{
  uartx_write_text(&huart1, "suscribete al canal\r\n\r\n");

  resultado = calc.suma(3, 4);
  sprintf(texto,"suma=%u\r\n\r\n",resultado);
  uartx_write_text(&huart1, texto);

  resultado = calc.multiplica(3, 4);
  sprintf(texto,"mul=%u\r\n\r\n",resultado);
  uartx_write_text(&huart1, texto);

  HAL_Delay(600);
}
4.3

Resultado

▶ 11:58

En Hercules aparece el mensaje y los resultados 7 y 12. Ya se combinan librerías en C y en C++ en el mismo proyecto.

Fase 5

Proyecto que estaba en C

5.1

Convert to C++

▶ 12:50

Si el proyecto se creó en C, al compilar con main.cpp salen errores (referencias indefinidas a cpp_main).

Clic derecho en el proyecto > Convert to C++. Luego se crea la carpeta de librerías con main.cpp y se hace todo lo anterior.
