Múltiples interrupciones en Arduino

El programa principal configura el puerto serial, la interrupción por flanco y el Timer2; revisa si llegó una trama serial, mira el porcentaje de disparo (si es menor de 5 % apaga, si es mayor de 90 % prende y si no calcula el tiempo del timer con una ecuación) y envía la temperatura y el estado de un suiche. La interrupción por cruce por cero carga el Timer2 y lo habilita; la del Timer2 envía el pulso de disparo y se deshabilita. Se usa el Timer2 porque el Timer0 lo usan millis y delay y el Timer1 lo usan el servo y el PWM. La ecuación del timer se saca en Excel con una línea de tendencia.

Fase 1

La idea del programa

1.1

Programa principal

▶ 0:00

El programa principal hace cuatro cosas:

  • Configura el puerto serial, la interrupción por flanco, el timer y la interrupción serial.
  • Revisa si está activa la bandera de datos seriales y, si la está, procesa los datos.
  • Mira el porcentaje de disparo: menor de 5 % apaga, mayor de 90 % prende; si no, aplica una ecuación para pasar ese porcentaje a tiempo del timer.
  • Lee las variables análogas y digitales, arma la trama y la envía.

▶ 1:04

En cada flanco de subida (cruce por cero) se carga el timer con el valor de disparo calculado en el programa principal y se activa la interrupción del timer para que avise cuándo disparar.

Interrupción del timer

▶ 1:39

Cuando el timer se desborda envía el pulso de disparo y desactiva su propia interrupción hasta el siguiente cruce por cero.

2.2

Setup

▶ 3:55

Primero se deshabilitan las interrupciones mientras se configura todo. Se usa la interrupción externa del pin 2 por flanco de subida.

Para el disparo se usa el Timer2: el Timer0 lo usan millis y delay, y el Timer1 lo usan el servo y el PWM. El Timer2 se configura con preescalador de 1024 y su interrupción queda deshabilitada hasta el primer cruce.

void setup()
{
  noInterrupts();
  Serial.begin(9600);
  pinMode(led,OUTPUT);
  pinMode(pulso,OUTPUT);
  pinMode(suiche,INPUT);
  pinMode(2,INPUT);//PIN DE LA INTERRUPCION
  digitalWrite(led,LOW);
  attachInterrupt(digitalPinToInterrupt(2), cruce,RISING );//interrupcion por flanco de subida
  //Configura registroA
  TCCR2A=0;
  //configura registroB
  TCCR2B=0;
  TCCR2B=0b111;// Configura el preescalador a 1024 16ms
  TCNT2=0;  //Arranca en cero el timer2
  sbi(TIFR2,TOV2); // pone un uno para limpiar bandera de desborde
  cbi(TIMSK2,TOIE2); // Deshabilita interrupcion del timer2
  // ...
  interrupts();
}

Fase 3

Las rutinas

3.1

Interrupción por cruce

▶ 7:15

Al detectar el cruce apaga la carga, carga el Timer2 con el valor calculado, limpia la bandera de desborde y habilita la interrupción del timer.

//si se da la interrupcion por cruce
void cruce()
{
  digitalWrite(pulso,LOW);//APAGA LA CARGA
  TCNT2=calculo;// carga el valor en el timer2
  sbi(TIFR2,TOV2); // pone un uno para limpiar bandera de desborde
  sbi(TIMSK2,TOIE2); // habilita interrupcion del timer2
}
3.2

El loop

▶ 8:54

Si llegó una trama la procesa y limpia el buffer. Con menos de 5 % deshabilita la interrupción y deja la carga apagada; con más de 90 % la deja prendida; en otro caso calcula el valor del timer y vuelve a habilitar la interrupción por flanco.

Después lee la temperatura y envía la trama con la temperatura y el estado del suiche.

if (flag_rx==1)
{
  procesarx();
  flag_rx=0;// borra la bandera
  puntero=0;  //resetea contador de datos
  memset(trama_rx,0,30);  // borra el vector de datos recibidos
}
if (dispara<=5)
{
  detachInterrupt(digitalPinToInterrupt(2));//deshabilita interrupcion por flanco
  digitalWrite(pulso,LOW);//APAGA LA CARGA
}
else if (dispara>=90)
{
  detachInterrupt(digitalPinToInterrupt(2));// DESHABILITA INTERRUPCION POR FLANCO
  digitalWrite(pulso,HIGH);//activa la carga
}
else
{
  calculo = -1.3054*dispara + 256.17;//ecuacion para pasar a tiempo
  attachInterrupt(digitalPinToInterrupt(2), cruce,RISING );//interrupcion por flanco de subida
}
// ... lectura de la temperatura
Serial.print("temp=");
dtostrf(temperatura,5,3,trama_tx);  // convierte de decimal a texto
Serial.print(trama_tx);
Serial.print("/");
if (digitalRead(suiche)==1) Serial.print("led=on/");
else Serial.print("led=off/");
delay(50);

3.6

Interrupción del Timer2

▶ 13:44

Cuando se desborda el Timer2 se aplica el pulso de disparo de 10 µs, se limpia la bandera y se deshabilita la interrupción del timer hasta el siguiente cruce. Si se quiere, se puede dejar la señal encendida sin esperar los 10 µs.

//interrupcion del timer2
ISR(TIMER2_OVF_vect)
{
  //aplica pulso de disparo
  digitalWrite(pulso,HIGH);//activa la carga
  delayMicroseconds(10);
  digitalWrite(pulso,LOW);//APAGA LA CARGA
  sbi(TIFR2,TOV2); // pone un uno para limpiar bandera de desborde
  cbi(TIMSK2,TOIE2); // deshabilita interrupcion del timer2
}
