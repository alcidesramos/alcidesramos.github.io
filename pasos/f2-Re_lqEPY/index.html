Clase 113: PID para la fuente conmutada

Continuación de la clase 112. El objetivo no es sintonizar el PID sino mostrar cómo se implementa dentro del microcontrolador con un tiempo de muestreo preciso. El ADC pasa a DMA con dos canales: el voltaje de salida y un potenciómetro que da el set point de 0 a 21 V. Con el TIM2 a 1 µs se mide cuánto tarda el proceso de lectura y control (unos 35 µs), luego todo se mueve a la interrupción del TIM3 cada 10 ms. La librería PID calcula la parte proporcional, integral y derivativa, satura la salida entre 0 y 1000 y la carga al PWM. Al final se grafica set point y voltaje con un osciloscopio serial.

Fase 1

ADC por DMA con set point

1.1

Configurar ADC1 con DMA

▶ 1:09

En ADC1 se habilitan IN0 (voltaje de salida) e IN1 (potenciómetro del set point).

En DMA Settings se agrega la petición del ADC1. En Parameter Settings se ponen 2 conversiones, con 15 ciclos de muestreo en cada canal para no leer tan rápido y reducir el ruido.

Se activa la conversión continua al terminar todas las conversiones.

1.2

Leer los dos canales

▶ 2:25

En adc_x.h se indica que se trabaja con 2 canales por DMA. Ya no se usa ADC_Read sino ADC_Read_DMA, que deja los valores en adc_codigo[0] y adc_codigo[1].

El set point se escala al rango de la fuente (0 a 21 V).

ADC_Read_DMA(&hadc1);
voltaje=adc_codigo[0]*3.3/4095.0;
voltaje=voltaje*8.1439;
float setpoint=adc_codigo[1]*21/4095.0;

sprintf(texto,"VOL=%.1f   SET=%.1f\r\n\r\n",voltaje,setpoint);
uartx_write_text(&huart1, texto);
Fase 2

Medir el tiempo del proceso

2.1

Librería PID y tiempo de muestreo

▶ 5:12

Se copian las librerías PID y timer.c a la carpeta Librerias. En PID.h se define el tiempo de muestreo y las constantes.

Antes de usar el PID hay que saber cuánto tarda el proceso de lectura y control, para escoger un tiempo de muestreo varias veces mayor.

2.2

TIM2 a 1 µs

▶ 7:45

Se habilita TIM2 con reloj interno y preescalador 84-1, así cada cuenta vale 1 µs. El periodo se deja en el máximo.

Se arranca el timer, se pone el contador en cero, se ejecuta el proceso y se lee TIM2->CNT.

HAL_TIM_Base_Start(&htim2);
TIM2->CNT=0;

// proceso a medir
ADC_Read_DMA(&hadc1);
voltaje=adc_codigo[0]*3.3/4095.0;
voltaje=voltaje*8.1439;
PID_Control(12.5);

uint32_t tiempo=TIM2->CNT;
sprintf(texto,"TIM=%lu\r\n",tiempo);
uartx_write_text(&huart1, texto);
2.3

Resultado: 35 µs

▶ 9:20

Con un HAL_Delay dentro de la lectura por DMA el proceso tardaba casi 2 ms. Al quitarlo, todo tarda unos 35 µs.

Con eso un tiempo de muestreo de 10 a 20 ms es más que suficiente.

Haz esta medición siempre que agregues algo pesado, como un filtro digital, para confirmar que el tiempo de muestreo sigue siendo adecuado.

Fase 3

Interrupción de muestreo

3.1

Calcular el TIM3

▶ 10:21

Con la hoja de Excel: 84 MHz, preescalador 840-1 y periodo 1000 dan 10 ms.

Con preescalador 84 solo se llega a unos 65 ms (contador de 16 bits); para tiempos mayores se sube el preescalador.

3.2

Habilitar la interrupción

▶ 11:45

Se configura TIM3 con reloj interno, prescaler 839 y periodo 1000, y en NVIC Settings se habilita TIM3 global interrupt.

3.3

Mover el proceso a timer.c

▶ 12:37

La librería timer.c no lleva .h: solo se indica el timer de la interrupción (TIM3) y se escribe el código dentro del callback.

Las variables compartidas con el main se declaran extern. Dentro de la interrupción se usa una variable local volt para no escribir dos veces la misma variable global.

#define TIM_INT TIM3

#include "main.h"
#include "PID.h"
#include "adc_x.h"
#include "PWMB.h"

extern float voltaje;
extern float setpoint;

void HAL_TIM_PeriodElapsedCallback(TIM_HandleTypeDef *htim)
{
  if (htim->Instance == TIM_INT)
  {
    ADC_Read_DMA(&hadc1);
    float volt=adc_codigo[0]*3.3/4095.0;
    voltaje=volt*8.1439;
    setpoint=adc_codigo[1]*21/4095.0;
    PID_Control(voltaje);
    PWM_valor(&PWM1, ut);
  }
}

Fase 4

La librería PID

4.1

Constantes en PID.h

▶ 16:40

Se definen tiempo de muestreo, constantes kp, ki, kd, set point inicial y los límites de salida (0 a 1000, el rango del PWM).

Una idea para el orden de kp: salida máxima / error máximo = 1000/22 ≈ 45. Aquí se empezó con 100 para probar.

#define PID_muestreo 10e-3   // tiempo de muestreo
#define PID_kp 100
#define PID_ki 100
#define PID_kd 100
#define PID_SET 4.0
#define PID_MAX 1000
#define PID_MIN 0
4.2

Algoritmo PID_Control

▶ 18:20

Calcula el error con el set point, la parte proporcional, acumula la integral multiplicando por el tiempo de muestreo y calcula la derivativa con el error anterior.

La salida ut se satura entre PID_MIN y PID_MAX. ut es global, así que se puede usar directamente para el PWM.

float kp=PID_kp, ki=PID_ki, kd=PID_kd;
float setpoint=PID_SET;
float error, up, ui=0.0, ud, ut, error_=0.0;

float PID_Control(float pid_in)
{
  error=setpoint-pid_in;
  up=kp*error;                          // proporcional
  ui+=ki*t_mues*error;                  // integral
  ud=kd*(error-error_)/(float)t_mues;   // derivativa
  ut=up+ui+ud;
  if (ut>PID_MAX) ut=(float)PID_MAX;
  if (ut<PID_MIN) ut=(float)PID_MIN;
  error_=error;
  return ut;
}
Fase 5

Prueba y gráfica

5.1

Enviar datos para graficar

▶ 21:44

Para el osciloscopio serial se mandan set point y voltaje separados por coma, lo más rápido posible. Se pueden enviar hasta 9 variables (3 ventanas de 3 señales).

No mezcles este envío con el texto VOL=/SET=: si se envían los dos formatos el gráfico se ve como ruido.

sprintf(texto,"%.1f,%.1f\r",setpoint,voltaje);
uartx_write_text(&huart1, texto);
HAL_Delay(1);
5.2

Respuesta del lazo cerrado

▶ 24:00

Solo con proporcional (kp=100) la salida intenta seguir el set point pero no llega. Al agregar integral (ki=100) el voltaje sí alcanza el set point.

Las constantes quedan para sintonizar según el montaje; un circuito en PCB tendrá mucho menos ruido que en protoboard.

A estas velocidades Hercules se bloquea; usa el programa de osciloscopio. Se puede subir el puerto hasta 921600 baudios si se configura igual en el micro.
