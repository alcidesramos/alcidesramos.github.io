Restaurar ventanas y split en CubeIDE

Dos problemas comunes en STM32CubeIDE: el editor queda partido en dos sin saber por qué, o se cierran ventanas como Project Explorer y Console. Se muestra cómo quitar o poner el split vertical y cómo restaurar todo con Reset Perspective.

Fase 1

Split del editor

1.1

Para qué sirve

▶ 0:00

El split muestra el mismo archivo dos veces: en un lado trabajas y en el otro conservas una copia de referencia sin tocarla.

1.2

Poner o quitar el split

▶ 0:33

Ve a Window → Editor → Toggle Split Editor (Vertical). La misma opción lo activa o lo desactiva.

Fase 2

Ventanas por defecto

2.1

Restaurar la perspectiva

▶ 0:50

Si cerraste ventanas y no sabes cómo recuperarlas: Window → Perspective → Reset Perspective… y confirma con Reset Perspective.

Las ventanas vuelven como cuando se instala el programa.
