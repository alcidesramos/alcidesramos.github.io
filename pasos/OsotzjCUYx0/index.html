Sensor de temperatura sin contacto MLX90614 con STM32

El MLX90614 mide temperatura sin contacto: la del objeto al que apunta y la del ambiente. La librería se adaptó de una de Arduino en C++: se tomaron las funciones, se quitó lo que no servía, se cambió la parte de I2C y se agregó un Init que dice si el sensor está conectado. En el video solo se usa: se crea el proyecto, se configuran USART1 e I2C1, se agregan las librerías y se envían las lecturas a Hércules. No siempre se construye todo desde cero: si existe, se adapta y se mejora.

Fase 1

Crear y configurar el proyecto

1.1

Proyecto nuevo

▶ 1:11

File → New → STM32 Project, elige el STM32F401CCU6 y llámalo, por ejemplo, MLX90614_CANAL. El reloj puede quedar en 16 MHz interno (o súbelo a 84 MHz si quieres).

1.2

USART1 a 115200

▶ 2:21

En Connectivity → USART1, modo Asynchronous a 115200 baudios, para mandar las lecturas al computador.

1.3

I2C1 en modo estándar

▶ 2:35

Activa I2C1 en modo I2C; el Standard Mode (100 kHz) que trae por defecto sirve. Genera el código y compila.

Fase 2

Agregar las librerías

2.1

Carpeta Librerias

▶ 2:53

Crea la carpeta Librerias dentro de Core y pega MLX90614.c/.h y la librería de UART. Agrégala a las rutas de include (clic derecho → Add/remove include path, en Debug y Release).

2.2

Qué trae la librería

▶ 3:26

Las funciones principales:

  • MLX90614_Init(): devuelve 1 si el sensor responde.
  • read16 / write16 y crc8: lectura y escritura de 16 bits por I2C con el código de detección de errores del sensor.
  • readEmissivity / writeEmissivity: leer o cambiar la emisividad.
  • readObjectTempC / readAmbientTempC (y sus versiones en Fahrenheit).
2.3

Includes, flotante y variables

▶ 3:58

Incluye las dos librerías y las de C (stdio, string). En las propiedades del proyecto habilita printf con float (MCU Settings). Declara las variables:

char texto[100];
float temperatura, ambiente;
Fase 3

Leer el sensor

3.1

Verificar el sensor

▶ 4:50

Antes del while, comprueba si el sensor está conectado. Si no te interesa verificarlo, basta con llamar MLX90614_Init().

if (MLX90614_Init() == 1) uartx_write_text(&huart1, "sensor ok\r\n");
else uartx_write_text(&huart1, "NO SENSOR\r\n");
3.2

La emisividad

▶ 5:36

La emisividad depende del material, va de 0 a 1 (madera y similares: 0.92 a 0.95). Puedes escribir un valor y luego leerlo para comprobarlo.

//MLX90614_writeEmissivity(0.95);
sprintf(texto, "Emi=%.2f\r\n", MLX90614_readEmissivity());
uartx_write_text(&huart1, texto);
3.3

Temperatura del objeto y del ambiente

▶ 6:45

En el while lee las dos temperaturas en grados centígrados y mándalas cada 600 ms (o el tiempo que necesites).

while (1)
{
  temperatura = MLX90614_readObjectTempC();
  ambiente = MLX90614_readAmbientTempC();
  sprintf(texto, "TEM=%.2f   T_AMB=%.2f\r\n\r\n", temperatura, ambiente);
  uartx_write_text(&huart1, texto);
  HAL_Delay(600);
}
3.4

Probar

▶ 7:19

Programa el micro y abre Hércules a 115200. Sale sensor ok, la emisividad y las temperaturas (en el video unos 33 °C del objeto y 32 °C del ambiente). Al poner la mano frente al sensor sube la temperatura del objeto.
