Decodificador IR por hash en Proteus

En un video anterior el decodificador por hash se mostró con hardware real. Aquí se simula en Proteus: un PIC16F1824 recibe el receptor IR en la interrupción externa por flanco de bajada y mide los tiempos con el Timer0 (prescalador para unos 16 ms). Con los tiempos se normaliza la trama y una función hash la convierte en un número de 32 bits, sin importar el protocolo del control. El código se envía por la UART como texto hexadecimal. Después se copian los códigos de las teclas elegidas al programa y cada uno cambia el estado de un LED y escribe COMANDO1, COMANDO2 o COMANDO3. En la simulación hay detalles que no son iguales a la realidad, como LEDs que quedan prendidos.

2.1

Timer e interrupción

▶ 3:25

El Timer0 mide tiempos de hasta unos 16 ms y la interrupción externa se activa por flanco de bajada.

// configura el timer cero para medir tiempos de 16 ms
OPTION_REG = 0;   // prescalador asignado al timer 0
// selecciona el prescalador para 16 ms
PS2_bit = 1;
PS1_bit = 1;
PS0_bit = 1;

UART1_Write_Text("INICIANDO\r\n");
LATC = 0;

// habilitamos interrupción
INTCON = 0b01000000;
INTEDG_bit = 0;   // por flanco de bajada
INTF_bit = 0;     // limpia la bandera de interrupción
INTE_bit = 1;     // habilita la interrupción por flanco

GIE_bit = 1;      // autoriza todas las interrupciones
2.2

Código hash

▶ 5:44

Cuando llega una trama completa se normaliza, se calcula el hash y se envía en hexadecimal.

while (1)
{
  if (flag_codigo == 1)
  {
    normaliza();
    codigo_ir = Hash_algoritmo();
    LongIntToHex(codigo_ir, texto);
    UART1_Write_Text("CODIGO_IR=");
    UART1_Write_Text(texto);
    UART1_Write('\r');
    UART1_Write('\n');
    // ... aquí se comparan los códigos
  }
}

{
  led2 = ~led2;
  UART1_Write_Text("COMANDO2");
