Clase 123: TFT ILI9488 con fonts propios

Primer video de la serie de la pantalla ILI9488 de 3.5 pulgadas. Se explican sus pines (alimentación de 3.3 o 5 V, CS, RESET, DC, MOSI, SCK, LED y MISO opcional) y se configura el STM32F411 a máxima velocidad con SPI1 en modo solo transmisión a unos 12 Mbit/s, porque la pantalla admite hasta 15 MHz. La librería de base se tomó de internet y se amplió con funciones propias de figuras, dashboard y fonts personalizables. Se inicia la pantalla, se elige la orientación, se pinta el fondo, se escriben textos con varios fonts y se crea uno nuevo con GLCD Font Creator.

Fase 1

La pantalla

1.1

Pines de la ILI9488

▶ 0:34

VCC (3.3 o 5 V) y GND; CS, RESET y DC/RS van al micro; SDI (MOSI) y SCK al bus SPI.

LED es la luz de fondo: si va al micro se puede apagar para ahorrar energía; si no, se conecta a 3.3 V.

SDO (MISO) es opcional: solo se necesita para leer de la pantalla.

Fase 2

Configuración

2.1

SPI1 solo transmisión

▶ 2:44

En SPI1 se elige Transmit Only Master para no gastar el pin MISO. Quedan SCK y MOSI.

2.2

Pines de control y velocidad

▶ 3:49

Cuatro salidas con estos nombres: TFT_CS, TFT_RST, TFT_DC y TFT_LED (opcional).

Se pone cristal externo y el PLL a la máxima velocidad del micro para que dibujar sea rápido.

En el SPI (8 bits) el prescaler se sube a 8 para quedar en unos 12 Mbit/s. La pantalla admite hasta 15 MHz según el datasheet.

Con 20 MHz también funcionó, pero lo recomendable es no pasar de 15 MHz.

Fase 3

Librerías

3.1

Agregar e incluir

▶ 6:18

Se crea la carpeta Librerias con ili9488, fonts e imagenes, se agrega al include path y se incluyen en main.c. También se habilita float con printf.

#include "ili9488.h"
#include "fonts.h"
#include "imagenes.h"
Fase 4

Primer dibujo

4.1

Iniciar la pantalla

▶ 9:33

Se inicia la pantalla, se elige la orientación (horizontal, horizontal invertida, vertical o vertical invertida) y se llena de un color.

La luz de fondo debe estar encendida: con el pin TFT_LED en alto, o conectando LED a 3.3 V.

ILI9488_Init();
setRotation(horizontal);
HAL_GPIO_WritePin(TFT_LED_GPIO_Port, TFT_LED_Pin, 1);  // luz de fondo
fillScreen(COLOR_BLUE);
4.2

Escribir texto

▶ 11:55

draw_string escribe sin fondo en la posición x, y con un color y un font. Hay varios fonts de distintos tamaños (10x2, 19x3, 25x3...).

draw_string(0, 0, "SUSCRIBANSE", COLOR_WHITE, font2);
draw_string(20, 100, "AL CANAL", COLOR_RED, font4);
Fase 5

Crear un font

5.1

Generar el font

▶ 14:56

En GLCD Font Creator: File > New Font > Import an existing system font, se elige la letra, el estilo y el tamaño (por ejemplo 28).

Cada carácter se puede editar: mover, quitar columnas o rotar. Luego Export for GLCD, se elige mikroC y se copia el código.

5.2

Adaptarlo en fonts.c

▶ 17:09

Se pega el arreglo en fonts.c con el nombre font5 y se cambia short por char.

En la cabecera va el alto del font (42 en el ejemplo) y el número de bytes por columna: el ancho 55 dividido entre 8 y redondeado hacia arriba = 7.

fonts.h ya declara hasta 20 fonts; si necesitas más, agrégalos también allí.

const unsigned char font5[] = {42, 7,
  0x00, 0x00, 0x00, ...   // datos exportados
};
5.3

Texto con fondo

▶ 18:49

draw_string_fondo escribe con color de letra y color de fondo. Con el nuevo font5 se tienen tres tipos de letra distintos en pantalla.

draw_string_fondo(0, 200, "HOLA", COLOR_WHITE, COLOR_BLACK, font5);
