Velocista con control proporcional

Con la posición de la línea ya calculada por pesos (de -10 a 10) se arma el control más sencillo: proporcional. Una función map, igual a la de Arduino, convierte ese rango en una velocidad de giro entre -velo_giro_max y +velo_giro_max. La función aplica_pwm suma esa velocidad a un motor y la resta al otro sobre una velocidad básica, limita ambos valores entre 0 y 255 y deja los motores siempre hacia adelante. Con velocidad básica 125 y giro máximo 100 el robot sigue la pista, y luego se prueba a 500 mm/s. Para terminar, se corre contra el robot Zumo de ejemplo de Proteus, que trae un PID, y el proporcional gana la carrera.

1.2

Función map

▶ 1:11

Para pasar de un rango a otro se usa una función map como la de Arduino.

float map(float x, float in_min, float in_max, float out_min, float out_max)
{
  return (x - in_min) * (out_max - out_min) / (in_max - in_min) + out_min;
}

Fase 2

El control

2.1

Aplicar el PWM

▶ 2:53

Un motor gana velocidad y el otro la pierde. Los valores se limitan entre 0 y 255 y los motores van siempre hacia adelante.

void aplica_pwm(float pwm_vel)
{
  velo_der = velo_basica - pwm_vel;   // uno gana velocidad
  velo_izq = velo_basica + pwm_vel;   // otro pierde velocidad

  if (velo_der < 0) velo_der = 0;
  if (velo_der > 255) velo_der = 255;
  if (velo_izq < 0) velo_izq = 0;
  if (velo_izq > 255) velo_izq = 255;

  // siempre los motores adelante
  m1_g = 0;
  m2_g = 0;
  // aplica el valor absoluto de las velocidades
  PWM1_Set_Duty(abs(velo_der));
  PWM2_Set_Duty(abs(velo_izq));
}

Versión final

▶ 4:35

En la versión que queda, la función recibe la posición y llama a la función de PWM; aquí aparece ya la versión rápida, aplica_pwm_fast, que se explica en la siguiente parte.

void proporcional(float pro_in)
{
  velo_giro = map(pro_in, -10.0, 10.0, -(float)velo_giro_max, (float)velo_giro_max);
  aplica_pwm_fast(velo_giro);
}
