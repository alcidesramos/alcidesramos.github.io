LIDAR TF Mini con dsPIC33F

En el video anterior se explicó el LIDAR TF Mini y se hizo su librería para PIC. Aquí se pasa a un dsPIC33FJ128MC802 en una tarjeta de desarrollo con LCD. El micro se configura a 80 MHz con el oscilador interno y el PLL. Con los pines remapeables se asignan la UART1 al LIDAR y la UART2 al computador, ambas a 115200. Se agregan las rutinas de trampas de error del dsPIC y la interrupción de recepción, que va guardando los bytes de la trama con una máquina de estados y avisa con una bandera cuando llegan los 8 datos. En el ciclo principal se procesa la trama, en formato hexadecimal o de texto según un #define, y la distancia se muestra en el LCD y se envía por serial. Lo único que cambia respecto a la versión para PIC son los registros de la UART, las interrupciones y los pines del LCD de la tarjeta.

2.2

Recibir la trama

▶ 7:52

La interrupción guarda los bytes con una máquina de estados. Con 8 datos vuelve al estado inicial, deshabilita la interrupción y activa la bandera.

case tf_datos:
  trama_rx_lidar[trama_rx_lidar_cont] = dat_rx;
  trama_rx_lidar_cont++;
  if (trama_rx_lidar_cont > 7)   // si captura los datos completos
  {
    tf_estado = tf_cabe;
    trama_rx_lidar_cont = 0;
    U1RXIE_bit = 0;   // deshabilita la interrupción
    flag_rx_lidar = 1; // activa la bandera de datos listos
  }
  break;

3.2

UART por PPS

▶ 11:27

UART1 al LIDAR y UART2 al computador. La UART2 solo usa TX.

Unlock_IOLOCK();
PPS_Mapping(8, _OUTPUT, _U1TX);   // lidar tx
PPS_Mapping(9, _INPUT, _U1RX);    // lidar rx
PPS_Mapping(0, _OUTPUT, _U2TX);   // tx pc
Lock_IOLOCK();

4.2

Procesar y mostrar

▶ 17:03

Cuando la bandera está activa se procesa la trama, se muestra la distancia y se envía por la UART2. Luego se limpia el desbordamiento y se vuelve a habilitar la recepción.

while (1)
{
  if (flag_rx_lidar == 1)
  {
#ifdef tf_hex
    procesa_lidar_hex();
    sprintf(texto, "DIST=%u", (unsigned int)distancia);
#else
    procesa_lidar_str();
    sprintf(texto, "DIST=%.1f", distancia_float);
#endif
    Lcd_Out(2, 5, "        ");
    Lcd_Out(2, 5, texto);
    UART2_Write_Text(texto);
    UART2_Write_Text("\r\n");

    // activa int serial; evita errores de desbordamiento
    U1STA.B1 = 0;
    U1RXIF_bit = 0;
    U1RXIE_bit = 1;
    flag_rx_lidar = 0;
  }
  Delay_ms(200);
}
