Guardar datos en la EEPROM del PIC

Video a pedido de un seguidor del canal. La EEPROM de datos guarda valores que deben sobrevivir a un apagón, como una clave, un tiempo o un contador de piezas. Con un PIC18F2550 se usa la librería EEPROM de MikroC para guardar y leer un byte, con un pulsador que restaura el valor de fábrica al encender. Como EEPROM_Write y EEPROM_Read trabajan de a un byte, se hacen funciones con un puntero tipo char que recorren los bytes de la variable para guardar enteros (2 bytes), long y float (4 bytes) y textos terminados en cero. Con el visor de memoria EEPROM de Proteus se comprueba dónde queda cada byte.

Fase 1

Un byte

1.1

El proyecto

▶ 1:07

PIC18F2550 a 4 MHz con cristal XT. Un pulsador en RB7 usa la pull-up interna del puerto B, y el serial se usa solo para ver qué pasa.

ADCON1 = 0b1111;   // todo digital
TRISB7_bit = 1;    // entrada pulsador
TRISC6_bit = 0;    // salida TX
NOT_RBPU_bit = 0;  // habilita las pull-up del puerto B
UART1_Init(9600);
UART1_Write_Text("INICIANDO\r\n");
1.2

Ver la EEPROM en Proteus

▶ 4:37

Con la simulación en pausa, en Debug > PIC18 CPU EEPROM Memory se ve el contenido. Una EEPROM borrada tiene 255 (FF) en todas las posiciones.

1.3

Escribir y leer

▶ 5:43

Se activa la librería EEPROM. EEPROM_Write(dirección, dato) guarda un byte y EEPROM_Read(dirección) lo lee.

unsigned char contador;

contador = 15;
EEPROM_Write(0, contador);
contador = EEPROM_Read(0);
1.4

Restaurar de fábrica con un pulsador

▶ 7:55

Si se escribe el valor inicial cada vez que arranca, se pierde lo guardado. Mejor: solo si el pulsador está presionado al encender se escribe el valor de fábrica; si no, se lee el último valor guardado. Luego el contador sigue desde ahí.

contador = 15;
if (RB7_bit == 0) EEPROM_Write(0, contador);   // valor de fábrica
contador = EEPROM_Read(0);

while (1) {
  contador++;
  EEPROM_Write(0, contador);
  sprintf(texto, "valor=%u\r\n", (unsigned int)contador);
  UART1_Write_Text(texto);
  Delay_ms(1000);
}

En sprintf haga el cast a unsigned int si la variable es char; si no, el formato muestra valores errados.

Fase 2

Enteros de 2 bytes

2.1

Escribir un entero

▶ 13:37

Un unsigned int ocupa 2 bytes. Un puntero tipo char apunta al byte bajo de la variable; se escribe ese byte, se incrementa el puntero y se escribe el otro. Así el entero ocupa dos posiciones seguidas de la EEPROM.

void EEPROM_Write_Int(unsigned char dir, unsigned int dato_e)
{
  char *punte;       // puntero tipo char
  punte = &dato_e;
  dir += 1;
  EEPROM_Write(dir, *punte);
  punte++;
  dir--;
  EEPROM_Write(dir, *punte);
}
2.2

Leer un entero

▶ 15:48

La lectura hace el camino inverso: el puntero apunta a la variable de salida y se llenan sus dos bytes desde las mismas posiciones.

unsigned int EEPROM_Read_Int(unsigned char dir)
{
  char *punte;
  unsigned int leido;
  punte = &leido;
  dir += 1;
  *punte = EEPROM_Read(dir);
  punte++;
  dir--;
  *punte = EEPROM_Read(dir);
  return (leido);
}
2.3

Comprobarlo con el depurador

▶ 16:54

Se escribe 500 (0x01F4) en la posición 0 y con el depurador y la ventana Watch se sigue el puntero paso a paso. En la EEPROM quedan el 01 y el F4 en dos posiciones, y al leerlas se recupera el 500. El contador ya pasa de 255 sin perderse.

Fase 3

Long, float y textos

3.1

Long y float de 4 bytes

▶ 24:45

Para unsigned long y float, que ocupan 4 bytes, la función es la misma pero se recorren cuatro posiciones: se suma 3 a la dirección y se va restando mientras el puntero avanza. Así se guardan valores como 100000 o 10.5 con todos sus decimales.

float EEPROM_Read_Float(unsigned char dir)
{
  char *punte;
  float leido;
  punte = &leido;
  dir += 3;
  *punte = EEPROM_Read(dir);
  punte++;  dir--;
  *punte = EEPROM_Read(dir);
  punte++;  dir--;
  *punte = EEPROM_Read(dir);
  punte++;  dir--;
  *punte = EEPROM_Read(dir);
  return (leido);
}
3.2

Textos

▶ 31:43

Un texto se escribe carácter por carácter hasta encontrar el nulo del final, y se escribe también ese 0 para saber dónde termina. Al leer se copian caracteres hasta encontrar el 0.

void EEPROM_Write_Texto(unsigned char dir, char *cadena)
{
  while (*cadena) {
    EEPROM_Write(dir, *cadena);
    cadena++;
    dir++;
  }
  EEPROM_Write(dir, 0);   // escribe el carácter nulo
}

void EEPROM_Read_Texto(unsigned char dir, char *cadena)
{
  char dato;
  do {
    dato = EEPROM_Read(dir);
    *cadena = dato;
    cadena++;
    dir++;
  } while (dato != 0);
}
