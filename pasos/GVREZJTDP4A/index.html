Librerías GPS para STM32, versión 2026

Las librerías para leer un GPS se actualizaron: ahora la trama llega por UART con DMA y detección de línea libre (IDLE), sin bloquear el programa, y pueden convivir con otro puerto serial que también reciba datos. Se configura el proyecto con CubeMX, se trabaja en VS Code con CMake, se agregan las librerías gps, UARTRX y UART_INT_DMA_IDLE, y se muestran latitud, longitud, fecha, hora, velocidad, satélites, dilución horizontal y altura. También se comprueba si el equipo está dentro de un radio de operación. Para probar sin GPS real se usa Proteus con COMPIM y un simulador de GPS propio que envía las tramas NMEA desde un mapa.

Fase 1

Configurar el proyecto

1.1

Puertos seriales en CubeMX

▶ 1:40

Crea el proyecto GPS_CANAL para el STM32F401. Usa:

  • USART2 asíncrono a 9600 baudios para el GPS, con DMA en RX y su interrupción.
  • USART1 para enviar los datos al computador.
  • Un pin de salida para un LED que parpadea con cada trama.
  • Genera el proyecto con toolchain CMake para abrirlo en VS Code.
1.2

Abrir en VS Code y agregar las librerías

▶ 9:10

Abre la carpeta en VS Code, compila una vez y crea la carpeta LIBRERIAS con gps.c/.h, UARTRX.c/.h, UART_INT_DMA_IDLE.c y uart.c/.h. Agrégalas a CMakeLists.txt (en el video con un script de Python que lo hace solo) e inclúyelas en main.c.

#include "stdio.h"
#include "string.h"
#include "stdlib.h"
#include "math.h"
#include "stdint.h"

#include "uart.h"
#include "UARTRX.h"
#include "gps.h"
Fase 2

Configurar las librerías

2.1

Definir los puertos de recepción

▶ 13:40

En UARTRX.c se declara cada puerto que recibe por interrupción, con su UART y el tamaño del buffer. El del GPS usa el USART2.

UARTRXS UARTRX1    = {&huart1, USART1, 100};
UARTRXS GPS_UARTRX = {&huart2, USART2, 100};
2.2

Parámetros en gps.h

▶ 15:10

En gps.h se ajustan la coordenada de referencia, el radio de operación en metros y la zona horaria (Colombia: -5).

#define precision 200   // radio de operación en metros
#define hor_utc   -5    // hora de Colombia
2.3

Las interrupciones

▶ 16:40

En UART_INT_DMA_IDLE.c los callbacks de HAL reparten el evento entre el GPS y los demás puertos. Así varias librerías pueden usar la recepción por DMA sin chocar.

void HAL_UARTEx_RxEventCallback(UART_HandleTypeDef *huart, uint16_t Size)
{
  GPS_Interrupt(huart, Size);
  uartRX_INTERRUPT(huart, Size);
}

void HAL_UART_ErrorCallback(UART_HandleTypeDef *huart)
{
  GPS_Error(huart);
  uartRX_Errores(huart);
}
Fase 3

Leer los datos

3.1

Cuando llega una trama

▶ 18:10

En el while se revisa la bandera de recepción del GPS. Cuando hay trama se procesa, se reinicia la recepción por DMA y se envían los datos que ya quedaron en variables.

if (GPS_UARTRX.flag_rx == 1)
{
  HAL_GPIO_TogglePin(LED_GPIO_Port, LED_Pin);
  // ... procesar la trama ...
  uartRX_DMA_Re_init(&GPS_UARTRX);

  sprintf(texto, "LAT=%.5f   LON=%.5f\r\n", latitud, longitud);
  uartx_write_text(&huart1, texto);
  sprintf(texto, "hor=%u  min=%u  seg=%u\r\n", hor_gps, min_gps, seg_gps);
  uartx_write_text(&huart1, texto);
  sprintf(texto, "vel=%.2f\r\n", gps_vel_kph);
  uartx_write_text(&huart1, texto);
}
3.2

Qué se extrae

▶ 21:10

La librería separa los campos de las tramas NMEA y llena las variables:

  • Latitud y longitud en grados (con el signo según N/S y E/W).
  • Fecha y hora, ya corregida con hor_utc.
  • Velocidad en km/h.
  • Modo, número de satélites, dilución horizontal y altura.
3.3

Radio de operación

▶ 24:10

Con estaDentroDelRadio se compara la posición con un punto de referencia y el radio definido en precision. Sirve, por ejemplo, para saber si un vehículo salió de su zona.

if (estaDentroDelRadio(4.5981, -74.0758, latitud, longitud))  // ejemplo: Bogotá
  sprintf(texto, "Dentro del radio de operación\r\n");
else
  sprintf(texto, "Fuera del radio de operación\r\n");
uartx_write_text(&huart1, texto);
Fase 4

Probar sin GPS real

4.1

El circuito en Proteus

▶ 4:40

Black Pill, un COMPIM conectado al RX2 (por donde entra el GPS), un Virtual Terminal en la salida TX1 y otro para ver las tramas del GPS, y un LED con su resistencia de 220 Ω.

4.2

El simulador de GPS

▶ 25:40

El simulador abre un puerto COM (enlazado con el del COMPIM) a 9600 y envía tramas NMEA ($GPRMC, $GPGGA, $GPVTG…) según el punto marcado en el mapa. Puedes buscar un lugar o fijar coordenadas, y cambiar el rumbo y la velocidad.

4.3

Resultado

▶ 28:40

Al mover el punto o cambiar la velocidad, el terminal de salida muestra la nueva posición, la hora, la velocidad, los satélites y si está dentro o fuera del radio de operación. La vista puede ser mapa o satélite.
