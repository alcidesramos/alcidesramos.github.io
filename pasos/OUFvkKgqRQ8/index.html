Entradas y el condicional if

Octava lección del curso y la primera con entradas. Se explica por qué un pulsador necesita una resistencia pull-up o pull-down, cómo configurar el pin como entrada con TRIS y cómo comparar con == (no con =). Con dos pulsadores en RB4 y RB5 y los procedimientos de la lección anterior se arman ejemplos con if, if-else, dos if independientes y una cadena de else if para las cuatro combinaciones. Al final se habla del antirrebote y de las pull-up internas del puerto B con OPTION_REG.

Fase 1

Entradas digitales

1.1

Pull-up y pull-down

▶ 0:00

Un pin de entrada necesita tener siempre un 1 o un 0 definido, pero un pulsador solo da uno de los dos. Con una resistencia al positivo (pull-up) el pin lee 1 en reposo y 0 al presionar; con una resistencia a tierra (pull-down) lee 0 en reposo y 1 al presionar.

Para la pull-up se recomienda unos 10 kΩ. Para la pull-down, 330 Ω y como mucho 1 kΩ: con valores altos, en ambientes industriales la tierra puede quedar flotando y meter ruido.

1.2

El pin como entrada

▶ 1:46

Para que el pin sea entrada su bit de TRIS debe ir en 1 (hasta ahora se usaban 0 porque eran salidas).

Fase 2

El condicional if

2.1

Sintaxis y operadores de comparación

▶ 2:18

if (condición) { ... } ejecuta el bloque solo si la condición se cumple. Las comparaciones son ==, !=, >, <, >= y <=; la tabla está en la ayuda de MikroC (Relational Operators).

Para comparar se usa doble igual. Un solo = asigna un valor al pin en vez de preguntar por él.

2.2

Circuito con dos pulsadores

▶ 3:57

Se reutiliza el circuito de la lección de procedimientos, con dos pulsadores con pull-up en RB4 y RB5: al presionar se lee 0.

2.3

Proyecto y procedimientos reutilizados

▶ 5:09

Se crea el proyecto condicional en la carpeta clase 8 (PIC16F877A a 4 MHz) y se copian los procedimientos de la lección 7 (hola, baja, efecto1, melodia1, melodia2). Hay que activar otra vez la librería Sound.

2.4

Definir pulsadores y configurar el puerto B

▶ 6:51

Se les pone nombre a los pulsadores (RB4_bit es lo mismo que PORTB.B4). Una forma cómoda es poner todo el puerto como salida y luego marcar solo las entradas.

#define sw1 RB4_bit
#define sw2 PORTB.B5

TRISB = 0;          // todo salida
TRISD = 0;          // display
TRISB4_bit = 1;     // entrada sw1
TRISB5_bit = 1;     // entrada sw2
Sound_Init(&PORTC, 6);
2.5

Primer if

▶ 10:47

Mientras sw1 esté presionado (en 0) se llama a hola(); al soltarlo el display se queda quieto. Dentro de las llaves pueden ir varias órdenes, por ejemplo hola() y melodia1().

while (1) {
  if (sw1 == 0) {
    hola();
    melodia1();
  }
}
Fase 3

else, varias condiciones y else if

3.1

if con else

▶ 13:07

Si baja() está antes del if, se ejecuta siempre y el if agrega algo más. Con else se hace una cosa o la otra. El pulsador no responde de inmediato: hay que esperar a que termine el procedimiento en curso (eso se resuelve más adelante con interrupciones).

if (sw1 == 0) {
  hola();
  melodia1();
} else {
  baja();
}
3.2

Dos if independientes

▶ 15:21

Con un if para sw1 y otro para sw2, cada uno hace lo suyo, y si se presionan los dos se hacen las dos cosas, una después de la otra.

3.3

Unir condiciones con && y ||

▶ 16:37

Con dos pulsadores hay cuatro combinaciones. Cada condición va entre paréntesis y todas dentro de un paréntesis general, unidas con && (y) o || (o). En las comparaciones se usan dobles, no los operadores de bits de la lección 6.

3.4

Cadena de else if

▶ 19:02

Como las combinaciones son excluyentes, con else if el micro deja de revisar las demás en cuanto una se cumple, lo que ahorra procesamiento. La última puede ser un else solo, porque es la única que queda.

if ((sw1 == 1) && (sw2 == 1)) {
  hola();
  melodia1();
}
else if ((sw1 == 0) && (sw2 == 1)) {
  efecto1();
}
else if ((sw1 == 1) && (sw2 == 0)) {
  melodia2();
}
else {            // los dos presionados
  baja();
  melodia1();
}
Fase 4

Detalles finales

4.1

Llaves opcionales con una sola orden

▶ 22:26

Si dentro del if hay una sola orden, se pueden quitar las llaves y escribirla en la misma línea de la condición.

4.2

Antirrebote

▶ 22:59

Los contactos del pulsador rebotan y el micro puede contar varias pulsaciones. Si solo se detecta la pulsación, se pone después un retardo de 100 a 300 ms. Aquí no hizo falta porque los procedimientos ya tienen retardos. MikroC trae la librería Button, pero el profesor prefiere hacerlo con su propio if.

Sin antirrebote, una sola pulsación puede contarse varias veces.

4.3

Pull-up internas del puerto B

▶ 24:43

En estos PIC el puerto B tiene resistencias pull-up internas (no pull-down) para los pines que son entrada. Se habilitan poniendo OPTION_REG = 0 antes del while, y así se pueden quitar las resistencias externas y conectar el pulsador directo a tierra.

OPTION_REG = 0;   // habilita las pull-up internas del puerto B
