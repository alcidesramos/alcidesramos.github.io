Juegos de luces con 24 LEDs

Los 24 LEDs se manejan como un solo número unsigned long: la función saca reparte sus bytes con Lo, Hi y Higher en PORTB, PORTC y PORTD (hace falta built_in.h). Con eso se escriben los efectos: flash, alternado, policía, corrimientos a la derecha y a la izquierda desplazando 0x000001 o 0x800000 en 24 pasos, acerca y aleja, auto fantástico y los de encendido y apagado progresivo, como derecha_on con salida = (salida << 1) + 1. El retardo se lee del ADC y se escala a 0..300 ms para usar VDelay_ms. Un switch elige el efecto (hasta 8) y el Timer1, configurado con Timer Calculator a 200 ms, revisa el pulsador en la interrupción y avanza al siguiente efecto. El programa usa cerca del 10% de RAM y el 11% de ROM.

Lo, Hi y Higher

▶ 2:19

La ayuda de MikroC muestra Lo, Hi y Higher, que devuelven el byte 0, 1 y 2 de un número. Requieren built_in.h.

1.4

Función saca

▶ 3:19

Reparte los 24 bits en los tres puertos.

#include "built_in.h"

unsigned int retardo;
unsigned int codigo;
#define sv RA1_bit
#define LEDS_L PORTB
#define LEDS_M PORTC
#define LEDS_H PORTD
unsigned long salida;

void saca(unsigned long dato)
{
  LEDS_L = Lo(dato);
  LEDS_M = Hi(dato);
  LEDS_H = Higher(dato);
}

2.3

Encendido progresivo

▶ 11:17

derecha_on va llenando los LEDs uno a uno; también hay derecha_off, izquierda_on e izquierda_off.

void derecha_on(unsigned int velo)
{
  char cuenta;

  salida = 0x000001;
  saca(salida);
  for (cuenta = 0; cuenta < 24; cuenta++)
  {
    VDelay_ms(velo);
    salida = (salida << 1) + 1;
    saca(salida);
  }
}

Fase 3

Cambiar de efecto

3.1

Switch

▶ 13:16

Un switch con la variable efecto elige qué juego corre; un caso puede combinar varios efectos.

switch (efecto)
{
  // primer efecto deseado
  case 0:
    // flash(retardo);
    derecha_on(100);
    izquierda_off(100);
    izquierda_on(100);
    derecha_off(100);
    break;

  // 2 efecto deseado
  case 1:
    alternado(retardo);
    break;
  // ... hasta 8 efectos
}
3.2

Timer1 a 200 ms

▶ 15:16

Con Timer Calculator se genera la configuración del Timer1. En la interrupción se revisa el pulsador y se incrementa efecto, deshabilitando el timer mientras se procesa.

void InitTimer1(){
  T1CON = 0x31;
  TMR1IF_bit = 0;
  TMR1H = 0x3C;
  TMR1L = 0xB0;
  TMR1IE_bit = 1;
  INTCON = 0xC0;
}

void Interrupt(){
  if (TMR1IF_bit){
    TMR1IF_bit = 0;
    TMR1H = 0x3C;
    TMR1L = 0xB0;
    // aquí: si se presiona el pulsador, efecto++
  }
}
