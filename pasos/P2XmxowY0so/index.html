Clase 124: TFT ILI9488 figuras e imágenes

Seguimos con la librería de la pantalla TFT ILI9488 por SPI. Primero recorremos las funciones de figuras que trae la librería (línea, rectángulo, triángulo, círculo, rectángulo redondeado y elipse, rellenas o solo borde), separándolas con un retardo y un fillScreen para ver cada una. Luego agregamos la función draw_bitmap, que pinta una imagen guardada como arreglo en flash con posición y escala. Una imagen de pantalla completa (480x320) no cabe en la flash del F411, así que pasamos a la Blackpill U585 (2 MB de flash) para mostrar imágenes completas en horizontal y en vertical. Al final se explica cómo convertir cualquier foto a arreglo C con el programa gratuito LCD Image Converter.

Fase 1

Figuras geométricas

1.1

Funciones disponibles en la librería

▶ 0:40

Al final del archivo ili9488.h está la ayuda con todas las funciones de dibujo: línea, rectángulo, rectángulo relleno, triángulo, triángulo relleno, círculo, rectángulo con esquinas redondeadas, elipse y elipse rellena.

Todas reciben coordenadas en píxeles, el color (COLOR_RED, COLOR_BLUE, COLOR_BLUEVIOLET...) y, las que solo dibujan borde, el grosor de la línea.

1.2

Probar las figuras una por una

▶ 1:50

En el main, después de ILI9488_Init() y setRotation(horizontal), se llama cada figura. Entre una y otra se pone un HAL_Delay y un fillScreen(COLOR_WHITE) para borrar la pantalla y ver cada figura sola.

Las líneas que no se quieren probar se comentan con // para ir viéndolas de a una.

ILI9488_Init();
setRotation(horizontal);
fillScreen(COLOR_BLUE);

draw_string(50, 0, "SUSCRIBANSE", COLOR_WHITE, font2);
draw_string(20, 100, "AL CANAL", COLOR_RED, font4);
draw_string_fondo(0, 200, "HOLA", COLOR_WHITE, COLOR_BLACK, font4);
HAL_Delay(2000);

draw_line(0, 0, 100, 100, COLOR_BLUEVIOLET, 3);   // x1,y1,x2,y2,color,grosor
HAL_Delay(3000);
fillScreen(COLOR_WHITE);

draw_fill_rectangle(0, 0, 100, 100, COLOR_BLUEVIOLET);
HAL_Delay(3000);
fillScreen(COLOR_WHITE);

draw_fill_triangulo(100, 0, 50, 100, 200, 100, COLOR_BLUE); // 3 vertices
HAL_Delay(3000);
fillScreen(COLOR_WHITE);

draw_circulo(100, 100, 50, COLOR_BLUEVIOLET, 3);  // centro, radio, color, grosor
HAL_Delay(3000);
fillScreen(COLOR_WHITE);

draw_fill_rectangulo_red(0, 0, 100, 100, 5, COLOR_BLUEVIOLET); // esquinas redondeadas
HAL_Delay(3000);
fillScreen(COLOR_WHITE);

draw_elipse(120, 80, 50, 30, COLOR_RED, 5);      // centro, radio x, radio y
HAL_Delay(3000);
fillScreen(COLOR_WHITE);

draw_fill_elipse(120, 80, 50, 30, COLOR_BLUE);

Los nombres de los parámetros de grosor y radio de esquina se tomaron de lo que se ve en pantalla; revisa la ayuda al final de ili9488.h para el orden exacto en tu versión de la librería.

Resultado en la pantalla

Fase 2

Mostrar imágenes

2.1

Función draw_bitmap

▶ 6:40

Se agrega a ili9488.c (y su prototipo a ili9488.h) una función que recibe la posición x, y, una escala y el arreglo de la imagen.

Los dos primeros valores del arreglo son el ancho y el alto; el resto son los colores de cada píxel en formato RGB565. Se abre una ventana de dibujo con setAddrWindow y se envían todos los píxeles seguidos. Con escala 2 cada píxel se repite en horizontal y vertical, y la imagen sale al doble de tamaño.

void draw_bitmap(uint16_t x1, uint16_t y1, int scale, const unsigned int *bmp)
{
    int width  = bmp[0];   // Ancho
    int height = bmp[1];   // Alto
    unsigned int this_byte;

    int x2 = x1 + (width  * scale) - 1;
    int y2 = y1 + (height * scale) - 1;

    // configurar ventana de dibujo en el TFT
    setAddrWindow(x1, y1, x2, y2);

    HAL_GPIO_WritePin(TFT_CS_GPIO_Port, TFT_CS_Pin, GPIO_PIN_RESET);

    // recorrer todos los pixeles
    for (int i = 0; i < height; i++) {
        for (int sv = 0; sv < scale; sv++) {
            for (int j = 0; j < width; j++) {
                this_byte = bmp[2 + (i * width) + j];
                for (int sh = 0; sh < scale; sh++) {
                    write16BitColor(this_byte);
                }
            }
        }
    }

    HAL_GPIO_WritePin(TFT_CS_GPIO_Port, TFT_CS_Pin, GPIO_PIN_SET);
}
2.2

Guardar la imagen como arreglo

▶ 8:25

Las imágenes se guardan en un archivo imagenes.h dentro de la carpeta de librerías, cada una como un arreglo const (así queda en flash y no en RAM).

El arreglo empieza por ancho y alto, y luego los datos de color.

const unsigned int tigre[] = {
    480, 320,          // ancho, alto
    0x18c3, 0x18c3, 0x18c3, /* ... datos de LCD Image Converter ... */
};
2.3

Dibujar la imagen en el main

▶ 7:50

Se incluye imagenes.h en el main y se llama draw_bitmap con la posición, la escala y el nombre del arreglo. Una imagen pequeña cabe sin problema en el F411.

#include "imagenes.h"

draw_bitmap(300, 0, 1, zorro);   // imagen pequeña en x=300, y=0, escala 1
Fase 3

Imágenes de pantalla completa en el U585

3.1

Por qué no cabe en el F411

▶ 13:10

Una imagen de 480x320 son 153.600 píxeles. Guardada como arreglo de unsigned int ocupa unos 600 KB, más que toda la flash del F411 (512 KB), y el proyecto no compila.

Por eso el mismo proyecto se pasa a la Blackpill STM32U585, que tiene 2 MB de flash. Se copian las librerías ili9488, fonts e imagenes y se configura el SPI igual que en el F411.

Si guardas los píxeles como uint16_t (const uint16_t imagen[]) en vez de unsigned int, cada píxel ocupa 2 bytes y la imagen pesa la mitad. En ese caso cambia también el tipo del parámetro bmp en draw_bitmap.

3.2

Imagen horizontal y vertical

▶ 16:40

Para una imagen de 480x320 se usa setRotation(horizontal); para una de 320x480 se cambia a setRotation(vertical) antes de dibujarla.

En la ventana Build Analyzer se ve el uso de la flash: con dos imágenes completas el U585 queda alrededor de 628 KB de 2 MB.

setRotation(horizontal);
fillScreen(ILI9488_RED);

draw_bitmap(0, 0, 1, tigre);    // 480x320
HAL_Delay(2000);

setRotation(vertical);
draw_bitmap(0, 0, 1, Dobby);    // 320x480
Fase 4

Convertir fotos con LCD Image Converter

4.1

Abrir la imagen

▶ 17:13

Primero se ajusta la foto a 480x320 (horizontal) o 320x480 (vertical) como máximo con cualquier editor.

En LCD Image Converter se abre con File > Open y se elige el archivo .jpg o .bmp.

4.2

Configurar la conversión y copiar los datos

▶ 17:46

En Options > Conversion se elige el preset de color de 16 bits (R5G6B5), que es el formato que usa la pantalla.

Con Show Preview aparece la imagen y, al lado, todos los datos en hexadecimal. Se seleccionan y copian.

Se pegan en imagenes.h dentro de un arreglo nuevo, escribiendo antes el ancho y el alto.

const unsigned int Dobby[] = {
    320, 480,          // ancho, alto (vertical)
    /* pegar aquí los datos copiados del Preview */
};
