Valor True RMS con PIC

Se parte de un video anterior que medía voltaje AC tomando el pico y dividiendo entre 1.414. Ese cálculo solo sirve para ondas seno. El True RMS que dan los multímetros es la raíz cuadrada de la suma de los cuadrados de cada muestra dividida entre el número de muestras. Se calcula cuántas muestras hacen falta, se cambia el programa y se ve que la lectura queda estable.

Fase 1

La fórmula

1.1

RMS por pico

▶ 0:00

Multiplicar el pico por 0.707 (o dividir entre 1.414) solo es correcto si la señal es una seno perfecta.

1.2

True RMS

▶ 0:32

El valor eficaz real es la raíz cuadrada del promedio de los cuadrados de las muestras. Tiene más carga de cálculo, pero sirve para cualquier forma de onda.

1.3

El programa anterior

▶ 0:32

Antes se hacían varias lecturas, se tomaba la mayor, se pasaba a voltios, se aplicaba el divisor y se dividía entre 1.4142.

Fase 2

Programa

2.1

Variables

▶ 1:41

Ya no se necesitan dos lecturas. Se agregan la suma de los cuadrados (float) y el contador de muestras.

float suma = 0;
unsigned int muestras = 0;
2.2

Sumar cuadrados

▶ 3:56

Cada lectura se pasa a voltios, se eleva al cuadrado, se suma y se cuenta la muestra.

lectura = ADC_Get_Sample(0);
Delay_us(10);
voltaje = lectura*5.0/1023.0;
suma += voltaje*voltaje;
muestras++;
2.3

Cuántas muestras

▶ 5:02

A 60 Hz el periodo es de 16.66 ms. Si cada lectura tarda unos 20 µs, hacen falta al menos unas 400 muestras por ciclo; lo ideal es el doble o el triple. Se usan 1500.

2.4

Raíz del promedio

▶ 6:41

Al llegar a 1500 muestras se aplica la fórmula con sqrt (incluir la librería matemática en MikroC), luego el divisor resistivo y la caída del puente rectificador, y se muestra en el LCD. Para la siguiente medición hay que volver a poner en cero suma y muestras.

if (muestras == 1500) {
  voltaje = sqrt(suma/(float)muestras);
  voltaje = voltaje*(res1+res2)/res2;  // divisor resistivo
  voltaje = voltaje + 1.4;             // caída del puente
  FloatToStr_FixLen(voltaje, texto, 6);
  Lcd_Out(1, 9, texto);
  Delay_ms(100);
}
Fase 3

Resultado

3.1

Simulación

▶ 8:52

La lectura queda estable en unos 127.5 V. Con menos muestras se vuelve menos precisa; en la vida real conviene más de 1200.

3.2

Comparación

▶ 9:56

El método por pico salta un poco porque no siempre lee el pico exacto. El True RMS da el valor real de la señal.
