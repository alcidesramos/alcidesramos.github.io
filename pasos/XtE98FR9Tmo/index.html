Varios sensores ultrasónicos con timer

Se leen varios sensores ultrasónicos midiendo el ancho del pulso de eco. Con pulseIn funciona, pero pierde precisión a distancias largas y bloquea si un sensor se desconecta. Con el Timer1 configurado a mano (prescaler y tiempo máximo calculados en Excel) se mide el pulso con más resolución y se retorna -1 si el timer se desborda. Luego se pasa al PIC12F1822 en MikroC.

  • Arduino Uno
  • MikroC PRO for PIC y PIC12F1822 (oscilador interno con PLL a 32 MHz)
  • Sensores ultrasónicos SRF04 o HC-SR04
  • Excel para calcular el timer
  • Proteus con Virtual Terminal

Fase 1

La medición

1.1

Tiempo y distancia

▶ 1:09

El sonido viaja a unos 343 m/s (0.0343 cm/µs). El eco recorre ida y vuelta, así que distancia = tiempo × 0.0343 / 2. Para 4 m el pulso dura unos 23 ms.

1.2

Cuatro sensores

▶ 2:21

Los cuatro sensores comparten el pin de disparo y cada eco va a un pin distinto.

Fase 2

Con pulseIn

2.1

Función de lectura

▶ 2:54

Se manda un pulso de 10 µs al disparo y pulseIn mide en microsegundos cuánto dura el eco en alto.

float lee_distancia(char pin) {
  float calculo;
  digitalWrite(disparo, HIGH);
  delayMicroseconds(10);
  digitalWrite(disparo, LOW);
  contador = pulseIn(pin, HIGH);
  calculo = (float)contador*0.0343/2.0;
  return calculo;
}
2.2

Resultado y problemas

▶ 6:33

Entre lecturas se esperan 50 ms para que no haya eco residual. A mayor distancia el error crece (unos 4 cm) y, si un sensor se desconecta, pulseIn espera hasta un segundo. Se puede poner un tiempo límite de 30000 µs.

Fase 3

Con el timer

3.1

Calcular el timer

▶ 10:44

En Excel se calcula cuánto tarda en desbordarse cada timer con cada prescaler. El Timer0 de 8 bits no alcanza los 23 ms; el Timer1 de 16 bits con prescaler 8 llega a unos 32 ms con resolución de 0.5 µs.

3.2

Leer y escribir el timer

▶ 14:50

Para leer o escribir TCNT1 se guarda SREG, se desactivan las interrupciones y luego se recupera, porque es un registro de 16 bits.

3.3

Medir el pulso

▶ 18:18

Se dispara, se limpia la bandera de desborde (TOV1) y se espera a que suba el eco; luego se pone el timer en cero y se espera a que baje. Si el timer se desborda en cualquiera de las esperas se retorna -1: el sensor no está o no hay eco.

3.4

Más precisión

▶ 20:39

Con el timer las lecturas quedan más cerca del valor real que con pulseIn.

Fase 4

En el PIC

4.1

PIC12F1822 a 32 MHz

▶ 22:41

Se usa el micro más pequeño y económico. El oscilador interno a 8 MHz con el PLL activado da 32 MHz. Los pines de eco son entradas y uno es el disparo.

IRCF3_bit = 1; IRCF2_bit = 1;
IRCF1_bit = 1; IRCF0_bit = 0; // 8 MHz
SPLLEN_bit = 1;               // PLL x4 = 32 MHz
UART1_Init(9600);
4.2

Misma lógica

▶ 26:24

Timer1 con prescaler 4, se limpian TMR1H, TMR1L y TMR1IF, y se espera el eco igual que en Arduino, retornando -1 si se desborda. El conteo es TMR1H por 256 más TMR1L.

4.3

Ahorrar memoria

▶ 29:19

Las funciones de texto de MikroC ocupan mucha memoria para este micro, así que se usa una función más liviana para pasar el flotante a texto con los decimales que se quiera.

4.4

Prueba

▶ 31:01

Los cuatro sensores se leen con precisión y se muestran en la terminal.
