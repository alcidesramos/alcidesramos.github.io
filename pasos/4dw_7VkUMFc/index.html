Reconocimiento de rostros con HuskyLens y STM32

Primer programa para reconocer rostros con la cámara HuskyLens desde un STM32F401. Se configuran dos UART (USART1 con la cámara, USART6 para enviar resultados), la recepción por DMA con detección de línea inactiva (IDLE) y un LED. Con dos librerías pequeñas (uart_int_idle_dma y huskeycam) se envía a la cámara el comando de pedir bloques, se mira cuántos bytes responde (32 = hay una cara) y el byte 29 dice el ID de la cara aprendida. En Proteus se simula con COMPIM conectado a la cámara real.

Fase 1

Proteus

1.1

Black Pill y alimentación

▶ 0:31

Crea un proyecto nuevo con la BLACKPILL_ARZ. En Design → Configure Power Rails pon el riel positivo en 3.3 V y pasa VDDA a ese riel.

1.2

COMPIM hacia la cámara

▶ 1:40

Agrega un COMPIM en el puerto COM donde está conectada la cámara (aquí mediante un cable USB-serial) a 9600 baudios.

En el COMPIM las líneas no van cruzadas: TX del micro (PA9) con TXD del COMPIM. Con la cámara física sí se cruzan: TX del micro con RX de la cámara.

Fase 2

CubeMX

2.1

USART1 para la cámara

▶ 2:12

USART1 en modo Asynchronous a 9600 (o 115200 si la cámara está así). Activa su interrupción en NVIC y en DMA Settings agrega la recepción USART1_RX: el DMA recibe sin frenar al micro.

2.2

USART6 para los resultados

▶ 2:47

Habilita un segundo puerto (USART6, solo TX en PA11) a 9600 para enviar el nombre de la persona detectada.

Un LED en PA0 como salida (LED1). Reloj a 16 MHz para Proteus (84 MHz en la tarjeta real). Activa la generación del .hex.

Fase 3

Librerías

3.1

Carpeta Librerias

▶ 4:57

En Core crea la carpeta Librerias, agrégala al path y copia uart.c/h, uart_int_idle_dma.c y huskeycam.c/h. Incluye string.h, stdio.h, stdint.h y huskeycam.h en el main.

3.2

Recepción por inactividad (IDLE)

▶ 5:30

Cuando llegan datos y la línea se queda quieta, el callback guarda cuántos bytes llegaron y levanta la bandera flag_rx.

void HAL_UARTEx_RxEventCallback(UART_HandleTypeDef *huart, uint16_t Size)
{
  if (huart->Instance == huskeycam)
  {
    num_datos = Size;
    flag_rx = 1;
  }
}
3.3

Elegir el puerto de la cámara

▶ 6:03

En huskeycam.h se define qué UART usa la cámara. Si usas otro puerto (USART2, USART6) cambia las dos líneas.

#define uart_husky huart1
#define huskeycam  USART1
3.4

Iniciar la cámara y pedir bloques

▶ 9:05

Huskey_init() borra el buffer de 100 bytes, limpia las banderas de la UART y arranca la recepción por DMA con IDLE. Huskeylen_Block() envía los 6 bytes del comando que pide los bloques detectados.

const uint8_t bloque[] = {0x55,0xAA,0x11,0x00,0x21,0x31};

void Huskey_init(void)
{
  memset(trama_huskey, 0, huskey_buff);
  uart_husky.Instance->SR &= ~(UART_SR_RXNE | UART_SR_ORE);
  uint8_t dummy = huskeycam->DR;
  HAL_UARTEx_ReceiveToIdle_DMA(&uart_husky, (uint8_t*)trama_huskey, huskey_buff);
}
Fase 4

Programa principal

4.1

Preguntar y esperar

▶ 11:49

Llama Huskey_init() antes del while. En el ciclo se piden bloques, se esperan 100 ms y, si llegó respuesta, se procesa y se reinicia la recepción.

4.2

Probar la comunicación

▶ 14:03

Con una Virtual Terminal en el RX del micro se ve si la cámara responde (en hexadecimal). Si no responde, puede estar bloqueada: desconéctala y vuelve a conectarla.

4.3

32 bytes = hay una cara

▶ 16:22

Si la respuesta tiene 32 bytes hay un rostro en la imagen. En la posición 29 viene el ID de la cara aprendida.

4.4

Nombrar las caras

▶ 17:31

Con un enum se le pone nombre a cada ID y se envía por USART6 quién es. Si es una cara conocida en especial, además titila el LED.

enum caras {nadie, chavo, alcides, roca, mujer_maravilla, scarlett_johansson};

Huskeylen_Block();
HAL_Delay(100);
if (flag_rx == 1)
{
  if (num_datos == 32)
  {
    if (trama_huskey[29] == nadie) uartx_write_text(&huart6, "NO SE QUIEN ES\r\n");
    else if (trama_huskey[29] == chavo) uartx_write_text(&huart6, "EL CHAVO\r\n");
    else if (trama_huskey[29] == alcides)
    {
      HAL_GPIO_TogglePin(LED1_GPIO_Port, LED1_Pin);
      uartx_write_text(&huart6, "SUSCRIBETE AL CANAL\r\n");
    }
    /* ... resto de caras ... */
  }
  flag_rx = 0;
  Huskey_init();
}
4.5

Resultado

▶ 22:45

Al mostrarle fotos a la cámara, la terminal escribe el nombre de cada persona aprendida y "NO SE QUIEN ES" para las que no conoce. Si la simulación se bloquea, aumenta el retardo después de pedir bloques (por ejemplo 200 ms).
