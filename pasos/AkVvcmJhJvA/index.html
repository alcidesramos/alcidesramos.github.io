Condicionales y lectura de puertos con registros

Clase del semestre 2024-I. Con dos pulsadores se analizan las cuatro combinaciones posibles uniendo condiciones con && y ||, y se optimiza el código con else if y un else final porque los casos son mutuamente excluyentes. Luego se conecta un thumbwheel BCD en Proteus y se lee el puerto B completo con el registro IDR, se filtran los bits que interesan con una máscara AND y se usan desplazamientos (>>) cuando los bits están en otra parte del puerto.

Fase 1

Condiciones combinadas

1.1

Cuatro combinaciones

▶ 1:40

Con dos pulsadores hay cuatro casos (00, 01, 10, 11). Para preguntar por dos condiciones a la vez se unen con operadores lógicos de condición:

&& (Y): se deben cumplir ambas. || (O): basta con una.

Para condiciones van dobles: && y ||. Un solo & o | es una operación entre bits, no entre condiciones.

1.2

Definir las entradas

▶ 8:16

Las lecturas se acortan con #define. Si un pulsador está con pull-up y otro con pull-down, niega el que lee al revés en el propio #define para que ambos lean 1 al presionar.

#define in1 HAL_GPIO_ReadPin(in1_GPIO_Port, in1_Pin)
#define in2 !(HAL_GPIO_ReadPin(in2_GPIO_Port, in2_Pin))
1.3

Primer caso

▶ 5:42

Encierra cada condición en paréntesis y toda la agrupación en otro par. Si ambos están presionados, parpadea el LED1.

if ((in1 == 1) && (in2 == 1))
{
  HAL_GPIO_TogglePin(led1_GPIO_Port, led1_Pin);
  HAL_Delay(500);
}
1.4

Apagar el otro LED

▶ 13:00

Como los LED quedan titilando, en cada caso apaga el LED que no corresponde con HAL_GPIO_WritePin(..., 0).

Fase 2

else if y else

2.1

Usar else if

▶ 17:57

Los cuatro casos son mutuamente excluyentes: si se cumple uno, los demás no pueden cumplirse. Con if separados el micro evalúa todos y pierde tiempo; con else if deja de evaluar en cuanto encuentra el que se cumple.

2.2

El último caso con else

▶ 21:27

Si ya preguntaste por tres casos, el cuarto es el que queda: basta un else sin condición.

if ((in1 == 1) && (in2 == 1))
{
  HAL_GPIO_TogglePin(led1_GPIO_Port, led1_Pin);
  HAL_Delay(500);
  HAL_GPIO_WritePin(led2_GPIO_Port, led2_Pin, 0);
}
else if ((in1 == 1) && (in2 == 0))
{
  HAL_GPIO_TogglePin(led2_GPIO_Port, led2_Pin);
  HAL_Delay(500);
  HAL_GPIO_WritePin(led1_GPIO_Port, led1_Pin, 0);
}
else if ((in1 == 0) && (in2 == 0))
{
  HAL_GPIO_TogglePin(led1_GPIO_Port, led1_Pin);
  HAL_GPIO_TogglePin(led2_GPIO_Port, led2_Pin);
  HAL_Delay(500);
}
else
{
  HAL_GPIO_WritePin(led1_GPIO_Port, led1_Pin, 0);
  HAL_GPIO_WritePin(led2_GPIO_Port, led2_Pin, 0);
}

Usa else if solo cuando los casos son excluyentes; si se pueden cumplir varios a la vez, van if separados.

Fase 3

Leer un puerto completo

3.1

El thumbwheel en Proteus

▶ 23:56

Busca THUMBSWITCH-BCD: entrega el número seleccionado (0 a 9) en 4 bits a la vez, así no lees pin por pin.

Conecta sus salidas A, B, C, D con etiquetas a PB0–PB3 configurados como entradas.

3.2

Registro de entrada IDR

▶ 31:00

Igual que ODR es el registro de salida, IDR (Input Data Register) tiene el estado de todas las entradas del puerto. Defínelo con un nombre corto (entre paréntesis para agruparlo).

#define lecturas (GPIOB->IDR)
3.3

Comparar el número

▶ 33:37

Guarda la lectura en una variable de 16 bits (los puertos tienen 16 pines) y compárala.

uint16_t codigo;
codigo = lecturas;
if (codigo == 7)
{
  HAL_GPIO_TogglePin(led1_GPIO_Port, led1_Pin);
  HAL_Delay(500);
}
3.4

Máscara con AND

▶ 38:30

No funciona: el resto del puerto (otros pines, otros periféricos) también aparece en IDR y altera el número.

Aplica una máscara AND para dejar en 0 todo lo que no interesa y conservar solo los 4 bits del thumbwheel.

codigo = lecturas & 0x000F;   // solo PB0..PB3
if (codigo == 7) { /* ... */ }
Fase 4

Desplazamientos

4.1

Datos en PB12–PB15

▶ 46:26

Si el thumbwheel está en PB12–PB15, el número queda en los bits altos. Puedes comparar con la máscara y el valor desplazados (& 0xF000 y == 0x7000), pero es más claro mover los bits.

Desplaza la lectura 12 posiciones a la derecha con >> y luego aplica la máscara.

codigo = lecturas >> 12;
codigo = codigo & 0b1111;
if (codigo == 7) { /* ... */ }
4.2

Datos en PB3–PB6

▶ 54:49

Con el mismo método, si los bits están en PB3–PB6 desplazas 3 posiciones.

Si la información está repartida en dos grupos, desplaza cada uno a su sitio y únelos con OR.

codigo = (lecturas >> 3) & 0x0F;
