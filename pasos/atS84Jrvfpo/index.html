El depurador de MikroC

Lección 44 del curso. A partir de una pregunta publicada en Facebook (qué imprime un programa con #define x 2+3 e y = x*x*x) se usa el depurador de MikroC: barra de herramientas, paso a paso y ventana de variables. Se ve que #define solo reemplaza texto y por precedencia da 17. Después se compara en el resumen de memoria qué pasa con un #define, una variable int y una constante.

Fase 1

La pregunta

1.1

¿125 o 17?

▶ 0:00

El programa define x como 2+3 y calcula y = x*x*x. Mucha gente responde 125, pero la respuesta es 17.

1.2

Proyecto de prueba

▶ 1:04

Se crea un proyecto nuevo con cualquier micro y se escribe el mismo código: #define x 2+3, int y; y en el main y = x*x*x.

Fase 2

Usar el depurador

2.1

Activar la barra

▶ 1:40

En View, Toolbars se activa la barra Debugger y se inicia la depuración. Aparecen la ventana de variables (Watch Values) y el reloj (Watch Clock).

2.2

Agregar la variable

▶ 2:11

Se escribe y en el buscador y se agrega. Se puede ver en decimal, hexadecimal, binario o flotante.

2.3

Paso a paso

▶ 2:44

Step Over ejecuta una función completa y Step Into entra en ella. Al pasar la línea, y vale 17.

2.4

Por qué 17

▶ 3:18

El preprocesador cambia cada x por el texto 2+3, así que la línea queda y = 2+3*2+3*2+3. Por precedencia primero se multiplica: 2 + 6 + 6 + 3 = 17.

#define x 2+3
int y;
void main() {
  y = x*x*x;   // queda y = 2+3*2+3*2+3 = 17
}
2.5

Con una variable

▶ 4:26

Si en vez del #define se declara int x = 2+3, primero se guarda 5 y y vale 125.

Fase 3

Memoria

3.1

Variable

▶ 5:31

En View, Statistics (resumen) se ve el consumo. Con la variable int x se usan 4 bytes de RAM y 168 de ROM.

3.2

#define y constante

▶ 6:38

Con #define solo quedan 2 bytes de RAM y 38 de ROM, porque no se guarda nada. Si x se declara const int, también queda en 2 y 38. Si un valor no va a cambiar, conviene definirlo o hacerlo constante.
