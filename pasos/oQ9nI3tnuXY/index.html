Interrupciones de alta y baja prioridad

Lección 35 del curso, continuación de la 34. Allí todo se trabajó en alta prioridad como en un PIC16. Aquí se activa IPEN, con lo que GIE pasa a habilitar las de alta (GIEH) y PEIE las de baja (GIEL). El Timer1 queda en alta, el Timer0 en baja e INT0, que no tiene bit de prioridad, siempre en alta. Luego se agrega INT1 en baja prioridad con un segundo pulsador.

Fase 1

Dos vectores

1.1

Bits de prioridad

▶ 0:00

En el diagrama de lógica de interrupciones cada fuente tiene, además de IF e IE, un bit IP: con 1 es de alta prioridad y con 0 de baja. INT0 no tiene IP y siempre es de alta.

1.2

0x0008 y 0x0018

▶ 0:34

El vector de alta prioridad está en 0x0008 y el de baja en 0x0018. Una interrupción de baja puede ser interrumpida por una de alta.

1.3

IPEN, GIEH y GIEL

▶ 1:08

Con IPEN en 0 el micro funciona como un PIC16. Con IPEN en 1, GIE (GIEH) habilita las de alta prioridad y PEIE (GIEL) las de baja, en lugar de las de periféricos.

Fase 2

Configurar prioridades

2.1

Asignar cada fuente

▶ 2:15

Se activa IPEN, se deja INTCON en cero y se asigna la prioridad de cada timer. Antes de GIE se habilitan las bajas con GIEL.

TMR1IP_bit = 1;   // prioridad alta
TMR0IP_bit = 0;   // prioridad baja

IPEN_bit = 1;   // autoriza prioridades
GIEL_bit = 1;   // autoriza las bajas
GIE_bit = 1;    // autoriza las interrupciones altas
2.2

Función de baja prioridad

▶ 5:14

Con el asistente de interrupciones se crea la de baja prioridad, que MikroC ubica en 0x0018. El código del Timer0 se pasa a esa función; el nombre no puede llevar espacios.

void int_bajas() iv 0x0018 ics ICS_AUTO
{
  if (TMR0IF_bit == 1)
  {
    TMR0H = 11;
    TMR0L = 220;
    led2 = ~led2;
    TMR0IF_bit = 0;
  }
}
2.3

Probar

▶ 6:20

Con GIEL en 0 deja de funcionar solo el Timer0, que está en baja; el Timer1 y el pulsador siguen. Si el Timer1 se pasa a baja y su código sigue en la función alta, deja de funcionar: cada fuente debe atenderse en la función de su prioridad.

Fase 3

INT1 en baja prioridad

3.1

Segundo pulsador

▶ 7:57

Se agrega un pulsador en RB1 como entrada y se configura INT1 igual que INT0, pero con su bit de prioridad en 0.

TRISB1_bit = 1;   // entrada pulsador

// AUTORIZAR INT1
INT1IF_bit = 0;    // limpia la bandera
INT1IE_bit = 1;    // autoriza int propia
INTEDG1_bit = 0;   // flanco de bajada
INT1IP_bit = 0;    // prioridad baja
3.2

Resultado

▶ 10:13

En baja quedan el Timer0 e INT1, y en alta INT0 y el Timer1. Lo más importante va en alta y lo menos importante en baja.
