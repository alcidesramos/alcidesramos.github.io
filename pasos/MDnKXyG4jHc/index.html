Datalogger con DS18B20, DS1307 y SD

El video repasa los tres protocolos: 1-Wire (DS18B20), I2C (DS1307) y SPI (memoria SD). La SD se inicia con SPI lento, se sube la velocidad y se crea o abre Datos.txt. El DS18B20 se lee con su propia librería, incluyendo negativos y decimales. El reloj usa una librería propia por I2C por software. Cada 2 segundos se escribe una fila separada por tabulaciones; un pulsador cierra el archivo para retirar la memoria sin dañarla.

Fase 1

Protocolos

1.1

1-Wire

▶ 0:00

El DS18B20 usa un solo hilo con una resistencia de 4.7 kΩ. Llega a unos 5 m (más bajando la resistencia) y es digital, así que tiene menos ruido que el LM35 a distancia.

1.2

I2C

▶ 2:12

Dos hilos, reloj y datos, de colector abierto con resistencias pull-up. El maestro envía inicio, la dirección con el bit de leer o escribir, y cada byte con su reconocimiento hasta la condición de parada.

1.3

SPI

▶ 4:22

Cuatro hilos: reloj, entrada, salida y selección. Es full duplex: en cada pulso de reloj sale un bit y entra otro. Hay que configurar el reposo del reloj y el flanco de lectura según el dispositivo.

1.4

La SD en Proteus

▶ 7:41

Proteus necesita una imagen de la memoria, no el archivo que crea por defecto. Las librerías de MikroC para SD son para PIC18, y FAT16 conviene para que quepa en memoria.

Fase 2

Memoria SD

2.1

Proyecto

▶ 10:57

PIC18F25K50 a 20 MHz (la SD necesita velocidad). Se activan SPI, MMC y MMC_FAT16, UART, conversiones y cadenas.

2.2

Pines

▶ 14:21

Todo digital y como salida; el pulsador es entrada con pull-up. La selección de la SD va en RB4.

sbit Mmc_Chip_Select at LATB4_bit;
sbit Mmc_Chip_Select_Direction at TRISB4_bit;
2.3

Iniciar y crear el archivo

▶ 17:40

El SPI arranca lento, se espera a que la memoria esté insertada y luego se sube la velocidad. Mmc_Fat_Assign con 0xA0 abre Datos.txt o lo crea si no existe. Se escriben los encabezados separados por tabulación.

SPI1_Init_Advanced(_SPI_MASTER_OSC_DIV64, _SPI_DATA_SAMPLE_MIDDLE, _SPI_CLK_IDLE_LOW, _SPI_LOW_2_HIGH);
UART1_Write_Text("INICIANDO\r\n");
while (Mmc_Fat_Init() == 1);    // espera la memoria
// sube la velocidad del SPI
SPI1_Init_Advanced(_SPI_MASTER_OSC_DIV4, _SPI_DATA_SAMPLE_MIDDLE, _SPI_CLK_IDLE_LOW, _SPI_LOW_2_HIGH);
UART1_Write_Text("MEMORIA INICIADA\r\n");
// Mmc_Fat_QuickFormat("ARZ");  // si se quiere formatear
Mmc_Fat_Assign("Datos.TXT", 0xA0);
Mmc_Fat_Write("TEMPE\t", 6);
Mmc_Fat_Write("HORA\t\t", 6);
Mmc_Fat_Write("FECHA\r\n", 7);
2.4

Revisar la imagen

▶ 22:01

Con UltraISO se abre la imagen de la SD y se ve el archivo creado. Proteus debe estar cerrado o sin la memoria puesta para poder modificarla.

Fase 3

DS18B20

3.1

Librería

▶ 25:18

La librería del sensor se guarda en una carpeta Librerias del proyecto y se incluye. Necesita la librería One_Wire de MikroC.

3.2

Lectura

▶ 27:28

Reset, 0xCC (todos los sensores), 0x44 (iniciar conversión), espera, reset, 0xCC y 0xBE para leer los dos bytes. Si es negativo se toma el complemento. Los 4 bits bajos son la parte decimal.

td_ = t1_ & 0x0F;    // parte decimal
tempo_ = 0;
if (td_.b3 == 1) tempo_ = tempo_ + 0.5;
if (td_.b2 == 1) tempo_ = tempo_ + 0.25;
if (td_.b1 == 1) tempo_ = tempo_ + 0.125;
if (td_.b0 == 1) tempo_ = tempo_ + 0.0625;
3.3

Dos lecturas al inicio

▶ 29:42

Al arrancar el sensor puede dar valores errados, así que se hacen dos lecturas que no se guardan, con un segundo entre ellas. La temperatura se escribe con tres decimales y un tab.

Fase 4

Reloj DS1307

4.1

I2C por software

▶ 34:06

La librería propia del DS1307 sirve por hardware o por software. Aquí va por software en RC0 y RC1, así que se activan las librerías I2C y Software_I2C.

sbit Soft_I2C_Scl at RC0_bit;
sbit Soft_I2C_Sda at RC1_bit;
sbit Soft_I2C_Scl_Direction at TRISC0_bit;
sbit Soft_I2C_Sda_Direction at TRISC1_bit;
4.2

Poner la hora

▶ 37:21

Se cargan hora, fecha y día de la semana (domingo = 1) y se guarda en el reloj. Se hace una sola vez; después se comenta para que no la vuelva a cargar.

4.3

Guardar una fila

▶ 41:42

Se lee el reloj, se arma la hora con dos dígitos y un tab, y la fecha con un enter al final. Si el pulsador no está presionado se escribe en la SD; si se presiona se cierra el archivo para poder sacar la memoria.

leertodo_s();
memset(texto, 0, 50);
sprintf(texto, "%02u:%02u:%02u\t", (unsigned int)ds1307_hora, (unsigned int)ds1307_minuto, (unsigned int)ds1307_segundo);
if (RB7_bit == 1) Mmc_Fat_Write(texto, strlen(texto));
UART1_Write_Text(texto);
// la fecha igual, terminando en \r\n
if (RB7_bit == 0) Mmc_Fat_Close();
Delay_ms(2000);   // tiempo entre datos
Fase 5

Resultado

5.1

Abrir en Excel

▶ 46:07

Se extrae Datos.txt de la imagen y se abre en Excel como texto delimitado por tabulaciones. Quedan las columnas de temperatura, hora y fecha, listas para graficar, incluso con temperaturas negativas.
