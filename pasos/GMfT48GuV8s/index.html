PWM con output compare en dsPIC

En un PIC o en Arduino, mover servos suele hacerse con interrupciones de timer, y eso carga el programa. El dsPIC lo hace por hardware con el módulo output compare en modo PWM, y puede bajar a 50 Hz sin cambiar el cristal. Se usa el oscilador interno de 7,37 MHz con PLL para llegar a 80 MHz, se remapean OC1 y OC2 a RP2 y RP3, y el Timer2 con prescaler 64 y PR2 = 12500 da el periodo de 20 ms. Luego se hacen funciones para mover el servo en grados (con un mapeo lineal o con la ecuación sacada en Excel) y para dar el ancho en porcentaje.

Proyecto y reloj

1.1

Pines de output compare

▶ 0:37

Este micro tiene pines de motor control (PWM1H/L) y dos módulos output compare, OC1 y OC2. En esta clase se usa el PWM normal por output compare.

1.2

Oscilador interno

▶ 2:21

El proyecto se configura a 80 MHz con el oscilador interno y el PLL, sin cristal. Se deja activa la configuración múltiple del remapeo para poder mover el PWM y el serial.

1.3

VCAP y AVDD

▶ 4:03

En el montaje real hay que conectar AVDD y AVSS y poner un capacitor de 10 µF, mejor de tantalio, en VCAP; sin eso el micro no arranca. El oscilador interno es de 7,37 MHz.

1.4

Librería de interrupciones

▶ 5:08

Se agrega Config_Interrupcion, que limpia las trampas del núcleo (falla de oscilador, error de dirección, pila y matemático) y trae las funciones para habilitar y deshabilitar interrupciones.

1.5

Reloj, puertos y remapeo

▶ 6:17

El main ajusta el PLL para el oscilador interno, deja todo digital y remapea el serial a RP0/RP1 y las salidas OC1 y OC2 a RP2 y RP3. En Proteus sale INICIANDO.

CLKDIVbits.PLLPRE = 0;   // N1 = 2
CLKDIVbits.PLLPOST = 0;  // N2 = 2
PLLFBD=41; // selecciona M=40; siempre lo deseado menos 2;  CRISTAL INTERNO

//INICIALIZA PINES DIGITALES
AD1PCFGL = 0xFFFF;
//puertos como ENTRADAS
TRISA=0XFFFF;
TRISB=0XFFFF;

Unlock_IOLOCK();
// UART1
PPS_Mapping(0,_OUTPUT,_U1TX);
PPS_Mapping(1,_INPUT,_U1RX);
//REMAPEO PWM
PPS_Mapping(2,_OUTPUT,_OC1);
PPS_Mapping(3,_OUTPUT,_OC2);

UART1_Write_Text("INICIANDO\r\n");
Fase 2

Configurar el PWM

2.1

Registro OCxCON

▶ 9:09

En el manual de referencia, los bits OCM en 110 ponen el módulo en PWM sin protección de fallas. OCTSEL elige el timer: 0 para Timer2 y 1 para Timer3.

2.2

50 Hz con el Timer2

▶ 10:50

En la hoja de Excel, para 50 Hz a 80 MHz sirven los prescaler 8 y 64. Con 64 el PR2 es 12500; con 8 sería mayor y daría más resolución.

2.3

pwm_init_basico

▶ 12:30

La librería CONFIG_PWM_B configura el Timer2 y los dos módulos. Para arrancar se carga la mitad del periodo, 6250, que da 50 % de ciclo útil.

void pwm_init_basico()
{
//configuracion timer 2
TMR2=0;
PR2=12500; // para 50HZ = 20 ms manejo de servos
//limpia el registro de configuracion
T2CON=0;
//preescalador 64
T2CONbits.TCKPS=0B10;
T2CONbits.TON=1; // prende el timer 2
//configuración
//modulo pwm  oc1
OC1CON=OC2CON=0;
OC1CONbits.OCTSEL= OC2CONbits.OCTSEL=0; //trabaja con timer2 sino timer 1
// ... OC1R/OC1RS y OC2R/OC2RS en 6250 (50 %)
// ... OCM = 110: PWM sin protección de fallas
}
2.4

Señal por hardware

▶ 15:24

Se llama pwm_init_basico antes del while y el while queda vacío. Aun así el osciloscopio muestra las dos señales y el frecuencímetro marca 50 Hz: todo lo hace el hardware.

Fase 3

Servo y motor

3.1

Ancho fijo para el servo

▶ 17:46

Con prescaler 64, 1,5 ms equivalen a unos 938 pasos. Primero se calculó mal (1250) y el pulso no daba; al corregir, el servo queda en el centro.

3.2

Mapeo de ángulo a tiempo

▶ 21:33

Se definen el rango del servo (1 a 2 ms, como los de Proteus) y una función map de línea recta. servo1 pasa el ángulo de -90 a 90 a milisegundos y lo convierte a cuentas de OC1RS; pwm1 recibe un porcentaje.

const float ser_min=1.0; // tiempo minimo en milisegundo de movimiento del servo
const float ser_max=2.0;
signed char cuenta;

float map(float x_in, float x1_, float y1_, float x2_, float y2_)
{
float pendiente;
  pendiente=(y2_ - y1_) / (x2_ - x1_);
  pendiente=pendiente*(x_in- x1_);
  pendiente=pendiente+y1_;
  return( pendiente);
}

void servo1(float angulo)
{
  angulo=map(angulo,-90.0,ser_min,90.0,ser_max);
  OC1RS=angulo*(float)PR2/20.0;
}

void pwm1(float ancho)
{
  OC1RS=ancho*(float)PR2/100.0;
}
3.3

Probar servo y motor

▶ 23:13

servo1(90) da 2 ms y pwm2(80) deja la otra salida al 80 %. En el osciloscopio se ven las dos señales.

3.4

Barrido del servo

▶ 25:00

Un for mueve el servo de -90 a 90 grados de 5 en 5, con 50 ms entre pasos.

servo1_ecu(-90);
for (cuenta=-90;cuenta<=90;cuenta+=5)
{
servo1_ecu(cuenta);
Delay_ms(50);
}
pwm2(80);
Delay_ms(1000);
3.5

Ecuación desde Excel

▶ 26:43

En Excel se ponen -90° = 625 y 90° = 1250, se grafica, se agrega una línea de tendencia y se muestra la ecuación. Esa recta reemplaza el mapeo en una sola línea, más rápida.

void servo1_ecu(float angulo)
{
  OC1RS=3.4722*angulo + 937.5;
}
3.6

Resultado

▶ 29:32

El servo va de un extremo al otro con servo1_ecu y la otra salida sigue al 80 %. Todo por hardware y a 50 Hz, ideal para servos y para motores DC con buen torque.
