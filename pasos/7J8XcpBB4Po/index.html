Arduino a Ubidots con el ESP8266

Es la versión para Arduino de un proyecto hecho antes con PIC. Un sensor de temperatura en A0 y un interruptor en el pin 2 se leen en el loop. En el setup se configura el ESP8266 con comandos AT: sin eco, modo estación, IP fija, conexión a la red WiFi y conexión TCP a things.ubidots.com por el puerto 80. En cada vuelta se arma la trama {"temperatura": ..., "led": ...} con sprintf, se calcula su largo y se envía un POST HTTP con AT+CIPSEND. En el tablero de Ubidots se ven los cambios cuando se mueve la temperatura o el interruptor en Proteus.

Fase 2

El programa

2.1

Variables y función para enviar

▶ 0:32

Antes del setup se declaran el pin del interruptor, las tramas y una función que envía cualquier texto al ESP8266: primero AT+CIPSEND con el canal y el largo, y luego el texto.

#define suiche 2
unsigned int codigo;
float temperatura;
char trama[150];
char trama_largo[20];
char captu[30];
char led = '0';
int var_largo;

void manda_esp8266(const char *info)
{
  unsigned int largo;
  Serial.print("AT+CIPSEND=4,");   // canal 4
  largo = strlen(info);              // largo de la trama
  sprintf(captu, "%u", largo);
  Serial.print(captu);
  Serial.print("\r\n");
  delay(100);                        // espera antes de enviar
  Serial.print(info);
}
2.2

Configurar el ESP8266 en el setup

▶ 1:37

Se configuran el puerto serial y el interruptor, y se mandan los comandos AT: sin eco, modo estación, IP fija con puerta de enlace y máscara, conexión a la red WiFi, múltiples conexiones y conexión TCP con Ubidots por el puerto 80.

void setup()
{
  Serial.begin(115200);
  pinMode(suiche, INPUT);

  Serial.print("ATE0\r\n");        // sin eco
  delay(200);
  Serial.print("AT+CWMODE=1\r\n");  // se conecta a una red existente
  delay(200);
  Serial.print("AT+CWDHCP=1,0\r\n"); // deshabilita DHCP para IP manual
  delay(300);
  // IP, puerta de enlace y máscara de tu red
  Serial.print("AT+CIPSTA=\"192.168.1.117\",\"192.168.1.1\",\"255.255.255.0\"\r\n");
  delay(300);
  Serial.print("AT+CWJAP=\"TU_RED\",\"TU_CLAVE\"\r\n"); // red WiFi
  delay(6000);
  Serial.print("AT+CIPMUX=1\r\n");  // acepta múltiples conexiones
  delay(200);
  Serial.print("AT+CIFSR\r\n");     // mira qué IP tiene el módulo
  delay(1000);
  // se conecta a Ubidots
  Serial.write("AT+CIPSTART=4,\"TCP\",\"things.ubidots.com\",80\r\n");
  delay(3000);
}

En el código de ejemplo van marcadores (TU_RED, TU_CLAVE, TU_TOKEN, la IP): pon los de tu red y tu cuenta de Ubidots y no publiques tu token ni la clave de tu WiFi.

2.3

Armar y enviar la trama

▶ 2:49

En el loop se lee la temperatura (10 mV/°C: código × 500/1023) y el interruptor. sprintf de Arduino no imprime decimales, por eso la temperatura se envía como entero.

Se envía la cabecera del POST, luego el largo de la trama y luego la trama con las variables.

void loop()
{
  // lee la temperatura
  codigo = analogRead(0);
  temperatura = codigo * 500.0 / 1023.0;
  if (digitalRead(suiche) == 0) led = '0'; else led = '1';

  // limpia las tramas
  memset(trama_largo, 20, 0);
  memset(trama, 150, 0);
  // arma la trama de variables
  sprintf(trama, "{\"temperatura\": %u ,\"led\": %c}\n", (int)temperatura, led);
  // calcula el largo y lo pasa a cadena con dos fin de línea
  var_largo = strlen(trama) - 1;
  sprintf(trama_largo, "%u\n\n", var_largo);

  // envío a Ubidots: dispositivo y token de tu cuenta
  manda_esp8266("POST /api/v1.6/devices/micasa/?token=TU_TOKEN HTTP/1.1\nHost: things.ubidots.com\nContent-Type: application/json\nContent-Length: ");
  delay(1000);
  manda_esp8266(trama_largo);   // manda el largo de la trama
  delay(500);
  manda_esp8266(trama);         // manda las variables
  delay(500);
}

Prueba

3.1

Simulación en Proteus

▶ 4:00

En Proteus el Arduino se conecta al ESP8266 real por un puerto COM (COMPIM) a 115200. En el terminal se ven los comandos y las respuestas; cuando el módulo se conecta empieza a enviar.

3.2

Ver los cambios en Ubidots

▶ 4:00

Con 33 °C el tablero muestra 33 y el indicador del interruptor en ABIERTO. Al bajar la temperatura a 16 °C y cambiar el interruptor en Proteus, después de unos segundos Ubidots muestra 16 y CERRADO.
