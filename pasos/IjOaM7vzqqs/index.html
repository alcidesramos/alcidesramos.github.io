Módulo input capture en dsPIC

En la clase anterior se usaron tres timers para tres sensores. Ahora el módulo input capture hace lo mismo con un solo timer (Timer2) para cuatro señales. Cada módulo (IC1, IC2, IC7 e IC8) guarda el valor del timer en cada flanco de subida y de bajada; en la interrupción del flanco de bajada se resta la captura anterior, y si el timer desbordó en medio se corrige con PR2. Los cuatro pines de captura son remapeables, así que se ponen en RB2 a RB5. Con prescaler 64 se miden pulsos de hasta unos 100 ms.

1.2

Cuatro canales

▶ 2:19

El datasheet indica cuatro módulos de captura que pueden capturar en flanco de subida, de bajada o en ambos. Curiosamente se llaman IC1, IC2, IC7 e IC8.

1.3

Registro ICxCON

▶ 4:02

El bit ICTMR elige el timer: 1 para Timer2 y 0 para Timer3. Los bits ICM en 0b001 capturan en cada flanco, que es lo que se necesita para medir un ancho de pulso.

2.3

Timer2 y módulos

▶ 12:37

El Timer2 cuenta hasta 65535 con prescaler 64, unos 100 ms. Luego se limpian los cuatro módulos, se asocian al Timer2, se pone captura en cada flanco, se habilitan sus interrupciones y se les da prioridad 3.

extern unsigned int pulso_1,pulso_2,pulso_3,pulso_4;
extern sfr sbit in_pulso_1;
// ... in_pulso_2 a in_pulso_4
unsigned int pul1_1=0,pul1_2=0;
// ... pul2_x, pul3_x, pul4_x

void confi_timer_2(){
  //configuracion timer 2
  //100ms
  tmr2=0;
  pr2=65535;
  t2con=0;
  //preescalador 64
  t2con.b5=1;
  t2con.b4=0;
  T2CONbits.TON=1; //prendo
}

void config_inputcapure(){
  confi_timer_2();
  IC1CON=IC2CON=IC7CON=IC8CON=0; //limpia registo
  ICTMR_IC1CON_bit=ICTMR_IC2CON_bit=ICTMR_IC7CON_bit=ICTMR_IC8CON_bit=1; //1=timer 2 es la fuente de reloj 0= timer 3
  //  Captura cada flanco de subida o bajada
  IC1CONbits.ICM=IC2CONbits.ICM=IC7CONbits.ICM=IC8CONbits.ICM=0b001;
  //habilita la interrupcion
  IC1IF_bit=IC2IF_bit=IC7IF_bit=IC8IF_bit=0;
  IC1IE_bit=IC2IE_bit=IC7IE_bit=IC8IE_bit=1;
  //Prioridad de la interrupcion
  IC1IP_2_bit=IC2IP_2_bit=IC7IP_2_bit=IC8IP_2_bit=0;
  IC1IP_1_bit=IC2IP_1_bit=IC7IP_1_bit=IC8IP_1_bit=1;
  IC1IP_0_bit=IC2IP_0_bit=IC7IP_0_bit=IC8IP_0_bit=1;
}
Fase 3

Interrupciones de captura

3.1

Restar capturas

▶ 15:35

En cada interrupción se lee ICxBUF. Si el pin ya está en cero, fue el flanco de bajada: el ancho es la captura actual menos la anterior.

3.2

Desborde del timer

▶ 16:44

Si la resta da negativa es porque el timer pasó por cero entre las dos capturas. En ese caso se suma lo que faltaba hasta PR2.

void INTIC1() iv IVT_ADDR_IC1INTERRUPT ics ICS_AUTO {
  pul1_2=IC1BUF;
  if (in_pulso_1==0) {
    //Para medir ancho de pulso
    if (pul1_2>pul1_1) pulso_1=(pul1_2-pul1_1);
    else pulso_1=(PR2 - pul1_1) + pul1_2;   //desborde del timer
  }
  pul1_1=pul1_2;
  IC1IF_bit=0; // limpia la bandera
}
// ... igual para IC2, IC7 (pulso_3) e IC8 (pulso_4)

Para qué sirve

▶ 25:24
