El modulador de señales DSM en MikroC

Versión en MikroC de un video hecho con MPLAB XC8. El DSM (Data Signal Modulator) combina una señal moduladora con dos portadoras: cuando la moduladora está en 1 sale una portadora y cuando está en 0 sale la otra, lo que da una modulación FSK. MikroC no trae librería para el DSM ni deja escoger el timer de cada PWM, así que todo se hace con registros. Con un PIC16F1824 a 32 MHz se configura PWM1 a 40 kHz con el Timer2 y PWM4 con el Timer6 a otra frecuencia, y luego el DSM con tres moduladoras distintas: un pin de entrada, el bit MDBIT por software y la salida TX del UART.

Fase 1

Configuración base

1.1

Reloj a 32 MHz

▶ 1:11

Proyecto con PIC16F1824 y oscilador interno. En Edit Project se deja el PLL deshabilitado y se prende por software: oscilador interno a 8 MHz y el PLL x4 da 32 MHz.

OSCTUNE = 0;      // frecuencia centrada
SCS1_bit = 0;     // oscilador puesto en la palabra de configuración
SCS0_bit = 0;
// oscilador interno a 8 MHz
IRCF3_bit = 1;  IRCF2_bit = 1;
IRCF1_bit = 1;  IRCF0_bit = 0;
SPLLEN_bit = 1;   // prende el PLL x4, entonces 32 MHz
1.2

Remapear el UART

▶ 4:31

Al iniciar el UART, MikroC lo deja en RC4 y RC5. Con los bits de remapeo se pasa RX a RA1 y TX a RA0. RC3 queda como entrada para la moduladora manual.

UART1_Init(9600);
// pines UART
RXDTSEL_bit = 1;   // RX en RA1
TXCKSEL_bit = 1;   // TX en RA0
TRISA = 0;
TRISC = 0;
TRISC3_bit = 1;    // entrada de moduladora manual
Fase 2

Las dos portadoras

2.1

Por qué a mano

▶ 5:37

Se necesitan dos PWM con frecuencias distintas, así que cada uno va con un timer diferente: PWM1 con el Timer2 y PWM4 con el Timer6. La librería de MikroC no deja escoger el timer, por eso se configuran los registros. Los valores salen de las fórmulas del PWM de la hoja de datos, calculados en Excel.

2.2

PWM1 a 40 kHz con el Timer2

▶ 7:51

Con preescalador de 1 y PR2 = 199 el periodo es de 25 µs (40 kHz). CCP1 se asocia al Timer2 con C1TSEL, se pone en modo PWM y el ciclo útil queda en 50 % con CCPR1L = 99. La salida va por P1A.

// configuración módulo PWM1 CCP1 al timer 2
T2CON = 0;
T2CKPS1_bit = 0;   // preescalador 1
T2CKPS0_bit = 0;
PR2 = 199;         // para 25 us, 40 kHz
CCP1CON = 0;
C1TSEL1_bit = 0;   // selecciona el timer 2
C1TSEL0_bit = 0;
CCP1M3_bit = 1;    // modo PWM
CCP1M2_bit = 1;
CCPR1L = 99;       // parte alta del ciclo útil
DC1B1_bit = 0;     // bits bajos del ciclo útil
DC1B0_bit = 0;
PSTR1CON = 0;
STR1A_bit = 1;     // salida PWM en P1A
TMR2ON_bit = 1;    // prende el timer 2
2.3

PWM4 con el Timer6

▶ 15:53

Igual con CCP4 y el Timer6: preescalador de 4 y PR6 = 119 para un periodo de 60 µs. C4TSEL en 10 asocia CCP4 al Timer6.

// configuración módulo PWM4 CCP4 al timer 6
T6CON = 0;
T6CKPS1_bit = 0;   // preescalador 4
T6CKPS0_bit = 1;
PR6 = 119;         // para 60 us
CCP4CON = 0;
C4TSEL1_bit = 1;   // selecciona el timer 6
C4TSEL0_bit = 0;
CCP4M3_bit = 1;    // modo PWM
CCP4M2_bit = 1;
TMR6ON_bit = 1;
Fase 3

El modulador

3.1

Configurar el DSM

▶ 19:19

En MDCON se habilita la salida por el pin y la moduladora. En MDSRC se escoge quién modula (MDMS): 0000 el bit MDBIT por software, 0001 el pin MDMIN, 1010 el TX del UART, y otras opciones como los comparadores o el SPI. En MDCARH y MDCARL se escogen las portadoras para el 1 y el 0: aquí CCP1 y CCP4.

MDCON = 0;
MDEN_bit = 0;        // deshabilita el módulo
MDOE_bit = 1;        // habilita la salida en el pin
MDSLR_bit = 1;       // slew rate
MDMSODIS_bit = 0;    // habilita la moduladora
// quién modula: en este caso manual, MDMIN
MDMS3_bit = 0;  MDMS2_bit = 0;
MDMS1_bit = 0;  MDMS0_bit = 1;
// fuente para el 0: en este caso CCP4
MDCL3_bit = 0;  MDCL2_bit = 1;
MDCL1_bit = 0;  MDCL0_bit = 1;
MDEN_bit = 1;        // habilita el módulo
3.2

Moduladora por un pin

▶ 22:45

Con la moduladora en el pin MDMIN (RC3), un interruptor cambia la salida: con 1 sale la portadora rápida y con 0 la lenta. Es una modulación FSK de lo que entre por ese pin.

3.3

Moduladora por software

▶ 23:53

Con MDMS en 0000, el bit MDBIT decide qué portadora sale. Así se codifica información por software, por ejemplo para controles infrarrojos o comunicación por la red eléctrica. Al terminar se apaga el módulo para que la señal no quede activa.

MDEN_bit = 1;    // habilita el módulo
MDBIT_bit = 1;
Delay_ms(1);
MDBIT_bit = 0;
Delay_ms(1);
MDEN_bit = 0;    // deshabilita el módulo
3.4

Moduladora por el UART

▶ 27:14

Con MDMS en 1010 la moduladora es la salida TX del UART: lo que se transmite sale modulado en FSK. Se habilita el módulo, se envía el dato, se espera a que termine la transmisión y se apaga. En el analizador digital de Proteus se ve la trama serial junto a la señal modulada.
