Compuertas lógicas con Arduino

Las compuertas lógicas se pueden hacer por hardware (circuitos TTL o CMOS, o una FPGA) o por software. Por software es más lento, pero se pueden tener muchas entradas y cualquier combinación sin comprar un chip por compuerta. Se usan dos pulsadores en los pines 0 y 1 con la resistencia de pull-up interna, cuatro LEDs en los pines 8 a 11 y los operadores de C: & para AND, | para OR, ^ para XOR y ! para NOT. Al final se guarda una ecuación booleana en una variable y se saca por un LED.

Compuertas por software

1.1

Hardware o software

▶ 0:00

Las compuertas AND, OR, XOR y NOT se conocen por sus símbolos y vienen en chips TTL o CMOS. También se pueden hacer en una FPGA o, como aquí, por software con un Arduino.

1.2

Los operadores de C

▶ 1:10

En C cada compuerta tiene su operador de bits:

  • AND: &
  • OR: |
  • XOR: ^
  • NOT: ! (para un solo bit)
1.3

El circuito

▶ 1:44

En Proteus se crea un proyecto con Arduino (hay que tener Arduino instalado en el computador). Las entradas A y B son dos pulsadores en los pines 0 y 1, sin resistencia, porque se usa el pull-up interno. Los LEDs de AND, OR, XOR y NOT van en los pines 8, 9, 10 y 11.

Fase 2

El programa

2.1

Definiciones y setup

▶ 6:38

Se definen los pines, dos variables boolean para las entradas y cuatro para las salidas. Las entradas usan INPUT_PULLUP y los LEDs son salidas. Conviene compilar seguido para no acumular errores.

//DEFINICIONES DE LOS PINES USADOS
#define IN_A 0
#define IN_B 1

#define AND_LED 8
#define OR_LED 9
#define XOR_LED 10
#define NOT_LED 11

boolean  A,B; //variables entrada
boolean and1,or1,xor1,not1; // variables salidas

void setup()
{
  pinMode(IN_A,INPUT_PULLUP);
  pinMode(IN_B,INPUT_PULLUP);
  pinMode(AND_LED,OUTPUT);
  pinMode(OR_LED,OUTPUT);
  pinMode(XOR_LED,OUTPUT);
  pinMode(NOT_LED,OUTPUT);
}
2.2

Las operaciones

▶ 9:34

En el loop se leen las dos entradas y se escribe en cada LED el resultado de la operación directamente.

void loop()
{
  A=digitalRead(IN_A);
  B=digitalRead(IN_B);

  digitalWrite(AND_LED, A &B);
  digitalWrite(OR_LED, A |B);
  digitalWrite(XOR_LED, A ^B);
  digitalWrite(NOT_LED, !A);
}
Fase 3

Prueba y variantes

3.1

Simular

▶ 13:45

Con las dos entradas en 1 prende la AND y la OR, y la XOR queda apagada porque son iguales. Cambiando los pulsadores se recorre la tabla de verdad. Si un LED no responde, revisar que el pin del #define sea el correcto (aquí el XOR estaba mal puesto).

3.2

Guardar la operación en una variable

▶ 15:07

Otra forma es calcular primero el resultado en una variable y después sacarlo. Así se puede escribir cualquier ecuación booleana (por ejemplo, una ya reducida por Karnaugh) y sacarla por un LED.

boolean and1,or1,xor1,not1,operacion; // variables salidas
// ...
void loop()
{
  A=digitalRead(IN_A);
  B=digitalRead(IN_B);

  and1=A &B;
  operacion= A&B | (!B ^A);

  digitalWrite(AND_LED, and1);
  digitalWrite(OR_LED,operacion);
  digitalWrite(XOR_LED, A ^ B);
  digitalWrite(NOT_LED, !A );
}
