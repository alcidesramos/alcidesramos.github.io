Ocho servos con XC8

Un suscriptor pidió pasar a XC8 el manejo de varios servos que estaba en MikroC. La librería usa el Timer1: cada 2,5 ms interrumpe y atiende el pulso de un servo, de modo que los ocho se refrescan sin bloquear el programa. El proyecto se crea en MPLAB X con un PIC16F1619 y el MCC solo para el oscilador interno. En main.c se definen los pines (LATC0 a LATC5, LATB4 y LATB5) y sus registros TRIS, se incluye la librería, se llama a init_servos con el pulso mínimo y máximo en milisegundos y se habilitan las interrupciones. La función de interrupción solo llama a servos_interrupcion. Con servo_valor(número, ángulo) cada servo va de -90 a 90 grados, y con un for se hace un movimiento escalonado para que no sea brusco.

1.3

Pines de los servos

▶ 5:03

Cada servo tiene su pin de salida y su registro de dirección. La librería usa estos nombres.

// PINES DE LOS SERVOS
#define servo1 LATC0
#define servo2 LATC1
#define servo3 LATC2
#define servo4 LATC3
#define servo5 LATC4
#define servo6 LATC5
#define servo7 LATB4
#define servo8 LATB5

#define servo1_direction TRISC0
#define servo2_direction TRISC1
// ... hasta servo8_direction TRISB5

#include "Servos_T1.h"
Fase 2

Programa

2.1

Iniciar

▶ 7:17

init_servos recibe el pulso mínimo y máximo en milisegundos (no más de 2,5 ms) y luego se habilitan las interrupciones globales.

init_servos(0.5, 2.5);  // inicia servos en los rangos mínimo y máximo
GIE = 1;                // habilita interrupciones globales
2.2

Mover los servos

▶ 8:20

servo_valor(número, ángulo) recibe de -90 a 90 grados. Con un for se hace un barrido escalonado.

for (angulo = -90; angulo <= 90; angulo = angulo + 10)
{
  servo_valor(2, angulo);
  __delay_ms(200);
}

for (angulo = 90; angulo >= -90; angulo = angulo - 10)
{
  servo_valor(3, angulo);
  __delay_ms(200);
}

servo_valor(1, 0);
servo_valor(4, 45);
servo_valor(5, -45);
servo_valor(6, 90);
servo_valor(7, -90);
servo_valor(8, 20);
2.3

Interrupción

▶ 9:00

La función de interrupción de XC8 solo llama a la de la librería.

void interrupt interrupcion(void)   // interrupt function
{
  servos_interrupcion();
}
2.4

La librería

▶ 9:34

init_servos limita el máximo, calcula el paso por grado, pone los pines como salida y en bajo, y habilita la interrupción del Timer1.

2.5

Prueba

▶ 10:44

En Proteus cada servo va al ángulo indicado y los dos del for hacen el barrido.
