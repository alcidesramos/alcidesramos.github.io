PWM de motor control en dsPIC

El dsPIC33FJ32MC202 trae un módulo PWM para control de motores con tres pares de salidas (PWM1H/L). En este micro el ciclo útil es uno por par: el pin H y el L de un par solo pueden ir iguales, invertidos (complementarios) o desfasados. Se configura la base de tiempo con P1TPER = 12499 y prescaler 64 para 50 Hz, modo continuo ascendente, salidas independientes y actualización inmediata del ciclo útil. Se prueba el modo complementario, útil para inversores, y luego se copian las funciones de servo y PWM de la clase anterior usando P1DC1 y P1DC2, que cuentan al doble de resolución.

Fase 2

Configuración

2.1

Librería CONFIG_PWM_F

▶ 3:49

Se agrega la librería al proyecto. Pone los pines RB12 a RB15 como salida y limpia P1TCON. El periodo va en P1TPER, que es de 15 bits.

#include "CONFIG_PWM_F.h"

void pwm_fast_init()
{
  //salida pines PWM
  TRISB12_bit=0;
  TRISB13_bit=0;
  TRISB14_bit=0;
  TRISB15_bit=0;

  P1TCON=0;  //limpia todos los bits
  P1TPER=12499;  //carga el periodo;
  P1TCONbits.PTEN=1; //Habilita el timer
  P1TCONbits.PTOPS=0B0000; // POSTPRESCALADOR DE SALIDA EN CERO 0-16 =0

2.3

Modo y salidas

▶ 6:39

Prescaler 64, modo continuo ascendente, pares en modo independiente y salidas L1 y L2 habilitadas como PWM. Las salidas H quedan libres como pines normales.

  //PREESCALDOR EN 64
  P1TCONbits.PTCKPS=0B11; // PREESCALSOR DE ENTRRADA 1 =64
  //SE PUEDEN OPTENER LA MITAD DE LA FREUENCIA SI ESTA EN MODO UP/DOWN
  P1TCONbits.PTMOD=0B00; // OPERA EN MODO CONTINUO  CONTADOR ASCENDENTE

  //MODO DE OPERACION DEL MODULO PWM
  PWM1CON1=0;
  PMOD1_bit=1; //PWM1x1 EN MODO INDEPENDIENTE
  PMOD2_bit=1; // PWM1x2 EN MODO INDEPENDIENTE
  PEN1L_bit=1; // HABILITA SALIDA PWM1L1 COMO PWM
  // PEN1H_bit=1; // HABILITA SALIDA PWM1H1 COMO PWM
  PEN2L_bit=1; // HABILITA SALIDA PWM1L2 COMO PWM
  //PEN2H_bit=1; // HABILITA SALIDA PWM1H2 COMO PWM
2.4

Ciclo útil

▶ 8:18

El ciclo útil se actualiza de inmediato y los pines quedan a cargo del módulo. Con Excel, 1 ms da 1249 y 10 ms (50 %) da 12499. Los tiempos muertos y fallas no se configuran por ahora.

  // SEGUNDO REGISTRO DE CONFIGURACION
  PWM1CON2=0;
  PWM1CON2bits.IUE=1; // ACTUALIZA LOS CICLO UTIL DE INEMDIATO
  //LOS PINES PWM LOS CONTOLA EL MODULO PWM
  POVD1L_bit=1;
  POVD1H_bit=1;
  POVD2L_bit=1;
  POVD2H_bit=1;
  // POR EL MOMENTO NO SE CONFIGRAN LOS REGISTOS DE TIEMPO MUERTO NI DE FALLAS
  // CARGA EL CICLO UTIL;
  P1DC1=1249;
  P1DC2=12449; //CICLO UTIL AL 50%
}

2.6

Modo complementario

▶ 10:31

Con PMOD en 0 el par queda complementario: cuando un pin sube el otro baja. Sirve para conmutar MOSFET en inversores de DC a AC. Luego se vuelve al modo independiente.

3.1

Funciones nuevas

▶ 13:14

Se copian las funciones de la clase 6 como servo3, servo3_ecu y pwm3 (y las 4 para el segundo par). Ahora se escribe en P1DC1, que cuenta al doble, por eso aparece el factor 2.

void servo3(float angulo)
{
  angulo=map(angulo,-90.0,ser_min,90.0,ser_max);
  PDC1=angulo*(float)P1TPER*2.0/20.0;
}

void servo3_ecu(float angulo)
{
  PDC1= 6.9444*angulo + 1874.0;
}

void pwm3(float ancho)
{
  PDC1=ancho*(float)P1TPER*2.0/100.0;
}

3.4

Los dos módulos a la vez

▶ 18:12

El while mueve dos servos igual, uno con output compare y otro con motor control, y baja los PWM al terminar cada barrido.

while (1)
{
  PWM2(90); //90 %
  PWM4(90); //90 %
  for (cuenta=-90;cuenta<=90;cuenta+=5)
  {
  // servo1(cuenta);
  servo1_ecu(cuenta);
  servo3_ecu(cuenta);
  Delay_ms(50);
  }
  // ... baja el porcentaje de PWM2 y PWM4
}
3.5

Tiempo muerto

▶ 20:57

El módulo también tiene control de tiempo muerto: un retardo entre que una salida baja y la otra sube para que los MOSFET no conduzcan a la vez. Es clave en convertidores DC-DC e inversores.
