STM32CubeMonitor como datalogger

Además de ver los datos, a veces se necesita guardarlos para analizarlos después (por ejemplo para identificar un motor en MATLAB). Se activa el registro en el nodo de variables, se crea la variable de entorno LOGPATH en Windows con la carpeta donde se guardan los archivos y se revisa el CSV en Excel. Al final se cambia la frecuencia de muestreo.

Fase 1

Activar el registro

1.1

Log all values

▶ 0:33

Doble clic en el nodo de procesamiento de myVariables. En Log option elige Log all values (o Log only changes si se repiten muchos datos) y el formato CSV de varias columnas para abrirlo en Excel.

Fase 2

Dónde se guarda

2.1

Crear la variable de entorno

▶ 1:37

CubeMonitor no guarda hasta que se le dice dónde. En Windows busca Editar las variables de entorno, pulsa Nueva y crea:

  • Nombre: LOGPATH
  • Valor: la carpeta donde quieres los archivos (por ejemplo D:\guarda)
2.2

Adquirir y revisar

▶ 2:48

Haz DEPLOY, Start y Stop. Cada adquisición crea un archivo nuevo con fecha y hora en esa carpeta, con columnas de tiempo, codigo y voltaje.

Si acabas de crear LOGPATH, cierra y vuelve a abrir CubeMonitor para que la tome.

Fase 3

Frecuencia de muestreo

3.1

Cambiar la frecuencia

▶ 3:53

En myVariables, Acquisition parameters → Sampling frequency: sequential loop, 0.1 Hz, 1 Hz, 10 Hz, 100 Hz, 1000 Hz o una personalizada. Con 1 kHz el archivo muestra datos cada pocos milisegundos.

3.2

Para qué sirve

▶ 5:00

Con los datos y su tiempo se puede graficar en MATLAB, identificar la planta y calcular un PID, sin enviar nada por el puerto serial: todo va por el programador.
