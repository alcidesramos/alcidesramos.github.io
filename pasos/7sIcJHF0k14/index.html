UART idle line en CCS

Es el mismo método de línea libre (idle line) hecho antes en MikroC, ahora en CCS. La interrupción serial guarda cada byte en un arreglo y reinicia el Timer0; si el timer alcanza a desbordar es porque no llegaron más datos, entonces se marca la trama como completa y se apaga la recepción. En el while se imprime la trama, se busca el texto led= y luego on para prender o apagar un LED, se limpia el buffer y se vuelve a habilitar la recepción. Se prueba en Proteus con el terminal Hercules y se compara la memoria con MikroC.

Timer0 de 8 bits

▶ 1:50

El Timer0 se configura interno, de 8 bits y con prescaler 32: desborda en unos 8,1 ms. Ese es el tiempo de silencio que marca el fin de una trama a 9600 baudios.

2.2

Interrupción serial

▶ 3:45

Cada byte se guarda en el arreglo y se reinicia el Timer0. Mientras sigan llegando datos, el timer nunca alcanza a desbordar.

#INT_RDA
void RDA_isr(void){
  dato_rx=getc();
  trama_rx[cont_trama]=dato_rx;
  cont_trama++;
  if (cont_trama>=50) cont_trama=0;
  set_timer0(0);
  setup_timer_0(RTCC_INTERNAL|RTCC_DIV_32|RTCC_8_BIT);
  clear_interrupt(INT_TIMER0);
  enable_interrupts(INT_TIMER0);
}
2.3

Fin de trama por Timer0

▶ 5:00

Si el Timer0 desborda, la línea quedó libre: se levanta la bandera, se reinicia el contador y se apagan la recepción y el timer hasta procesar la trama.

#INT_TIMER0
void TIMER0_isr(void){
  flag_rx=1;
  cont_trama=0;
  disable_interrupts(INT_RDA);
  disable_interrupts(INT_TIMER0);
  setup_timer_0(T0_OFF);
  clear_interrupt(INT_TIMER0);
}
2.4

Procesar el comando

▶ 6:10

En el while se imprime la trama y se busca led= y luego on. CCS guarda las constantes en ROM, así que strstr no acepta el texto directo: primero se copia a una cadena en RAM con strcpy. Al final se limpia el buffer y se vuelve a habilitar la recepción.

setup_adc_ports(NO_ANALOGS, VSS_VDD);
// setup_timer_0(...) como en el asistente
enable_interrupts(INT_RDA);
enable_interrupts(GLOBAL);
printf("INICIANDO\r\n");

while(TRUE){
  if(flag_rx==1){
    cont_trama=0;
    printf(trama_rx);
    strcpy(texto,"led=");
    if(strstr(trama_rx,texto)){
      strcpy(texto,"on");
      if(strstr(trama_rx,texto)) output_bit(PIN_C1,1);
      else output_bit(PIN_C1,0);
    }
    memset(trama_rx,0,50);
    clear_interrupt(INT_RDA);
    enable_interrupts(INT_RDA);
    flag_rx=0;
  }
  output_toggle(PIN_C0);
  delay_ms(300);
}
Fase 3

Prueba y comparación

3.1

Comparación con MikroC

▶ 7:50

El programa de MikroC hace lo mismo escribiendo en los registros. En memoria, CCS usa 6 % de RAM y 2 % de ROM; MikroC, 4,3 % de RAM y 2,7 % de ROM.

3.2

Simulación con Hercules

▶ 9:20

Desde Hercules se mandan tramas de cualquier largo. El micro devuelve la trama completa y con led=on o led=off prende o apaga el LED, mientras el otro LED sigue parpadeando.
