PWM básico con output compare en XC16

Se arma el proyecto desde cero en MPLAB X con las librerías de PWM y de interrupciones, el oscilador interno con PLL a 80 MHz y el remapeo de OC1 y OC2 a RP2 y RP3. El Timer2 con prescaler 64 y PR2 de 12500 da los 50 Hz del servo. Se reutilizan las funciones del UART de la clase de serial, se crea map para pasar de ángulo a milisegundos y funciones de porcentaje para motor DC. Al final se muestra cómo sacar en Excel la ecuación del servo con una línea de tendencia y se hace el barrido completo.

  • MPLAB X con XC16

1.3

Librería de PWM

▶ 3:19

La hoja de Excel dice que para 50 Hz a 80 MHz sirve el prescaler 64 con PR2 de 12500. OCTSEL en 0 trabaja con el Timer2 y en 1 con el Timer3. El ciclo útil arranca en 6250, el 50 %.

#include "xc.h"

void pwm_init_basico()
{
//configuracion timer 2
TMR2=0;
PR2=12500;// para 50HZ = 20 ms manejo de servos
//limpia el registro de configuracion
T2CON=0;
//preescalador  64
T2CONbits.TCKPS=0B10;

 T2CONbits.TON=1; // prende el timer 2

//modulo pwm   oc1
    OC1CON=OC2CON=0;
    OC1CONbits.OCTSEL= OC2CONbits.OCTSEL=0;   //trabaja con timer2  sino timer 3

   OC1RS=OC1R=OC2RS=OC2R=6250;      //registro ancho pulso

    //lo habilita como PWM
    // ...
}

const float ser_min=1.0; // tiempo minimo en milisegundo de movimiento del servo
const float ser_max=2.0; // tiempo maximo en milisegundo de movimiento del servo
signed char cuenta;

float salida1, salida2; //salidas pwm

float map(float x_in, float x1_, float y1_, float x2_, float y2_)
{
float pendiente;
  pendiente=(y2_ - y1_) / (x2_ - x1_);
  pendiente=pendiente*(x_in- x1_);
  pendiente=pendiente+y1_;
  return( pendiente);
}

3.1

Funciones de servo y porcentaje

▶ 8:25

servo1 pasa el ángulo de −90 a 90 a milisegundos con map y lo divide entre los 20 ms del periodo. pwm2 da el porcentaje sobre PR2 para el motor DC.

void servo1(float angulo)
{
  angulo=map(angulo,-90.0,ser_min,90.0,ser_max);
  OC1RS=angulo*(float)PR2/20.0;
}

void pwm1(float ancho)
{
  OC1RS=ancho*(float)PR2/100.0;
}

void servo2(float angulo)
{
  angulo=map(angulo,-90.0,ser_min,90.0,ser_max);
  OC2RS=angulo*(float)PR2/20.0;
}

void pwm2(float ancho)
{
  OC2RS=ancho*(float)PR2/100.0;
}

Programa completo

▶ 14:47

El servo hace el barrido de −90 a 90 de 5 en 5 grados con la ecuación, cada 50 ms, y el motor DC cambia de porcentaje. Con un retardo extra se alcanza a ver el cambio en el osciloscopio.

habilita();
while (1)
{
   // servo1_ecu(0);
   servo1(-90); // angulo  1ms

   for (cuenta=-90;cuenta<=90;cuenta+=5)
   {
   // servo1(cuenta);
      servo1_ecu(cuenta);
      __delay_ms(50);// velocidad paso a paso
   }
   pwm2(20);  //porcentaje
}
