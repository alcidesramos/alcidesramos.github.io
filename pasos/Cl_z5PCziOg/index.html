Reloj de tiempo real RTC en el STM32

El STM32F401 trae reloj de tiempo real incorporado: no hace falta un DS1307 ni otro módulo. Se activa el cristal LSE de 32.768 kHz, el RTC con calendario en formato binario y una hora y fecha iniciales. Proteus no lo simula, así que se hace en la tarjeta real. El problema: en cada reset la hora vuelve al valor inicial. La solución es escribir un número cualquiera en un registro de backup la primera vez y, si ya está, no volver a configurar la hora. Con una pila en VBAT el reloj sigue aunque se quite la alimentación.

▶ Ver el video completo (14:09) Empezar el paso a paso
  • Black Pill STM32F401CCU6 (trae el cristal de 32.768 kHz en PC14/PC15)
  • Pila CR2032 o cualquier pila plana de 3 V con su base, conectada a VBAT
  • ST-Link y conversor USB serial

Fase 1

Configuración

1.1

Pila de respaldo

▶ 0:00

La pila de 3 V va al pin VBAT del micro. Mientras tenga pila, el RTC sigue contando aunque el micro se quede sin alimentación.

1.2

Cristales HSE y LSE

▶ 1:35

En RCC se activan High Speed Clock (HSE) y Low Speed Clock (LSE) como Crystal/Ceramic Resonator. El LSE es el cristal de 32.768 Hz (2^15) de los pines 14 y 15: dividiéndolo, el micro obtiene exactamente un segundo.

1.3

Activar el RTC

▶ 2:43

En Timers, RTC: Activate Clock Source y Activate Calendar. Las alarmas quedan para otra clase. Con Calibration en 1 Hz el RTC saca un pulso por segundo por PC13 (RTC_AF1); como ahí está el LED de la tarjeta, se verá parpadear cada segundo. Es opcional.

1.4

Reloj del RTC y del sistema

▶ 3:48

En Clock Configuration, el RTC Clock Mux debe tomar el LSE. Con el oscilador interno (LSI) se pierde la hora al apagar. El sistema va con HSE y PLL a 84 MHz. USART1 asíncrono a 9600.

1.5

Hora y fecha iniciales

▶ 4:59

En los parámetros del RTC:

  • Data Format: Binary data format (más fácil que BCD).
  • Hours 10, Minutes 20, Seconds 30.
  • Day Light Saving: sin ajuste (solo para países con horario de verano).
  • Store Operation: Reset.
  • Week Day: Friday; Month: October; Date: 17; Year: 23 (dos cifras).
Fase 2

Leer la hora

2.1

Variables y while

▶ 8:31

Se crean una estructura para la hora y otra para la fecha. En el while se leen, se les da formato con dos dígitos y se envían por la UART.

/* USER CODE BEGIN PV */
RTC_TimeTypeDef tiempo;
RTC_DateTypeDef fecha;
char texto[50];

/* USER CODE BEGIN 2 */
uartx_write_text(&huart1, "INICIANDO\r\n");

while (1)
{
  HAL_RTC_GetTime(&hrtc, &tiempo, RTC_FORMAT_BIN);
  HAL_RTC_GetDate(&hrtc, &fecha, RTC_FORMAT_BIN);
  sprintf(texto, "%02d:%02d:%02d   %02d/%02d/20%02d\r\n",
          tiempo.Hours, tiempo.Minutes, tiempo.Seconds,
          fecha.Date, fecha.Month, fecha.Year);
  uartx_write_text(&huart1, texto);
  HAL_Delay(950);
}

Llama a HAL_RTC_GetTime antes que a HAL_RTC_GetDate: leer la hora bloquea los registros hasta que se lee la fecha.

2.2

El problema del reset

▶ 10:13

Funciona, pero al resetear el micro la hora vuelve a 10:20:30, aunque tenga la pila. MX_RTC_Init vuelve a escribir la hora inicial cada vez que arranca.

Fase 3

Registro de backup

3.1

Configurar la hora solo una vez

▶ 10:46

Dentro de MX_RTC_Init, en USER CODE BEGIN Check_RTC_BKUP, se lee el registro de backup DR0. Si ya tiene el número de control (aquí 0x1017, cualquiera de 32 bits sirve), se recuperan hora y fecha y se sale sin configurar. Si no, se sigue con la configuración inicial y al final se escribe el número.

/* USER CODE BEGIN Check_RTC_BKUP */
// verifica si ya se guardó el dato en el registro de respaldo
if (HAL_RTCEx_BKUPRead(&hrtc, RTC_BKP_DR0) == 0x1017)
{
  // si ya está, recupera la hora y la fecha del RTC y no vuelve a iniciar
  HAL_RTC_GetDate(&hrtc, &sDate, RTC_FORMAT_BIN);
  HAL_RTC_GetTime(&hrtc, &sTime, RTC_FORMAT_BIN);
  return;
}
HAL_RTCEx_BKUPWrite(&hrtc, RTC_BKP_DR0, 0x1017);
/* USER CODE END Check_RTC_BKUP */

/* luego sigue el código generado: sTime.Hours = 10; ... HAL_RTC_SetTime(...); HAL_RTC_SetDate(...); */

Los registros de backup conservan su valor mientras haya pila en VBAT. Si quitas la pila y la alimentación, se borran y el reloj vuelve a la hora inicial.

3.2

Prueba

▶ 12:27

Ahora, al quitar los 5 V y volver a conectarlos, la hora sigue donde iba (de :44 salta a :58). Solo si se desconecta todo, incluida la pila, vuelve a 10:20:30.

El LED de PC13 parpadea cada segundo con la salida de calibración del RTC.
