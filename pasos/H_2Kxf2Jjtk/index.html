Buque por radio con dsPIC y XBee

El dsPIC trabaja a 80 MHz con el oscilador interno y PLL (con el interno de 7.37 MHz PLLFBD es 41; con cristal de 4 MHz, 78). El UART y los PWM se remapean a los pines que se quieran. La interrupción del UART usa una máquina de estados que espera I, N, I y luego guarda todo hasta el *, con un límite de 50 datos; entonces activa una bandera. procesa_rx1 separa con strtok la dirección, la velocidad y los dos LEDs. La dirección va directo al servo 1 y la velocidad (0 a 100) se escala a 0 a 90 para el variador. En XCTU se configuran los XBee serie 1 con el mismo canal y red, y sus direcciones de origen y destino cruzadas.

Preparar el dsPIC

La trama

Proyecto

dsPIC33FJ32MC202 a 80 MHz. Oscilador interno rápido con PLL, primario deshabilitado y la opción de múltiples reconfiguraciones de pines.

1.3

Librerías y variables

▶ 3:57

Se agregan las librerías propias de interrupciones, PWM y la del UART con trama. Se declaran la trama, la bandera y los LEDs.

1.4

Servos

▶ 5:37

Cada servo convierte el ángulo en el valor del registro del PWM con la ecuación explicada en el video de PWM.

sbit led1 at RB0_bit;
sbit led2 at RB1_bit;

float serv1, serv2;

void servo1(float angulo)
{
  OC1RS = 3.4722*angulo + 937.5;
}

void servo2(float angulo)
{
  OC2RS = 3.4722*angulo + 937.5;
}
1.5

Remapear pines

▶ 6:56

Todo digital, puertos como salida y con PPS_Mapping el UART en RP13 y RP14 y los PWM en RP2 y RP3.

AD1PCFGL = 0xFFFF;   //1=digital 0=analogo
TRISA = 0;           //todo salida A
TRISB = 0;           //salida todo B
//REMAPEAMOS SALIDA SERIAL
PPS_Mapping(13, _OUTPUT, _U1TX);
PPS_Mapping(14, _INPUT, _U1RX);
//REMAPEO PWM
PPS_Mapping(2, _OUTPUT, _OC1);
PPS_Mapping(3, _OUTPUT, _OC2);
pwm_init_basico();
Fase 2

Recibir la trama

2.1

Máquina de estados

▶ 8:07

En la interrupción del UART se espera la I, luego la N, luego la I; si algo no coincide se vuelve al inicio. En el estado final se guarda todo hasta el *, y entonces se activa flag_rx1. Si pasan 50 datos sin *, se reinicia.

2.2

Probar la recepción

▶ 10:59

En el ciclo, si hay trama se reenvía por serial, se limpia y se habilita otra vez la interrupción. Con un puerto virtual entre LabVIEW y Proteus se ve llegar la trama.

2.3

Sacar los valores

▶ 13:16

Con strtok se separa cada campo por /. La dirección y la velocidad se convierten con atof y los LEDs con atoi. Para más datos, se copia y pega otra captura.

void procesa_rx1()
{
  // INI=/DIR/VEL/L1/L2/*
  strcpy(Captura_rx1, strtok(Trama_rx1, "/"));  //inicia captura de tokens desde el /
  strcpy(Captura_rx1, strtok(0, "/"));          //captura hasta el 1 dato
  serv1 = atof(Captura_rx1);
  strcpy(Captura_rx1, strtok(0, "/"));          //captura hasta el 1 dato
  serv2 = atof(Captura_rx1);
  strcpy(Captura_rx1, strtok(0, "/"));
  led1 = atoi(Captura_rx1);
  strcpy(Captura_rx1, strtok(0, "/"));
  led2 = atoi(Captura_rx1);
}
2.4

Mover los servos

▶ 15:27

servo1 recibe la dirección. La velocidad (0 a 100) se multiplica por 90.0 y se divide entre 100 para llevarla de 0 a 90 grados, que el variador entiende como de quieto a máxima velocidad.

2.5

Oscilador interno

▶ 16:35

Si no responde, revisar el PLL: con el oscilador interno de 7.37 MHz el multiplicador es 41 para llegar a 80 MHz; con cristal de 4 MHz sería 78.

CLKDIVbits.PLLPRE = 0;    // N1 = 2
CLKDIVbits.PLLPOST = 0;   // N2 = 2
PLLFBD = 41;              // con oscilador interno de 7.37 MHz (78 con cristal de 4 MHz)
2.6

Funcionando

▶ 17:47

Al mover el joystick se mueven los dos servos y los botones prenden los LEDs, todo al mismo tiempo.

Fase 3

Por radio con XBee

3.1

XCTU

▶ 18:56

Se recomiendan los XBee serie 1 o serie 3, que tienen menos retardo que los serie 2. En XCTU se buscan los módulos en sus puertos.

3.2

Configuración

▶ 21:11

Los dos deben tener el mismo canal y la misma red (PAN ID). Cada uno tiene su dirección y transmite a la del otro, para que nadie más maneje el buque. Se bajan a 9600 baudios para la simulación.

3.3

Prueba real

▶ 23:26

LabVIEW envía por el XBee del computador y el del buque entrega la trama al dsPIC: el control mueve la dirección, la velocidad y las luces de forma inalámbrica.
