Librería para varios encoders

Con la librería encoder.c/.h cada encoder es una estructura ENCODERS asociada a un timer. Se declara en encoder.c, se inicializa con Encoder_init indicando 4X, 2X o 1X, la librería atiende la interrupción de captura y Encoder_velo (llamada desde el SysTick) calcula la velocidad. Se lee la perilla en el TIM3 y luego se agrega el encoder del motor en el TIM1.

▶ Ver el video completo (15:56) Empezar el paso a paso
  • STM32F411 (Black Pill) a 100 MHz
  • Encoder tipo perilla en PA6/PA7 (TIM3) y encoder del motor en PA8/PA9 (TIM1)
  • Librerías encoder.c/.h y uart.c/.h
  • Conversor USB-serial (TX en PB6) y Hercules

2.2

Declarar el encoder en encoder.c

▶ 5:00

Declara como externo el handle del timer y crea la estructura ENCODERS con el handle y la instancia. El .h ya trae extern para ENCODER1 a ENCODER4; el nombre y el timer no tienen que coincidir en número.

//incluir los timer usados
extern TIM_HandleTypeDef htim3;

//configura encoder a usar
ENCODERS ENCODER1 = {&htim3, TIM3};
2.3

Interrupción incluida en la librería

▶ 5:33

La librería ya contiene HAL_TIM_IC_CaptureCallback. Hay un bloque if por cada encoder; para el segundo se descomenta y se cambia al ENCODER2.

void HAL_TIM_IC_CaptureCallback(TIM_HandleTypeDef *htim)
{
    //agregar por cada encoder usado
    if (htim->Instance == ENCODER1.TIMX)
    {
        ENCODER1.pulsos = __HAL_TIM_GET_COUNTER(htim);
        ENCODER1.posicion = (int16_t)ENCODER1.pulsos / ENCODER1.resolucion;
        ENCODER1.velo = ENCODER1.posicion;
    }
}
2.4

Velocidad en Encoder_velo

▶ 6:49

En Encoder_velo hay tres líneas por cada encoder cuya velocidad quieras calcular; el procedimiento siempre termina limpiando el contador. Se calcula cada 500 ms.

void Encoder_velo()
{
    encoder_velo++;
    if (encoder_velo > 500)
    {
        //repetir por cada encoder que se quiera saber velocidad
        ENCODER1.velo = ENCODER1.velo - ENCODER1.velo_ant;
        ENCODER1.velo_ant = ENCODER1.velo;
        ENCODER1.velocidad = ENCODER1.velo / 0.5;  //500 ms

        //va al final
        encoder_velo = 0;  //limpia el encoder
    }
}
2.5

Llamar desde el SysTick

▶ 7:57

En Core/Src/stm32f4xx_it.c incluye encoder.h y llama a Encoder_velo() dentro de SysTick_Handler.

/* USER CODE BEGIN Includes */
#include "encoder.h"
/* USER CODE END Includes */

void SysTick_Handler(void)
{
    /* USER CODE BEGIN SysTick_IRQn 0 */
    Encoder_velo();
    /* USER CODE END SysTick_IRQn 0 */
    HAL_IncTick();
}
Fase 3

Usarla en main

3.1

Inicializar y leer

▶ 8:32

Antes del while inicializa el encoder con su resolución (4 para 4X, 2 para 2X o 1). Encoder_init arranca el timer en modo encoder con interrupción. Luego solo se leen los campos posicion y velocidad de la estructura.

char texto[100];

Encoder_init(&ENCODER1, 4);  // inicializo encoder 1 a 4x

while (1)
{
    sprintf(texto, "Pos=%d  vel1=%.1f\r\n\r\n", ENCODER1.posicion, ENCODER1.velocidad);
    uartx_write_text(&huart1, texto);
    HAL_Delay(100);
}

Probar

▶ 11:20

Fase 4

Segundo encoder

4.1

TIM1 en modo encoder

▶ 11:53

Configura TIM1 en Encoder Mode con TI1 and TI2 y habilita la interrupción de capture compare.

4.2

Declararlo en la librería

▶ 12:27

En encoder.c agrega el extern de htim1 y la estructura ENCODER2. Descomenta el if del ENCODER2 en el callback y copia las tres líneas de velocidad para el ENCODER2 en Encoder_velo.

extern TIM_HandleTypeDef htim1;
extern TIM_HandleTypeDef htim3;

ENCODERS ENCODER1 = {&htim3, TIM3};
ENCODERS ENCODER2 = {&htim1, TIM1};

// en el callback
if (htim->Instance == ENCODER2.TIMX)
{
    ENCODER2.pulsos = __HAL_TIM_GET_COUNTER(htim);
    ENCODER2.posicion = (int16_t)ENCODER2.pulsos / ENCODER2.resolucion;
    ENCODER2.velo = ENCODER2.posicion;
}

Si aparece 'htim1 undeclared', falta descomentar o agregar la línea extern TIM_HandleTypeDef htim1; en encoder.c.

4.3

Inicializar y mostrar ambos

▶ 14:07

En main inicializa el ENCODER2 con la misma línea y agrega sus campos al sprintf.

Encoder_init(&ENCODER1, 4);  // inicializo encoder 1 a 4x
Encoder_init(&ENCODER2, 4);  // inicializo encoder 2 a 4x

sprintf(texto, "Pos1=%d  vel1=%.1f  Pos2=%d  vel2=%.1f\r\n",
        ENCODER1.posicion, ENCODER1.velocidad,
        ENCODER2.posicion, ENCODER2.velocidad);
