Clase 32: mostrar variables con sprintf

Hasta ahora escribíamos texto fijo. Con sprintf de stdio.h guardamos en un arreglo el texto ya formateado de una o varias variables y luego lo mostramos con Lcd_Text. Consume bastante memoria, así que conviene un Cortex-M3 o superior.

Fase 1

Preparar

1.1

La tabla de formatos

▶ 0:32
  • %u entero sin signo (16 bits), %d o %i con signo
  • %lu / %ld para 32 bits
  • %o octal, %x / %X hexadecimal
  • %f flotante, %e / %E notación científica
  • %c carácter, %s cadena
  • Flags: - justifica a la izquierda, + fuerza el signo, # pone 0x en hex, 0 rellena con ceros
  • Un número es el ancho mínimo; .n es la cantidad de decimales
1.2

Librerías y arreglo de texto

▶ 1:37

Incluye stdio.h y string.h y declara un arreglo donde sprintf guardará el texto (con 50 posiciones vas sobrado):

#include "stdio.h"
#include "string.h"
char texto[50];
1.3

Lo básico

▶ 2:46
sprintf(texto, "HOLA MUNDO");
Lcd_Text(2, 1, texto);
Fase 2

Enteros

2.1

Entero sin signo

▶ 3:56

Crea variables de prueba (uint16_t, int16_t, float y una cadena) y muestra un contador:

sprintf(texto, "CNT1=%u", cont8);
Lcd_Text(2, 1, texto);
cont8++;
Delay_ms(200);
2.2

Ancho, ceros y hexadecimal

▶ 5:37

%3u reserva 3 posiciones, %03u rellena con ceros, %-3u justifica a la izquierda. %X muestra en hexadecimal y %#X le agrega el 0x.

sprintf(texto, "CNT1=%#03X", cont8);
2.3

Con signo

▶ 7:54

Para una variable con signo usa %d. Con %+d siempre aparece el signo, + o −.

sprintf(texto, "CNT2=%3d", cont8s);
Lcd_Text(3, 1, texto);
cont8s--;
2.4

Varias variables en una línea

▶ 9:48

Cada formato toma la variable que le corresponde, en orden. Cuida que el formato coincida con el tipo (%u sin signo, %d con signo) y que quepa en el display.

sprintf(texto, "CNT1=%-u CNT1=%3d", cont8, cont8s);
2.5

Cadenas

▶ 12:03
sprintf(texto, "CNT2=%s", ok);   // ok es un arreglo char
Lcd_Text(4, 1, texto);
Fase 3

Flotantes

3.1

El float no sale

▶ 12:37

Por defecto STM32CubeIDE usa una versión reducida de la librería (newlib-nano) sin soporte de float en printf, para ahorrar memoria.

sprintf(texto, "CNTf=%f", contf);
Lcd_Text(4, 1, texto);
contf += 0.65;
3.2

Habilitar float en sprintf

▶ 13:43

Clic derecho en el proyecto → Properties → C/C++ Build → Settings → MCU Settings y marca Use float with printf from newlib-nano (-u _printf_float). Si también lo necesitas para scanf, marca la otra casilla. Apply and Close. El programa ocupa más memoria.

3.3

Limitar los decimales

▶ 14:16

%.2f deja 2 decimales. %4.2f además fija un ancho total de 4 caracteres, contando el punto y los decimales.

sprintf(texto, "CNTf=%.2f", contf);
