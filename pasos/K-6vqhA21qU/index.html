Crear e instalar librerías en MikroC

Lección 17 del curso. Con la librería de LCD por I2C de la clase anterior, ahora en un PIC12F1822 de 8 pines, se repasa cómo usarla agregando el .c al proyecto e incluyendo el .h. Luego se crea un paquete con el Package Manager de MikroC: nombre, autor, micros compatibles, dependencia de Software_I2C y archivos. Al instalarlo, la librería aparece en el Library Manager y basta marcarla. Por último se crea un paquete protegido con el archivo .mcl compilado, para que otros la usen sin ver ni cambiar el código.

Fase 1

La librería en un micro pequeño

1.1

LCD I2C con un PIC de 8 pines

▶ 0:00

La LCD por I2C se conecta a un PIC12F1822 en RA0 (SDA) y RA1 (SCL). Se crea el proyecto lcd12f1822 a 8 MHz con oscilador interno, sin watchdog ni monitor de reloj, y se configura como en la lección 14: oscilador interno a 8 MHz, PLL apagado, pines digitales y puerto como salida.

IRCF3_bit = 1;  IRCF2_bit = 1;
IRCF1_bit = 1;  IRCF0_bit = 0;   // 8 MHz
// SPLLEN_bit = 1;  // PLL x4 = 32 MHz
ANSELA = 0;   // todo digital
TRISA = 0;
LATA = 0;
1.2

Usarla con .c y .h

▶ 2:49

El .c se agrega en Project Manager > Sources y el .h se incluye en el programa. También hay que activar Lcd_Constants y Software_I2C. Así el programa principal queda corto.

#include "soft_i2c_lcd.h"

sbit Soft_I2C_Sda at RA0_bit;
sbit Soft_I2C_Scl at RA1_bit;
sbit Soft_I2C_Sda_Direction at TRISA0_bit;
sbit Soft_I2C_Scl_Direction at TRISA1_bit;
Fase 2

Crear el paquete

2.1

Sacar los archivos del proyecto

▶ 5:34

Se quitan del proyecto el .c y el .h, y se mueven a otra carpeta junto con el .mcl (la librería compilada que MikroC crea al compilar). Si se dejan en la carpeta del proyecto, a veces MikroC no reconoce la librería instalada.

2.2

Package Manager

▶ 6:42

En Tools > Package Manager se crea un paquete nuevo para MikroC PRO for PIC con nombre (por ejemplo lcd_i2c) y autor. Se agrega una librería, se le pone nombre y se escogen los micros: se pueden filtrar (por ejemplo solo los 12F) o marcar todos, aunque así tarda más en instalar.

2.3

Dependencias y archivos

▶ 7:54

Con clic derecho en Dependency se agrega Software_I2C, para que se active sola al marcar la librería. En Main Library File se agrega el .c y en Other Library Files el .h. Si se tiene, también se puede agregar un ejemplo y un archivo de ayuda. Luego se guarda el paquete (.mpkg).

2.4

Instalar y usar

▶ 9:32

Con doble clic al .mpkg (o el botón de instalar del Package Manager) se instala. Después, en el Library Manager, se pulsa Rebuild all available libraries y la librería aparece en Third Party Libraries. Basta marcarla: ya no hay que incluir el .h ni agregar el .c, y sale en cualquier proyecto nuevo.

Si se marca la librería y además se dejan los archivos en el proyecto, el compilador da error por funciones repetidas.

2.5

Ver el código de la librería

▶ 12:14

Con clic derecho sobre la librería instalada se puede ver la ayuda, los ejemplos, desinstalarla o abrir su código, que cualquiera puede leer y modificar.

Fase 3

Librería protegida

3.1

Paquete con el .mcl

▶ 12:45

Para que otros usen la librería sin ver el código, se crea otro paquete (por ejemplo lcd_i2c_protegida) igual al anterior, pero en Main Library File se pone el .mcl compilado en vez del .c. Se guarda y se instala.

3.2

Usar una u otra

▶ 14:24

Tras reconstruir las librerías aparecen las dos. Solo se puede marcar una, porque tienen las mismas funciones. En la protegida no aparece la opción de abrir el código. Cada quien escoge la que le convenga.
