Clase 112: Fuente conmutada en lazo abierto

Primera parte del proyecto de fuente conmutada (la segunda cierra el lazo con PID). Se arma un convertidor Buck con un MOSFET IRF540 disparado por un transistor 2N3904, inductor, diodo rápido y un divisor resistivo hacia el ADC. En CubeIDE se configura el TIM1 canal 1 como PWM a 100 kHz (periodo 840 con 84 MHz), en modo PWM2 y polaridad de reposo en alto para compensar la lógica invertida del transistor. Se lee el voltaje de salida con el ADC, se calcula el factor de escala real midiendo con el multímetro y se envía el valor por el puerto serial.

  • Blackpill STM32F401
  • MOSFET IRF540 y transistor 2N3904 como driver
  • Inductor de 470 µH, diodo rápido (1N5821) y condensadores de 470 µF
  • Divisor resistivo (33k / 4.7k) para llevar la salida a menos de 3.3 V
  • Fuente de 24 V y una resistencia de carga
  • Multímetro y analizador lógico para ver la señal
  • Librerías del canal: adc_x, uart y PWMB

Fase 1

El circuito

1.1

Esquema del convertidor Buck

▶ 0:35

El micro genera el PWM, lee el voltaje de salida con el ADC y usa el puerto serial para monitorear (y más adelante recibir el set point).

El disparo del MOSFET IRF540 se hace con un transistor NPN 2N3904. Esto invierte la lógica: cuando el micro saca un 1 el MOSFET se apaga.

El diodo y la bobina deben soportar la corriente que quieras en la salida. Para fuentes conmutadas se recomienda trabajar de 70-100 kHz hacia arriba.

El divisor R4/R5 lleva el voltaje de salida al ADC. Antes de conectarlo al micro verifica que nunca supere 3.3 V.

Conecta el divisor al micro solo después de medir que con el máximo ciclo útil no pasa de 3.3 V.

Fase 2

Proyecto y configuración

2.1

Calcular el periodo del PWM

▶ 2:40

Con la hoja de Excel del canal se pone la frecuencia del micro (84 MHz), el preescalador en 1 (se carga 0) y la frecuencia deseada de 100 kHz.

El resultado es un periodo de 840 cuentas, que es el valor que se carga en el Counter Period del timer.

El reloj se configura con cristal externo y PLL a la máxima velocidad del micro, pensando en el PID de la siguiente clase.

2.2

Agregar librerías e includes

▶ 4:10

Se crea la carpeta Librerias dentro de Core y se copian adc_x, uart y PWMB del canal.

Se agrega la carpeta al include path (clic derecho > Add/remove include path) y se incluyen también las librerías estándar que se usarán con el PID.

#include "uart.h"
#include "adc_x.h"
#include "PWMB.h"

#include "stdint.h"
#include "stdio.h"
#include "stdlib.h"
#include "math.h"
#include "string.h"
2.3

ADC y puerto serial

▶ 5:55

En Analog se habilita el ADC1 con un solo canal (IN0), sin más configuración.

En Connectivity se activa USART1 en modo asíncrono a 115200 baudios. Si el computador lo permite se puede subir para graficar más rápido.

2.4

TIM1 canal 1 en modo PWM2

▶ 6:50

TIM1 con reloj interno y Channel 1 como PWM Generation CH1 (queda en PA8). Prescaler 0 y Counter Period 840. Se deja el auto-reload preload habilitado.

Se cambia el modo a PWM mode 2: el ancho de pulso que se programa queda en el semiciclo negativo, que es el que enciende el MOSFET con lógica invertida.

La polaridad de reposo se deja en alto, que con lógica invertida equivale a apagado. Así al arrancar el micro no aparece voltaje en la carga.

Con un driver de disparo positivo (por ejemplo un IR2110) deja PWM mode 1. El código es el mismo, solo cambia el modo en CubeMX.

Fase 3

Generar el PWM

3.1

Configurar la librería PWMB

▶ 8:05

En PWMB.c se declara el PWM con el timer y canal usados: TIM1, canal 1.

La escala de la librería se pone en 1000 (la potencia de 10 más cercana a 840) para manejar el ancho de pulso de 0 a 1000.

float escala=1000;   // escala para trabajar el PWM
extern TIM_HandleTypeDef htim1;

PWMS PWM1 = {&htim1, &(TIM1->CCR1), TIM_CHANNEL_1};
3.2

Inicializar y dar un valor

▶ 8:40

Antes del while se escribe un mensaje por el serial, se inicia el PWM y se le da un valor.

Con un valor pequeño la salida queda casi en cero; con 900 el pulso negativo ocupa el 90% y la salida sube a unos 8 V. Con 1000 se obtiene el máximo (unos 20.9 V en este montaje).

uartx_write_text(&huart1, "INICIANDO\r\n");
PWM_init(&PWM1);
PWM_valor(&PWM1, 1000);

En el analizador lógico se ve la señal a 100 kHz con el ciclo útil invertido, que es lo esperado por el transistor.

Fase 4

Leer el voltaje de salida

4.1

Calcular el factor de escala

▶ 12:00

Las resistencias del divisor tienen tolerancia, así que el factor se saca midiendo: con el PWM al máximo se mide la salida (20.93 V) y el punto del divisor (2.57 V).

20.93 / 2.57 = 8.1439. Ese es el número por el que se multiplica el voltaje leído por el ADC para obtener el voltaje real.

4.2

Habilitar float en printf

▶ 14:30

Clic derecho en el proyecto > Properties > C/C++ Build > Settings > MCU Settings y se marca usar float con printf.

4.3

Código del lazo principal

▶ 14:50

Se declaran las variables para la cadena, el código del ADC y el voltaje.

Dentro del while se lee el ADC, se pasa a voltios, se multiplica por el factor y se envía por el puerto serial cada 500 ms.

char texto[50];
uint16_t codigo=0;
float voltaje=0;

while (1)
{
  codigo=ADC_Read(&hadc1);
  voltaje=codigo*3.3/4095.0;
  voltaje=voltaje*8.1439;
  sprintf(texto,"VOL=%.1f\r\n\r\n",voltaje);
  uartx_write_text(&huart1, texto);
  HAL_Delay(500);
}
4.4

Prueba

▶ 17:10

En Hercules se lee unos 20.8 V y el multímetro marca 20.9 V; la diferencia de 0.1 V se puede corregir ajustando el factor.

Con PWM_valor en 700 la salida baja a unos 5 V y el micro lee entre 4.7 y 4.95 V.

La relación ciclo útil-voltaje no es lineal; por eso en la siguiente clase se cierra el lazo con un PID para fijar el voltaje de salida.
