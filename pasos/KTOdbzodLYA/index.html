Lector RFID RC522 con PIC

El RC522 se conecta por SPI y trabaja a 3.3 V. Se usa una librería de terceros con SPI por software, así que el módulo puede ir en cualquier pin. El código leído (UID) se pasa por el algoritmo hash FNV, igual que con los controles infrarrojos, para tener un solo número por tarjeta. Se leen los códigos por serial, se ponen en el programa y cada tarjeta cambia el estado de un LED.

Proyecto

▶ 2:43

PIC18F2550 a 48 MHz con la configuración del bootloader. Todo digital, comparadores apagados, UART a 9600 y un mensaje de inicio.

ADCON1 = 0b1111;   // todo digital
CMCON = 7;         // apaga el comparador
TRISB = 0;
TRISC = 0;
TRISC.B7 = 1;      // entrada rx
UART1_Init(9600);
RCEN_bit = 1;      // recepcion continua
UART1_Write_Text("Iniciando\r\n");
Fase 2

Leer tarjetas

2.1

Pines del módulo

▶ 6:06

La librería usa SPI por software, así que se define en qué pines va cada señal. Se incluye RC522.h y se activa la librería Soft_SPI.

#include "RC522.h"
// conexion de modulo RFID usando SPI por software
sbit MFRC522_CS  at LATA0_bit;   // SDA
sbit MFRC522_Rst at LATA1_bit;   // RST
sbit SoftSPI_SDO at LATA2_bit;   // MOSI
sbit SoftSPI_CLK at LATA3_bit;   // SCK
sbit SoftSPI_SDI at RA4_bit;     // MISO
sbit MFRC522_CS_Direction  at TRISA0_bit;
sbit MFRC522_Rst_Direction at TRISA1_bit;
sbit SoftSPI_SDO_Direction at TRISA2_bit;
sbit SoftSPI_CLK_Direction at TRISA3_bit;
sbit SoftSPI_SDI_Direction at TRISA4_bit;

char texto[10];
char UID[10];            // almacena el buffer del codigo de rfid
unsigned int TagType;    // almacena el tipo de tag
2.2

Detectar la tarjeta

▶ 8:57

Se inician el SPI y el módulo. MFRC522_isCard dice si hay una tarjeta cerca.

2.3

Código único

▶ 10:38

MFRC522_ReadCardSerial llena el buffer UID. Se aplica el hash FNV a sus 5 datos, se pasa a hexadecimal y se envía por serial.

Soft_SPI_Init();    // inicia modulo SPI
MFRC522_Init();     // inicializa la tarjeta
while (1) {
  if (MFRC522_isCard(&TagType)) {
    if (MFRC522_ReadCardSerial(&UID)) {
      codigo_rfid = Hash_algoritmo();
      LongIntToHex(codigo_rfid, texto);
      UART1_Write_Text("CODIGO_RFID=");
      UART1_Write_Text(texto);
      UART1_Write('\r');
      UART1_Write('\n');
    }
  }
}
Fase 3

Controlar

3.1

Una acción por tarjeta

▶ 12:56

Con los códigos leídos se arma una cadena de if: cada tarjeta cambia un LED y envía su nombre. Se pueden agregar tantas tarjetas como se quiera para dar acceso.

if (codigo_rfid == 0x00000000) {        // codigo de la tarjeta 1
  led1 = ~led1;
  UART1_Write_Text("TAG1\r\n");
}
else if (codigo_rfid == 0x00000000) {   // codigo de la tarjeta 2
  led2 = ~led2;
  UART1_Write_Text("TAG2\r\n");
}
// ... tarjetas 3 y 4
codigo_rfid = 0;
Delay_ms(2000);
