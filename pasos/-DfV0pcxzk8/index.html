Onda seno de 60 Hz por PWM

La idea es sacar una seno de 60 Hz filtrando un PWM cuyo ciclo útil cambia según una tabla. Con 120 muestras por ciclo, la interrupción debe ocurrir 7200 veces por segundo. En el MCC se pone el oscilador externo de 20 MHz, el CCP1 en modo PWM sobre el Timer2 y la interrupción del Timer2; el cálculo de periodo y preescalador se revisa en Excel. La salida va a RC0. El vector con la onda viene de MATLAB y se declara en main.c; en tmr2.c se usa con extern. La rutina del Timer2 avanza el índice y carga el nuevo ciclo útil. El ciclo principal queda vacío. En Proteus la señal pasa por dos filtros RC, un LM358 y una etapa push-pull.

2.3

Variables con extern

▶ 9:03

La interrupción está en tmr2.c, otro archivo. Para usar las variables de main.c sin declararlas otra vez se usa extern.

// en tmr2.c
extern const muestras;
extern unsigned int onda[];
extern unsigned int es, toca;
2.4

Rutina del Timer2

▶ 10:12

En cada interrupción se avanza en la tabla y se carga el nuevo ciclo útil del PWM.

void TMR2_DefaultInterruptHandler(void)
{
  toca++;
  if (toca >= muestras - 1) toca = 0;
  es = onda[toca];
  // se carga es como ciclo útil del PWM
}
