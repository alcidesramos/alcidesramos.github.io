Clase 118: Sintonizar el PID con datos de entrada y salida

Quinto capítulo de la serie del motor DC. La identificación con un solo escalón dio alrededor de 78-83% de ajuste; aquí se usan datos más ricos. Sin PID, el potenciómetro se mapea directo a la entrada del motor (0 a 4200) y se envían entrada y RPM por el serial. Con el data log de Serial Oscilloscope se graban varias subidas y bajadas, MATLAB grafica las dos señales y PID Tuner identifica la planta con datos arbitrarios de entrada y salida. Las nuevas constantes se cargan en PID.h y en Teleplot se ve que la velocidad sigue al set point mejor que con el método del escalón.

Fase 1

Registrar entrada y salida

1.1

Entrada al motor desde el potenciómetro

▶ 0:33

Se comenta el PID y el escalón del capítulo anterior. El potenciómetro se mapea a la entrada del motor (0 a 4200) y se aplica directo al PWM.

Se envían dos datos separados por coma: la entrada aplicada al motor y la salida medida (RPM). Para dos datos se usa Serial Oscilloscope en vez de Teleplot.

setpoint=ADC_Read(&hadc1)*222.0/4095.0;
float entrada=map(setpoint,0,222.0,0,4200);
//PID_Control(RPM);
PWM_valor(&PWM1, entrada);

// Serial Oscilloscope
sprintf(texto,"%.1f,%.1f\r",entrada,RPM);
uartx_write_text(&huart1, texto);
1.2

Data log en Serial Oscilloscope

▶ 3:52

Se abre el puerto y en la ventana de canales se ve la entrada (roja) y las RPM (verde).

En Log To File se inicia el registro y se mueve el potenciómetro varias veces arriba y abajo. Luego se detiene el log y se copia el archivo a la carpeta de MATLAB.

Este método es más preciso que un solo escalón, sobre todo en sistemas complejos.

Fase 2

Identificar en MATLAB

2.1

Graficar entrada y salida

▶ 5:32

El script lee el archivo del log, toma la primera columna como entrada y la segunda como salida, y las grafica juntas.

clc, clear all, close all

datos = readmatrix('oscilo.csv');
datain  = datos(:, 1);   % entrada (PWM)
dataout = datos(:, 2);   % salida (RPM)

figure(1)
plot(datain, 'b-', 'DisplayName','ENTRADA');
hold on
plot(dataout, 'r-', 'DisplayName','SALIDA');
legend;
xlabel('TIEMPO');
ylabel('RPM');
grid on;

El nombre del archivo del log puede variar; usa el que guardaste desde Serial Oscilloscope.

2.2

Importar en PID Tuner

▶ 6:37

Se abre PID Tuner (PID estándar) y en la identificación de planta se elige Get I/O Data con datos arbitrarios de entrada y salida.

Output signal: dataout. Input signal: datain. Sample time: 20 ms (el del timer).

2.3

Estimar la planta

▶ 7:43

Con Auto Estimate se obtiene un modelo de un polo con cerca de 76% de ajuste. Volver a estimar a veces mejora el resultado.

Se aplica la planta y se vuelve a la pestaña PID Tuner, ajustando respuesta rápida y comportamiento robusto.

2.4

Nuevas constantes

▶ 8:50

Show Parameters entrega Kp = 310.3606, Ti = 254.7424 y Td = 2.9673, distintas a las del método del escalón. Se cargan en PID.h.

#define PID_kp 310.3606
#define PID_ki 254.7424
#define PID_kd 2.9673

PID Tuner da Ti y Td en forma estándar; si tu librería usa kp, ki, kd en forma paralela, convierte con ki = Kp/Ti y kd = Kp·Td, o pide el formato paralelo en PID Tuner.

Fase 3

Probar el PID

3.1

Activar el PID

▶ 9:25

En el callback del timer al PID le entran las RPM y su salida ut va al PWM. Se comenta el envío para Serial Oscilloscope y se envían set point y RPM a Teleplot.

setpoint=ADC_Read(&hadc1)*222.0/4095.0;
PID_Control(RPM);
PWM_valor(&PWM1, ut);

sprintf(texto,">SP:%.1f\n",setpoint);
uartx_write_text(&huart1, texto);
sprintf(texto,">OUT:%.1f\n",RPM);
uartx_write_text(&huart1, texto);
3.2

Resultado

▶ 10:29

En Teleplot la velocidad (OUT) sigue al set point (SP) y responde mejor que con las constantes del escalón.

Hay tres formas válidas de llegar al PID: con la respuesta al escalón, con datos de entrada y salida, o a mano con la gráfica (Ziegler-Nichols).
