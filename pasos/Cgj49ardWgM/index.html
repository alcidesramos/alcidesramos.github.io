SIM800 y Ubidots con PIC (parte 1)

El PIC trabaja a 48 MHz (cristal de 20 MHz con PLL). El SIM800 se alimenta a unos 4 V y se enciende con un pulso a través de un transistor. El GPS va por un puerto serial por software y el SIM800 por el UART con interrupción, guardando las respuestas en una trama. La función manda_AT_COMANDO envía un comando y espera una de dos respuestas con un tiempo límite, así el programa no se bloquea. Se intenta encender el módulo hasta 10 veces, se configura el APN del operador, se abre la conexión TCP y se arma el JSON con sprintf. En Ubidots se crea el dispositivo con sus variables y un tablero.

Fase 1

Preparar el proyecto

1.1

El módulo SIM800

▶ 0:00

Es un módulo GSM/GPRS que se maneja con comandos AT por serial. Necesita una fuente capaz de dar los picos de corriente (unos 4 V) y se enciende con un pulso en su pin de encendido, que aquí se da con un transistor desde el PIC.

1.2

Timer de 1 segundo

▶ 5:00

El Timer0 con preescalador 256 se usa como base de tiempo para que las lecturas del GPS y las esperas de respuesta tengan un límite y el programa nunca se quede bloqueado.

1.3

Interrupción serial

▶ 7:30

Se habilita la recepción continua y la interrupción del UART. En la interrupción cada dato se guarda en trama_rx con una máquina de estados que permite capturar solo la parte que interesa de la respuesta.

Fase 2

Funciones de comunicación

2.1

Serial por software

▶ 11:40

El GPS va en un puerto serial por software. Se escriben funciones para enviar textos constantes y variables, y una lectura que retorna si se cumplió el tiempo de espera.

2.2

Esperar respuestas

▶ 14:00

La función tiempo revisa durante un número de milisegundos si en la trama llegó una de dos respuestas (por ejemplo OK o ERROR) con strstr. Retorna 1, 2 o 0 si no llegó nada.

2.3

Mandar un comando AT

▶ 17:30

manda_AT_COMANDO envía el comando, el fin de línea y espera la respuesta. prendio pregunta con AT si el módulo ya está encendido; si no responde, da el pulso de encendido.

char manda_AT_COMANDO(char *coman, char cap[15], char cap1[15], unsigned int retardo)
{
  Uart1_write_text(coman);          // manda el comando
  Uart1_write_text_const("\r\n");  // manda final de linea
  return (tiempo(retardo, cap, cap1));
}

// funcion que intenta prender el modulo
unsigned char prendio()
{
  Delay_ms(2000);
  // manda comando at para ver si ya esta encendido
  if (manda_AT_COMANDO("AT", "OK", "ERROR", 2000) == 1) return 1;
  // sino manda pulso de encendido
  else {
    pin_on = 0;
    Delay_ms(1000);
    // ...
  }
}
2.4

Encender el módulo

▶ 19:40

En el programa principal se intenta encender el módulo hasta 10 veces. En la terminal se ve el AT, el OK y el mensaje de prueba cuando lo logra.

cuenta_on = 0;
while ((prendio() == 0) || (cuenta_on <= 10)) cuenta_on++;  // intenta prender el modulo usando 10 intentos
Fase 3

GPRS y Ubidots

3.1

Configurar GPRS

▶ 23:40

config_gprs manda la secuencia de comandos: el APN del operador con AT+CSTT (sin usuario ni clave en este caso; cada operador tiene el suyo), la calidad de servicio, el modo de mensajes de texto y la consulta del estado hasta que llegue IP START.

3.2

Conexión TCP

▶ 31:20

conecta abre el socket con AT+CIPSTART hacia things.ubidots.com en el puerto 80 y espera CONNECT OK o ALREADY CONNECT.

3.3

Variables

▶ 33:20

Se declaran temperatura, latitud, longitud y el estado del LED que se van a enviar, y un buffer para lo que responda Ubidots.

3.4

Dispositivo en Ubidots

▶ 38:20

En Ubidots se crea el dispositivo pruebas con las variables gps, led y temperatura, y luego un tablero para verlas. El token de la cuenta no se debe mostrar.

3.5

Armar y enviar el JSON

▶ 40:20

Con sprintf se arma el JSON: la temperatura con 2 decimales y la latitud y longitud con 7. Se calcula el largo, se envía la cabecera HTTP con el token y el cuerpo, y se termina con Ctrl+Z (0x1A) esperando SEND OK.

sprintf(trama_tx, "{\"led\": %d,\"temperatura\": %5.2f,\"gps\":{\"lat\":%11.7f, \"lng\":%12.7f}}",
        (unsigned int)led_ubidot, temperatura, latitud, longitud);
largo = strlen(trama_tx);
sprintf(largo_str, "%u\n\n", largo);
Uart1_write_text_const("POST /api/v1.6/devices/pruebas/?token=TU_TOKEN HTTP/1.1\nHost: things.ubidots.com\nContent-Type: application/json\nContent-Length: ");
UART1_Write_Text(largo_str);
Uart1_write_text(trama_tx);
Delay_ms(4000);   // retardo de envio
temp = manda_AT_COMANDO("\x1A", "SEND OK", "ERROR", 4000);  // comando de fin de envio
3.6

Prueba

▶ 43:20
