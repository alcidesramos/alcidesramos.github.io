Distancia con el HC-SR04

El HC-SR04 recibe un pulso de 10 µs en TRIG y responde con un pulso en ECHO cuyo ancho es proporcional a la distancia: µs / 58 = cm (µs / 148 = pulgadas). La función SFR04_READ mide ese ancho con el contador de ciclos DWT, con un límite de tiempo (60 ms) para no bloquear el programa si el sensor falla. Varios sensores comparten el TRIG y cada uno tiene su pin de ECHO; se leen uno tras otro.

Fase 1

El sensor

1.1

Cómo mide

▶ 0:00

Se da un pulso de 10 µs en TRIG. El módulo envía 8 ciclos de ultrasonido a 40 kHz y pone ECHO en alto el tiempo que tarda el eco en volver.

Distancia en cm = ancho del pulso en µs / 58. En pulgadas, / 148. Se recomienda un ciclo de medición de más de 60 ms.

Fase 3

Librería

3.1

La variable pasos

▶ 5:06

delay_us_dwt_init() activa el contador de ciclos DWT y calcula pasos: cuántos ciclos de reloj hay en 1 µs. La librería del sensor la usa para convertir el tiempo límite a ciclos y el conteo a µs.

void delay_us_dwt_init(void)
{
    CoreDebug->DEMCR |= CoreDebug_DEMCR_TRCENA_Msk;
    DWT->CTRL |= DWT_CTRL_CYCCNTENA_Msk;
    pasos = (HAL_RCC_GetHCLKFreq() / 1000000);   // ciclos por µs
}
3.2

Medir el pulso sin bloquear

▶ 5:37

Se dispara el sensor, se espera a que ECHO suba y luego se cuenta mientras está en alto. En cada espera, si el contador pasa del límite se devuelve 0: así un sensor dañado o desconectado no detiene el programa.

extern uint32_t pasos;

float SFR04_READ(GPIO_TypeDef *GPIOx, uint16_t GPIO_Pin, const uint32_t tiempo)
{
    uint32_t ciclos;
    float valor = 0;
    float eco;

    delay_us_dwt_init();
    ciclos = pasos * tiempo * 1000;   // tiempo límite en ms pasado a ciclos

    // pulso de disparo
    HAL_GPIO_WritePin(TR_GPIO_Port, TR_Pin, 1);
    delay_us_dwt(10);
    HAL_GPIO_WritePin(TR_GPIO_Port, TR_Pin, 0);

    DWT->CYCCNT = 0;   // espera a que ECHO suba
    while (HAL_GPIO_ReadPin(GPIOx, GPIO_Pin) == 0)
        if (DWT->CYCCNT >= ciclos) return (0);

    DWT->CYCCNT = 0;   // cuenta mientras ECHO está en alto
    while (HAL_GPIO_ReadPin(GPIOx, GPIO_Pin) == 1)
        if (DWT->CYCCNT >= ciclos) return (0);

    eco = DWT->CYCCNT;
    valor = eco / (float)pasos;   // ciclos a µs
    valor = valor / 58.0;         // µs a cm (148.0 para pulgadas)
    return valor;
}

Si prefieres distinguir el error de una distancia real, devuelve -1 en vez de 0 cuando se acaba el tiempo.
