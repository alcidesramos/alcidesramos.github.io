Interrupciones por timer desde los registros

Lección 33 del curso. En la 31 Timer Calculator hacía el trabajo, pero al usar varios timers puede haber conflictos, así que aquí se configuran desde los registros. Se explican los timers 0, 1 y los pares (2, 4, 6), cuántos pasos da un timer según el valor inicial, el tiempo de ciclo con cristal de 4 MHz y el prescalador. Con una hoja de Excel se calculan los valores y se programan las interrupciones del Timer1 y del Timer0.

Fase 1

Cómo funcionan los timers

1.1

Timer0, Timer1 y timers pares

▶ 0:32

El Timer0 comparte el prescalador con el watchdog, es de 8 bits en los PIC16 y de 8 o 16 en los PIC18, y puede contar pulsos de un pin externo (normalmente RA4). El Timer1 es de 16 bits con prescalador. Los timers 2, 4 y 6 son de 8 bits con prescalador y postscaler.

1.2

Pasos

▶ 4:09

Un timer de 8 bits cuenta hasta 255 y uno de 16 hasta 65535; la interrupción ocurre al desbordarse. Si el Timer0 arranca en 200, da 56 pasos hasta desbordarse: los pasos son el conteo máximo menos el valor inicial.

1.3

Cristal y prescalador

▶ 6:26

El micro trabaja a la cuarta parte del cristal: con 4 MHz cada paso dura 1 µs. El prescalador multiplica ese tiempo, así que el tiempo total es pasos por prescalador por tiempo de ciclo.

1.4

Timers con PR

▶ 9:16

En los timers pares no se carga un valor inicial: cuentan desde cero hasta el valor del registro PR (PR2, PR4...) y se reinician solos, así que no hay que recargarlos para mantener el tiempo.

Fase 2

Timer1 cada 200 ms

2.1

Calcular en Excel

▶ 11:28

En la hoja de cálculo se pone la frecuencia del cristal y el tiempo deseado. Para 200 ms el Timer1 cumple con prescalador de 4 y valores 60 en TMR1H y 175 en TMR1L.

2.2

Configurar el Timer1

▶ 14:11

Primero el valor inicial, luego el prescalador con los bits T1CKPS1 y T1CKPS0, después la interrupción (limpiar bandera y habilitar) y por último prender el timer. Como es de periférico, PEIE debe estar en 1.

// CONFIGURACION TIMER1
// 1) valor inicial para 200 ms
TMR1H = 60;
TMR1L = 175;
// 2) prescalador 4
T1CKPS1_bit = 1;
T1CKPS0_bit = 0;
// 3) configura interrupcion timer
TMR1IF_bit = 0;   // limpia bandera
TMR1IE_bit = 1;   // habilita la interrupcion
TMR1ON_bit = 1;   // prende
2.3

En la interrupción

▶ 18:48

El Timer1 sigue desde cero al desbordarse, así que hay que volver a cargarle el valor inicial para mantener los 200 ms. Luego se hace la tarea y se limpia la bandera.

if (TMR1IF_bit == 1)
{
  TMR1H = 60;   // valor inicial para 200 ms
  TMR1L = 175;
  led1 = ~led1;
  TMR1IF_bit = 0;
}
Fase 3

Timer0 cada 10 ms

3.1

OPTION_REG

▶ 20:32

El Timer0 se configura en OPTION_REG. Se pone en cero y se ajustan los bits: T0CS en 0 para contar con el oscilador, PSA en 0 para que el prescalador quede en el timer y no en el watchdog, y PS2 a PS0 para el valor del prescalador.

3.2

Valores

▶ 22:10

A 4 MHz el Timer0 llega a unos 65 ms como máximo. Para 10 ms la hoja da prescalador de 64 y valor inicial 100.

// timer cero
OPTION_REG = 0;
TMR0 = 100;
// prescalador 64, 10 ms
PS2_bit = 1;
PS1_bit = 0;
PS0_bit = 1;
// INTERRUPCION
TMR0IF_bit = 0;
TMR0IE_bit = 1;

GIE_bit = 1;   // autoriza las interrupciones
3.3

Alargar a un segundo

▶ 25:40

En la interrupción se recarga el Timer0 y se cuenta con una variable: cien veces 10 ms es un segundo. Al final hay un led cada 200 ms con el Timer1 y otro cada segundo con el Timer0.

if (TMR0IF_bit == 1)
{
  TMR0 = 100;
  alargue++;
  if (alargue >= 100)   // 10ms*100 = 1 seg
  {
    led2 = ~led2;
    alargue = 0;
  }
  TMR0IF_bit = 0;
}
