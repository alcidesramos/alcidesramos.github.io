Sensor LIDAR VL53L0X con STM32

Los sensores ToF (tiempo de vuelo) disparan un láser y miden cuánto tarda en volver. ST no publica los registros del VL53L0X: solo entrega una API (STSW-IMG005). Aquí se usa esa API con una librería propia (lidarvl53) que la hace fácil de usar: lidar_init, lidar_lee_mm y lidar_lee_cm. Se configuran I2C1, USART1 y un pin XSHUT, se agregan los include paths de la API y se ve la distancia en Hercules.

  • Black Pill STM32F401CCU6
  • Sensor VL53L0X (módulo morado o el de filtro; hay de 0.5, 2 y 4 m)
  • Programador ST-Link
  • Conversor USB a serial para USART1
  • API VL53L0X de ST (STSW-IMG005) y librería lidarvl53

Fase 1

El sensor

1.1

API de ST

▶ 0:00

La API de ST (VL53L0X API, STSW-IMG005) es la única forma documentada de usarlo: el datasheet no muestra registros. Al ser del fabricante es confiable y está optimizada.

1.2

Pines

▶ 1:06

VIN de 3.3 a 5 V (tiene regulador), GND, SCL y SDA. GPIO1 es una interrupción que aquí no se usa. XSHUT habilita el sensor: con un solo sensor no hace falta, con varios se usa para elegir cuál leer.

Se le puede cambiar la dirección I2C, pero se pierde al quitar la energía. Para varios sensores es mejor usar XSHUT o un multiplexor I2C (hasta 8 sensores por un canal).

Fase 2

Proyecto

2.1

Reloj, UART e I2C

▶ 3:16

Proyecto nuevo para el STM32F401: HSE con cristal y PLL a 84 MHz. USART1 asíncrono a 115200. I2C1 en modo I2C a 100 kHz (la librería está hecha para I2C1).

2.2

Pin XSHUT

▶ 7:10

PB12 como GPIO_Output con la etiqueta lidar1. Si hubiera más sensores serían lidar2, lidar3, etc.

2.3

Librerías e include paths

▶ 5:29

Se crea la carpeta Librerias en Core y se copian la carpeta VL53L0X (la API), la librería lidarvl53 y la de UART. Hay que agregar al include path la carpeta Librerias y también las carpetas inc de core y de platform de la API.

/* USER CODE BEGIN Includes */
#include "uart.h"
#include "lidarvl53.h"
#include "stdio.h"

Si salen muchos errores al compilar (aquí salieron 19) casi siempre falta un include path: el de core/inc o el de platform/inc.

Fase 3

Código

3.1

Distancia máxima y direcciones

▶ 10:05

En lidarvl53.h están las direcciones de hasta 8 sensores (0x52 es la de fábrica) y lidar_max_mm. Es lo único que hay que modificar: 500 para el de 50 cm, 2000 para el de 2 m y 4000 para el de 4 m.

#define lidar_max_mm 2000

#define dir_s1 0x52   // direccion del 1er sensor
#define dir_s2 0x53   // direccion del 2do sensor
// ... hasta dir_s8 0x59
3.2

Variables e inicio

▶ 8:59

Una variable entera para los milímetros, una float para los centímetros con decimales y la cadena para la UART. Habilitar el sensor con XSHUT es opcional con un solo sensor; con varios, se hace antes de leer cada uno.

/* USER CODE BEGIN PV */
uint16_t milimetros;
float distancia;
char texto[100];

/* USER CODE BEGIN 2 */
// opcional: habilitar el sensor por XSHUT
HAL_GPIO_WritePin(lidar1_GPIO_Port, lidar1_Pin, 0);
HAL_Delay(20);
HAL_GPIO_WritePin(lidar1_GPIO_Port, lidar1_Pin, 1);
HAL_Delay(20);

uartx_write_text(&huart1, "iniciando\r\n");
lidar_init(dir_s1);
3.3

Leer en el while

▶ 11:17

Se puede leer en mm o en cm (aquí ambos). Si la lectura es negativa no hay sensor conectado.

while (1)
{
  milimetros = lidar_lee_mm(dir_s1);
  distancia  = lidar_lee_cm(dir_s1);

  if (distancia < 0) uartx_write_text(&huart1, "SENSOR NO CONECTADO\r\n");
  else
  {
    sprintf(texto, "Dis_mil=%u   Dis_cm=%.1f\r\n\r\n", milimetros, distancia);
    uartx_write_text(&huart1, texto);
  }
  HAL_Delay(500);
}

En el video la etiqueta dice Dis_mts, pero lidar_lee_cm devuelve centímetros (por eso sale 197.0 y no 1.97). Aquí se corrigió la etiqueta a Dis_cm.

Fase 4

Prueba

4.1

printf con float

▶ 14:07

Si la columna con decimales sale vacía, falta habilitar float en printf: clic derecho en el proyecto, Properties, C/C++ Build, Settings, MCU Settings, Use float with printf.

4.2

Grabar y medir

▶ 12:26

Se graba con el ST-Link (Debug, se escanea el programador) y se abre Hercules a 115200. Sin nada al frente marca 2000 mm (el máximo). Al poner un objeto marca la distancia: 114 mm, 250 mm, 80 mm... La cámara del celular alcanza a ver el láser cuando dispara.
