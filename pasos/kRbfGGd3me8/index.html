Convertir números a texto en MikroC

Lección 18 del curso. La LCD solo muestra texto, así que los números hay que convertirlos a cadena. Con un PIC16F877A a 4 MHz y la LCD en el puerto C se prueban las funciones de la librería Conversions, cada una con su tipo de variable y el tamaño mínimo del vector de salida. FloatToStr_FixLen falla con números menores que uno, así que se usa una función propia, float_to_str_, que deja escoger los decimales. Por último se usa sprinti para dar formato a enteros y varias variables a la vez (una fecha), y se pasa a un PIC18F2550 para usar sprintf con flotantes.

Fase 1

Por qué convertir

1.1

La LCD solo recibe texto

▶ 0:00

Un número como 23.456 guardado en una variable no se puede mandar directo con Lcd_Out: hay que convertirlo en una cadena de caracteres. Para eso MikroC trae la librería Conversions, que pasa números a texto.

1.2

El proyecto base

▶ 3:00

Se crea el proyecto con un PIC16F877A a 4 MHz y se toma la configuración de la LCD del ejemplo de la ayuda, cambiando los pines al puerto C (RC0 a RC5, con sus TRISC). Se escribe algo fijo para comprobar que la LCD funciona.

Fase 2

Librería Conversions

2.1

Cada función y su vector

▶ 5:30

Cada función sirve para un tipo de variable y necesita un vector de salida de un tamaño mínimo, contando el signo y el carácter nulo del final:

  • ByteToStr: char (0 a 255), vector de 4.
  • ShortToStr: signed short (-128 a 127), vector de 4.
  • WordToStr: unsigned int (0 a 65535), vector de 6.
  • IntToStr: signed int (-32768 a 32767), vector de 7.
  • LongToStr: signed long, vector de 12; LongWordToStr: unsigned long, vector de 11.
  • FloatToStr y FloatToStr_FixLen: float, vector de 15.

Las versiones ...WithZeros rellenan con ceros a la izquierda en vez de espacios.

2.2

Contador con ByteToStr

▶ 8:00

Un for cuenta de 0 a 100, convierte la variable con ByteToStr y la muestra. El número sale alineado a la derecha y con espacios delante, porque el vector siempre tiene el mismo largo.

char cuenta;
char texto[4];

while (1) {
  for (cuenta = 0; cuenta <= 100; cuenta++) {
    ByteToStr(cuenta, texto);
    Lcd_Out(1, 10, texto);
    Delay_ms(80);
  }
}
2.3

Variables más grandes

▶ 10:00

Si la variable pasa de 255 se cambia a unsigned int y se usa WordToStr con un vector de 6. Con enteros con signo, IntToStr con vector de 7.

Fase 3

Números con decimales

3.1

FloatToStr_FixLen

▶ 12:20

Para flotantes, FloatToStr_FixLen deja fijar el largo, pero con números menores que uno no muestra bien el valor, y eso es un problema si se miden voltajes pequeños.

float cuenta;
char texto[15];

for (cuenta = 12.56; cuenta <= 16.80; cuenta = cuenta + 0.1) {
  FloatToStr_FixLen(cuenta, texto, 6);
  Lcd_Out(1, 10, texto);
  Delay_ms(80);
}
3.2

Una función propia: float_to_str_

▶ 14:20

Para resolverlo se usa una función propia que recibe el número, el vector y la cantidad de decimales que se quieren. Funciona también con números menores que uno.

for (cuenta = 0.156; cuenta <= 16.80; cuenta = cuenta + 0.1) {
  FloatToStr_(cuenta, texto, 3);   // 3 decimales
  Lcd_Out(1, 10, texto);
  Delay_ms(80);
}
3.3

Tres formas de usarla

▶ 16:00

La función viene como texto para copiar en el programa, como un .h que se incluye con #include, o como paquete para instalar con el Package Manager (lección 17). Instalada, aparece en el Library Manager junto a las de MikroC.

Active su librería solo en los proyectos que la usan, para no ocupar memoria de más.

Fase 4

Dar formato con sprinti y sprintf

4.1

sprinti en el 16F

▶ 19:10

En la ayuda de cada función se ve el tamaño del vector. Para dar formato, el 16F usa sprinti (enteros con signo) y sprintl (long). El formato %03u muestra el número con tres cifras rellenando con ceros.

sprinti(texto, "contador=%03u", cuenta);
Lcd_Out(1, 1, texto);
4.2

Varias variables a la vez

▶ 23:20

Con un solo sprinti se arma una fecha a partir de día, mes y año. Las variables deben ser unsigned int; si son char, se les hace un cast.

dia = 23;  mes = 10;  ano = 18;
sprinti(texto, "fecha=%02u/%02u/20%02u",
        (unsigned int)dia, (unsigned int)mes, (unsigned int)ano);
Lcd_Out(3, 1, texto);

Si las variables no son enteras, sprinti muestra valores errados.

4.3

sprintf con flotantes en el 18F2550

▶ 30:30

sprintf permite flotantes, pero no cabe en el 16F877A. Se pasa el proyecto a un PIC18F2550: se ponen los pines digitales con ADCON1, se cambian los pines de la LCD y se usa un formato como %5.2f (cinco posiciones, dos decimales) o %.3f.

sprintf(texto, "contador=%5.2f", cuenta);
Lcd_Out(1, 1, texto);
