Clase 146: generador de señales con mis librerías del DAC

Tras ver en la clase anterior de dónde salen los cálculos, ahora usamos una librería que lo hace todo. En modo simple basta con inicializar cada DAC del usuario y sacar un código o un voltaje. Con DMA (dos canales de GPDMA, TIM6 y TIM7) la librería genera la forma de onda en un buffer y calcula sola el prescaler y el periodo del timer para la frecuencia pedida. Probamos cuadrada y seno juntas, dos senos desfasados 90 o 180 grados, diente de sierra, rotación del buffer, y vemos el compromiso entre número de muestras y frecuencia máxima.

Fase 1

Proyecto y librería en modo simple

1.1

DAC1 con dos salidas y reloj a 250 MHz

▶ 1:05

En CubeMX activamos DAC1 OUT1 y OUT2 (only external pin), con HSE de 8 MHz y el sistema a 250 MHz. Por ahora sin DMA. El proyecto se llama DAC_DMA_CANAL.

1.2

La línea de oro: #define DMA

▶ 4:43

Creamos la carpeta LIBRERIAS dentro de Core, pegamos DAC.h y DAC.c y la agregamos a las rutas de include.

En DAC.h: sin DMA la línea va comentada, con DMA se descomenta. La librería habilita solo las funciones que tocan.

//descomentar si usa DMA
//#define DMA

typedef struct {
  DAC_HandleTypeDef *hdac;
  uint32_t channel;
#ifdef DMA
  TIM_HandleTypeDef *htim;
#endif
  uint32_t *buffer;
  uint16_t size;
} DACS;

void DAC_INIT(DACS *dac);
void DAC_OUT_CODIGO(DACS *dac, uint16_t codigo);
void DAC_OUT_VOLTAJE(DACS *dac, float valor);
1.3

Los DAC del usuario

▶ 6:28

En DAC.c se declaran las variables DACU1 y DACU2 diciendo qué DAC y qué canal usa cada una. Si tu micro tiene más DAC, agregas DACU3, DACU4.

DACS DACU1 = {&hdac1, DAC_CHANNEL_1};
DACS DACU2 = {&hdac1, DAC_CHANNEL_2};
1.4

Código, voltaje y rampa

▶ 7:32

En el main se inicializan los dos DAC y se saca un código por uno y un voltaje por el otro. Una rampa en el while sube el voltaje de 0 a 3.3 V.

DAC_INIT(&DACU1);
DAC_INIT(&DACU2);

DAC_OUT_CODIGO(&DACU1, 3000);
DAC_OUT_VOLTAJE(&DACU2, 2.2);

while (1)
{
  for (float voltaje = 0; voltaje <= 3.3; voltaje += 0.1)
  {
    DAC_OUT_VOLTAJE(&DACU2, voltaje);
    HAL_Delay(200);
  }
}
Fase 2

Configuración para DMA

2.1

Trigger de cada canal

▶ 10:54

En el DAC, el trigger del canal 1 es el Timer 6 y el del canal 2 el Timer 7. Así cada salida genera su propia señal.

2.2

Dos canales de GPDMA

▶ 11:29

En GPDMA1 habilitamos dos canales en Standard Request Mode, ambos en modo circular.

Request DAC1_CH1 en uno y DAC1_CH2 en el otro, memoria a periférico, incremento en la fuente y ancho Word en origen y destino. Prioridad media (o alta si uno debe mandar).

2.3

TIM6 y TIM7

▶ 13:10

Activamos los dos timers con auto-reload preload habilitado y Trigger Event Selection: Update Event.

El prescaler y el periodo ya no se calculan a mano: la librería busca los mejores valores para la frecuencia pedida.

Si olvidas el Update Event el DMA no se sincroniza y no sale nada (pasó en el video).

2.4

Activar DMA y tamaño del buffer

▶ 13:43

Regeneramos el código y en DAC.h descomentamos #define DMA. Se define el tamaño del buffer de cada DAC del usuario.

//descomentar si usa DMA
#define DMA

//define tamaño buffer de los DAC del usuario
#define sizebuff_DACU1 200
#define sizebuff_DACU2 200

Más muestras dan una señal más limpia, pero exigen un timer más rápido y bajan la frecuencia máxima posible.

Fase 3

Generando señales

3.1

Cuadrada y senoidal a la vez

▶ 14:48

Se llena el buffer con la forma de onda y se arranca el DMA de cada DAC. La cuadrada recibe frecuencia, voltaje, ciclo útil y offset; la seno recibe frecuencia, amplitud y offset.

La función interna DAC_TimerConfig prueba todos los prescaler posibles y elige el ARR con menor error.

CUADRADA(&DACU2, 1000, 3.0, 50.0, 0);
SENO(&DACU1, 900, 2.0, 1.0);
DAC_INIT_DMA(&DACU2);
DAC_INIT_DMA(&DACU1);

Cambiando el ciclo útil a 20 y la seno a 1200 Hz se ve el cambio al instante.

3.2

Dos senos desfasados

▶ 19:24

SENO_FASE agrega un último parámetro con el desfase en grados. Con 90 o 180 grados se pueden tener dos senos complementarios, útiles por ejemplo para un inversor.

SENO(&DACU1, 60, 2.0, 0.0);
SENO_FASE(&DACU2, 60, 2.0, 0.0, 90);
DAC_INIT_DMA(&DACU2);
DAC_INIT_DMA(&DACU1);

Cada señal debe ir a un DAC distinto; si las dos van al mismo canal se pisan entre ellas.

3.3

Diente de sierra y rotar el buffer

▶ 21:12

DIENTE_SIERRA genera la rampa. ROTA_DER y ROTA_IZQ desplazan el buffer en el tiempo, como mover la señal en el eje X.

DIENTE_SIERRA(&DACU1, 60, 2.0, 0.0);
SENO_FASE(&DACU2, 60, 2.0, 0.0, 180);
ROTA_DER(DACU1.buffer, DACU1.size, 50);
DAC_INIT_DMA(&DACU2);
DAC_INIT_DMA(&DACU1);
3.4

Muestras contra frecuencia máxima

▶ 23:57

Con 200 muestras la seno llega a unos 95 kHz; con 500 muestras cae a unos 50 kHz porque el timer no da más.

Con 5 muestras la señal ya no parece seno (Nyquist). Con 10 muestras se llega a 300 kHz, pero muy discretizada. Un valor normal es 50 o 100 muestras.

#define sizebuff_DACU1 5
#define sizebuff_DACU2 5
3.5

Cambiar de señal en el tiempo

▶ 33:07

Como el DMA trabaja solo, el while queda libre. Se puede cambiar la forma de onda cada cierto tiempo: cuadrada, seno y triangular cada 2 segundos.

while (1)
{
  CUADRADA(&DACU1, 1000, 3.0, 20.0, 0);
  HAL_Delay(2000);
  SENO(&DACU1, 3000, 2.0, 1.0);
  HAL_Delay(2000);
  TRIANGULAR(&DACU1, 3000, 2.0, 1.0);
  HAL_Delay(2000);
}
