Nivel de audio con el STM32

La salida de audio tiene alrededor de 1 V y parte negativa, que el micro no acepta. Un amplificador operacional de alimentación simple (LM358 o MCP6002) deja solo la parte positiva, con un capacitor que sostiene el pico y una resistencia que lo descarga. El STM32 toma 200 muestras con el ADC, se queda con el máximo y lo compara con cinco umbrales para dar el nivel 1 a 6 por el puerto serial.

Fase 1

El circuito

1.1

Quitar la parte negativa

▶ 0:00

El audio entra al operacional (LM358 o MCP6002, alimentados con fuente simple a 5 V) con un capacitor de 100 nF de desacople cerca de la alimentación. A la salida, C2 de 100 nF mantiene el nivel del pico y R1 de 2,2 kΩ lo descarga cuando no hay señal, para que no quede un voltaje fijo.

1.2

Simulación en Proteus

▶ 1:05

Con una señal seno de 1 V de pico, el osciloscopio muestra que a la salida solo queda la parte positiva. Como el audio no pasa de 1,8 V, se puede llevar directo al ADC sin superar los 3,3 V; un zener de 3,3 V sería una protección opcional. Proteus también permite cargar un archivo de audio en el generador.

Configurar el micro

Reloj, ADC y USART

Fase 3

Detectar el pico

3.1

Buscar el máximo de 200 muestras

▶ 6:44

En el while se leen 200 muestras, se convierten a voltaje y se guarda la mayor. El número de muestras se puede cambiar según la rapidez que necesites. Declara char texto[50]; y agrega un retardo para no saturar el serial.

while (1)
{
    float max = 0;
    for (uint16_t cuen = 0; cuen < 200; cuen++)
    {
        uint16_t codigo = ADC_Read(&hadc1);
        float voltaje = codigo*3.3/4095.0;
        if (voltaje > max) max = voltaje;  //busca maximo
    }
    sprintf(texto, "Max=%.3f\r\n\r\n", max);
    uartx_write_text(&huart1, texto);
    HAL_Delay(500);
}
3.2

Probar con un tono

▶ 8:58

Con un tono continuo de 1 kHz al máximo volumen el pico llega a unos 1,6 V; al bajar el volumen baja a 0,6 o 0,5 V. Así se encuentran los niveles mínimo y máximo de tu señal.

Fase 4

Clasificar en niveles

4.1

Comparar el pico

▶ 6:10

Define cinco umbrales de voltaje (n1 a n5) entre el mínimo y el máximo que mediste; si tu audio es más bajo, bájalos. Con un audio real (no un tono) el nivel sube y baja como las barras de un vúmetro.

Con una cadena de if se decide el nivel. En lugar del serial, aquí se encenderían los LED de un vúmetro o se activaría cualquier carga.

// ejemplo: ajusta los valores a tu señal
#define n1 0.3
#define n2 0.6
#define n3 0.9
#define n4 1.2
#define n5 1.5

if (max < n1)
    uartx_write_text(&huart1, "NIVEL 1\r\n");
else if ((max >= n1) && (max < n2))
    uartx_write_text(&huart1, "NIVEL 2\r\n");
else if ((max >= n2) && (max < n3))
    uartx_write_text(&huart1, "NIVEL 3\r\n");
else if ((max >= n3) && (max < n4))
    uartx_write_text(&huart1, "NIVEL 4\r\n");
else if ((max >= n4) && (max < n5))
    uartx_write_text(&huart1, "NIVEL 5\r\n");
else if (max >= n5)
    uartx_write_text(&huart1, "NIVEL 6\r\n");
4.2

Resultado

▶ 11:44

Al máximo volumen marca NIVEL 6 y al ir bajando pasa por 5, 4, 3, 2 hasta 1. El micro ya detecta el pico de la señal de audio para activar lo que necesites.
