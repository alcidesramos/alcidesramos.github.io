Tres interrupciones: cruce por cero, timer y serial

El proyecto controla la potencia de una carga AC desde LabVIEW y a la vez monitorea temperatura y un pulsador. Todo se hace con interrupciones: la de flanco detecta el cruce por cero y arranca el Timer0 con el tiempo calculado; la del Timer0 da el pulso al triac y se apaga; la serial arma la trama que llega y avisa al programa principal con una bandera. Una ecuación sacada en Excel convierte el porcentaje pedido en el valor del timer.

Fase 1

La idea

1.1

Qué hace el proyecto

▶ 1:05

Desde LabVIEW se ve la temperatura y el estado de un pulsador, se prende un LED y se elige la potencia de la carga AC. El reto es el cruce por cero sin bloquear el micro, así que todo se hace por interrupciones.

Para esto se recomienda un PIC18: en un PIC16 también se puede, pero la memoria queda justa.

1.2

Programa principal

▶ 2:40

El main configura el puerto serial y las tres interrupciones. En el ciclo revisa si llegó una trama, decide el disparo (menos de 5 % apaga, más de 90 % prende del todo, en medio aplica la ecuación) y envía la temperatura y el pulsador.

1.3

Las tres interrupciones

▶ 4:17

Flanco: en cada cruce por cero carga el Timer0 y activa su interrupción. Timer0: da el pulso de disparo y se desactiva. Serial: guarda datos hasta el asterisco de fin de trama y activa una bandera. Cada una debe ser muy corta.

Fase 2

Programa principal

2.1

Proyecto y variables

▶ 6:42

Proyecto nuevo con el PIC18F2550 a 20 MHz (oscilador HS). Conviene un cristal de 10 MHz o más para que las interrupciones no se vuelvan lentas.

Variables: el pulsador en RB1, el pulso de disparo en LATC1, calculo (valor para el timer), dispara (porcentaje 0-100), la temperatura y las tramas de envío y recepción.

2.2

Procesar la trama

▶ 9:05

Se activan las librerías de conversiones, C_String, C_Stdlib y UART. procesarx busca en la trama si trae el LED o el porcentaje de disparo y lo pasa a número.

void procesarx() {
  if (strstr(trama_rx, "led=")) {
    if (strstr(trama_rx, "on")) led = 1;
    else led = 0;
  }
  else if (strstr(trama_rx, "pul=")) {
    strcpy(procesa, strtok(trama_rx, "="));
    strcpy(procesa, strtok(0, "/"));
    dispara = atoi(procesa);
  }
}
2.3

Entradas, salidas y serial

▶ 10:46

Se configura el canal análogo, la entrada del cruce por cero, el pulsador, el LED, la salida de disparo y los pines TX y RX. El puerto serial arranca a 9600 baudios.

2.4

Flanco y Timer0

▶ 11:52

La interrupción INT0 se configura por flanco de subida. El Timer0 trabaja en 8 bits con prescaler 256: a 20 MHz alcanza unos 13 ms, más que los 8.33 ms de un semiciclo.

Su interrupción queda apagada: la prende el cruce por cero. Al final se habilitan las interrupciones globales.

INT0IF_bit = 0;     // limpia bandera
INTEDG0_bit = 1;    // flanco de subida
INT0IE_bit = 1;     // habilita INT0

TMR0ON_bit = 1;     // habilita el timer 0
T08BIT_bit = 1;     // timer de 8 bits
T0CS_bit = 0;       // cuenta con el reloj
PSA_bit = 0;        // usa prescaler
T0PS2_bit = 1; T0PS1_bit = 1; T0PS0_bit = 1;  // 256

GIE_bit = 1;
2.5

Decidir el disparo

▶ 14:44

Si el porcentaje es menor que 5 se apaga la interrupción de flanco y la carga. Si es mayor que 90 se apaga la interrupción y se deja la carga prendida. En medio se calcula el valor del timer y se habilita la interrupción de flanco.

if (dispara < 5) {
  INT0IE_bit = 0;   // deshabilita interrupcion por flanco
  pulso = 0;        // apaga la carga
}
else if (dispara > 90) {
  INT0IE_bit = 0;
  pulso = 1;
}
else {
  calculo = -1.6266 * dispara + 256.1;
  INT0IF_bit = 0;
  INT0IE_bit = 1;   // habilita interrupcion por flanco
}
2.6

La ecuación en Excel

▶ 16:22

Con el cristal y el prescaler se calcula, para varios porcentajes entre 5 y 90, el tiempo de disparo y el valor del timer. Con esos puntos se hace una gráfica de dispersión y se agrega una línea de tendencia que da la ecuación.

2.7

Enviar a LabVIEW

▶ 19:10

Después se arma la trama con la temperatura y el estado del pulsador y se envía. Un retardo de 50 ms es suficiente.

Fase 3

Interrupciones

3.1

Un solo vector

▶ 19:45

En los PIC16 y PIC18 todas las interrupciones llegan a la misma función. Hay que revisar la bandera de cada una para saber cuál ocurrió. La más crítica, el cruce por cero, se revisa primero.

3.2

Cruce por cero y serial

▶ 21:01

En el cruce por cero se apaga el pulso, se carga el Timer0 con el valor calculado y se habilita su interrupción. En la serial se guarda el dato; si llega el asterisco se activa la bandera para el main.

Si hay un error de recepción se apaga y prende de nuevo la recepción (CREN) para limpiarlo; si no, el micro se puede bloquear.

if (INT0IF_bit == 1) {
  pulso = 0;
  TMR0L = calculo;   // tiempo a temporizar
  TMR0IF_bit = 0;
  TMR0IE_bit = 1;    // activa interrupcion del timer 0
  INT0IF_bit = 0;
}
if (RCIF_bit == 1) {
  datorx = UART1_Read();
  trama_rx[puntero] = datorx;
  puntero++;
  if (puntero >= 30) puntero = 0;
  if (datorx == '*') {
    RCIE_bit = 0;
    flag_rx = 1;     // trama valida
  }
}
3.3

Timer0: el disparo

▶ 23:12

Cuando el Timer0 se desborda se da un pulso de 10 µs al triac y se desactiva su interrupción hasta el próximo cruce. El triac se apaga solo cuando la señal vuelve a cero.

if (TMR0IF_bit == 1) {
  pulso = 1;
  Delay_us(10);
  pulso = 0;
  TMR0IF_bit = 0;
  TMR0IE_bit = 0;   // deshabilita interrupcion del timer
}
