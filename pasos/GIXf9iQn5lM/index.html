Velocidad de un motor: ON-OFF y PID

En lazo abierto el potenciómetro da el PWM pero no se sabe si el motor llega a la velocidad. Para cerrar el lazo se mide la frecuencia del encoder con la interrupción externa y el Timer1 (con preescalador 8 para frecuencias bajas). El set point del potenciómetro se lleva al mismo rango de la frecuencia con una recta sacada en Excel. Luego se prueba el ON-OFF (prende o apaga), un control que sube o baja la salida según el error y un PID discreto. Los datos se envían por serial a LabVIEW para graficar.

▶ Ver el video completo (46:15) Empezar el paso a paso
  • MikroC PRO for PIC (ADC, PWM, UART)
  • PIC16F877A
  • Motor DC con encoder (ENCMOTOR en Proteus) y transistor TIP122
  • Potenciómetro para el set point
  • LabVIEW y COMPIM para graficar
  • Excel para la recta del set point

Fase 1

Lazo abierto

1.1

Circuito

▶ 0:00

El PWM de RC2 mueve el motor con un TIP122. El encoder entra por RB0, un potenciómetro da el set point en AN0 y el serial va al COMPIM. Un selector elige si el set point viene del potenciómetro o de LabVIEW.

1.2

Configuración

▶ 3:16

Entradas para el encoder, el selector y RX, pull ups del puerto B, UART a 19200 y PWM arrancando a máxima velocidad.

ADCON1 = 0;          // todo analogo
TRISA = 255;
TRISB = 0;
TRISC = 0;
TRISB0_bit = 1;      // ENTRADA RPM
TRISB7_bit = 1;      // ENTRADA SELECTOR DE POTENCIOMETRO O LABVIEW
TRISC7_bit = 1;      // ENTRADA RX
NOT_RBPU_bit = 0;    // habilita pull up
UART1_Init(19200);
UART1_Write_Text_const("Iniciando");
PWM1_Init(620);
PWM1_Set_Duty(255);  // maxima velocidad
PWM1_Start();
1.3

Potenciómetro al PWM

▶ 7:45

El ADC de 10 bits se corre dos lugares para quedar en 0-255. El motor cambia de velocidad, pero si se le pone carga baja y nadie lo corrige: eso es lazo abierto.

ADC_Init();
while (1) {
  codigo = ADC_Get_Sample(0);
  PWM1_Set_Duty(codigo >> 2);
  Delay_ms(500);
}
Fase 2

Medir la velocidad

2.1

Encoder

▶ 9:55

En el motor de Proteus se ajustan el voltaje, las RPM sin carga y los pulsos por vuelta. La frecuencia se mide como en el video de medición de frecuencia: interrupción INT y Timer1.

2.2

Calcular y enviar

▶ 16:16

Con flag_cero se calcula solo si hubo pulsos. La frecuencia se pasa a texto con dos decimales y se envía por serial.

if (flag_cero != 0) frecuencia = (Clock_kHz()*1e3)/(1.0*contador*4.0*8.0);  // 8 es el preescalador
flag_cero = 0;
FloatToStr_(frecuencia, texto, 2);
UART1_Write_Text_const("RPM=");
UART1_Write_Text(texto);
2.3

Preescalador

▶ 20:24

Por debajo de unos 38 Hz el Timer1 se desborda antes del siguiente pulso y la medida falla. Con preescalador 8 se miden frecuencias mucho más bajas.

2.4

Set point en el mismo rango

▶ 22:38

El motor va de unos 5 a 70 Hz. En Excel se grafican los puntos ADC 0 → 5 y ADC 1023 → 70 y la línea de tendencia da la ecuación para pasar el código del ADC a set point.

set_point = codigo*65.0/1023.0 + 5.0;
Fase 3

Control ON-OFF

3.1

Prender o apagar

▶ 24:53

Si la velocidad está por debajo del set point el PWM va al máximo; si está por encima, se apaga. Se envía SP, RPM y salida a LabVIEW.

if (set_point > frecuencia) PWM1_Set_Duty(255);  // prende
else PWM1_Set_Duty(0);                          // apaga
3.2

Resultado

▶ 30:41

La velocidad oscila alrededor del set point todo el tiempo. Funciona, pero no es un buen control para algo como una caminadora.

Fase 4

Control por software

4.1

Subir o bajar

▶ 35:13

Se compara la salida con el set point: si está por encima, se baja un poco el PWM; si está por debajo, se sube. Por eso ambos deben estar en el mismo rango.

4.2

Resultado

▶ 37:30

Después de un retardo la velocidad se estabiliza casi sobre la línea, con mucha menos oscilación que el ON-OFF.

Fase 5

PID

5.1

La función

▶ 40:57

Es la misma función pid discreta de los otros videos, con la salida limitada a 0-255. Las constantes se ajustan a mano empezando por la proporcional.

5.2

Ajuste

▶ 43:12

Solo con proporcional la velocidad queda un poco por debajo; al agregar integral se elimina ese error. Si se suben mucho las ganancias aparecen oscilaciones fuertes.
