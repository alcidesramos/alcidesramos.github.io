Leer señales analógicas con el ADC

Lección 19 del curso. Primero la teoría: un ADC de 10 bits da códigos de 0 a 1023 y con 5 V de referencia cada código vale unos 4.887 mV; además, la señal debe muestrearse al menos al doble de su frecuencia (Nyquist). Leer un canal siempre lleva tres pasos: poner el pin como análogo, ponerlo como entrada y leerlo con ADC_Read. Se hace el ejemplo en un PIC16F877A con un potenciómetro y un LM35, mostrando el código, el voltaje y la temperatura, y después se pasa el mismo programa al PIC16F887 y al PIC18F45K22, que configuran los pines análogos de otra forma.

Fase 1

Teoría del ADC

1.1

Resolución de 10 bits

▶ 0:00

El ADC de los PIC es de 10 bits: hay 210 = 1024 códigos, de 0 a 1023. Con referencia de 0 a 5 V, cada código vale 5/1023 = 4.887 mV. Así, 0 V da el código 0 y 5 V da 1023.

  • El LM35 entrega 10 mV por cada grado: 20 mV son 2 °C.
  • Un sensor de 1 mV por grado no se notaría, porque es menor que la resolución.
1.2

Frecuencia de muestreo

▶ 2:40

Para reconstruir una señal hay que tomar suficientes muestras. Por el teorema de Nyquist, la frecuencia de muestreo debe ser al menos el doble de la frecuencia de la señal; con más muestras, la señal se ve más parecida a la original.

Fase 2

ADC en el 16F877A

2.1

Los tres pasos

▶ 5:20

Para leer cualquier canal análogo:

  • Configurar el pin como análogo.
  • Configurar el pin como entrada (TRIS en 1).
  • Leer el canal con ADC_Read(canal), que devuelve un valor de 0 a 1023.
2.2

ADCON1 y su tabla

▶ 11:00

En el 16F877A los pines análogos se escogen con los bits PCFG de ADCON1, según la tabla de la hoja de datos. Algunas combinaciones útiles:

  • 0b0110: todo digital.
  • 0b0000: todo análogo.
  • 0b1110: solo AN0 análogo.
  • 0b0100: AN0, AN1 y AN3 análogos.
2.3

Mostrar el código en la LCD

▶ 16:40

Se lee el canal 0 y se muestra el código con sprinti. La variable debe ser unsigned int.

unsigned int codigo;

ADCON1 = 0b0100;   // AN0, AN1 y AN3 análogos
TRISA0_bit = 1;
TRISA1_bit = 1;

while (1) {
  codigo = ADC_Read(0);
  sprinti(texto, "Codigo=%4u", codigo);
  Lcd_Out(1, 1, texto);
  Delay_ms(100);
}
2.4

Voltaje y temperatura

▶ 19:40

El código se pasa a voltaje multiplicando por 5.0 y dividiendo por 1023.0. Para el LM35, el voltaje se multiplica por 100 para tener grados. El flotante se convierte con la función float_to_str_ de la lección 18, y el símbolo de grado se escribe con Lcd_Chr_CP(223).

codigo = ADC_Read(0);
voltaje = codigo * 5.0 / 1023.0;
floattostr_(voltaje, texto, 2);
Lcd_Out(1, 1, "volt=");
Lcd_Out_CP(texto);
Lcd_Chr_CP('V');

codigo = ADC_Read(1);
temperatura = codigo * 500.0 / 1023.0;
floattostr_(temperatura, texto, 2);
Lcd_Out(2, 1, "temp=");
Lcd_Out_CP(texto);
Lcd_Chr_CP(223);   // símbolo de grado
Lcd_Chr_CP('C');
Fase 3

Otros micros

3.1

PIC16F887: ANSEL y ANSELH

▶ 25:40

El 16F887 no usa la tabla de ADCON1: cada canal tiene su bit. ANSEL maneja AN0 a AN7 y ANSELH AN8 a AN13; un 1 es análogo y un 0 digital. Por ejemplo, AN8 es ANSELH.B0. En el ejemplo el potenciómetro pasa a RA5 (AN4) y el LM35 a RB2 (AN8).

ANSEL  = 0;  ANSELH = 0;   // todo digital
ANSEL.B4  = 1;   // AN4 en RA5
ANSELH.B0 = 1;   // AN8 en RB2
TRISA5_bit = 1;
TRISB2_bit = 1;
3.2

PIC18F45K22: ANSELA a ANSELE

▶ 34:00

El 18F45K22 tiene un registro por puerto, de ANSELA a ANSELE, y bits como ANSA0_bit o ANSB1_bit (que es AN10). Al tener más memoria, aquí sí se puede usar sprintf con flotantes, por ejemplo "Volt=%5.3fV".

ANSELA = 0; ANSELB = 0; ANSELC = 0;
ANSELD = 0; ANSELE = 0;
ANSA0_bit = 1;   // AN0
ANSB1_bit = 1;   // AN10

sprintf(texto, "Volt=%5.3fV", voltaje);
