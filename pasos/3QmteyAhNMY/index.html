Motores paso a paso con LabVIEW y XC8

El PIC16F1824 maneja dos motores paso a paso de cuatro hilos: el motor 1 en RA0, RA1, RA2 y RA4 y el motor 2 en RC0 a RC3. Desde LabVIEW se envía por serial el sentido, la velocidad y si el motor gira continuo o un número de pasos. En el MCC se configuran los pines, el Timer0 con preescalador de 256 y la EUSART a 9600. El código de MikroC se copia casi igual; lo que cambia es el acceso a bits de la secuencia, que en XC8 se hace con una unión con campos de bits, y la interrupción, que se llama desde el archivo que genera el MCC. En el Timer0 cada motor suma un contador y da un paso cuando llega al valor de su velocidad.

2.4

Bits con una unión

▶ 11:33

MikroC permite leer un bit con .b0; XC8 no. Se crea una unión con campos de bits para sacar cada bit de la secuencia a su pin.

// typedef union char_ { ... } con un campo de bits por cada bit (ver video)

void saca_secuencia1(void)
{
  pasos1++;
  // m11 = bit 0 de codigo1[secuencia1], m12 = bit 1, ...
}

void izquierda1(void)
{
  secuencia1--;
  if (secuencia1 < 0) secuencia1 = n_pasos;
  saca_secuencia1();
}

En cada desborde del Timer0 se suma el contador de cada motor. Cuando llega al valor de velocidad da un paso; en modo pasos se detiene al completar los pedidos.

velo1++;

Ciclo principal

▶ 20:54

Cuando llega una trama completa se procesa, se limpia y se reactiva la recepción. El LED de RA5 parpadea cada 500 ms.

printf("INICIANDO");

while (1)
{
  if (flag_rx == 1)
  {
    procesarx();
    puntero = 0;
    memset(trama_rx, 0, 30);

    RCIF = 0;
    RCIE = 1;
  }

}
