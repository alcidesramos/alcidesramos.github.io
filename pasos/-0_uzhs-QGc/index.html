Velocista con control PID

Se repasa el diagrama de un PID y su forma discreta: el error es setpoint menos entrada, la parte proporcional es kp por el error, la integral acumula ki por el tiempo de muestreo por el error y la derivativa es kd por el cambio del error sobre el tiempo de muestreo. La suma se limita a la velocidad de giro máxima y se guardan la integral y el error anteriores. El tiempo de muestreo se deja en 1. Para corregir más rápido se crea aplica_pwm_fast, que permite valores entre -255 y 255 e invierte el giro del motor cuando el valor es negativo. Se prueba en Proteus, se invierte la salida y se ajusta: kp 30 y kd 2, luego velocidades de 140 y 120, y por último ki 0,1. El robot termina la pista y le gana al ejemplo.

Fase 2

Programa

2.1

La función PID

▶ 5:13

El tiempo de muestreo se deja en 1 y se ajusta según los datos. La salida se limita y se guardan la integral y el error para la siguiente vuelta. La salida va invertida a los motores.

const float t_muestreo = 1;  // se ajusta según los datos obtenidos
// calculando el error
error = setpoint - pid_in;

up = kp * error;
ui = ui_ + (ki * t_muestreo * error);
ud = kd * (error - error_) / t_muestreo;

ut = up + ui + ud;
if (ut > max_x) ut = max_x;
if (ut < min_x) ut = min_x;

ui_ = ui;       // guarda salida integral anterior
error_ = error;
aplica_pwm_fast(-ut);

2.3

PWM rápido

▶ 11:06

Para corregir más rápido, aplica_pwm_fast permite valores negativos: si la velocidad es negativa se invierte el giro de ese motor.

void aplica_pwm_fast(float pwm_vel)
{
  velo_der = velo_basica - pwm_vel;   // uno gana velocidad
  velo_izq = velo_basica + pwm_vel;   // otro pierde velocidad

  if (velo_der < -255) velo_der = -255;
  if (velo_der > 255) velo_der = 255;
  if (velo_izq < -255) velo_izq = -255;
  if (velo_izq > 255) velo_izq = 255;

  // determina el giro de los motores
  if (velo_der <= 0) m1_g = 1;   // invierte giro
  else m1_g = 0;

  if (velo_izq <= 0) m2_g = 1;   // invierte giro
  else m2_g = 0;
  // ... luego se aplica el PWM con el valor absoluto
}
