Posición y velocidad de encoders de cuadratura

Sin librerías, paso a paso: se configura el TIM3 en modo encoder (TI1 y TI2, 4X) con interrupción, se arranca con HAL_TIM_Encoder_Start_IT y en HAL_TIM_IC_CaptureCallback se lee el contador y se convierte a una posición con signo. La velocidad se calcula en el SysTick cada 500 ms. Se ven las variables en tiempo real con Live Expressions del depurador y luego por puerto serial. Al final se agrega un segundo encoder en el TIM1.

▶ Ver el video completo (25:34) Empezar el paso a paso
  • STM32F411 (Black Pill) a 100 MHz
  • Encoder tipo perilla en PA6/PA7 (TIM3)
  • Motor DC con encoder en PA8/PA9 (TIM1)
  • Conversor USB-serial (TX en PB6, RX en PA10)
  • ST-Link para usar Live Expressions

Fase 1

El encoder de cuadratura

1.1

La tarjeta

▶ 0:00

La tarjeta tiene un encoder tipo perilla en PA6 y PA7 y el encoder del motor en PA8 y PA9. El USART1 transmite por PB6 y recibe por PA10. El puente H se verá en otro video.

1.2

Modos de conteo

▶ 1:36

1X cuenta solo el flanco de subida de un canal; 2X cuenta subida y bajada de un canal; 4X cuenta los cuatro flancos de los dos canales, así que da 4 pulsos por ciclo. Lo más usado es 4X; solo reduce la resolución si el motor es muy rápido.

Fase 2

Configurar el primer encoder

2.1

Reloj a máxima velocidad

▶ 3:22

Crea el proyecto (encoder_canal) para el STM32F411. En RCC activa el cristal externo (HSE) y en Clock Configuration usa el PLL para llegar a 100 MHz, el máximo de este micro, para responder bien a encoders rápidos.

2.2

TIM3 en modo encoder

▶ 3:55

En Timers > TIM3 elige Combined Channels: Encoder Mode; se habilitan PA6 y PA7. En Parameter Settings pon Encoder Mode en TI1 and TI2 (4X); TI1 o TI2 solos dan 2X. En NVIC habilita la interrupción global del TIM3.

Activa también USART1 asíncrono (115200) y mueve su TX a PB6 si tu tarjeta lo usa así.

Fase 3

Leer la posición

3.1

Variables

▶ 6:04

encoder_pulsos guarda el contador del timer (0 a 65535 en un timer de 16 bits). Para tener posiciones negativas al girar a la izquierda se convierte a int16_t, que parte el rango a la mitad.

/* USER CODE BEGIN PV */
#define encoder_res 4   // 4X (2 si usas 2X)

uint32_t encoder_pulsos = 0;
int16_t  encoder_pos = 0;
/* USER CODE END PV */
3.2

Arrancar el encoder con interrupción

▶ 7:14

Antes del while arranca el timer en modo encoder con interrupción. Como son dos canales se usa TIM_CHANNEL_ALL.

HAL_TIM_Encoder_Start_IT(&htim3, TIM_CHANNEL_ALL);
3.3

Encontrar el callback

▶ 7:48

En lugar de usar la interrupción propia de cada timer en stm32f4xx_it.c, es mejor usar el callback global de input capture y ver qué timer lo produjo. Está en Drivers > STM32F4xx_HAL_Driver > Src > stm32f4xx_hal_tim.c como función __weak.

Si el archivo no muestra el código por ser muy grande, ve a Window > Preferences > C/C++ > Editor > Scalability y desmarca las opciones de ese apartado.

3.4

Calcular la posición

▶ 9:29

Copia HAL_TIM_IC_CaptureCallback a main.c (en USER CODE BEGIN 0) sin la palabra __weak. Si la interrupción es del TIM3 se lee el contador, se convierte a entero con signo y se divide entre la resolución.

void HAL_TIM_IC_CaptureCallback(TIM_HandleTypeDef *htim)
{
    //VERIFICA QUE ES DEBIDO AL TIMER3
    if (htim->Instance == TIM3)
    {
        encoder_pulsos = __HAL_TIM_GET_COUNTER(&htim3);
        encoder_pos = (int16_t)encoder_pulsos / encoder_res;
    }
}
3.5

Ver las variables en vivo

▶ 11:08

Entra en depuración, pulsa Resume y en la pestaña Live Expressions agrega encoder_pulsos y encoder_pos. Al girar a la derecha la posición sube; a la izquierda encoder_pulsos salta a 65535 pero encoder_pos se vuelve negativa.

Fase 4

Calcular la velocidad

4.1

Variables de velocidad

▶ 12:48

Se usa la posición actual y la anterior, separadas por un tiempo exacto que cuenta el SysTick (interrupción de 1 ms).

int16_t encoder_vel_act = 0, encoder_vel_ant = 0;
float   encoder_velocidad = 0;
4.2

Externas en stm32f4xx_it.c

▶ 13:22

En Core/Src/stm32f4xx_it.c declara esas variables como externas y crea ahí el contador de tiempo.

/* USER CODE BEGIN PV */
extern int16_t encoder_vel_act, encoder_vel_ant;
extern float encoder_velocidad;
uint16_t encoder_vel_cont = 0;
/* USER CODE END PV */
4.3

Velocidad en el SysTick_Handler

▶ 13:55

Cada 500 ms la velocidad es la posición actual menos la anterior dividida entre 0,5 s. Con 200 ms dividirías entre 0,2; cuanto menor el tiempo, más carga para el micro.

void SysTick_Handler(void)
{
    /* USER CODE BEGIN SysTick_IRQn 0 */
    encoder_vel_cont++;
    if (encoder_vel_cont > 500)
    {
        encoder_velocidad = encoder_vel_act - encoder_vel_ant;
        encoder_velocidad = encoder_velocidad / 0.5;  // porque fue 500 ms
        encoder_vel_ant = encoder_vel_act;
        encoder_vel_cont = 0;
    }
    /* USER CODE END SysTick_IRQn 0 */
    HAL_IncTick();
}
4.4

Guardar la posición actual

▶ 15:39

En la primera prueba la velocidad no cambiaba: faltaba copiar la posición en encoder_vel_act dentro del callback.

encoder_pulsos = __HAL_TIM_GET_COUNTER(&htim3);
encoder_pos = (int16_t)encoder_pulsos / encoder_res;
encoder_vel_act = encoder_pos;
4.5

Probar la velocidad

▶ 16:16

En Live Expressions agrega encoder_velocidad. Quieto da 0; girando despacio da 2 o 4 y rápido 14 o 32. Hacia la izquierda la velocidad es negativa (-20).

Fase 5

Ver los datos por serial

5.1

Librería uart y float en printf

▶ 16:48

Copia uart.c/uart.h a la carpeta Librerias e incluye stdio.h, stdint.h, stdlib.h y string.h. En Properties > C/C++ Build > Settings > MCU Settings marca Use float with printf, porque la velocidad es flotante. Crea char texto[100];.

5.2

Enviar posición y velocidad

▶ 18:35

En el while envía la posición y la velocidad cada 200 ms; un retardo muy largo puede hacer perder lecturas.

while (1)
{
    sprintf(texto, "POS1=%d    VE1=%.1f\r\n\r\n", encoder_pos, encoder_velocidad);
    uartx_write_text(&huart1, texto);
    HAL_Delay(200);
}
Fase 6

Segundo encoder

6.1

TIM1 en modo encoder

▶ 20:53

Configura TIM1 en Encoder Mode con TI1 and TI2. Este timer tiene varias interrupciones: habilita la de capture compare (TIM1 capture compare interrupt).

6.2

Variables y callback del encoder 2

▶ 22:04

Duplica las variables con el prefijo encoder2_ y agrega un if para el TIM1 en el callback. Arráncalo igual que el primero.

uint32_t encoder2_pulsos = 0;
int16_t  encoder2_pos = 0;
int16_t  encoder2_vel_act = 0, encoder2_vel_ant = 0;
float    encoder2_velocidad = 0;

// en HAL_TIM_IC_CaptureCallback
if (htim->Instance == TIM1)
{
    encoder2_pulsos = __HAL_TIM_GET_COUNTER(&htim1);
    encoder2_pos = (int16_t)encoder2_pulsos / encoder_res;
    encoder2_vel_act = encoder2_pos;
}

// antes del while
HAL_TIM_Encoder_Start_IT(&htim1, TIM_CHANNEL_ALL);
6.3

Velocidad del encoder 2

▶ 23:50

En stm32f4xx_it.c agrega las externas del encoder 2 y en el SysTick repite las tres líneas del cálculo con sus variables (el contador de tiempo es el mismo).

extern int16_t encoder2_vel_act, encoder2_vel_ant;
extern float encoder2_velocidad;

// dentro del if (encoder_vel_cont > 500)
encoder2_velocidad = encoder2_vel_act - encoder2_vel_ant;
encoder2_velocidad = encoder2_velocidad / 0.5;
encoder2_vel_ant = encoder2_vel_act;
6.4

Resultado

▶ 24:57

Por el serial salen POS1/VE1 y POS2/VE2: la perilla y el eje del motor se leen al mismo tiempo por interrupciones, con velocidad positiva o negativa según el sentido. En el siguiente video todo esto se agrupa en una librería con estructuras.

sprintf(texto, "POS1=%d  VE1=%.1f  POS2=%d  VE2=%.1f\r\n",
        encoder_pos, encoder_velocidad, encoder2_pos, encoder2_velocidad);
