Clase 148: librerías GPS actualizadas y alarma por ubicación

Actualizo las librerías de GPS de la clase 7, ahora más optimizadas. Con las tramas NMEA RMC y GGA se obtiene casi todo: hora, fecha, latitud, longitud, velocidad, rumbo, altitud y calidad de la señal. El proyecto usa un STM32F401 en Proteus: USART1 para enviar datos, USART2 para el GPS con DMA de recepción, y un LED en PA4 como alarma. Con mi emulador de GPS y un puerto virtual se envían las tramas a Proteus, y el LED se enciende cuando la posición está a menos de 200 m del punto de control (el Castillo de San Felipe en Cartagena).

  • Virtual Serial Port con un par COM1–COM2

Fase 1

Tramas NMEA

1.1

Qué trae cada trama

▶ 1:50

Con RMC se obtienen hora, fecha, latitud, longitud, velocidad y rumbo. GGA agrega la altitud, el número de satélites y el indicador de calidad: 0 no es válido (ignorar), 1 hay señal GPS, 2 es diferencial y más preciso.

Fase 2

Proyecto en CubeMX

2.1

Puertos seriales

▶ 2:40

Micro STM32F401. USART1 asíncrono a 9600 para enviar datos y USART2 a 9600 para el GPS. A baja velocidad para no saturar Proteus.

2.2

DMA de recepción del GPS

▶ 3:40

En USART2, pestaña DMA Settings, se agrega el DMA de RX y en NVIC se habilita la interrupción global del USART2. Se agrega PA4 como salida con etiqueta LED (la alarma). Proyecto GPS_CANAL1 con CMake para VS Code.

Si también quiere recibir por el puerto de datos con DMA, haga el mismo procedimiento en USART1.

Fase 3

Circuito en Proteus

3.1

Componentes

▶ 5:40

Blackpill, LED amarillo con resistencia de 220 Ω en PA4 y un COMPIM que hace de GPS externo. El COMPIM se configura en COM1 a 9600 y el emulador de GPS envía por COM2 a 9600 (par creado con Virtual Serial Port).

3.2

Terminales virtuales

▶ 10:40

Una terminal MICRO en TX1 para ver lo que envía el micro y otra GPS en RX2 para ver las tramas que llegan. En Proteus el COMPIM es directo (RX con RX), no cruzado como un GPS real.

Arranque primero la simulación de Proteus y luego el emulador. Si lo hace al revés, Windows acumula tramas en el buffer y Proteus se bloquea. Guarde el proyecto de Proteus a menudo.

Fase 4

Librerías en VS Code

4.1

Copiar las librerías

▶ 12:00

En una carpeta LIBRERIAS del proyecto se copian gps.c/gps.h, UARTRX.c/UARTRX.h, UART_INT_DMA_IDLE.c y uart.c/uart.h. Con el botón CMake ARZ se agregan al CMakeLists y se pasa la FPU a software para simular.

#include "stdio.h"
#include "string.h"
#include "stdlib.h"
#include "math.h"

#include "uart.h"
#include "gps.h"
#include "UARTRX.h"
4.2

Probar el puerto serial

▶ 16:55

Antes de seguir, se envía un texto por USART1 para comprobar que todo compila y llega a la terminal MICRO.

uartx_write_text(&huart1, "INICIANDO\r\n");
Fase 5

Configurar la recepción del GPS

5.1

Declarar los puertos de recepción

▶ 18:30

En UARTRX.c se declara una variable por cada puerto que recibe. Para el GPS se usa GPS_UARTRX asociada a huart2/USART2 con un buffer grande, de unos 1000 bytes.

UARTRXS UARTRX1    = {&huart1, USART1, 100};
UARTRXS GPS_UARTRX = {&huart2, USART2, 1000};
5.2

Interrupción de recepción

▶ 20:40

En UART_INT_DMA_IDLE.c se incluye gps.h y en el callback de recepción se llama el procesamiento del GPS, igual que en el de errores. Las instrucciones exactas están comentadas en gps.h.

#include "main.h"
#include "UARTRX.h"
#include "gps.h"

void HAL_UARTEx_RxEventCallback(UART_HandleTypeDef *huart, uint16_t Size)
{
  uartRX_INTERRUPT(huart, Size);
  // + la llamada del GPS indicada en gps.h
}

void HAL_UART_ErrorCallback(UART_HandleTypeDef *huart)
{
  uartRX_Errores(huart);
  // + el manejo de errores del GPS indicado en gps.h
}

El nombre exacto de las funciones del GPS para la interrupción no se lee bien en el video; cópielo del ejemplo que trae gps.h.

5.3

Zona horaria y punto de control

▶ 24:10

En gps.h se ajusta la hora UTC de su país (Colombia es -5), el punto de control y el radio de la alarma en metros.

#define hor_utc    -5          // hora de Colombia UTC -5
#define latitud1   10.42258    // Castillo de San Felipe
#define longitud1  -75.53930
#define presicion  200         // radio de operación en metros
Fase 6

Leer el GPS y la alarma

6.1

Iniciar la recepción

▶ 21:40

Antes del while se inicia la recepción por DMA con interrupción IDLE del puerto del GPS.

uartx_write_text(&huart1, "INICIANDO\r\n");
uartRX_it_idle_dma_init(&GPS_UARTRX);
6.2

Procesar las tramas

▶ 22:40

En el while, cuando llega una trama se leen RMC y GGA, se reinicia el DMA y se envían los datos por USART1. La variable texto se declara como arreglo de char.

char texto[100];

while (1)
{
  if (GPS_UARTRX.flag_rx == 1)   // hay trama de GPS
  {
    GPS_RMC();
    GPS_GGA();
    uartRX_DMA_Re_init(&GPS_UARTRX);   // recepción para otra trama

    sprintf(texto, "LAT=%.5f  LON=%.5f\r\n", latitud, longitud);
    uartx_write_text(&huart1, texto);
    sprintf(texto, "vel=%.2f\r\n", gps_vel_kph);
    uartx_write_text(&huart1, texto);
    sprintf(texto, "Rumbo=%.2f\r\n", gps_rumbo);
    uartx_write_text(&huart1, texto);

    if (estaDentroDelRadio(latitud1, longitud1, latitud, longitud))
    {
      sprintf(texto, "Dentro del radio de operación\r\n");
      uartx_write_text(&huart1, texto);
      HAL_GPIO_WritePin(LED_GPIO_Port, LED_Pin, GPIO_PIN_SET);
    }
    else
    {
      sprintf(texto, "Fuera del radio de operación\r\n");
      uartx_write_text(&huart1, texto);
      HAL_GPIO_WritePin(LED_GPIO_Port, LED_Pin, GPIO_PIN_RESET);
    }
  }
}

Además hay variables para fecha (dia, mes, año), hora, minutos, segundos, altitud y satélites; revise sus nombres en gps.h.

6.3

Probar con el emulador

▶ 28:10

Con Proteus corriendo se abre el puerto en el emulador. La terminal GPS muestra las tramas y la terminal MICRO los datos decodificados; al cambiar rumbo y velocidad en el emulador cambian en la terminal. Al buscar el Castillo de San Felipe el LED se enciende y al alejarse más de 200 m se apaga.

6.4

Ordenar el código

▶ 29:40

Para no saturar el while, todo el bloque se pasa a una función procesa_GPS() y en el while solo se llama esa función. El proyecto queda subido a GitHub.

void procesa_GPS(void);

while (1)
{
  procesa_GPS();
}
