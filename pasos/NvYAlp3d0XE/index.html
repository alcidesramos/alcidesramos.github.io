Monitoreo en Ubidots con PIC y ESP8266

Se crea en Ubidots un device con las variables temperatura y led y un tablero con un medidor y un indicador. El PIC configura el ESP8266 para unirse a la red WiFi con IP fija, abre una conexión TCP con things.ubidots.com por el puerto 80 y en cada ciclo envía un POST con la trama JSON y su largo. Para no gastar RAM se usan funciones propias que envían constantes.

▶ Ver el video completo (21:13) Empezar el paso a paso
  • MikroC PRO for PIC
  • PIC18F2550 a 4 MHz
  • Módulo ESP8266 (por USB como puerto serie)
  • Sensor LM35 y switch
  • Cuenta educativa de Ubidots
  • Hercules para probar
  • Proteus

1.3

Formato de la petición

▶ 3:46

Se envía un POST con el nombre del device y el token, y luego el JSON con las variables. Content-Length es el largo de ese JSON. El token sale de API Credentials en la cuenta.

Se puede probar con Hercules conectando por TCP a things.ubidots.com en el puerto 80.

POST /api/v1.6/devices/micasa/?token=TU_TOKEN HTTP/1.1
Host: things.ubidots.com
Content-Type: application/json
Content-Length: 31

{"temperatura": 49.03,"led": 1}

2.3

Funciones de envío

▶ 9:01

manda_serial_const envía una constante sin gastar RAM. manda_esp8266_const envía datos por el socket 4: manda AT+CIPSEND con el socket y el largo, espera y luego el texto. Hay otra versión igual para variables.

void manda_esp8266_const(const char *info) {
  unsigned int largo;
  manda_serial_const("AT+CIPSEND=");
  UART1_Write('4');          // socket
  UART1_Write(',');
  largo = strlen_const(info);
  sprinti(captu, "%lu", largo);
  UART1_Write_Text(captu);
  manda_serial_const("\r\n");
  Delay_ms(100);
  manda_serial_const(info);
}
2.4

Configuración del ESP8266

▶ 11:44

Puerto serial a 115200 baudios. Se quita el eco con ATE0, se pone en modo estación, se desactiva el DHCP y se da una IP fija dentro de la red del router, con la puerta de enlace y la máscara. Luego se une a la red WiFi.

UART1_Init(115200);
manda_serial_const("ATE0\r\n");            // sin eco
manda_serial_const("AT+CWMODE=1\r\n");      // estacion
manda_serial_const("AT+CWDHCP=1,0\r\n");    // sin DHCP
manda_serial_const("AT+CIPSTA=\"192.168.1.50\",\"192.168.1.1\",\"255.255.255.0\"\r\n");
manda_serial_const("AT+CWJAP=\"tu_red\",\"tu_clave\"\r\n");
2.5

Conectar con Ubidots

▶ 13:57

Se aceptan múltiples conexiones, se revisa la IP y se abre la conexión TCP por el socket 4.

manda_serial_const("AT+CIPMUX=1\r\n");
Delay_ms(300);
manda_serial_const("AT+CIFSR\r\n");          // mira la IP
Delay_ms(1000);
manda_serial_const("AT+CIPSTART=4,\"TCP\",\"things.ubidots.com\",80\r\n");
Delay_ms(3000);

Se lee la temperatura y el switch, se arma el JSON con sprintf, se calcula su largo y se le suman los dos fines de línea. Luego se envía el POST (con el device y el token propios), el largo y la trama.

codigo = ADC_Read(0);
temperatura = codigo * 500.0 / 1023.0;
if (suiche == 0) led = '0'; else led = '1';
