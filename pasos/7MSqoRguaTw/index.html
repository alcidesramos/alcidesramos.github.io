Control y monitoreo WiFi con DT-06 y LabVIEW

Se usa el mismo programa del STM32 de la clase 93 (que ya entiende V00 y V01), con el envío de monitoreo acelerado a 10 ms. En LabVIEW se mantiene el ciclo de lectura (TCP Read con Match Pattern para A00 y A01) y se agrega otro while que usa la misma conexión TCP con TCP Write. Dentro de una Event Structure, el evento Value Change del botón elige con Select la cadena !V00=1$ o !V00=0$, y el evento Value Change del dial arma con Concatenate Strings !V01= + valor + $. A diferencia de Virtuino, todo responde casi en tiempo real.

Fase 1

Punto de partida

1.1

Dirección y puerto por defecto

▶ 0:00

Se abre el VI de monitoreo, se escribe la IP del DT-06 (192.168.4.1) y el puerto 200, y con clic derecho → Data Operations → Make Current Value Default quedan guardados.

1.2

Monitoreo más rápido

▶ 0:33

En el STM32 el envío de monitoreo se baja a 10 ms. Con LabVIEW el termómetro y el LED del pulsador responden casi al instante, algo que Virtuino no lograba.

Fase 2

Ciclo de escritura

2.1

Segundo while con TCP Write

▶ 2:16

Se crea otro while (con condición de paro en una constante falsa; el programa se detiene con el botón de LabVIEW) y dentro un TCP Write conectado a la misma referencia de conexión de TCP Open. Al final también se cierra con TCP Close Connection.

2.2

Evento del botón

▶ 3:46

Se encierra el TCP Write en una Event Structure y se agrega un botón en el panel. El evento es Value Change del botón: con un Select, si es verdadero se envía !V00=1$ y si es falso !V00=0$.

Evento: "Boolean": Value Change
Select(NewVal):  True  -> "!V00=1$"
                 False -> "!V00=0$"
-> TCP Write
2.3

Prueba del LED

▶ 6:35

Al pulsar el botón en el panel el LED de la tarjeta se apaga o se prende de inmediato, mientras la temperatura y el pulsador se siguen leyendo.

Fase 3

Control analógico

3.1

Evento del dial

▶ 7:44

Se agrega un dial de 0 a 100 y se duplica el evento para Value Change del dial. Con Concatenate Strings se arma la trama: constante !V01=, el valor convertido con Number To Fractional String (use system decimal point = False) y la constante $.

Evento: "Dial": Value Change
Concatenate Strings( "!V01=" , NumberToFractionalString(NewVal) , "$" )
-> TCP Write
3.2

Resultado

▶ 9:59

Al girar el dial a 40 o 90 el analizador lógico muestra el cambio de ancho de pulso casi en tiempo real, y el botón sigue controlando el LED. Con el DT-06 cualquier microcontrolador puede monitorearse y controlarse por WiFi desde un PC o un celular.
