Serial full duplex en PIC y Arduino

Se toma el programa de recepción por interrupción y se le agrega transmisión: el micro lee un LM35 y un pulsador y manda los datos en una trama que LabVIEW sabe separar. Primero se migra el proyecto a un PIC18F25K20, más moderno, y luego se arma la trama con FloatToStr y con sprintf. En Arduino se hace con Serial.print y dtostrf, porque su sprintf no maneja flotantes.

Fase 1

Migrar el micro

1.1

Un PIC más moderno

▶ 0:00

El mismo programa se pasa a un PIC18F25K20, más actual y con más recursos. En la configuración del proyecto solo se cambia el micro.

1.2

Cambios necesarios

▶ 3:57

Los PIC18 tienen dos vectores de interrupción, así que el de alta prioridad pasa a 0x0008. También hay que poner los pines como digitales con ANSEL y ANSELH.

1.3

Funciona igual

▶ 5:49

Con esos cambios el programa compila y funciona igual en el nuevo micro.

Fase 2

Agregar transmisión

2.1

Sensor y pulsador

▶ 7:44

Se agregan un LM35 en el canal analógico 0 y un pulsador. Solo ese canal queda analógico; el resto, digital.

2.2

Variables

▶ 11:56

Se agregan el código del ADC, la temperatura y una cadena para pasar el número a texto.

#define suiche RB7_bit
unsigned int codigo;
float temperatura;
char texto[20]; // número a cadena
2.3

Mandar la temperatura

▶ 13:06

Se lee el canal, se calcula la temperatura del LM35 (500/1023 por cuenta) y se manda con el formato temp=valor/ para que LabVIEW lo encuentre.

codigo = ADC_Read(0);
temperatura = codigo*500.0/1023.0;
FloatToStr_FixLen(temperatura, texto, 5);
UART1_Write_Text("temp=");
UART1_Write_Text(texto);
UART1_Write('/');
2.4

Mandar el switch

▶ 17:38

Si el pulsador está en 1 se manda led=on/; si no, led=off/. LabVIEW enciende el indicador según lo que haya entre el '=' y la '/'.

if (suiche == 1) UART1_Write_Text("led=on/");
else UART1_Write_Text("led=off/");
2.5

Prueba

▶ 19:44

El panel muestra la temperatura y el switch mientras sigue mandando órdenes al micro: transmisión y recepción al mismo tiempo.

2.6

Con sprintf

▶ 20:19

sprintf arma la trama completa con el formato que uno quiera, incluidos los decimales.

sprintf(texto, "temp=%4.2f/", temperatura);
UART1_Write_Text(texto);
Fase 3

Arduino

3.1

Con Serial.print

▶ 23:13

En Arduino se lee con analogRead y digitalRead y se manda con Serial.print, que convierte el flotante solo (con dos decimales).

codigo = analogRead(0);
temperatura = codigo*500.0/1023.0;
Serial.print("temp=");
Serial.print(temperatura);
Serial.print("/");
if (digitalRead(suiche) == 1) Serial.print("led=on/");
else Serial.print("led=off/");
3.2

sprintf y flotantes

▶ 32:46

El sprintf de Arduino no maneja %f y manda un signo de interrogación. La solución es convertir primero con dtostrf y luego mandar el texto.

dtostrf(temperatura, 5, 2, texto);
Serial.print("temp=");
Serial.print(texto);
