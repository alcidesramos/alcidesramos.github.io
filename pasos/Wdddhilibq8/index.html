Radar con mini LIDAR, servo, STM32 y LabVIEW

Muestra breve de un prototipo para un vehículo explorador. Un servo mueve un mini LIDAR de -90° a 90° y de regreso; en cada ángulo el STM32F103 (Blue Pill) lee la distancia y la envía por dos caminos: un puerto USB CDC hacia el computador (para la prueba) y el USART3, donde irá un módem inalámbrico porque el vehículo no estará conectado al PC. En LabVIEW se lee la trama y se dibuja un gráfico polar con lo que el vehículo tiene al frente.

Fase 1

El hardware y la configuración

1.1

El prototipo

▶ 0:00

El LIDAR va montado sobre el servo y conectado a la Blue Pill. El servo hace el barrido de todo el recorrido.

1.2

Puertos del micro

▶ 0:33

En el .ioc del STM32F103C8 se usan:

  • USART1: el LIDAR.
  • USB_DEVICE (CDC): crea un puerto COM en el computador para la prueba.
  • USART3: el módem inalámbrico, para que la información llegue a distancia.
  • Un timer en PWM para el servo, con su librería (rango en grados y en milisegundos).
Fase 2

El programa

2.1

Barrido del servo

▶ 1:40

Para cada ángulo de -90 a 90 se posiciona el servo, se lee el LIDAR y se envía la trama (dos veces, para que haya redundancia) por el USART3 y por el USB. Después se repite de 90 a -90.

for (int8_t cont = -90; cont <= 90; cont++)
{
  servo1_pos(cont);
  lidar();
  sprintf(texto, "INI/%u/%d/INI/%u/%d/*\r\n", distancia, cont, distancia, cont);
  uartx_write_text(&huart3, texto);   // módem inalámbrico
  usb_uart_write(texto);              // puerto USB de prueba
}
2.2

Leer el LIDAR

▶ 2:12

Se reciben 25 bytes, se busca el inicio de la trama (0x59) y con los bytes siguientes se arman la distancia y la fuerza de la señal.

void lidar()
{
  memset(trama_rx, 0, 100);
  HAL_UART_Receive(&huart1, trama_rx, 25, 300);
  char pos = procesa_rx();      // busca el 0x59
  lidar_low  = trama_rx[pos+2];
  lidar_hihg = trama_rx[pos+3];
  distancia = ((unsigned int)lidar_hihg << 8) | lidar_low;
  lidar_low  = trama_rx[pos+4];
  lidar_hihg = trama_rx[pos+5];
  fuerza = ((unsigned int)lidar_hihg << 8) | lidar_low;
}
Fase 3

LabVIEW

3.1

Ver el entorno

▶ 2:20

En LabVIEW se elige el COM que creó el USB (VISA resource) y la distancia máxima. Al dar Play, el gráfico polar muestra a qué distancia están los objetos en cada ángulo, como un radar: si acercas la mano, el trazo se hace más pequeño.

3.2

Cómo se lee la trama

▶ 3:16

El diagrama de bloques lee los bytes del puerto (Bytes at Port y VISA Read), separa el ángulo y la distancia de la trama INI/…/*, los guarda en un vector y los pasa al gráfico.
