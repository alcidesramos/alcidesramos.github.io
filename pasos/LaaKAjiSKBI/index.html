GitHub Copilot en VS Code aplicado a STM32 en C

En esta clase pruebo por primera vez GitHub Copilot dentro de Visual Studio Code con un proyecto STM32 en C. Vemos los modos de chat (ask, agent y plan), cómo darle contexto, cómo le pido que haga el parpadeo de un LED, que cree una librería para leer el ADC1 y que la integre con el puerto serial. También agrego mi carpeta de librerías al espacio de trabajo para que use mi uart.c, y uso las sugerencias en línea escribiendo un comentario. Todo se simula en Proteus con un potenciómetro en el ADC y una terminal virtual.

3.1

Parpadeo del LED

▶ 7:40

Le pido en modo agente que haga parpadear el LED. Copilot agrega el código dentro del while(1) y muestra los cambios para aceptarlos o descartarlos.

HAL_GPIO_TogglePin(LED_GPIO_Port, LED_Pin);

Revise siempre lo que propone antes de aceptar: el código que sugiere puede variar según el contexto.

3.2

Crear la librería ADC1

▶ 9:05

Le pido una librería para leer el ADC. Crea LIBRERIAS/ADC1.c y ADC1.h. Al principio hubo errores de include; se corrigen incluyendo main.h y el propio encabezado, y agregando la carpeta al CMakeLists.

#include "main.h"
#include "ADC1.h"

extern ADC_HandleTypeDef hadc1;

uint32_t ADC1_Read(void){
  uint32_t value = 0;
  HAL_ADC_Start(&hadc1);
  if(HAL_ADC_PollForConversion(&hadc1, 10) == HAL_OK){
    value = HAL_ADC_GetValue(&hadc1);
  }
  HAL_ADC_Stop(&hadc1);
  return value;
}

La línea extern de hadc1 es necesaria si la librería no la ve desde main.h; ajústela a su proyecto.

3.3

Enviar el valor por serial

▶ 10:10

Copilot integra la lectura en main y la envía por USART1. En Proteus la terminal muestra el valor al mover el potenciómetro.

uint32_t adc_val = ADC1_Read();
char msg[48];
int len = snprintf(msg, sizeof(msg), "ADC1=%lu\r\n", (unsigned long)adc_val);
if(len > 0){
  HAL_UART_Transmit(&huart1, (uint8_t*)msg, (uint16_t)len, 100);
}
HAL_Delay(200);

Fase 5

Sugerencias en línea

5.1

Promedio de N muestras

▶ 17:40

Basta con escribir un comentario que describa la función; Copilot sugiere el código en gris y se acepta con Tab.

//FUNCION QUE CALCULA EL PROMEDIO DE N MUESTRAS DEL ADC
uint32_t ADC1_Read_Average(uint8_t samples){
  uint32_t sum = 0;
  for(uint8_t i = 0; i < samples; i++){
    sum += ADC1_Read();
    HAL_Delay(10);
  }
  return sum / samples;
}
5.2

Convertir a voltaje

▶ 19:25

Con otro comentario sugiere la conversión a voltios usando 3.3 V y 4095 cuentas (12 bits).

float ADC1_Read_Voltage(uint8_t samples){
  uint32_t avg = ADC1_Read_Average(samples);
  return (avg * 3.3f) / 4095.0f;
}

El cuerpo exacto que sugirió puede diferir; la idea es promedio × 3.3 / 4095. Para imprimir float recuerde habilitar printf con float en CMake.

6.1

Mi impresión

▶ 23:30
