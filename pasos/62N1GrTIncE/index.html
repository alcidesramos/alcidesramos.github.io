Proteus · parte 3: Blue Pill, Black Pill y Nucleo en esquemático, PCB y 3D

Uso de las librerías propias para Proteus: la Blue Pill y la Black Pill se ven como las tarjetas reales, se simulan, tienen huella para PCB y modelo 3D. También se muestra cómo pasar el programa de la Blue Pill (F103) a la Black Pill (F401) y la Nucleo L476, que solo tiene esquemático, PCB y 3D (no se simula).

▶ Ver el video completo (14:24) Empezar el paso a paso
  • Librerías: LIBRERIAS_PROTEUS_2026
  • Software: Proteus 8, STM32CubeMX, Keil µVision o CubeIDE
  • Archivos 3D: BLUEPILL.step, BLACKPILL.step, NUCLEO L476.STEP

Fase 1

Instalar las librerías

1.1

Copiar las librerías y los modelos 3D

▶ 0:00
  • Las dos librerías (esquemático ARZ.LIB y PCB ARZ_PCB.LIB) van sí o sí en C:\Program Files (x86)\Labcenter Electronics\Proteus 8 Professional\DATA\LIBRARY.
  • Los archivos 3D (.step) van donde quieras. Se recomienda DATA\MODELS, donde Proteus guarda los suyos.
Fase 2

Blue Pill

2.1

Poner BLUEPILL_ARZ y alimentarla

▶ 1:09

Al buscar BLUEPILL salen la de Proteus y BLUEPILL_ARZ. Lo mínimo para que trabaje: un terminal Power llamado VDD (en mayúscula) y tierra. El reset es opcional.

2.2

Programa a 8 MHz y riel a 3.3 V

▶ 2:17

Doble clic: cristal de 8 MHz y el .hex. En Configure Power Rails, el riel VDD a 3.3 V, como en la clase 5. Con un voltímetro se comprueba que el pin da 3.3 V.

2.3

Modelo 3D en el PCB

▶ 2:51

En PCB Layout aparece la huella. Para el 3D: clic derecho sobre el componente → 3D Model, escoge BLUEPILL.step y en el Offset pon 44mm para que quede centrada. La primera carga es lenta.

Fase 3

Black Pill

3.1

Pasar el proyecto del F103 al F401

▶ 5:38

La lista de micros compatibles de CubeMX no ofrece ningún F4 para el F103. Entonces se hace como en la clase 3: proyecto nuevo con el STM32F401CCU (paquete UFQFPN48) y File → Import Project. El LED queda en PC13. Revisa el reloj (cristal) y genera el código.

3.2

Mismo código, otra tarjeta

▶ 8:27

Pega el código del parpadeo en el main.c nuevo, compila y carga el .hex en BLACKPILL_ARZ (8 MHz).

while (1)
{
  HAL_GPIO_TogglePin(LED_GPIO_Port, LED_Pin);
  HAL_Delay(100);
}
3.3

Black Pill en PCB y 3D

▶ 9:33

Modelo BLACKPILL.step con rotación Z 270, offset Y 6mm y Z 20mm.

Fase 4

Nucleo L476

4.1

Solo esquemático, PCB y 3D

▶ 11:22

Proteus no simula la Nucleo L476, pero la librería sirve para el esquemático, el PCB y la vista 3D. Si no pasa al PCB, en el componente asigna el paquete con Tools → Package. Modelo NUCLEO L476.STEP con offset X 37mm e Y -27mm.
