Velocista: sistema de pesos

Para controlar el robot hace falta saber qué tan lejos está de la línea. A cada sensor se le asigna un peso, de −10 a 10 para seis sensores (−10, −5, −1, 1, 5, 10), sin repetir valores para que cada combinación dé un número distinto. El desvío es la suma de normalizado por peso sobre la suma de normalizados; en Excel se prueba la fórmula. Si todo está en negro (denominador de 5,8 o más) o todo en blanco (0,2 o menos), se devuelve 10 o −10 según el peso anterior, para recordar por dónde se salió el robot. Se usan rangos en lugar de igualdades por los decimales. El desvío va por serial y con él se harán controles P, PID o difusos.

Fase 1

Los pesos

1.1

Qué se necesita

▶ 0:00

Ya se sabe si cada sensor está en la línea. Para un control hay que saber cuánto se aleja el robot: por ejemplo 10 muy a la derecha, 0 en el centro y −10 muy a la izquierda.

1.2

Pesos en Excel

▶ 0:31

Para seis sensores los pesos son −10, −5, −1, 1, 5 y 10 (para ocho se puede llegar a ±40). No deben repetirse para que cada combinación dé un valor distinto.

1.3

La fórmula

▶ 2:11

El desvío es la suma de cada lectura normalizada por su peso, dividida entre la suma de las lecturas. Con dos sensores centrales da 0; al alejarse da 1, 3, 5, 7,5 o 10.

Fase 2

En el programa

2.1

Vector de pesos

▶ 3:17

Se crean el vector de pesos y la variable peso_anterior, que recuerda si el robot se salió por la derecha o por la izquierda.

2.2

Calcular

▶ 4:23

Numerador y denominador se suman en un for; se revisan los casos especiales y luego se divide.

float calcula_pesos() {
  char cuenta;
  float numerador = 0, denominador = 0;
  float valor;
  for (cuenta = 0; cuenta < 6; cuenta++) {
    numerador = normalizados[cuenta] * pesos[cuenta] + numerador;
    denominador = normalizados[cuenta] + denominador;
  }
  // si es todo negro
  if (denominador >= 5.8) {  // indica que todo está en negro
    if (peso_anterior > 0) return (10.0);    // estaba muy a la derecha
    else if (peso_anterior < 0) return (-10.0); // estaba muy a la izquierda
  }
  // si es todo blanco
  else if (denominador <= 0.2) {  // se salió; evita errores de flotante
    if (peso_anterior > 0) return (10.0);
    else if (peso_anterior < 0) return (-10.0);
  }
  else
    valor = numerador / denominador;
  peso_anterior = valor;  // almacena el valor por si se llega a salir de la línea
  return (valor);
}
2.3

Casos especiales

▶ 4:59

Con todo negro el denominador es 6; se compara con 5,8 por los decimales. Con todo blanco es 0; se compara con 0,2. En ambos casos se devuelve el extremo según el peso anterior.

2.4

Enviar el desvío

▶ 7:11

Después de normalizar se calculan los pesos y se manda el desvío por serial.

void manda_caculo_pesos() {
  sprintf(texto, "desvio=%.1f \r\n\r\n", calcula_pesos());
  UART1_Write_Text(texto);
}
